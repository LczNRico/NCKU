# 第三章：結晶固體的結構 — 講義一
## 基礎概念與金屬晶體結構（FCC、BCC、HCP）

---

## 一、基礎概念

### 1.1 結晶 vs. 非結晶固體

| 名稱 | 英文 | 定義 |
|---|---|---|
| 結晶材料 | crystalline material | 原子在**長程**（long-range）內呈週期性、重複排列 |
| 非結晶（非晶質）材料 | noncrystalline / amorphous material | 缺乏長程原子規則排列，結構類似液體（又稱 supercooled liquid） |

**重點觀察**：
- 金屬幾乎都是結晶材料。
- 陶瓷、高分子則可能是結晶、半結晶（semicrystalline）或非結晶。
- 相同成分的材料，結晶態常呈不透明或半透明，非結晶態（如玻璃）常呈透明——這是原子排列規則性差異造成光學性質不同的實例。

### 1.2 晶格、晶胞、原子硬球模型

| 名稱 | 英文 | 說明 |
|---|---|---|
| 晶體結構 | crystal structure | 原子、離子或分子在空間中的排列方式 |
| 晶格 | lattice | 與原子位置（或球心）重合的三維點陣 |
| 晶胞 | unit cell | 能代表整個晶體結構對稱性的最小重複單元（building block） |
| 原子硬球模型 | atomic hard-sphere model | 把原子視為具有明確直徑、彼此相切的實心球 |

> **記憶技巧（類比）**：晶胞就像樂高（Lego）積木的最小單元——只要知道這一小塊的形狀與排列方式，透過整數倍的平移（translation）就能重建整個巨大的晶體結構。

**晶胞選取原則**：
1. 晶胞角點通常與硬球原子中心重合。
2. 同一晶體結構可能有多種晶胞選法，但通常選**幾何對稱性最高**者。

### 1.3 單位晶胞原子數的計算通式（立方系統）

原子依所在位置，只有部分「屬於」該晶胞：

$$N = N_i + \frac{N_f}{2} + \frac{N_c}{8} \quad \text{(3.2)}$$

其中：
- $N_i$：內部原子數（interior atoms，完全屬於該晶胞）
- $N_f$：面心原子數（face atoms，與相鄰一個晶胞共用，故 ÷2）
- $N_c$：角落原子數（corner atoms，與相鄰八個晶胞共用，故 ÷8）

> **易混淆點**：角落原子是被 **8 個**晶胞共用（三維空間中一個角落同時屬於 2×2×2 = 8 個立方體），面心原子是被 **2 個**晶胞共用。六方晶系（HCP）則不同，角落原子由 **6 個**晶胞共用，詳見下方 HCP 段落。

## 二、金屬三大晶體結構總覽

金屬鍵結不具方向性（nondirectional），因此原子傾向以**最密堆積**方式排列，常見三種結構如下：

| 性質 | FCC 面心立方<br>(face-centered cubic) | BCC 體心立方<br>(body-centered cubic) | HCP 六方最密堆積<br>(hexagonal close-packed) |
|---|---|---|---|
| 每晶胞原子數 | 4 | 2 | 6 |
| 原子堆積因子 APF<br>(atomic packing factor) | 0.74 | 0.68 | 0.74 |
| 配位數 CN<br>(coordination number) | 12 | 8 | 12 |
| 晶胞邊長與原子半徑關係 | $a = 2\sqrt{2}\,R$ | $a = \dfrac{4R}{\sqrt{3}}$ | $a = 2R$，$c \approx 1.633a$ |
| 是否為最密堆積結構 | 是 | 否 | 是 |
| 原子相切方向 | 面對角線<br>(face diagonal) | 體對角線<br>(body diagonal) | 底面（basal plane） |
| 代表金屬 | Al, Cu, Ag, Au, Ni, Pt, Pb, γ-Fe（912°C 以上） | α-Fe（常溫）, Cr, W, Mo, V, Na, K | Mg, Zn, Ti, Co, Cd, Zr, Be |

> **考點提醒**：APF 相同（FCC = HCP = 0.74）是本章最常見的混淆點，兩者都是「最密堆積」，差異僅在**堆疊順序**（見講義三），而非堆積效率。

## 三、FCC 面心立方晶體結構詳解

### 3.1 結構描述
原子位於立方體 8 個角落，以及 6 個面的中心。

### 3.2 單位晶胞原子數推導

$$N_c = 8,\quad N_f = 6,\quad N_i = 0$$
$$N = 0 + \frac{6}{2} + \frac{8}{8} = 3 + 1 = 4 \ \text{個原子}$$

### 3.3 晶胞邊長 $a$ 與原子半徑 $R$ 關係式推導

**幾何關係**：面對角線方向上，原子彼此相切，面對角線長度 $= 4R$（角落原子半徑 + 面心原子直徑 + 角落原子半徑，實際上是角落原子與面心原子相切兩次）。

利用直角三角形（面對角線為斜邊，兩邊為晶胞邊長 $a$）：

$$a^2 + a^2 = (4R)^2$$
$$2a^2 = 16R^2$$
$$a = 2\sqrt{2}\,R \approx 2.828R \quad \text{(3.1)}$$

反推：
$$R = \frac{\sqrt{2}}{4}a \approx 0.354a$$

### 3.4 晶胞體積推導（Example Problem 3.1 型）

$$V_C = a^3 = (2\sqrt{2}R)^3 = 16\sqrt{2}\,R^3 \quad \text{(3.6)}$$

### 3.5 原子堆積因子 APF 推導（Example Problem 3.2 型）

$$\text{APF} = \frac{V_S}{V_C} = \frac{\text{晶胞內原子體積和}}{\text{晶胞總體積}}$$

單一原子體積 $= \dfrac{4}{3}\pi R^3$，FCC 每晶胞 4 個原子：

$$V_S = 4 \times \frac{4}{3}\pi R^3 = \frac{16}{3}\pi R^3$$

代入 $V_C = 16\sqrt{2}R^3$：

$$\text{APF} = \frac{\frac{16}{3}\pi R^3}{16\sqrt{2}R^3} = \frac{\pi}{3\sqrt{2}} \approx 0.74$$

> 0.74 是等徑球體所能達到的**最大堆積效率**（連同 HCP），沒有任何等徑球排列方式能超過此值。

### 3.6 配位數

FCC 配位數 = **12**。以正面面心原子為例：與其相鄰接觸的原子包含 4 個角落原子（同層）、4 個面心原子（背後相鄰晶胞貢獻）、以及 4 個面心原子（前方相鄰晶胞貢獻），共 12 個最近鄰。

## 四、BCC 體心立方晶體結構詳解

### 4.1 結構描述
原子位於立方體 8 個角落，以及體心（body center）一個原子。

### 4.2 單位晶胞原子數推導

$$N_c = 8,\quad N_f = 0,\quad N_i = 1$$
$$N = 1 + 0 + \frac{8}{8} = 1 + 1 = 2 \ \text{個原子}$$

### 4.3 晶胞邊長 $a$ 與原子半徑 $R$ 關係式推導

**幾何關係**：原子沿**體對角線**方向相切，體對角線長度 $= 4R$。

先求面對角線：$\sqrt{a^2+a^2} = a\sqrt{2}$

再求體對角線（面對角線與晶胞邊長構成另一直角三角形）：

$$(\text{體對角線})^2 = a^2 + (a\sqrt{2})^2 = a^2 + 2a^2 = 3a^2$$
$$\text{體對角線} = a\sqrt{3} = 4R$$
$$a = \frac{4R}{\sqrt{3}} \approx 2.309R \quad \text{(3.4)}$$

反推：
$$R = \frac{\sqrt{3}}{4}a \approx 0.433a$$

### 4.4 原子堆積因子 APF 推導

$$V_S = 2 \times \frac{4}{3}\pi R^3 = \frac{8}{3}\pi R^3$$

$$V_C = a^3 = \left(\frac{4R}{\sqrt{3}}\right)^3 = \frac{64R^3}{3\sqrt{3}}$$

$$\text{APF} = \frac{\frac{8}{3}\pi R^3}{\frac{64R^3}{3\sqrt{3}}} = \frac{8\pi\sqrt{3}}{64} = \frac{\pi\sqrt{3}}{8} \approx 0.68$$

### 4.5 配位數

BCC 配位數 = **8**。體心原子與 8 個角落原子皆為最近鄰。

> **補充**：簡單立方（simple cubic, SC）只有角落原子（$N=1$，APF ≈ 0.52），因堆積效率過低，自然界中僅有類金屬釙（Po）採此結構，金屬元素均不採用。

## 五、HCP 六方最密堆積晶體結構詳解

### 5.1 結構描述
- 上、下兩個六邊形面，各由 6 個角落原子環繞 1 個面心原子構成。
- 兩面之間的中間層（midplane）另有 3 個內部原子。

### 5.2 單位晶胞原子數推導（注意：公式與立方系統不同！）

因為角落原子的夾角是六邊形的內角（120°），每個角落原子被 **6 個**晶胞共用，故公式修正為：

$$N = N_i + \frac{N_f}{2} + \frac{N_c}{6} \quad \text{(3.5)}$$

代入：
- $N_c = 12$（上下兩面各 6 個角落原子）
- $N_f = 2$（上下面心各 1 個）
- $N_i = 3$（中間層 3 個原子）

$$N = 3 + \frac{2}{2} + \frac{12}{6} = 3 + 1 + 2 = 6 \ \text{個原子}$$

### 5.3 晶格參數關係

- 短邊長 $a = 2R$（同層原子相切）
- 長邊長（晶胞高度）$c$，理想比值：

$$\frac{c}{a} = \sqrt{\frac{8}{3}} \approx 1.633$$

> **重要觀念**：這個 1.633 是**理想球體堆積**下的比值，實際金屬常有偏差（見下表），偏差反映該金屬鍵結並非完全等向性的硬球模型。

| 金屬 | c/a 實際值 |
|---|---|
| 理想值 | 1.633 |
| Mg | 1.62 |
| Co | 1.62 |
| Ti | 1.59 |
| Zn | 1.86 |

### 5.4 晶胞體積推導（Example Problem 3.3 型）

以底面積 × 高度計算。底面由 3 個全等平行四邊形（如 $ACDE$）組成：

$$\text{底面積} = 3 \times (CD)(BC)$$

其中 $CD = a$，$BC = a\cos(30°) = \dfrac{a\sqrt{3}}{2}$，故：

$$\text{底面積} = 3a \times \frac{a\sqrt{3}}{2} = \frac{3\sqrt{3}}{2}a^2$$

$$V_C = \frac{3\sqrt{3}}{2}a^2 c \quad \text{(3.7a)}$$

代入 $a = 2R$：

$$V_C = 6\sqrt{3}\,R^2 c \quad \text{(3.7b)}$$

### 5.5 配位數與 APF

配位數 = **12**（同 FCC）：
- 同層（basal plane）6 個
- 上一層 3 個
- 下一層 3 個

APF = **0.74**（與 FCC 相同，因為兩者都是「等徑球最密堆積」，差異只在堆疊順序，詳見講義三）。

## 六、理論密度計算

### 6.1 公式推導邏輯

密度 = 質量 / 體積。晶胞的質量可由「原子數 × 原子重量 ÷ 亞佛加厥數」求得：

$$\rho = \frac{nA}{V_C N_A} \quad \text{(3.8)}$$

其中：
- $n$：每晶胞的原子數
- $A$：原子量（atomic weight, g/mol）
- $V_C$：晶胞體積（cm³）
- $N_A$：亞佛加厥數（Avogadro's number）$= 6.022 \times 10^{23}$ atoms/mol

> **單位邏輯**：$\dfrac{nA}{N_A}$ 得到「一個晶胞的質量（g）」，除以 $V_C$（cm³）即為密度（g/cm³）。

### 6.2 範例：銅的理論密度（Example Problem 3.4 型）

已知：Cu 為 FCC，$R = 0.128$ nm，$A = 63.5$ g/mol。

$$V_C = 16\sqrt{2}R^3 = 16\sqrt{2}(1.28\times10^{-8}\,\text{cm})^3$$

$$\rho_{Cu} = \frac{(4)(63.5)}{16\sqrt{2}(1.28\times10^{-8})^3 (6.022\times10^{23})} \approx 8.89\ \text{g/cm}^3$$

與實測值 8.94 g/cm³ 非常接近（誤差主要來自原子半徑測量精度、實際晶格缺陷等因素）。

## 七、多晶型與同素異形

| 名稱 | 英文 | 定義 |
|---|---|---|
| 多晶型 | polymorphism | 同一材料可存在一種以上晶體結構的現象 |
| 同素異形 | allotropy | 多晶型發生於**元素固體**時的特稱 |

**影響因素**：溫度與外部壓力。

### 案例一：碳（Carbon）
- 常壓：石墨（graphite）為穩定相
- 極高壓：鑽石（diamond）

### 案例二：鐵（Iron）
- 室溫：α-Fe，**BCC**
- 912°C 以上：γ-Fe，**FCC**

> 這是材料科學中極重要的相變，是鋼鐵熱處理（如沃斯田鐵化 austenitizing）的理論基礎。

### 案例三：錫害（Tin Disease）— 實務案例
- 白錫（β-Sn）：常溫穩定，**體心正方**（body-centered tetragonal）結構
- 灰錫（α-Sn）：13.2°C 以下穩定，**鑽石立方**（diamond cubic）結構，與鑽石結構類似

**關鍵數據**：
- 轉變溫度：13.2°C（55.8°F）
- 體積膨脹：+27%
- 密度變化：由 7.30 g/cm³ 降至 5.77 g/cm³

轉變速率極慢，但溫度越低速率越快。體積膨脹會導致金屬錫崩解成粉末狀灰錫。

**歷史事件**：1850 年俄羅斯嚴冬，士兵制服上的錫扣、教堂管風琴的錫管因低溫轉變為灰錫而崩碎，此現象被稱為「錫疫（tin disease / tin pest）」。

> **工程啟示**：這是「相變 → 體積變化 → 結構完整性喪失」的典型案例，說明晶體結構與材料巨觀性能（宏觀性質，macroscopic properties）之間的直接連結，呼應材料科學核心的 **PSPP（Processing–Structure–Properties–Performance）** 典範。

## 九、易混淆名詞辨析

| 容易混淆的一組 | 差異重點 |
|---|---|
| 晶格 (lattice) vs. 晶胞 (unit cell) | 晶格是**整個**三維點陣；晶胞是**最小重複單元** |
| 晶體結構 (crystal structure) vs. 晶系 (crystal system) | 晶體結構含原子排列細節（如 FCC/BCC/HCP）；晶系僅依晶胞**幾何形狀**分類（七大晶系，見講義二） |
| 多晶型 (polymorphism) vs. 同素異形 (allotropy) | 同素異形是多晶型**專指元素**時的用詞；化合物的多重結構只能稱多晶型，不能稱同素異形 |
| APF 相同（FCC=HCP=0.74） | 堆積效率相同，但**堆疊順序不同**（ABCABC vs. ABAB），詳見講義三 |
| 配位數 (coordination number) vs. 原子數/晶胞 | 配位數是**最近鄰數目**；原子數/晶胞是**幾何歸屬計算**結果，兩者概念不同不可混用 |

### 例題 3（改編自 Callister *Materials Science and Engineering: An Introduction*，第 3 章習題，經改寫）：由密度反推結構類型

**題目**：某金屬原子量為 50.9 g/mol，原子半徑為 0.132 nm，實測密度為 5.96 g/cm³。試判斷該金屬屬於 FCC 或 BCC 結構。

**詳解**：

**策略**：分別假設 FCC、BCC，計算理論密度，比較何者與實測值接近。

**假設 FCC**（$n=4$，$V_C = 16\sqrt{2}R^3$）：

$$R = 0.132\ \text{nm} = 1.32\times10^{-8}\ \text{cm}$$
$$V_C = 16\sqrt{2}(1.32\times10^{-8})^3 = 16(1.414)(2.30\times10^{-24}) \approx 5.20\times10^{-23}\ \text{cm}^3$$
$$\rho_{FCC} = \frac{(4)(50.9)}{(5.20\times10^{-23})(6.022\times10^{23})} \approx \frac{203.6}{31.3} \approx 6.50\ \text{g/cm}^3$$

**假設 BCC**（$n=2$，$V_C = \left(\dfrac{4R}{\sqrt{3}}\right)^3$）：

$$a = \frac{4(1.32\times10^{-8})}{\sqrt{3}} = 3.049\times10^{-8}\ \text{cm}$$
$$V_C = a^3 = 2.834\times10^{-23}\ \text{cm}^3$$
$$\rho_{BCC} = \frac{(2)(50.9)}{(2.834\times10^{-23})(6.022\times10^{23})} \approx \frac{101.8}{17.07} \approx 5.96\ \text{g/cm}^3$$

**結論**：$\rho_{BCC} \approx 5.96$ g/cm³ 與實測值完全吻合，故該金屬應為 **BCC** 結構（實際上這組數據對應釩 Vanadium，V，確實為 BCC 金屬）。

> **解題技巧**：凡遇到「已知密度、原子量、原子半徑，反推結構」的題型，標準作法就是**兩種結構都算一次**，比對何者接近實測值——這是本章计算题中鑑別度最高的題型之一。

### 例題 4（改編自 Callister 課後習題，經改寫）：由密度反推原子半徑

**題目**：鉻（Cr）為 BCC 結構，密度為 7.19 g/cm³，原子量為 52.00 g/mol。試計算其原子半徑。

**詳解**：

由 $\rho = \dfrac{nA}{V_C N_A}$，先解出 $V_C$：

$$V_C = \frac{nA}{\rho N_A} = \frac{(2)(52.00)}{(7.19)(6.022\times10^{23})} = \frac{104.0}{4.330\times10^{24}} = 2.402\times10^{-23}\ \text{cm}^3$$

因為 BCC 為立方系統，$V_C = a^3$：

$$a = (2.402\times10^{-23})^{1/3} = 2.884\times10^{-8}\ \text{cm} = 0.2884\ \text{nm}$$

再由 BCC 關係式 $a = \dfrac{4R}{\sqrt{3}}$ 反推 $R$：

$$R = \frac{a\sqrt{3}}{4} = \frac{(0.2884)(1.732)}{4} \approx 0.1249\ \text{nm}$$

**結論**：$R_{Cr} \approx 0.125$ nm，與課本表列數值（0.1249 nm）一致。

> **解題技巧**：「由密度反推原子半徑」的題型，核心邏輯永遠是：**密度公式 → 先解出晶胞體積 $V_C$ → 再依結構類型代入邊長公式反推 $R$**。務必先確認題目給的是哪種結構，才能選對邊長—半徑關係式。

### 例題 5（綜合概念題，改編自 Callister 課後習題）：HCP 鎂的晶胞體積與密度

**題目**：鎂（Mg）為 HCP 結構，晶格參數 $a = 0.3209$ nm，$c/a = 1.624$，原子量為 24.31 g/mol。試計算其理論密度。

**詳解**：

**Step 1：求 c 值**

$$c = 1.624 \times a = 1.624 \times 0.3209 = 0.5211\ \text{nm}$$

**Step 2：求晶胞體積**（利用 3.7a 式）

$$V_C = \frac{3\sqrt{3}}{2}a^2 c$$

$$a = 3.209\times10^{-8}\ \text{cm}, \quad c = 5.211\times10^{-8}\ \text{cm}$$

$$V_C = \frac{3\sqrt{3}}{2}(3.209\times10^{-8})^2(5.211\times10^{-8})$$

$$= 2.598 \times (1.0298\times10^{-15}) \times (5.211\times10^{-8})$$

$$\approx 1.394\times10^{-22}\ \text{cm}^3$$

**Step 3：代入密度公式**（HCP，$n=6$）

$$\rho_{Mg} = \frac{(6)(24.31)}{(1.394\times10^{-22})(6.022\times10^{23})} = \frac{145.9}{83.95} \approx 1.74\ \text{g/cm}^3$$

**結論**：與鎂的實測密度（約 1.74 g/cm³）高度吻合。

> **解題技巧**：HCP 題型的關鍵在於**先求出 $c$**（常需由 $c/a$ 比值換算），再代入六方晶胞體積公式，最後才套用通用密度公式——步驟比立方系統多一步，務必按順序進行，避免漏算 $c$。

## 十一、考前重點提醒

1. **三大結構的邊長公式務必能夠現場推導**，不要死背——尤其 FCC（面對角線）與 BCC（體對角線）的幾何推導是必考。
2. **HCP 的原子數公式分母是 6，不是 8**——這是最容易出錯的細節。
3. 遇到「反推結構類型」或「反推原子半徑」題型，永遠遵循：**先由密度公式解出 $V_C$ → 再依結構類型代回幾何公式**。
4. APF 數值請記熟：**FCC = HCP = 0.74，BCC = 0.68，SC ≈ 0.52**。
5. 同素異形（allotropy）只用於**元素**；化合物請一律使用「多晶型（polymorphism）」。
6. 錫害案例可作為申論題／概念連結題的素材，說明「晶體結構 → 密度變化 → 材料失效」的因果鏈。
