## 1. 缺陷分類

**核心句**：沒有完美晶體（There is no such thing as a perfect crystal）。晶體缺陷（crystalline defect）一定存在，而且材料性質對缺陷很敏感，例如晶片良率（wafer yield）。

| 分類 | 維度 | 包含 |
|---|---|---|
| **點缺陷（point defect）** | 0 維 | 空位（vacancy）、間隙原子（interstitial atom）、取代型雜質原子（substitutional impurity atom） |
| **線缺陷（linear defect）** | 1 維 | 差排（dislocation）：刃型、螺旋型、混合型 |
| **界面缺陷（interfacial defect）** | 2 維 | 晶界（grain boundary）、雙晶界（twin boundary）、疊差（stacking fault）；另有外表面、相界 |
| 體缺陷（bulk defect） | 3 維 | 孔隙、裂紋、夾雜物（教授簡報未列，知道即可） |

## 2. 點缺陷

### 2.1 空位（Vacancy）與自身間隙原子（Self-Interstitial）

| | 空位 | 自身間隙原子 |
|---|---|---|
| 定義 | 晶格位置少了原子 | **同種**原子擠進間隙位置 |
| 晶格畸變（lattice distortion） | 小 | 大 |
| 濃度 | 較高 | 極低 |

**為什麼一定有空位？** 形成空位會增加熵（entropy），使自由能降低，所以只要 T > 0 K，平衡狀態下一定有空位。

### 2.2 平衡空位數

$$
\boxed{\frac{N_v}{N} = \exp\left(-\frac{Q_v}{kT}\right)}\qquad
\boxed{N = \frac{N_A\,\rho}{A}}
$$

- $Q_v$：空位形成能，教授稱為**活化能（activation energy）**
- $N$：原子位置總數。每個晶格位置都可能是空位（each lattice site is a potential vacancy）
- 熔點附近 $N_v/N \approx 10^{-4}$

**單位陷阱**

| 項目 | 規則 |
|---|---|
| $Q_v$ 用 eV/atom | $k = 8.62\times10^{-5}$ eV/atom·K |
| $Q_v$ 用 J/atom | $k = 1.38\times10^{-23}$ J/atom·K |
| $Q_v$ 用 J/mol | 改用 $R = 8.31$ J/mol·K |
| 溫度 | 一定要換成 K（°C + 273） |
| $N$ 的單位 | $N_A\rho/A$ 算出來是 cm⁻³，要 m⁻³ 必須 **× 10⁶** |

**由實驗求 $Q_v$**：以 $\ln(N_v/N)$ 對 $1/T$ 作圖得一直線，**斜率 = $-Q_v/k$**。（$N_v/N$ 對 $T$ 作圖則是指數曲線。）

**兩溫度比值法**：$\ln\dfrac{N_{v2}}{N_{v1}} = -\dfrac{Q_v}{k}\left(\dfrac{1}{T_2}-\dfrac{1}{T_1}\right)$

**NiAl 表面實驗**（簡報）：溫度升高 → 平衡空位濃度增加 → 表面原子島長大。這是空位濃度隨溫度改變的直接證據。

### 2.3 例題 4.1（必會）

Cu，1000 °C，$Q_v = 0.9$ eV，$\rho = 8.4$ g/cm³，$A = 63.5$ g/mol

$$
N = \frac{(6.022\times10^{23})(8.4)(10^6)}{63.5} = 8.0\times10^{28}\ \text{m}^{-3}
$$

$$
N_v = N\exp\left(-\frac{0.9}{(8.62\times10^{-5})(1273)}\right) = (8.0\times10^{28})(2.7\times10^{-4}) = \mathbf{2.2\times10^{25}\ m^{-3}}
$$

## 3. 固溶體（Solid Solution）

### 3.1 加入雜質 B 的兩種結果

1. **B 溶於 A 的固溶體**：B 隨機分布，晶體結構不變。
2. **固溶體＋第二相顆粒（second phase particle）**：通常發生在 B 濃度較高時；第二相的成分不同，結構也常不同。

| | 取代型（substitutional） | 間隙型（interstitial） |
|---|---|---|
| 溶質位置 | 取代主原子（host atom）位置 | 擠進間隙 |
| 溶質大小 | 與主原子相近 | 遠小於主原子 |
| 溶解度 | 可完全互溶 | 有限（< 10%） |
| 例子 | Cu 溶於 Ni | C 溶於 Fe |

### 3.2 休謨–羅瑟里法則（Hume–Rothery Rules，教授版）

1. 原子半徑差 $\Delta r$ **< 15%**，其中 $\Delta r\% = \dfrac{r_\text{solute}-r_\text{host}}{r_\text{host}}\times100\%$
2. **週期表位置相近**，也就是電負度（electronegativity）相近
3. **純金屬的晶體結構相同**
4. **價數（valence）**：其他條件相同時，較容易溶解**價數較高**的金屬

> 判斷技巧：只要**晶體結構不同**，就不可能完全互溶。

**簡報例題：Al 和 Ag 哪個在 Zn（HCP，+2）中溶解度較大？**
- 原子半徑：Al 差 7.4%，Ag 差 8.5% → Al 略優
- 電負度：Al 差 0.1，Ag 差 0.3 → Al 優
- 結構：兩者都是 FCC，與 Zn 不同 → 平手
- 價數：Al +3 較高，Ag +1 較低 → Al 優
- **答：Al**

### 3.3 間隙半徑（必背）

| | 八面體間隙（octahedral） | 四面體間隙（tetrahedral） |
|---|---|---|
| **FCC** | **0.414 R**（4 個/單位晶格） | 0.225 R（8 個） |
| **BCC** | 0.155 R（6 個） | **0.291 R**（12 個） |

- 推導原則：間隙原子剛好碰到最近的主原子，所以 $R + r$ = 間隙中心到主原子中心的距離。代入 FCC $a = 2\sqrt2 R$、BCC $a = 4R/\sqrt3$。
- **反直覺重點**：BCC 的原子堆積因子（APF）較小，但最大間隙（0.291R）比 FCC（0.414R）小。所以碳在 FCC 鐵中的溶解度（約 2.14 wt%）遠大於 BCC 鐵（約 0.022 wt%）。

## 4. 成分表示法（Specification of Composition）

| 公式 | 用途 | 記憶法 |
|---|---|---|
| $C_1 = \dfrac{m_1}{m_1+m_2}\times100$ | 重量百分率（wt%） | 質量比 |
| $C_1' = \dfrac{n_{m1}}{n_{m1}+n_{m2}}\times100$，$n_m = m'/A$ | 原子百分率（at%） | 莫耳比 |
| $C_1' = \dfrac{C_1A_2}{C_1A_2+C_2A_1}\times100$ | wt% → at% | **除以原子量** |
| $C_1 = \dfrac{C_1'A_1}{C_1'A_1+C_2'A_2}\times100$ | at% → wt% | **乘以原子量** |
| $C_1'' = \dfrac{C_1}{C_1/\rho_1+C_2/\rho_2}\times10^3$ | wt% → kg/m³ | 取 100 g 合金 |
| $\rho_\text{ave} = \dfrac{100}{C_1/\rho_1+C_2/\rho_2}$ | 合金平均密度 | 總質量 ÷ 總體積 |
| $A_\text{ave} = \dfrac{100}{C_1/A_1+C_2/A_2}$ | 合金平均原子量 | 總質量 ÷ 總莫耳數 |
| $N_1 = \dfrac{N_AC_1}{\dfrac{C_1A_1}{\rho_1}+\dfrac{A_1}{\rho_2}(100-C_1)}$ | 元素 1 原子數/cm³（式 4.21） | 作業 4.27 要推導 |
| $n = \dfrac{\rho\,a^3N_A}{A}$ | 每單位晶格原子數（第 3 章） | 判斷 SC、BCC、FCC：n = 1、2、4 |

**檢查方向**：較重的元素，at% < wt%。
**多元合金**：不能直接套二元公式，要先算各元素的莫耳數。

## 5. 差排（Dislocation）

### 5.1 三種差排

| | 刃差排（edge） | 螺旋差排（screw） | 混合差排（mixed） |
|---|---|---|---|
| 結構 | 多插入**半個原子面（extra half-plane）** | 剪應力造成的**螺旋斜坡（spiral ramp）** | 兼具兩者 |
| **b 與差排線** | **垂直（⊥）** | **平行（∥）** | 既不垂直也不平行 |
| 符號 | ⊥ | 圓弧箭頭 | — |

**布格向量（Burgers vector, b）**：描述晶格畸變的大小與方向。
- 金屬中 b 指向**最密堆積方向（close-packed direction）**，|b| = 原子間距 = **2R**。
- 同一條差排線上，b **處處相同**（Figure 4.6：A 點是純螺旋、B 點是純刃型，中間是混合型）。

### 5.2 怎麼畫 b：布格迴路（Burgers circuit）

1. 在含差排的晶體中，繞差排線走一圈封閉迴路，記下各方向的步數。
2. 在完美晶體中照同樣步數走，迴路會**差一格**。
3. 從終點 F 指向起點 S 的向量就是 **b**。
4. 檢查：刃差排 b ⊥ 線，螺旋差排 b ∥ 線，長度是一個原子間距。

**考試畫圖清單**：畫出差排線（⊥ 或 AB 線）、b 的箭頭加標示、長度一格、方向關係正確。

### 5.3 差排運動與塑性變形（簡報）

- **施加（剪）應力時，差排會移動**：一次只斷開並重接一排鍵，所以比整片原子面同時滑動容易得多（實際強度比理論值低 10³～10⁴ 倍）。
- **永久（塑性）變形來自差排運動**：差排移出表面後，晶體錯開一個 b，原子換了鄰居，所以變形無法恢復。
- 單晶拉伸後側面出現的**階梯（steps）**，就是大量差排移動到表面造成的。
- 觀察：**TEM**，差排呈**暗線**（Figure 4.7）。
- **延伸觀念**：阻擋差排 → 強度提高（晶界、溶質原子，第 7 章）。

## 6. 界面缺陷

### 6.1 凝固（Solidification）與晶粒（簡報）

- **兩步驟**：成核（nucleation）→ 晶體成長，直到邊界相遇，成為晶粒（grain）。
- **等軸晶（equiaxed）**：在模壁附近形成，因為冷卻快、ΔT 大、成核多。
- **柱狀晶（columnar）**：在冷卻較慢的內部形成，沿熱流的反方向拉長。
- **晶粒細化劑（grain refiner）**：加入後晶粒更小、更均勻、成為等軸晶。

### 6.2 晶界（Grain Boundary）

- 晶粒之間的區域，跨越晶界時**晶體方位錯配（crystallographic misalignment）**。
- 原子略為混亂（slight atomic disorder），所以：
  - **原子移動性高（high atomic mobility）**
  - **化學反應性高（high chemical reactivity）**，是蝕刻處
- **小角度晶界（small-angle）**：可用差排陣列描述，能量較低。
- **大角度晶界（high-angle）**：能量較高。

### 6.3 雙晶界與疊差

| | 雙晶界（twin boundary） | 疊差（stacking fault） |
|---|---|---|
| 定義 | 兩側原子位置呈**鏡面反射（mirror reflection）** | 堆疊順序出錯 |
| FCC 例子 | ABCAB**C**BACBA（以 C 為鏡面） | ABC**AB**ABC（教授例子） |
| 兩側方位 | 鏡像，方位不同 | 相同 |

- 機械雙晶（mechanical twin）：由剪力造成，常見於 BCC、HCP。
- 退火雙晶（annealing twin）：由退火造成，常見於 FCC。

### 6.4 能量比較與催化劑

**界面能**：外表面 > 大角度晶界 > 小角度晶界 > 雙晶界。
判斷邏輯：斷的鍵越多、排列越亂，能量越高。

**表面能**：平面密度（planar density）越大，表面能越低。

**催化劑（catalyst）**：加快反應速率但本身不被消耗。反應通常發生在**表面缺陷**上，例如台階（step）、階緣（ledge）、扭折（kink）、吸附原子（adatom）。應用：汽車觸媒轉化器中的 (Ce₀.₅Zr₀.₅)O₂。

> 注意區分：吸附（adsorption）是附著在表面，吸收（absorption）是進入內部。

## 7. 顯微檢驗（Microscopic Examination）

### 7.1 晶粒大小的範圍

- **可以非常大**：石英（quartz）、鑽石（diamond）、矽（Si）的大塊單晶；鋁製路燈桿與垃圾桶上的晶粒肉眼可見。
- **可以非常小**（< mm）：必須用顯微鏡觀察。

### 7.2 光學顯微鏡（Optical Microscopy）

| 項目 | 重點 |
|---|---|
| 極限 | 約 **2000×**；最佳解析度 **≈ 0.1 μm（100 nm）** |
| 試片準備 | 研磨（grinding）→ **拋光（polishing）**去除刮痕 → **蝕刻（etching）**產生對比 |
| 晶粒明暗不同 | 晶粒方位不同 → 蝕刻後紋理不同 → 反射率（reflectance）不同 |
| 晶界呈暗線 | 晶界較易被蝕刻 → 形成表面溝槽（surface groove）→ 光反射偏離物鏡 |
| 偏振光（polarized light） | 增加對比；也可觀察高分子等透明試片 |

### 7.3 電子顯微鏡與 STM

**為什麼要用電子？** 要提高解析度，需要波長更短的輻射。X 光波長夠短但**難以聚焦**；電子束波長可短到約 **3 pm**，而且能用**磁透鏡**聚焦，放大倍率可達 10⁶×，可達原子級解析度。

| | TEM（穿透式） | SEM（掃描式） | STM（掃描穿隧） |
|---|---|---|---|
| 原理 | 電子**穿透**薄膜試片 | 電子**掃描**表面，收集反射電子 | 尖端只有**一個原子**的探針掃描表面 |
| 觀察範圍 | 內部（例如差排） | 表面；景深大 | 表面原子 |
| 試片要求 | 極薄 | 需導電 | 表面平整 |
| 特色 | 約 10⁶× | 適合破斷面 | 能推動、**重新排列原子**（CO 小人、Fe 原子排成「原子」） |

**選擇技術的口訣**：先看尺寸，再看是表面還是內部（內部用 TEM），最後看表面平不平（凹凸不平用 SEM）。

## 8. 晶粒尺寸測定（Grain-Size Determination）

| 公式 | 意義 | 注意 |
|---|---|---|
| $\ell = \dfrac{L_T}{P\,M}$ | 截線法（linear intercept）平均截線長度 | $L_T$ 是照片上量的長度，要除以 $M$ |
| $n = 2^{G-1}$ | **100×** 下每 in² 的晶粒數 | 晶粒越細，G 越大 |
| $n_M\left(\dfrac{M}{100}\right)^2 = 2^{G-1}$ | 非 100× 倍率的修正 | M > 100 時修正因子 > 1 |
| $G = -6.6457\log\ell - 3.298$ | 由 $\ell$ 求 G | $\ell$ 用 **mm** |
| $M = \dfrac{\text{比例尺量測長度（μm）}}{\text{比例尺標示值（μm）}}$ | 由比例尺求放大倍率 | mm × 1000 = μm |

**快速練習**

| 題目 | 解 |
|---|---|
| 250× 下量得 30 顆/in²，求 G（習題 4.48） | $n = 30\times(2.5)^2 = 187.5$；$G = 1 + \dfrac{\log 187.5}{\log 2} = $ **8.55** |
| G = 6，1× 下每 in² 晶粒數（習題 4.47） | $n_M = 2^5\times(100/1)^2 = $ **3.2×10⁵** |
| 例題 4.5：比例尺 16 mm = 100 μm，7 條 50 mm 線，P = 58 | $M = 160$；$\ell = \dfrac{350}{58\times160} = $ **0.0377 mm**；$G = $ **6.16** |

## 10. 易混淆名詞

| 名詞對 | 區別 |
|---|---|
| 空位 vs 自身間隙原子 | 少一個原子 vs 多一個**同種**原子在間隙 |
| 自身間隙原子 vs 間隙型雜質 | 主原子本身 vs 外來的小原子 |
| 溶質（solute）vs 溶劑（solvent） | 含量少 vs 含量最多 |
| wt% vs at% | 質量基準 vs 莫耳基準 |
| $k$ vs $R$ | 每原子 vs 每莫耳，$R = kN_A$ |
| 刃差排 vs 螺旋差排 | b ⊥ 線 vs b ∥ 線 |
| 疊差 vs 雙晶界 | 兩側方位相同 vs 兩側為鏡像 |
| 機械雙晶 vs 退火雙晶 | 剪力造成、BCC/HCP vs 退火造成、FCC |
| 吸附 vs 吸收 | 附著在表面 vs 進入內部 |
| 等軸晶 vs 柱狀晶 | 各方向等長、模壁附近 vs 單向拉長、內部 |
| 拋光 vs 蝕刻 | 去除刮痕 vs 產生對比 |
| TEM vs SEM | 穿透、看內部 vs 掃描、看表面且景深大 |
| 放大倍率 vs 解析度 | 放大多少倍 vs 能分辨的最小距離 |
