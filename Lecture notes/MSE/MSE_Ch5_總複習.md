## 2. 公式卡

### 2.1 基本定義與第一定律（穩態）

| 編號 | 公式 | 用途 | 注意 |
|---|---|---|---|
| 5.1 | $J = \dfrac{M}{At} = \dfrac1A\dfrac{dM}{dt}$ | 通量定義；求總質量 $M = JAt$ | $t$ 用秒 |
| 5.2 | $J = -D\dfrac{dC}{dx}$ | **菲克第一定律**（Fick's first law），穩態 | $C$ 要用 kg/m³（或 g/cm³） |
| 5.3 | $\dfrac{dC}{dx} = \dfrac{C_A - C_B}{x_A - x_B}$ | 線性剖面的梯度 | 分子分母同順序 |
| 4.9 | $C_1'' = \dfrac{C_1}{C_1/\rho_1 + C_2/\rho_2}\times10^3$ | wt% → kg/m³ | 鐵中稀薄溶質：$C''\approx C\times78.7$ |
| — | $C \propto \sqrt{p}$ | 雙原子氣體溶解度（西韋特定律 Sieverts' law） | 代 $\sqrt{p}$ 的差 |

### 2.2 第二定律（非穩態）

| 編號 | 公式 | 用途 | 注意 |
|---|---|---|---|
| 5.4b | $\dfrac{\partial C}{\partial t} = D\dfrac{\partial^2 C}{\partial x^2}$ | **菲克第二定律**（Fick's second law） | 假設 $D$ 與濃度無關 |
| 5.5 | $\dfrac{C_x - C_0}{C_s - C_0} = 1 - \text{erf}\left(\dfrac{x}{2\sqrt{Dt}}\right)$ | 半無限、**表面濃度固定** | 比值 → wt% 可直接用 |
| 5.6b | $\dfrac{x^2}{Dt}$ = 常數 | 同濃度的比例計算 | 不需 erf 表 |
| 5.7 | $D_1t_1 = D_2t_2$ | 同位置、同濃度、換溫度 | 時間可直接用 h |
| 5.15 | $C_x = C_2 + \dfrac{C_1 - C_2}{2}\left[1 - \text{erf}\left(\dfrac{x}{2\sqrt{Dt}}\right)\right]$ | 擴散偶（diffusion couple） | 界面濃度恆為 $\frac{C_1+C_2}{2}$ |
| — | $x \sim \sqrt{Dt}$ | 擴散距離估計 | 深度 ×2 → 時間 ×4 |
| — | $l > 10\sqrt{Dt}$ | 半無限的判斷 | — |

### 2.3 溫度效應

| 編號 | 公式 | 用途 |
|---|---|---|
| 5.8 | $D = D_0\exp\left(-\dfrac{Q_d}{RT}\right)$ | 用法 A：求 $D$ |
| 5.9a | $\ln D = \ln D_0 - \dfrac{Q_d}{R}\cdot\dfrac1T$ | 斜率 $-Q_d/R$ |
| 5.9b | $\log D = \log D_0 - \dfrac{Q_d}{2.3R}\cdot\dfrac1T$ | 讀圖題，斜率 $-Q_d/2.3R$ |
| — | $T = \dfrac{Q_d}{R\ln(D_0/D)}$ | 用法 B：反求 $T$ |
| — | $D_2 = D_1\exp\left[-\dfrac{Q_d}{R}\left(\dfrac1{T_2} - \dfrac1{T_1}\right)\right]$ | 用法 C：兩溫度換算（$D_0$ 消去） |
| — | $Q_d = -R\dfrac{\ln D_1 - \ln D_2}{1/T_1 - 1/T_2}$，$D_0 = D_1e^{Q_d/RT_1}$ | 用法 D：兩點求參數 |

### 2.4 半導體

| 編號 | 公式 | 用途 |
|---|---|---|
| 5.5 | erf 解 | 預沉積（predeposition，表面濃度固定） |
| 5.11 | $C(x,t) = \dfrac{Q_0}{\sqrt{\pi Dt}}\exp\left(-\dfrac{x^2}{4Dt}\right)$ | 驅入擴散（drive-in diffusion，總量固定） |
| 5.12 | $Q_0 = 2C_s\sqrt{\dfrac{D_pt_p}{\pi}}$ | 預沉積引入的總量（atoms/m²） |
| 5.13 | $x_j = \left[4D_dt_d\ln\dfrac{Q_0}{C_B\sqrt{\pi D_dt_d}}\right]^{1/2}$ | 接面深度（junction depth），由 5.11 令 $C = C_B$ 推得 |

### 2.5 跨章公式

| 公式 | 來源 | 用途 |
|---|---|---|
| $N_v = N\exp(-Q_v/kT)$ | 第4章 | 空位數（簡報 p.5「By which equation?」） |
| FCC $a = 2\sqrt2R$；BCC $a = 4R/\sqrt3$ | 第3章 | 間隙位置半徑、晶向題 |

## 3. 題型判斷流程圖

```
讀題 ─→ 題目在問什麼？
│
├─ 機制、比較、為什麼？ ─────────────────→ 【概念題】Part 1、5、9 節
│     關鍵字：mechanism, why faster, rank
│
├─ 晶向、相鄰間隙位置？ ─────────────────→ 【晶向題】終點−起點→化整數→⟨uvw⟩
│                                              （先確認是最近鄰！）
│
├─ 只給 D0、Qd、T 或 D 的關係？ ─────────→ 【阿瑞尼斯】用法 A／B／C／D
│     沒有濃度、沒有位置                        （Part 4 第 3 節）
│
└─ 有濃度、位置、時間 ─→ 濃度/通量會隨時間變嗎？
        │
        ├─ 不會（steady state、兩側濃度固定、線性剖面）
        │     └→ 【第一定律】J = −D ΔC/Δx
        │           ├ 給 wt% → 先用 Eq. 4.9 換 kg/m³
        │           ├ 求總量 → M = JAt
        │           └ 要 D 但只給 D0、Qd、T → 先算 D
        │
        └─ 會（carburize、after t hours、surface maintained）
              │
              ├─ 兩次處理「相同濃度」可比較？
              │     ├ 同溫度        → x²/t = 常數
              │     ├ 同位置換溫度  → D₁t₁ = D₂t₂ ─→ 再接阿瑞尼斯
              │     └ 同時間換位置  → x²/D = 常數 ─→ 再接阿瑞尼斯
              │     （不需 erf 表、不需 Cs、C0）
              │
              ├─ 擴散偶（兩塊合金接合）？
              │     └→ Eq. 5.15，左式分母為 (C₁−C₂)/2
              │
              ├─ 半導體：預沉積＋驅入？
              │     └→ 分別算 Dp、Dd（eV → 用 k）→ Q0 → Eq. 5.11
              │
              └─ 一般：表面濃度固定
                    └→ Eq. 5.5：左式 → erf = 1 − 左式 → 內插 z
                        ├ 求 t：t = x²/(4z²D)
                        ├ 求 x：x = 2z√(Dt)
                        ├ 求 D：D = x²/(4z²t) ─→ 求 T：T = Qd/[R ln(D0/D)]
                        └ 求 Cx：已知 z → 查 erf → 代回
```

### 3.1 關鍵字對照

| 題目關鍵字 | 判斷 |
|---|---|
| *steady state*、*linear concentration profile*、*concentrations at the two faces ... maintained constant* | 第一定律 |
| *surface concentration is maintained*、*carburizing time*、*after ... h* | 第二定律 erf 解 |
| *same diffusion result*、*same concentration at a specific point* | $Dt$ 或 $x^2/Dt$ = 常數 |
| *diffusion couple*、*original interface* | Eq. 5.15 |
| *preexponential*、*activation energy*、*at what temperature* | 阿瑞尼斯 |
| *plot of the logarithm ... versus reciprocal* | 讀圖，用 Eq. 5.9b |
| *predeposition*、*drive-in*、*junction depth*、*background concentration* | 半導體公式 |
| *oxygen-rich, carbon-free atmosphere* | 脫碳：$C_s = 0$，erf 解照用 |
| *pure iron* | $C_0 = 0$ |

## 7. 快問快答（概念題自我測驗）

> 先遮住右欄自己回答，再對答案。

| # | 問題 | 答案 |
|---|---|---|
| 1 | 擴散的定義？ | 以原子運動造成的質量傳輸 |
| 2 | 自擴散為何無法由成分變化觀察？ | 所有原子同種，成分始終不變 |
| 3 | 原子跳一步的兩個條件？ | 鄰近有空位置；足夠振動能（斷鍵＋晶格畸變） |
| 4 | 空位擴散中，空位往哪移動？ | 與原子擴散方向相反 |
| 5 | 間隙擴散較快的兩個理由？ | 原子小、較易移動；空間隙位置遠多於空位 |
| 6 | 哪些原子以間隙機制擴散？ | H、C、N、O 等小原子 |
| 7 | 穩態的定義？ | 通量不隨時間變，無淨累積 |
| 8 | 穩態擴散的驅動力？ | 濃度梯度 |
| 9 | 菲克第一定律的負號代表？ | 擴散方向由高濃度往低濃度 |
| 10 | 穩態且 $D$ 為常數時，濃度剖面是什麼形狀？為什麼？ | 直線；$\partial C/\partial t = 0$ → $d^2C/dx^2 = 0$ |
| 11 | 第二定律從哪兩件事推出？ | 第一定律＋質量守恆 |
| 12 | 半無限固體的條件？ | 擴散前緣到不了另一端，$l > 10\sqrt{Dt}$ |
| 13 | Eq. 5.5 的三個條件？ | $t = 0$：$C = C_0$；$x = 0$：$C = C_s$；$x = \infty$：$C = C_0$ |
| 14 | 深度加倍，時間要變幾倍？ | 4 倍 |

## 8. 考前模擬練習（新題，附詳解）

### 練習 1　滲碳深度（erf → $x$）

**題目**：含 0.15 wt% C 的鋼在 1000 °C 滲碳，表面碳濃度維持 1.0 wt%。6 h 後，含碳量 0.50 wt% 的位置在表面下多深？使用 Table 5.2 中 C 在 γ-Fe 的數據。

<details>
<summary>詳解（先自己做再展開）</summary>

**步驟 1**：$\dfrac{0.50 - 0.15}{1.0 - 0.15} = 0.4118 = 1 - \text{erf}(z)$ → erf($z$) = 0.5882

**步驟 2**：內插（0.55 → 0.5633；0.60 → 0.6039）：$z = 0.55 + 0.05\times\dfrac{0.5882 - 0.5633}{0.6039 - 0.5633} = 0.581$

**步驟 3**：$D = (2.3\times10^{-5})\exp\left[-\dfrac{148{,}000}{(8.31)(1273)}\right] = 1.93\times10^{-11}$ m²/s

**步驟 4**：$x = 2z\sqrt{Dt} = 2(0.581)\sqrt{(1.93\times10^{-11})(21{,}600)} = 2(0.581)(6.46\times10^{-4}) = 7.5\times10^{-4}$ m

**答案**：約 0.75 mm（1000 °C > 912 °C，γ-Fe ✓）
</details>

---

### 練習 2　擴散係數排序（概念＋計算）

**題目**：不必精算，先排序再驗算：(a) C 在 α-Fe，600 °C；(b) C 在 γ-Fe，1000 °C；(c) Fe 在 γ-Fe，1000 °C；(d) Cu 在 Al，500 °C。

<details>
<summary>詳解</summary>

**判斷**：(a)、(b) 是間隙擴散 → 大；(c)、(d) 是空位擴散 → 小。(c) 的 $Q_d$ = 284 kJ/mol 最大。

| 系統 | $D$（m²/s） |
|---|---|
| (b) C 在 γ-Fe，1000 °C | $1.9\times10^{-11}$ |
| (a) C 在 α-Fe，600 °C | $6.4\times10^{-12}$ |
| (d) Cu 在 Al，500 °C | $4.2\times10^{-14}$ |
| (c) Fe 在 γ-Fe，1000 °C | $1.1\times10^{-16}$ |

**排序**：(b) > (a) > (d) > (c)

**觀察**：(a) 溫度低了 400 °C，仍只比 (b) 小約 3 倍，因為 α-Fe 的 $Q_d$ 小；(c) 溫度高，卻因 $Q_d$ 大而最慢。
</details>

---

### 練習 3　降溫後所需時間（$Dt$ ＋用法 C）

**題目**：Ni–Cu 擴散偶在 1000 °C 處理 10 h 達到某擴散結果。若改在 900 °C 進行，需多少時間才能得到相同結果？（Ni 在 Cu：$Q_d$ = 230,000 J/mol）

<details>
<summary>詳解</summary>

$$\frac{D_{1000}}{D_{900}} = \exp\left[-\frac{230{,}000}{8.31}\left(\frac1{1273} - \frac1{1173}\right)\right] = \exp(1.854) = 6.38$$

$$t_{900} = t_{1000}\cdot\frac{D_{1000}}{D_{900}} = (10\ \text{h})(6.38) = 64\ \text{h}$$

**答案**：約 64 h（不需要 $D_0$）
</details>

---

### 練習 4　穩態通量的溫度效應

**題目**：氮氣穿過 α-Fe 薄膜達穩態。若兩側濃度不變，溫度由 500 °C 升到 700 °C，通量變為幾倍？（N 在 α-Fe：$Q_d$ = 77,000 J/mol；假設表面濃度不隨溫度改變）

<details>
<summary>詳解</summary>

濃度梯度相同 → $J \propto D$

$$\frac{J_{700}}{J_{500}} = \frac{D_{700}}{D_{500}} = \exp\left[-\frac{77{,}000}{8.31}\left(\frac1{973} - \frac1{773}\right)\right] = \exp(2.464) = 11.8$$

**答案**：約 12 倍

> 若題目不假設表面濃度固定，實際上溶解度也會隨溫度改變（Part 2 習題 5.11、5.D1），此時通量比要再乘上溶解度比。
</details>

## 9. 易混淆總整理（跨 Part）

| 一對 | 一句話區分 |
|---|---|
| 互擴散 vs 自擴散 | 異種 vs 同種原子；後者看不出成分變化 |
| 空位 vs 間隙位置 | 晶格位置少了原子 vs 本來就不是晶格位置的空隙 |
| FCC vs BCC 間隙 | FCC 八面體最大（0.414R）；BCC 四面體 > 八面體 |
| 溶解度 vs 擴散速率 | C：γ-Fe 溶得多、α-Fe 跑得快 |
| $J$ vs $D$ | 實際流量 vs 材料性質 |
| 穩態 vs 平衡 | 穩態仍有淨流動；平衡無淨流動 |
| 第一 vs 第二定律 | 穩態流量 vs 濃度隨時間變化 |
| erf($z$) vs $1 - $erf($z$) | 查表前要先用 1 減 |
| $x^2/t$ vs $Dt$ = 常數 | 同溫度 vs 同位置換溫度 |
| $R$ vs $k$ | J/mol vs eV/atom |
| $\ln$ vs $\log$ | 斜率 $-Q_d/R$ vs $-Q_d/2.3R$ |
| $Q_d$ vs $Q_0$ vs $Q_v$ | 擴散活化能 vs 雜質總量 vs 空位形成能 |
| 預沉積 vs 驅入 | 表面濃度固定（erf）vs 總量固定（高斯） |
| $C_0$ vs $C_B$ | 同一件事：初始／背景濃度 |
| 滲碳 vs 脫碳 | $C_s > C_0$ vs $C_s < C_0$（$C_s$ 常為 0） |
