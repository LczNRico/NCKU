## 1. S<sub>N</sub>1 與 S<sub>N</sub>2 的比較（6-16）

### 1.1 大方向：親核基決定反應級數

```
                    ┌── 強親核基 ──→ S_N2（以及第 7 章的 E2）
鹵烷 + 親核基 ───────┤
                    └── 弱親核基 ──→ S_N1（以及第 7 章的 E1）
```

> **解題提示（課本 Problem-Solving Hint）**
> 親核基（或鹼）的強度**通常決定反應的級數**：強親核基促成雙分子、二級反應；弱親核基較常經單分子、一級機構反應。此外，**3° 鹵化物不太可能 S<sub>N</sub>2**；**1° 鹵化物除非能共振穩定，否則不太可能 S<sub>N</sub>1**。

### 1.2 六個比較面向

**(1) 親核基的影響**
- S<sub>N</sub>2：親核基參與唯一的慢步驟 → **需要強親核基**。
- S<sub>N</sub>1：親核基不參與慢步驟 → **強弱不重要（通常是弱的）**。
- 弱親核基無法促成 S<sub>N</sub>2，所以二級、三級受質遇到弱親核基時常改走 S<sub>N</sub>1。

**(2) 受質的影響**
- 甲基、一級鹵化物：難以離子化（甲基、一級碳陽離子能量太高）→ **差的 S<sub>N</sub>1 受質**；但障礙小 → **好的 S<sub>N</sub>2 受質**。
- 三級鹵化物：障礙太大 → **不能 S<sub>N</sub>2**；但能離子化成三級碳陽離子 → **只走 S<sub>N</sub>1**。
- 二級鹵化物：**兩者皆可，取決於條件**。

$$\text{S}_\text{N}\text{1 受質：} 3° > 2° \quad (1°、\text{CH}_3\text{X 不太可能})$$
$$\text{S}_\text{N}\text{2 受質：} \text{CH}_3\text{X} > 1° > 2° \quad (3° \text{ 不適用})$$

- **硝酸銀 (AgNO₃)**：在離子化溶劑中加入 Ag⁺，Ag⁺ 拉走鹵離子生成 AgX 沉澱，可**強迫**原本不易離子化的受質生成碳陽離子，常伴隨有趣的重排。

**(3) 溶劑的影響**
- S<sub>N</sub>1：慢步驟生成兩個離子，需要**強極性、能溶劑化離子的溶劑**（水、醇），常需加熱回流。
- S<sub>N</sub>2：過渡態的電荷分離較少；強溶劑化反而會削弱親核基（需要剝除溶劑）。因此只要親核基能溶解，**S<sub>N</sub>2 在較不極性的溶劑中可能更快**；**極性非質子性溶劑**可增強弱親核基的強度。

**(4) 動力學**

$$\text{S}_\text{N}\text{1 rate} = k_r[\text{R–X}] \qquad \text{S}_\text{N}\text{2 rate} = k_r[\text{R–X}][\text{Nuc:}^-]$$

**(5) 立體化學**
- S<sub>N</sub>1：平面碳陽離子可從兩面攻擊 → **構形保持與反轉的混合；外消旋化**。
- S<sub>N</sub>2：背面攻擊 → **完全構形反轉**。

**(6) 重排**
- S<sub>N</sub>1：有碳陽離子中間物，可經 ~H 或 ~R 重排成更穩定的碳陽離子 → **重排常見**。
- S<sub>N</sub>2：一步完成、無中間物 → **不可能重排**。

### 1.3 總整理表 (Summary: Nucleophilic Substitutions)

| | S<sub>N</sub>1 | S<sub>N</sub>2 |
|---|---|---|
| **促進因素** | | |
| 親核基 | 弱親核基即可 | 需要強親核基 |
| 受質 (RX) | 3° > 2° | CH₃X > 1° > 2° |
| 溶劑 | 需要好的離子化溶劑 | 多種溶劑皆可 |
| 離去基 | 需要好的離去基 | 需要好的離去基 |
| 其他 | AgNO₃ 可強迫離子化 | — |
| **特徵** | | |
| 動力學 | 一級，k<sub>r</sub>[RX] | 二級，k<sub>r</sub>[RX][Nuc:⁻] |
| 立體化學 | 反轉與保持混合 | 完全反轉 |
| 重排 | 常見 | 不可能 |

**依受質分類**

| 受質 | S<sub>N</sub>1 條件（弱親核基） | S<sub>N</sub>2 條件（強親核基） |
|---|---|---|
| 甲基鹵化物 CH₃X | 不反應：甲基陽離子太不穩定 | S<sub>N</sub>2 無障礙，有利 |
| 一級鹵化物 RCH₂X | 幾乎不反應，除非能生成共振穩定的陽離子 | 有利，除非 R 特別龐大（如新戊基） |
| 二級鹵化物 R₂CHX | 在好溶劑中可進行 S<sub>N</sub>1，常伴隨重排 | 可進行，除非烷基或親核基龐大 |
| 三級鹵化物 R₃CX | 在好溶劑中容易進行 S<sub>N</sub>1 | 不可能（立體障礙） |

### 1.4 「故事的其餘部分」(The Rest of the Story)

- 鹵烷與親核基反應時，**消去反應常伴隨取代**，在有利條件下甚至成為主反應。
- 第 6 章專注於取代；第 7 章會加入 **E1、E2 消去**，那時才能完整預測「取代 vs. 消去」的競爭。
- 本份講義中凡是「實務上消去會競爭」的情況，都會註明「（第 7 章）」，作答時以取代產物為主即可。

## 2. 機構判斷流程（解題 SOP）

```
步驟 0：X 接在 sp³ 碳上嗎？
        └─ 否（乙烯基、芳基鹵化物）→ S_N1、S_N2 都不進行

步驟 1：看受質級數
        ├─ CH₃X、1°（無共振穩定）→ S_N2
        │      └─ 若為新戊基型（β 碳為四級碳）→ S_N2 極慢；
        │         強迫離子化（AgNO₃、加熱）則經重排的 S_N1
        ├─ 3° → S_N1（S_N2 不可能）
        ├─ 苯甲基、烯丙基（含一級）→ 兩者皆可，看步驟 2
        └─ 2° → 兩者皆可，看步驟 2

步驟 2：看親核基（對 2°、苯甲基、烯丙基受質具決定性）
        ├─ 強親核基（帶負電：RO⁻、HO⁻、CN⁻、RS⁻、I⁻、N₃⁻、RC≡C⁻…）→ S_N2
        └─ 弱親核基（中性：H₂O、ROH、RCOOH）→ S_N1（溶劑解）

步驟 3：看溶劑（用來確認）
        ├─ 極性非質子性（丙酮、DMSO、DMF、CH₃CN）→ 支持 S_N2
        └─ 極性質子性（水、醇、羧酸），常加熱 → 支持 S_N1

步驟 4：寫產物
        ├─ S_N2：Nuc 取代 X；立體中心完全反轉；無重排
        └─ S_N1：① 檢查碳陽離子能否經 ~H、~R 重排成更穩定者
                 ② 溶劑從兩面攻擊 → 外消旋化
                 ③ 中性親核基需去質子化
```

**常見親核基強弱速查**

| 強親核基（→ S<sub>N</sub>2） | 弱親核基（→ S<sub>N</sub>1） |
|---|---|
| HO⁻、RO⁻、RS⁻、HS⁻、CN⁻、N₃⁻、I⁻、RC≡C⁻、NH₂⁻、R₃N、R₃P、RNH₂、NH₃（中等偏強） | H₂O、ROH、RCOOH（溶劑解） |

> Br⁻、Cl⁻、RCOO⁻ 屬中等強度；判斷時要搭配受質與溶劑。

## 3. 判斷流程的應用例題

### 例題 1（課本 Problem 6-27）

寫出預期的取代產物，並判斷主要機構為一級 (S<sub>N</sub>1) 或二級 (S<sub>N</sub>2)。

**詳解**

| | 反應 | 判斷 | 產物 |
|---|---|---|---|
| (a) | 2-氯-2-甲基丁烷 + CH₃COOH | 3° 受質＋弱親核基（乙酸，亦為極性質子性溶劑）→ **S<sub>N</sub>1** | CH₃CH₂C(CH₃)₂–O–C(=O)–CH₃，乙酸第三戊酯 (*tert*-pentyl acetate) |
| (b) | 異丁基溴 + 甲氧化鈉 | 1° 受質＋強親核基 → **S<sub>N</sub>2**（β 碳有分支，速率較慢；消去會競爭，第 7 章） | (CH₃)₂CHCH₂–O–CH₃，1-甲氧基-2-甲基丙烷 (1-methoxy-2-methylpropane) |
| (c) | 1-碘-1-甲基環己烷 + 乙醇 | 3° 受質＋弱親核基 → **S<sub>N</sub>1** | 1-乙氧基-1-甲基環己烷 (1-ethoxy-1-methylcyclohexane) |
| (d) | 環己基溴 + 甲醇 | 2° 受質＋**弱**親核基（溶劑解）→ **S<sub>N</sub>1** | 甲氧基環己烷 (methoxycyclohexane) |
| (e) | 環己基溴 + 乙氧化鈉 | 2° 受質＋**強**親核基 → **S<sub>N</sub>2**（E2 會強烈競爭，第 7 章） | 乙氧基環己烷 (ethoxycyclohexane) |

> **(d) 與 (e) 的對比**是本節精髓：**同一個二級受質，親核基強弱決定機構**。

### 例題 2（綜合判斷：同一受質、不同條件）

(R)-2-溴丁烷分別在下列條件下反應，判斷機構並寫出產物的立體化學：
(a) NaN₃，DMSO　(b) 水，加熱　(c) NaSCH₃，丙酮　(d) 甲醇，AgNO₃

**詳解**

| | 判斷 | 產物 |
|---|---|---|
| (a) | 強親核基＋極性非質子性溶劑 → S<sub>N</sub>2 | (S)-2-疊氮丁烷 (2-azidobutane)（N₃ 為第 1 優先，順序不變 → R 變 S） |
| (b) | 弱親核基＋極性質子性溶劑＋加熱 → S<sub>N</sub>1 | 丁-2-醇，(R) 與 (S) 混合，(S)（反轉）略多 |
| (c) | 強親核基＋極性非質子性溶劑 → S<sub>N</sub>2 | (S)-2-(甲硫基)丁烷 (2-(methylsulfanyl)butane) |
| (d) | 弱親核基＋Ag⁺ 強迫離子化 → S<sub>N</sub>1 | 2-甲氧基丁烷 (2-methoxybutane)，部分外消旋 |

（2-丁基陽離子為 2°，相鄰碳上 H 轉移只會得到另一個 2° 陽離子，不產生新的骨架產物。）

## 4. 鹵烷反應總整理 (Summary: Reactions of Alkyl Halides)

### 4.1 本章已學：親核取代（6-9）

| 反應 | 反應式 | 說明 |
|---|---|---|
| a. 醇的生成 | R–X + ⁻OH → R–OH + X⁻ | |
| b. 鹵素交換 | R–X + I⁻ → R–I + X⁻（丙酮）<br>R–Cl + KF → R–F + KCl（18-冠醚-6，CH₃CN） | 合成碘化物、氟化物 |
| c. 威廉森醚合成 | R–X + R′O⁻ → R–O–R′ + X⁻<br>R–X + R′S⁻ → R–S–R′ + X⁻ | 醚、硫醚合成；R–X 應為甲基或一級 |
| d. 胺的合成 | R–X + 過量 :NH₃ → R–NH₃⁺ X⁻ → R–NH₂ + NH₄⁺ X⁻ | 需過量氨 |
| e. 腈的合成 | R–X + ⁻C≡N → R–C≡N + X⁻ | 碳鏈增加一個碳 |
| f. 炔的合成（9-7） | R–C≡C⁻ + R′–X → R–C≡C–R′ + X⁻ | 形成 C–C 鍵 |

### 4.2 後續章節會學（先知道即可）

| 反應 | 反應式 | 章節 |
|---|---|---|
| 去鹵化氫 (dehydrohalogenation) | H–C–C–X + KOH → C=C + X⁻ | 第 7 章 |
| 格任亞試劑 (Grignard reagent) | R–X + Mg --乙醚--> R–Mg–X（有機鎂鹵化物 organomagnesium halide） | 10-8 |
| 有機鋰試劑 (organolithium reagent) | R–X + 2 Li → R–Li + Li⁺X⁻ | 10-8 |
| 有機銅試劑偶合 (organocopper coupling) | 2 R–Li + CuI → R₂CuLi + LiI；R₂CuLi + R′–X → R–R′ + R–Cu + LiX | 10-9 |
| 還原 (reduction) | R–X --(1) Mg 或 Li；(2) H₂O--> R–H | 10-10 |

## 7. 全章易錯觀念總清單

**分類與命名**
1. 烯丙基氯、苯甲基溴是**烷基**鹵化物（看與 X 相連的碳是否為 sp³）。
2. 異丁基鹵化物是**一級**；第二丁基是二級；新戊基是一級但極度障礙。

**物性**
3. 偶極矩最大的鍵是 C–Cl（不是 C–F）；沸點最高的是碘化物（倫敦力為主）。
4. CCl₄ 含極性鍵但為非極性分子。

**自由基反應**
5. 共振式不是平衡；烯丙基轉移時雙鍵跟著移位；注意對稱造成的重複產物。
6. NBS 的作用是維持**低濃度** Br₂。

**S<sub>N</sub>2**
7. 「2」是雙分子，不是兩步驟；沒有中間物。
8. 親核性（速率）≠ 鹼性（平衡）；同族與立體障礙時趨勢相反。
9. 強鹼不能當離去基；–OH 須先質子化。
10. 三級鹵烷不進行 S<sub>N</sub>2；新戊基型的一級也極慢；但 γ 位的龐大基團影響不大。
11. R/S 只是名字：構形反轉後標記可能不變。

**S<sub>N</sub>1**
12. 速率與親核基無關（零級）。
13. 受質順序與 S<sub>N</sub>2 相反。
14. 外消旋化不一定 50:50，反轉通常略多。
15. 中性親核基要畫去質子化步驟，由溶劑拔質子。
16. 能重排就要考慮重排；一級受質離子化時同步重排；通常只重排一次、只發生 1,2-轉移。

**綜合判斷**
17. 二級受質：**強親核基 → S<sub>N</sub>2；弱親核基 → S<sub>N</sub>1**。
18. 乙烯基、芳基鹵化物兩種取代都不進行。
19. 規劃威廉森醚合成：鹵烷端用甲基或一級，龐大的一側放在烷氧離子。

**題 7** 欲合成甲基第三丁基醚 (CH₃–O–C(CH₃)₃)，寫出合理的 S<sub>N</sub>2 路線，並說明另一種組合為何失敗。

**題 8** 順-1-溴-3-甲基環己烷 (*cis*-1-bromo-3-methylcyclohexane) + NaSCH₃，DMF，寫出產物的立體化學。

**題 9** 2-溴-2-甲基丙烷的溶劑解在下列哪個溶劑中較快？(a) 100% 乙醇 (b) 80% 乙醇／20% 水。說明理由。

**題 10** (S)-2-溴丁烷在甲醇中反應，同時經 S<sub>N</sub>1 與 S<sub>N</sub>2 進行。產物 2-甲氧基丁烷的鏡像異構物過量為 20%（反轉構形過量）。假設 S<sub>N</sub>1 部分完全外消旋，求經 S<sub>N</sub>2 進行的比例。

### 詳解

**題 1** 二級受質＋強親核基 N₃⁻＋極性非質子性溶劑 DMF → **S<sub>N</sub>2**，完全構形反轉。
產物：**(R)-2-疊氮辛烷 ((R)-2-azidooctane)**。
R/S：反應物 I（第 1）> 己基 > CH₃ > H；產物 N₃（N，原子序 7，第 1）> 己基 > CH₃ > H。優先順序排列相同、空間反轉 → S 變 R。

**題 2** 3° 受質＋弱親核基（溶劑甲醇）＋加熱 → **S<sub>N</sub>1**。
產物：**2-甲氧基-2-甲基戊烷 (2-methoxy-2-methylpentane)**。三級碳陽離子已最穩定，不重排；C2 帶兩個甲基，非立體中心，無立體化學問題。

**題 3** 2° 受質＋弱親核基（水）→ **S<sub>N</sub>1**。
- 離子化 → C2 上的 2° 碳陽離子 → 水直接攻擊 → **3-甲基丁-2-醇 (3-methylbutan-2-ol)**（未重排）
- C3 上的 H 經**氫負離子轉移** → C3 上的 3° 碳陽離子 → 水攻擊 → **2-甲基丁-2-醇 (2-methylbutan-2-ol)**（重排）

**題 4** 一級苯甲基受質（無障礙）＋強親核基＋極性非質子性溶劑 → **S<sub>N</sub>2**。
產物：**C₆H₅–CH₂–CN，苯乙腈 (2-phenylacetonitrile)**。（苯甲基受質在弱親核基、質子性溶劑中也能 S<sub>N</sub>1，但本題條件明確指向 S<sub>N</sub>2。）

**題 5**

| | 試劑 A（NaI/丙酮，測 S<sub>N</sub>2） | 試劑 B（AgNO₃/乙醇，測 S<sub>N</sub>1） |
|---|---|---|
| (i) 1-溴丁烷 | **快**（一級、無障礙） | 慢（一級碳陽離子難生成） |
| (ii) 2-溴-2-甲基丙烷 | 不反應（三級無法 S<sub>N</sub>2） | **快**（三級碳陽離子） |
| (iii) 溴苯 | 不反應 | 不反應 |
| (iv) 苯甲基溴 | **快**（一級、無障礙） | **快**（苯甲基陽離子共振穩定） |

原理：A 中 I⁻ 為強親核基、丙酮為極性非質子性溶劑，而 NaBr 不溶於丙酮而沉澱 → 偵測 S<sub>N</sub>2；B 中 Ag⁺ 拉走鹵離子促進離子化、乙醇為弱親核基與質子性溶劑 → 偵測 S<sub>N</sub>1。

**題 6** **S<sub>N</sub>1**。
(1) 速率與親核基濃度無關 → 親核基不在速率決定步驟 → 一級動力學。
(2) 光學活性消失 → 經過平面、非手性的碳陽離子，從兩面被攻擊 → 外消旋化。
(3) 碳骨架改變 → 碳陽離子中間物發生了 ~H 或 ~R 重排。三者都指向碳陽離子中間物。

**題 7** 正確路線：**CH₃–I（或 CH₃Br）+ (CH₃)₃C–O⁻ K⁺** → S<sub>N</sub>2（甲基受質無障礙，即使親核基龐大也能攻擊）。
錯誤組合：(CH₃)₃C–Br + CH₃O⁻：三級受質無法 S<sub>N</sub>2；CH₃O⁻ 為強鹼，會引起消去，主產物為 2-甲基丙烯（第 7 章）。

**題 8** 二級受質＋強親核基 CH₃S⁻＋DMF → **S<sub>N</sub>2**，構形反轉。
Br 與 CH₃ 原本同側（順式）；CH₃S⁻ 從背面進入 → SCH₃ 與 CH₃ 異側 → **反-1-甲基-3-(甲硫基)環己烷 (*trans*-1-methyl-3-(methylsulfanyl)cyclohexane)**。

**題 9** **(b) 較快**。加入水使溶劑極性大增（水 ε = 78，且能以氫鍵溶劑化陰離子），更能穩定離子化過渡態與生成的離子，S<sub>N</sub>1 速率提高。

**題 10** 設 S<sub>N</sub>2 比例為 x，S<sub>N</sub>1 比例為 1 − x。
- S<sub>N</sub>2 部分：全部為反轉構形 → 貢獻反轉 x
- S<sub>N</sub>1 部分：反轉與保持各 (1 − x)/2 → 對 e.e. 無貢獻

$$\text{e.e.} = \left[x + \frac{1-x}{2}\right] - \frac{1-x}{2} = x = 20\%$$

→ **20% 經 S<sub>N</sub>2，80% 經 S<sub>N</sub>1**。（這個「e.e. ＝ S<sub>N</sub>2 比例」的結果，下一題 6-28 會反過來用。）

### 習題 6-28（S<sub>N</sub>1 與 S<sub>N</sub>2 競爭的定量計算）

**題目** 在特定條件下，(R)-2-溴丁烷與水一起加熱時，S<sub>N</sub>1 取代的速率是 S<sub>N</sub>2 的兩倍。計算產物的鏡像異構物過量 (e.e.) 與預期的比旋光度。(R)-丁-2-醇的比旋光度為 −13.5°。假設 S<sub>N</sub>1 生成等量的兩種鏡像異構物。

**詳解**

**Step 1：兩條路徑的比例**
S<sub>N</sub>1 : S<sub>N</sub>2 ＝ 2 : 1 → S<sub>N</sub>1 佔 **2/3**，S<sub>N</sub>2 佔 **1/3**。

**Step 2：各路徑的立體化學**
- **S<sub>N</sub>2（1/3）**：水從背面攻擊 → 完全構形反轉。
  R/S 判定：反應物 Br > 乙基 > 甲基 > H；產物 OH > 乙基 > 甲基 > H，優先順序排列相同 → (R) 變 **(S)-丁-2-醇**。
- **S<sub>N</sub>1（2/3）**：外消旋 → (R) 1/3、(S) 1/3。

**Step 3：產物組成**

| 來源 | (R)-丁-2-醇 | (S)-丁-2-醇 |
|---|---|---|
| S<sub>N</sub>2 | 0 | 1/3 |
| S<sub>N</sub>1 | 1/3 | 1/3 |
| **合計** | **1/3 (33.3%)** | **2/3 (66.7%)** |

**Step 4：鏡像異構物過量**

$$\text{e.e.} = 66.7\% - 33.3\% = \mathbf{33.3\%\ (S)}$$

（驗證：e.e. 恰等於 S<sub>N</sub>2 的比例 1/3，與綜合練習題 10 的結論一致。）

**Step 5：比旋光度**
(R)-丁-2-醇為 −13.5° → (S)-丁-2-醇為 **+13.5°**（鏡像異構物的比旋光度大小相等、符號相反）。

$$[\alpha]_\text{產物} = \text{e.e.} \times [\alpha]_{(S)} = 0.333 \times (+13.5°) = \mathbf{+4.5°}$$

> **常見錯誤**：直接用 −13.5° 計算而得到負值。產物中過量的是 **(S)**，所以符號為正。

### 習題 6-30（合成設計與副產物分析）

**題目** 說明如何以一至兩步驟由苯乙烷 (phenylethane，又稱乙苯 ethylbenzene) 轉換為下列三種產物，並說明各情況下可能產生雜質的副反應。
(a) 1-溴-1-苯乙烷 (1-bromo-1-phenylethane)
(b) 1-甲氧基-1-苯乙烷 (1-methoxy-1-phenylethane)
(c) 2-苯基丙腈 (2-phenylpropanenitrile)

**詳解**

**分析起始物**：C₆H₅–CH₂–CH₃。CH₂ 為**苯甲基位**，其 C–H 鍵最弱，自由基溴化具高度選擇性。

**(a) 一步：苯甲基溴化**

```
C₆H₅–CH₂CH₃  --NBS, hν（或 Br₂, hν）-->  C₆H₅–CHBr–CH₃
```

- 機構：Br• 奪取苯甲基氫 → 共振穩定的苯甲基自由基 → 與 Br₂ 反應。
- **可能雜質**：
  - **二溴化**：產物的苯甲基上仍有一個 H，可再被溴化 → C₆H₅–CBr₂–CH₃（以控制 NBS／Br₂ 用量減少）。
  - 少量甲基上的溴化 → C₆H₅–CH₂–CH₂Br（溴化選擇性高，量很少）。
  - 不可使用路易斯酸催化（如 FeBr₃）或在暗處使用大量 Br₂，否則會發生苯環上的溴化（芳香取代，後續章節）。

**(b) 兩步：溴化後取代**

```
Step 1：同 (a)
Step 2：C₆H₅–CHBr–CH₃  --CH₃OH, 加熱（S_N1）-->  C₆H₅–CH(OCH₃)–CH₃
   或   C₆H₅–CHBr–CH₃  --NaOCH₃, CH₃OH（S_N2）-->  C₆H₅–CH(OCH₃)–CH₃
```

- 受質是**二級苯甲基**溴化物：苯甲基陽離子共振穩定 → 在甲醇中**溶劑解（S<sub>N</sub>1）**很容易；也可用 S<sub>N</sub>2。
- **可能雜質**：
  - **消去產物苯乙烯 (styrene)** C₆H₅–CH=CH₂：用強鹼 NaOCH₃ 時 E2 競爭明顯；溶劑解時碳陽離子也可能失去質子（E1）（第 7 章）。生成的雙鍵與苯環共軛，特別穩定，使消去更容易。
  - 若溶劑含水 → 生成 1-苯乙醇 (1-phenylethanol)。
  - (a) 步驟帶入的二溴化物雜質。
- **條件選擇**：使用中性甲醇溶劑解（弱親核基、弱鹼）可**減少消去**，通常是較好的選擇。

**(c) 兩步：溴化後以氰離子取代**

```
Step 1：同 (a)
Step 2：C₆H₅–CHBr–CH₃  --NaCN, DMSO（或丙酮）-->  C₆H₅–CH(CN)–CH₃
```

- 強親核基 CN⁻＋極性非質子性溶劑 → S<sub>N</sub>2。產物命名：腈碳為 C1，C2 接苯基，C3 為甲基 → 2-苯基丙腈。
- **可能雜質**：
  - **苯乙烯**（E2；CN⁻ 鹼性不強，量較少）。
  - 若改用質子性溶劑（如乙醇、水），二級苯甲基受質可能部分走 S<sub>N</sub>1，溶劑競爭為親核基 → **溶劑解產物**（醚或醇）。所以宜用**極性非質子性溶劑**。

> **觀念連結**：這題把 Part 1（苯甲基自由基溴化）、Part 2（S<sub>N</sub>2 條件）、Part 3（苯甲基陽離子與 S<sub>N</sub>1）串成一條合成路線，並預告第 7 章的消去競爭。

### 習題 6-36（威廉森醚合成的路線選擇）

**題目** 寫出 (CH₃)₂CH–O–CH₃（甲基異丙基醚 isopropyl methyl ether，2-甲氧基丙烷 2-methoxypropane）的兩種合成方法，並說明哪一種較好。

**詳解**

醚 R–O–R′ 可從 C–O 鍵的任一側切開，得到兩種「鹵烷＋烷氧離子」組合：

| | 路線 | 受質級數 | 評估 |
|---|---|---|---|
| **路線 1** | CH₃–I（或 CH₃Br）+ (CH₃)₂CH–O⁻ Na⁺（異丙氧化鈉 sodium isopropoxide） | **甲基** | S<sub>N</sub>2 最快、無障礙；甲基鹵化物**無 β 氫**，不可能消去 → **較好** |
| 路線 2 | (CH₃)₂CH–Br + CH₃O⁻ Na⁺ | **二級** | S<sub>N</sub>2 較慢；CH₃O⁻ 是強鹼，會與受質的 β 氫進行 E2，生成丙烯 (propene) 副產物（第 7 章） |

**結論**：**路線 1 較好**。

> **通則**：威廉森醚合成時，讓**鹵烷端越簡單越好（甲基 > 一級）**，把分支、龐大的部分放在**烷氧離子**那一側。烷氧離子的立體障礙會降低親核性，但對甲基受質影響不大；鹵烷的立體障礙則會直接阻礙 S<sub>N</sub>2 並促進消去。

### 習題 6-38（S<sub>N</sub>1 動力學）

**題目** 第三丁基氯與等量乙醇在惰性溶劑 (inert solvent) 中加熱，產物之一為乙基第三丁基醚。
(a) 乙醇濃度加倍，速率如何變化？
(b) 第三丁基氯濃度變為 3 倍、乙醇濃度加倍，速率如何變化？
(c) 溫度升高，速率如何變化？

**詳解**

三級受質＋弱親核基（中性乙醇）→ **S<sub>N</sub>1**：

$$\text{rate} = k_r[(\text{CH}_3)_3\text{CCl}]$$

- **(a) 不變。** 乙醇不出現在速率定律中（零級）；它只在快速的第二步才參與。
- **(b) 變為 3 倍。** 只有第三丁基氯的濃度影響速率；乙醇加倍不影響。
- **(c) 增加。** 溫度升高使速率常數 k 增大（阿瑞尼士方程式）；高度吸熱的離子化步驟尤其需要熱能，這也是 S<sub>N</sub>1 常在回流下進行的原因。

**與習題 6-37（S<sub>N</sub>2）的對照**

| 變化 | 6-37 S<sub>N</sub>2（CH₃Br + *t*-BuO⁻） | 6-38 S<sub>N</sub>1（*t*-BuCl + EtOH） |
|---|---|---|
| 受質 × 2 | × 2 | × 2 |
| 親核基 × 2 | × 2 | **不變** |
| 受質 × 2、親核基 × 3 | × 6 | × 2 |
| 受質 × 3、親核基 × 2 | × 6 | × 3 |

> **細節補充**：在惰性（低極性）溶劑中大量增加乙醇，會使整個介質的**極性**上升，嚴格來說會間接加速離子化。課本題目的意圖是考速率定律，答「不變」；若老師追問，可補充這一點。

### 習題 6-46（由環己烷出發的合成）

**題目** 以環己烷 (cyclohexane) 為起始物之一，說明如何合成下列化合物：
(a) 溴環己烷　(b) 環己醇　(c) 環己甲腈 (cyclohexanecarbonitrile, 氰基環己烷)　(d) 環己基銨溴化物 (cyclohexylammonium bromide, C₆H₁₁NH₃⁺ Br⁻)　(e) 甲氧基環己烷

**詳解**

**關鍵第一步：把不活潑的烷類「官能基化」**
環己烷沒有離去基，無法直接取代。先用**自由基溴化**引入 Br——環己烷的 12 個 H 全部等價，只得單一一溴產物。

**(a)**
```
環己烷  --Br₂, hν（或 Cl₂/hν 得氯化物）-->  溴環己烷 (bromocyclohexane)  +  HBr
```
使用**過量環己烷**以減少多溴化。

以下 (b)～(e) 皆以溴環己烷（**二級**鹵化物）為受質，依目標選擇 S<sub>N</sub>1 或 S<sub>N</sub>2 條件：

| | 目標 | 試劑／條件 | 機構 | 注意事項 |
|---|---|---|---|---|
| (b) | 環己醇 | **H₂O（可加丙酮助溶），加熱**；或 NaOH | S<sub>N</sub>1（溶劑解）；或 S<sub>N</sub>2 | 用 NaOH 時 E2 生成環己烯的競爭很嚴重；中性水溶劑解可降低消去（但仍有 E1） |
| (c) | 環己甲腈 | **NaCN，DMSO** | S<sub>N</sub>2 | 極性非質子性溶劑增強 CN⁻；產物碳數 7 |
| (d) | 環己基銨溴化物 | **NH₃（不要過量，或反應後保持鹽的形式）** | S<sub>N</sub>2 | 題目要的是**銨鹽**本身；若 NH₃ 大量過量，會把 RNH₃⁺ 去質子化成環己胺 (cyclohexylamine) |
| (e) | 甲氧基環己烷 | **CH₃OH，加熱**；或 NaOCH₃ | S<sub>N</sub>1（溶劑解）；或 S<sub>N</sub>2 | 與 (b) 同理：強鹼 NaOCH₃ 會引起 E2 |

**(e) 的另一種思路（更好的威廉森路線）**
參照 6-36 的原則：把龐大的一側放在烷氧離子上——
```
溴環己烷 → 環己醇（b）→ Na 或 NaH → 環己氧化鈉 (sodium cyclohexoxide)
環己氧化鈉 + CH₃I  --S_N2-->  甲氧基環己烷
```
甲基受質無法消去，產率較高（步驟較多，但選擇性好）。

> **合成設計心法**：烷類 →（自由基鹵化）→ 鹵烷 →（S<sub>N</sub>1／S<sub>N</sub>2）→ 各種官能基。對**二級**鹵化物要特別留意消去的競爭，並依目標選擇「強親核基＋非質子性溶劑」或「溶劑解」。

### 習題 6-56（鄰基參與——本章最具挑戰性的題目）

**題目** 下列反應在二級條件（強親核基）下進行，但產物結構顯示發生了重排。此外，其速率比氫氧離子在類似條件下取代 2-氯丁烷快數千倍。提出機構解釋速率的提升與重排。（Et 為乙基）

```
Et₂N–CH₂–CH(Cl)–CH₂CH₃   +   ⁻OH   →   HO–CH₂–CH(NEt₂)–CH₂CH₃   +   Cl⁻
1-(二乙胺基)-2-氯丁烷                     2-(二乙胺基)丁-1-醇
                                          (2-(diethylamino)butan-1-ol)
```

**觀察整理**
1. Cl 原本在 **C2**，產物中 OH 卻在 **C1**；NEt₂ 則從 C1 移到 C2 → 兩個基團「交換位置」。
2. 速率遠快於一般的二級氯化物。
3. 條件是強親核基，但重排通常只在碳陽離子（S<sub>N</sub>1）中出現——矛盾？

**詳解：鄰基參與 (neighboring group participation)，經由氮丙啶鎓離子 (aziridinium ion)**

**Step 1（速率決定步驟）：分子內 S<sub>N</sub>2——氮的孤對電子從背面取代 Cl⁻**

```
     Et₂N:                                Et₂N⁺
     /    ↘                              /    \
  H₂C     CH–CH₂CH₃     →           H₂C ——— CH–CH₂CH₃   +  Cl⁻
          |                       （三員環：N、C1、C2）
          Cl                         氮丙啶鎓離子 (aziridinium ion)
```

- 胺的 N 是很好的親核基，而且**就在分子內、緊鄰反應中心**（隔一個碳）。
- N 從 C2 的背面攻擊、Cl⁻ 離開 → 形成帶正電的**三員環**（類似課本「氮芥 nitrogen mustard」抗癌藥中間物的結構，見課本 Application: Biochemistry）。

**Step 2：⁻OH 對三員環的 S<sub>N</sub>2 開環——攻擊較不擁擠的 C1**

```
       Et₂N⁺                                   NEt₂
      /    \                                    |
  H₂C ——— CH–CH₂CH₃   +  ⁻OH   →   HO–CH₂ –– CH–CH₂CH₃
  ↑                                    2-(二乙胺基)丁-1-醇
  HO⁻ 攻擊這裡（一級碳，障礙小）
```

- 氮丙啶鎓離子有兩個可被攻擊的碳：C1（一級）與 C2（二級）。
- HO⁻ 是強親核基，以 S<sub>N</sub>2 方式攻擊**障礙較小的一級碳 C1**，C1–N⁺ 鍵斷裂，N 以中性胺的形式留在 C2 上。
- 結果：**OH 在 C1、NEt₂ 在 C2**——看起來像「重排」，其實是兩次 S<sub>N</sub>2 的結果，骨架上沒有發生 H 或烷基轉移。

**為什麼速率快數千倍？**

| 因素 | 說明 |
|---|---|
| **分子內反應的優勢** | 親核基 N 與親電子碳 C2 在同一分子中，距離固定且很近；不必等待兩個分子在溶液中碰撞。等效上，親核基的「局部濃度」極高 |
| **熵的優勢** | 分子內反應不需把兩個獨立分子組合成一個過渡態，熵的損失小，活化自由能較低 |
| **胺是好的親核基** | 中性胺的 N 孤對電子親核性強，且三員環雖有張力，形成速度仍快 |
| **第二步極快** | 氮丙啶鎓離子帶正電、三員環張力大，是**極佳的離去基系統**，HO⁻ 開環非常迅速 |

對照組 2-氯丁烷 + ⁻OH：必須靠分子間碰撞，且二級碳有立體障礙，又沒有鄰近的親核基幫忙 → 慢得多。

**立體化學補充**
- 若 C2 為立體中心：Step 1 中 N 從背面攻擊 C2 → C2 **反轉一次**；Step 2 攻擊的是 C1（非立體中心），C2 構形不再改變。
- 若 HO⁻ 改攻擊 C2，則 C2 會再反轉一次（淨保持），得到未重排的 1-(二乙胺基)丁-2-醇——但 C2 較擁擠，這不是主要路徑。

**為什麼這題「條件是二級、卻有重排」不矛盾？**
重排的來源不是碳陽離子，而是**鄰近基團的分子內親核攻擊**。這個例子提醒我們：「重排 ⇒ S<sub>N</sub>1」不是絕對的規則；當分子內有鄰近的親核基（N、S、O 的孤對電子）時，要考慮鄰基參與。

> **課本連結：氮芥 (nitrogen mustard)** 抗癌藥（課本 312 頁 Application）就是利用完全相同的機構：N 以分子內 S<sub>N</sub>2 取代 Cl⁻ 形成氮丙啶鎓離子，再被 DNA 上的氮原子攻擊開環。兩條鏈各重複一次，就把 DNA 的雙股交聯 (cross-link) 起來，阻止 DNA 複製。
