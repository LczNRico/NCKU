## 1. 鹵烷的反應：取代與消去（6-7）

### 1.1 基本名詞

| 名詞 | 定義 |
|---|---|
| **離去基 (leaving group)** | 帶著原本的鍵結電子對離開的原子或原子團。鹵離子 (halide ion) 很穩定，是**好的離去基** |
| **受質 (substrate)** | 被試劑攻擊的化合物（此處為鹵烷） |
| **親核基 (nucleophile, Nuc:⁻)** | 富含電子、能提供一對電子形成新鍵的物種（即**路易斯鹼 Lewis base**） |
| **親電子基 (electrophile)** | 能接受電子對形成新鍵的物種（即**路易斯酸 Lewis acid**）；鹵烷中 δ+ 的碳即為親電中心 |
| **取代反應 (substitution)** | 一個原子或原子團取代另一個（離去基） |
| **消去反應 (elimination)** | 從受質失去兩個原子或原子團，通常生成 π 鍵 (pi bond) |

### 1.2 親核取代 vs. 消去

**親核取代 (nucleophilic substitution)**：親核基以其孤對電子 (lone pair) 攻擊碳，取代離去基。

```
   H  X                     H  Nuc
   |  |                     |  |
 –C––C–  +  Nuc:⁻   →     –C––C–   +  X:⁻
   |  |                     |  |
```

**消去（去鹵化氫 dehydrohalogenation）**：試劑作為**鹼 (base, B:⁻)**，奪取與頭碳相鄰碳上的質子 (proton)，同時鹵離子離開，生成 C=C（第 7 章）。

```
   H  X
   |  |
 –C––C–  +  B:⁻   →   B–H  +  C=C  +  X:⁻
   |  |
```

> **關鍵觀念**：大多數親核基同時也是鹼，所以同一個試劑可以「當親核基去攻擊碳」，也可以「當鹼去拔質子」。取代與消去常互相競爭。本章（Part 1～4）專注於取代，第 7 章再加入消去並學習如何判斷。

### 例題 1（課本 Problem 6-11）

判斷下列反應屬於取代、消去或兩者皆非，指出離去基，若為取代反應再指出親核基。
(a) 溴環己烷 (bromocyclohexane) + Na⁺ ⁻OCH₃ → 甲氧基環己烷 (methoxycyclohexane) + NaBr
(b) 環己醇 (cyclohexanol) + H₂SO₄ → 環己烯 (cyclohexene) + H₃O⁺ + HSO₄⁻
(c) 反-1,2-二溴環己烷 (*trans*-1,2-dibromocyclohexane) + KI → 環己烯 + IBr + KBr

**詳解**

| | 類型 | 離去基 | 親核基 |
|---|---|---|---|
| (a) | **取代**：–Br 被 –OCH₃ 取代 | Br⁻ | CH₃O⁻（甲氧離子 methoxide ion） |
| (b) | **消去**（脫水 dehydration）：失去 H 與 OH，生成 C=C | H₂O（–OH 先被質子化成 –OH₂⁺ 才離開） | — |
| (c) | **消去**（去鹵化 dehalogenation）：失去兩個相鄰的 Br，生成 C=C | Br⁻（I⁻ 攻擊其中一個 Br，生成 IBr，另一個 Br 以 Br⁻ 離開） | — |

### 例題 2（課本 Problem 6-12）

寫出 1-溴己烷 (1-bromohexane) 分別與下列試劑反應的取代產物。(a) NaOCH₂CH₃　(b) KCN　(c) NaOH

**詳解**

| | 親核基 | 產物 | 名稱 |
|---|---|---|---|
| (a) | CH₃CH₂O⁻（乙氧離子 ethoxide） | CH₃(CH₂)₅–O–CH₂CH₃ | 1-乙氧基己烷 (1-ethoxyhexane)（醚 ether） |
| (b) | ⁻CN（氰離子 cyanide） | CH₃(CH₂)₅–CN | 庚腈 (heptanenitrile)（腈 nitrile；碳數由 6 增為 7） |

## 2. S<sub>N</sub>2 反應的機構與動力學（6-8）

### 2.1 通式與實例

```
Nuc:⁻   +   –C–X:    →    Nuc–C–   +   :X:⁻
親核基      受質             產物         離去基
```

實例：碘甲烷 (iodomethane) + 氫氧離子 → 甲醇 (methanol) + 碘離子

```
HO:⁻  +  H₃C–I   →   HO–CH₃  +  I⁻
```

- HO⁻：氧上有孤對電子且帶負電 → **強親核基**。
- CH₃I：碳接陰電性較大的 I，帶 δ+ → **親電子基**。

### 2.2 機構：背面攻擊、一步完成

```
          H                    ┌     H      ┐‡           H
          |                    │     |      │            /
HO:⁻ →  C–I     →     │ HO···C···I  │⁻   →   HO–C      +  I⁻
        /  \                   │    / \     │            \ \
       H    H                  └   H   H    ┘            H  H
  親核基  親電子基               過渡態                   產物   離去基
```

- 親核基從離去基的**正對面（背面 back side）**攻擊碳。
- 彎曲箭號 (curved arrow) 一律由**電子豐富處（親核基的孤對電子）**指向**電子缺乏處（親電子的碳）**；另一支箭號由 C–I 鍵指向 I，表示 I 帶走鍵結電子對。
- 碳的價殼層最多只能容納 8 個電子（**八隅體 octet**），所以 C–O 鍵開始形成的**同時**，C–I 鍵必須開始斷裂。
- 新鍵形成與舊鍵斷裂**同時發生、一步完成**→ **協同反應 (concerted reaction)**。

### 2.3 過渡態 (transition state) 的結構

- 碳暫時與 **5 個**原子相連：3 個 H 加上兩個部分鍵 (partial bond)（HO···C 與 C···I）。
- 三個不參與反應的 H 排在**同一平面**上（類似 sp² 的平面三角形），Nuc 與離去基位於垂直此平面的軸線兩端 → 近似**三角雙錐 (trigonal bipyramidal)** 幾何。
- 負電荷**分散**在親核基與離去基兩端（δ⁻···C···δ⁻）。
- 過渡態是能量最高點，**無法分離、只存在一瞬間**；不是中間物 (intermediate)。

| | 過渡態 (transition state) | 中間物 (intermediate) |
|---|---|---|
| 能量圖上的位置 | 能量**極大值** (maximum) | 能量的**相對極小值** (local minimum) |
| 壽命 | 一瞬間，無法分離 | 有限的存在時間，有時可偵測甚至分離 |
| 鍵結 | 有部分鍵 | 鍵結完整 |
| S<sub>N</sub>2 | 1 個 | 0 個 |

### 2.4 反應能量圖 (reaction-energy diagram)

```
能量
 ↑            ‡  [HO···CH₃···I]⁻
 │           ╱ ╲
 │          ╱   ╲
 │         ╱     ╲
 │  HO⁻ + CH₃I    ╲
 │  ───────        ╲
 │                  ╲________
 │                   HO–CH₃ + I⁻
 └──────────────────────────────→ 反應座標 (reaction coordinate)
```

- 只有**一個能量最高點（過渡態）**、**沒有中間物**。
- 產物能量低於反應物 → **放熱反應 (exothermic)**。
- 過渡態能量高，因為它含一個五配位碳與兩個部分鍵。

### 2.5 動力學證據與速率定律推導

**實驗觀察**：改變反應物濃度、測量每秒生成甲醇的量（反應速率 rate）：

| 實驗 | [CH₃I] | [⁻OH] | 相對速率 |
|---|---|---|---|
| 1 | x | y | 1 |
| 2 | **2x** | y | **2** |
| 3 | x | **2y** | **2** |
| 4 | 2x | 2y | 4 |

**推論**：速率與兩者濃度各成一次方正比 →

$$\text{rate} = k_r[\text{CH}_3\text{I}][^-\text{OH}]$$

- 對 CH₃I 為**一級 (first order)**、對 ⁻OH 為一級，**總反應級數為二級 (second order overall)**。
- k<sub>r</sub> 為**速率常數 (rate constant)**，單位為 M⁻¹ s⁻¹（L mol⁻¹ s⁻¹）；它取決於過渡態能量（活化能 activation energy, E<sub>a</sub>）與溫度（第 4-9 節：$k = Ae^{-E_a/RT}$）。

**由速率定律推回機構的邏輯**

1. 對於單一步驟（**基本反應 elementary reaction**），速率正比於「在那一步碰撞的各分子濃度乘積」。
2. 速率同時依賴 [CH₃I] 與 [⁻OH] → 在**速率決定步驟 (rate-limiting step)** 的過渡態中，**兩個分子都必須存在** → 這一步是兩分子碰撞。
3. 這與「一步、協同、兩分子同時參與」的機構完全吻合。

**命名**：S<sub>N</sub>2 ＝ **S**ubstitution（取代）, **N**ucleophilic（親核）, **2** ＝ bimolecular（**雙分子**）。
「雙分子」指的是**速率決定步驟的過渡態含有兩個分子**；雙分子反應通常表現為總二級的速率定律。

> **注意：「2」不是指「兩個步驟」**。S<sub>N</sub>2 只有一個步驟；S<sub>N</sub>1 反而有兩個以上的步驟。

### 2.6 關鍵機構 6-2：S<sub>N</sub>2 反應 (Key Mechanism 6-2)

**一步（協同）反應**：強親核基攻擊親電的碳，迫使離去基離開。
**受質反應性順序**：CH₃X > 1° > 2°（3° 鹵烷**無法**進行 S<sub>N</sub>2）

**範例**：1-溴丁烷 (1-bromobutane) + 甲氧化鈉 (sodium methoxide) → 1-甲氧基丁烷 (1-methoxybutane) + NaBr

```
CH₃O:⁻ + CH₃CH₂CH₂–CH₂–Br  →  [CH₃O···CH₂(CH₂CH₂CH₃)···Br]⁻‡  →  CH₃O–CH₂CH₂CH₂CH₃ + Br⁻
```

### 例題 3（課本 Problem 6-13）

(a) 某條件下，0.5 M 1-溴丁烷與 1.0 M 甲氧化鈉反應，1-甲氧基丁烷生成速率為 0.05 mol/L·s。若改用 0.1 M 1-溴丁烷與 2.0 M NaOCH₃，速率為何？
(b) 1-溴丁烷與大量過量的氨 (NH₃) 反應，畫出反應物、過渡態與產物。（起始產物為胺的鹽類 RNH₃⁺ Br⁻，再被過量氨去質子化為胺。）
(c) 寫出另一組烷氧離子與烷基溴的組合，經 S<sub>N</sub>2 同樣得到 1-甲氧基丁烷。

**詳解**

**(a)** rate = k[RBr][CH₃O⁻]

由第一組條件求 k：

$$k = \frac{0.05}{(0.5)(1.0)} = 0.10\ \text{L mol}^{-1}\text{s}^{-1}$$

新條件：

$$\text{rate} = (0.10)(0.1)(2.0) = 0.02\ \text{mol L}^{-1}\text{s}^{-1}$$

（亦可用比例：[RBr] 變為 1/5 倍、[CH₃O⁻] 變為 2 倍 → 速率變為 2/5 倍 → 0.05 × 0.4 = 0.02。）

**(b)**

```
反應物：   H₃N:  +  CH₃CH₂CH₂–CH₂–Br

過渡態：   [ H₃N^δ+ ··· CH₂(CH₂CH₂CH₃) ··· Br^δ− ]‡
          （三個 H 與丙基位於同一平面；N 部分帶正電、Br 部分帶負電）

起始產物： CH₃CH₂CH₂CH₂–NH₃⁺  Br⁻         （丁基銨溴化物 butylammonium bromide）

去質子化： CH₃CH₂CH₂CH₂–NH₃⁺ + :NH₃  →  CH₃CH₂CH₂CH₂–NH₂ + NH₄⁺
                                         丁-1-胺 (butan-1-amine)
```

> 與 HO⁻ 不同，NH₃ 是**中性**親核基，所以過渡態出現電荷分離（N 帶 δ+、Br 帶 δ−）。這點在習題 6-55 會再用到。

**(c)** 把 C–O 鍵的「另一側」作為反應位置：
CH₃–Br（溴甲烷 bromomethane）+ ⁻O–CH₂CH₂CH₂CH₃（丁氧離子 butoxide）→ CH₃–O–CH₂CH₂CH₂CH₃ + Br⁻
（甲基鹵化物是最佳的 S<sub>N</sub>2 受質，這條路線同樣理想。）

## 3. S<sub>N</sub>2 反應的普遍性與合成應用（6-9）

### 3.1 S<sub>N</sub>2 反應總表 (Summary: S<sub>N</sub>2 Reactions of Alkyl Halides)

通式：Nuc:⁻ + R–X → Nuc–R + X⁻

| 親核基 | 產物 | 產物類別 |
|---|---|---|
| I⁻ 碘離子 | R–I | 鹵烷（鹵素交換 halogen exchange） |
| ⁻OH 氫氧離子 | R–OH | 醇 (alcohol) |
| ⁻OR′ 烷氧離子 (alkoxide) | R–O–R′ | 醚 (ether)（**威廉森醚合成 Williamson ether synthesis**） |
| ⁻SH 硫氫離子 (hydrosulfide) | R–SH | 硫醇 (thiol)，又稱 mercaptan |
| ⁻SR′ 硫烷氧離子 (thiolate) | R–S–R′ | 硫醚 (thioether, sulfide) |
| :NH₃ 氨 | R–NH₃⁺ X⁻ | 胺鹽 (amine salt)，經過量氨去質子化得胺 (amine) |
| ⁻N₃ 疊氮離子 (azide ion) | R–N₃ | 疊氮化物 (azide) |
| ⁻C≡C–R′ 炔化物離子 (acetylide ion) | R–C≡C–R′ | 炔 (alkyne) |
| ⁻C≡N 氰離子 (cyanide) | R–C≡N | 腈 (nitrile) |
| ⁻O–C(=O)–R′ 羧酸根 (carboxylate) | R–O–C(=O)–R′ | 酯 (ester) |
| :PPh₃ 三苯基膦 (triphenylphosphine) | [R–PPh₃]⁺ X⁻ | 鏻鹽 (phosphonium salt) |

> **合成觀點**：S<sub>N</sub>2 讓鹵烷成為「官能基轉換的樞紐」。其中 ⁻CN 與 ⁻C≡CR 會形成**新的 C–C 鍵**，可以延長碳鏈。

### 3.2 鹵素交換反應 (halogen exchange reaction)

烷基碘與烷基氟不易直接合成，可由烷基氯或烷基溴轉換：

```
R–X  +  I⁻   --丙酮 (acetone)-->   R–I  +  X⁻         （X = Cl, Br）
R–Cl +  KF   --18-冠醚-6, CH₃CN-->  R–F  +  KCl
```

**例**
- 烯丙基氯 (allyl chloride) + NaI → 烯丙基碘 (allyl iodide) + NaCl
- 乙基氯 (ethyl chloride) + KF (18-crown-6, CH₃CN) → 乙基氟 (ethyl fluoride) + KCl

> **補充：為什麼碘化物交換選用丙酮？**（課本未詳述，但常見於考題）
> NaI 可溶於丙酮，而生成的 NaCl、NaBr 在丙酮中**幾乎不溶**，會沉澱析出。依**勒沙特列原理 (Le Chatelier's principle)**，產物持續離開溶液，使平衡往 R–I 方向移動。此反應又稱**芬克爾斯坦反應 (Finkelstein reaction)**。

> **為什麼氟化物需要 18-冠醚-6？**
> F⁻ 在質子性溶劑中被強烈溶劑化而親核性極弱（見 4.5 節）。改用極性非質子性溶劑 CH₃CN，並以**冠醚 (crown ether)** 包住 K⁺ 使 KF 溶解，「裸露」的 F⁻ 就能成為有效的親核基。

## 4. 影響 S<sub>N</sub>2 的因素（一）：親核基的強度（6-10）

### 4.1 「強」親核基的定義

- 在相同條件下，**S<sub>N</sub>2 反應較快**的親核基即為「較強」的親核基。
- 例：甲氧離子 CH₃O⁻ 的反應速率約為甲醇 CH₃OH 的 **100 萬倍**。

**為什麼帶負電的較強？——從過渡態的電荷分布理解**

```
CH₃O⁻  + CH₃–I → [CH₃O^δ−···CH₃···I^δ−]‡   負電荷分散於兩端 → 過渡態較穩定 → E_a 低
CH₃OH  + CH₃–I → [CH₃O(H)^δ+···CH₃···I^δ−]‡ 需產生電荷分離 → 過渡態較不穩定 → E_a 高
```

→ **一個鹼的親核性永遠大於它的共軛酸 (conjugate acid)**。

### 4.2 親核性 (nucleophilicity) vs. 鹼性 (basicity)

| | 鹼性 (basicity) | 親核性 (nucleophilicity) |
|---|---|---|
| 攻擊對象 | 質子 H⁺ | 親電子的**碳**原子 |
| 本質 | **熱力學 (thermodynamic)**：以**平衡常數** K<sub>eq</sub>（或 K<sub>b</sub>、共軛酸的 pK<sub>a</sub>）衡量 | **動力學 (kinetic)**：以**反應速率**（速率常數 k<sub>r</sub>）衡量 |
| 反應式 | B:⁻ + H–A ⇌ B–H + A:⁻ | B:⁻ + –C–X → B–C– + X:⁻ |

大多數（但不是全部）強親核基也是強鹼，反之亦然；兩者趨勢在**同一週期 (period)** 一致，在**同一族 (group)** 的質子性溶劑中**相反**，在**有立體障礙**時也會分歧。

### 4.3 表 6-3：常見親核基（在水、醇等極性質子性溶劑中，由弱到強）

| 強度 | 親核基 |
|---|---|
| **弱 (weak)** | ROH、H₂O、RCOOH、F⁻ |
| **中等 (moderate)** | Cl⁻、RCOO⁻、RSH、RSR、NH₃、RNH₂、Br⁻ |
| **強 (strong)** | RO⁻、HO⁻、R₃N、⁻CN、RC≡C⁻、I⁻、NH₂⁻、RS⁻、HS⁻、R₃P |

### 4.4 親核性的趨勢 (Trends in Nucleophilicity)

**趨勢 1：帶負電者 > 相似的中性物種（鹼 > 其共軛酸）**

$$\text{HO}^- > \text{H}_2\text{O} \qquad \text{HS}^- > \text{H}_2\text{S} \qquad \text{NH}_2^- > \text{NH}_3$$

**趨勢 2：同一週期由左至右，親核性下降**（陰電性增加，非鍵結電子被抓得越緊）

$$\text{NH}_2^- > \text{HO}^- > \text{F}^- \qquad \text{NH}_3 > \text{H}_2\text{O} \qquad (\text{CH}_3\text{CH}_2)_3\text{P} > (\text{CH}_3\text{CH}_2)_2\text{S}$$

**趨勢 3：同一族由上至下，親核性增加**（原子變大、可極化性增加、陰電性降低；指質子性溶劑中）

$$\text{I}^- > \text{Br}^- > \text{Cl}^- > \text{F}^- \qquad \text{HSe}^- > \text{HS}^- > \text{HO}^- \qquad (\text{CH}_3\text{CH}_2)_3\text{P} > (\text{CH}_3\text{CH}_2)_3\text{N}$$

**趨勢 4：立體障礙越大，親核性越小**

**趨勢 5：親核基在極性非質子性溶劑中較強**；在質子性溶劑中因氫鍵溶劑化而減弱。

### 4.5 趨勢 3 的兩個原因

**(1) 可極化性 (polarizability)：軟／硬親核基**

- 往下一族，原子變大，最外層電子離原子核較遠、受束縛較鬆 → **可極化性高**：電子雲容易朝正電荷方向偏移。
- **F⁻**：外層為第 2 層，電子緊密 → **「硬」(hard)、低可極化性**；必須非常靠近碳才能開始成鍵 → 過渡態中 F–C 鍵結很少。
- **I⁻**：外層為第 5 層，電子鬆散 → **「軟」(soft)、高可極化性**；在較遠距離就能開始與碳的 sp³ 背面瓣 (back lobe) 重疊 → 過渡態中已有相當程度的鍵結 → **過渡態能量降低**。

**(2) 溶劑化 (solvation)**

- 在**質子性溶劑 (protic solvent)**（含 O–H 或 N–H，含 O–H 者又稱**含羥基溶劑 hydroxylic solvent**）中，溶劑分子以**氫鍵 (hydrogen bond)** 包圍陰離子。
- **小陰離子**（如 F⁻）電荷密度高，溶劑分子可靠得更近、氫鍵更強 → 溶劑化更強。
- 進行反應時，必須先「剝除 (strip off)」部分溶劑分子 → 要付出能量 → 強烈溶劑化的 F⁻ 親核性大幅下降。
- 大而電荷分散的 I⁻ 溶劑化弱 → 容易反應。

> 兩個因素在質子性溶劑中**方向一致**：可極化性隨原子序增加而上升、溶劑化能隨原子序增加而下降 → 親核性往下增加。

### 4.6 立體障礙對親核性的影響 (steric effects)

| | 第三丁氧離子 (*tert*-butoxide) (CH₃)₃C–O⁻ | 乙氧離子 (ethoxide) CH₃CH₂–O⁻ |
|---|---|---|
| 鹼性 | **較強** | 較弱 |
| 親核性 | 較弱（三個甲基阻礙接近碳） | **較強** |

- **鹼性**：攻擊的是位於分子表面、體積極小的質子 → 幾乎不受立體障礙影響。
- **親核性**：要接近擁擠的碳原子 → 龐大的親核基不易靠近。
- **應用**：想要試劑當**鹼**（例如第 7 章的消去）→ 用龐大的 *t*-BuO⁻；想要當**親核基** → 用障礙小的 EtO⁻。

> **立體障礙 (steric hindrance)**：龐大基團因體積而干擾反應的效應。**立體障礙對親核性的影響遠大於對鹼性的影響。**

### 4.7 溶劑效應 (solvent effects)

| 溶劑類型 | 特徵 | 對陰離子親核基的影響 | 例子 |
|---|---|---|---|
| **質子性溶劑 (protic solvent)** | 含 O–H 或 N–H，可提供氫鍵 | 強烈溶劑化陰離子 → **降低**親核性（小陰離子尤甚）；但試劑溶解度佳 | 水、甲醇、乙醇 |
| **極性非質子性溶劑 (polar aprotic solvent)** | 有大偶極矩（可溶解離子試劑），但**無** O–H、N–H，不與陰離子形成氫鍵 | 陰離子幾乎「裸露」→ **提升**親核性；S<sub>N</sub>2 常加速 **1000 倍以上** | 乙腈 (acetonitrile, CH₃CN)、N,N-二甲基甲醯胺 (N,N-dimethylformamide, DMF)、丙酮 (acetone)、二甲基亞碸 (dimethyl sulfoxide, DMSO)、四甲基脲 (tetramethylurea, TMU) |
| **非極性非質子性溶劑** | 無極性 | 離子試劑**不溶**，反應難以進行 | 烷類（己烷） |

**冠醚的作用**：18-冠醚-6 (18-crown-6) 的六個氧原子朝內，恰好包住 K⁺；KX 溶於非質子性溶劑時，K⁺ 被冠醚溶劑化，陰離子 X⁻ 被「拖」進溶液而幾乎沒有溶劑化 → 極具反應性。

```
例：  C₆H₅–CH₂Cl  --KF, 18-冠醚-6, CH₃CN-->  C₆H₅–CH₂F  +  Cl⁻
```

> **補充（延伸觀念）**：在極性非質子性溶劑（或氣相）中，溶劑化的差異消失，鹵離子的親核性順序會轉為與**鹼性**一致：F⁻ > Cl⁻ > Br⁻ > I⁻。也就是說，「往下一族親核性增加」主要是**質子性溶劑**造成的現象。

### 例題 6（課本 Problem 6-16）

在醇類溶劑中，比較各組何者為較強的 S<sub>N</sub>2 親核基並說明。

**詳解**

| | 較強者 | 理由 |
|---|---|---|
| (a) (CH₃CH₂)₃N vs. (CH₃CH₂)₂NH | **(CH₃CH₂)₂NH** | 三乙胺的 N 周圍有三個乙基，立體障礙較大 |
| (b) (CH₃)₂O vs. (CH₃)₂S | **(CH₃)₂S** | S 在 O 下方，較大、可極化性高、陰電性低（趨勢 3） |
| (c) NH₃ vs. PH₃ | **PH₃** | P 在 N 下方（趨勢 3） |
| (d) CH₃S⁻ vs. H₂S | **CH₃S⁻** | 帶負電（趨勢 1） |
| (e) (CH₃)₃N vs. (CH₃)₂O | **(CH₃)₃N** | 同週期 N 在 O 左邊，陰電性較小，孤對電子較易提供（趨勢 2） |
| (f) CH₃COO⁻ vs. CF₃COO⁻ | **CH₃COO⁻** | CF₃ 的強拉電子誘導效應 (inductive effect) 使 CF₃COO⁻ 上的負電荷更分散穩定，鹼性與親核性都較弱 |
| (g) (CH₃)₂CHO⁻ vs. CH₃CH₂CH₂O⁻ | **CH₃CH₂CH₂O⁻** | 異丙氧離子 O 所接碳為二級，立體障礙較大 |
| (h) I⁻ vs. Cl⁻ | **I⁻** | 在質子性溶劑中：較大、可極化性高、溶劑化較弱 |

## 5. 影響 S<sub>N</sub>2 的因素（二）：受質——離去基與立體障礙（6-11）

好的 S<sub>N</sub>2 受質需要：**(1) 親電的碳、(2) 好的離去基、(3) 碳周圍立體障礙不大。**

### 5.1 離去基效應 (leaving-group effects)

離去基的兩個功能：
1. 極化 C–X 鍵，使碳成為親電中心。
2. 帶著鍵結電子對離開。

**好的離去基的三個條件**

| 條件 | 原因 |
|---|---|
| **1. 拉電子 (electron-withdrawing)** | 使碳帶 δ+；也能穩定帶負電的過渡態 |
| **2. 離開後穩定（是弱鹼 weak base）** | 離去基在過渡態中正在離開；若它是活潑（高能）的物種，會拉高過渡態與產物的能量，使反應變慢、平衡偏向反應物 |
| **3. 可極化 (polarizable)** | 在過渡態中仍能與碳保持部分鍵結，穩定過渡態、降低活化能（與「軟」親核基的道理相同，只是方向相反：成鍵 vs. 斷鍵） |

**核心規則：好的離去基＝弱鹼＝強酸的共軛鹼 (conjugate base)**

| 共軛酸 | pK<sub>a</sub> | 共軛鹼（離去基） | 離去能力 |
|---|---|---|---|
| HI | −10 | I⁻ | 極佳 |
| HBr | −9 | Br⁻ | 佳 |
| HCl | −7 | Cl⁻ | 佳 |
| H₃O⁺ | −1.7 | H₂O | 佳（中性離去基） |
| HF | 3.2 | F⁻ | 差 |
| H₂O | 15.7 | HO⁻ | **極差** |
| ROH | 約 16～18 | RO⁻ | **極差** |

**表 6-4：常見的弱鹼型離去基**
- **離子**：Cl⁻、Br⁻、I⁻、磺酸根 (sulfonate, RSO₃⁻)、硫酸根 (sulfate, ROSO₃⁻)、磷酸根 (phosphate)
- **中性分子**（從帶正電的物種上離開）：水 H₂O、醇 ROH、胺 R₃N、硫醚 R₂S

**強鹼是差的離去基**：HO⁻、RO⁻、NH₂⁻（醯胺離子 amide ion）

```
CH₃–OH + Br⁻   ✗   （HO⁻ 無法當離去基）
```

**解決方法：先質子化 (protonation)**——醇在酸中，–OH 被質子化為 –OH₂⁺，離去基變成中性的水分子：

```
CH₃–OH  +  H–Br   ⇌   CH₃–OH₂⁺  +  Br⁻          （質子化的醇 protonated alcohol）
Br⁻  +  CH₃–OH₂⁺   →   Br–CH₃  +  H₂O            （S_N2，離去基為 H₂O）
```

> 限制：因為需要酸，只能搭配本身是**弱鹼**的親核基（Br⁻、I⁻）；強鹼性的親核基（如 CH₃O⁻）在酸中會先被質子化而失去作用。

> **解題提示**：**不要寫出以 HO⁻、RO⁻ 等強鹼作為離去基的 S<sub>N</sub>2 反應。**

### 例題 7（課本 Problem 6-17）

乙醚 (diethyl ether, CH₃CH₂OCH₂CH₃) 以濃 HBr 處理，起始產物為 CH₃CH₂Br 與 CH₃CH₂OH。提出機構。

**詳解**

醚的 C–O 鍵若直接斷裂，離去基是 CH₃CH₂O⁻（強鹼）→ 不可能。必須先質子化：

```
Step 1（質子化，快速平衡）：
CH₃CH₂–O–CH₂CH₃  +  H–Br   ⇌   CH₃CH₂–O⁺(H)–CH₂CH₃  +  Br⁻
                                  質子化的醚（鋞離子 oxonium ion）

Step 2（S_N2，Br⁻ 背面攻擊一級碳）：
Br⁻  +  CH₃CH₂–O⁺(H)–CH₂CH₃   →   Br–CH₂CH₃  +  HO–CH₂CH₃
                                     溴乙烷         乙醇（中性離去基）
```

- 乙基為一級、無障礙 → S<sub>N</sub>2 合理。
- 離去基是**中性的乙醇分子**（弱鹼）。
- 若 HBr 過量，生成的乙醇會再被質子化並轉為第二分子溴乙烷。

### 5.2 受質的立體效應 (steric effects on the substrate)

**受質的結構是影響 S<sub>N</sub>2 速率最重要的因素。**

**表 6-5：烷基取代對 S<sub>N</sub>2 速率的影響**（以異丙基溴 = 1 為基準）

| 類別 | 結構 | 相對速率 |
|---|---|---|
| 甲基 (methyl) | CH₃–Br | > 1000 |
| 一級 (1°) 乙基 | CH₃CH₂–Br | 50 |
| 一級 (1°) 正丁基 | CH₃CH₂CH₂CH₂–Br | 20 |
| 一級 (1°) 異丁基 | (CH₃)₂CHCH₂–Br | 2 |
| 二級 (2°) 異丙基 | (CH₃)₂CH–Br | 1 |
| 一級 (1°) 新戊基 (neopentyl) | (CH₃)₃CCH₂–Br | 0.0005 |
| 三級 (3°) 第三丁基 | (CH₃)₃C–Br | < 0.001 |

$$\text{S}_\text{N}\text{2 相對速率：} \text{CH}_3\text{X} > 1° > 2° \gg 3°$$

**解釋**
- 親核基必須從背面進入 C–X sp³ 軌域背面瓣的成鍵距離內。
- 頭碳上接兩個烷基 → 背面擁擠，攻擊困難；接三個烷基 → **不可能**。
- 決定因素是**烷基的體積（立體效應）**，而非電子效應。
- **新戊基溴**雖然是一級鹵化物，但相鄰碳上的第三丁基體積龐大，正好擋住背面攻擊路徑 → 速率與三級鹵化物相當。
- 從異丁基 (2) 與正丁基 (20) 的比較也可看出：**β 碳（與頭碳相鄰的碳）上的分支**同樣會降低速率。

> **解題提示**：**不要寫出發生在三級鹵烷上的 S<sub>N</sub>2 反應。**

## 6. S<sub>N</sub>2 反應的立體化學（6-12）

### 6.1 背面攻擊的軌域解釋

- 碳最多只能有四個填滿的鍵結軌域（八隅體），所以離去基必須在親核基成鍵的同時離開。
- 親核基的電子進入 C–X 鍵的**反鍵結分子軌域 (antibonding MO, σ\*)**——因為鍵結軌域 σ 已經填滿。
- σ\* 軌域在碳的**背面（遠離 X 的一側）**有較大的瓣 (lobe)；在 C 與 X 之間則有節面 (node)。所以親核基必須從背面進入。
- 電子填入 σ\* 會削弱 C–X 鍵，使離去基離開。
- 過渡態中，碳同時與親核基和離去基有部分鍵結。

### 6.2 構形反轉 (inversion of configuration)

- 背面攻擊使碳的四面體「**內翻外**」，就像**雨傘被強風吹翻**。
- 產物中，親核基位於與原離去基**相反**的立體位置。
- 若頭碳為**不對稱碳 (asymmetric carbon)**，產物得到**相反的構形**。

**機構 6-3：S<sub>N</sub>2 的構形反轉 (Mechanism 6-3)**

```
           H                       H                        H
           |                       |                        |
HO:⁻ →  C–Br:      →     [HO···C···Br]⁻‡       →      HO–C      +  Br⁻
       ⋰  ╲                    ⋰  ╲                       ╱  ⋱
    CH₃   CH₂CH₃          H₃C    CH₂CH₃              CH₃CH₂    CH₃
  (S)-2-溴丁烷                過渡態                    (R)-丁-2-醇
  ((S)-2-bromobutane)                                   ((R)-butan-2-ol)
```

- **瓦爾登反轉 (Walden inversion)**：反應序列中，不對稱碳發生構形反轉的步驟。S<sub>N</sub>2 是最常見的例子。（1890 年代德國杜賓根大學的 Paul Walden 最早研究此類反應。）

### 6.3 環狀化合物：cis ⇄ trans

構形反轉在環上最容易看出來：

```
順-1-溴-3-甲基環戊烷 (cis-1-bromo-3-methylcyclopentane)
     + ⁻OH  --S_N2-->
反-3-甲基環戊醇 (trans-3-methylcyclopentanol)
```

Br 與 CH₃ 原本在環的同側；OH 從 Br 的背面（即環的另一側）進入 → OH 與 CH₃ 位於異側。

### 6.4 立體專一性反應 (stereospecific reaction)

**定義**：不同的立體異構物 (stereoisomer) 反應後，生成**不同的**立體異構物產物。

- S<sub>N</sub>2 是立體專一性反應：(R) 受質 → 一種產物；(S) 受質 → 其鏡像異構物 (enantiomer)。
- **判斷機構的證據**：若產物顯示**完全構形反轉**，且速率為**二級**，很可能是 S<sub>N</sub>2。
- 若分子中沒有不對稱碳或環，就無法從立體化學判斷，只能依靠動力學等其他證據。

> **⚠ 重要提醒：(R) 與 (S) 只是「名字」**
> R/S 由取代基的**優先順序 (priority)** 決定。親核基與離去基的優先順序若不同，構形反轉後的**標記不一定**由 R 變 S。判斷立體化學時要看**空間排列**，不要只看名字！（見例題 11）

### 例題 10（課本 Problem 6-20，節選）

畫出下列 S<sub>N</sub>2 反應產物的立體結構。
(a) 反-1-溴-3-甲基環戊烷 (*trans*-1-bromo-3-methylcyclopentane) + KOH
(b) (R)-2-溴戊烷 ((R)-2-bromopentane) + KCN

**詳解**

**(a)** 反式起始物中 Br 與 CH₃ 在環的異側。HO⁻ 從 Br 的背面進入 → OH 與 CH₃ 位於**同側** →
**順-3-甲基環戊醇 (*cis*-3-methylcyclopentanol)**

**(b)** CN⁻ 從 Br 的背面攻擊 C2，構形反轉。

產物：CH₃–CH(CN)–CH₂CH₂CH₃，主鏈含腈碳 → **2-甲基戊腈 (2-methylpentanenitrile)**

R/S 判定：
- 反應物 C2 的優先順序：Br > CH₂CH₂CH₃（丙基）> CH₃ > H
- 產物 C2 的優先順序：CN（C 接 N,N,N）> CH₂CH₂CH₃（C 接 C,H,H）> CH₃ > H
- CN 取代了 Br 的「第一優先」地位，優先順序的排列與反應物相同；而空間排列反轉 → 標記由 R 變為 **S**
→ 產物為 **(S)-2-甲基戊腈**

### 例題 11（課本 Problem 6-21）

適當條件下，(S)-1-溴-1-氟乙烷 ((S)-1-bromo-1-fluoroethane) 與甲氧化鈉反應，得到純的 (S)-1-氟-1-甲氧基乙烷 ((S)-1-fluoro-1-methoxyethane)。
CH₃CHBrF + NaOCH₃ → CH₃CHFOCH₃ + NaBr
(a) 為何被取代的是溴而非氟？
(b) 畫出起始物、過渡態、產物的立體結構。
(c) 產物是構形保持還是構形反轉？
(d) 結果是否與 S<sub>N</sub>2 機構相符？

**詳解**

**(a)** Br⁻ 是遠比 F⁻ 好的離去基：Br⁻ 為更弱的鹼（HBr pK<sub>a</sub> −9 vs. HF 3.2）、可極化性高、C–Br 鍵較弱。F⁻ 小而硬，是很差的離去基。

**(b)**

```
          H                          H                           H
          |                          |                           |
CH₃O:⁻ → C–Br     →     [CH₃O···C···Br]⁻‡     →     CH₃O–C     +  Br⁻
        ⋰  ╲                     ⋰  ╲                       ╱  ⋱
       F    CH₃                 F    CH₃                 H₃C    F
      (S)-起始物                 過渡態                    (S)-產物
```

**(c) 構形反轉**——雖然標記仍是 (S)，但空間排列已經反轉。

逐步分析優先順序：

| | 優先序 1 | 優先序 2 | 優先序 3 | 優先序 4 |
|---|---|---|---|---|
| 起始物 | **Br** | F | CH₃ | H |
| 產物 | **F** | OCH₃（取代 Br 的位置） | CH₃ | H |

- 空間排列反轉 → 若優先順序不變，標記應由 S 變 R。
- 但新進入的 OCH₃（第 2 優先）的位置原本屬於 Br（第 1 優先）；F 則由第 2 升為第 1。**前兩名的優先順序對調**，這本身又讓標記反過來一次。
- 兩次「翻轉」相互抵消 → 標記仍為 S。

**(d) 相符。** 實際的空間排列是構形反轉，且是單一立體異構物（立體專一）→ 符合 S<sub>N</sub>2 背面攻擊。

## 7. 總整理表

### 7.1 S<sub>N</sub>2 反應特徵一覽

| 項目 | S<sub>N</sub>2 |
|---|---|
| 全名 | 雙分子親核取代 (bimolecular nucleophilic substitution) |
| 步驟數 | 1（協同反應） |
| 中間物 | 無 |
| 過渡態 | 1 個；五配位、近似三角雙錐；負電荷分散於 Nuc 與 LG |
| 速率定律 | rate = k[R–X][Nuc:⁻]，總二級 |
| 受質 | CH₃X > 1° > 2° ≫ 3°（3° 不反應） |
| 親核基 | 需要**強**親核基 |
| 離去基 | 需要好的離去基（弱鹼） |
| 溶劑 | 極性非質子性溶劑可大幅加速 |
| 立體化學 | **完全構形反轉**（瓦爾登反轉），立體專一 |
| 重排 | 不可能（無碳陽離子） |

### 7.2 親核性判斷流程

1. **電荷**：帶負電 > 中性（同原子）
2. **同週期**：越左越強（C > N > O > F）
3. **同族**：質子性溶劑中越下越強（I > Br > Cl > F；S > O；P > N）
4. **立體障礙**：越龐大越弱（EtO⁻ > *t*-BuO⁻）
5. **溶劑**：極性非質子性溶劑 > 質子性溶劑

### 7.3 受質反應性判斷流程

1. **先看級數**：CH₃ > 1° > 2°，3° 不行；注意新戊基型（β 位分支）大幅減速
2. **再看離去基**：I⁻ > Br⁻ > Cl⁻ ≫ F⁻；HO⁻、RO⁻、NH₂⁻ 不能當離去基
3. **不能直接離開的基團**：先質子化（–OH → –OH₂⁺）

### 7.4 鹼性 vs. 親核性比較

| 比較情境 | 鹼性順序 | 親核性順序（質子性溶劑） | 是否一致 |
|---|---|---|---|
| 同原子，帶電 vs. 中性 | HO⁻ > H₂O | HO⁻ > H₂O | ✔ |
| 同週期 | NH₂⁻ > HO⁻ > F⁻ | NH₂⁻ > HO⁻ > F⁻ | ✔ |
| 同族 | F⁻ > Cl⁻ > Br⁻ > I⁻ | I⁻ > Br⁻ > Cl⁻ > F⁻ | ✘（相反） |
| 立體障礙 | *t*-BuO⁻ > EtO⁻ | EtO⁻ > *t*-BuO⁻ | ✘（相反） |

## 8. 易錯觀念

1. **S<sub>N</sub>2 的「2」指雙分子**，不是兩個步驟。
2. **過渡態 ≠ 中間物**：S<sub>N</sub>2 沒有中間物。
3. **親核性是動力學（速率），鹼性是熱力學（平衡）**；兩者在同族與有立體障礙時趨勢相反。
4. 「I⁻ 的親核性大於 F⁻」**只在質子性溶劑中成立**。
5. **強鹼是差的離去基**；–OH、–OR 要先質子化才能離開。
6. **新戊基鹵化物是一級，但 S<sub>N</sub>2 極慢**；判斷障礙時也要看 β 碳。
7. **三級鹵烷不進行 S<sub>N</sub>2**——寫產物前先檢查級數。
8. **R/S 標記不等於空間排列**：構形反轉後標記可能不變（例題 11）。
9. 合成醚時，**讓鹵烷端是甲基或一級、烷氧離子端可以龐大**；反過來（三級鹵烷 + 烷氧離子）只會得到消去產物。
10. 腈的合成會**增加一個碳**；命名時別忘了把 CN 的碳算進主鏈。

### 習題 6-37（S<sub>N</sub>2 動力學與合成策略）

**題目** 溴甲烷加入第三丁氧化鉀中，產物為第三丁基甲基醚 (*tert*-butyl methyl ether)：
CH₃–Br + (CH₃)₃C–O⁻ K⁺ → (CH₃)₃C–O–CH₃
(a) 溴甲烷濃度加倍，速率如何變化？
(b) 第三丁氧化鉀濃度變為 3 倍、溴甲烷濃度加倍，速率如何變化？
(c) 溫度升高，速率如何變化？

**詳解**

**機構判斷**：受質為甲基鹵化物（最佳 S<sub>N</sub>2 受質、不可能形成甲基陽離子）；親核基為帶負電的烷氧離子（強親核基）→ **S<sub>N</sub>2**。

$$\text{rate} = k[\text{CH}_3\text{Br}][(\text{CH}_3)_3\text{CO}^-]$$

- **(a)** [CH₃Br] × 2 → 速率 **× 2**（加倍）。
- **(b)** 速率 × (2 × 3) = **× 6**。
- **(c)** 速率**增加**。依阿瑞尼士方程式 (Arrhenius equation) $k = Ae^{-E_a/RT}$，溫度升高時有較大比例的碰撞具有足以越過活化能的能量，速率常數 k 增大。

**延伸觀念（合成策略）**
第三丁氧離子是龐大的親核基，本題仍能順利進行，是因為受質為**完全沒有障礙的甲基**。若改用 (CH₃)₃C–Br + CH₃O⁻ 的組合，三級受質無法進行 S<sub>N</sub>2，CH₃O⁻ 只會當鹼引起消去（第 7 章）。**規劃威廉森醚合成時，讓障礙落在親核基那一側。**

### 習題 6-39（碘離子的催化作用）

**題目** 氯環己烷 (chlorocyclohexane) 在乙醇中與氰化鈉 (NaCN) 反應生成氰基環己烷 (cyanocyclohexane)。加入少量碘化鈉 (NaI) 後，生成速率增加。解釋此加速現象。

**詳解**

**沒有 NaI 時（慢）**

```
環己基–Cl  +  ⁻CN   --慢-->   環己基–CN  +  Cl⁻
```

慢的原因：(1) 受質為二級（有障礙）；(2) Cl⁻ 只是中等的離去基；(3) 在質子性溶劑乙醇中，⁻CN 被氫鍵溶劑化，親核性受到壓抑。

**加入 NaI 後：兩步驟的「接力」**

```
Step 1：環己基–Cl  +  I⁻   →   環己基–I  +  Cl⁻      （比 CN⁻ 直接攻擊快）
Step 2：環己基–I   +  ⁻CN  →   環己基–CN +  I⁻       （非常快，I⁻ 再生）
```

**為什麼兩步都比原本的一步快？**

| 步驟 | 加速原因 |
|---|---|
| Step 1 | I⁻ 在質子性溶劑中是**極強的親核基**：體積大、可極化性高、溶劑化弱（「軟」親核基），攻擊氯環己烷比 ⁻CN 更快 |
| Step 2 | 生成的碘環己烷帶有**極佳的離去基** I⁻（最弱的鹼、最可極化、C–I 鍵最弱），⁻CN 取代 I⁻ 遠比取代 Cl⁻ 容易 |

**I⁻ 是催化劑 (catalyst)**：在 Step 1 消耗、在 Step 2 再生，總反應不變，但提供了一條**活化能較低的替代路徑**。因此只需「少量」NaI 即可。

> **I⁻ 的雙重角色**：同時是好的親核基與好的離去基——這兩個性質都來自它的**高可極化性**。這是本題的核心觀念。

**立體化學補充**：若受質具有立體中心，每一步 S<sub>N</sub>2 各發生一次構形反轉，兩次反轉的結果是**淨構形保持 (net retention)**。（本題的環己烷無立體中心，此點不影響答案，但值得記住。）

### 習題 6-45（S<sub>N</sub>2 產物預測，節選 (a)(d)(f)）

**題目** 預測下列 S<sub>N</sub>2 反應的產物。
(a) CH₃CH₂ONa + CH₃CH₂Cl
(d) CH₃(CH₂)₈CH₂Cl + Na⁺ ⁻:C≡CH
(f) (CH₃)₃C–CH₂CH₂Br + 過量 NH₃

**詳解**

**(a)** 威廉森醚合成：

```
CH₃CH₂O⁻ Na⁺  +  CH₃CH₂–Cl   →   CH₃CH₂–O–CH₂CH₃  +  NaCl
                                  乙醚 (diethyl ether)
```

一級受質、強親核基 → S<sub>N</sub>2。

**(d)** 炔化物離子的烷基化 (alkylation of acetylide)：

```
CH₃(CH₂)₈CH₂–Cl  +  ⁻:C≡CH   →   CH₃(CH₂)₈CH₂–C≡CH  +  Cl⁻
                                  十二-1-炔 (dodec-1-yne)
```

碳數：10（癸基）+ 2 = 12。形成新的 C–C 鍵。

**(f)** 胺的合成：

```
(CH₃)₃C–CH₂–CH₂–Br  +  NH₃  →  (CH₃)₃C–CH₂–CH₂–NH₃⁺ Br⁻
(CH₃)₃C–CH₂–CH₂–NH₃⁺ + NH₃(過量)  →  (CH₃)₃C–CH₂–CH₂–NH₂ + NH₄⁺
                                       3,3-二甲基丁-1-胺 (3,3-dimethylbutan-1-amine)
```

> **本題陷阱**：看到第三丁基，很容易聯想到「新戊基型 → S<sub>N</sub>2 極慢」。但請數一數：
> - 新戊基溴 (CH₃)₃C–**CH₂**–Br：頭碳的**相鄰碳（β 碳）**就是四級碳 → 障礙極大。
> - 本題 (CH₃)₃C–CH₂–**CH₂**–Br：頭碳的相鄰碳是 CH₂，四級碳在 **γ 位**，距離較遠，龐大基團可以轉開 → 背面攻擊不受明顯阻礙。
> 所以本題可以正常進行 S<sub>N</sub>2。**障礙的關鍵在 α 碳與 β 碳。**

### 習題 6-48（放射性碘交換與旋光度——S<sub>N</sub>2 立體化學的經典證據）

**題目** 純 (S)-2-碘丁烷 ((S)-2-iodobutane)（[α] = +15.90°）的丙酮溶液，與放射性碘離子 ¹³¹I⁻ 反應，直到 1.0% 的碘丁烷含有放射性碘。回收的碘丁烷比旋光度 (specific rotation) 為 +15.58°。
(a) 求產物混合物中 (R)- 與 (S)-2-碘丁烷的百分比。
(b) 這個結果對 2-碘丁烷與碘離子反應的機構有何啟示？

**詳解**

**(a)**

**光學純度 (optical purity)** ＝ 觀測比旋光度 ÷ 純鏡像異構物的比旋光度，數值上等於**鏡像異構物過量 (enantiomeric excess, e.e.)**：

$$\text{e.e.} = \frac{+15.58°}{+15.90°} \times 100\% = 97.99\% \approx 98.0\%\ \text{（S 過量）}$$

設 S 佔 x%、R 佔 y%：

$$x + y = 100 \qquad x - y = 98.0$$

$$x = 99.0\% \qquad y = 1.0\%$$

→ **(S) 99.0%、(R) 1.0%**

**(b)**

- 有 **1.0%** 的分子與 ¹³¹I⁻ 發生取代（含放射性碘）。
- 產物中恰好有 **1.0%** 的 (R) 構形。
- 兩個數字**完全相等** → **每一次取代都伴隨構形反轉**：每個發生交換的 (S) 分子都變成了 (R)。
- 這正是 S<sub>N</sub>2 **背面攻擊、完全構形反轉**的直接證據。

**深入理解：為什麼旋光度下降了 2% 而不是 1%？**

每一個被轉換的分子產生「雙重效應」：
1. 它本身不再貢獻 (S) 的旋光（少了 1%）。
2. 它變成 (R)，會**抵消**另一個 (S) 分子的旋光（再少 1%）。

所以 e.e. 由 100% 下降到 98%：**失去光學活性的速率是交換速率的 2 倍**。

**對照**：若反應經過平面的碳陽離子（S<sub>N</sub>1，Part 3），被轉換的 1% 會以接近 50:50 的比例生成 R 與 S，旋光度只會下降約 1%（e.e. ≈ 99%），而非 2%。實驗結果（e.e. = 98%）排除了這種可能。

> 這是 1930 年代 Hughes 與 Ingold 等人用來確立 S<sub>N</sub>2 構形反轉的經典實驗設計。

### 習題 6-53（四氟硼酸三乙基鋞——強力乙基化試劑）

**題目** 四氟硼酸三乙基鋞 (triethyloxonium tetrafluoroborate)，(CH₃CH₂)₃O⁺ BF₄⁻，是熔點 91～92 °C 的固體。
(1) 說明此試劑如何經 S<sub>N</sub>2 把乙基轉移給親核基 (Nuc:⁻)。
(2) 離去基是什麼？
(3) 為什麼此試劑可能比乙基鹵化物更好用？（參考表 6-2）

**詳解**

**(1) 機構**

```
Nuc:⁻  +  CH₃CH₂–O⁺(CH₂CH₃)₂   →   [Nuc^δ−···CH₂(CH₃)···O^δ+(CH₂CH₃)₂]‡   →   Nuc–CH₂CH₃  +  O(CH₂CH₃)₂
                                                                                    乙基化產物     乙醚
```

- 親核基從 O 的背面攻擊其中一個乙基的 **α 碳**（一級碳，無障礙 → 適合 S<sub>N</sub>2）。
- C–O 鍵斷裂，鍵結電子對留在氧上。

**(2) 離去基是乙醚 (diethyl ether, CH₃CH₂OCH₂CH₃)**——一個**中性分子**。

為什麼是極佳的離去基？
- 從帶正電的鋞離子離開後，O 變回中性，非常穩定。
- 乙醚的共軛酸（質子化乙醚）pK<sub>a</sub> 約 −3.5，是強酸 → 乙醚是**極弱的鹼**。
- 帶正電的 O⁺ 對 α 碳有極強的拉電子效應，使碳的親電性非常高。

BF₄⁻（四氟硼酸根）是非親核性 (non-nucleophilic) 的相對離子 (counterion)，不會與親核基競爭。

**(3) 比乙基鹵化物更好用的原因**

| 比較 | 乙基鹵化物（表 6-2） | (CH₃CH₂)₃O⁺ BF₄⁻ |
|---|---|---|
| 物理狀態 | 乙基氟 bp −38 °C、乙基氯 bp 12 °C：室溫為**氣體**；乙基溴 bp 38 °C、乙基碘 bp 72 °C：**揮發性**液體 | **固體**（mp 91～92 °C） |
| 操作 | 難以精確秤量，易逸散，有吸入毒性 | 可直接秤重，計量準確 |
| 反應性 | 中等；弱親核基難以被乙基化 | **極高**；連弱親核基（如醚、醯胺、羰基氧）都能被乙基化 |

> **觀念連結**：這題把「**中性分子可從帶正電物種離開**」（表 6-4）與「質子化醇以水為離去基」的觀念推廣到烷基化：把 H⁺ 換成乙基，就得到鋞鹽。

### 習題 6-55（溶劑極性與帶電荷的過渡態）

**題目** 胺與鹵烷反應生成銨鹽 (ammonium salt)：
R₃N + R′–X → R₃N⁺–R′ X⁻
此 S<sub>N</sub>2 反應的速率對溶劑極性很敏感。分別畫出在非極性溶劑與極性溶劑中的能量圖，從過渡態的性質解釋為何此反應對溶劑極性敏感，並預測在較極性的溶劑中反應較快或較慢。

**詳解**

**Step 1：分析各階段的電荷**

| 階段 | 電荷狀態 |
|---|---|
| 反應物 R₃N + R′X | **兩者皆為中性**分子 |
| 過渡態 [R₃N^δ+···R′···X^δ−]‡ | **電荷分離 (charge separation) 正在形成**：N 帶部分正電、X 帶部分負電 → 偶極很大 |
| 產物 R₃N⁺R′ + X⁻ | **完整的離子對** |

**Step 2：極性溶劑的作用**

極性溶劑以偶極（質子性溶劑還有氫鍵）溶劑化並**穩定帶電荷或強極性的物種**：

- 反應物為中性 → 極性溶劑對其**穩定作用小**。
- 過渡態有部分電荷 → 極性溶劑**明顯穩定**它。
- 產物為離子 → 極性溶劑**強烈穩定**它。

**Step 3：能量圖**

```
能量
 ↑        ‡ 非極性溶劑
 │       ╱╲
 │      ╱  ╲         ‡ 極性溶劑（過渡態被穩定，能量降低）
 │     ╱    ╲       ╱╲
 │    ╱      ╲     ╱  ╲
 │ R₃N + R′X ─────────  ╲       （反應物為中性，兩種溶劑中能量差異不大）
 │   ╱         ╲  ╱       ╲
 │  ╱           ╲╱          ╲
 │               ╲ R₃N⁺R′ X⁻（非極性：離子不穩定，能量較高）
 │                ╲
 │                  ╲___ R₃N⁺R′ X⁻（極性：離子被強烈溶劑化，能量更低）
 └──────────────────────────────→ 反應座標
```

（為方便比較，兩條曲線以相同的反應物能量為基準畫在同一張圖中。）

- **E<sub>a</sub>(極性) < E<sub>a</sub>(非極性)**
- 在非極性溶劑中，生成離子對很不利，反應甚至可能幾乎不進行。

**Step 4：結論**

**在較極性的溶劑中反應較快。** 因為過渡態比反應物更極性（電荷正在產生），極性溶劑對過渡態的穩定作用大於對反應物的穩定作用，使活化能下降。

**對照與延伸：為什麼 HO⁻ + CH₃I 不一樣？**

| | R₃N + R′X | HO⁻ + CH₃I |
|---|---|---|
| 反應物 | 中性 | 親核基**帶完整負電荷** |
| 過渡態 | 電荷**正在產生** | 電荷**由集中變分散**（δ⁻···C···δ⁻） |
| 極性（尤其質子性）溶劑的影響 | 穩定過渡態更多 → **加速** | 強烈溶劑化帶電的反應物 HO⁻（電荷集中、較易溶劑化）→ 反應物被穩定得更多 → **減速** |

> **一般原則（休斯–英戈爾德溶劑效應 Hughes–Ingold rules）**：比較「反應物」與「過渡態」哪一個電荷較集中——溶劑極性增加時，**電荷較集中的那一方被穩定得較多**。若是過渡態 → 加速；若是反應物 → 減速。這個原則在 Part 3 討論 S<sub>N</sub>1（中性受質解離成離子 → 強烈需要極性溶劑）時會再次用到。
