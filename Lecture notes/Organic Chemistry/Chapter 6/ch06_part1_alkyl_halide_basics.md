## 1. 鹵化物的分類與 C–X 鍵的反應性（6-1）

### 1.1 三大類含鹵有機化合物

分類的依據是：**鹵素原子 (halogen atom) 接在哪一種混成軌域 (hybrid orbital) 的碳原子上**。

| 類別 | 定義 | 範例 |
|---|---|---|
| **烷基鹵化物 (alkyl halide)**，又稱 **鹵烷 (haloalkane)** | 鹵素接在 **sp³ 混成** 的碳上 | CHCl₃ 氯仿 (chloroform)、CF₃CHClBr 氟烷 (halothane) |
| **乙烯基鹵化物 (vinyl halide)** | 鹵素接在 **烯類 (alkene) 雙鍵的 sp² 碳** 上 | CH₂=CHCl 氯乙烯 (vinyl chloride)、CF₂=CF₂ 四氟乙烯 (tetrafluoroethylene, TFE) |
| **芳基鹵化物 (aryl halide)** | 鹵素接在 **芳香環 (aromatic ring) 的 sp² 碳** 上 | 對二氯苯 (*para*-dichlorobenzene)、甲狀腺素 (thyroxine) |

乙烯基鹵化物與芳基鹵化物的鍵結與混成不同，**不進行本章的 S<sub>N</sub>1 / S<sub>N</sub>2 反應**（原因在 Part 3 說明），會在後續章節另外討論。

> **⚠ 判斷陷阱**
> - 烯丙基氯 (allyl chloride) CH₂=CH–CH₂Cl：分子中有雙鍵，但 Cl 接在 **sp³** 的 CH₂ 上 → 屬於 **烷基鹵化物**，不是乙烯基鹵化物。
> - 苯甲基溴 (benzyl bromide) C₆H₅–CH₂Br：分子中有苯環，但 Br 接在 **sp³** 的 CH₂ 上 → 屬於 **烷基鹵化物**，不是芳基鹵化物。
> - 判斷時只看「**與鹵素直接相連的那個碳**」的混成。

### 1.2 C–X 鍵的極性與反應性

- 鹵素的陰電性 (electronegativity) 大於碳，因此 C–X 鍵為**極性共價鍵 (polar covalent bond)**：C 帶部分正電荷 (δ+)、X 帶部分負電荷 (δ−)。
- 靜電位能圖 (electrostatic potential map, EPM)：氯甲烷 (chloromethane) 中 Cl 周圍為紅色（電子密度高），C 與 H 周圍為藍色（電子密度低）。
- δ+ 的碳具有**親電性 (electrophilicity)**，可被**親核基 (nucleophile)** 攻擊；鹵素則帶著原本的鍵結電子對以**鹵離子 (halide ion)** 的形式離開，扮演**離去基 (leaving group)**。
- 結果有兩種：
  - 鹵素被其他官能基 (functional group) 取代 → **取代反應 (substitution)**
  - 鹵素連同鄰近的 H 被移除 → **消去反應 (elimination)**（第 7 章）
- 因此鹵烷是有機合成 (organic synthesis) 中非常重要的**中間物 (intermediate)**，可轉換成多種官能基。

### 例題 1（課本 Problem 6-1）

(a) (CH₃)₃CF　(b) CH₃CH=CBrCH₃　(c) CH₃CF₃　(d) 氯環戊烷 (chlorocyclopentane)　(f) 9-溴蒽 (9-bromoanthracene)

**詳解**

|---|---|---|

| (c) | CF₃ 的碳為 sp³ | 烷基鹵化物 |
| (d) | 環戊烷的 sp³ 碳 | 烷基鹵化物（二級） |
| (f) | 蒽環上的芳香 sp² 碳 | 芳基鹵化物 |

## 2. 鹵烷的命名（6-2）

### 2.1 IUPAC 系統命名 (systematic nomenclature)

把鹵素視為烷類 (alkane) 主鏈上的**取代基 (substituent)**：

| 鹵素 | 字首 (prefix) | 中文 |
|---|---|---|
| F | fluoro- | 氟 |
| Cl | chloro- | 氯 |
| Br | bromo- | 溴 |
| I | iodo- | 碘 |

**命名步驟**

1. 選出**最長碳鏈 (longest chain)** 為主鏈。
2. 從靠近**第一個取代基**的一端開始編號，使取代基位號 (locant) 的組合最小（鹵素與烷基地位相同，不享有優先）。
3. 若位號組合相同，則讓**英文字母序在前**的取代基得到較小的號碼。
4. 取代基依**英文字母順序 (alphabetical order)** 排列；環狀化合物需標示 *cis*/*trans*（順式／反式）。

**課本範例**

| 結構 | IUPAC 名稱 | 俗名 (common name) |
|---|---|---|
| CH₃CH₂F | 氟乙烷 (fluoroethane) | 乙基氟 (ethyl fluoride) |
| CH₃CH₂CH₂CH₂Cl | 1-氯丁烷 (1-chlorobutane) | 正丁基氯 (*n*-butyl chloride) |
| CH₃CHBrCH₃ | 2-溴丙烷 (2-bromopropane) | 異丙基溴 (isopropyl bromide) |
| C₆H₁₁I | 碘環己烷 (iodocyclohexane) | 環己基碘 (cyclohexyl iodide) |
| 環戊烷 1 號碳接 Cl、3 號碳接 CH₃，兩者反式 | 反-1-氯-3-甲基環戊烷 (*trans*-1-chloro-3-methylcyclopentane) | 無 |
| CH₃CH₂–CH(CH₂I)–CH₂CH₃ | 3-(碘甲基)戊烷 (3-(iodomethyl)pentane) | 無 |
| CH₃CH₂CH₂–CH(CH₂CH₂F)–CH₂CH₂CH₃ | 4-(2-氟乙基)庚烷 (4-(2-fluoroethyl)heptane) | 無 |

> **說明：為什麼是 3-(碘甲基)戊烷？**
> 若主鏈經過 CH₂I，只能得到 4 個碳的鏈；不經過 CH₂I 則可得 5 個碳。主鏈以「最長」優先，因此主鏈為戊烷，–CH₂I 視為取代基「碘甲基 (iodomethyl)」，括號是為了避免與主鏈編號混淆。

### 2.2 俗名 (common / trivial names)

俗名＝**烷基 (alkyl group) 名稱 ＋ 鹵化物 (halide)**，這正是「alkyl halide」一詞的由來。只適用於簡單的分子。

| 烷基 | 結構 | 中文 |
|---|---|---|
| methyl | CH₃– | 甲基 |
| ethyl | CH₃CH₂– | 乙基 |
| *n*-propyl | CH₃CH₂CH₂– | 正丙基 |
| isopropyl | (CH₃)₂CH– | 異丙基 |
| *n*-butyl | CH₃CH₂CH₂CH₂– | 正丁基 |
| *sec*-butyl | CH₃CH₂CH(CH₃)– | 第二丁基 |
| isobutyl | (CH₃)₂CHCH₂– | 異丁基 |
| *tert*-butyl | (CH₃)₃C– | 第三丁基 |
| neopentyl | (CH₃)₃CCH₂– | 新戊基 |
| *tert*-pentyl | CH₃CH₂C(CH₃)₂– | 第三戊基 |

**鹵甲烷 (halomethane) 的特殊俗名**

| 通式 | 俗名類別 | 例子（IUPAC／俗名） |
|---|---|---|
| CH₂X₂ | 亞甲基鹵化物 (methylene halide) | CH₂Cl₂：二氯甲烷 (dichloromethane)／methylene chloride |
| CHX₃ | 鹵仿 (haloform) | CHCl₃：三氯甲烷 (trichloromethane)／氯仿 (chloroform) |
| CX₄ | 四鹵化碳 (carbon tetrahalide) | CCl₄：四氯甲烷 (tetrachloromethane)／四氯化碳 (carbon tetrachloride) |

### 2.3 一級、二級、三級鹵化物

依「**與鹵素相連的碳（頭碳 head carbon）上接了幾個碳**」分類：

| 類別 | 頭碳接的碳數 | 通式 | 範例 |
|---|---|---|---|
| 甲基鹵化物 (methyl halide) | 0 | CH₃–X | CH₃Br 溴甲烷 (bromomethane) |
| 一級鹵化物 (primary, 1° halide) | 1 | R–CH₂–X | CH₃CH₂CH₂F 1-氟丙烷 (1-fluoropropane) |
| 二級鹵化物 (secondary, 2° halide) | 2 | R₂CH–X | CH₃CHICH₂CH₃ 2-碘丁烷 (2-iodobutane)／第二丁基碘 |
| 三級鹵化物 (tertiary, 3° halide) | 3 | R₃C–X | (CH₃)₃CCl 2-氯-2-甲基丙烷 (2-chloro-2-methylpropane)／第三丁基氯 |

> 這個分類在後面的 S<sub>N</sub>1／S<sub>N</sub>2 判斷中是**最關鍵的資訊**，務必熟練。

### 2.4 偕二鹵化物與鄰二鹵化物

- **偕二鹵化物 (geminal dihalide)**：兩個鹵素接在**同一個碳**上（拉丁文 *geminus*＝雙胞胎），例：CH₃CH₂CBr₂CH₃。
- **鄰二鹵化物 (vicinal dihalide)**：兩個鹵素接在**相鄰的碳**上（拉丁文 *vicinus*＝鄰近），例：CH₃CHBrCHBrCH₃。

(c) 3-iodo-2-methylpentane　(e) 2-chloro-3-ethyl-2-methylhexane　(f) isobutyl iodide　(g) *cis*-1-chloro-3-(chloromethyl)cyclohexane　(h) *tert*-butyl bromide

**詳解**

- (c) 3-碘-2-甲基戊烷：主鏈 5 碳，C2 接甲基、C3 接碘

- (e) 2-氯-3-乙基-2-甲基己烷：主鏈 6 碳，C2 同時接 Cl 和 CH₃，C3 接乙基
  `CH₃–CCl(CH₃)–CH(CH₂CH₃)–CH₂–CH₂–CH₃`（三級鹵化物）

## 3. 鹵烷的常見用途（6-3）

本節以閱讀、記憶為主，整理成表：

| 用途 | 代表化合物 | 重點 |
|---|---|---|
| **溶劑 (solvent)** | 四氯化碳 CCl₄、1,1,1-三氯乙烷 (1,1,1-trichloroethane)、二氯甲烷 CH₂Cl₂、氯仿 CHCl₃ | CCl₄ 有毒且**致癌 (carcinogenic)**，已被取代；CH₂Cl₂ 曾用於萃取咖啡因 (caffeine) 製造低咖啡因咖啡，後改用**超臨界二氧化碳 (supercritical CO₂)**；鹵化溶劑會溶解皮膚油脂，造成皮膚炎 (dermatitis) |
| **試劑 (reagent)** | 各種 R–X | 可轉為**有機金屬試劑 (organometallic reagent)**（含 C–金屬鍵，第 10 章） |
| **麻醉劑 (anesthetic)** | 氯仿 CHCl₃、氟烷 (halothane) CF₃CHClBr、異氟烷 (isoflurane)、地氟烷 (desflurane)、七氟烷 (sevoflurane)、氯乙烷 (ethyl chloride) | 氯仿因毒性被淘汰；氯乙烷沸點 12 °C，噴在皮膚上蒸發吸熱，作**局部麻醉 (topical anesthetic)** |
| **冷媒與發泡劑 (refrigerant, foaming agent)** | 氟里昂 (freon)＝**氟氯碳化物 (chlorofluorocarbons, CFCs)**：Freon-12 CF₂Cl₂、Freon-11 CCl₃F；替代品 Freon-22 CHClF₂（**氫氟氯碳化物 HCFC**）、HFC-134a CF₃CH₂F | CFCs 擴散至**平流層 (stratosphere)**，其中的 Cl 原子催化**臭氧 (ozone, O₃)** 分解；含 C–H 鍵的 HCFC 在較低的大氣層即被分解；HFC-134a 不含 Cl |
| **殺蟲劑 (pesticide / insecticide)** | DDT、靈丹 (lindane)、開蓬 (kepone)、阿特靈 (aldrin)、可氯丹 (chlordane) | DDT（1939）大幅降低瘧疾 (malaria) 等疾病的死亡；但在環境中**持久累積 (persistent, bioaccumulation)**，1972 年美國禁止作為農業用途 |

**補充（屬第 4 章觀念的延伸）：Cl 自由基催化臭氧分解**

```
Cl• + O₃ → ClO• + O₂
ClO• + O → Cl• + O₂
───────────────────────
淨反應： O₃ + O → 2 O₂     （Cl• 再生，為催化劑 catalyst）
```

1995 年諾貝爾化學獎頒給 Crutzen、Molina、Rowland，表彰他們對臭氧層形成與 Cl 自由基破壞臭氧機制的研究。

**補充：氯仿的保存** 氯仿在室溫下與 O₂ 反應可生成劇毒的**光氣 (phosgene, COCl₂)**，因此市售氯仿常加入少量乙醇 (ethanol) 以破壞可能生成的光氣。

## 4. 鹵烷的結構與偶極矩（6-4）

### 4.1 C–X 鍵的極化

- 鹵素接在 sp³ 碳上，幾何為**四面體 (tetrahedral)**。
- 鹵素陰電性大於碳 → C–X 鍵極化：C^δ+^–X^δ−^。
- 鍵的極性以**偶極矩 (dipole moment, μ)** 量化，單位為**德拜 (debye, D)**。

### 4.2 偶極矩公式推導：μ = 4.8 × δ × d

偶極矩的定義：兩個大小相等、符號相反的電荷 (+q 與 −q) 相隔距離 d：

$$\mu = q \times d$$

在分子中，電荷並不是完整的一個電子電量，而是**部分電荷 (partial charge)**。令 δ 表示「電荷分離的程度，以一個電子電量 e 為單位」，即 q = δ·e。

**以 CGS 單位推導（課本使用的形式）**

- 電子電量 e = 4.8 × 10⁻¹⁰ esu
- 鍵長以 Å 表示：1 Å = 10⁻⁸ cm
- 1 D = 10⁻¹⁸ esu·cm

$$\mu = (\delta \times 4.8\times10^{-10}\ \text{esu}) \times (d \times 10^{-8}\ \text{cm}) = 4.8\,\delta\,d \times 10^{-18}\ \text{esu·cm}$$

$$\boxed{\mu\ (\text{D}) = 4.8 \times \delta \times d\ (\text{Å})}$$

**以 SI 單位驗證**：e·Å = (1.602 × 10⁻¹⁹ C)(10⁻¹⁰ m) = 1.602 × 10⁻²⁹ C·m；而 1 D = 3.336 × 10⁻³⁰ C·m，故 1 e·Å = 1.602 × 10⁻²⁹ / 3.336 × 10⁻³⁰ ≈ **4.80 D**，與上式一致。

> **δ 的物理意義**
> δ 是一個 0～1 之間的分數：δ = 1 代表一個電子完全轉移（純離子鍵的極限），δ = 0 代表完全不極化（純共價、非極性）。C–X 鍵的 δ 約 0.1～0.25，說明它是**極性共價鍵**而非離子鍵。也因此 δ 可以理解為「鍵的離子性百分比」的粗略指標。

### 4.3 兩個相反的趨勢

| | C–F | C–Cl | C–Br | C–I |
|---|---|---|---|---|
| 鹵素陰電性 (electronegativity) | 4.0 | 3.2 | 3.0 | 2.7 |
| 鍵長 d (bond length, Å) | 1.38 | 1.78 | 1.94 | 2.14 |
| 鍵偶極矩 μ (bond dipole moment, D) | 1.51 | **1.56** | 1.48 | 1.29 |
| 由公式反推 δ = μ/(4.8d) | 0.228 | 0.183 | 0.159 | 0.126 |

- 由上往下（F → I）：**陰電性下降 → δ 變小**；但**原子變大 → d 變長**。
- 兩效應互相抵消，μ = 4.8δd 的乘積在 **Cl 達最大**。

$$\text{鍵偶極矩：C–I} < \text{C–Br} < \text{C–F} < \text{C–Cl}$$

> 注意：C–F 的 δ 最大（極性最強），但鍵最短，所以 μ 反而略小於 C–Cl。「極性最大」與「偶極矩最大」不是同一件事！

### 4.4 分子偶極矩 (molecular dipole moment)

**分子偶極矩是所有鍵偶極矩的向量和 (vector sum)**，取決於鍵角與分子形狀。

**表 6-1　鹵甲烷的分子偶極矩（D）**

| X | CH₃X | CH₂X₂ | CHX₃ | CX₄ |
|---|---|---|---|---|
| F | 1.82 | 1.97 | 1.65 | 0 |
| Cl | 1.94 | 1.60 | 1.03 | 0 |
| Br | 1.79 | 1.45 | 1.02 | 0 |
| I | 1.64 | 1.11 | 1.00 | 0 |

- **CX₄ 必為 0**：四個相同的鍵偶極以正四面體對稱排列，向量和為零（四氯化碳是非極性分子，但每一根 C–Cl 鍵都是極性鍵）。
- CH₃X 的順序 Cl > F > Br > I 與鍵偶極矩順序一致。
- 其餘數值不容易用簡單向量和精確預測（鍵角變形、各鍵間的相互極化都有影響），考試重點在**定性判斷**：對稱抵消 → 0；不對稱 → 不為 0。

### 例題 4（課本 Problem 6-5）

判斷各組中分子偶極矩較大者，並說明理由。
(a) 乙基氯 (ethyl chloride) 或乙基碘 (ethyl iodide)
(b) 1-溴丙烷 (1-bromopropane) 或環丙烷 (cyclopropane)
(c) 順-2,3-二溴丁-2-烯 (*cis*-2,3-dibromobut-2-ene) 或反-2,3-二溴丁-2-烯 (*trans*-)
(d) 順-1,2-二氯環丁烷 (*cis*-1,2-dichlorocyclobutane) 或反-1,3-二氯環丁烷 (*trans*-1,3-dichlorocyclobutane)

**詳解**

- (a) **乙基氯**較大。C–Cl 鍵偶極矩（1.56 D）> C–I（1.29 D）；兩者其餘結構相同。
- (b) **1-溴丙烷**較大。環丙烷只有 C–C 與 C–H 鍵，且高度對稱，μ ≈ 0；1-溴丙烷含極性 C–Br 鍵。
- (c) **順式**較大。反式中兩個 C–Br 鍵偶極方向相反、互相抵消（兩個 C–CH₃ 也抵消），μ = 0；順式中兩個 C–Br 偶極指向同側，向量相加。
- (d) **順-1,2-二氯環丁烷**較大。順-1,2 中兩個 C–Cl 在同側且相鄰，向量相加；反-1,3 中兩個 C–Cl 位於環的對角且分處兩側，方向近乎相反，大致抵消。

## 5. 鹵烷的物理性質（6-5）

### 5.1 沸點 (boiling point)

影響鹵烷沸點的分子間作用力 (intermolecular forces)：

1. **倫敦分散力 (London dispersion force)**——**最主要**。來自瞬間偶極 (temporary dipole) 的相互誘導，屬於**表面作用力**：表面積越大、可極化性 (polarizability) 越大，作用力越強。
2. **偶極–偶極力 (dipole–dipole force)**——來自極性 C–X 鍵，影響**較小**。

鹵烷**沒有**可形成氫鍵 (hydrogen bond) 的 O–H 或 N–H，因此不考慮分子間氫鍵。

**鹵素原子的大小（凡得瓦半徑 van der Waals radius）**

| 原子 | H | F | Cl | Br | I |
|---|---|---|---|---|---|
| 凡得瓦半徑 (10⁻⁸ cm, 即 Å) | 1.2 | 1.35 | 1.8 | 1.95 | 2.15 |

**推論一：氟化物 vs. 烷類** F 的大小與 H 接近，所以烷基氟化物 (alkyl fluoride) 的表面積與對應烷類差不多，倫敦力相近；但 C–F 帶來偶極–偶極力，沸點略高。
例：正丁烷 (*n*-butane) bp 0 °C；正丁基氟 (*n*-butyl fluoride) bp 33 °C。

**推論二：F < Cl < Br < I** 鹵素越大，表面積與可極化性越大，分子量也越大（運動越慢），沸點越高。

| 乙基鹵化物 (ethyl halide) | CH₃CH₂F | CH₃CH₂Cl | CH₃CH₂Br | CH₃CH₂I |
|---|---|---|---|---|
| 沸點 (°C) | −38 | 12 | 38 | 72 |

| 正丁基鹵化物 | F | Cl | Br | I |
|---|---|---|---|---|
| 沸點 (°C) | 33 | 78 | 102 | 131 |

**推論三：支鏈 (branching) 使沸點下降** 支鏈越多，分子越接近球形 (spherical)，表面積越小，倫敦力越弱。
例：正丁基溴 (*n*-butyl bromide) bp 102 °C；第三丁基溴 (*tert*-butyl bromide) bp 73 °C。

> 偶極矩最大的是 C–Cl，但沸點最高的卻是碘化物——再次證明**倫敦力才是主角**。

### 例題 6（課本 Problem 6-7）

水與己烷 (hexane) 混合搖晃後分成兩層，哪一層是哪一物質？水與氯仿呢？水與乙醇 (CH₃CH₂OH) 呢？

**詳解**

- **水／己烷**：兩者不互溶。己烷密度約 0.66 g/mL < 1.00 → **己烷在上層、水在下層**。

## 6. 鹵烷的製備（6-6）

### 6.1 自由基鹵化 (free-radical halogenation) 的回顧與限制

**機構 (mechanism)（第 4 章）**

```
起始步驟 (initiation)：     X₂  --hν 或加熱-->  2 X•
傳遞步驟 (propagation)：    R–H + X•  →  R• + H–X
                           R• + X₂   →  R–X + X•
終止步驟 (termination)：    任兩個自由基結合（X• + X•、R• + X•、R• + R•）
```

**作為實驗室合成方法的缺點**

1. 分子中常有**不同種類的氫**，產物為異構物混合物。
2. 可能**多重取代 (multiple substitution)**，生成二鹵、三鹵化物。
   例：丙烷 (propane) 氯化 → 1-氯丙烷、2-氯丙烷、1,1-二氯丙烷、1,2-二氯丙烷、2,2-二氯丙烷……的混合物。

工業上可接受（原料便宜、產物可蒸餾分離後分別出售），實驗室則需要「單一產物、高產率」，所以很少使用。

**選擇性 (selectivity) 的回顧**

| | 1° H | 2° H | 3° H |
|---|---|---|---|
| 氯化（25 °C，每個 H 的相對反應性，約略值） | 1 | 約 4.5 | 約 5.5 |
| 溴化（每個 H 的相對反應性，約略值） | 1 | 約 82 | 約 1600 |

依**哈蒙德假說 (Hammond's postulate)**：溴原子奪氫為吸熱步驟 → **晚期過渡態 (late transition state)**，結構近似自由基，因此自由基穩定度的差異幾乎完全反映在活化能上 → 溴化**高度選擇性**。氯原子奪氫為放熱 → 早期過渡態 → 選擇性差。

**實驗室中可用的特殊情形**

| 情形 | 範例 | 說明 |
|---|---|---|
| 所有氫都等價 (equivalent) | 環己烷 + Cl₂, hν → 氯環己烷 (chlorocyclohexane)（50%） | 用**過量環己烷、少量 Cl₂** 抑制多重取代 |
| 只有一個特別活潑的氫 + 溴化 | 異丁烷 (isobutane) + Br₂, hν → 第三丁基溴（90%） | 唯一的 3° H 被選擇性奪取，形成 3° 自由基 |

### 6.2 烯丙基溴化 (allylic bromination)

#### (1) 名詞定義

- **烯丙基位 (allylic position)**：緊鄰 C=C 雙鍵的**飽和碳 (sp³ carbon)**。
- **烯丙基氫 (allylic hydrogen)**：接在烯丙基位上的氫。

```
     雙鍵碳   烯丙基位
        ↓      ↓
 C=C–C–H      → 這個 H 是烯丙基氫
```

#### (2) 為何烯丙基氫特別容易被奪取？——共振穩定化

課本給的**鍵解離焓 (bond dissociation enthalpy, BDE)**：

| 斷裂的鍵 | 生成的自由基 | ΔH° |
|---|---|---|
| CH₂=CH–CH₂–H | 1° 烯丙基自由基 (allylic radical) | +372 kJ/mol (89 kcal/mol) |
| (CH₃)₂CH–H | 2° 自由基 | +413 kJ/mol (99 kcal/mol)（課本數據） |

即使是**一級**的烯丙基自由基，也比一般**二級**自由基容易形成，原因是**共振穩定化 (resonance stabilization)**：

```
 [ CH₂=CH–ĊH₂   ←→   ĊH₂–CH=CH₂ ]
```

> **共振的物理意義（重要觀念）**
> - 這兩個結構**不是**兩種會互相轉換的分子，也不是快速平衡；真正的分子只有一種，是兩者的**共振混成體 (resonance hybrid)**。
> - 從軌域觀點：三個相鄰碳原子的 p 軌域平行重疊，未成對電子 (unpaired electron) **非定域化 (delocalized)** 在整個三碳系統上。
> - 未成對電子的密度集中在**兩端的碳（C1 與 C3）**，中間的 C2 幾乎沒有 → 這解釋了為什麼溴只會接在兩端，而不會接在中間碳上。
> - 電子分布範圍越廣，能量越低 → 自由基越穩定 → C–H 鍵越容易斷。

#### (3) 機構：機構 6-1 烯丙基溴化 (Mechanism 6-1)

```
起始步驟：           Br–Br  --hν-->  2 Br•

第一傳遞步驟：       C=C–C–H  +  Br•   →   [ C=C–Ċ  ←→  Ċ–C=C ]  +  H–Br
（奪取烯丙基氫）                             烯丙基自由基（共振穩定）

第二傳遞步驟：       烯丙基自由基 + Br–Br  →  C=C–C–Br   或   Br–C–C=C   +  Br•
（任一端的自由基碳                          （原位置）       （烯丙基轉移產物）
  都可以與 Br₂ 反應）

總反應：             C=C–C–H  +  Br₂  --hν-->  C=C–C–Br  +  HBr
```

- 若在第二種共振式的自由基碳上反應，溴接到的位置與原本被奪走的 H 不同，雙鍵也移位 → 稱為**烯丙基轉移 (allylic shift)**。
- 例：環己烯 (cyclohexene) + Br₂, hν → 3-溴環己烯 (3-bromocyclohexene)（80%）

#### (4) NBS 的角色：維持低濃度的 Br₂

高濃度的 Br₂ 會與 C=C **加成 (addition)**（第 8 章），生成鄰二溴化物，與我們想要的取代反應競爭。

**N-溴丁二醯亞胺 (N-bromosuccinimide, NBS)** 的作用：

```
NBS  +  HBr  →  丁二醯亞胺 (succinimide)  +  Br₂
```

- 每一次傳遞步驟一產生 HBr，就立刻被 NBS 轉成一分子 Br₂，正好補充傳遞步驟二消耗掉的 Br₂。
- 因此反應中 Br₂ 始終維持**低而穩定的濃度**。
- 市售 NBS 本身含微量 Br₂，可用來起始反應，不需另外加 Br₂。

> **為什麼「低濃度 Br₂」就能偏向取代而非加成？**
> - 自由基連鎖取代只需要**極少量** Br₂ 就能持續進行。
> - 加成反應的速率對 [Br₂] 的依賴程度較高；Br₂ 很稀時，加成大幅變慢。
> - 此外，Br• 即使加到雙鍵上，生成的溴烷基自由基在缺少 Br₂ 可捕捉時會再脫去 Br•（可逆），雙鍵恢復；而奪取烯丙基氫則導向穩定的共振自由基，最終生成烯丙基溴。

NBS 也可用於**苯甲基位 (benzylic position)**（緊鄰芳香環的碳）的溴化，因為苯甲基自由基 (benzylic radical) 也受共振穩定（第 15 章詳述）。

#### (5) 預測 NBS 烯丙基溴化產物的步驟

1. 找出分子中**所有種類**的烯丙基氫（及苯甲基氫）。
2. 判斷奪取哪一種 H 會得到**最穩定**的自由基。
3. 畫出該自由基的**所有共振式**。
4. 在每一個帶未成對電子的碳上接 Br，寫出產物。
5. 檢查**對稱性**：不同共振式是否給出相同的化合物（若相同，只有一種產物）。

### 例題 7（課本 Problem 6-8）

(a) 提出 H₂C=CH–CH₃ + Br₂ --hν--> H₂C=CH–CH₂Br + HBr 的機構。
(b) 利用鍵解離焓計算各步驟的 ΔH° 及總 ΔH°（CH₂=CHCH₂–Br 的 BDE 約 280 kJ/mol），並判斷這些數值是否符合快速的自由基連鎖反應。

**所需數據（課本表 4-2）**：Br–Br 192 kJ/mol；H–Br 368 kJ/mol；CH₂=CHCH₂–H 372 kJ/mol；CH₂=CHCH₂–Br 280 kJ/mol（題目給定）。

**詳解**

(a) 機構

```
起始：     Br₂  --hν-->  2 Br•
傳遞 1：   CH₂=CH–CH₃ + Br•  →  [CH₂=CH–ĊH₂ ←→ ĊH₂–CH=CH₂] + HBr
傳遞 2：   CH₂=CH–ĊH₂ + Br₂  →  CH₂=CH–CH₂Br + Br•
```

（丙烯的烯丙基自由基兩個共振式等價，兩端反應得到同一產物。）

(b) ΔH° ＝ Σ（斷鍵 BDE）− Σ（成鍵 BDE）

| 步驟 | 斷鍵 | 成鍵 | ΔH° |
|---|---|---|---|
| 起始 | Br–Br（+192） | — | **+192 kJ/mol** |
| 傳遞 1 | C–H（+372） | H–Br（−368） | **+4 kJ/mol** |
| 傳遞 2 | Br–Br（+192） | C–Br（−280） | **−88 kJ/mol** |
| **總反應**（傳遞 1 + 傳遞 2） | | | **−84 kJ/mol** |

驗算總反應：斷 C–H（372）+ Br–Br（192）＝ 564；成 C–Br（280）+ H–Br（368）＝ 648；ΔH° ＝ 564 − 648 ＝ −84 kJ/mol ✓

**判斷**：起始步驟強烈吸熱，但只需要少數自由基就能起始，由光能 (hν) 提供；兩個傳遞步驟一個幾乎熱中性 (+4)、一個強烈放熱 (−88)，**沒有高度吸熱的傳遞步驟**，因此連鎖反應能快速進行。總反應放熱，熱力學有利。

### 例題 8（課本 Problem 6-9）

2,3-二甲基丁-2-烯 (2,3-dimethylbut-2-ene) 與 NBS 照光反應生成兩種產物。
(a) 寫出機構，說明兩產物如何由共振穩定的中間物產生。
(b) 環己烯用 NBS 溴化只得一種主產物，為何沒有烯丙基轉移的第二產物？

**詳解**

(a) 2,3-二甲基丁-2-烯：(CH₃)₂C=C(CH₃)₂，四個甲基上的 12 個氫全部等價，且都是烯丙基氫。

```
起始：    NBS 中微量 Br₂ --hν--> 2 Br•

傳遞 1：  (CH₃)₂C=C(CH₃)–CH₃ + Br•  →  HBr + 烯丙基自由基

          [ (CH₃)₂C=C(CH₃)–ĊH₂   ←→   (CH₃)₂Ċ–C(CH₃)=CH₂ ]
               1° 自由基端                3° 自由基端

傳遞 2：  在 1° 端與 Br₂ 反應 → (CH₃)₂C=C(CH₃)–CH₂Br
                                 1-溴-2,3-二甲基丁-2-烯 (1-bromo-2,3-dimethylbut-2-ene)
          在 3° 端與 Br₂ 反應 → Br–C(CH₃)₂–C(CH₃)=CH₂
                                 3-溴-2,3-二甲基丁-1-烯 (3-bromo-2,3-dimethylbut-1-ene)（烯丙基轉移）

HBr + NBS → 丁二醯亞胺 + Br₂（補充 Br₂）
```

(b) 環己烯奪取 C3 上的烯丙基氫後，自由基非定域化在 C1 與 C3 上。這兩個共振式**由對稱性互為等價**（把環翻過來就重合），所以 Br 無論接在哪一端，得到的都是**同一個化合物** 3-溴環己烯（雙鍵移位後重新編號仍是 3-溴環己烯）。並不是沒有發生烯丙基轉移，而是轉移後的產物與原產物相同。

## 8. 易錯觀念

1. **烯丙基氯、苯甲基溴是「烷基」鹵化物**——看的是與鹵素相連的那個碳的混成。
2. **極性最大 ≠ 偶極矩最大**：C–F 的 δ 最大，但 C–Cl 的鍵偶極矩最大。
3. **CCl₄ 的 C–Cl 是極性鍵，但分子是非極性分子**（向量和為零）。
4. **鹵烷沸點以倫敦分散力為主**，因此碘化物沸點最高，而非偶極矩最大的氯化物。
5. **支鏈降低沸點**：比較沸點時，碳數相同要看形狀；碳數或鹵素不同時，分子量／鹵素大小通常是主要因素。
6. **共振式不是平衡**：烯丙基自由基只有一種真實結構（共振混成體）。
7. **烯丙基轉移時雙鍵會移位**：寫產物時記得把雙鍵移到新位置。
8. **畫烯丙基自由基共振式時**，未成對電子只出現在兩端碳上，Br 不會接到中間碳。
9. **NBS 的目的不是「提供大量溴」**，而是「維持低濃度 Br₂」以避免與雙鍵加成。
10. 命名時鹵素與烷基取代基**地位相同**，依最低位號組合與英文字母序決定，鹵素沒有編號優先權。

### 習題 6-47（物性、反應性與環境的綜合題）

**題目** 草莓農曾大量使用溴甲烷 (methyl bromide, bp 4 °C) 進行土壤消毒。溴甲烷與部分氟里昂一樣會擴散到平流層破壞臭氧層。農業化學家建議改用碘甲烷 (methyl iodide, bp 43 °C)。
(1) 為何碘甲烷對害蟲（以及人類）的毒性可能比溴甲烷更強？
(2) 為何碘甲烷比溴甲烷較不容易抵達平流層？

**詳解**

**(1) 毒性較強的原因——碘甲烷是更強的甲基化劑 (methylating agent)**

- 這類鹵甲烷的毒性來自於它們會被生物分子上的**親核基**（例如 DNA 鹼基上的 N、蛋白質上的 –SH 與 –NH₂）攻擊，發生 S<sub>N</sub>2 反應，把甲基接到生物分子上（**烷基化 alkylation**），破壞其功能。
- 碘離子 (I⁻) 是比溴離子更好的**離去基**：C–I 鍵最弱（CH₃–I 約 234 kJ/mol vs. CH₃–Br 293 kJ/mol），且 I 原子大、可極化性高、I⁻ 是極弱的鹼（詳見 Part 2 的離去基條件）。
- 因此 CH₃I 的 S<sub>N</sub>2 反應比 CH₃Br 更快 → 對生物分子的甲基化更迅速 → 毒性更強。

**(2) 較不易抵達平流層的原因**

- **揮發性較低**：碘甲烷沸點 43 °C，室溫下為液體；溴甲烷沸點 4 °C，室溫下為氣體，極易逸散到大氣中。碘甲烷蒸氣壓較低，從土壤中逸散的量較少。
- **在低層大氣中較快被分解**：C–I 鍵很弱，能吸收波長較長的陽光（對流層中就有的紫外光）而發生**光解 (photolysis)**；同時它也較容易與環境中的親核基（水、土壤成分）反應。碘甲烷在大氣中的**壽命 (lifetime)** 很短，在擴散到平流層之前大多已被破壞。
- 類比課本中 HCFC 的觀念：只要分子在**對流層 (troposphere)** 就能被分解，就不會造成平流層臭氧的損害。

> **觀念連結**：這題把 6-4（鍵長、鍵能）、6-5（沸點）、6-3（臭氧層）與 S<sub>N</sub>2 反應性（Part 2）串在一起，是典型的申論型考題。

### 習題 6-50（烯丙基溴化與烯丙基轉移）

**題目** 3-甲基丁-1-烯 (3-methylbut-1-ene) 與 NBS 照光反應，得到未重排產物與重排產物兩種。寫出機構解釋這兩種產物。

```
CH₂=CH–CH(CH₃)₂  --NBS, hν-->  CH₂=CH–CBr(CH₃)₂   +   BrCH₂–CH=C(CH₃)₂
 3-甲基丁-1-烯                    未重排                    重排
```

**詳解**

**Step 0：找烯丙基氫**
3-甲基丁-1-烯中，C3 緊鄰雙鍵，是烯丙基位，且 C3 上只有**一個三級氫**（同時是 3° 又是烯丙基 → 非常容易被奪取）。

**Step 1：起始**

```
Br–Br（NBS 所含微量）--hν-->  2 Br•
```

**Step 2：第一傳遞步驟——奪取 C3 上的烯丙基氫**

```
CH₂=CH–C(CH₃)₂      +   Br•   →   H–Br  +  烯丙基自由基
          |
          H
```

**Step 3：烯丙基自由基的共振式**

```
[ CH₂=CH–Ċ(CH₃)₂         ←→        ĊH₂–CH=C(CH₃)₂ ]
   未成對電子在 3° 碳上                未成對電子在 1° 碳上
   （雙鍵為單取代）                     （雙鍵為三取代）
```

**Step 4：第二傳遞步驟——兩端都可與 Br₂ 反應**

```
在 C3（三級端）反應：  CH₂=CH–CBr(CH₃)₂  +  Br•
                       3-溴-3-甲基丁-1-烯 (3-bromo-3-methylbut-1-ene)  → 未重排產物

在 C1（一級端）反應：  BrCH₂–CH=C(CH₃)₂  +  Br•
                       1-溴-3-甲基丁-2-烯 (1-bromo-3-methylbut-2-ene)  → 重排產物（烯丙基轉移）
```

**Step 5：NBS 補充 Br₂**

```
NBS + HBr → 丁二醯亞胺 + Br₂
```

**討論**
- 「重排」並不是碳骨架改變，而是**雙鍵與溴的位置一起移動**——這就是烯丙基轉移。
- 重排產物中的雙鍵為**三取代 (trisubstituted)**，比未重排產物的單取代雙鍵穩定；且一級碳的立體障礙較小，Br₂ 較容易接近。這兩點有利於重排產物的生成，因此重排產物通常佔有相當大的比例。

### 習題 6-57(b)（亞甲基環己烷的烯丙基溴化）

**題目** 提出機構解釋下列反應的產物（依教材圖示判讀，起始物為亞甲基環己烷 methylenecyclohexane）：

```
亞甲基環己烷  --NBS, hν-->  2-溴-1-亞甲基環己烷  +  1-(溴甲基)環己烯
                            (2-bromo-1-methylidenecyclohexane)   (1-(bromomethyl)cyclohexene)
```

**詳解**

**Step 0：找烯丙基氫**
亞甲基環己烷：環上 C1 以雙鍵連接環外的 =CH₂。烯丙基位為環上的 **C2 與 C6**（兩者因對稱而等價），各帶兩個 2° 氫。（環外的 =CH₂ 是 sp² 碳，上面的氫是乙烯基氫 vinylic hydrogen，不是烯丙基氫。）

**Step 1：起始** Br₂ --hν--> 2 Br•

**Step 2：奪取 C2 上的烯丙基氫**

```
C2–H + Br• → C2• + HBr
```

**Step 3：共振式**

```
[  環外 CH₂=C1，C2 為 2° 自由基     ←→     環外 •CH₂（1° 自由基），C1=C2 成為環內雙鍵  ]
```

**Step 4：兩端分別與 Br₂ 反應**

- 在 **C2** 反應 → Br 接在環上 C2，環外雙鍵保留 → **2-溴-1-亞甲基環己烷**
- 在**環外 CH₂** 反應 → Br 接在 CH₂ 上，雙鍵移入環內（C1=C2）→ **1-(溴甲基)環己烯**（烯丙基轉移產物）

**Step 5：** NBS + HBr → 丁二醯亞胺 + Br₂

**討論**
- 1-(溴甲基)環己烯的雙鍵為**三取代環內雙鍵**，較環外雙取代雙鍵穩定。
- 這個自由基與下一題 6-59 中「從 1-甲基環己烯的甲基上奪氫」所得的自由基**完全相同**——同一個自由基可以從兩種不同的烯類產生，請兩題對照著看。

### 習題 6-59（1-甲基環己烯的 NBS 溴化——本章 Part 1 最具挑戰性）

**題目** 學生將 NBS 加入 1-甲基環己烯 (1-methylcyclohexene) 溶液並用日光燈照射，直到 NBS 完全反應。仔細蒸餾後，產物混合物中有兩種主要產物，分子式皆為 C₇H₁₁Br。
(a) 畫出三種可能的烯丙基自由基中間物的共振式。
(b) 將這三種中間物依穩定度由大到小排列。
(c) 畫出由每一種自由基中間物所得的產物。

**詳解**

**編號約定**：環上帶甲基的雙鍵碳為 C1，另一個雙鍵碳為 C2，順著環依序為 C3、C4、C5、C6（C6 與 C1 相鄰）；甲基碳稱為 C7。

```
         C7H₃
          |
     C6 — C1
    /       \
  C5         C2      ← C1=C2 為雙鍵
    \       /
     C4 — C3
```

**找出烯丙基氫**：與雙鍵碳（C1、C2）相鄰的 sp³ 碳有三個：

| 烯丙基位 | 所接的雙鍵碳 | 氫的種類 |
|---|---|---|
| C7（甲基） | C1 | 3 個 1° 氫 |
| C6 | C1 | 2 個 2° 氫 |
| C3 | C2 | 2 個 2° 氫 |

#### (a) 三種烯丙基自由基及其共振式

**自由基 A：奪取 C7（甲基）上的氫**

```
A-1：C7•（1° 自由基），C1=C2 為環內三取代雙鍵
A-2：C2•（2° 自由基），C1=C7 為環外雙取代雙鍵（亞甲基）
```

**自由基 B：奪取 C6 上的氫**

```
B-1：C6•（2° 自由基），C1=C2 雙鍵（三取代）
B-2：C2•（2° 自由基），C1=C6 雙鍵（三取代）
```

**自由基 C：奪取 C3 上的氫**

```
C-1：C3•（2° 自由基），C1=C2 雙鍵（三取代）
C-2：C1•（3° 自由基，C1 帶甲基），C2=C3 雙鍵（雙取代）
```

#### (b) 穩定度排序

判斷依據：自由基的穩定度與**未成對電子分布的碳之取代程度**有關（3° > 2° > 1°），在共振混成體中，取代程度越高的碳分擔越多未成對電子，整體越穩定。

| 自由基 | 未成對電子分布在 | 評價 |
|---|---|---|
| **C** | 3° 碳（C1）與 2° 碳（C3） | 含一個三級自由基共振式 → **最穩定** |
| **B** | 2° 碳（C6）與 2° 碳（C2） | 兩端皆為二級 → 次之 |
| **A** | 1° 碳（C7）與 2° 碳（C2） | 含一級自由基共振式 → **最不穩定** |

$$\textbf{C} > \textbf{B} > \textbf{A}$$

#### (c) 各自由基所得產物

| 自由基 | 在哪個碳接 Br | 產物 |
|---|---|---|
| **A** | C7 | **1-(溴甲基)環己烯** (1-(bromomethyl)cyclohexene) |
| **A** | C2 | **2-溴-1-亞甲基環己烷** (2-bromo-1-methylidenecyclohexane) |
| **B** | C6 | **6-溴-1-甲基環己烯** (6-bromo-1-methylcyclohexene) |
| **B** | C2 | 雙鍵移至 C1=C6，Br 位於 C2，而 C2 正好與帶甲基的 C1 相鄰 → 重新編號後**仍是 6-溴-1-甲基環己烯** |
| **C** | C3 | **3-溴-1-甲基環己烯** (3-bromo-1-methylcyclohexene) |
| **C** | C1 | Br 與 CH₃ 同在 C1，雙鍵移至 C2=C3 → 重新編號為 **3-溴-3-甲基環己烯** (3-bromo-3-methylcyclohexene) |

所有產物分子式皆為 C₇H₁₁Br ✓

**重點說明**

1. **自由基 B 只給一種產物**：B-1 與 B-2 兩個共振式以「通過 C1、C4 的鏡面」互為鏡像——兩端都是「Br 接在與甲基碳相鄰的烯丙基碳上」。這與例題 8(b) 環己烯的情形相同：烯丙基轉移後得到相同的化合物。（產物 C6 為手性中心，以外消旋形式生成。）
2. **自由基 C 給兩種不同的產物**：一端是 2° 碳、另一端是帶甲基的 3° 碳，兩端不等價。
3. **自由基 A 與習題 6-57(b) 中的自由基相同**，產物也相同。
4. 總計最多可能有 **5 種**不同的單溴產物，這說明了即使是「選擇性高」的 NBS 溴化，面對多種烯丙基氫時仍會得到混合物；實驗中能分離出的主要產物會來自較穩定的自由基（C 與 B）。

> **解題 SOP 回顧**：找出所有烯丙基位 → 每一種各畫兩個共振式 → 依未成對電子所在碳的級數比較穩定度 → 每個自由基碳各接一次 Br → 重新編號、檢查是否重複。
