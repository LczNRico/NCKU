## 1. S<sub>N</sub>1 反應的發現：溶劑解與一級動力學（6-13）

### 1.1 一個「不可能是 S<sub>N</sub>2」的取代反應

```
(CH₃)₃C–Br  +  CH₃–OH   --煮沸-->   (CH₃)₃C–O–CH₃  +  HBr
第三丁基溴      甲醇                  甲基第三丁基醚 (methyl tert-butyl ether)
```

- **溶劑解 (solvolysis)**：溶劑本身作為親核基的取代（或消去）反應。solvo＝溶劑，lysis＝斷裂，字面意思是「被溶劑切斷」。
- 這不是 S<sub>N</sub>2，因為 S<sub>N</sub>2 需要 (1) 強親核基、(2) 障礙不大的受質；但此處：
  - 甲醇是**弱親核基 (weak nucleophile)**（中性分子）
  - 第三丁基溴是**三級**、障礙極大的受質

### 1.2 動力學證據

實驗發現：**反應速率與甲醇（親核基）的濃度無關**，只與第三丁基溴的濃度有關。

$$\text{rate} = k_r[(\text{CH}_3)_3\text{C–Br}]$$

- 對鹵烷為一級、對親核基為**零級 (zeroth order)** → **總一級 (first order overall)**。
- 推論：親核基**不在速率決定步驟的過渡態中** → 親核基必定是在慢步驟**之後**才參與反應。

**命名**：S<sub>N</sub>1 ＝ **S**ubstitution, **N**ucleophilic, **1** ＝ **unimolecular（單分子）**——速率決定步驟的過渡態中**只有一個分子**。

## 2. S<sub>N</sub>1 的機構與能量圖（6-13）

### 2.1 第三丁基溴在甲醇中的 S<sub>N</sub>1 機構

```
Step 1：形成碳陽離子 (carbocation)（速率決定步驟，慢）
   (CH₃)₃C–Br   ⇌   (CH₃)₃C⁺  +  Br⁻

Step 2：親核基攻擊碳陽離子（快）
   (CH₃)₃C⁺  +  :Ö(H)–CH₃   ⇌   (CH₃)₃C–O⁺(H)–CH₃

Step 3：失去質子給溶劑（快）
   (CH₃)₃C–O⁺(H)–CH₃  +  CH₃–ÖH   ⇌   (CH₃)₃C–O–CH₃  +  CH₃–OH₂⁺
```

- **Step 1**：C–Br 鍵**異裂 (heterolytic cleavage)**，Br 帶走兩個電子 → 碳陽離子＋溴離子。這是高度吸熱、活化能最大的一步 → **速率決定步驟 (rate-limiting step)**。
- **Step 2**：碳陽離子是**非常強的親電子基**，連弱親核基都能迅速與之反應。
- **Step 3**：若親核基是中性的水或醇，Step 2 生成帶正電的產物，必須再失去一個質子 (proton) 才得到中性產物。

> **解題提示（課本 Problem-Solving Hint）**
> - **絕對不要畫質子「憑空掉下來」**（–H⁺ 飛走），一定要畫出一個鹼（通常是溶劑分子）把質子拔走。
> - 在 HBr、HCl 等強酸存在下，為什麼拔質子的是溶劑而不是 Br⁻？因為溶劑的鹼性遠大於鹵離子：HI（pK<sub>a</sub> −10）、HBr（−9）、HCl（−7）都比 CH₃OH₂⁺（−2.5）、CH₃CH₂OH₂⁺（−2.4）、H₃O⁺（−1.7）強得多，所以平衡 ROH + HX ⇌ ROH₂⁺ + X⁻ 極度偏右。寫「HBr 的水溶液」時，實際上存在的是 H₃O⁺ 與 Br⁻。

### 2.2 為什麼 S<sub>N</sub>1 通常搭配弱親核基？

- 親核基不影響速率，所以「弱」不是缺點。
- 若使用強親核基，它會**直接攻擊受質**，反應改走二級的路徑（S<sub>N</sub>2，或第 7 章的 E2）。
- 因此 S<sub>N</sub>1 的典型條件是：**弱親核基＋（通常同時是）極性質子性溶劑**，也就是溶劑解。

### 2.3 關鍵機構 6-4：S<sub>N</sub>1 反應 (Key Mechanism 6-4)

**兩步驟機構**：慢的離子化 (ionization) 產生碳陽離子，再與（通常為弱的）親核基快速反應。
**反應性：3° > 2° > 1°**

```
Step 1：  R–X   ⇌   R⁺  +  X⁻          （速率決定步驟）
Step 2：  R⁺  +  Nuc:⁻   →   R–Nuc     （快）
（若親核基為水或醇，還需 Step 3：去質子化）
```

**範例：1-碘-1-甲基環己烷 (1-iodo-1-methylcyclohexane) 在甲醇中的溶劑解**

```
Step 1：1-碘-1-甲基環己烷  ⇌  1-甲基環己基陽離子（3°）+ I⁻
Step 2：碳陽離子 + CH₃OH  →  環上 C1 接 –O⁺(H)CH₃
Step 3：–O⁺(H)CH₃ + CH₃OH  →  1-甲氧基-1-甲基環己烷 (1-methoxy-1-methylcyclohexane) + CH₃OH₂⁺
```

### 2.4 進階：由機構推導一級速率定律

設機構為：

$$\text{R–X} \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} \text{R}^+ + \text{X}^- \qquad \text{R}^+ + \text{Nuc} \xrightarrow{k_2} \text{R–Nuc}$$

碳陽離子極不穩定，濃度極低且幾乎不隨時間改變，可使用**穩定態近似 (steady-state approximation)**：

$$\frac{d[\text{R}^+]}{dt} = k_1[\text{RX}] - k_{-1}[\text{R}^+][\text{X}^-] - k_2[\text{R}^+][\text{Nuc}] = 0$$

$$[\text{R}^+] = \frac{k_1[\text{RX}]}{k_{-1}[\text{X}^-] + k_2[\text{Nuc}]}$$

產物生成速率：

$$\text{rate} = k_2[\text{R}^+][\text{Nuc}] = \frac{k_1 k_2[\text{RX}][\text{Nuc}]}{k_{-1}[\text{X}^-] + k_2[\text{Nuc}]}$$

當親核基大量存在（例如它就是溶劑），碳陽離子被親核基捕捉的速率遠大於與 X⁻ 重新結合的速率，即 $k_2[\text{Nuc}] \gg k_{-1}[\text{X}^-]$：

$$\boxed{\text{rate} \approx k_1[\text{RX}]}$$

→ 速率只由第一步（離子化）決定，與親核基無關。這就是「速率決定步驟」的數學意義。

> 這個推導也說明了：若額外加入大量 X⁻（例如加 NaBr），$k_{-1}[\text{X}^-]$ 項變大，碳陽離子更容易「回到」反應物，S<sub>N</sub>1 速率會下降。這稱為**同離子效應 (common-ion effect)**（課本外補充，可作為延伸理解）。

### 2.5 反應能量圖：S<sub>N</sub>1 vs. S<sub>N</sub>2

```
        S_N1                                        S_N2
能量                                       能量
 ↑      ‡1（速率決定）                       ↑            ‡ [Nuc···C···X]⁻
 │      ╱╲        ‡2                        │           ╱╲
 │     ╱  ╲      ╱╲                         │          ╱  ╲
 │    ╱    ╲____╱  ╲                        │         ╱    ╲
 │   ╱   R⁺ + X⁻    ╲                       │        ╱      ╲
 │  ╱   + Nuc:⁻      ╲                      │ R–X + Nuc:⁻    ╲
 │ R–X + Nuc:⁻        ╲                     │ ──────          ╲
 │ ──────              ╲______               │                  ╲______
 │                   R–Nuc + X⁻             │                R–Nuc + X⁻
 └──────────────────────────→               └──────────────────────────→
```

| | S<sub>N</sub>1 | S<sub>N</sub>2 |
|---|---|---|
| 過渡態數目 | 2 個（‡1、‡2） | 1 個 |
| 中間物 | **碳陽離子**（能量圖上的相對極小值） | 無 |
| 速率決定步驟 | 第一步（離子化），強烈吸熱、E<sub>a</sub> 大 | 唯一一步 |
| 第二步 | 親核基攻擊，強烈放熱、‡2 能量較低 | — |

**結論**：凡是**有利於碳陽離子生成**（降低 ‡1）的因素都會加速 S<sub>N</sub>1；**阻礙碳陽離子生成**的因素則會減慢 S<sub>N</sub>1。後面三節（受質、離去基、溶劑）都是這個原則的應用。

### 例題 1（課本 Problem 6-22）

提出 3-溴-2,3-二甲基戊烷 (3-bromo-2,3-dimethylpentane) 在乙醇中溶劑解的 S<sub>N</sub>1 機構。

**詳解**

受質：CH₃–CH(CH₃)–C(Br)(CH₃)–CH₂CH₃，Br 接在**三級碳** C3 上。

```
Step 1（慢）：離子化
CH₃CH(CH₃)–C(Br)(CH₃)–CH₂CH₃   ⇌   CH₃CH(CH₃)–C⁺(CH₃)–CH₂CH₃  +  Br⁻
                                       3° 碳陽離子

Step 2（快）：乙醇攻擊
CH₃CH(CH₃)–C⁺(CH₃)–CH₂CH₃  +  CH₃CH₂–ÖH   →   CH₃CH(CH₃)–C(CH₃)(CH₂CH₃)–O⁺(H)CH₂CH₃

Step 3（快）：另一分子乙醇去質子化
… –O⁺(H)CH₂CH₃  +  CH₃CH₂OH   →   … –O–CH₂CH₃  +  CH₃CH₂OH₂⁺
```

產物：**3-乙氧基-2,3-二甲基戊烷 (3-ethoxy-2,3-dimethylpentane)**

> 此碳陽離子已經是三級，相鄰 C2 上的氫若轉移過來，只會得到另一個三級碳陽離子（穩定度相近），沒有明顯驅動力，所以不考慮重排。

## 3. 影響 S<sub>N</sub>1 的因素（一）：受質結構與碳陽離子穩定度（6-13A）

### 3.1 為什麼速率取決於碳陽離子穩定度？——哈蒙德假說

- 速率決定步驟（離子化）是**強烈吸熱**的。
- 依**哈蒙德假說 (Hammond's postulate)**：吸熱步驟的過渡態在結構與能量上**接近產物**（此處即碳陽離子）。
- 所以凡是使碳陽離子更穩定的因素，也同樣穩定 ‡1、降低活化能 → S<sub>N</sub>1 更快。

### 3.2 烷基如何穩定碳陽離子

碳陽離子的帶正電碳為 **sp² 混成、平面三角形 (trigonal planar)**，有一個**空的 p 軌域 (vacant p orbital)**。

**(1) 誘導效應 (inductive effect)**：烷基透過 σ 鍵把電子密度推向帶正電的碳，分散正電荷。

**(2) 超共軛 (hyperconjugation)**：相鄰 C–H（或 C–C）**σ 鍵**的電子雲，與碳陽離子的**空 p 軌域**部分重疊，把電子密度「分享」給缺電子的碳，使正電荷部分分散到相鄰的氫上。

```
            H
            |  ← 這根 C–H σ 鍵與空 p 軌域側向重疊
       H –– C –– C⁺        （空 p 軌域垂直於平面）
            |     \
            H      CH₃
```

相鄰的烷基越多，可參與超共軛的 σ 鍵越多 → 越穩定。

$$\text{碳陽離子穩定度：} 3° > 2° > 1° > \text{CH}_3^+$$

$$\boxed{\text{S}_\text{N}\text{1 反應性：} 3° > 2° > 1° > \text{CH}_3\text{X}}$$

> **與 S<sub>N</sub>2 的順序正好相反！**
> - S<sub>N</sub>2：烷基**阻礙**強親核基的背面攻擊 → CH₃X > 1° > 2° ≫ 3°
> - S<sub>N</sub>1：烷基**穩定**碳陽離子中間物 → 3° > 2° > 1° > CH₃X
> - 簡單的一級與甲基碳陽離子在溶液中通常**不會生成**。

### 3.3 共振穩定化 (resonance stabilization)

**烯丙基溴 (allyl bromide)**：雖為一級鹵化物，S<sub>N</sub>1 速率卻與二級鹵化物相當。

```
CH₂=CH–CH₂–Br   ⇌   [ CH₂=CH–CH₂⁺   ←→   ⁺CH₂–CH=CH₂ ]  +  Br⁻
                       共振穩定的烯丙基陽離子 (allylic cation)
                       正電荷平均分布在兩端的碳上
```

親核基可攻擊任一端的碳。

**苯甲基 (benzylic) 與環狀烯丙基**（Problem 6-24）：苯甲基溴（一級）與 3-溴環己烯（二級）的 S<sub>N</sub>1 速率都與**三級**鹵化物相當。

```
苯甲基陽離子 (benzyl cation)：正電荷由 CH₂ 經共振分散到苯環的
    鄰位 (ortho) ×2 與對位 (para) 碳上 → 共 4 個共振式

環己-2-烯基陽離子 (cyclohex-2-enyl cation)：正電荷分散在 C1 與 C3 兩個二級碳上
```

**綜合穩定度順序（實用版）**

$$\text{苯甲基} \approx \text{3°} \approx \text{二級烯丙基} \;>\; \text{2°} \approx \text{一級烯丙基} \;>\; 1° \;>\; \text{CH}_3^+$$

實際上，**只有苯甲基、三級、烯丙基與二級鹵化物**會進行 S<sub>N</sub>1；甲基與一級鹵化物太難形成碳陽離子，幾乎一律走 S<sub>N</sub>2。

### 3.4 乙烯基與芳基鹵化物：兩種機構都不行

| 機構 | 為何不行 |
|---|---|
| S<sub>N</sub>1 | 需形成**乙烯基陽離子 (vinyl cation)** 或**芳基陽離子 (aryl cation)**，兩者都比一般烷基碳陽離子不穩定得多 |
| S<sub>N</sub>2 | 需從背面攻擊，但背面被雙鍵或芳香環的 π 電子擋住（電子互斥），無法接近 |

### 例題 3（課本 Problem 6-24）

3-溴環己烯 (3-bromocyclohexene) 為二級、苯甲基溴 (benzyl bromide) 為一級，但兩者 S<sub>N</sub>1 速率都與多數三級鹵化物相當。用共振式解釋。

**詳解**

**3-溴環己烯**：離子化得到環己-2-烯基陽離子，其正電荷經共振分散在兩個二級碳上：

```
[ C1=C2–C3⁺   ←→   ⁺C1–C2=C3 ]     （兩個共振式等價）
```

正電荷不再集中於單一碳，穩定度與三級碳陽離子相當。

**苯甲基溴**：離子化得到苯甲基陽離子：

```
C₆H₅–CH₂⁺   ←→   CH₂ 與環形成雙鍵，正電荷在鄰位碳（2 種）  ←→   正電荷在對位碳
```

共 4 個共振式（CH₂⁺、兩個鄰位、一個對位），正電荷高度分散 → 穩定度與三級相當。

**結論**：雖然頭碳的級數只有 1° 或 2°，但**共振提供的穩定化遠超過烷基的超共軛**，使離子化的活化能大幅降低。

## 4. 影響 S<sub>N</sub>1 的因素（二）：離去基與溶劑（6-13B、6-13C）

### 4.1 離去基效應 (leaving-group effects)

- 在速率決定步驟中，離去基正在斷開與碳的鍵、同時逐漸帶上負電荷：

```
R₃C–X   →   [ R₃C^δ+ ······ X^δ− ]‡   →   R₃C⁺  +  X⁻
              部分鍵結仍然存在
```

- 好的離去基需要：
  1. **弱鹼**：帶著電子對離開後要很穩定。
  2. **可極化**：在過渡態中仍能與正在形成的碳陽離子保持部分鍵結，穩定 ‡1。
- **S<sub>N</sub>1 與 S<sub>N</sub>2 對離去基的要求相同**，表 6-4 的離去基兩者通用。

**離去能力順序（FOCUS 表）**

$$\text{磺酸根 (sulfonate)} > \text{I}^- > \text{Br}^- \approx \text{H}_2\text{O} > \text{Cl}^- \gg \text{F}^-$$

> **強鹼（HO⁻、RO⁻、H⁻、R₂N⁻、R₃C⁻）在 S<sub>N</sub>1 中永遠不會是離去基。**

### 4.2 溶劑效應 (solvent effects)

速率決定步驟由**中性分子生成兩個離子**，而且電荷分離在過渡態中就已開始 → 需要能**穩定離子的極性溶劑**。

- **極性溶劑**：以溶劑偶極與離子電荷作用（溶劑化）。
- **質子性溶劑**（水、醇）更有效：
  - 陰離子（X⁻）與溶劑的 –OH 氫原子形成**氫鍵**。
  - 陽離子（R⁺）與溶劑 –OH 氧原子的**非鍵結電子**錯合。

這與食鹽溶於水時的離子溶劑化非常類似。

**表 6-6：介電常數 (dielectric constant, ε) 與第三丁基氯的相對離子化速率**

| 溶劑 | ε | 相對速率 |
|---|---|---|
| 水 (water) | 78 | 8000 |
| 甲醇 (methanol) | 33 | 1000 |
| 乙醇 (ethanol) | 24 | 200 |
| 丙酮 (acetone) | 21 | 1 |
| 乙醚 (diethyl ether) | 4.3 | 0.001 |
| 己烷 (hexane) | 2.0 | < 0.0001 |

- **介電常數**是溶劑極性的指標，代表溶劑「屏蔽並穩定離子電荷」的能力。
- 水與丙酮的 ε 雖然沒有差很多（78 vs. 21），但速率差了 8000 倍——因為水是**質子性**溶劑，能以氫鍵溶劑化 X⁻。
- 實務上：多數鹵烷不溶於水，常用**丙酮–水、醇–水**等高極性混合溶劑；也常加熱至**回流 (reflux)** 提供離子化所需的能量。

> **與 Part 2 習題 6-55 的原則一致**：反應物（中性 R–X）→ 過渡態（電荷大量產生）→ 極性溶劑對過渡態的穩定遠大於對反應物 → 大幅加速。

### 4.3 FOCUS：影響 S<sub>N</sub>1 速率的因素

| 因素 | 有利於 S<sub>N</sub>1 |
|---|---|
| 1. 結構 | 能穩定碳陽離子：**取代程度高**、**有共振**（苯甲基 ≈ 3° ≈ 烯丙基 > 2°） |
| 2. 離去基 | 可極化的大原子、弱鹼（磺酸根 > I⁻ > Br⁻ ≈ H₂O > Cl⁻） |
| 3. 溶劑 | 極性，尤其是**質子性**溶劑（水、醇、羧酸） |
| 親核基 | **不影響速率**（不在速率決定步驟中） |

## 5. S<sub>N</sub>1 反應的立體化學：外消旋化（6-14）

### 5.1 平面碳陽離子可從兩面攻擊

- S<sub>N</sub>2 是**立體專一性**的（背面攻擊、完全構形反轉）。
- S<sub>N</sub>1 **不是**立體專一性的：碳陽離子為 sp² **平面**結構，且通常是**非手性 (achiral)**，親核基可以從**上下兩面**攻擊。

**範例（圖 6-11）：(S)-3-溴-2,3-二甲基戊烷在乙醇中的 S<sub>N</sub>1**

```
               (S)-3-溴-2,3-二甲基戊烷
                        │ –Br⁻
                        ↓
              平面、非手性的碳陽離子
           ↙ 從上方（原離去基那一側）       ↘ 從下方（背面）
  EtOH 攻擊 → –H⁺                       EtOH 攻擊 → –H⁺
  (S)-3-乙氧基-2,3-二甲基戊烷            (R)-3-乙氧基-2,3-二甲基戊烷
  構形保持 (retention of configuration)  構形反轉 (inversion of configuration)
```

### 5.2 名詞

| 名詞 | 定義 |
|---|---|
| **構形保持 (retention of configuration)** | 親核基佔據原本離去基的位置（從**正面 front side** 攻擊） |
| **構形反轉 (inversion of configuration)** | 親核基佔據離去基的相反位置（從**背面 back side** 攻擊） |
| **外消旋化 (racemization)** | 同時生成兩種鏡像異構物的過程（不論兩者是否等量）；產物為外消旋混合物 (racemic mixture)，或至少光學純度低於起始物 |

**外消旋化 ＝ 構形保持 ＋ 構形反轉 的組合。**

### 5.3 為什麼通常「反轉略多於保持」？

- 離去基剛離開時，仍停留在碳陽離子的**正面附近**，部分遮蔽了正面。
- 背面沒有阻擋 → 親核基較容易從背面進入。
- 結果：產物很少是完全的 50:50，通常**反轉的比例稍高**。

### 5.4 環狀範例：以氘標記區分兩面（圖 6-12）

**順-1-溴-3-氘環戊烷 (*cis*-1-bromo-3-deuteriocyclopentane) 在甲醇中的 S<sub>N</sub>1**

- **氘 (deuterium, D)** 的大小、形狀、反應性與 H 相同，只是用來**標記**環的某一面。
- 反應物中 Br 與 D 為順式。

| 攻擊方向 | 產物（OCH₃ 與 D 的關係） | 意義 | 比例 |
|---|---|---|---|
| 從上方（Br 離開的同一側） | **順式 (cis)** | 構形保持 | 40% |
| 從下方（背面） | **反式 (trans)** | 構形反轉 | 60% |

反式略多，因為離去的 Br⁻ 部分擋住了正面。

### 5.5 機構 6-5：S<sub>N</sub>1 的外消旋化 (Mechanism 6-5)

```
Step 1：四面體碳離子化 → 平面碳陽離子 + X⁻
Step 2：Nuc:⁻ 從上方攻擊 → 構形保持
        Nuc:⁻ 從下方攻擊 → 構形反轉
```

若該碳是**立體中心 (stereogenic center)**，兩種產物即為不同的立體異構物。

## 6. S<sub>N</sub>1 反應中的重排（6-15）

### 6.1 什麼是重排？

- **重排 (rearrangement)**：分子中鍵結順序改變的反應。碳陽離子常經由重排轉變為**更穩定**的碳陽離子。
- 重排可發生在碳陽離子**生成之後**，也可能在離去基**正在離開的同時**發生。
- **S<sub>N</sub>2 不會重排**：一步完成，沒有碳陽離子，也沒有重排的機會。

### 6.2 氫負離子轉移 (hydride shift, ~H)

**範例：2-溴-3-甲基丁烷 (2-bromo-3-methylbutane) 在乙醇中加熱**

```
CH₃–CHBr–CH(CH₃)–CH₃   --CH₃CH₂OH, 加熱-->
     2-乙氧基-3-甲基丁烷 (2-ethoxy-3-methylbutane)    （未重排）
  +  2-乙氧基-2-甲基丁烷 (2-ethoxy-2-methylbutane)    （重排）
  +  HBr
```

**機構 6-6：S<sub>N</sub>1 中的氫負離子轉移**

```
Step 1：離子化
   CH₃–CH(Br)–CH(CH₃)–CH₃   ⇌   CH₃–CH⁺–CH(CH₃)–CH₃  +  Br⁻
                                   2° 碳陽離子（C2）

Step 2：氫負離子轉移（C3 上的 H 帶著鍵結電子對移到 C2）
   CH₃–CH⁺–C(H)(CH₃)–CH₃   --~H-->   CH₃–CH₂–C⁺(CH₃)–CH₃
          2° 碳陽離子                    3° 碳陽離子（C3）

Step 3：溶劑（弱親核基）攻擊重排後的碳陽離子
   CH₃CH₂–C⁺(CH₃)₂  +  CH₃CH₂ÖH   →   CH₃CH₂–C(CH₃)₂–O⁺(H)CH₂CH₃

Step 4：去質子化
   … –O⁺(H)CH₂CH₃  +  CH₃CH₂OH   →   CH₃CH₂–C(CH₃)₂–OCH₂CH₃  +  CH₃CH₂OH₂⁺
                                       2-乙氧基-2-甲基丁烷（重排產物）
```

**三維圖像**：C3 的 C–H σ 鍵與 C2 的空 p 軌域平行重疊，H 帶著鍵結電子對「滑」到 C2，C3 留下空 p 軌域成為新的碳陽離子中心。
（形式上是「氫負離子 H:⁻」移動，但**並沒有真正游離的氫負離子**；H 始終與分子保持鍵結。）

### 例題 4（課本 Problem 6-25）

寫出由 2-溴-3-甲基丁烷生成未重排產物 2-乙氧基-3-甲基丁烷的 S<sub>N</sub>1 機構。

**詳解**

```
Step 1：CH₃–CH(Br)–CH(CH₃)₂   ⇌   CH₃–CH⁺–CH(CH₃)₂  +  Br⁻      （2° 碳陽離子）

Step 2：在重排發生之前，乙醇即攻擊 C2
        CH₃–CH⁺–CH(CH₃)₂  +  CH₃CH₂ÖH   →   CH₃–CH(O⁺(H)CH₂CH₃)–CH(CH₃)₂

Step 3：乙醇去質子化
        → CH₃–CH(OCH₂CH₃)–CH(CH₃)₂  +  CH₃CH₂OH₂⁺
          2-乙氧基-3-甲基丁烷
```

> 2° 碳陽離子生成後，**被溶劑捕捉**與**重排**兩者互相競爭，因此兩種產物都會出現。

### 6.3 甲基轉移 (methyl shift, ~CH₃) 與烷基轉移 (alkyl shift, ~R)

**範例：新戊基溴 (neopentyl bromide) 在乙醇中煮沸——只得到重排產物**

- 若不重排，離子化會得到極不穩定的**一級**碳陽離子 (CH₃)₃C–CH₂⁺ → 實際上不會生成。
- 實際情形：**甲基轉移在溴離子離開的同時發生**（協同），直接得到三級碳陽離子。

**機構 6-7：S<sub>N</sub>1 中的甲基轉移**

```
Step 1：離子化伴隨甲基轉移
   (CH₃)₃C–CH₂–Br   --~CH₃, –Br⁻-->   (CH₃)₂C⁺–CH₂–CH₃
   （C2 上的一個甲基帶著鍵結電子對移到 C1，同時 C1–Br 斷裂）   3° 碳陽離子

Step 2：乙醇攻擊
   (CH₃)₂C⁺–CH₂CH₃  +  CH₃CH₂ÖH   →   (CH₃)₂C(O⁺(H)CH₂CH₃)–CH₂CH₃

Step 3：去質子化
   → (CH₃)₂C(OCH₂CH₃)–CH₂CH₃  +  CH₃CH₂OH₂⁺
     2-乙氧基-2-甲基丁烷 (2-ethoxy-2-methylbutane)
```

**觀念整理**
- 帶正電的碳缺電子；相鄰碳上的 H 或烷基帶著**電子對**移過來 → 正電荷移到相鄰碳。
- 「**初生的一級碳陽離子 (incipient 1° carbocation)**」：一級鹵化物若離子化，通常是在離去的**同時**重排，不會真的生成一級碳陽離子。

### 6.4 重排的判斷原則

> **解題提示（課本 Problem-Solving Hints 整理）**
> 1. 只要**氫負離子轉移或烷基轉移能形成更穩定的碳陽離子**，就要預期會重排。
> 2. 常見方向：**2° → 3°**、**2° → 共振穩定**、**3° → 共振穩定**、**（初生）1° → 3° 或 2°**。
> 3. 碳陽離子**通常只重排一次**。
> 4. 只轉移**相鄰碳**（1,2-轉移 1,2-shift）上的 H 或烷基。
> 5. **甲基與一級鹵化物很少在溶液中離子化**；若一級鹵化物離子化，幾乎一定伴隨重排。
> 6. **H 與 CH₃ 都可以轉移時**，選擇能得到較穩定碳陽離子的那一個；若都得到同級碳陽離子，通常 H 較容易轉移。

**判斷 SOP**

```
① 寫出離去基離開後的碳陽離子（若為 1°，直接考慮離子化時重排）
② 檢查「相鄰碳」上有哪些 H、CH₃、R 或環鍵可以轉移
③ 轉移後是否得到更穩定的碳陽離子？
     是 → 預期有重排產物（2° 起始時通常兩種產物並存）
     否 → 不重排
④ 溶劑攻擊各個碳陽離子 → 去質子化 → 寫出所有產物
```

## 8. 易錯觀念

1. **S<sub>N</sub>1 的「1」指單分子**（速率決定步驟只有一個分子），不是「一個步驟」。
2. **S<sub>N</sub>1 速率與親核基無關**：加倍親核基濃度、換成更強的親核基，速率都不變（但換成強親核基可能改走其他機構）。
3. **碳陽離子是中間物，不是過渡態**；它在能量圖上位於兩個高峰之間的低谷。
4. **S<sub>N</sub>1 與 S<sub>N</sub>2 的受質順序相反**。
5. **烯丙基溴、苯甲基溴雖為一級，卻可進行 S<sub>N</sub>1**（共振穩定）；但它們同樣是很好的 S<sub>N</sub>2 受質（無障礙）。
6. **乙烯基、芳基鹵化物兩種取代機構都不進行。**
7. **外消旋化不一定是 50:50**；通常構形反轉略多。
8. **去質子化要畫出鹼（溶劑）**，不要讓 H⁺ 憑空消失。
9. **2° 碳陽離子可重排成 3° 時，重排與未重排產物通常同時出現**；**一級受質（如新戊基）則只得重排產物**。
10. **重排只發生在相鄰碳**，且通常只發生一次。

> 提示：Cl 接在什麼混成的碳上？

### 簡答

1. rate = k[(CH₃)₃CBr]。(a) **不變**（親核基為零級）；(b) **加倍**。
2. **2-溴-2-甲基丙烷 ≈ 苯甲基溴 > 2-溴丙烷 > 1-溴丙烷**；**溴苯不反應**（芳基陽離子極不穩定）。實務上 1-溴丙烷在此條件下幾乎不進行 S<sub>N</sub>1。
3. 產物為 **3-甲基己-3-醇 (3-methylhexan-3-ol)**。三級平面碳陽離子可從兩面被水攻擊 → (R) 與 (S) 兩種都生成（外消旋化），通常 (R)（構形反轉）略多。
4. 先生成 2° 碳陽離子（C2）；C3 上的 H 經氫負離子轉移 → 3° 碳陽離子（C3）。產物：**3-甲基丁-2-醇 (3-methylbutan-2-ol)**（未重排）與 **2-甲基丁-2-醇 (2-methylbutan-2-ol)**（重排）。
5. **水 > 乙醇 > 丙酮 > 己烷**（ε 分別為 78、24、21、2.0；水與乙醇為質子性溶劑）。
6. Ag⁺ 與 Br 結合，以 AgBr 沉澱形式強力拉走溴（強烈放熱，推動離子化）；離子化時**同時發生甲基轉移**，不經過一級碳陽離子，直接得到 3° 碳陽離子 (CH₃)₂C⁺CH₂CH₃ → 產物為 **2-乙氧基-2-甲基丁烷**（只有重排產物）。
7. 碳陽離子在 C1；甲醇從兩側攻擊 → **順-** 與 **反-1-甲氧基-4-第三丁基環己烷**。C4 的構形不受影響。（離子化後得到同一個平面碳陽離子；本題的重點在於產物同時有順反兩種。）
8. Cl 接在 **sp² 雙鍵碳**上（乙烯基鹵化物）：S<sub>N</sub>1 需生成不穩定的乙烯基陽離子；S<sub>N</sub>2 的背面攻擊被 π 電子阻擋。

### 課內習題 6-26（氫負離子轉移、甲基轉移與擴環——重排綜合題）

**題目** 對下列各溶劑解反應，提出包含氫負離子轉移或烷基轉移的機構，並說明重排如何形成較穩定的中間物。

**(a)** CH₃–C(CH₃)₂–CHI–CH₃ --CH₃OH, 加熱--> CH₃–C(CH₃)₂–CH(OCH₃)–CH₃ ＋ CH₃–C(OCH₃)(CH₃)–CH(CH₃)–CH₃

**詳解**

受質：3-碘-2,2-二甲基丁烷 (3-iodo-2,2-dimethylbutane)，I 接在二級碳 C3 上；相鄰 C2 是**四級碳**（帶三個甲基，沒有 H）。

```
Step 1：離子化
   (CH₃)₃C–CHI–CH₃   ⇌   (CH₃)₃C–CH⁺–CH₃  +  I⁻          （2° 碳陽離子，C3）

路徑 A（未重排）：甲醇直接攻擊 C3 → 去質子化
   → (CH₃)₃C–CH(OCH₃)–CH₃                3-甲氧基-2,2-二甲基丁烷 (3-methoxy-2,2-dimethylbutane)

路徑 B（甲基轉移）：C2 上的一個甲基帶著電子對移到 C3
   (CH₃)₃C–CH⁺–CH₃   --~CH₃-->   (CH₃)₂C⁺–CH(CH₃)–CH₃      （3° 碳陽離子，C2）
   → 甲醇攻擊 C2 → 去質子化
   → (CH₃)₂C(OCH₃)–CH(CH₃)₂              2-甲氧基-2,3-二甲基丁烷 (2-methoxy-2,3-dimethylbutane)
```

**為什麼是甲基轉移而不是氫負離子轉移？** C2 是四級碳，上面**沒有氫**可以轉移，只能轉移甲基。轉移後 2° → 3°，碳陽離子穩定化。

---

**(b)** 1-氯-2-甲基環己烷 (1-chloro-2-methylcyclohexane) --CH₃CH₂OH, 加熱--> 1-乙氧基-2-甲基環己烷 ＋ 1-乙氧基-1-甲基環己烷

**詳解**

```
Step 1：離子化 → C1 上的 2° 碳陽離子（C2 帶甲基與一個 H）

路徑 A（未重排）：乙醇攻擊 C1 → 去質子化
   → 1-乙氧基-2-甲基環己烷 (1-ethoxy-2-methylcyclohexane)（順式與反式混合物）

路徑 B（氫負離子轉移）：C2 上的 H 帶著電子對移到 C1
   C1⁺（2°）  --~H-->  C2⁺（3°，C2 帶甲基且接兩個環碳）
   → 乙醇攻擊 C2 → 去質子化
   → 1-乙氧基-1-甲基環己烷 (1-ethoxy-1-methylcyclohexane)
```

**為什麼是 ~H 而非 ~CH₃？** 若甲基從 C2 轉到 C1，正電荷移到 C2，而 C2 失去甲基後只剩兩個環碳 → 仍是 2°，沒有好處。轉移 H 則讓帶甲基的 C2 成為 3° 碳陽離子。**選擇能得到較穩定碳陽離子的轉移方式。**

---

**(c)** 4-碘環己烯 (4-iodocyclohexene)（依教材圖示判讀）+ CH₃COOH 加熱 → 兩種乙酸環己烯酯 (cyclohexenyl acetate)

**詳解**

受質中 I 接在 C4，**不是**烯丙基位（C4 與雙鍵 C1=C2 之間隔著 C3），所以直接離子化只得到普通的 2° 碳陽離子。

```
Step 1：離子化 → C4 上的 2° 碳陽離子（非共振穩定）

路徑 A（未重排）：乙酸的羰基氧（或羥基氧）攻擊 C4 → 去質子化
   → 乙酸環己-3-烯-1-基酯 (cyclohex-3-en-1-yl acetate)

路徑 B（氫負離子轉移）：C3 上的 H 轉移到 C4
   C4⁺（2°） --~H-->  C3⁺，而 C3 緊鄰 C2=C1 雙鍵 → 烯丙基陽離子！
   [ C1=C2–C3⁺  ←→  ⁺C1–C2=C3 ]（兩共振式因對稱性等價）
   → 乙酸攻擊 C3（或 C1，得到相同產物）→ 去質子化
   → 乙酸環己-2-烯-1-基酯 (cyclohex-2-en-1-yl acetate)
```

**驅動力**：**2° → 共振穩定的烯丙基陽離子**。乙酸是弱親核基，同時也是極性質子性溶劑。

---

**(d)** (碘甲基)環己烷 ((iodomethyl)cyclohexane) --CH₃CH₂OH, 加熱--> 1-乙氧基-1-甲基環己烷 ＋ 乙氧基環庚烷 (ethoxycycloheptane)

**詳解**

受質為**一級**鹵化物，不會生成一級碳陽離子；離子化時**同時**發生轉移（初生的 1° 碳陽離子）。頭碳 CH₂ 的相鄰碳是環上的 C1（帶一個 H，並接兩個環碳）。

```
路徑 A（氫負離子轉移，與離子化協同）：
   環 C1 上的 H 移到 CH₂，I⁻ 同時離開
   → 1-甲基環己基陽離子（3°）
   → 乙醇攻擊、去質子化 → 1-乙氧基-1-甲基環己烷

路徑 B（烷基轉移：環上的 C–C 鍵遷移 → 擴環 ring expansion）：
   環 C1–C2 鍵的電子對移向 CH₂（C2 由接在 C1 改為接在 CH₂ 上），I⁻ 同時離開
   → 環由六員環擴大為七員環，正電荷落在原本的 C1（現為環庚基上的 2° 碳）
   → 環庚基陽離子 (cycloheptyl cation)（2°）
   → 乙醇攻擊、去質子化 → 乙氧基環庚烷
```

**討論**
- 兩條路徑都避開了極不穩定的一級碳陽離子（初生 1° → 3° 或 2°）。
- 擴環是一種**烷基轉移**：遷移的「烷基」是環本身的一根 C–C 鍵。
- 擴環在六員環 → 七員環時沒有減少環張力的好處，所以主要靠「避免 1° 碳陽離子」驅動；若是由**四員環或五員環擴大**，減少**環張力 (ring strain)** 會成為額外的強大驅動力（見下題 6-29(b)）。

### 課內習題 6-29（硝酸銀促進的離子化與重排）

**題目** 加入硝酸銀 (silver nitrate, AgNO₃) 可迫使不易離子化的受質發生一級反應：Ag⁺ 與鹵素結合生成鹵化銀 (silver halide) 沉澱（強烈放熱），產生烷基陽離子。
R–X + Ag⁺ → R⁺ + AgX↓
寫出下列銀離子促進重排的機構。

**(a)** (CH₃)₃C–CH₂–I（新戊基碘 neopentyl iodide）--AgNO₃, H₂O--> (CH₃)₂C(OH)–CH₂CH₃

**詳解**

```
Step 1：Ag⁺ 與 I 的孤對電子配位，C–I 鍵被強力拉長
   (CH₃)₃C–CH₂–I  +  Ag⁺   →   (CH₃)₃C–CH₂–I⁺–Ag

Step 2：甲基轉移與 AgI 離去協同發生（避免 1° 碳陽離子）
   (CH₃)₃C–CH₂–I⁺–Ag   --~CH₃-->   (CH₃)₂C⁺–CH₂–CH₃  +  AgI↓
                                    3° 碳陽離子（第三戊基陽離子 tert-pentyl cation）

Step 3：水攻擊
   (CH₃)₂C⁺–CH₂CH₃  +  H₂O   →   (CH₃)₂C(O⁺H₂)–CH₂CH₃

Step 4：另一分子水去質子化
   (CH₃)₂C(O⁺H₂)–CH₂CH₃  +  H₂O   →   (CH₃)₂C(OH)–CH₂CH₃  +  H₃O⁺
                                       2-甲基丁-2-醇 (2-methylbutan-2-ol)
```

**重點**：AgI 的生成高度放熱且以沉澱離開，提供了離子化的驅動力；但即使有 Ag⁺ 幫忙，一級碳陽離子也不會真正生成——**重排與離子化同時發生**。

**(b)** 環上 –CH₂I 經 AgNO₃（H₂O／乙醇）轉為擴大一個碳的環醇（依教材圖示判讀為**擴環**反應；以下以 (碘甲基)環丁烷 (iodomethyl)cyclobutane 為例說明，若原題為五員環，機構完全相同，產物為環己醇）

**詳解**

```
Step 1：Ag⁺ 與 I 配位

Step 2：擴環（烷基轉移）與 AgI 離去協同
   環 C1–C2 鍵的電子對移向 CH₂，C2 改接到 CH₂ 上
   四員環 → 五員環，正電荷落在原 C1 → 環戊基陽離子 (cyclopentyl cation)（2°）

Step 3：水攻擊 → Step 4：去質子化
   → 環戊醇 (cyclopentanol)
```

**為什麼不是氫負離子轉移得到 3° 的 1-甲基環丁基陽離子？**
擴環同時達成兩件事：(1) 避免初生的一級碳陽離子；(2) **大幅減少環張力**——環丁烷的環張力約 110 kJ/mol，環戊烷只有約 26 kJ/mol（四員環 → 五員環）。這個額外的能量釋放足以彌補「得到 2° 而非 3°」的差距，因此擴環產物為主。

> **觀念**：判斷重排時，「碳陽離子級數」不是唯一考量；**環張力的釋放**也是重要的驅動力。

### 章末習題 6-41（烯丙基鹵化物的 S<sub>N</sub>1）

**題目** 烯丙基鹵化物 (allylic halide) 的結構為 C=C–C–X。
(a) 說明烯丙基鹵化物的一級離子化如何產生共振穩定的陽離子。
(b) 畫出各烯丙基鹵化物離子化後陽離子的共振式。
(c) 寫出這些鹵化物在乙醇中進行 S<sub>N</sub>1 溶劑解的產物。

（原題 (b)(c) 的四個結構在 PDF 中無法清楚判讀，以下以三個代表性的烯丙基鹵化物示範同一解法。）

**詳解**

**(a) 一般原理**

```
C=C–C–X   ⇌   [ C=C–C⁺   ←→   ⁺C–C=C ]  +  X⁻
```

- 離子化後，帶正電的碳有一個空 p 軌域，與相鄰 C=C 的 π 軌域平行 → 三個 p 軌域形成共軛系統。
- π 電子非定域化 → 正電荷**分布於兩端的碳**（C1 與 C3），中間碳不帶正電。
- 非定域化降低能量 → 碳陽離子穩定 → 離子化的活化能下降 → S<sub>N</sub>1 加速。

**(b)(c) 示範**

| 受質 | 陽離子共振式 | 乙醇溶劑解產物 |
|---|---|---|
| **3-氯丁-1-烯** (3-chlorobut-1-ene) CH₂=CH–CHCl–CH₃ | [CH₂=CH–CH⁺–CH₃ ↔ ⁺CH₂–CH=CH–CH₃]（一端 2°、一端 1°） | 3-乙氧基丁-1-烯 (3-ethoxybut-1-ene) ＋ 1-乙氧基丁-2-烯 (1-ethoxybut-2-ene)（*E*/*Z*） |
| **3-溴環己烯** (3-bromocyclohexene) | [C1=C2–C3⁺ ↔ ⁺C1–C2=C3]（兩端等價） | **只有一種**：3-乙氧基環己烯 (3-ethoxycyclohexene)（外消旋） |
| **1-(溴甲基)環己烯** (1-(bromomethyl)cyclohexene) | [環 C1=C2，環外 CH₂⁺ ↔ 環外 CH₂=C1，C2⁺]（一端 1°、一端 2°） | 1-(乙氧基甲基)環己烯 (1-(ethoxymethyl)cyclohexene) ＋ 2-乙氧基-1-亞甲基環己烷 (2-ethoxy-1-methylidenecyclohexane) |

**解題要點**
1. 正電荷出現在哪幾個碳，乙醇就可能攻擊哪幾個碳。
2. **檢查對稱性**：兩端等價時只有一種產物（3-溴環己烯）。
3. 這與 Part 1 的烯丙基溴化完全平行：那裡是**烯丙基自由基**，這裡是**烯丙基陽離子**——共振的觀念相同，只是未成對電子換成了正電荷（空軌域）。
4. 3-氯丁-1-烯與 1-氯丁-2-烯會生成**同一個**烯丙基陽離子，因此兩者的溶劑解產物混合物相同。

### 章末習題 6-44（取代反應的立體化學）

**題目** 以立體結構或費雪投影式 (Fischer projection) 畫出下列取代反應的產物。
(a) 2-溴丁烷（費雪投影式）+ NaCN，丙酮
(b) 3-溴-2-甲基戊烷（費雪投影式，Br 所在的 C3 為立體中心）+ NaOH，水／丙酮
(c) 3-溴-2,3-二甲基戊烷（C3 接 CH₃、CH(CH₃)₂、CH₂CH₃、Br）在乙醇中加熱

（本題的費雪投影式構形在 PDF 中無法判讀，以下給出**與起始構形無關的通用解法**；套用到你課本上的圖即可。）

**通用工具：在費雪投影式上畫出 S<sub>N</sub>2 構形反轉的產物**

> 在費雪投影式中，若離去基 X 與 H 位於同一條水平線上：
> **把親核基放在原本 H 的位置、把 H 放在原本 X 的位置**，其餘不動——得到的就是構形反轉的產物。
> （原理：在費雪投影式中交換任意兩個基團，會得到相反構形；「交換 X 與 H 再把 X 換成 Nuc」等同於 Nuc 從背面進入。）

**詳解**

**(a)** 判斷機構：2° 受質＋**強親核基** CN⁻＋**極性非質子性溶劑**丙酮 → **S<sub>N</sub>2**
- 產物：CH₃–CH(CN)–CH₂CH₃，**2-甲基丁腈 (2-methylbutanenitrile)**
- 立體化學：**完全構形反轉**。在費雪投影式中，CN 放在原本 H 的那一側，H 放在原本 Br 的那一側。
- R/S：CN 與 Br 在各自分子中都是第 1 優先，其餘順序（乙基 > 甲基 > H）不變 → 若起始物為 (R)，產物為 (S)；反之亦然。

**(b)** 判斷機構：2° 受質＋**強親核基** HO⁻ → **S<sub>N</sub>2**
- 產物：(CH₃)₂CH–CH(OH)–CH₂CH₃，**2-甲基戊-3-醇 (2-methylpentan-3-ol)**
- 立體化學：只有 C3（反應中心）**構形反轉**；分子中若有其他立體中心則**不受影響**（不參與反應的碳，鍵結不變）。
- （第 7 章會學到此條件下也可能伴隨消去，此處只討論取代產物。）

**(c)** 判斷機構：**3° 受質＋弱親核基（溶劑乙醇）＋加熱** → **S<sub>N</sub>1**
- 產物：**3-乙氧基-2,3-二甲基戊烷 (3-ethoxy-2,3-dimethylpentane)**
- 立體化學：離子化得到平面的 3° 碳陽離子，乙醇從兩面攻擊 → **兩種鏡像異構物皆生成（外消旋化）**，構形反轉者略多。
- 這正是課本圖 6-11 的例子：(S) 起始物 → (S)（保持）＋ (R)（反轉）。
- 畫法：C3 上沒有 H，費雪投影式的「交換 H 與 X」技巧不適用，建議改用**楔形／虛線立體結構 (wedge-and-dash structure)**。畫兩個產物：一個 OCH₂CH₃ 位於原本 Br 的位置（構形保持），另一個 OCH₂CH₃ 位於 Br 的相反方向、其餘三個烷基如雨傘翻面（構形反轉）。在費雪投影式中，也可以直接交換任意兩個基團來表示另一個鏡像異構物。

> **解題 SOP**：先判斷 S<sub>N</sub>1 或 S<sub>N</sub>2（受質級數、親核基強弱、溶劑），再決定立體化學——**S<sub>N</sub>2 → 完全反轉；S<sub>N</sub>1 → 外消旋化**。

### 章末習題 6-49（外消旋化的三種情境）

**題目**
(a) 光學活性的 2-溴丁烷以 KBr 溶液處理會外消旋化。寫出機構。
(b) 光學活性的丁-2-醇以 KOH 溶液處理則**不會**外消旋化。解釋為何不會發生類似 (a) 的反應。
(c) 光學活性的丁-2-醇在稀酸中會外消旋化。提出機構。

**詳解**

**(a) Br⁻ 對 2-溴丁烷的 S<sub>N</sub>2「自我交換」**

```
Br⁻  +  (R)-CH₃CH(Br)CH₂CH₃   →   [Br···C···Br]⁻‡   →   (S)-CH₃CH(Br)CH₂CH₃  +  Br⁻
```

- 親核基與離去基都是 Br⁻；2° 受質、Br⁻ 為不錯的親核基 → S<sub>N</sub>2。
- 每次取代都使構形反轉：(R) → (S)，而 (S) 也可以再被反轉回 (R)。
- 反應不斷可逆地進行；因為兩個鏡像異構物能量相同（平衡常數 K = 1），最終達到 **50:50 的外消旋混合物**，光學活性消失。

**(b) 丁-2-醇 + KOH 不外消旋**

類似 (a) 的反應需要：

```
HO⁻  +  CH₃CH(OH)CH₂CH₃   →   HO–CH(CH₃)CH₂CH₃  +  HO⁻   ✗
```

- 這要求 **HO⁻ 當離去基**，但 HO⁻ 是**強鹼、極差的離去基**（H₂O 的 pK<sub>a</sub> 15.7）。
- 鹼性條件下 –OH 無法被質子化，沒有辦法離開 → 反應不發生 → 不外消旋。
- （HO⁻ 頂多與醇的 O–H 進行酸鹼反應生成烷氧離子，但這不涉及立體中心 C–O 鍵的斷裂，構形不變。）

**(c) 稀酸中的外消旋化**

**Step 1：質子化**——讓離去基由 HO⁻ 變成 H₂O

```
CH₃CH(OH)CH₂CH₃  +  H₃O⁺   ⇌   CH₃CH(O⁺H₂)CH₂CH₃  +  H₂O
```

**Step 2a：S<sub>N</sub>1 路徑**——水離開，生成平面的 2° 碳陽離子

```
CH₃CH(O⁺H₂)CH₂CH₃   ⇌   CH₃–CH⁺–CH₂CH₃  +  H₂O
```

**Step 3a**：水從兩面攻擊平面碳陽離子 → (R) 與 (S) 的質子化醇都生成

**Step 4a**：去質子化 → (R)- 與 (S)-丁-2-醇

**Step 2b（亦可能）：S<sub>N</sub>2 路徑**——水分子從背面攻擊質子化的醇，取代 H₂O，構形反轉；不斷重複即如 (a) 一樣趨向外消旋

**結論**：不論是 S<sub>N</sub>1（平面碳陽離子）或反覆的 S<sub>N</sub>2（重複反轉），結果都是外消旋化。關鍵在於**酸把差的離去基（HO⁻）轉變成好的離去基（H₂O）**。

> **三小題的共同主軸**：外消旋化需要「**立體中心上的鍵能夠斷裂再形成**」，而這取決於**有沒有好的離去基**。

### 章末習題 6-52（為何 S<sub>N</sub>1 通常反轉較多？——離子對的觀念）

**題目** 由於 S<sub>N</sub>1 經過平面碳陽離子，我們可能預期光學活性的起始物會得到完全外消旋的產物。但多數情況下，S<sub>N</sub>1 實際上得到較多的構形反轉產物。一般而言，碳陽離子越穩定，反轉產物的過量越少；極穩定的碳陽離子則得到完全外消旋的產物。解釋這些觀察。

**詳解**

**核心觀念：離子化後，離去基並沒有立刻消失**

離子化後，碳陽離子與離去的陰離子 X⁻ 會經歷幾個階段（課本外的延伸名詞，有助理解）：

```
R–X   →   R⁺ X⁻         →   R⁺ ‖ X⁻                →   R⁺   +   X⁻
          緊密離子對          溶劑分隔離子對                自由離子
          (intimate/contact    (solvent-separated            (free ions)
           ion pair)            ion pair)
          X⁻ 仍緊貼正面         X⁻ 與碳陽離子之間            X⁻ 已擴散離開
                                插入溶劑分子
```

**1. 為什麼反轉多於保持？**
- 剛離子化時，X⁻ 仍停留在碳陽離子的**正面**（原本鍵結的那一側），像盾牌一樣擋住從正面進攻的親核基。
- 背面沒有阻擋 → 溶劑分子較容易從背面攻擊 → **構形反轉較多**。

**2. 為什麼碳陽離子越穩定，反轉過量越少？**
- 碳陽離子越**不穩定** → 反應性越高 → **壽命越短** → 在 X⁻ 還沒離開正面時，就已被（背面的）溶劑捕捉 → 反轉比例高。
- 碳陽離子越**穩定** → 壽命越長 → X⁻ 有足夠時間**擴散離開**，碳陽離子成為「自由」、被溶劑對稱包圍的平面離子 → 兩面被攻擊的機率趨於相等。

**3. 極穩定的碳陽離子為何完全外消旋？**
- 壽命長到幾乎所有的碳陽離子都在 X⁻ 完全離開之後才被捕捉 → 兩面完全對稱 → **50:50**。

**一句話總結**：反轉過量的多寡反映了「**碳陽離子被捕捉時，離去基還有多靠近**」；碳陽離子越穩定、壽命越長，離去基越來得及離開，產物越接近完全外消旋。

> **連結**：這也解釋了課本圖 6-12 中 60:40（反轉：保持）的結果——二級的環戊基陽離子不夠穩定，Br⁻ 離開前就被甲醇捕捉了不少。

### 章末習題 6-54（呋喃甲基氯——會進行 S<sub>N</sub>1 的一級鹵化物）

**題目** 呋喃甲基氯 (furfuryl chloride) 可經 S<sub>N</sub>2 與 S<sub>N</sub>1 兩種機構進行取代。因為它是一級鹵化物，我們預期 S<sub>N</sub>2 而非 S<sub>N</sub>1。畫出下列 S<sub>N</sub>1 反應的機構，並特別注意中間物的結構。為什麼這個一級鹵化物能進行 S<sub>N</sub>1？

```
呋喃甲基氯  +  甲酸鈉 (sodium formate, HCOONa)   --乙醇-->   甲酸呋喃甲酯 (furfuryl formate)  +  NaCl
```

**詳解**

**結構**：呋喃 (furan) 為五員芳香環：O1、C2=C3、C4=C5（O1 接 C2 與 C5）。呋喃甲基氯是 C2 上接 –CH₂Cl。

**Step 1：離子化（速率決定步驟）**

```
呋喃–CH₂–Cl   ⇌   呋喃–CH₂⁺  +  Cl⁻
```

**關鍵：這個「一級」碳陽離子受到高度共振穩定**

```
共振式 ①：  ⁺CH₂–C2（環內 C2=C3、C4=C5）              正電荷在環外 CH₂（1°）
共振式 ②：  CH₂=C2，C3⁺（C4=C5 保留）                  正電荷在 C3
共振式 ③：  CH₂=C2，C3=C4，C5⁺                         正電荷在 C5
共振式 ④：  CH₂=C2，C3=C4，O1⁺=C5                      正電荷在環上的氧（鋞離子 oxonium）
```

推動方式：②由 C2=C3 的 π 電子推向 C2–CH₂；③由 C4=C5 的 π 電子推向 C3–C4；④由 O1 的孤對電子推向 O1–C5。

**共振式 ④ 特別重要**：在這個共振式中，**每一個原子都具有完整的八隅體**（O 有三根鍵和一對孤對電子、所有碳都有四根鍵），沒有任何原子缺電子 → 它是**貢獻很大的共振式**。氧的孤對電子直接提供電子給缺電子中心，使這個碳陽離子的穩定度遠超過一般一級碳陽離子，甚至可與三級碳陽離子相比。

**Step 2：親核基攻擊**

```
呋喃–CH₂⁺  +  ⁻O–C(=O)–H   →   呋喃–CH₂–O–C(=O)–H
                                 甲酸呋喃甲酯
```

- 甲酸根 (formate) 是中等強度的親核基（負電荷被共振分散於兩個氧），且乙醇為極性質子性溶劑 → 有利 S<sub>N</sub>1。
- 雖然正電荷可分布在 C3、C5、O 上，但親核基攻擊**環外 CH₂** 才能保留呋喃環的**芳香性 (aromaticity)**——攻擊環上碳會破壞芳香環，得到能量高得多的產物。因此產物是取代在 CH₂ 上的甲酸呋喃甲酯。

**為什麼一級鹵化物能進行 S<sub>N</sub>1？**
「一級」只描述頭碳上接了幾個碳，並不代表碳陽離子一定不穩定。決定 S<sub>N</sub>1 能否進行的是**碳陽離子的穩定度**；呋喃甲基陽離子透過與芳香環共振、特別是與**環上氧的孤對電子**共振而高度穩定化，所以可以離子化。這和苯甲基溴、烯丙基溴（都是一級卻能進行 S<sub>N</sub>1）是同樣的道理，而且氧的孤對電子提供的穩定化更強。

**同時也能進行 S<sub>N</sub>2**：頭碳是一級、障礙小 → 遇到強親核基時也能進行 S<sub>N</sub>2。苯甲基、烯丙基、呋喃甲基這類受質**兩種機構都很快**，實際走哪一條取決於反應條件（親核基強弱、溶劑）。

> **觀念連結**：「**鄰近原子的孤對電子穩定碳陽離子**」這個觀念在後續章節（例如縮醛 acetal、糖類化學）會一再出現，是有機化學的重要主題。
