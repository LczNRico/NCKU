## 一、觀念說明

### 1-1　為什麼需要 (R)/(S)

- **丙胺酸 (alanine，IUPAC 名 2-胺基丙酸 2-aminopropanoic acid)** 有一個不對稱碳，因此有兩個鏡像異構物 (enantiomers)。
- 生物體的酵素 (enzyme) 只能代謝其中一個，所以這兩者是不同的物質，名稱必須能夠區分。
- 不對稱碳周圍四個基團的兩種空間排列，稱為兩種**組態 (configurations)**。
- 只要能為每個不對稱碳的組態命名，就能為任何掌性化合物的每一個鏡像異構物取得唯一的名稱。
- 目前最通用的系統是 **CIP 規則**：每個不對稱碳標上 **(R)** 或 **(S)**。

### 1-2　CIP 規則步驟一：排定優先順序 (priority)

四個基團依序稱為第 1（最高）、第 2、第 3、第 4（最低）優先基團。

**規則 (a)：先比「直接相連的原子」的原子序 (atomic number)，大者優先**
- 只看與不對稱碳直接相連的那個原子，不看整個基團的大小或質量。
- 同一元素的不同同位素 (isotopes)：質量數大者優先。例如氚 (tritium, ³H 或 T) > 氘 (deuterium, ²H 或 D) > 氕 (protium, ¹H)。

常見原子的優先順序：

$$\mathrm{I > Br > Cl > S > F > O > N > {}^{13}C > {}^{12}C > Li > {}^{3}H > {}^{2}H > {}^{1}H}$$

例：若不對稱碳連接 H、CH₃、NH₂、F，則優先順序為 F（9）> N（7）> C（6）> H（1）。

**規則 (b)：直接相連的原子相同時，往外一層比較**
1. 把第二層所連的三個原子由大到小排成一組，例如 (C, C, H)。
2. 兩組從第一個位置開始逐一比較，**第一個出現差異的位置**就決定勝負。
3. 若整組完全相同，再沿著優先順序最高的分支往外走一層，繼續比較。
4. **一個高優先原子勝過任何數目的低優先原子**。

例（課本 p.252）：
- 異丙基 (isopropyl, –CH(CH₃)₂) 的第一個碳連 (C, C, H)；乙基 (ethyl, –CH₂CH₃) 連 (C, H, H)。第二個位置 C > H，所以**異丙基 > 乙基**。
- –CH₂CH₂Br 與 –CH₂CH₃：第一、二層都是 (C, H, H)。到第三層，前者為 (Br, H, H)、後者為 (H, H, H)，所以 **–CH₂CH₂Br > –CH₂CH₃**。
- –CH₂Br (Br, H, H) 與 –C(CH₃)₃ (C, C, C)：第一個位置 Br > C 就分出勝負，所以 **–CH₂Br > –C(CH₃)₃**。

**規則 (c)：雙鍵、參鍵視為與「複製原子」各自相連**
- 把每一個 π 鍵假想打斷，在鍵的**兩端各補上一個對方原子的複製**，稱為複製原子 (duplicate atom)。
- 複製原子本身不再連接其他真實原子。依 IUPAC 2013 規則，可視為接上原子序為 0 的「幻原子 (phantom atoms)」。
- 每打斷一個 π 鍵，就要補兩個複製原子（兩端各一個）。

```
 R–CH=CH₂   視為   R–CH–CH₂            R–C≡CH   視為       (C)(C)
                     |   |                                     |  |
                    (C) (C)                             R –— C —— C –H
                                                               |  |
                                                              (C)(C)

 R–CH=O     視為   R–CH–O              R–CH=NH  視為   R–CH–NH
                     |  |                                 |   |
                    (O)(C)                               (N) (C)

          （括號內為複製原子）
```

所以：
- –CHO 的碳 → (O, O, H)
- –COOH 的碳 → (O, O, O)
- –CH=CH₂ 的第一個碳 → (C, C, H)
- –C≡CH 的第一個碳 → (C, C, C)

### 1-3　CIP 規則步驟二：判定 (R)/(S)

1. 讓**第 4 優先基團朝後**，遠離觀察者。
2. 其餘三個基團朝向觀察者，像方向盤 (steering wheel) 的輻條。
3. 畫一個箭頭：第 1 → 第 2 → 第 3。
   - **順時針 (clockwise)** → **(R)**（拉丁文 *rectus*，「正、右」）
   - **逆時針 (counterclockwise)** → **(S)**（拉丁文 *sinister*，「左」）
4. 另一種記法：把箭頭當成方向盤轉動的方向。車子往右轉是 (R)，往左轉是 (S)。

**時鐘記法（本講義使用）**

為了在純文字中清楚描述立體結構，本講義在**第 4 優先基團朝後**時，用時鐘位置表示其餘三個基團在紙面上的投影方向：

```
              12
         10        2
       9      C*      3
         8         4
               6
```

例如「Br 在 12 點、CH₃ 在 4 點、C₂H₅ 在 8 點」。由第 1 → 第 2 → 第 3 的鐘點順序，就能直接讀出旋轉方向：
- 鐘點依 12→4→8 方向遞增 → 順時針
- 鐘點依 12→8→4 方向遞減 → 逆時針

### 1-4　第 4 優先基團不在後方時

| 第 4 優先基團的位置 | 處理方式 |
|---|---|
| 朝後（虛線鍵） | 直接讀 1→2→3 的方向 |
| 朝前（楔形鍵） | 直接讀方向，然後**反過來**（課本 p.255 提示欄） |
| 在紙面上 | 用**交換法**：把它與朝後的基團交換，判定後再反過來（見推導 2-4） |

### 1-5　(R)/(S) 只是名稱

- (R)/(S) 是人為依優先順序定出來的**名稱**，描述原子的空間排列。
- 它與分子使偏振光往哪個方向旋轉，也就是 (+)/(−)，**沒有固定的對應關係**（Part 3 詳述）。
- 優先順序一變，(R)/(S) 標記就可能改變，即使空間排列完全沒變（例題 8、習題 5-38）。

## 二、原理推導

### 2-1　為何「交換任兩基團 ⇒ 組態反轉」

設不對稱碳連接 p、q、r、s，現在交換 p 與 q。

1. 由 Part 1 推導 2-2 的幾何事實：在正四面體中，碳原子與 r、s 兩根鍵所決定的平面 Π，恰好垂直平分 p 與 q 兩根鍵的夾角。
2. 以 Π 為鏡面做反射：r、s 位於 Π 上，不動；p 與 q 的位置互換。
3. 所以「交換 p、q」的結果，正好等於原結構的**鏡像**。
4. 優先順序沒變、空間方向反了，所以 (R) ↔ (S)。∎

**推論**：分子只有一個不對稱碳時，交換任兩基團就會得到它的鏡像異構物（課本 p.255 提示欄）。

### 2-2　交換兩次 = 不變；三個基團輪換 = 不變

- 交換兩次等於反射兩次。連續兩次鏡面反射等於一次旋轉（Part 1 推導 2-1），旋轉不改變組態。
- 固定一個基團，讓其餘三個依序輪換位置（p→q→r→p），等於做了兩次交換，所以組態不變。事實上，這就是繞固定基團那根鍵轉 120°。

**應用**：判斷兩張圖是否為同一分子時，可以數「把 A 變成 B 需要交換幾次」。
- 偶數次 → 同一組態
- 奇數次 → 相反組態

### 2-3　為何第 4 優先基團朝前時要「反判」

- 同一個轉動，從正面看是順時針，從背面看就是逆時針，就像透過玻璃從背後看時鐘。
- 第 4 優先基團朝前時，我們等於是從定義規定的反方向在觀察，所以讀到的方向剛好相反。

### 2-4　交換法（第 4 優先基團在紙面上時）

1. 把第 4 優先基團與目前朝後（虛線）的基團交換位置。
2. 交換後，第 4 優先基團朝後，可以直接讀出 (R) 或 (S)。
3. 由推導 2-1，交換一次會使組態反轉，所以**原分子的答案要反過來**。

### 2-5　延伸：用向量判定 (R)/(S)

令 **v₁、v₂、v₃** 為由不對稱碳指向第 1、2、3 優先基團的向量。座標取 x 向右、y 向上、z 朝向讀者，則：

$$(R) \iff (\mathbf{v}_1 \times \mathbf{v}_2)\cdot \mathbf{v}_3 < 0 \qquad (S) \iff (\mathbf{v}_1 \times \mathbf{v}_2)\cdot \mathbf{v}_3 > 0$$

**驗證**：取第 4 優先基團朝後（−z），三個基團略朝前：
- **v₁** = (0, 1, 0.3)，指向 12 點
- **v₂** = (0.87, −0.5, 0.3)，指向 4 點
- **v₃** = (−0.87, −0.5, 0.3)，指向 8 點

12→4→8 是順時針，應為 (R)。計算得 **v₁ × v₂** = (0.45, 0.26, −0.87)，與 **v₃** 的內積 ≈ −0.78 < 0，符合 (R)。

這個公式說明了 (R)/(S) 本質上就是三個向量構成的「左右手系」。交換任兩個向量時三重積變號，這正是推導 2-1 的代數版本。

## 三、例題講解

### 例題 1：優先順序綜合判定

**題目**：排出下列各組基團的優先順序。
(a) –CH₂OH、–CH(CH₃)₂、–CH₃、–H
(b) –C≡CH、–C(CH₃)₃、–CH=CH₂、–CH(CH₃)₂
(c) –C₆H₅（苯基 phenyl）、–C≡CH（乙炔基 ethynyl）

**詳解**：

**(a)**
- 直接相連的原子都是 C（H 除外，H 最低）。
- 往外一層：–CH₂OH 為 (O, H, H)，–CH(CH₃)₂ 為 (C, C, H)，–CH₃ 為 (H, H, H)。
- 比較第一個位置：O > C > H。
- 答：**–CH₂OH > –CH(CH₃)₂ > –CH₃ > –H**。
- 重點：一個 O 勝過兩個 C。

**(b)** 先展開複製原子，列出第一層：

| 基團 | 第一個碳所連的原子 | 比較 |
|---|---|---|
| –C≡CH | (C, C, C)：一個真實 C 加兩個複製 C | 與三級丁基同為 (C, C, C) |
| –C(CH₃)₃ | (C, C, C) | |
| –CH=CH₂ | (C, C, H)：一個真實 C 加一個複製 C | 與異丙基同為 (C, C, H) |
| –CH(CH₃)₂ | (C, C, H) | |

第一層出現兩組平手，各自往外一層，依分支優先順序逐一比較：

- **–C≡CH 對 –C(CH₃)₃**
  - 乙炔基的分支：真實的末端 CH 連 (C, C, H)（兩個複製 C 加一個 H）；兩個複製 C 各連 (0, 0, 0)。
  - 三級丁基的分支：三個 CH₃，各連 (H, H, H)。
  - 先比最高的分支：(C, C, H) 對 (H, H, H)，乙炔基勝。
- **–CH=CH₂ 對 –CH(CH₃)₂**
  - 乙烯基 (vinyl) 的最高分支：=CH₂ 連 (C, H, H)（一個複製 C 加兩個 H）。
  - 異丙基的最高分支：CH₃ 連 (H, H, H)。
  - 乙烯基勝。

答：**–C≡CH > –C(CH₃)₃ > –CH=CH₂ > –CH(CH₃)₂**

**(c)**
- 第一層兩者都是 (C, C, C)。
- 往外一層：
  - 苯基的分支依序為：兩個鄰位 (ortho) 碳各連 (C, C, H)，一個複製 C 連 (0, 0, 0)。
  - 乙炔基的分支依序為：一個 (C, C, H)，兩個 (0, 0, 0)。
- 第一個分支平手；第二個分支 (C, C, H) > (0, 0, 0)。
- 答：**苯基 > 乙炔基**。

> 結合 (b)、(c)：**–C₆H₅ > –C≡CH > –C(CH₃)₃ > –CH=CH₂ > –CH(CH₃)₂**。這是常考的排序。

### 例題 2：天然丙胺酸為 (S)（課本 p.254）

**題目**：天然丙胺酸中，H 朝後，COOH 在 12 點、NH₂ 在 4 點、CH₃ 在 8 點。判定其組態。

**詳解**：
1. 優先順序：
   - NH₂：N，原子序 7，第 1。
   - COOH：C 連 (O, O, O)，第 2。
   - CH₃：C 連 (H, H, H)，第 3。
   - H：第 4。
2. H 朝後，直接讀箭頭：NH₂（4 點）→ COOH（12 點）→ CH₃（8 點），也就是 4 → 12 → 8，**逆時針**。
3. 答：**(S)-丙胺酸**。

> **補充**：天然胺基酸 (amino acids) 幾乎都是 (S) 組態，**例外是半胱胺酸 (cysteine)**。
> 半胱胺酸的側鏈是 –CH₂SH，其碳連 (S, H, H)。因為 S > O，–CH₂SH 的優先順序高於 –COOH (O, O, O)。
> 空間排列與其他天然胺基酸相同，只因優先順序改變，標記就變成 **(R)**。

### 例題 3：1,3-二溴丁烷（課本 Solved Problem 5-2）

**題目**：畫出 1,3-二溴丁烷 (1,3-dibromobutane, BrCH₂CH₂–CHBr–CH₃) 的兩個鏡像異構物，並標出 (R)/(S)。

**詳解**：
1. 不對稱碳是 C3。
2. 優先順序：
   - Br：第 1。
   - –CH₂CH₂Br：第一層 (C, H, H)。
   - –CH₃：第一層 (H, H, H)。
   - 所以 –CH₂CH₂Br 第 2、–CH₃ 第 3、H 第 4。
   - 注意：–CH₂CH₂Br 中的 Br 離不對稱碳有兩個鍵遠，但這裡在第一層就分出勝負了，用不到 Br。
3. 兩種排列（H 都朝後）：

| 排列 | Br | –CH₂CH₂Br | –CH₃ | 1→2→3 | 組態 |
|---|---|---|---|---|---|
| 甲 | 8 點 | 12 點 | 4 點 | 8→12→4，順時針 | **(R)** |
| 乙 | 4 點 | 12 點 | 8 點 | 4→12→8，逆時針 | **(S)** |

甲、乙互為鏡像：左右對調，上下與前後不變。

### 例題 4：第 4 優先基團朝前

**題目**：丁-2-醇（2-丁醇，butan-2-ol）中，H 為楔形鍵（朝前）。在紙面投影上，OH 在 12 點、C₂H₅ 在 4 點、CH₃ 在 8 點。判定其組態。

**詳解**：
1. 優先順序：OH > C₂H₅ > CH₃ > H。
2. 直接讀方向：12 → 4 → 8，順時針。
3. 但 H 朝前，要反過來，所以是逆時針。
4. 答：**(S)-丁-2-醇**。

### 例題 5：第 4 優先基團在紙面上（交換法）

**題目**：2-氯丁烷 (2-chlorobutane) 的一張立體圖如下：H 在上方（紙面內），CH₃ 在左下（紙面內），Cl 在右側（楔形，朝前），C₂H₅ 在右側（虛線，朝後）。判定其組態。

**詳解**：
1. 優先順序：Cl > C₂H₅ > CH₃ > H。
2. 交換 H 與朝後的 C₂H₅。交換後：
   - C₂H₅ 在上方（紙面），投影在 12 點。
   - CH₃ 在左下，投影在 8 點。
   - Cl 在右下前方，投影在約 4 點。
   - H 朝後。
3. 讀方向：Cl（4 點）→ C₂H₅（12 點）→ CH₃（8 點），4 → 12 → 8，逆時針，所以交換後的分子是 (S)。
4. 交換過一次，原分子要反過來。
5. 答：**(R)-2-氯丁烷**。

> 以推導 2-5 的向量法驗算：
> - **v**(Cl) = (0.6, −0.3, 0.7)
> - **v**(C₂H₅) = (0.6, −0.3, −0.7)
> - **v**(CH₃) = (−0.87, −0.5, 0)
>
> 三重積 ≈ −0.78 < 0，確認為 (R)。

### 例題 6：環上的不對稱碳：香芹酮（課本 Solved Problem 5-3）

**題目**：找出香芹酮 (carvone，2-甲基-5-(丙-1-烯-2-基)環己-2-烯-1-酮，2-methyl-5-(prop-1-en-2-yl)cyclohex-2-en-1-one) 的不對稱碳，並排出其四個基團的優先順序。

**詳解**：
1. 不對稱碳是帶異丙烯基 (isopropenyl, –C(CH₃)=CH₂) 的環碳 C5。它雖然連著兩個環上的 –CH₂–，但這兩個 CH₂ 是不同的基團。
2. 比較四個基團：

| 基團 | 第一層 | 第二層（沿最高分支） | 優先 |
|---|---|---|---|
| –C(CH₃)=CH₂ | (C, C, C)（含一個複製 C） | | **1** |
| 環 C6H₂ → C1(=O) | (C, H, H) | C1 連 (O, O, C)（含複製 O） | **2** |
| 環 C4H₂ → C3H= | (C, H, H) | C3 連 (C, C, H)（含複製 C） | **3** |
| H | | | **4** |

3. 兩個環 CH₂ 在第一層平手，到第二層時 O > C，所以通往羰基 (carbonyl group, C=O) 的那一側優先。
4. 課本圖中的結構判定為 **(S)-香芹酮**。它就是 5-5 節中帶有葛縷子 (caraway) 氣味的 (+)-香芹酮。

> 環上碳的技巧：從不對稱碳出發，沿環兩個方向同步往外走，直到遇到第一個差異點（課本 p.254 提示欄）。

### 例題 7：複製原子的深入判定（課本 Problem 5-6(i)）

**題目**：某不對稱碳連接 –CHO、–CH(OCH₃)₂、–CH(CH₃)₂、–CH=CH₂。排出優先順序。

**詳解**：

**第一層**：

| 基團 | 第一個碳所連 |
|---|---|
| –CH(OCH₃)₂ | (O, O, H) |
| –CHO | (O, O, H)：一個真實 O 加一個複製 O |
| –CH=CH₂ | (C, C, H) |
| –CH(CH₃)₂ | (C, C, H) |

兩組平手，各自往外一層：

**–CH(OCH₃)₂ 對 –CHO**
- –CH(OCH₃)₂ 的分支：兩個 O，各連 (C)，即甲基碳。
- –CHO 的分支：真實的 =O 連 (C)，是複製的 C；複製 O 連 (0)，是幻原子。
- 依序比較：第一分支 (C) 對 (C) 平手；第二分支 (C) 對 (0)，–CH(OCH₃)₂ 勝。

**–CH=CH₂ 對 –CH(CH₃)₂**
- 乙烯基的最高分支 =CH₂ 連 (C, H, H)。
- 異丙基的最高分支 CH₃ 連 (H, H, H)。
- 乙烯基勝。

答：**–CH(OCH₃)₂ > –CHO > –CH=CH₂ > –CH(CH₃)₂**

> 陷阱：很多人直覺認為 –CHO 有雙鍵 O 應該比較高。但複製原子後面沒有接任何真實原子，在更外層的比較中反而吃虧。

### 例題 8：反應前後標記不變，但旋光方向改變（結合課本 5-14 的例子）

**題目**：(S)-2-甲基丁-1-醇（(S)-2-methylbutan-1-ol）與三溴化磷 (phosphorus tribromide, PBr₃) 反應，生成 1-溴-2-甲基丁烷 (1-bromo-2-methylbutane)。反應不斷不對稱碳上的任何鍵。產物的組態為何？已知反應物為 (+)，產物為 (−)，這說明什麼？

**詳解**：
1. 不對稱碳 C2 上的基團：
   - 反應物：–CH₂OH (O, H, H)、–C₂H₅、–CH₃、H。
   - 產物：–CH₂Br (Br, H, H)、–C₂H₅、–CH₃、H。
2. 兩者的優先順序都是「–CH₂X 第 1、–C₂H₅ 第 2、–CH₃ 第 3」。名次沒變，空間排列也沒變。
3. 答：產物為 **(S)-1-溴-2-甲基丁烷**。
4. 旋光方向卻由 (+) 變成 (−)。這證明 **(R)/(S) 與 (+)/(−) 沒有固定關係**。

> 對照習題 5-38：該題空間排列不變，但優先名次互換，所以標記由 (R) 變成 (S)。

## 四、整理比較表

### 4-1　常見基團的優先順序（由高到低）

| 類別 | 排序 |
|---|---|
| 鹵素 (halogen) 等 | –I > –Br > –Cl > –SH > –F |
| 氧上的基團 | –OCH₃ > –OH |
| 氮上的基團 | –NO₂ > –N(CH₃)₂ > –NHCH₃ > –NH₂ |
| 碳上的基團 | –CH₂Br > –CCl₃ > –COCl > –CH₂Cl > –COOCH₃ > –COOH > –CONH₂ > –CHO > –CH₂OH > –C≡N > –CH₂NH₂ > –C₆H₅ > –C≡CH > –C(CH₃)₃ > –CH=CH₂ > –CH(CH₃)₂ > –CH₂CH₃ > –CH₃ |
| 氫 | –T > –D > –H |

三個類別之間的順序是：任何鹵素、O、N 上的基團都高於所有碳上的基團，因為直接相連的原子先決定。

表中幾個值得注意的比較：
- –CH₂Br (Br, H, H) > –CCl₃ (Cl, Cl, Cl)：第一個位置 Br > Cl，就分出勝負。
- –CH₂Cl (Cl, H, H) > –COOH (O, O, O)：一個 Cl 勝過三個 O。
- –CH₂OH (O, H, H) > –C≡N (N, N, N)：一個 O 勝過三個 N。
- –COOCH₃ > –COOH：第一層同為 (O, O, O)，往外一層時，單鍵 O 上接的是 C 而不是 H。

### 4-2　判定 (R)/(S) 的流程

```
1. 找出不對稱碳
2. 排出四個基團的優先順序（規則 a → b → c）
3. 看第 4 優先基團的位置
   ├─ 朝後（虛線）    → 直接讀 1→2→3：順時針 R、逆時針 S
   ├─ 朝前（楔形）    → 直接讀，再反過來
   └─ 在紙面上        → 與朝後的基團交換 → 讀 → 反過來
4. 若有多個不對稱碳，逐一判定，寫成 (2R,3S) 等形式
```

### 4-3　操作與組態的關係

| 對分子做的操作 | 組態的變化 |
|---|---|
| 整個分子旋轉 | 不變 |
| 交換任兩基團 1 次 | 反轉 |
| 交換 2 次 | 不變 |
| 固定一基團，其餘三個輪換 | 不變（等於交換 2 次） |
| 取鏡像 | 反轉 |
| 改變遠處的基團，使優先名次互換 | 標記可能改變，空間排列不變 |

### 4-4　常見陷阱

| 錯誤想法 | 正確觀念 |
|---|---|
| 基團越大、越重，優先順序越高 | 只比原子序，而且由內往外逐層比 |
| 一層比不出來，就把整個基團的原子加總比較 | 只看第一個出現差異的位置 |
| 雙鍵 O 一定勝過兩個單鍵 O | 複製原子後面是幻原子，往外比較時可能吃虧（例題 7） |
| H 朝前時，直接讀出的方向就是答案 | 要反過來 |
| (R) 一定是右旋 (+) | 兩者無關（例題 8） |
| 標記由 R 變成 S，代表空間排列反轉了 | 也可能只是優先名次改變（習題 5-38） |
| 環上兩個 CH₂ 無法比較 | 沿環繼續往外走，直到出現差異（例題 6） |

## 六、章末精選題詳解

### 習題 5-38\*（課本標示較難）

**題目**：3,4-二甲基戊-1-烯 (3,4-dimethylpent-1-ene, CH₂=CH–CH(CH₃)–CH(CH₃)₂)。純的 (R) 異構物以 H₂/Pt 處理後，得到 (S)-2,3-二甲基戊烷 ((S)-2,3-dimethylpentane)。
(a) 寫出反應式，標出反應物與產物的立體化學。
(b) 掌性中心的組態是保留還是反轉？
(c) 反應物叫 (R)、產物叫 (S)，是否代表空間排列改變了？為何名稱會變？
(d) (R)/(S) 標記對預測旋光的正負號有多大用處？能否預測反應物或產物的旋光方向？

**詳解**：

**(a)** 不對稱碳為反應物的 C3。

**反應物**的優先順序：
- 乙烯基 –CH=CH₂ 與異丙基 –CH(CH₃)₂：第一層都是 (C, C, H)。
- 往外一層：乙烯基的最高分支 =CH₂ 連 (C, H, H)，異丙基的 CH₃ 連 (H, H, H)，乙烯基勝。
- 所以：乙烯基 (1) > 異丙基 (2) > CH₃ (3) > H (4)。

**(R) 反應物**的一種畫法：H 朝後，乙烯基 12 點、異丙基 4 點、CH₃ 8 點。12→4→8 為順時針，是 (R)。

```
                       H₂, Pt
 (R)-CH₂=CH–C*H(CH₃)–CH(CH₃)₂  ───────→  (S)-CH₃CH₂–C*H(CH₃)–CH(CH₃)₂
   乙烯基 12 點                             乙基 12 點
   異丙基  4 點                             異丙基 4 點
   CH₃     8 點                             CH₃    8 點
   H 朝後                                   H 朝後
```

**產物**是 2,3-二甲基戊烷，不對稱碳為主鏈的 C3。各基團位置不變，只是乙烯基變成了乙基。
- 新的優先順序：異丙基 (C, C, H) > 乙基 (C, H, H) > CH₃ > H。
- 讀方向：異丙基（4 點）→ 乙基（12 點）→ CH₃（8 點），4→12→8，逆時針，所以是 **(S)**。

**(b)** 氫化只發生在 C=C 上，不對稱碳上的四根鍵都沒有斷，所以**組態保留**（空間排列不變）。

**(c)** 空間排列**沒有改變**。名稱改變的原因是：
- 乙烯基原本排第 1、異丙基排第 2。
- 乙烯基被還原成乙基後，名次掉到異丙基之後。
- 第 1 與第 2 名互換，相當於推導 2-1 中「交換兩基團」的效果，只發生在名次上，不是空間上。所以標記由 R 變成 S。
- 結論：(R)/(S) 是依優先順序定的名稱，不是空間排列的直接描述。

**(d)** 幾乎沒有用處。
- (R)/(S) 不能預測旋光是 (+) 還是 (−)，反應物或產物都一樣，只能用旋光計 (polarimeter) 實際測量。
- 唯一可以確定的是：某化合物的鏡像異構物，旋光度與它大小相同、方向相反。
- 正如題目引用茱麗葉的話：「名字有什麼意義？玫瑰換了別的名字，依然芬芳。」

### 習題 5-27(b)：(R)-1,1,2-三甲基環己烷（接續 Part 1）

**題目**：同 5-27 的六個小題。Part 1 已完成掌性中心、對稱面、非鏡像異構物與掌性判斷，這裡補上 (R) 異構物的立體結構與鏡像異構物。

### 習題 5-27(d)：(1R,2R)-1,2-二溴環己烷 ((1R,2R)-1,2-dibromocyclohexane)

**題目**：同 5-27 的六個小題。

**詳解**：

**1. 畫出立體結構**

環畫成平面，C1 在右上頂點，C2 在其正下方的右下頂點。

**C1 的判定**：
- 優先順序：Br > C2（CHBr，連 Br, C, H）> C6（CH₂）> H。
- 投影方向：Br 朝環外的右上方（約 30°），C2 在正下方（270°），C6 在左上方（150°）。
- 讀方向：30° → 270° → 150°，角度一路遞減，為順時針。
- 所以 Br 為楔形、H 朝後時，C1 為 **(R)**。

**C2 的判定**：
- 優先順序：Br > C1 > C3 > H。
- 投影方向：Br 朝環外右下（330°），C1 在正上方（90°），C3 在左下方（210°）。
- 讀方向：330° → 90° → 210°，角度遞增，為逆時針。
- 若 Br 為虛線、H 為楔形（H 朝前）：讀到逆時針後要反判，得 **(R)**。
- 若 Br 為楔形、H 朝後：直接得 (S)。

**結論**：(1R,2R) 對應「C1 的 Br 朝前、C2 的 Br 朝後」，也就是**反式 (trans)**-1,2-二溴環己烷。

**2. 掌性中心**：C1\*、C2\*。

**3. 對稱面**：反式結構沒有對稱面。

**4. 鏡像異構物**：(1S,2S)-1,2-二溴環己烷，同為反式，兩個 Br 的楔形與虛線互換。

**5. 非鏡像異構物**：順式 (cis)，即 (1R,2S)-1,2-二溴環己烷。
- 兩個 Br 同為楔形。
- 有一個平分 C1–C2 鍵與 C4–C5 鍵的 σ，所以非掌性，是**內消旋化合物 (meso compound)**。
- (1R,2S) 與 (1S,2R) 是同一個化合物。

**6. 掌性**：(1R,2R) 與 (1S,2S) 為掌性；(1R,2S) 為非掌性。

> **規律**：對稱的 1,2-二取代環，反式為 (R,R)/(S,S)，順式為 (R,S) 的內消旋。這個規律在 Part 5 會再用到。

### 習題 5-26(a)、(l)：補上 (R)/(S)（接續 Part 1）

**(a) 1-氯乙-1-醇 (1-chloroethan-1-ol)**

> 本題依課本圖判讀：H 在上方（紙面內）、CH₃ 在右下（紙面內）、Cl 為左側虛線鍵、OH 為左下楔形鍵。若你的課本版本楔形與虛線相反，答案即反過來。

- 優先順序：Cl > OH > CH₃ > H。
- H 在紙面上，用交換法：交換 H 與朝後的 Cl。
  - 交換後 Cl 在 12 點，OH 在約 8 點，CH₃ 在約 4 點，H 朝後。
  - Cl → OH → CH₃ 為 12→8→4，逆時針，得 (S)。
- 交換過一次，原分子要反過來，所以為 **(R)**。

**(l) 7,7-二甲基降莰-2-烯 (7,7-dimethylbicyclo[2.2.1]hept-2-ene)**

**C1 的優先順序**：

| 基團 | 第一層 | 名次 |
|---|---|---|
| C7 | (C, C, C)：連兩個 CH₃ 與 C4 | 1 |
| C2 | (C, C, H)：sp²，含一個複製 C | 2 |
| C6 | (C, H, H) | 3 |
| H | | 4 |

C4 的四個基團依序是 C7、C3、C5、H，正好是 C1 那四個基團的鏡像對應。

- 分子有 σ，而且 σ 把 C1 與 C4 互相反射，對應基團的名次也相同。
- 鏡像會使旋轉方向相反，所以 **C1 與 C4 的組態必定一個是 R、一個是 S**。
- 由於分子對稱，編號從哪一個橋頭碳開始都可以。依 IUPAC 慣例，可選擇時讓較小的位號為 R，所以命名為 **(1R,4S)-7,7-二甲基降莰-2-烯**。
- 這與 Part 1 的結論一致：分子是內消旋化合物。

## 本份重點回顧

1. 優先順序：先比直接相連原子的原子序；平手時，往外逐層比較第一個差異點；重鍵以複製原子展開。
2. 第 4 優先基團朝後時，1→2→3 順時針為 R、逆時針為 S。朝前時要反判；在紙面上時，交換後再反判。
3. 交換任兩基團一次會使組態反轉；交換偶數次或做旋轉，組態不變。
4. (R)/(S) 是依優先順序定出的名稱。它與 (+)/(−) 無關，也可能因優先名次改變而改變，而空間排列完全不動。
