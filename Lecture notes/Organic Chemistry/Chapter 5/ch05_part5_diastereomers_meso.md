## 一、觀念說明

### 1-1　非鏡像異構物（5-11）

**非鏡像異構物 (diastereomers)**：**不互為鏡像**的立體異構物。

立體異構物只有兩種關係：互為鏡像的是鏡像異構物，其餘一律是非鏡像異構物。大多數非鏡像異構物屬於以下兩類。

**(1) 雙鍵上的順反異構 (cis-trans isomerism on double bonds)**（5-11A）
- 例：cis-丁-2-烯與 trans-丁-2-烯 (cis-/trans-but-2-ene)。
- 兩者不互為鏡像，所以是非鏡像異構物。

**(2) 環上的順反異構**（5-11B）
- 例：cis- 與 trans-1,2-二甲基環戊烷 (1,2-dimethylcyclopentane) 互為非鏡像異構物。
- trans 異構物有鏡像異構物。
- cis 異構物有內部鏡面 σ，所以非掌性，沒有鏡像異構物。

**(3) 含兩個以上掌性中心的分子**（5-11C）
- 例：2-溴-3-氯丁烷 (2-bromo-3-chlorobutane)，C2 與 C3 都是不對稱碳。

```
   (2S,3R)        (2R,3S)        (2S,3S)        (2R,3R)
     CH₃            CH₃            CH₃            CH₃
  H ──┼── Br    Br ──┼── H      H ──┼── Br    Br ──┼── H
  H ──┼── Cl    Cl ──┼── H     Cl ──┼── H      H ──┼── Cl
     CH₃            CH₃            CH₃            CH₃
   └──── 鏡像異構物 ────┘        └──── 鏡像異構物 ────┘
          └──────────── 兩組之間互為非鏡像異構物 ────────────┘
```

- (2S,3R) 與 (2S,3S)：C2 的組態相同，C3 的組態不同，所以**不是鏡像**，是非鏡像異構物。
- 鏡像異構物之間，**每一個**不對稱碳都必須互為鏡像。
- 這 4 個立體異構物構成兩對鏡像異構物；任一對中的任一個，與另一對中的任一個都是非鏡像異構物。

> **判定口訣**（課本 FOCUS 欄）
> - **全部**掌性中心都反轉 → 鏡像異構物
> - **至少一個**反轉、**至少一個**不變 → 非鏡像異構物

### 1-2　異構物分類總表（課本 SUMMARY）

```
                          異構物 isomers
                 （分子式相同的不同化合物）
                ┌───────────────┴───────────────┐
         結構異構物                         立體異構物
   constitutional isomers                stereoisomers
     （鍵結順序不同）                   （只有空間方位不同）
                                ┌──────────────┴──────────────┐
                         鏡像異構物                     非鏡像異構物
                         enantiomers                    diastereomers
                       （互為鏡像）                   （不互為鏡像）
                                                ┌──────────┴──────────┐
                                          順反異構物            其他非鏡像異構物
                                     cis-trans isomers       （兩個以上掌性中心）
                                    （雙鍵或環上的順反）
```

### 1-3　含兩個以上不對稱碳的分子：2ⁿ 規則（5-12）

**2ⁿ 規則 (2ⁿ rule)**：含 n 個掌性中心（通常是不對稱碳）的化合物，**最多**有 2ⁿ 個立體異構物。

- 實際數目常常比 2ⁿ 少，特別是**兩個不對稱碳帶有相同取代基**時。

**例：2,3-二溴丁烷 (2,3-dibromobutane)**
- n = 2，最多 4 個，但實際只有 **3 個**。
- (2R,3R) 與 (2S,3S)：一對鏡像異構物，合稱 **(±) 非鏡像異構物**。
- (2R,3S) 與 (2S,3R)：**是同一個化合物**，有內部鏡面，非掌性，稱為**內消旋非鏡像異構物 (meso diastereomer)**。

```
   (2R,3R)        (2S,3S)        (2R,3S) = (2S,3R)
     CH₃            CH₃              CH₃
  Br ──┼── H     H ──┼── Br       H ──┼── Br
   H ──┼── Br   Br ──┼── H        H ──┼── Br    ← 兩列之間有水平的 σ
     CH₃            CH₃              CH₃
   └─── (±) 鏡像異構物 ───┘        內消旋
```

可以這樣理解內消旋化合物：它的 (R) 中心與 (S) 中心經 σ 互為鏡像，就像分子內部自己構成了一個外消旋混合物。

### 1-4　內消旋化合物（5-13）

> **內消旋化合物 (meso compound)**：含有掌性中心（通常是不對稱碳），但本身**非掌性**的化合物。

- 大多數內消旋化合物都有類似的對稱結構：**兩個相同的半邊，組態相反**。
- meso 源自希臘文「中間」：最初指一組非鏡像異構物中非掌性的那一個，它的旋光性介於右旋與左旋之間（為 0）。
- 原始定義是「**具有掌性非鏡像異構物的非掌性化合物**」（見 Part 4 習題 5-41）。

**已出現過的內消旋化合物**：
- cis-1,2-二氯環戊烷
- cis-1,2-二溴環己烷：椅式構形不對稱，但兩個鏡像椅式構形快速互變，可以用平面構形判斷。
- 內消旋-2,3-二溴丁烷
- 內消旋酒石酸 (meso-tartaric acid)

> **解題提示**：含兩個掌性中心的內消旋化合物，組態必定是 **(R,S)** 或 **(S,R)**，因為兩個中心經 σ 互為鏡像（推導 2-2）。

**為何不能把內消旋定義成「含有立體中心的非掌性化合物」**（課本 Solved Problem 5-8）
- 立體中心也包括雙鍵碳。
- 例如 cis- 與 trans-丁-2-烯都含有立體中心，而且都是非掌性的，若照這個定義兩者都會被歸為內消旋。
- 但它們根本**沒有掌性的非鏡像異構物**，所以不能稱為內消旋。

### 1-5　課本 FOCUS 欄：多個掌性中心的實例數據

**2,3-二羥基丁酸 (2,3-dihydroxybutanoic acid)**：兩個掌性中心，4 個立體異構物都具掌性。

| 異構物 | 熔點 | 旋光度 | 關係 |
|---|---|---|---|
| A (2S,3S) | 64 °C | +11° | A、B 互為鏡像異構物 |
| B (2R,3R) | 64 °C | −11° | |
| C (2R,3S) | 75 °C | +19° | C、D 互為鏡像異構物 |
| D (2S,3R) | 75 °C | −19° | |

A、B 各自與 C、D 互為非鏡像異構物。

**酒石酸 (tartaric acid)**：兩端相同，只有 **3 個**立體異構物。

| 異構物 | 熔點 | 旋光度 |
|---|---|---|
| (2R,3R) | 172 °C | +12° |
| (2S,3S) | 172 °C | −12° |
| (2R,3S)，即內消旋 | 166 °C | 0° |

**規律**：
- 鏡像異構物之間：熔點相同，旋光度大小相同、方向相反。
- 非鏡像異構物之間：熔點、旋光度都不同。

### 1-6　絕對組態與相對組態（5-14）

**絕對組態 (absolute configuration)**
- 分子中原子在空間中的實際排列。也可以說是每個掌性中心的 (R)/(S) 組態。
- 例如給定名稱「(R)-丁-2-醇」，任何化學家都能做出正確的分子模型。

**相對組態 (relative configuration)**
- 由實驗確定的、兩個分子組態之間的關係，即使兩者的絕對組態都未知。

**歷史背景**：
- 1951 年以前，無法把立體結構圖與實際的鏡像異構物、它的旋光方向連結起來，沒有任何化合物的絕對組態是已知的。
- 1951 年，**X 射線晶體繞射 (X-ray crystallography)** 首次被用來決定原子在空間中的方位，之後才得以確定絕對組態。
- 在此之前，化學家只能比較不同化合物之間的相對組態。

**用反應建立相對組態**：只要反應**不斷不對稱碳上的任何鍵**，產物與反應物的相對組態就相同。

```
     CH₃CH₂–C*H(CH₃)–CH₂OH    ──PBr₃──→    CH₃CH₂–C*H(CH₃)–CH₂Br
   (+)-2-甲基丁-1-醇                    (−)-1-溴-2-甲基丁烷
       [α] = +5.8°                           [α] = −4.0°
```

- 這兩者有**相同的相對組態**。
- 但若不與絕對組態已知的化合物作關聯，就無法知道它們是 (R) 還是 (S)。
- 這個例子也再次說明，旋光方向會變，與組態無關。

**D/L 命名法 (D-L configurations)，又稱 Fischer–Rosanoff 規則 (Fischer–Rosanoff convention)**
- 以甘油醛 (glyceraldehyde) 為基準：
  - 與 **(+)-甘油醛**相對組態相同的化合物，標 **D**。
  - 與 **(−)-甘油醛**相對組態相同的化合物，標 **L**。
- 現在已知 (+)-甘油醛是 **(R)**，在費雪投影式中 OH 在**右**；(−)-甘油醛是 **(S)**，OH 在左。

**判定方法**：把費雪投影式畫成最氧化的一端在上，看**離最氧化端最遠的那個不對稱碳**（通常是最下方的不對稱碳）：
- OH（或胺基酸的 NH₂）在**右** → **D**
- 在**左** → **L**

| 化合物類別 | 天然常見的組態 | 判定依據 |
|---|---|---|
| 醣類 (sugars) | 大多為 **D**，例如 D-(+)-葡萄糖、D-(−)-蘇糖 (threose) | 最下方不對稱碳的 OH 在右 |
| 胺基酸 (amino acids) | 大多為 **L**，例如 L-(−)-絲胺酸 (serine)、L-(+)-麩胺酸 (glutamic acid)、L-(+)-丙胺酸 | α 碳的 NH₂ 在左 |

醣類有好幾個不對稱碳，但都可以從醛基端逐步氧化降解成甘油醛（第 23 章），所以能這樣比較。

> **三套符號互不相關**：
> - **D/L**：相對組態，與甘油醛比較。
> - **(R)/(S)**：絕對組態，依 CIP 規則命名。
> - **(+)/(−)**：旋光方向，由實驗測得。
>
> 例如 D-(−)-赤藻糖、L-(+)-丙胺酸、(S)-L-丙胺酸。三者之間都沒有固定的對應關係。

> 補充（課本提示欄）：環狀化合物名稱中的 cis/trans 也只表示**相對組態**。
> - 例如 cis-1-溴-2-甲基環己烷，只說明 Br 與 CH₃ 在環的同側，兩個 cis 鏡像異構物都符合這個名稱。
> - (1S,2R)-1-溴-2-甲基環己烷則指定了絕對組態，只對應一個結構。

### 1-7　非鏡像異構物的物理性質（5-15）

**鏡像異構物**除了旋光方向之外，物理性質完全相同；**非鏡像異構物**的物理性質一般都不同。

| 化合物 | 異構物 | 數據 | 原因 |
|---|---|---|---|
| 丁-2-烯 | trans | 沸點 0.9 °C，偶極矩 μ = 0 | 鍵偶極互相抵消 |
| | cis | 沸點 3.7 °C，μ = 0.33 D | 鍵偶極的向量和不為零，有偶極–偶極作用力 |
| 2,3-二溴琥珀酸 (2,3-dibromosuccinic acid) | 內消旋 | 熔點 256 °C | 熔點相差將近 100 °C |
| | (±) | 熔點 158 °C | |
| 葡萄糖與半乳糖（只有 C4 不同） | D-(+)-葡萄糖 (glucose) | 熔點 148 °C | |
| | D-(+)-半乳糖 (galactose) | 熔點 167 °C | |

> 只有一個不對稱碳組態不同的兩個非鏡像異構物，稱為**差向異構物 (epimers)**，例如葡萄糖與半乳糖。這個名詞會在醣類一章再出現。

**重要結論**：非鏡像異構物可以用**一般的物理方法**分離，例如蒸餾 (distillation)、再結晶 (recrystallization)、層析 (chromatography)。鏡像異構物的分離則困難得多（1-8）。

### 1-8　鏡像異構物的離析（5-16）

**純鏡像異構物的來源**：
- **大多從生物來源取得**，因為生物體內的掌性分子通常只有一種鏡像異構物。
  - (+)-酒石酸：取自釀酒時酵母形成的沉澱。
  - (+)-葡萄糖：取自葡萄、甜菜、甘蔗、蜂蜜。
  - (+)-丙胺酸：取自蛋白質。
- **若以非掌性試劑合成**，得到的是外消旋混合物。例如丁-2-酮以 H₂/Pt 還原，得到 (±)-丁-2-醇。

**離析 (resolution)**：把外消旋混合物分成兩個純鏡像異構物的過程。
- 它與一般的物理分離不同，**必須使用掌性探針**。
- 所用的掌性化合物或掌性裝置，稱為**離析劑 (resolving agent)**。

#### 1-8-1　Pasteur 的手工離析（1848 年）

- Louis Pasteur 發現，外消旋 (±)-酒石酸的某種鹽（酒石酸鈉銨 sodium ammonium tartrate），會結晶成互為鏡像的兩種晶體。
- 他在顯微鏡下用鑷子把兩種晶體分開。
- 「左手」晶體與「右手」晶體配成的溶液，使偏振光朝相反方向旋轉。
- 這是**第一次人工離析鏡像異構物**。
- 可惜，很少有外消旋化合物會分別結晶成兩種鏡像晶體，所以需要其他方法。

#### 1-8-2　化學離析 (chemical resolution)（5-16A）

**原理**：讓外消旋物與**單一鏡像異構物的離析劑**結合，形成一對**非鏡像異構物**；用一般方法分離後，再把離析劑切除。

**例：離析 (±)-丁-2-醇**（課本 Figure 5-22）

1. **選擇離析劑**：羧酸 (carboxylic acid) 可與醇 (alcohol) 形成酯 (ester)。(R,R)-(+)-酒石酸便宜、無毒，任何酒廠都能大量供應。

```
   R–COOH  +  R′–OH   ⇌ (H⁺ 催化)   R–COO–R′  +  H₂O
     酸         醇                      酯         水
```

2. **形成非鏡像異構物**：

```
 (R)-丁-2-醇 ┐                     (R)-2-丁基 (R,R)-酒石酸酯 ┐
             ├ + (R,R)-酒石酸 ──H⁺──→                         ├ 非鏡像異構物
 (S)-丁-2-醇 ┘                     (S)-2-丁基 (R,R)-酒石酸酯 ┘ （不互為鏡像）
```

3. **分離**：以蒸餾、再結晶或層析，把兩個非鏡像異構酯分開。
4. **切除離析劑**：加酸催化劑與過量的水，使酯水解 (hydrolysis)，平衡移回酸與醇：
   - (R)-酯 → (R)-丁-2-醇 + (+)-酒石酸
   - (S)-酯 → (S)-丁-2-醇 + (+)-酒石酸
5. **回收離析劑**：酒石酸便宜，通常直接丟棄；昂貴的離析劑則必須小心回收再利用。

#### 1-8-3　層析離析 (chromatographic resolution)（5-16B）

- **一般層析**：溶液流過填有吸附性顆粒的管柱。吸附較強的化合物在固定相 (stationary phase) 上停留較久，較晚流出；吸附較弱的較早流出。
- **掌性層析**：管柱的填充顆粒表面塗有**掌性分子**（課本 Figure 5-23）。
  1. 兩個鏡像異構物與掌性填充物形成弱的錯合物，通常靠氫鍵 (hydrogen bonding)。
  2. 這兩種錯合物互為**非鏡像異構物**，結合能與錯合平衡常數不同。
  3. 結合較強的鏡像異構物移動較慢，較晚流出管柱。

#### 1-8-4　酵素法

- 酵素只處理外消旋物中的某一個鏡像異構物，另一個保持不變，藉此去除不要的立體異構物（課本應用欄）。
- 這種方法稱為**動力學離析 (kinetic resolution)**。

## 二、原理推導

### 2-1　立體異構物數目的計算

**(1) 2ⁿ 規則的由來**
- 每個掌性中心有兩種組態 (R/S)，n 個中心彼此獨立，所以組合數為 2 × 2 × … × 2 = 2ⁿ。
- 這只是**上限**：若分子有對稱性，部分組合會是同一個化合物。

**(2) 兩端相同的鏈狀分子（n 為偶數）**

例如酒石酸、2,3-二溴丁烷、己-2,3,4,5-四醇。

1. 把每個化合物寫成一個由 R/S 組成的字串，依編號順序排列，例如 RS、RRSS。
2. 分子兩端相同，所以從另一端編號會得到**倒過來的字串**。同一個化合物可能對應兩個字串，例如 RS 與 SR。
   （每個中心的 R/S 是該原子本身的性質，不會因為改從另一端編號而改變，所以字串只是倒過來，個別字母不變。）
3. 回文字串（倒過來仍相同，例如 RR、RSSR）共有 2^{n/2} 個，每個只對應自己。其餘字串兩兩成對。
4. 所以不同化合物的總數為：

$$N_{\text{總}} = \frac{2^n + 2^{n/2}}{2} = 2^{n-1} + 2^{\,n/2-1}$$

5. **內消旋**的條件是：鏡像（每個字母都換成相反的）等於倒過來的字串。符合條件的字串有 2^{n/2} 個，兩兩為同一化合物，所以：

$$N_{\text{meso}} = 2^{\,n/2-1}$$

| n | 總數 | 內消旋 | 掌性（成對） | 實例 |
|---|---|---|---|---|
| 2 | 3 | 1 | 2（1 對） | 酒石酸、2,3-二溴丁烷 |
| 4 | 10 | 2 | 8（4 對） | 己-2,3,4,5-四醇；由六碳醣氧化得到的醣二酸 (aldaric acids) |

**(3) 兩端相同的鏈狀分子（n 為奇數）**

例如 2,3,4-三溴戊烷 (2,3,4-tribromopentane)。
- 中間的碳在某些異構物中是「假不對稱 (pseudoasymmetric)」碳（見習題 5-37）。
- 結果為：

$$N_{\text{總}} = 2^{\,n-1}, \qquad N_{\text{meso}} = 2^{(n-1)/2}$$

| n | 總數 | 內消旋 | 掌性 |
|---|---|---|---|
| 3 | 4 | 2 | 2（1 對） |

### 2-2　為何內消旋必為 (R,S)，而 (±) 型為 (R,R)/(S,S)

設分子有兩個「結構相同」的掌性中心 C_a 與 C_b。

**情況一：分子有對稱面 σ，且 σ 把 C_a 映到 C_b**
- 鏡面反射使旋轉方向相反，而兩個中心上對應基團的優先順序相同。
- 所以 C_a 與 C_b 的組態**相反**：**(R,S)**，為內消旋。

**情況二：分子有一條 C₂ 旋轉軸，把 C_a 轉到 C_b**
- 旋轉不改變旋轉方向。
- 所以 C_a 與 C_b 的組態**相同**：**(R,R) 或 (S,S)**。
- 單有旋轉軸並不會使分子變成非掌性，所以這兩者是掌性的。

這解釋了 Part 4 例題 2 中 cis-1,3-二溴環己烷是 (1R,3S)、trans 是 (1R,3R)，以及 Part 2 中 trans-1,2-二溴環己烷是 (R,R) 的原因。

> 注意：這個規律只適用於**兩個不對稱碳的取代基組成完全相同**時。例如 2-溴-3-氯丁烷的 (2S,3R) 就不是內消旋（Part 4 習題 5-26(g) 的陷阱）。

### 2-3　為何鏡像異構物無法以一般方法分離，非鏡像異構物卻可以

**鏡像異構物**
1. 把整個系統照鏡子：在非掌性環境中（溶劑、容器、光線都非掌性），(R) 的任何能量或作用力都會對應到 (S) 的等值能量或作用力。
2. 所以兩者的沸點、溶解度、吸附強度完全相同，一般物理方法**不可能**把它們分開。

**非鏡像異構物**
- 它們並不互為鏡像，沒有任何對稱性強迫兩者的能量相等，所以物性一般不同，可以分離。

**離析的關鍵**：讓兩個鏡像異構物各自與**同一個**掌性離析劑 X(R) 作用：

$$\text{(R)·X(R)} \quad \text{與} \quad \text{(S)·X(R)}$$

- (R)·X(R) 的鏡像是 (S)·X(S)，**不是** (S)·X(R)。
- 所以 (R)·X(R) 與 (S)·X(R) 互為**非鏡像異構物**，能量不同，可以分離。
- 若離析劑本身是外消旋的，就會同時生成兩組鏡像對，等於什麼也沒分開。所以**離析劑必須是光學純的**。

**掌性層析的定量表示**：
- 兩個鏡像異構物與掌性固定相的錯合平衡常數分別為 K_R、K_S。
- 分離因子 (separation factor) 為：

$$\alpha_{\text{sep}} = \frac{K_R}{K_S} = e^{-(\Delta G_R - \Delta G_S)/RT}$$

- 結合自由能只要差 1 kcal/mol 左右，室溫下 α ≈ 5，就足以在管柱上明顯分開。

### 2-4　為何已有掌性中心的分子，反應後兩個新非鏡像異構物不等量

- 分子中已有一個掌性中心時，新掌性中心形成時的兩條路徑，其過渡態互為**非鏡像異構物**，而不是鏡像。
- 兩者能量不同（ΔΔG‡ ≠ 0），所以兩個產物的生成速率不同，比例不是 50:50。
- 這與 Part 3 推導 2-5 正好對照：
  - 非掌性環境下生成鏡像異構物 → 必定 1:1。
  - 已有掌性時生成非鏡像異構物 → 一般**不是** 1:1。
- 習題 5-36(e) 就是應用這一點。

### 2-5　D/L 與 (R)/(S) 的關係

- 甘油醛的 D 型恰好是 (R)，但這只是**巧合**。
- 例如：
  - 大多數 L-胺基酸是 (S)，但 L-半胱胺酸是 (R)，因為 –CH₂SH 的優先順序高於 –COOH（Part 2 例題 2）。
  - 對 D-醣類而言，最下方不對稱碳的 –CH₂OH 優先順序通常最低，該碳通常是 (R)，但其他碳不一定。
- **結論**：D/L 只能用費雪投影式中 OH 或 NH₂ 的左右來判斷，不能由 R/S 推導。

### 例題 3：列出所有立體異構物（課本 Problem 5-22）

**題目**：畫出下列化合物所有不同的立體異構物，並說明彼此的關係。

**詳解**：

**(a) CH₃–CHCl–CHOH–COOH，3-氯-2-羥基丁酸 (3-chloro-2-hydroxybutanoic acid)**
- n = 2，兩個中心的取代基不同，沒有內消旋。
- 共 **4 個**：(2R,3R)/(2S,3S) 為一對，(2R,3S)/(2S,3R) 為另一對。

**(b) 酒石酸，HOOC–CHOH–CHOH–COOH**
- 共 **3 個**：(R,R) 與 (S,S) 為一對鏡像異構物；(R,S) 為內消旋，與前兩者都是非鏡像異構物。

```
   (2R,3R)       (2S,3S)        內消旋 (2R,3S)
    COOH          COOH              COOH
  H ─┼─ OH     HO ─┼─ H          H ─┼─ OH
 HO ─┼─ H       H ─┼─ OH         H ─┼─ OH   ← σ
    COOH          COOH              COOH
```

> 驗算 (2R,3R)：
> - **C2**：優先順序為 OH > COOH (O,O,O) > C3 (O,C,H)。OH（右）→ COOH（上）→ C3（下），查 Part 4 速查表為 R。✓
> - **C3**：優先順序為 OH > COOH（下）> C2（上）。OH（左）→ COOH（下）→ C2（上），查速查表為 R。✓

**(c) HOOC–CHBr–CHOH–CHOH–COOH，2-溴-3,4-二羥基戊二酸 (2-bromo-3,4-dihydroxypentanedioic acid)**
- n = 3，兩端雖然都是 COOH，但 C2 帶 Br、C4 帶 OH，**分子並不對稱**，不可能有 σ。
- 共 **2³ = 8 個**，構成 4 對鏡像異構物，沒有內消旋。

**(e) 型（與課本 5-22(e) 同類）：3,5-二甲基環己醇 (3,5-dimethylcyclohexan-1-ol)**
- 帶 OH 的 C1 兩側環路徑相同，**不是不對稱碳**。C3、C5 是不對稱碳。
- **兩個 CH₃ 為 cis**：
  - 有通過 C1、C4 的 σ。
  - OH 可以與兩個 CH₃ 同側或反側，得到 **2 個非掌性的非鏡像異構物**。
  - 此時 C1 是**立體中心**，但不是掌性中心（課本提示欄）。
- **兩個 CH₃ 為 trans**：
  - 交換 C1 上的 OH 與 H，得到的是同一個分子，所以 C1 不是立體中心。
  - 分子具掌性，得到 **1 對鏡像異構物**。
- 共 **4 個**：2 個非掌性加 1 對鏡像異構物。這與習題 5-37 是同一個模式。

### 例題 4：可否用一般方法分離（課本 Problem 5-23、5-24）

**題目**：
- 5-23：判斷下列各組能否以再結晶或蒸餾分離。
- 5-24：畫出 (R)-2-丁基 (R,R)-酒石酸酯與 (S)-2-丁基 (R,R)-酒石酸酯的鏡像並命名，說明兩者不是鏡像異構物。

**詳解**：

**5-23(a) 內消旋酒石酸與 (±)-酒石酸**
- 兩者是**非鏡像異構物**，所以**可以分離**。
- 但分離出來的 (±)-酒石酸仍是外消旋物。要再把它分成 (+) 與 (−)，必須進行離析。

**5-23(d) 一對酸鹼鹽 (acid–base salt)**
- 兩者分別是 (R)-1-苯基丙-2-銨 ((R)-1-phenylpropan-2-ammonium) 與 (S)-1-苯基丙-2-銨，各自與同一個 (R,R)-酒石酸根 (tartrate) 形成鹽。
- 兩者是**非鏡像異構物**，所以**可以分離**。這正是**化學離析胺類**的標準做法：用光學純的酸形成非鏡像異構鹽，再結晶分離後加鹼游離出胺。

**5-24**
- 鏡像要把**每一個**掌性中心都反轉：
  - (R)-2-丁基 (R,R)-酒石酸酯的鏡像是 **(S)-2-丁基 (S,S)-酒石酸酯**。
  - (S)-2-丁基 (R,R)-酒石酸酯的鏡像是 **(R)-2-丁基 (S,S)-酒石酸酯**。
- 兩個酯的鏡像都不是對方，所以 (R)-2-丁基 (R,R)-酒石酸酯與 (S)-2-丁基 (R,R)-酒石酸酯是**非鏡像異構物**。
- 這正是化學離析之所以可行的原因。

**題目**：判斷下列化合物是 D 型還是 L 型，並說明 D/L 與旋光方向、(R)/(S) 的關係。
(a) CHO／H–OH／HO–H／H–OH／H–OH／CH₂OH
(b) CHO／HO–H／H–OH／CH₂OH

## 四、整理比較表

### 4-1　鏡像異構物與非鏡像異構物

| 項目 | 鏡像異構物 | 非鏡像異構物 |
|---|---|---|
| 定義 | 互為不可重疊的鏡像 | 不互為鏡像的立體異構物 |
| 掌性中心的組態 | **全部**相反 | **部分**相反 |
| 非掌性環境中的物性 | 完全相同 | 一般都不同 |
| 旋光度 | 大小相等、方向相反 | 沒有固定關係 |
| 與掌性試劑的反應 | 不同 | 不同 |
| 能否用蒸餾、再結晶、一般層析分離 | 不能，必須離析 | 可以 |
| 例子 | (R)- 與 (S)-丁-2-醇 | cis- 與 trans-丁-2-烯；赤藻糖與蘇糖 |

### 4-2　判斷兩個結構關係的流程

```
兩個結構的分子式相同？
 ├─ 否 → 不是異構物
 └─ 是 → 鍵結順序相同？
          ├─ 否 → 結構異構物
          └─ 是 → 能否重疊（含旋轉、構形變化）？
                   ├─ 能 → 同一化合物
                   │        （內消旋化合物的 (R,S) 與 (S,R) 屬於此類）
                   └─ 不能 → 互為鏡像？
                            ├─ 是 → 鏡像異構物
                            │        （所有掌性中心都反轉）
                            └─ 否 → 非鏡像異構物
                                     （部分反轉，或雙鍵、環上的順反不同）
```

**實用做法**：寫出兩個結構的 (R)/(S) 字串來比較。
- 全部相同 → 同一化合物。
- 全部相反 → 鏡像異構物；但若分子是內消旋，全部相反後仍是同一化合物。
- 部分相反 → 非鏡像異構物。

### 4-3　三套組態與旋光符號

| 符號 | 意義 | 決定方式 | 舉例 |
|---|---|---|---|
| (R)/(S) | 絕對組態 | CIP 規則 | (R)-甘油醛 |
| D/L | 相對組態 | 費雪投影式中最下方不對稱碳的 OH 或 NH₂ 在右 → D，在左 → L | D-甘油醛 |
| (+)/(−)，或 *d*/*l* | 旋光方向 | 旋光計測量 | (+)-甘油醛 |
| (±) 或 (*d,l*) | 外消旋 | 等量混合 | (±)-丁-2-醇 |
| meso | 內消旋 | 有掌性中心但非掌性 | 內消旋酒石酸 |
| cis/trans | 環或雙鍵上的相對位置 | 取代基同側／異側 | cis-1,2-二甲基環戊烷 |

### 4-4　離析方法比較

| 方法 | 原理 | 優點 | 限制 |
|---|---|---|---|
| Pasteur 手工挑選晶體 | 外消旋物結晶成互為鏡像的兩種晶體 | 不需要離析劑 | 只有極少數化合物適用 |
| 化學離析 | 與光學純離析劑生成非鏡像異構物，分離後再切除離析劑 | 普遍適用於酸、鹼、醇等 | 需要可逆的化學反應；離析劑可能昂貴 |
| 掌性層析 | 鏡像異構物與掌性固定相形成非鏡像異構錯合物，結合強度不同 | 可同時用於分析與分離 | 掌性管柱成本高 |
| 酵素法（動力學離析） | 酵素只轉化其中一個鏡像異構物 | 選擇性極高 | 理論產率最多 50% |

### 4-5　常見陷阱

| 錯誤想法 | 正確觀念 |
|---|---|
| (R,S) 一定是內消旋 | 兩個中心的取代基必須相同，例如 2-溴-3-氯丁烷的 (2S,3R) 是掌性的 |
| 只要有 n 個不對稱碳，就一定有 2ⁿ 個異構物 | 2ⁿ 只是上限，內消旋會使數目減少 |
| 鏡像異構物只要反轉一個中心 | 必須**全部**反轉，只反轉一個得到的是非鏡像異構物 |
| 內消旋化合物是外消旋混合物 | 內消旋是**單一化合物**；外消旋是兩個化合物的等量**混合物**，兩者旋光度都是 0 |
| D 型就是右旋，或 D 型就是 (R) | 三者無關 |
| 離析劑可以是外消旋的 | 必須光學純，否則只會形成兩組鏡像對 |
| 非鏡像異構物一定等量生成 | 已有掌性中心時，生成的量一般不相等 |

### 習題 5-36\*（課本標示較難）

**題目**：下列化合物進行自由基溴化 (free-radical bromination) 時，溴主要取代在與苯環相鄰的**苯甲位 (benzylic position)**。若反應停在單溴化階段，會得到兩個立體異構物。

依課本圖，起始物為 1-苯基丙-2-醇 (1-phenylpropan-2-ol)，PhCH₂–CH(OH)–CH₃，C2 具有確定的組態；以下設為 (2S)。

(a) 提出反應機構，說明為何自由基鹵化幾乎只發生在苯甲位。
(b) 畫出在苯甲位單溴化所得的兩個立體異構物。
(c) 標出產物中不對稱碳的 (R)/(S)。
(d) 兩個產物是什麼關係？
(e) 兩個產物的生成量是否相同，也就是說，產物混合物是否恰好 50:50？
(f) 兩個產物的沸點、熔點、溶解度等物理性質是否相同？理論上能否用蒸餾或再結晶分離？

**詳解**：

**(a) 反應機構與選擇性**

起始 (initiation)：

$$\mathrm{Br_2} \xrightarrow{h\nu} 2\,\mathrm{Br}\cdot$$

傳遞 (propagation)：

$$\mathrm{PhCH_2R} + \mathrm{Br}\cdot \rightarrow \mathrm{Ph\dot{C}HR} + \mathrm{HBr}$$
$$\mathrm{Ph\dot{C}HR} + \mathrm{Br_2} \rightarrow \mathrm{PhCHBrR} + \mathrm{Br}\cdot$$

選擇性的來源：
- 苯甲位自由基 (benzylic radical) 的未成對電子可以**共振 (resonance)** 到苯環的鄰位與對位，非常穩定。
- 所以苯甲位 C–H 鍵的鍵解離能 (bond dissociation energy) 特別低，約 85–90 kcal/mol；一般二級 C–H 約 95–98 kcal/mol。
- 溴原子奪氫的步驟是吸熱的，依 Hammond 假說 (Hammond postulate)，過渡態接近自由基產物，對自由基的穩定性非常敏感。
- 因此溴化具有很高的選擇性，幾乎只發生在苯甲位。

**(b) 兩個產物**
- 產物為 1-溴-1-苯基丙-2-醇 (1-bromo-1-phenylpropan-2-ol)，PhCHBr–CH(OH)–CH₃。
- 新的掌性中心 C1 可以是 R 或 S；原有的 C2 沒有參與反應，組態不變。

**(c) 組態**

| 碳 | 優先順序 | 組態 |
|---|---|---|
| C1 | Br > C2（連 O, C, H）> C₆H₅ (C,C,C) > H | 兩個產物分別為 R 與 S |
| C2 | OH > C1 > CH₃ > H | 反應前後都是 S |

C2 在反應前的優先順序是 OH > CH₂Ph (C,H,H) > CH₃ > H；反應後 C1 變成 CHBrPh (Br,C,H)，仍然排第 2。優先順序沒變、空間排列也沒變，所以 C2 仍是 (S)。

兩個產物為 **(1R,2S)** 與 **(1S,2S)**-1-溴-1-苯基丙-2-醇。

**(d)** 只有 C1 不同，所以兩者是**非鏡像異構物**。

**(e) 不會是 50:50。**
- 苯甲位自由基是平面的，Br₂ 可以從上下兩面進攻。
- 但分子中已經有 (S)-C2，兩面進攻的過渡態互為**非鏡像異構物**，能量不同（推導 2-4）。
- 所以兩個產物的生成速率不同，比例一般不是 50:50。
- 與 Part 3 的丁-2-酮氫化對照：那裡沒有原有的掌性中心，產物必定是 50:50。

**(f) 物理性質不同。**
- 非鏡像異構物的沸點、熔點、溶解度一般都不同。
- 所以**理論上可以**用蒸餾或再結晶分離。

### 習題 5-37\*（課本標示較難）

**題目**：如果你覺得自己已經掌握這些定義，試試這道難題。
(a) 畫出 2,3,4-三溴戊烷 (2,3,4-tribromopentane) 的所有立體異構物（用費雪投影式會比較方便）。你應該會得到兩個內消旋結構與一對鏡像異構物。
(b) 標出不對稱碳，並逐一標 (R)/(S)。
(c) 說明在內消旋結構中，C3 既不是不對稱碳，也不是掌性中心，卻是一個立體中心。
(d) 說明在鏡像異構物中，C3 不是立體中心。

**詳解**：

**(a)** 費雪投影式由上而下為：CH₃／C2／C3／C4／CH₃。

| 異構物 | C2 | C3 | C4 | 對稱 | 性質 |
|---|---|---|---|---|---|
| 內消旋 I | H–Br | H–Br | H–Br | 通過 C3 的水平 σ | 非掌性 |
| 內消旋 II | H–Br | Br–H | H–Br | 通過 C3 的水平 σ | 非掌性 |
| 鏡像異構物 III | H–Br | H–Br | Br–H | 無 σ | 掌性 |
| 鏡像異構物 III′ | Br–H | Br–H | H–Br | 無 σ | 掌性，為 III 的鏡像 |

- III 中 C3 的 Br 若改放在左邊，把整個投影式轉 180° 後會回到 III，所以是同一個化合物。因此 III 只有一種，沒有另一個 C3 異構物（見 (d)）。
- 共 **4 個**立體異構物，少於 2³ = 8。這與推導 2-1 的 n 為奇數公式一致：總數 2² = 4，內消旋 2¹ = 2。

**(b) 組態**

C2 的優先順序為 Br > C3（連 Br, C, H）> CH₃ > H；C4 同理，只是 C3 在上、CH₃ 在下。

| 異構物 | C2 | C4 | 標記 |
|---|---|---|---|
| 內消旋 I、II | Br 在右：Br（右）→ C3（下）→ CH₃（上），為 S | Br 在右：Br（右）→ C3（上）→ CH₃（下），為 R | (2S,4R)，等同 (2R,4S) |
| III | S | Br 在左，為 S | **(2S,4S)** |
| III′ | R | R | **(2R,4R)** |

C3 在 I、II 中是**假不對稱碳 (pseudoasymmetric carbon)**，用小寫的 r/s 表示：
- 依 CIP 規則，在其他條件相同時，(R) 分支的優先順序高於 (S) 分支。
- 所以 C3 的優先順序為 Br > C4(R) > C2(S) > H。
- 內消旋 I：Br（右）→ C4（下）→ C2（上），為 **s**，全名 (2R,3s,4S)。
- 內消旋 II：Br（左）→ C4（下）→ C2（上），為 **r**，全名 (2R,3r,4S)。

（r/s 屬於延伸內容，課本並不要求。）

**(c) 內消旋結構中的 C3**
- **不是不對稱碳**：C3 連接的兩個 –CHBrCH₃ 在**結構上**完全相同，鍵結順序一樣。
- **不是掌性中心**：C3 位於 σ 上，整個分子是非掌性的；而且 C3 周圍的排列經 σ 反射後與自身重合。
- **卻是立體中心**：交換 C3 上的 H 與 Br，內消旋 I 會變成內消旋 II。兩者都非掌性、不互為鏡像，是兩個不同的化合物（非鏡像異構物）。依立體中心的定義（交換兩基團會得到立體異構物），C3 是立體中心。
- 這說明了 Part 1 的包含關係：**不對稱碳 ⊂ 掌性中心 ⊂ 立體中心**，而且三者確實不同。

**(d) 鏡像異構物中的 C3**
- 在 III 中交換 C3 上的 H 與 Br，得到的投影式轉 180° 後與 III 完全相同，也就是**同一個化合物**。
- 交換兩基團沒有產生新的立體異構物，所以 C3 **不是立體中心**。
- 原因：III 的 C2 與 C4 組態相同（S, S），兩個分支 –C*HBrCH₃ 不只結構相同，連立體組態也相同，所以 C3 連接了兩個完全一樣的基團。

### 習題 5-40\*（課本標示較難）

**題目**：D-(−)-赤藻糖 (D-(−)-erythrose) 的分子式為 HOCH₂–CH(OH)–CH(OH)–CHO。
- 名稱中的 D 表示它可以降解成 D-(+)-甘油醛。
- 名稱中的 (−) 表示它具旋光性，且為左旋。
- D-(−)-赤藻糖以 H₂ 與鎳觸媒還原後，得到**不具旋光性**的產物 HOCH₂–CH(OH)–CH(OH)–CH₂OH。

已知 D-(+)-甘油醛的絕對組態（5-14），決定 D-(−)-赤藻糖的絕對組態。

**詳解**：

**步驟 1：由 D 決定 C3**
- D 表示 C3（最下方的不對稱碳）的組態與 D-(+)-甘油醛相同。
- D-(+)-甘油醛是 (R)，費雪投影式中 OH 在右。
- 所以赤藻糖的 C3 在費雪投影式中 **OH 在右**。

**步驟 2：由還原產物不具旋光性決定 C2**
- 還原把 CHO 變成 CH₂OH，產物丁-1,2,3,4-四醇 (butane-1,2,3,4-tetrol) 的兩端相同。
- 產物有兩種可能：
  - 若 C2 的 OH 也在**右**：CH₂OH／H–OH／H–OH／CH₂OH，有水平的 σ，是**內消旋**，不具旋光性（赤藻糖醇 erythritol）。
  - 若 C2 的 OH 在**左**：CH₂OH／HO–H／H–OH／CH₂OH，沒有 σ，具掌性，有旋光性（蘇糖醇 threitol）。
- 題目說產物不具旋光性，所以 **C2 的 OH 在右**。

**步驟 3：寫出結構並判定組態**
- D-(−)-赤藻糖為 **CHO／H–OH／H–OH／CH₂OH**。
- **C2**：優先順序為 OH > CHO (O,O,H) > C3 (O,C,H) > H。OH（右）→ CHO（上）→ C3（下），查速查表為 **R**。
- **C3**：優先順序為 OH > C2 (O,C,H) > CH₂OH (O,H,H) > H。OH（右）→ C2（上）→ CH₂OH（下），查速查表為 **R**。

答：**D-(−)-赤藻糖為 (2R,3R)-2,3,4-三羥基丁醛 ((2R,3R)-2,3,4-trihydroxybutanal)**

> 方法論：這題結合了三種資訊：
> - **D**：相對組態，決定一個中心。
> - **內消旋判斷**：對稱性，決定兩個中心之間的相對關係。
> - **甘油醛的絕對組態**：X 射線晶體繞射的結果，把相對組態轉換成絕對組態。
>
> 這正是 1951 年以前化學家建立醣類組態的方式（Fischer 證明葡萄糖結構的思路）。

```
異構物 isomers
 ├─ 結構異構物 constitutional isomers
 └─ 立體異構物 stereoisomers（組態異構物 configurational isomers）
     ├─ 鏡像異構物 enantiomers

         └─ 多掌性中心的非鏡像異構物（含內消旋化合物 meso compounds）

```

### 二、各份重點

|---|---|---|
| Part 1 | 掌性與對稱 | 有 σ 或 i 必非掌性；只有一個不對稱碳必為掌性 |
| Part 2 | (R)/(S) | 依原子序逐層比較；最低優先基團朝後時，順時針為 R |
| Part 3 | 旋光性 | [α] = α/(c·l)；化學純樣品 o.p. = e.e.；非掌性環境下只能得到外消旋物 |
| Part 4 | 構形與費雪投影式 | 用最對稱構形判斷；丙二烯、聯苯有軸掌性；費雪投影式可轉 180°、不可轉 90° |
| Part 5 | 非鏡像異構物與離析 | 部分反轉即為非鏡像異構物；內消旋為 (R,S)；先轉成非鏡像異構物才能離析 |

### 四、考前自我檢查清單

- [ ] 能在 30 秒內判斷一個分子有沒有 σ，並說出它是否具掌性。
- [ ] 能正確排出含雙鍵、環、同位素的基團優先順序。
- [ ] 遇到最低優先基團朝前或在紙面上時，不會忘記反判。
- [ ] 比旋光度計算時，c 用 g/mL、l 用 dm。
- [ ] 知道 (R)/(S)、(+)/(−)、D/L 三者互不相關。
- [ ] 費雪投影式只轉 180°；畫鏡像時對調所有橫線上的基團。
- [ ] 能用 2ⁿ 規則列出所有立體異構物，並找出內消旋化合物。
- [ ] 能說出鏡像異構物為何必須離析，以及離析劑為何必須光學純。
