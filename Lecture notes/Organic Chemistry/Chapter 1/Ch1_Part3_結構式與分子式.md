# 結構式的種類與分子式計算

## 一、結構式的三種類型（Types of Structural Formulas）

有機化學家依需求使用三種詳簡程度不同的結構式：

| 類型 | 英文名稱 | 詳簡程度 | 主要用途 |
|------|---------|---------|---------|
| 路易士結構式（Lewis structure）| full structural formula | 最詳細 | 強調電子分布、孤對電子 |
| 簡縮結構式（condensed structural formula）| condensed structure | 中等 | 日常書寫、快速表達連接方式 |
| 線角式（line-angle formula）| skeletal structure / stick figure | 最簡潔 | 有機化學最常用，尤其是環狀化合物 |

---

## 二、簡縮結構式（Condensed Structural Formulas）

### 2.1 書寫規則

- 每個碳原子與連接在其上的原子**合併書寫**，鍵結線通常省略
- 多個相同基團可用括號和下標表示
- **孤對電子通常省略**（需要時再補充）
- 多重鍵（雙鍵、三鍵）通常保留標示

### 2.2 常見對照表

| 分子名稱 | 路易士結構式（示意）| 簡縮結構式 |
|---------|------------------|----------|
| 正己烷（n-hexane）| H–C–C–C–C–C–C–H（全展開）| **CH₃(CH₂)₄CH₃** |
| 異丁烷（isobutane）| 分支結構 | **(CH₃)₃CH** |
| 乙烷（ethane）| H₃C–CH₃ | **CH₃CH₃** |
| 乙醇（ethanol）| H₃C–CH₂–OH | **CH₃CH₂OH** |
| 異丙醇（isopropyl alcohol）| (CH₃)₂CHOH | **(CH₃)₂CHOH** |
| 二乙醚（diethyl ether）| CH₃CH₂–O–CH₂CH₃ | **CH₃CH₂OCH₂CH₃** 或 **(CH₃CH₂)₂O** |
| 二甲胺（dimethylamine）| (CH₃)₂NH | **(CH₃)₂NH** |

### 2.3 含多重鍵的簡縮結構式

> **注意**：某些縮寫表面看起來連接方式不直觀，但須依八隅體規則理解

| 分子名稱 | 簡縮結構式 | 說明 |
|---------|----------|------|
| but-2-ene（丁-2-烯）| CH₃CH=CHCH₃ 或 **CH₃CH**=**CHCH₃** | C=C 雙鍵標示 |
| 乙醛（acetaldehyde）| **CH₃CHO** | –CHO 中 C 連接 H 和 =O，非字面意思的 C–H–O |
| 乙酸（acetic acid）| **CH₃COOH** 或 CH₃CO₂H | –COOH 代表羧基（carboxyl group）|
| 丙酮（acetone）| **CH₃COCH₃** 或 CH₃C(=O)CH₃ | C=O 為羰基（carbonyl group）|
| 乙腈（acetonitrile）| **CH₃CN** 或 CH₃C≡N | C≡N 為腈基（nitrile group）|

```
特別注意：CH₃CHO（乙醛）的真實連接：

      O
      ‖
  H₃C–C–H    ← 醛基（aldehyde group, –CHO）中的 C 連接一個 H 和一個 =O
             （不是 C–H–O 線性連接！）
```

## 三、線角式（Line-Angle Formulas）

### 3.1 基本規則

- **折線的每個端點和頂點**代表一個 **C 原子**（除非另有標示）
- **H 原子不畫出**，每個 C 原子預設有足夠的 H 使其形成 **4 個鍵**
- **雜原子（N、O、鹵素）** 必須標示出來
- 雜原子上的 H 必須畫出（如 –OH 中的 H、–NH– 中的 H）
- 孤對電子通常省略
- **雙鍵和三鍵**保留畫出（用 = 或 ≡）

### 3.2 線角式的讀法示範

```
範例 1：己烷（hexane, C₆H₁₄）

   /\/\/      =  CH₃CH₂CH₂CH₂CH₂CH₃

每個頂點或端點 = 1 個 C；共 6 個 C
```

```
範例 2：己-2-烯（hex-2-ene）

   /\=/\/     =  CH₃CH=CHCH₂CH₂CH₃
       ↑
     雙鍵（double bond）
```

```
範例 3：己-3-醇（hexan-3-ol）

   /\/OH\/    =  CH₃CH₂CH(OH)CH₂CH₂CH₃
        ↑
     O 要標出，旁邊的 H 也要標
```

```
範例 4：環己-2-烯-1-酮（cyclohex-2-en-1-one）

      O
      ‖
    /   \
   |     |      ← 六員環（six-membered ring），含 C=O 和 C=C
    \   /
     ‖
```

### 3.3 線角式轉換練習框架

**線角式 → Lewis 結構** 的步驟：

```
步驟一：在每個頂點和端點補上 C 原子
步驟二：計算每個 C 需要多少個 H（4 − 已有的鍵數 = H 數）
步驟三：標示雜原子的孤對電子（若需要）
```

**例：線角式轉換**

```
線角式：                    Lewis 結構：

  OH                              OH
   |                               |
  /\                        H₃C–C–CH₃
                                   |
                                   H

（2-甲基丙-2-醇，2-methylpropan-2-ol）

→ 頂點有 3 個鍵（2 個 C–C + 1 個 C–OH），故需 1 個 H
  兩個端點各有 1 個鍵，各需 3 個 H（CH₃）
```

## 四、分子式與實驗式（Molecular and Empirical Formulas）

### 4.1 兩者的區別

| 名稱 | 定義 | 給出的信息 |
|------|------|----------|
| 實驗式（empirical formula）| 元素組成的**最簡整數比** | 各元素的比例，不含結構信息 |
| 分子式（molecular formula）| 一個分子中各元素原子的**實際數目** | 原子個數，不含結構信息 |

```
例：葡萄糖（glucose）
  實驗式：CH₂O（最簡比 C:H:O = 1:2:1）
  分子式：C₆H₁₂O₆（實際原子個數）
  分子量：180 g/mol
```

### 4.2 由元素分析（Elemental Analysis）計算實驗式

**步驟：**

```
步驟一：假設樣品為 100 g
        → 各元素的質量（g）= 其百分比數值
        → 若百分比加總不到 100%，差額通常為氧（O）

步驟二：各元素質量 ÷ 原子量 = 莫耳數（moles of atoms）

步驟三：各莫耳數 ÷ 最小的莫耳數 → 最簡整數比

步驟四：若比值不為整數（如 1.5、1.33 等），則乘以適當倍數使其全為整數
```

### 4.3 由分子量決定分子式

```
分子式 = 實驗式 × n

其中 n = 分子量（MW）÷ 實驗式量（empirical formula weight）
n 必須為正整數
```

**分子量測定方法：**
- 凝固點下降法（freezing-point depression）
- 沸點上升法（boiling-point elevation）
- 氣體狀態下用氣體定律（gas law）
- **質譜法（mass spectrometry）**——現代最精準，將在 Chapter 12 介紹

## 五、課本例題精講

### 例題 1（Problem 1-11）：簡縮結構式 → Lewis 結構

**題目**：畫出 CH₂=CHCHO 的完整 Lewis 結構。

**解析：**

CH₂=CHCHO 由三部分拆解：

```
CH₂=CH–    （乙烯基 vinyl group，含 C=C）
      CH=O  （醛基 aldehyde group，含 C=O）
```

完整 Lewis 結構：

```
  H   H   H
  |   |   |
  C = C – C = O:

（從左到右：CH₂= 接 CH– 接 CHO）

每個碳都有 4 個鍵（八隅體）：
  C1（左端）：=C– 有 2 個 H，1 個雙鍵 → 4 個鍵 ✓
  C2（中間）：接 C1（雙鍵）和 C3（單鍵）和 H → 4 個鍵 ✓
  C3（右端）：接 C2（單鍵）和 =O 和 H → 4 個鍵 ✓
  O：2 個鍵（= C），2 個孤對 ✓
```

### 例題 2（Problem 1-14a）：元素分析 → 分子式

**題目**：某化合物 A 的元素分析結果：C 40.0%，H 6.67%，N 和 Cl 均無。分子量約為 90。求分子式，並提出一個可能結構。

**解析：**

**步驟一：計算 O 的比例**

```
100% − 40.0%（C）− 6.67%（H）= 53.33%（O）
```

**步驟二：計算各元素莫耳數（假設 100 g 樣品）**

```
n(C) = 40.0 g ÷ 12.0 g/mol = 3.33 mol
n(H) = 6.67 g ÷ 1.01 g/mol = 6.60 mol
n(O) = 53.33 g ÷ 16.0 g/mol = 3.33 mol
```

**步驟三：除以最小值，求最簡比**

```
最小值 = 3.33 mol

C : H : O = 3.33/3.33 : 6.60/3.33 : 3.33/3.33
          = 1 : 1.98 : 1
          ≈ 1 : 2 : 1

實驗式（empirical formula）= CH₂O
```

**步驟四：由分子量求分子式**

```
實驗式量（empirical formula weight）= 12 + 2(1) + 16 = 30 g/mol

n = MW ÷ 實驗式量 = 90 ÷ 30 = 3

分子式（molecular formula）= (CH₂O)₃ = C₃H₆O₃
```

**步驟五：提出可能結構**

C₃H₆O₃ 有許多可能結構，例如：

```
可能結構之一：3-羥基丙醛（3-hydroxypropanal）
HO–CH₂–CH₂–CHO

可能結構之二：甲酸乙酯（ethylene formate / 環狀碳酸酯）
等...（此分子式有多種可能）
```

### 例題 3（Problem 1-13）：Lewis 結構 → 線角式

**題目**：將 CH₃(CH₂)₃CH(CH₃)₂ 畫成線角式。

**解析：**

首先解析分子結構：
```
CH₃(CH₂)₃CH(CH₃)₂ = CH₃–CH₂–CH₂–CH₂–CH(CH₃)₂

= 4 碳直鏈 + 第 5 碳上有兩個甲基（isopropyl 基）
```

對應的線角式：

```
   /\/\/\    ← 主鏈 5 個碳（5 個頂點/端點）
         \/  ← 第 5 號碳（有分支）另有一個甲基
          |
          甲基（向下）
```

畫法：主鏈 4 個 CH₂ 及末端 CH 形成 zigzag，末端碳再往兩個方向各伸出一個短線代表兩個甲基。

## 六、進階例題（選自課後習題）

### 進階例題 A（Problem 1-47）★

**題目**：化合物 X 含 62.0% C 和 10.4% H，無 N 和鹵素，分子量約 117。求分子式，並畫出四個可能結構。

**解析：**

**步驟一：計算 O 的比例**
```
O% = 100 − 62.0 − 10.4 = 27.6%
```

**步驟二：計算莫耳數（100 g 樣品）**
```
n(C) = 62.0/12.0 = 5.17 mol
n(H) = 10.4/1.01 = 10.30 mol
n(O) = 27.6/16.0 = 1.73 mol
```

**步驟三：求最簡比**
```
最小值 = 1.73

C : H : O = 5.17/1.73 : 10.30/1.73 : 1.73/1.73
          = 2.99 : 5.95 : 1.00
          ≈ 3 : 6 : 1

實驗式 = C₃H₆O
實驗式量 = 3(12) + 6(1) + 16 = 58 g/mol
```

**步驟四：求分子式**
```
n = 117 ÷ 58 ≈ 2.02 ≈ 2

分子式 = (C₃H₆O)₂ = C₆H₁₂O₂
```

**步驟五：四個可能結構**

```
(1) 己酸（hexanoic acid）：
    CH₃(CH₂)₄COOH        → C₆H₁₂O₂ ✓（羧酸 carboxylic acid）

(2) 甲酸戊酯（pentyl formate）：
    HCOO–CH₂CH₂CH₂CH₂CH₃ → C₆H₁₂O₂ ✓（酯 ester）

(3) 丁酸乙酯（ethyl butanoate）：
    CH₃CH₂CH₂COO–CH₂CH₃   → C₆H₁₂O₂ ✓（酯 ester）

(4) 4-甲基戊酸（4-methylpentanoic acid）：
    (CH₃)₂CHCH₂CH₂COOH     → C₆H₁₂O₂ ✓（羧酸，有支鏈）
```

### 進階例題 B（Problem 1-48）★★

**題目**：1934 年 Doisy 燃燒 5.00 mg 雌二醇（estradiol），得到 14.54 mg CO₂ 和 3.97 mg H₂O。已知分子量為 272，求分子式。

**解析：**

**步驟一：從 CO₂ 和 H₂O 計算 C、H 的質量**

```
n(CO₂) = 14.54 mg ÷ 44.0 g/mol = 0.3305 mmol
→ n(C) = 0.3305 mmol
→ m(C) = 0.3305 × 12.0 = 3.966 mg

n(H₂O) = 3.97 mg ÷ 18.0 g/mol = 0.2206 mmol
→ n(H) = 2 × 0.2206 = 0.4411 mmol
→ m(H) = 0.4411 × 1.01 = 0.4455 mg
```

**步驟二：計算 O 的質量（差量法）**

```
m(O) = 5.00 − 3.966 − 0.4455 = 0.589 mg
n(O) = 0.589 mg ÷ 16.0 g/mol = 0.0368 mmol
```

**步驟三：求莫耳比**

```
C : H : O = 0.3305 : 0.4411 : 0.0368

÷ 0.0368：
C : H : O = 8.98 : 11.99 : 1.00 ≈ 9 : 12 : 1

實驗式 = C₉H₁₂O
實驗式量 = 9(12) + 12(1) + 16 = 136 g/mol
```

**步驟四：求分子式**

```
n = 272 ÷ 136 = 2

分子式 = (C₉H₁₂O)₂ = C₁₈H₂₄O₂
```

**答：雌二醇（estradiol）的分子式為 C₁₈H₂₄O₂**

## 七、本節重點整理

### 三種結構式比較

| 結構式類型 | 顯示孤對電子？ | 顯示 H？ | 顯示多重鍵？ | 最適合用於 |
|-----------|-------------|---------|------------|----------|
| Lewis 結構式 | ✓ | ✓ | ✓ | 強調電子分布 |
| 簡縮結構式（condensed）| 通常省略 | ✓ | ✓ | 日常書寫 |
| 線角式（line-angle）| 省略 | 省略（C 上）| ✓ | 複雜有機結構、環狀化合物 |

### 線角式讀法要點

| 規則 | 說明 |
|------|------|
| 每個折點/端點 = C 原子 | 若有標示其他符號（O、N、Cl 等），則為該雜原子 |
| C 上的 H 省略 | 每個 C 假設有足夠 H 使之形成 4 個鍵 |
| 雜原子上的 H 要畫出 | 如 –OH、–NH–、–NH₂ |
| 多重鍵要標示 | 雙鍵（=）、三鍵（≡）保留 |

### 分子式計算流程

```
元素分析數據（%C, %H, %O, ...）
        ↓  假設 100 g，各 % = 各元素克數
各元素莫耳數 = 克數 ÷ 原子量
        ↓  ÷ 最小莫耳數
最簡整數比
        ↓  確認為整數比（必要時 × 倍數）
實驗式（empirical formula）
        ↓  + 分子量數據
n = MW ÷ 實驗式量
        ↓
分子式（molecular formula）= 實驗式 × n
```
