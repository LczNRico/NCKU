## 一、有機化學的起源（Origins of Organic Chemistry）

**有機化學（organic chemistry）** 的現代定義：**碳化合物（carbon compounds）的化學**。

### 1.1 活力論的興衰（Vitalism and Its Disproof）

早期科學家認為有機化合物只能來自生物體，帶有「**活力（vital force）**」，此觀念稱為**活力論（vitalism）**。

| 時期 | 觀點 |
|------|------|
| 早期 | 有機物需活力（vital force）才能生成，無機物不具活力 |
| 1828 年後 | 活力論被推翻 |

**關鍵實驗**：1828 年，德國化學家 **Friedrich Wöhler** 加熱無機物碳酸銨（ammonium cyanate），得到有機物尿素（urea）：

```
NH₄⁺ ⁻OCN  →(加熱 heat)  H₂N–C(=O)–NH₂
碳酸銨（inorganic）         尿素（organic）
```

> **意義**：有機化合物可由無機物合成，打破了「有機 = 生命產物」的迷思。

### 1.2 碳的特殊性（Why Carbon?）

碳之所以成為有機化學的核心，在於它能：

- 與其他碳原子形成**強的 C–C 鍵（strong C–C bonds）**
- 形成**長鏈（chains）**與**環（rings）**
- 與 H、O、N、S、鹵素等多種元素成鍵
- 構成幾乎無限種類的分子

> **現代活力論的殘影**：現代社會仍有人相信「天然」（natural）維生素優於「人工合成」（synthetic）的相同化合物。化學上兩者完全相同，唯一可辨別的方式是測量 ¹⁴C 含量（天然產物含量較高）。

## 二、原子結構（Atomic Structure）

### 2.1 原子的組成（Structure of the Atom）

| 粒子 | 電荷 | 位置 | 相對質量 |
|------|------|------|---------|
| 質子（proton） | +1 | 原子核（nucleus） | ≈ 1 |
| 中子（neutron） | 0 | 原子核 | ≈ 1 |
| 電子（electron） | −1 | 核外（surrounding nucleus） | ≈ 1/1800 |

- **原子序（atomic number）**：質子數，決定元素種類
- **質量數（mass number）**：質子數 + 中子數
- **同位素（isotopes）**：質子數相同、中子數不同的原子

**碳的同位素範例：**

```
¹²C：6 質子 + 6 中子（最常見，佔 99%）
¹³C：6 質子 + 7 中子（佔 ~1%）
¹⁴C：6 質子 + 8 中子（放射性，半衰期 5730 年，用於碳定年法 carbon dating）
```

### 2.2 電子殼層與軌域（Electron Shells and Orbitals）

**軌域（orbital）**：電子允許存在的能量狀態，以**波函數（wave function, ψ）** 描述；電子在空間某點出現的機率由 **ψ²（電子密度 electron density）** 決定。

> **海森堡測不準原理（Heisenberg uncertainty principle）**：無法同時精確知道電子的位置與動量。

**殼層（shell）** 由**主量子數（principal quantum number, n）** 標示：

| 殼層（n） | 可容納電子數 | 含有軌域 |
|-----------|------------|---------|
| n = 1 | 2 | 1s |
| n = 2 | 8 | 2s、2pₓ、2p_y、2p_z |
| n = 3 | 18 | 3s、3p（×3）、3d（×5） |

#### s 軌域（s orbital）
- **球形對稱（spherically symmetrical）**，無方向性
- 電子密度在核處最大，向外指數遞減
- 1s 軌域電子密度在核最高；2s 有一個**節點（node）**（電子密度為零的球形界面），大部分電子密度在節點外側

#### p 軌域（p orbital）
- 啞鈴形，由**兩葉（two lobes）** 組成，中間有一個**節面（nodal plane）**（過核的平面，電子密度為零）
- 三個 2p 軌域（2pₓ、2p_y、2p_z）方向互相垂直，能量完全相同
- 能量相同的軌域稱為**縮併軌域（degenerate orbitals）**

```
p 軌域示意：

     +             +              +
     |             |              |
  z  |          y  |           x  |
─────┼─────    ─────┼─────    ─────┼─────
     |             |              |
     −             −              −

  2pz           2py            2px
（各自指向一個座標軸方向）
```

### 2.3 電子組態（Electronic Configurations）

填入電子需遵守三個原則：

**① Aufbau 原理（aufbau principle）**：從能量最低的軌域依序填入

**② 包利不相容原理（Pauli exclusion principle）**：每個軌域最多容納 2 個電子，且自旋必須相反（↑↓）

**③ 洪德規則（Hund's rule）**：能量相同的縮併軌域，電子先各佔一個（自旋相同），再成對

**第一、二週期元素電子組態：**

| 元素 | 電子組態 | 價電子數（valence electrons） |
|------|---------|--------------------------|
| H | 1s¹ | 1 |
| He | 1s² | 2 |
| Li | 1s² 2s¹ | 1 |
| Be | 1s² 2s² | 2 |
| B | 1s² 2s² 2pₓ¹ | 3 |
| **C** | **1s² 2s² 2pₓ¹ 2p_y¹** | **4** |
| **N** | **1s² 2s² 2pₓ¹ 2p_y¹ 2p_z¹** | **5** |
| **O** | **1s² 2s² 2pₓ² 2p_y¹ 2p_z¹** | **6** |
| **F** | **1s² 2s² 2pₓ² 2p_y² 2p_z¹** | **7** |
| Ne | 1s² 2s² 2pₓ² 2p_y² 2p_z² | 8 |

> **重點**：**價電子（valence electrons）** 即最外殼層電子，決定化學鍵結行為。週期表的族序數（group number）= 代表元素的價電子數（對主族元素 representative elements 而言）。

> **洪德規則應用於碳**：碳的第 3、4 個價電子（2p 電子）各佔不同的 2p 軌域，不成對，使碳更易形成 4 個鍵。

## 三、鍵結的形成：八隅體規則（Bond Formation: The Octet Rule）

### 3.1 八隅體規則（Octet Rule）

**G. N. Lewis（1915年）** 提出：原子傾向藉由得失或共用電子，使外層達到**8 個電子（八隅體）**，即類似鈍氣（noble gas）的穩定電子組態。

> **氫的特例**：氫只需 2 個電子即可達到氦（He）的組態，稱為「雙隅體（duet）」。

> **第三週期以後的例外**：第三列及更後面的元素（如 P、S、Cl）具有可用的低能量 d 軌域，可以容納超過 8 個電子（**擴展八隅體 expanded octet**）。

### 3.2 兩種鍵結方式

#### (A) 離子鍵（Ionic Bonding）
- **機制**：電子從一個原子**轉移（transfer）** 至另一個原子，形成帶相反電荷的離子（ions），靠靜電引力結合
- **特點**：通常形成三維晶格（crystal lattice），而非個別分子；多見於無機物

```
鋰與氟的離子鍵形成：

Li（1s² 2s¹）  →  Li⁺（1s²，氦組態）  +  e⁻
F（1s² 2s² 2p⁵）  +  e⁻  →  F⁻（1s² 2s² 2p⁶，氖組態）

→  Li⁺ F⁻  形成離子鍵（ionic bond）
```

#### (B) 共價鍵（Covalent Bonding）
- **機制**：兩原子**共用（share）** 電子對，每個原子都「感覺」電子屬於自己
- **特點**：有機化合物中最常見的鍵結類型

```
氫氣的共價鍵形成：

H•  +  •H  →  H:H（H₂）

每個 H 共用 2 個電子，達到 He 的組態（雙隅體）
```

### 3.3 兩種鍵結的比較

| 特性 | 離子鍵（ionic bond） | 共價鍵（covalent bond） |
|------|---------------------|----------------------|
| 電子行為 | 轉移（transfer） | 共用（sharing） |
| 產物 | 正負離子（cations / anions） | 分子（molecules） |
| 常見於 | 無機鹽（inorganic salts） | 有機化合物（organic compounds） |
| 電負度差（electronegativity difference）| 通常 ≥ 2 | 通常 < 2 |

## 四、課本例題精講

### 例題 1（Problem 1-1a）

**題目**：氮的穩定同位素質量數為 13、14、15、16、17。計算各同位素的質子數與中子數。

**解析：**

氮的原子序 = 7，故所有氮的同位素均有 **7 個質子**。

```
中子數（neutrons）= 質量數（mass number）− 質子數（atomic number）

¹³N：質量數 13 − 質子數 7 = 6 個中子
¹⁴N：14 − 7 = 7 個中子（最常見，穩定）
¹⁵N：15 − 7 = 8 個中子（穩定）
¹⁶N：16 − 7 = 9 個中子（放射性）
¹⁷N：17 − 7 = 10 個中子（放射性）
```

---

### 例題 2（Problem 1-1b）

**題目**：寫出下列第三列元素（Si、P、S、Cl）的電子組態。

**解析：**

第三列元素在第二列（Ne 組態 1s² 2s² 2p⁶）的基礎上，繼續填入 3s 和 3p 軌域：

```
Ne 核心組態（core configuration）：[Ne] = 1s² 2s² 2p⁶

Si（14 號）：[Ne] 3s² 3pₓ¹ 3p_y¹        價電子 4 個
P （15 號）：[Ne] 3s² 3pₓ¹ 3p_y¹ 3p_z¹  價電子 5 個
S （16 號）：[Ne] 3s² 3pₓ² 3p_y¹ 3p_z¹  價電子 6 個
Cl（17 號）：[Ne] 3s² 3pₓ² 3p_y² 3p_z¹  價電子 7 個
```

> **注意**：第三列元素（n = 3）有 3d 軌域可用，故 S、P 等可形成擴展八隅體（如 SF₆、PCl₅）。

## 五、進階例題（選自課後習題）

### 進階例題 A（Problem 1-29）

**題目**：判斷下列化合物的鍵結類型（共價鍵、離子鍵、或混合）：

(a) KCl　　(b) KOH　　(c) CH₃CH₂Li　　(d) CH₃Cl　　(e) KOCH₃

**解析：**

**(a) KCl — 離子鍵（ionic）**

K（電負度 0.8）與 Cl（電負度 3.2），電負度差 = **2.4 >> 2** → 完全離子鍵（ionic bond）

**(b) KOH — 混合（mixed）**

```
K–O：電負度差 = 3.4 − 0.8 = 2.6 → 離子鍵（K⁺ OH⁻）
O–H：電負度差 = 3.4 − 2.2 = 1.2 → 共價鍵（polar covalent bond）
```

→ KOH 含有離子鍵（K⁺ 與 OH⁻ 之間）與共價鍵（O–H 鍵）的**混合**。

**(c) CH₃CH₂Li — 混合（mixed）**

```
C–Li：C 電負度 2.5，Li 電負度 1.0，差 = 1.5 → 接近離子鍵（極性很強的共價鍵 / 離子性）
C–C、C–H：共價鍵
```

→ C–Li 鍵具有強烈的**離子性**（常被視為有機金屬化合物 organolithium compound）；其餘為共價鍵。

**(d) CH₃Cl — 共價鍵（covalent，極性共價鍵）**

```
C–Cl：電負度差 = 3.2 − 2.5 = 0.7 → 極性共價鍵（polar covalent bond）
C–H：差 ≈ 0.3 → 幾乎非極性共價鍵（nonpolar covalent bond）
```

**(e) KOCH₃ — 混合（mixed）**

```
K–O：電負度差 = 3.4 − 0.8 = 2.6 → 離子鍵（K⁺ ⁻OCH₃）
O–C：共價鍵
```

### 進階例題 B（Problem 1-30b）★

**題目**：NF₃ 是已知化合物，但 NF₅ 的所有合成嘗試均失敗。畫出 NF₃ 和假設存在的 NF₅ 的路易士結構（Lewis structure），並解釋 NF₅ 不可能存在的原因。

**解析：**

**NF₃ 的 Lewis 結構：**

```
  F          N 有 5 個價電子
  |          F 各有 7 個價電子
F–N:         共用 3 對（形成 3 個 N–F 鍵）
  |          N 上剩 1 個孤對電子（lone pair）
  F
  
  ✓ N 的八隅體：3 個鍵（6 e⁻）+ 1 孤對（2 e⁻）= 8 e⁻，滿足八隅體
```

**假設 NF₅ 的 Lewis 結構：**

```
  F   F
   \ /
 F–N–F         若 N 形成 5 個鍵：5 × 2 = 10 個電子在 N 的外層
   |
   F

  ✗ N 的外層 = 10 e⁻ > 8 e⁻，違反八隅體（octet rule）
```

**為何 NF₅ 不存在？**

氮（N）是**第二列元素（second-row element）**，只有 1s、2s、2p 軌域可用（n = 2 的殼層只能容納 8 個電子）。**第二列元素沒有可用的 d 軌域，無法形成擴展八隅體（expanded octet）**。

相比之下，磷（P）是第三列元素，有 3d 軌域可用，故 PF₅ 是穩定的化合物（磷外層有 10 個電子）。

## 六、本節重點整理

### 原子結構（Atomic Structure）

| 概念 | 要點 |
|------|------|
| 同位素（isotopes） | 質子數相同，中子數不同；¹⁴C 用於碳定年法（carbon dating） |
| 軌域（orbital） | 電子的能量狀態，由波函數（ψ）描述，電子密度 = ψ² |
| 節點（node）/ 節面（nodal plane） | 電子密度為零的點或面 |
| s 軌域（s orbital） | 球形，無方向性 |
| p 軌域（p orbital） | 啞鈴形，有節面，三個方向互相垂直，縮併（degenerate） |
| 縮併軌域（degenerate orbitals） | 能量完全相同的軌域 |

### 電子填入規則

| 規則 | 內容 |
|------|------|
| Aufbau 原理 | 由低能量軌域依序填入 |
| 包利不相容原理（Pauli exclusion principle） | 每個軌域最多 2 個電子，自旋相反（↑↓） |
| 洪德規則（Hund's rule） | 縮併軌域先各填一個，再成對 |

### 鍵結類型（Bond Types）

| 鍵結類型 | 機制 | 電負度差（ΔEN）參考 | 常見於 |
|---------|------|-------------------|-------|
| 離子鍵（ionic bond） | 電子轉移 | ≥ 2 | 無機鹽、金屬化合物 |
| 共價鍵（covalent bond）| 電子共用 | < 2 | 有機化合物 |
| 極性共價鍵（polar covalent bond） | 電子不均等共用 | 0.5 ~ 2 | C–O、C–N、C–Cl 等 |
| 非極性共價鍵（nonpolar covalent bond） | 電子均等共用 | < 0.5 | C–C、C–H |

### 八隅體規則重要例外

| 情況 | 原因 | 例子 |
|------|------|------|
| 氫（H）只需 2 個電子 | 滿足 He 組態即穩定 | H₂、CH₄ 中的 H |
| 第三列以後元素可超過 8 個電子 | 有 d 軌域可用（擴展八隅體） | SF₆（S 有 12 個電子）、PCl₅ |
| 硼（B）通常只有 6 個電子 | 第二列元素，只有 3 個價電子 | BF₃（B 有 6 個電子，不滿足八隅體） |
