## 一、Lewis 結構（Lewis Structures）

**Lewis 結構**：以點或短線表示所有**價電子（valence electrons）**，讓每個原子達到貴重氣體組態（氫需 2 個電子，其餘第二列元素需 8 個電子）。

**名詞說明：**
- **鍵結電子對（bonding pair）**：兩原子共用的電子對，以「–」（短線）表示
- **孤對電子（lone pair / nonbonding electrons）**：只屬於某一原子、不參與鍵結的電子對
- 正確的 Lewis 結構**必須標示孤對電子**；有機化學家有時省略孤對，但那不是嚴格意義的 Lewis 結構

### 1.1 繪製步驟

```
步驟一：計算所有原子的價電子總數
        （各元素族序數之和，再加上負電荷或減去正電荷）

步驟二：決定原子連接方式，寫出骨架

步驟三：每個鍵先用一對電子（–）連接

步驟四：將剩餘電子以孤對方式分配給各原子，使每個原子達到八隅體

步驟五：若電子不足，改用雙鍵（=）或三鍵（≡）
```

### 1.2 常見分子的 Lewis 結構

**甲烷（methane, CH₄）：**
```
       H
       |
  H – C – H      共 8 個價電子（C: 4, H×4: 4）
       |          C 有 4 個鍵（八隅體）; 每個 H 有 1 個鍵（雙隅體）
       H
```

**乙烷（ethane, C₂H₆）：**
```
  H   H
  |   |
H–C – C–H        共 14 個價電子（C×2: 8, H×6: 6）
  |   |          每個 C 有 4 個鍵（八隅體）; C–C 單鍵（single bond）
  H   H
```

**甲胺（methylamine, CH₃NH₂）：**
```
  H       H
  |       |
H–C  –  N:       N 上有 1 個孤對電子（lone pair）
  |       |
  H       H
```

**乙醇（ethanol, CH₃CH₂OH）：**
```
  H   H
  |   |
H–C – C – O:–H   O 上有 2 個孤對電子
  |   |
  H   H
```

**氯甲烷（chloromethane, CH₃Cl）：**
```
      H
      |
  H – C – Cl:    Cl 上有 3 個孤對電子
      |        ¨
      H
```

## 二、多重鍵（Multiple Bonding）

### 2.1 三種鍵結類型

| 鍵結類型 | 共用電子對數 | 符號 | 例子 |
|---------|------------|------|------|
| 單鍵（single bond） | 1 對（2 電子）| – | C–C、C–H |
| 雙鍵（double bond） | 2 對（4 電子）| = | C=C、C=O |
| 三鍵（triple bond） | 3 對（6 電子）| ≡ | C≡C、C≡N |

**含雙鍵的分子：**

```
乙烯（ethylene, C₂H₄）：         甲醛（formaldehyde, H₂CO）：
  H     H                              H
   \   /                               |
    C = C                              C = O:
   /   \                               |
  H     H                             H

亞甲胺（formaldimine, H₂CNH）：
  H
   \
    C = N:
   /     \
  H       H
```

**含三鍵的分子：**

```
乙炔（acetylene, C₂H₂）：         乙腈（acetonitrile, CH₃CN）：

H – C ≡ C – H                    H   H
                                  |   |
                                H–C – C ≡ N:
                                  |
                                  H
```

### 2.2 常見元素的化合價（Valence）與孤對電子數

> **重要：牢記下表，是快速繪製 Lewis 結構的關鍵**

| 元素 | 一般鍵數（Valence）| 孤對電子對數（Lone Pairs）| 例子 |
|------|-------------------|--------------------------|------|
| C（碳）| **4** | 0 | CH₄、C₂H₆ |
| N（氮）| **3** | 1 | NH₃、CH₃NH₂ |
| O（氧）| **2** | 2 | H₂O、CH₃OH |
| H（氫）| **1** | 0 | H₂、HCl |
| 鹵素（F, Cl, Br, I）| **1** | 3 | HCl、CH₃Cl |

> 以上為中性、無電荷情況下的常見鍵數；帶電荷的原子鍵數會改變（見形式電荷一節）。

## 三、電負度與鍵極性（Electronegativity and Bond Polarity）

### 3.1 非極性與極性共價鍵

| 鍵結類型 | 定義 | 電子分布 |
|---------|------|---------|
| 非極性共價鍵（nonpolar covalent bond） | 兩原子電負度相同或相近，電子均等共用 | 對稱 |
| 極性共價鍵（polar covalent bond） | 兩原子電負度不同，電子偏向電負度較大的原子 | 不對稱 |

### 3.2 電負度（Electronegativity）

**電負度（electronegativity）**：原子吸引鍵結電子的能力。**Pauling 電負度量表（Pauling electronegativity scale）** 數值：

```
週期表中的電負度趨勢：
  → 同週期：從左到右增加（增加核電荷，吸引電子能力增強）
  ↑ 同族：從下到上增加（較小的原子，核對鍵電子吸引力較強）

有機化學常用數值：
H  = 2.2   Li = 1.0   Na = 0.9
C  = 2.5   N  = 3.0   O  = 3.4
F  = 4.0   Cl = 3.2   Br = 3.0   I = 2.7
Si = 1.9   P  = 2.2   S  = 2.6
```

### 3.3 偶極矩（Dipole Moment）

**偶極矩（dipole moment, μ）**：衡量鍵極性的大小

```
μ = δ × d

其中：δ = 部分電荷量（partial charge）
      d = 鍵長（bond length）
      單位：Debye（D）
```

**表示方式：**

- 使用箭頭（arrow）由正極（δ⁺）指向負極（δ⁻），箭頭尾部畫一個 + 號
- 電負度較大的原子端為 δ⁻（電子豐富 electron-rich）；另一端為 δ⁺（電子貧乏 electron-poor）

```
氯甲烷（chloromethane, CH₃Cl）：

  H  δ⁺           δ⁻
   \ /+→
H – C – Cl        Cl 電負度（3.2）> C 電負度（2.5）
   /              → 電子偏向 Cl，Cl 為 δ⁻，C 為 δ⁺
  H
```

**靜電勢圖（electrostatic potential map, EPM）**：以顏色視覺化電荷分布
- **紅色（red）**：電子豐富區（δ⁻）
- **藍色/紫色（blue/purple）**：電子貧乏區（δ⁺）
- 橘、黃、綠色：中間值

## 四、形式電荷（Formal Charges）

### 4.1 形式電荷的定義與計算

**形式電荷（formal charge, FC）**：假設鍵結電子均等分配時，每個原子「擁有」的電子數，與中性自由原子的電子數之差。

> 形式電荷**不一定代表真實電荷分布**，但是追蹤電子、判斷合理結構的重要工具。

**計算公式：**

$$\boxed{FC = [\text{族序數（group number）}] - [\text{非鍵結電子數（nonbonding electrons）}] - \frac{1}{2}[\text{鍵結電子數（bonding electrons）}]}$$

或等價地表示為：

```
FC = 價電子數 − 孤對電子數 − (鍵數)

（因為鍵結電子對的一半 = 一個鍵）
```

### 4.2 計算示範

**甲烷（CH₄）中的碳：**

```
C 在族 4A → 族序數 = 4
C 形成 4 個鍵 → 共用電子 = 8 個 → ½ × 8 = 4
C 無孤對電子 → 非鍵結電子 = 0

FC(C) = 4 − 0 − 4 = 0   ✓（碳有 4 個鍵時形式電荷為 0）
```

**水合氫離子（hydronium ion, H₃O⁺）中的氧：**

```
O 在族 6A → 族序數 = 6
O 形成 3 個鍵 → 共用電子 = 6 → ½ × 6 = 3
O 有 1 個孤對 → 非鍵結電子 = 2

FC(O) = 6 − 2 − 3 = +1   ✓（氧有 3 個鍵時帶 +1 形式電荷）
```

**H₃N→BH₃（氮→硼配位化合物）：**

```
N（4 個鍵，無孤對）：
FC(N) = 5 − 0 − 4 = +1

B（4 個鍵，無孤對）：
FC(B) = 3 − 0 − 4 = −1

整體分子：+1 + (−1) = 0，中性 ✓
```

### 4.3 常見形式電荷速查

> **重要：牢記常見帶電情況，快速判斷結構合理性**

| 原子 | 價電子數 | 正電（FC = +1）| 中性（FC = 0）| 負電（FC = −1）|
|------|---------|--------------|--------------|--------------|
| C | 4 | 3 個鍵（缺八隅體）| 4 個鍵 | 3 個鍵 + 1 孤對 |
| N | 5 | 4 個鍵（有八隅體）| 3 個鍵 + 1 孤對 | 2 個鍵 + 2 孤對 |
| O | 6 | 3 個鍵（有八隅體）| 2 個鍵 + 2 孤對 | 1 個鍵 + 3 孤對 |
| 鹵素 | 7 | 2 個鍵 + 2 孤對 | 1 個鍵 + 3 孤對 | 0 個鍵（X⁻）|

## 五、離子結構（Ionic Structures）

部分有機化合物含有離子鍵。判斷規則：

> **電負度差 ≥ 2 的原子間**，通常畫成離子鍵（而非共價鍵）。

```
甲胺鹽酸鹽（methylammonium chloride, CH₃NH₃Cl）：

正確寫法（離子結構）：           錯誤寫法（共價結構）：
    H  H                              H  H  H
    |  |                              |  |  |
H–C–N–H  :Cl:⁻                   H–C–N–Cl   ← N 有 5 個鍵 = 10 電子
    |  |                              |
    H  H                              H
         +
（N 有 4 個鍵，形式電荷 +1）        ✗ 第二列元素 N 不能超過 8 電子
```

## 六、共振（Resonance）— 本章核心難點

### 6.1 共振的概念

當一個分子**無法用單一 Lewis 結構完整描述**，而可以寫出兩個或更多只有電子位置不同（原子骨架相同）的合法 Lewis 結構時，稱這些結構互為**共振式（resonance forms / resonance structures）**。

**真實分子是所有共振式的共振混成體（resonance hybrid）：**
- 電荷**去局域化（delocalized）** 分散在整個分子
- 各共振式並非獨立存在，分子也不會在各共振式之間「振盪（resonate）」
- 去局域化使分子更穩定，稱為**共振穩定（resonance stabilization）**

**書寫約定：**

```
結構 A  ↔  結構 B        「雙向箭頭（double-headed arrow）↔」連接共振式

注意：
  ↔  共振（resonance）：同一化合物的不同電子排列方式
  ⇌  平衡（equilibrium）：不同化合物之間的轉化
  →  彎曲箭頭（curved arrow）：概念性表示電子移動方向（imaginary!）
```

### 6.2 共振式的繪製規則

在不同共振式之間移動電子時，必須遵守：

1. **所有共振式必須是合法的 Lewis 結構**（第二列元素不超過 8 個電子）
2. **只有電子（尤其是 π 電子和孤對電子）可以移動，原子核不可移動**
3. **所有共振式的原子骨架（sigma 鍵框架）和鍵角必須完全相同**
4. **σ 鍵非常穩定，通常不參與共振**（移動的是 π 電子或孤對電子）
5. 若核移動了，就**不是共振式，而是不同化合物**

```
合法的共振式移動（電子移動）：

   H   H                H   H
    \ /                  \ /
     C=C         ↔       C–C
    / \                  / \
   H   H                H   H
       |                    +

   ✓ 電子移動，骨架不變    ✓ 合法共振式


不合法的移動（原子移動）：

   H   H                H   H   H
    \ /                  \  |
     C=C         ≠        C–C
    / \                  / \
   H   H                H

   ✗ H 原子移位 → 這是不同化合物，不是共振式！
```

### 6.3 共振式的能量與主次貢獻者

不同共振式的估算能量可能不同，**能量較低（較穩定）的共振式是「主要貢獻者（major contributor）」**，更接近真實結構。

**判斷主次的準則（由重要到次要）：**

```
1. 八隅體（octets）滿足越多越好  ← 最重要
2. 鍵數（bonds）越多越好
3. 電荷分離（charge separation）越少越好
4. 負電荷在電負度較大（more electronegative）的原子上更穩定
```

### 6.4 重要共振類型

#### 類型 A：負電荷的去局域化

**乙酸根（acetate ion, CH₃COO⁻）：**

```
    O                O⁻               O    ½⁻
    ‖                |                ‖
H₃C–C        ↔   H₃C–C          =  H₃C–C
    |                ‖                    |
    O⁻               O               O    ½⁻

   共振式 1        共振式 2         真實結構（混成體）

兩個 C–O 鍵等價（bond order = 1.5），負電荷各佔一半
→ 負電荷去局域化使乙酸（acetic acid）的酸性增強
```

#### 類型 B：正電荷的去局域化（碳正離子 carbocation 鄰近雜原子）

**[H₂C=NH₂]⁺（亞甲基銨離子）：**

```
        H                  H
        |     +             |
  H₂C – N:         ↔    H₂C = N
        |                  |     +
        H                  H

  次要貢獻者（minor）      主要貢獻者（major）
  C 沒有八隅體（缺）        C 和 N 都有八隅體 ✓
  N 有孤對電子             N 多一個鍵

→ 正電荷從 C 轉移到 N（儘管 N 電負度較大，但 N 在此狀況下有八隅體，更穩定）
```

#### 類型 C：雜原子鄰近碳正離子（O、N 提供電子）

```
  :Ö–C⁺      ↔    :Ö⁺=C          次要（minor）→ 主要（major）

  :N:–C⁺      ↔    :N:⁺=C         次要（minor）→ 主要（major）

說明：O 或 N 的孤對電子移入 C⁺，讓 C 獲得八隅體，形成更多鍵（更穩定）
     正電荷移到 O 或 N，但這兩者帶正電時仍有八隅體 → 比 C⁺ 沒有八隅體更穩定
```

#### 類型 D：雙鍵（π 電子）相鄰碳正離子或碳負離子

```
碳正離子的去局域化：

  –C=C–C⁺   →彎曲箭頭→   –C⁺–C=C    ← 正電荷分散在兩個 C 上

碳負離子的去局域化：

  –C⁻–C=C   →彎曲箭頭→   –C=C–C⁻    ← 負電荷分散在兩個 C 上
```

#### 類型 E：雙鍵（C=O）的極性

**甲醛（formaldehyde, H₂C=O）：**

```
     O:                  :O⁻            O
     ‖                    |             ‖         δ⁻
  H₂C           ↔      H₂C⁺        =  H₂C
                                                   δ⁺

主要（major）          次要（minor）     真實偶極矩（dipole moment）
所有八隅體 ✓           C 無八隅體，電荷分離
更多鍵，無電荷分離

→ 次要共振式雖能量高，但解釋了 C=O 鍵為何有很大的偶極矩（C 端 δ⁺，O 端 δ⁻）
```

### 6.5 共振式判斷流程圖

```
步驟 1：找出帶電荷或電子密度不均的部位（π 鍵、孤對電子、+/− 電荷）

步驟 2：尋找相鄰的 π 鍵或孤對電子，用彎曲箭頭移動電子

步驟 3：確認新結構符合八隅體規則（第二列元素 ≤ 8 電子）

步驟 4：比較各結構的穩定性 → 決定主次貢獻者

記憶口訣：
  要讓負電荷「去」到電負度大的原子（O、N 優先）
  要讓正電荷「移」到有孤對電子的原子（使碳獲得八隅體）
```

## 七、課本例題精講

### 例題 1（Solved Problem 1-1b）

**題目**：計算水合氫離子（hydronium ion, H₃O⁺）中氧原子的形式電荷。

**解析：**

首先繪製 Lewis 結構：

```
    H
    |
H – O⁺– H     共 8 個價電子（O: 6, H×3: 3, 減去 +1 電荷: −1 = 8）
    ..         O 形成 3 個鍵，有 1 個孤對（2 個電子）
```

計算 FC(O)：

```
族序數（group number） = 6（O 在族 6A）
非鍵結電子數（nonbonding electrons） = 2（1 個孤對）
鍵結電子數（bonding electrons） = 6（3 個鍵 × 2 = 6 個電子）

FC(O) = 6 − 2 − ½ × 6 = 6 − 2 − 3 = +1   ✓
```

**答：氧的形式電荷為 +1（氧有 3 個鍵時帶正電荷）**

---

### 例題 2（Solved Problem 1-2a）

**題目**：繪製 [CH₃OCH₂]⁺ 的重要共振式，指出主次貢獻者。

**解析：**

首先畫出起始結構（正電荷在 C 上）：

```
結構 1（次要 minor contributor）：

  H   H
  |   |
H–C–O–C⁺–H      CH₂ 上的 C 只有 3 個鍵（6 電子），無八隅體！
  |               O 有 2 個孤對電子
  H
```

O 的孤對電子可以移入相鄰的 C⁺，形成 C=O⁺：

```
  →（彎曲箭頭：O 的孤對電子 → C⁺）

結構 2（主要 major contributor）：

  H   H
  |   |
H–C–O⁺=C–H      O 形成 3 個鍵（八隅體 ✓）
  |   ..          C 形成 4 個鍵（八隅體 ✓）
  H               O 帶 +1 形式電荷（有八隅體，比無八隅體的 C⁺ 更穩定）
```

**主次判斷：**

| 共振式 | 八隅體 | 鍵數 | 電荷位置 | 結論 |
|--------|--------|------|---------|------|
| 結構 1（C⁺）| ✗（C 沒有）| 較少 | 碳（電負度較低，且無八隅體）| **次要（minor）** |
| 結構 2（O⁺）| ✓（全滿足）| 較多 | 氧（有八隅體，比結構 1 的 C⁺ 穩定）| **主要（major）** |

---

### 例題 3（Solved Problem 1-2b）—— 判斷共振式的主次

**題目**：下圖為含有 C=O 鍵鄰近碳負離子的兩個共振式，判斷主次：

```
結構 A：           結構 B：
   O               O⁻
   ‖                |
–C⁻–C–             –C=C–
   |                |
   H                H
```

**解析：**

| 共振式 | 八隅體 | 電荷位置 | 結論 |
|--------|--------|---------|------|
| 結構 A（C⁻）| ✓（全滿足）| 碳（電負度較低）| **次要（minor）** |
| 結構 B（O⁻）| ✓（全滿足）| 氧（電負度較高 3.4 > 2.5）| **主要（major）** |

→ 兩個結構都有完整八隅體，鍵數也相同，故**電荷位置**決定主次。
→ 負電荷在電負度較大的 O 上更穩定 → 結構 B 為主要貢獻者。

## 八、進階例題（選自課後習題）

### 進階例題 A（Problem 1-7b）★

**題目**：畫出 H₂C=CH–C⁺H₂（烯丙基碳正離子 allylic carbocation）的重要共振式。

**解析：**

起始結構：正電荷在 C3（末端 CH₂⁺），相鄰有一個 C=C 雙鍵（π 電子可以移動）。

```
結構 1：                    →彎曲箭頭（π 電子移動）

  H₂C = CH – C⁺H₂    →    H₂C⁺ – CH = CH₂

結構 1                        結構 2
```

**驗證：**

```
結構 1：H₂C=CH–C⁺H₂
  C1：sp²（2 個鍵 + 1 個 π）→ 有八隅體 ✓
  C2：sp²（參與 π 鍵）→ 有八隅體 ✓
  C3：3 個鍵，無孤對，無八隅體 ✗（正電荷在 C3）

結構 2：H₂C⁺–CH=CH₂
  C1：3 個鍵，無孤對，無八隅體 ✗（正電荷在 C1）
  C2：sp²（參與 π 鍵）→ 有八隅體 ✓
  C3：有八隅體 ✓
```

**結論：** 兩個共振式的估算能量相同（結構對稱，兩端碳情況等價），故**兩者能量相等（equal energy）**，正電荷均等分佈在 C1 和 C3 上。

```
真實結構（共振混成體）：

  H₂C ····· CH ····· CH₂
  δ+                  δ+
  
（正電荷各佔一半，分佈於 C1 和 C3）
```

### 進階例題 B（Problem 1-8a）★★

**題目**：對於重氮甲烷（diazomethane, H₂CNN），課本已給出以下三個共振式，判斷哪個最重要、哪個最不重要，並說明理由。

```
結構 A：        結構 B：        結構 C：
H₂N–N=C:⁻    H₂C–N⁻=N:⁺    H₂C=N⁺=N:⁻    ← 課本給出的三個共振式
（C 端負電荷）  （中間 N 負電荷）  （末端 N 負電荷）
```

**解析：**

首先計算各結構的八隅體情形與電荷合理性：

| 共振式 | C 的電子數 | N(中間)的電子數 | N(末端)的電子數 | 電荷位置合理性 | 評估 |
|--------|-----------|---------------|---------------|-------------|------|
| 結構 A（H₂N–N=C:⁻）| 8 ✓ | 8 ✓ | 8 ✓ | 負電荷在 C（電負度 2.5），正電荷在中間 N（電負度 3.0）→ 次合理 | **次要（minor）** |
| 結構 B（H₂C–N⁻=N:⁺）| 8 ✓ | 8 ✓ | 8 ✓ | 負電荷在中間 N，正電荷在末端 N → 合理 | **中等** |
| 結構 C（H₂C=N⁺=N:⁻）| 8 ✓ | 8 ✓ | 8 ✓ | 負電荷在末端 N（電負度 3.0）→ **最合理** | **主要（major）** |

**答：**
- **最重要（主要）**：結構 C（H₂C=N⁺=N⁻）——負電荷在末端 N（更電負），正電荷在中間 N（有八隅體）
- **最不重要（次要）**：結構 A（H₂NN⁺=C:⁻）——負電荷在碳（電負度最低）

### 進階例題 C（Problem 1-45e）★★

**題目**：下列兩個碳正離子（carbocations），哪一個更穩定？用共振式說明。

```
離子 I：   (CH₂=CH)–CH⁺–(CH₂=CH)    （兩個烯丙基，allylic carbocation）

離子 II：  CH₂=CH–CH₂–CH₂⁺           （普通烷基碳正離子，非共振穩定）
```

**解析：**

**離子 I** 的中心 C⁺ 兩側各有一個 C=C 雙鍵，可以向兩個方向去局域化：

```
  CH₂=CH–CH⁺–CH=CH₂

          ↕ 共振

  CH₂⁺–CH=CH–CH=CH₂   （電荷移到左端 C1）

          ↕ 共振（右側方向）

  CH₂=CH–CH=CH–CH₂⁺   （電荷移到右端 C5）
```

→ 正電荷分散在三個碳（C1、C3、C5）上，去局域化程度高，**共振穩定性強**

**離子 II** 的正電荷在 C4，相鄰無 π 鍵，**無法共振去局域化**：

```
  CH₂=CH–CH₂–CH₂⁺     ← C4 的正電荷無法與遠端的 C=C 共振（被 CH₂ 隔開）
```

**結論：離子 I 更穩定**，因為正電荷可以被三個烯丙基位置共振分散；離子 II 的正電荷是局域化的（localized），沒有共振穩定化能。

## 九、本節重點整理

### Lewis 結構與鍵結

| 概念 | 要點 |
|------|------|
| 孤對電子（lone pair） | 非鍵結電子，通常在 N（1 對）、O（2 對）、鹵素（3 對）上 |
| 常見化合價（valence）| C = 4、N = 3、O = 2、H = 1、鹵素 = 1 |
| 多重鍵（multiple bonds）| 雙鍵（=）：4 電子；三鍵（≡）：6 電子 |

### 電負度與偶極矩

| 概念 | 要點 |
|------|------|
| 電負度趨勢 | 同週期左→右增加；同族下→上增加 |
| 極性共價鍵（polar covalent bond）| 電子偏向電負度大的原子，形成 δ⁺/δ⁻ |
| C–H 鍵 | 電負度差 ≈ 0.3，通常視為**非極性（nonpolar）** |
| 偶極矩（dipole moment, μ）| μ = δ × d，單位 Debye（D） |

### 形式電荷（Formal Charge）

| 計算公式 | FC = 族序數 − 非鍵結電子數 − ½ × 鍵結電子數 |
|---------|----------------------------------------------|
| N（4 個鍵）| FC = +1 |
| O（3 個鍵）| FC = +1 |
| C（3 個鍵 + 無孤對）| FC = +1（碳正離子 carbocation）|
| C（3 個鍵 + 1 孤對）| FC = −1（碳負離子 carbanion）|

### 共振（Resonance）

| 概念 | 要點 |
|------|------|
| 共振式（resonance forms）| 同一化合物的不同電子排列；原子骨架不變 |
| 共振混成體（resonance hybrid）| 真實結構，電荷去局域化 |
| 主要貢獻者（major contributor）| 八隅體多、鍵多、電荷分離少、負電荷在電負度大的原子 |
| 彎曲箭頭（curved arrow）| 概念性工具，表示電子「移動」方向（π 電子或孤對電子） |
| 共振穩定（resonance stabilization）| 去局域化使能量降低，分子更穩定 |

### 易混淆：共振（Resonance）vs. 共振穩定的特殊情況

| 情況 | 負電荷移往何處更穩定？ | 正電荷移往何處更穩定？ |
|------|---------------------|---------------------|
| C vs. O | **O**（電負度更大）| **O**（有孤對電子可提供八隅體）|
| C vs. N | **N**（電負度更大）| **N**（有孤對電子可提供八隅體）|
| C⁺（無八隅體）vs. O⁺（有八隅體）| — | **O⁺**（有八隅體，儘管 O 電負度大，但此時比 C⁺ 沒八隅體更穩定）|
