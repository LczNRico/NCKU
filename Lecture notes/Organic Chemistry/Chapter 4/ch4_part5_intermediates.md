## 1. 自由基抑制劑（Radical Inhibitors）

### 1-1 為何需要抑制自由基反應？

- 空氣中的氧氣會透過**自由基連鎖反應**氧化食物、溶劑及其他化合物，使其變質（spoil）。
- 化學中間體可能經由自由基連鎖反應**分解（decompose）**或**聚合（polymerize）**。
- 生物細胞也會被自由基反應破壞，可能導致**老化（aging）**、**癌化突變（cancerous mutation）**或**細胞死亡（cell death）**。

**自由基抑制劑（radical inhibitor）**常被加入食品與化學品中，以延緩連鎖反應造成的變質。用於食品時也稱為**抗氧化劑（antioxidant）**。

### 1-2 作用原理（Figure 4-13）

**正常連鎖**：每個傳遞步驟都必須**快**（放熱或只輕微吸熱），一次起始才能帶動許多分子反應。

**加入抑制劑 I**：

```
能量
 ▲    正常連鎖                         加入抑制劑
 │  A· ─► B· ─► A· ─► B· …           A· + I ──► I·（相對穩定）
 │   ╲╱ ╲╱ ╲╱ ╲╱                              │
 │   多個放熱步驟，連續進行                   │ 下一步：I· + 反應物 → ？
 │                                            │ 強烈吸熱，太慢 ✗
 │                                            ▼
 │                                     連鎖中斷
 └────────────────────────────────────────────────►
```

**好的抑制劑要滿足兩個條件**：
1. 與連鎖自由基的反應要**快速且高度放熱**。
2. 生成的新自由基要**相對穩定**：它若要延續連鎖，必須經過**強烈吸熱**的步驟，所以實際上做不到。

> **連結 Part 2 挑戰題 4-54**：I₂ 抑制甲烷氯化，正是此原理的實例。

### 1-3 丁基羥基苯甲醚（BHA，Butylated Hydroxyanisole）

BHA 是常見的**食品抗氧化劑**，屬於**酚（phenol）**類：苯環上帶有 –OH。

**第一步**：BHA 把酚的 O–H 氫原子交給連鎖自由基（RO· 或 R·）

$$
\mathrm{BHA{-}O{-}H + RO\cdot\ (\text{或 } R\cdot) \longrightarrow BHA{-}O\cdot + ROH\ (\text{或 } RH)}
$$

- 生成的 **BHA 自由基（苯氧自由基 phenoxy radical）**可透過苯環**共振（resonance）**把未成對電子分散到苯環的鄰位與對位碳上，所以**相對穩定**，無法延續連鎖（共振式見例題 1）。

**第二步**：BHA 自由基再捕捉**第二個**自由基，生成更穩定、所有電子都成對的**醌（quinone）**

$$
\mathrm{BHA{-}O\cdot + RO\cdot\ (\text{或 } R\cdot) \longrightarrow \text{醌} + ROCH_3\ (\text{或 } RCH_3)}
$$

（BHA 苯環對位上的 –OCH₃ 基團把甲基轉移給自由基，本身變成 C=O）

**淨結果**：**一分子 BHA 可以消滅兩個自由基。**

### 1-4 生物體內的抑制劑

| 抑制劑 | 英文 | 結構特徵 | 作用方式 |
|---|---|---|---|
| **維生素 E** | vitamin E（生育醇 tocopherol） | **酚**：苯環上有 –OH，接一條長烷基鏈（脂溶性） | 與 BHA 相同：失去 O–H 的氫原子，生成穩定的苯氧自由基 |
| **維生素 C** | vitamin C（抗壞血酸 ascorbic acid） | 五員環內酯，含**烯二醇（enediol）**結構 | 失去 O–H 的氫原子，生成**共振穩定**的自由基（水溶性） |

維生素 C 的自由基中，未成對電子可以在 O、C=C、C=O 之間共振分散：

```
  維生素C（烯二醇 HO–C=C–OH）
        │  + R·
        ▼  − RH
  穩定自由基：·O–C=C–OH ↔ O=C–Ċ–OH ↔ …（電子分散在共軛系統中）
```

### 1-5 相關應用

| 應用 | 說明 |
|---|---|
| **食品抗氧化** | BHA、BHT、維生素 E 可防止油脂酸敗 |
| **健康研究** | 探討食物中的自由基抑制劑能否幫助細胞免於自由基傷害 |
| **老化與疾病** | 活性氧物種（reactive oxygen species）分解成羥自由基（hydroxyl radical），攻擊蛋白質與 DNA，傷害累積可能導致心臟病、癌症及老化 |
| **抗癌藥物** | 某些藥物（如**博來黴素 bleomycin**，用於睪丸癌）反其道而行：**產生**高活性的羥自由基，破壞快速分裂的腫瘤細胞 DNA，使腫瘤縮小 |

## 2. 反應中間體總覽（Reactive Intermediates）

### 2-1 定義

**反應中間體**：壽命短、濃度永遠很低的物種，因為它**一生成就立刻反應掉**。
- 通常是分子的**碎片**（例如自由基）。
- 常含有**鍵數不尋常**的原子，例如只有 2 或 3 個鍵的碳（穩定化合物中碳為 4 個鍵）。
- 會迅速反應成含**四價碳（tetravalent carbon）**的較穩定產物。

**為何重要？** 絕大多數反應機構都涉及反應中間體。要理解並自行提出機構，必須知道它們如何形成、結構與穩定性如何、傾向如何反應。

### 2-2 四種碳中間體

**三價碳（trivalent carbon，三個鍵）**依**非鍵結電子數**分為三種：

```
       H                 H                 H                  
       |                 |                 |                  
   H — C⁺            H — C·            H — C:⁻             :C — H
       |                 |                 |                   |
       H                 H                 H                   H
   碳陽離子            自由基            碳陰離子             碳烯
 (carbocation)       (radical)        (carbanion)          (carbene)
  0 個非鍵電子       1 個非鍵電子      2 個非鍵電子       二價碳，2 個非鍵電子
   帶正電              中性              帶負電               中性
```

**二價碳（divalent carbon，兩個鍵）**：最常見的是**碳烯**。它不像另外三種那麼常見。

## 3. 碳陽離子（Carbocation）

### 3-1 結構

- **別名**：碳鎓離子（carbonium ion）、碳烯鎓離子（carbenium ion）
- 帶正電的碳連接**三個原子**，**沒有**非鍵結電子 → 價殼層只有 **6 個電子**
- **sp² 混成**，**平面三角形（trigonal planar）**，鍵角約 **120°**
- 未混成的 **p 軌域是空的**，垂直於三個鍵所在的平面（Figure 4-14）
- 甲基陽離子（⁺CH₃）的結構與 **BH₃** 相似（第 1 章）

```
   俯視（top view）              側視（side view）
        H                            ○ ← 空的 p 軌域（vacant）
        |                            │
        C⁺                     H ─── C⁺ ─── H
       ╱ ╲                          ╱
      H   H                        H
   三個 sp² 軌域與 H 的 1s 重疊      │
   （平面，120°）                    ○
```

### 3-2 反應性

- 只有 6 個價電子 → **強親電子基（electrophile）／路易斯酸（Lewis acid）**，會與遇到的任何**親核基（nucleophile）**反應。
- 如同其他強酸，碳陽離子**不太可能存在於鹼性溶液中**。
- 在第 6 章的許多反應中作為中間體出現。

### 3-3 穩定化因素

碳陽離子**缺電子（electron-deficient）**，所以**推電子（electron-donating）**的烷基能穩定它，方式有二：

**(1) 誘導效應（inductive effect）**
- 經由 **σ 鍵**傳遞的電子密度推移。
- 帶正電的碳從**易極化（polarizable）**的烷基吸引部分電子密度，使正電荷分散到烷基上（烷基帶 δ⁺）。

**(2) 超共軛（hyperconjugation）**（Figure 4-15）
- 相鄰烷基的**填滿的 sp³ 軌域**（C–H 或 C–C σ 鍵）與碳陽離子**空的 p 軌域**部分重疊。
- 即使烷基會旋轉，總有一個 σ 鍵與空 p 軌域對齊。
- σ 鍵的電子對「擴散」進空 p 軌域，穩定缺電子的碳。
- **定義**：**p 軌域與 σ 鍵之間的重疊**稱為超共軛。

```
      空 p 軌域
         ○             H
         │   弱重疊   ╱
   H ─── C⁺ ~~~~~~ C ─ H     ← 相鄰 C–H σ 鍵的電子
        ╱          ╲           部分流入空 p 軌域
       H            H
    碳陽離子        烷基
```

**穩定性順序**：

$$
\boxed{\mathrm{R_3C^+}\ (3^\circ) > \mathrm{R_2CH^+}\ (2^\circ) > \mathrm{RCH_2^+}\ (1^\circ) > \mathrm{CH_3^+}\ (\text{甲基})}
$$

**(3) 共振穩定（resonance stabilization）**
- 若碳陽離子旁邊有 **π 鍵**，π 鍵的填滿 p 軌域會與空 p 軌域重疊，形成**非定域（delocalized）**的離子，正電荷由**兩個碳**分擔。
- **共振對碳陽離子的穩定效果特別顯著。**

**例：烯丙基型碳陽離子（allylic carbocation）**

$$
\left[\ \mathrm{CH_2{=}CH{-}\overset{+}{C}H{-}CH_3 \;\longleftrightarrow\; \overset{+}{C}H_2{-}CH{=}CH{-}CH_3}\ \right]
\;\equiv\;
\mathrm{\overset{\delta+}{C}H_2{\cdots}CH{\cdots}\overset{\delta+}{C}H{-}CH_3}
$$

### 3-4 碳陽離子的兩種典型反應

以**三級丁基溴**在乙醇中加熱為例：

**(a) 生成碳陽離子**

$$
\mathrm{(CH_3)_3C{-}Br \xrightarrow{\Delta,\ CH_3CH_2OH} (CH_3)_3C^+ + Br^-}
$$

高度取代的鹵烷在**極性溶劑（polar solvent）**中加熱可以**解離（ionize）**。

**(b-1) 作為親電子基：被親核基（常為溶劑）攻擊**

$$
\mathrm{(CH_3)_3C^+ + CH_3CH_2\ddot{O}H \longrightarrow (CH_3)_3C{-}\overset{+}{O}(H)CH_2CH_3 \xrightarrow{-H^+} (CH_3)_3C{-}O{-}CH_2CH_3}
$$

（生成三級丁基乙基醚 *tert*-butyl ethyl ether）

**(b-2) 作為強質子酸：把 H⁺ 交給弱鹼（常為溶劑）**

$$
\mathrm{(CH_3)_3C^+ + CH_3CH_2OH \longrightarrow CH_2{=}C(CH_3)_2 + CH_3CH_2\overset{+}{O}H_2}
$$

（失去相鄰碳上的 H⁺，生成烯類 2-甲基丙烯 2-methylpropene，即異丁烯 isobutylene）

> 這兩種反應分別對應第 6、7 章的 **S_N1（取代）**與 **E1（脫去）**反應。

## 4. 自由基（Free Radicals）：結構面

### 4-1 結構（Figure 4-16）

- 與碳陽離子相似：**sp² 混成**，**平面**或**接近平面**。
- 差別在於垂直於平面的 p 軌域**不是空的**，而是裝有**一個奇數電子（odd electron）**。
- 價殼層 **7 個電子**，**中性**。

### 4-2 缺電子與穩定性

- 自由基與碳陽離子都**缺電子**（沒有完整八隅體），所以**都被推電子的烷基穩定**。
- 由 BDE（Part 4，Figure 4-7）可證實：形成越高度取代的自由基，所需能量越少。

$$
\boxed{3^\circ > 2^\circ > 1^\circ > \text{甲基}}
$$

### 4-3 共振穩定

自由基旁邊有 π 鍵時，奇數電子可以**非定域化**到兩個碳上。**共振對自由基的穩定效果特別顯著**（例如烯丙基、苄基自由基，Part 4）。

$$
\left[\ \mathrm{CH_2{=}CH{-}\dot{C}H{-}CH_3 \;\longleftrightarrow\; \dot{C}H_2{-}CH{=}CH{-}CH_3}\ \right]
\;\equiv\;
\mathrm{\overset{\delta\cdot}{C}H_2{\cdots}CH{\cdots}\overset{\delta\cdot}{C}H{-}CH_3}
$$

> **解題提示（課本 HINT）**：只要沒有完整八隅體，不論是否帶形式電荷，都稱為**缺電子**。BH₃、BF₃ 的硼不帶電，卻是強親電子基（路易斯酸）。同理，碳陽離子（6 電子，帶正電）與自由基（7 電子，中性）都缺電子，反應性都很高。

### 4-4 應用：維生素 B₁₂

維生素 B₁₂ 是必需的飲食因子，缺乏會導致**貧血（anemia）**與**神經損傷（neurological damage）**。它輔助兩種酵素**產生並穩定甲基自由基**，這些甲基自由基再用於合成重要的細胞成分。

## 5. 碳陰離子（Carbanion）

### 5-1 結構

- 三價碳**帶負電**：三個鍵 ＋ 一對孤對電子 → 價殼層 **8 個電子**
- **不缺電子**，而是**富電子（electron-rich）** → **強親核基（nucleophile）／路易斯鹼（Lewis base）**
- 電子結構與**胺（amine）**相同，可與氨比較：

```
       H                   H
       |                   |
   H — C:⁻             H — N:
       |                   |
       H                   H
   甲基陰離子             氨
 (methyl anion)        (ammonia)
```

- 簡單碳陰離子為 **sp³ 混成**，**四面體（tetrahedral）**，其中一個頂點由**孤對電子**占據，所以形狀是**三角錐（trigonal pyramidal）**（Figure 4-17）。

### 5-2 反應性

- 碳陰離子的負電荷在碳上，碳的**陰電性（electronegativity）**比氮低，較不能容納負電荷 → 碳陰離子是比胺**更強的鹼**與**更強的親核基**。
- 碳陰離子鹼性強到可以從**氨**奪取質子：

$$
\mathrm{R_3C:^- + H{-}NH_2 \longrightarrow R_3C{-}H + {}^-:NH_2}
$$

- 如同其他強鹼，碳陰離子**不太可能存在於酸性溶液中**。

### 5-3 穩定性：與碳陽離子、自由基**相反**

碳陰離子已經富電子，**推電子**的烷基會使它**更不穩定**：

$$
\boxed{\text{甲基} > 1^\circ > 2^\circ > 3^\circ}\quad(\text{碳陰離子})
$$

### 5-4 真正常見的碳陰離子：由鄰近基團穩定

有機反應中出現的碳陰離子，幾乎都由鄰近基團穩定：

**(1) 誘導效應**：**拉電子（electron-withdrawing）**的鹵素原子經由 σ 鍵拉走電子密度，分散負電荷。例如 ⁻CBr₃（見第 6 節）。

**(2) 共振**：**羰基（carbonyl group, C=O）**的 π 鍵可與碳陰離子的非鍵電子重疊，把負電荷**非定域化到陰電性大的氧原子上**。

$$
\mathrm{H{-}CH_2{-}CHO + {}^-OH \longrightarrow
\left[\ {}^-:CH_2{-}CH{=}O \;\longleftrightarrow\; CH_2{=}CH{-}O:^-\ \right] + H_2O}
$$

- 這種共振穩定的碳陰離子稱為**烯醇離子（enolate ion）**（第 22 章）。
- 為了有效共振，帶負電的碳必須是 **sp² 混成**、**平面**的（第 1-17 節），這樣它的孤對電子才位於 p 軌域，能與 C=O 的 π 系統平行重疊。
- **共振穩定的碳陰離子是有機反應中最常見的碳陰離子。**

> ⚠️ **易錯點**：簡單碳陰離子是 sp³（三角錐），但**共振穩定**的碳陰離子是 **sp²**（平面）。混成會「為了共振而改變」。

## 6. 碳烯（Carbenes）

### 6-1 定義與結構

- **不帶電**的反應中間體，含有**二價碳**（只有兩個鍵）。
- 最簡單的碳烯是 **:CH₂**，稱為**亞甲基（methylene）**。分子中的 –CH₂– 基團也稱為亞甲基。
- 碳原子價殼層只有 **6 個電子**：2 個鍵（4 e⁻）＋ 1 對孤對電子（2 e⁻）。
- **sp² 混成**、**平面三角形**電子幾何：
  - **孤對電子**占據一個 **sp² 混成軌域**
  - 另有一個**空的 p 軌域**，垂直於分子平面

```
         空 p 軌域
            ○
            │
      Br ── C ── (sp² 軌域中的孤對電子 ‥)
           ╱
         Br
      二溴碳烯（dibromocarbene），:CBr₂
```

- 同時具有**孤對電子**（可作**親核基**）與**空 p 軌域**（可作**親電子基**）→ **兩者皆可**。

### 6-2 生成方法

**方法 1：碳陰離子脫去鹵離子（α-消去 α-elimination）**

以強鹼從三溴甲烷（tribromomethane，俗名溴仿 bromoform）奪取質子：

$$
\mathrm{HCBr_3 + {}^-OH \longrightarrow {}^-:CBr_3 + H_2O}
$$

生成的碳陰離子由三個 Br 的**誘導效應**穩定。它接著**逐出溴離子**，得到二溴碳烯：

$$
\mathrm{{}^-:CBr_3 \longrightarrow :CBr_2 + Br^-}
$$

**方法 2：重氮甲烷（diazomethane）加熱或照光**

$$
\mathrm{\overset{-}{C}H_2{-}\overset{+}{N}{\equiv}N \xrightarrow{\Delta\ \text{或}\ h\nu} :CH_2 + N{\equiv}N}
$$

驅動力是生成**非常穩定的 N₂ 分子**（強三鍵、氣體逸出使熵增加）。

### 6-3 反應

**(1) 加成到雙鍵上形成環丙烷（cyclopropane）**：碳烯最常見的合成用途

$$
\text{環己烯（cyclohexene）} + :\mathrm{CBr_2} \longrightarrow \text{7,7-二溴雙環[4.1.0]庚烷（7,7-dibromobicyclo[4.1.0]heptane）}
$$

**(2) 二聚化（dimerization）**：兩個碳烯相撞，**立即**結合成烯類

$$
\mathrm{R_2C: + :CR_2 \xrightarrow{\text{非常快}} R_2C{=}CR_2}
$$

所以**沒有任何簡單碳烯曾被純化或以高濃度製備**。實務上必須在**目標化合物存在下**生成碳烯，使它一生成就能立刻反應，濃度保持很低。

**碳烯與類碳烯（carbenoid，carbene-like reagent）**可用於合成，也可用於研究反應機構（第 8 章）。

> **補充（課本未詳述）**：碳烯有**單重態（singlet）**與**三重態（triplet）**兩種電子組態。上述「孤對電子在 sp²、p 軌域全空」的描述是**單重態**。鹵碳烯（如 :CBr₂）主要以單重態存在，因為鹵素的孤對電子可以捐給空 p 軌域而穩定它；:CH₂ 的基態則是三重態（兩個未成對電子）。了解即可，不必深究。

## 7. 公式與原理推導

### 7-1 以形式電荷與價電子數辨識中間體

**形式電荷（formal charge）**：

$$
\mathrm{FC} = V - N - \frac{B}{2}
$$

- $V$ ＝ 原子的價電子數（碳 ＝ 4）
- $N$ ＝ 非鍵結電子數
- $B$ ＝ 鍵結電子數

**碳周圍的價電子總數** ＝ $N + B$

| 中間體 | 鍵數 | B | N | FC ＝ 4 − N − B/2 | 價電子總數 N + B | 八隅體？ |
|---|---|---|---|---|---|---|
| 碳陽離子 | 3 | 6 | 0 | 4 − 0 − 3 ＝ **+1** | 6 | ✗ 缺電子 |
| 自由基 | 3 | 6 | 1 | 4 − 1 − 3 ＝ **0** | 7 | ✗ 缺電子 |
| 碳陰離子 | 3 | 6 | 2 | 4 − 2 − 3 ＝ **−1** | 8 | ✓ 富電子 |
| 碳烯 | 2 | 4 | 2 | 4 − 2 − 2 ＝ **0** | 6 | ✗ 缺電子（但有孤對電子） |
| （對照）烷類碳 | 4 | 8 | 0 | 4 − 0 − 4 ＝ 0 | 8 | ✓ |

**判斷流程**：
1. 數碳的**鍵數**：3 個鍵 → 碳陽離子／自由基／碳陰離子；2 個鍵 → 碳烯。
2. 三價碳再看**電荷**：＋ → 碳陽離子；中性（帶一個點）→ 自由基；− → 碳陰離子。

---

### 7-2 以 VSEPR 判斷混成與幾何形狀

**電子域數（electron domains）** ＝ 鍵結原子數 ＋ 孤對電子數

| 中間體 | 鍵結原子 | 孤對 | 電子域 | 混成 | 幾何形狀 | 鍵角 |
|---|---|---|---|---|---|---|
| 碳陽離子 | 3 | 0 | 3 | **sp²** | 平面三角形 | 120° |
| 自由基 | 3 | 單一電子* | 約 3 | **約 sp²** | 平面或接近平面 | 約 120° |
| 碳陰離子（簡單） | 3 | 1 | 4 | **sp³** | 三角錐 | 約 107°～109.5° |
| 碳陰離子（共振穩定） | 3 | 1（在 p 軌域） | — | **sp²** | 平面 | 120° |
| 碳烯（單重態） | 2 | 1 | 3 | **sp²** | 彎曲（bent） | 約 100°～120° |

\* 單一電子的排斥力小於一對電子，不足以把結構推成錐形。自由基的能量曲面很平，所以是「平面或接近平面」。

**物理意義**：空的或半滿的軌域應放在**能量最高**的 p 軌域；填滿的孤對電子應盡量放在 **s 成分較高**（能量較低）的軌域。所以碳陽離子把「空位」放在 p 軌域，簡單碳陰離子則把孤對電子放在 sp³ 軌域（具 25% s 成分）。

---

### 7-3 超共軛的計數：為何 3° > 2° > 1° > 甲基？

能與陽離子（或自由基）中心**空的（或半滿的）p 軌域**重疊的，是**相鄰碳（β 碳）**上的 C–H 或 C–C σ 鍵。粗略計算可用於超共軛的 **β C–H 鍵數**：

| 碳陽離子 | 結構 | 相鄰烷基數 | 可超共軛的 β C–H 鍵數 |
|---|---|---|---|
| 甲基 | ⁺CH₃ | 0 | **0** |
| 1°（乙基） | CH₃–⁺CH₂ | 1 | **3** |
| 2°（異丙基） | (CH₃)₂⁺CH | 2 | **6** |
| 3°（三級丁基） | (CH₃)₃C⁺ | 3 | **9** |

**超共軛作用越多 → 正電荷分散越好 → 越穩定。** 再加上誘導效應同方向加成，便得到 3° > 2° > 1° > 甲基。

**定量印證**（自由基，由 Part 4 的 BDE）：每多一個烷基，C–H BDE 約降低 10～16 kJ/mol：

$$
439\ (\text{甲基}) \xrightarrow{-16} 423\ (1^\circ) \xrightarrow{-10} 413\ (2^\circ) \xrightarrow{-10} 403\ (3^\circ)
$$

碳陽離子帶**完整正電荷**，對推電子效應的需求遠大於自由基，所以取代基造成的穩定化差異**更大**（氣相中每級約差 60～80 kJ/mol）。這是為何第 6 章中 1° 碳陽離子幾乎不會生成，而 3° 碳陽離子很常見。

---

### 7-4 推電子基對「缺電子」與「富電子」物種的相反效應

**統一原理**：

$$
\text{中心碳的電子需求} \times \text{取代基的電子效應} = \text{穩定或不穩定}
$$

| 取代基效應 | 碳陽離子（缺電子，+） | 自由基（缺電子，0） | 碳陰離子（富電子，−） |
|---|---|---|---|
| **推電子**（烷基） | 穩定（強） | 穩定（中） | **不穩定** |
| **拉電子**（鹵素、C=O、C≡N） | 不穩定 | 影響較複雜 | **穩定** |
| **共振**（相鄰 π 鍵） | 穩定（強） | 穩定（強） | 穩定（強，尤其負電荷可到 O、N） |

**記憶法**：
- 「**缺什麼補什麼**」：缺電子的物種需要推電子基；富電子的物種需要拉電子基。
- **共振對三者都有利**，因為電荷（或未成對電子）分散總是穩定的。

---

### 7-5 碳陰離子的鹼性：用 pKa 定量

碳陰離子的鹼性由其**共軛酸（conjugate acid）**的 pKa 表示：pKa 越大 → 共軛鹼越強。

| 共軛酸 | 共軛鹼 | pKa（約） |
|---|---|---|
| CH₄（烷類 C–H） | ⁻CH₃（烷基碳陰離子） | 約 50 |
| NH₃ | ⁻NH₂（胺基離子 amide ion） | 約 36（部分教材 38） |
| CH₃COCH₃（丙酮 acetone） | ⁻CH₂COCH₃（烯醇離子） | 約 19 |
| H₂O | ⁻OH | 15.7 |
| CH₃COCH₂COCH₃（乙醯丙酮） | 雙羰基穩定的碳陰離子 | 約 9 |

（pKa 為常見文獻值，課本此節未列出）

**驗證課本所述「碳陰離子可從氨奪取質子」**：

$$
\mathrm{R_3C^- + NH_3 \rightleftharpoons R_3CH + NH_2^-}
\qquad
K = 10^{\,\mathrm{p}K_a(\mathrm{R_3CH}) - \mathrm{p}K_a(\mathrm{NH_3})} \approx 10^{50-36} = 10^{14}
$$

平衡**極度偏右**。

**共振穩定的威力**：丙酮的 α-氫 pKa 約 19，比烷類（約 50）酸性強了 **10³¹ 倍**，全歸功於羰基的共振穩定。乙醯丙酮有**兩個**羰基共同分散負電荷，pKa 更降到約 9，因此連 NaOH 都能完全去質子化（見例題 5）。

---

### 7-6 抑制劑為何有效：以 BDE 做能量分析

以酚類抑制劑 ArO–H 攔截烷基自由基 R· 為例（ArO–H 的 BDE 約 360 kJ/mol，文獻值；烷類 C–H 約 400～440 kJ/mol）：

**(1) 攔截步驟**

$$
\mathrm{R\cdot + ArO{-}H \longrightarrow R{-}H + ArO\cdot}
\qquad
\Delta H^\circ \approx 360 - 420 = -60\ \mathrm{kJ/mol}
$$

→ **放熱且快速** ✓

**(2) ArO· 試圖延續連鎖**（例如奪取另一個烷類 R′–H 的氫）

$$
\mathrm{ArO\cdot + R'{-}H \longrightarrow ArO{-}H + R'\cdot}
\qquad
\Delta H^\circ \approx 420 - 360 = +60\ \mathrm{kJ/mol}
$$

→ **吸熱**，而且 Eₐ ≥ 60 kJ/mol，太慢 ✗

ArO· 只能等待與另一個自由基相遇而**終止**（BHA 的情況是再捕捉一個自由基，生成醌）。

**酚 O–H 為何這麼弱？** 生成的苯氧自由基可以**共振**，把未成對電子分散到苯環上。BHA 與維生素 E 的苯環上還有推電子基（–OCH₃、烷基），進一步穩定這個自由基。

## 8. 例題詳解（課文 Problem）

### 例題 1（Problem 4-26）BHA 自由基的共振式

**題目**：畫出共振式，說明 BHA 自由基如何藉由把自由基電子非定域化到其他原子而獲得穩定。

**詳解**：

BHA 為對位帶有 –OCH₃、鄰位帶有三級丁基（*tert*-butyl）的酚。失去 O–H 的氫後，未成對電子原本在氧上。氧上的奇數電子可與苯環的 π 系統共振，移到苯環的**鄰位（ortho）**與**對位（para）**碳：

```
  (i) 奇數電子在 O          (ii) 在鄰位碳            (iii) 在另一個鄰位碳        (iv) 在對位碳
                                                                              
       ·O:                     O                       O                         O
        |                     ‖                       ‖                         ‖
      ╱   ╲                  ╱   ╲                   ╱   ╲                     ╱   ╲
     ‖     |  tBu   ◄──►   |     Ċ tBu   ◄──►     Ċ     |  tBu    ◄──►      ‖     ‖ tBu
     |     ‖                ‖     |                 |     ‖                   |     |
      ╲   ╱                  ╲   ╱                   ╲   ╱                     ╲   ╱
        |                      |                       |                         Ċ
       OCH₃                   OCH₃                    OCH₃                       OCH₃
```

（示意：C=O 形成時，苯環上的一個雙鍵移位，奇數電子依序出現在兩個鄰位碳與對位碳上）

**重點**：
- 奇數電子分散在 **4 個原子**上（O、兩個鄰位 C、對位 C）→ 自由基很穩定。
- 對位上的 –OCH₃ 的氧還能以孤對電子進一步穩定對位碳上的奇數電子。
- 鄰位的大體積**三級丁基**提供**立體障礙（steric hindrance）**，阻止這個自由基去攻擊其他分子，使它更不容易延續連鎖。

### 例題 2（Problem 4-27）維生素 E 與氧化性自由基的反應

**題目**：寫出維生素 E 與氧化性自由基（RO·）反應，生成 ROH 與反應性較低的自由基的方程式。

**詳解**：

維生素 E 是一種**酚**，反應位置是苯環上的 **O–H**：

$$
\text{維生素 E}{-}\mathrm{O{-}H} + \mathrm{RO\cdot} \longrightarrow \text{維生素 E}{-}\mathrm{O\cdot} + \mathrm{RO{-}H}
$$

- 生成的**苯氧自由基**（維生素 E 自由基，tocopheroxyl radical）與 BHA 自由基一樣，可以共振把奇數電子分散到苯環上。
- 苯環上的三個甲基（推電子）與環上醚氧的孤對電子進一步穩定它，所以它反應性低，不會延續連鎖。
- 維生素 E 帶有長烷基鏈（R），是**脂溶性**的，所以能保護**細胞膜**中的脂質；維生素 C 則是**水溶性**的，在細胞內外水相中作用。兩者可互補。

### 例題 3（Problem 4-28）三苯甲基陽離子為何非常穩定？

**題目**：三苯甲基陽離子（triphenylmethyl cation，又稱 trityl cation）(C₆H₅)₃C⁺ 非常穩定，它的某些鹽類可以保存數個月。解釋原因。

**詳解**：

**(1) 大規模的共振穩定**
- 中心碳陽離子的空 p 軌域與**三個苯環**的 π 系統共軛。
- 正電荷可以非定域化到**每個苯環的鄰位與對位**碳上。
- 共振式數目：中心碳 1 個 ＋ 每個苯環 3 個（2 鄰位 ＋ 1 對位）× 3 個苯環 ＝ **10 個**正電荷位置。

$$
\mathrm{Ph_3C^+ \longleftrightarrow} \text{（正電荷在苯環 A 的鄰、對位）} \longleftrightarrow \text{（苯環 B）} \longleftrightarrow \text{（苯環 C）}
$$

**(2) 三級碳陽離子**：中心碳連接三個取代基。

**(3) 立體保護**：三個苯環呈**螺旋槳狀（propeller-shaped）**排列（因立體排斥，無法完全共平面），把中心碳遮住，使親核基較難接近。

**結論**：正電荷高度分散加上立體保護，使它能以穩定的鹽類（例如 Ph₃C⁺ BF₄⁻）存在。

### 例題 4（Problem 4-29 ＆ 4-30）排列碳陽離子與自由基的穩定性

**題目**：將下列碳陽離子（4-29）及對應的自由基（4-30）依穩定性遞減排列，並分類為 1°、2° 或 3°。

(a) 異戊基（isopentyl）：(CH₃)₂CHCH₂–CH₂⁺（或 ·CH₂）
(b) 3-甲基-2-丁基（3-methyl-2-butyl）：CH₃–CH⁺–CH(CH₃)₂
(c) 2-甲基-2-丁基（2-methyl-2-butyl）：CH₃–C⁺(CH₃)CH₂CH₃
(d) 環己烯環上**帶甲基、並與環內雙鍵相鄰**的碳帶正電（或奇數電子）：1-甲基環己-2-烯-1-基陽離子（自由基）（1-methylcyclohex-2-en-1-yl cation / radical）

**詳解**：

| | 結構 | 分類 | 額外穩定化 |
|---|---|---|---|
| (a) | (CH₃)₂CHCH₂CH₂⁺ | **1°** | 無 |
| (b) | CH₃CH⁺CH(CH₃)₂ | **2°** | 無 |
| (c) | (CH₃)₂C⁺CH₂CH₃ | **3°** | 無 |
| (d) | 1-甲基環己-2-烯-1-基 | **3°** | **烯丙位共振**：正電荷（或奇數電子）分散到 C1 與 C3 |

**穩定性順序（碳陽離子與自由基相同）**：

$$
\mathbf{(d) > (c) > (b) > (a)}
$$

**理由**：(d) 同時具有三級取代與烯丙位共振，**共振的穩定效果大於增加一個烷基**，所以最穩定。其餘依 3° > 2° > 1° 排列。

**(d) 的共振式**（以陽離子為例，自由基相同，只要把 ＋ 換成 ·）：

```
        CH₃                       CH₃
        |                         |
        C1⁺                       C1
      ╱    ╲                    ╱    ╲
    C6      C2        ◄──►    C6      C2
    |       ‖                 |       |
    C5      C3                C5      C3⁺
      ╲    ╱                    ╲    ╱
        C4                        C4       （雙鍵由 C2=C3 移到 C1=C2）
  正電荷在 C1（3°）         正電荷在 C3（2°）
```

兩個共振式**不等價**：正電荷在三級碳 C1 上的共振式較穩定，貢獻較大。

### 例題 5（Problem 4-31）乙醯丙酮的碳陰離子

**題目**：乙醯丙酮（acetylacetone，pentane-2,4-dione）與氫氧化鈉反應，生成水與碳陰離子的鈉鹽。寫出此碳陰離子的完整結構式，並以共振式說明其穩定性。

$$
\mathrm{CH_3{-}\overset{O}{\overset{\|}{C}}{-}CH_2{-}\overset{O}{\overset{\|}{C}}{-}CH_3}
$$

**詳解**：

**去質子化位置**：兩個羰基之間的 **CH₂**（C3）。這個氫同時受兩個 C=O 活化，酸性最強（pKa 約 9）。

$$
\mathrm{CH_3COCH_2COCH_3 + NaOH \longrightarrow Na^+\,[CH_3CO\overset{-}{C}HCOCH_3] + H_2O}
$$

**三個共振式**：

```
   (i) 負電荷在 C3           (ii) 負電荷在左邊 O          (iii) 負電荷在右邊 O

      O       O                 :O:⁻     O                   O       :O:⁻
      ‖       ‖                  |       ‖                   ‖        |
 CH₃–C–C̈H⁻–C–CH₃   ◄──►   CH₃–C=CH–C–CH₃    ◄──►   CH₃–C–CH=C–CH₃
                               
```

**分析**：
- 負電荷分散在 **3 個原子**上（1 個 C、2 個 O）。
- 其中 (ii)、(iii) 把負電荷放在**陰電性大的氧**上，是**主要貢獻者（major contributors）**。
- C3 必須是 **sp² 混成**，整個 O=C–C–C=O 部分呈**平面**，以利共振。
- 兩個羰基共同穩定，所以乙醯丙酮的酸性（pKa ≈ 9）比丙酮（pKa ≈ 19）強約 10¹⁰ 倍，甚至比水（15.7）還強。因此 NaOH 可以把它**完全**去質子化。

### 例題 6（Problem 4-32）丙腈的碳陰離子

**題目**：丙腈（propionitrile，:N≡C–CH₂CH₃）可被非常強的鹼去質子化。寫出所得碳陰離子的共振式。

**詳解**：

去質子化位置：與氰基（cyano group, –C≡N）相鄰的 **α 碳**（CH₂）。

$$
\mathrm{:N{\equiv}C{-}\overset{..}{\overset{-}{C}}H{-}CH_3 \;\longleftrightarrow\; {}^{-}:\overset{..}{N}{=}C{=}CH{-}CH_3}
$$

- 左：負電荷在碳上
- 右：負電荷在**陰電性較大的氮**上（C≡N 的一個 π 鍵移到氮成為孤對電子，碳陰離子的孤對電子形成新的 C=C）

**比較**：C≡N 對碳陰離子的穩定效果類似 C=O，但氮的陰電性比氧小，所以效果略弱（腈類 α-H 的 pKa 約 25，需要「非常強的鹼」）。

### 例題 7（Problem 4-33）重氮乙酸甲酯分解生成碳烯

**題目**：重氮乙酸甲酯（methyl diazoacetate）強熱時分解，放出氮氣並生成一個碳烯。畫出該碳烯的路易斯結構。

$$
\mathrm{{}^{-}\overset{..}{C}H(\overset{+}{N}{\equiv}N){-}\overset{O}{\overset{\|}{C}}{-}O{-}CH_3}
$$

**詳解**：

仿照重氮甲烷分解成 :CH₂ 的模式：C–N 鍵斷裂，N₂ 帶走電子離開：

$$
\mathrm{N_2{=}CH{-}COOCH_3 \xrightarrow{\Delta} :CH{-}COOCH_3 + N{\equiv}N}
$$

**碳烯的路易斯結構**：

```
         ‥              O
     H — C — C         ‖
              ╲       
         （碳烯碳）  C — O — CH₃
```

更清楚的寫法：

$$
\mathrm{H{-}\ddot{C}{-}C({=}\ddot{O}){-}\ddot{O}{-}CH_3}
$$

- 碳烯碳：**2 個鍵**（C–H、C–C）＋ **1 對孤對電子** → 6 個價電子，形式電荷 0。
- 名稱：**甲氧羰基碳烯（carbomethoxycarbene，methoxycarbonylcarbene）**。
- 驅動力：生成穩定的 N₂（強三鍵 ＋ 氣體逸出）。

## 11. 章末挑戰題精選詳解

### ★ 挑戰題 1（課本 4-45）畫出自由基的重要共振式

**題目**：畫出下列自由基的重要共振式。
(a) CH₂=CH–·CH₂（烯丙基自由基 allyl radical）
(b) C₆H₅–·CH₂（苄基自由基 benzyl radical）
(c) CH₃–C(=O)–O·（乙醯氧基自由基 acetoxy radical）
(d) 環己-2-烯-1-基自由基（cyclohex-2-en-1-yl radical）：環己烯中與雙鍵相鄰的環碳帶奇數電子
(e) 2-亞甲基環己基自由基（2-methylenecyclohexyl radical）：環上帶奇數電子的碳，旁邊的環碳有環外雙鍵 C=CH₂
(f) C₆H₅–O·（苯氧自由基 phenoxy radical）

**畫自由基共振式的規則**：
1. 用**半箭頭**：每移動一個電子畫一支。
2. 標準模式：「**奇數電子 ＋ 相鄰 π 鍵**」→ 奇數電子與 π 鍵的一個電子配對形成新 π 鍵，π 鍵的另一個電子移到**遠端**原子上，成為新的奇數電子。
3. **原子位置不動**，只有電子移動。
4. 每個共振式的**未成對電子數必須相同**（都是 1 個）。

**詳解**：

**(a) 烯丙基自由基**

```
      ⇀⇀            ⇀
   CH₂ = CH — ĊH₂   ◄──►   ĊH₂ — CH = CH₂
   （奇數電子在 C3）         （奇數電子在 C1）
```

半箭頭：
- C3 的奇數電子 → 移向 C2–C3 之間，形成新 π 鍵的一半
- C1=C2 π 鍵中的一個電子 → 移向 C2–C3 之間，形成新 π 鍵的另一半
- C1=C2 π 鍵中的另一個電子 → 留在 C1，成為新的奇數電子

**混成共振體（resonance hybrid）**：

$$
\mathrm{\overset{\delta\cdot}{C}H_2{\cdots}CH{\cdots}\overset{\delta\cdot}{C}H_2}
$$

- 兩個共振式**完全等價**（對稱），貢獻相同。
- 奇數電子均分在 C1 與 C3；中間 C2 **沒有**奇數電子。
- 兩個 C–C 鍵等長（約 1.5 級鍵）。
- 這解釋了烯丙位 C–H 的 BDE 只有 372 kJ/mol（Table 4-2）。

**(b) 苄基自由基**

奇數電子從苯甲基碳（benzylic carbon）經共振進入苯環，出現在**鄰位（2 個）**與**對位（1 個）**：

```
 (i) 奇數電子在苄基碳       (ii) 在一個鄰位        (iii) 在對位           (iv) 在另一個鄰位

      ĊH₂                    CH₂                    CH₂                     CH₂
       |                      ‖                      ‖                       ‖
     ╱ ╲                    ╱ ╲                    ╱ ╲                     ╱ ╲
    ‖   |       ◄──►       |   Ċ      ◄──►        |   ‖       ◄──►        Ċ   |
    |   ‖                  ‖   |                  ‖   |                   |   ‖
     ╲ ╱                    ╲ ╱                    ╲ ╱                     ╲ ╱
                                                    Ċ
```

**要點**：
- 共 **4 個**共振式：苄基碳 ＋ 2 個鄰位 ＋ 1 個對位。
- 奇數電子**不會**出現在間位（meta）或 ipso 碳（與 CH₂ 相連的環碳）上。可以用「**交替規則**」檢驗：奇數電子只會出現在與原位置相隔**偶數個鍵**的原子上。
- 結構 (ii)～(iv) 破壞了苯環的芳香性（aromaticity），貢獻較小；但整體的非定域化仍使苄基自由基非常穩定（PhCH₂–H 的 BDE 為 376 kJ/mol，遠低於一般 1° C–H 的 423）。
- 呼應 Part 4 例題 6(c)：甲苯的高辛烷值即源於此。

⚠️ **常見錯誤**：
1. 把奇數電子畫在間位（meta）上 ✗
2. 移動了原子（例如移動 H）→ 那是**互變異構（tautomerism）**，不是共振 ✗
3. 使用全箭頭 ✗

**(c) 乙醯氧基自由基**

奇數電子在單鍵氧上，旁邊就是 C=O 的 π 鍵：

```
        O                              ·O
        ‖                               |
  CH₃ — C — O·        ◄──►       CH₃ — C = O
  （奇數電子在單鍵 O）            （奇數電子移到原本的羰基 O）
```

半箭頭：單鍵 O 上的奇數電子與 C=O π 鍵的一個電子形成新的 C=O π 鍵；π 鍵的另一個電子留在原本的羰基氧上，成為新的奇數電子。

- 兩個共振式**完全等價**，奇數電子**均分在兩個氧**上，兩個 C–O 鍵等長。這與乙酸根離子（acetate ion）的負電荷分散方式完全相同。
- 奇數電子只在**氧**上，**不會**出現在羰基碳上（碳若帶奇數電子，氧就必須帶電荷分離，是很差的共振式）。
- 補充：這類醯氧自由基（acyloxy radical）很容易脫去 CO₂，生成甲基自由基（CH₃COO· → ·CH₃ + CO₂），這是**柯爾貝電解（Kolbe electrolysis）**的關鍵步驟。

**(d) 環己-2-烯-1-基自由基**

這是環狀的烯丙基自由基，也就是 Part 4 例題 9 中由環己烯生成的中間體：

```
         Ċ1                      C1
       ╱    ╲                  ╱    ╲
     C6      C2              C6      C2
     |       ‖      ◄──►     |       ‖  ← 雙鍵由 C2=C3 移到 C1=C2
     C5      C3              C5      Ċ3
       ╲    ╱                  ╲    ╱
         C4                      C4
  （奇數電子在 C1）         （奇數電子在 C3）
```

（第二個共振式中，C1=C2 為雙鍵、C2–C3 為單鍵）

- 兩個共振式**等價**（C1 與 C3 都是二級碳），奇數電子均分在 C1 與 C3。
- 所以 Br₂ 無論在哪一端反應，都得到同一個產物：3-溴環己烯。

**(e) 2-亞甲基環己基自由基**

奇數電子在環碳 C1 上，相鄰的 C2 有**環外雙鍵（exocyclic double bond）**C2=CH₂：

```
          CH₂                              ĊH₂
          ‖                                 |
    Ċ1 ── C2                         C1 ═══ C2
   ╱        ╲          ◄──►         ╱        ╲
  C6         C3                    C6         C3
   ╲        ╱                       ╲        ╱
    C5 ── C4                         C5 ── C4
 （奇數電子在環碳 C1，2°；       （奇數電子在環外 CH₂，1°；
   環外雙鍵，二取代）              環內雙鍵 C1=C2，三取代）
```

- 兩個共振式**不等價**：
  - 左：自由基在 **2°** 碳上，但雙鍵只是**二取代**的環外雙鍵。
  - 右：自由基在 **1°** 碳上，但雙鍵變成較穩定的**三取代**環內雙鍵。
- 兩者各有優缺點，**都是重要的共振式**，貢獻相近。
- 右側共振式也可以看成**環己-1-烯基甲基自由基（cyclohex-1-enylmethyl radical）**。所以從 1-甲基環己烯奪取甲基上的 H，與從亞甲基環己烷奪取環上烯丙位的 H，會得到**同一個**自由基。

**(f) 苯氧自由基**

與 (b) 苄基自由基的模式相同，但中心原子換成**氧**：

```
 (i) 奇數電子在 O        (ii) 在一個鄰位          (iii) 在對位           (iv) 在另一個鄰位

       ·O:                     O                      O                       O
        |                      ‖                      ‖                       ‖
      ╱   ╲                  ╱   ╲                  ╱   ╲                   ╱   ╲
     ‖     |     ◄──►       |     Ċ      ◄──►      |     ‖      ◄──►       Ċ     |
     |     ‖                ‖     |                ‖     |                 |     ‖
      ╲   ╱                  ╲   ╱                  ╲   ╱                   ╲   ╱
                                                      Ċ
```

- 共 **4 個**共振式：O、兩個鄰位 C、對位 C。
- 共振式 (ii)～(iv) 雖然破壞了芳香性，但生成了**很強的 C=O 鍵**，所以貢獻相當可觀。
- 這正是 BHA、維生素 E 等酚類抗氧化劑的自由基如此穩定的原因（例題 1、例題 2）。

**4-45 總整理**

| | 自由基 | 共振式數 | 奇數電子分佈位置 | 共振式等價？ |
|---|---|---|---|---|
| (a) | 烯丙基 | 2 | C1、C3 | 等價 |
| (b) | 苄基 | 4 | 苄基 C、2 個鄰位、對位 | 不等價 |
| (c) | 乙醯氧基 | 2 | 兩個 O | 等價 |
| (d) | 環己-2-烯-1-基 | 2 | C1、C3 | 等價 |
| (e) | 2-亞甲基環己基 | 2 | 環上 C1、環外 CH₂ | 不等價（貢獻相近） |
| (f) | 苯氧 | 4 | O、2 個鄰位、對位 | 不等價 |

**共通規則**：奇數電子只能經由**相鄰的 π 鍵**移動，而且只會出現在與原位置相隔**偶數個鍵**的原子上（1,3-關係）。

### ★ 挑戰題 2（課本 4-52）二氯甲烷與強鹼生成的類碳烯中間體

**題目**：二氯甲烷（dichloromethane）以強 NaOH 處理時，會生成一個反應行為類似碳烯的中間體。畫出此反應中間體的結構，並提出其生成機構。

**詳解**：

**Step 1　鹼奪取質子，生成碳陰離子**

$$
\mathrm{H{-}CHCl_2 + {}^-OH \longrightarrow {}^-:CHCl_2 + H_2O}
$$

- 生成**二氯甲基陰離子（dichloromethyl anion）**。
- 此碳陰離子由兩個 Cl 的**誘導效應**（拉電子）穩定，所以 CH₂Cl₂ 的 C–H 具有一定酸性。

**Step 2　碳陰離子逐出氯離子（α-消去 α-elimination）**

$$
\mathrm{{}^-:CHCl_2 \longrightarrow :CHCl + Cl^-}
$$

- 生成**氯碳烯（chlorocarbene，:CHCl）**。
- 稱為 **α-消去**，因為 H 與 Cl 是從**同一個碳**（α 碳）上脫去的。這與第 7 章的 β-消去（從相鄰碳脫去）不同。

**Step 3　氯碳烯的結構**

```
          空 p 軌域
             ○
             │
       H ─── C ‥  ← 孤對電子在 sp² 軌域
            ╱
          Cl
```

| 性質 | 說明 |
|---|---|
| 鍵數 | 2（C–H、C–Cl） |
| 非鍵電子 | 1 對（位於 sp² 軌域） |
| 價電子數 | 6 |
| 形式電荷 | 0 |
| 混成 | sp² |
| 軌域 | 一個**空的 p 軌域** |
| 性質 | 親核（孤對）＋ 親電（空 p） |

**Step 4　為何題目說「反應行為類似碳烯」？**
- 實際上，由 CH₂Cl₂ 生成游離 :CHCl 比由 CHCl₃ 生成 :CCl₂ **困難得多**：
  - CH₂Cl₂ 只有**兩個** Cl 穩定碳陰離子，酸性遠低於 CHCl₃（三個 Cl）。
  - 單一 Cl 對碳烯空 p 軌域的穩定作用也較弱。
- 所以題目用「intermediate that **reacts like** a carbene」，也就是**類碳烯（carbenoid）**：這個中間體可能不是完全游離的碳烯，而是與金屬離子或溶劑有某種結合，但它的反應（例如加成到雙鍵形成氯環丙烷 chlorocyclopropane）與碳烯相同。

**與課本 CHBr₃ 例子對照**

| | CHBr₃ + ⁻OH | CH₂Cl₂ + ⁻OH |
|---|---|---|
| 碳陰離子 | ⁻CBr₃（三個 Br 穩定） | ⁻CHCl₂（兩個 Cl 穩定） |
| 碳陰離子穩定度 | 高 | 較低 → 需要更強的鹼 |
| 生成的碳烯 | :CBr₂（二溴碳烯） | :CHCl（氯碳烯） |
| 機構 | 去質子化 → α-消去 | 去質子化 → α-消去 |

**延伸應用**：若在環己烯存在下進行，會生成 **7-氯雙環[4.1.0]庚烷（7-chlorobicyclo[4.1.0]heptane）**，這是碳烯加成到雙鍵形成環丙烷的典型反應（第 8 章）。

## 本部分重點回顧

1. **自由基抑制劑**以快速、放熱的步驟攔截連鎖自由基，生成穩定、無法延續連鎖的新自由基。酚類（BHA、BHT、維生素 E）與烯二醇（維生素 C）是典型代表；一分子 BHA 可消滅兩個自由基。
2. **四種碳中間體**依「鍵數 ＋ 非鍵電子數」分類：碳陽離子（3 鍵、0 e、＋、6 e⁻）、自由基（3 鍵、1 e、中性、7 e⁻）、碳陰離子（3 鍵、2 e、−、8 e⁻）、碳烯（2 鍵、2 e、中性、6 e⁻）。
3. **混成與幾何**：碳陽離子與自由基為 sp²、平面；簡單碳陰離子為 sp³、三角錐（共振時為 sp²、平面）；碳烯為 sp²，孤對電子在 sp² 軌域、p 軌域全空。
4. **穩定性**：缺電子的碳陽離子與自由基被烷基（誘導效應、超共軛）穩定，順序為 3° > 2° > 1° > 甲基；富電子的碳陰離子順序相反，由拉電子基與共振穩定。**共振對三者都有強大的穩定作用。**
5. **反應性**：碳陽離子是親電子基與強酸；碳陰離子是親核基與強鹼；碳烯兩者皆可，會加成到雙鍵形成環丙烷，並會快速二聚。
6. **碳烯的生成**：CHX₃ ＋ 強鹼（去質子化 → α-消去）；重氮化合物加熱或照光（放出 N₂）。
