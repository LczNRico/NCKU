# 第十九章　過渡金屬與配位化學
## 19.6　晶場模型（The Crystal Field Model）

---

## 一、為何需要晶場模型？

局域電子模型（localized electron model）的最大缺陷，是它無法說明 d 軌域能量如何受錯合物形成的影響。然而，錯離子最重要的兩個性質——**顏色（color）** 與**磁性（magnetism）**——正是由 d 軌域能量的變化所決定的。

**晶場模型（crystal field model）** 專注於 d 軌域的能量，目的是解釋錯離子的顏色與磁性。在最簡單的形式下，此模型做出以下假設：

- 配體（ligands）可視為**負點電荷（negative point charges）**
- 金屬-配體鍵結（metal-ligand bonding）完全是**離子性的（entirely ionic）**

> 嚴格而言，晶場模型並非鍵結模型，而是一個解釋顏色與磁性的**能量模型**。

---

## 二、八面體錯合物（Octahedral Complexes）

### 2.1 d 軌域的空間方向與配體的相對位置

八面體錯合物中，6 個配體（負點電荷）分別位於 ±x、±y、±z 軸上。5 個 3d 軌域依其空間方向可分為兩組：

**e_g 組**（指向配體，能量較高）：

| 軌域 | 方向 |
|------|------|
| dz² | 波瓣（lobes）沿 z 軸方向，直接指向 ±z 軸配體 |
| dx²-y² | 波瓣沿 x、y 軸方向，直接指向 ±x、±y 軸配體 |

**t₂g 組**（指向配體間隙，能量較低）：

| 軌域 | 方向 |
|------|------|
| dxy | 波瓣在 xy 平面，介於 x 和 y 軸之間 |
| dxz | 波瓣在 xz 平面，介於 x 和 z 軸之間 |
| dyz | 波瓣在 yz 平面，介於 y 和 z 軸之間 |

### 2.2 d 軌域能量分裂（d-Orbital Splitting）

**原理**：負電荷配體排斥帶負電的 d 電子；d 電子越靠近配體（負點電荷），能量越高。

- **e_g 組**（dz²、dx²-y²）：波瓣直接指向配體 → 受強烈排斥 → **能量較高**
- **t₂g 組**（dxy、dxz、dyz）：波瓣指向配體間隙 → 受排斥較小 → **能量較低**

```
能量（E）
    │        ___________  e_g（dz²、dx²-y²）
    │       /     Δ
    │  ____/______
    │  自由金屬離子
    │  的 3d 軌域
    │  （五重縮並）
    │       \
    │        ───────────  t₂g（dxy、dxz、dyz）
    │
```

兩組軌域之間的能量差稱為**晶場分裂能（crystal field splitting energy）**，以符號 **Δ（delta）** 或 **Δ_oct** 表示。

> **重要**：負點電荷配體使**所有** d 軌域能量都升高（相對於自由金屬離子），但 e_g 組升高更多，t₂g 組升高較少，因此產生分裂。

### 2.3 電子如何排布在分裂的 d 軌域中

d 電子排布取決於 **Δ 的大小**與**電子配對能（pairing energy, P）** 之間的競爭：

- **強場（strong field）**：Δ 很大，電子傾向成對填入能量較低的 t₂g 組 → **低自旋（low-spin）**，未成對電子數最少
- **弱場（weak field）**：Δ 很小，電子依洪德規則（Hund's rule）優先填入所有軌域再配對 → **高自旋（high-spin）**，未成對電子數最多

**以 Co³⁺（d⁶ 電子組態）為例：**

```
強場（large Δ）——低自旋：
    e_g  ___  ___
    t₂g  ↑↓  ↑↓  ↑↓
    → 0 個未成對電子，反磁性（diamagnetic）

弱場（small Δ）——高自旋：
    e_g  ↑    ↑
    t₂g  ↑↓   ↑    ↑
    → 4 個未成對電子，順磁性（paramagnetic）
```

> **判斷原則**：d¹、d²、d³ 和 d⁸、d⁹、d¹⁰ 的電子排布不受強場/弱場影響（只有一種可能）；**d⁴、d⁵、d⁶、d⁷** 才存在高自旋與低自旋兩種可能。

## 三、光譜化學系列（Spectrochemical Series）

對多種八面體錯合物的研究顯示，配體對 d 軌域分裂的能力（Δ 的大小）有固定的排序，稱為**光譜化學系列（spectrochemical series）**：

```
CN⁻ > NO₂⁻ > en > NH₃ > H₂O > OH⁻ > F⁻ > Cl⁻ > Br⁻ > I⁻
強場配體                                             弱場配體
（large Δ）                                        （small Δ）
```

**重要規律：**

- **強場配體（strong-field ligands）**：CN⁻、NO₂⁻ 等位於系列左側，產生大的 Δ，傾向形成低自旋錯合物
- **弱場配體（weak-field ligands）**：鹵素離子（Cl⁻、Br⁻、I⁻）等位於系列右側，產生小的 Δ，傾向形成高自旋錯合物
- **同一配體，金屬離子電荷越高，Δ 越大**：因電荷密度（charge density）增加，配體被吸引更靠近金屬，排斥 d 電子的效果更強。例如 NH₃ 對 Co²⁺ 是弱場配體，但對 Co³⁺ 是強場配體。

## 四、晶場模型解釋磁性（Magnetism）

### 4.1 順磁性（Paramagnetism）與反磁性（Diamagnetism）

| 術語 | 定義 | 原因 |
|------|------|------|
| 順磁性（paramagnetism） | 被磁場吸引 | 含有未成對電子（unpaired electrons） |
| 反磁性（diamagnetism） | 被磁場微弱排斥 | 所有電子均成對（all electrons paired） |

### 4.2 應用範例

**比較 Co(NH₃)₆³⁺ 與 CoF₆³⁻：**

Co³⁺ 的 d 電子組態為 d⁶。

- NH₃ 為強場配體（large Δ）→ 低自旋（low-spin）→ t₂g 填滿（↑↓ ↑↓ ↑↓）→ 0 個未成對電子 → **反磁性（diamagnetic）**
- F⁻ 為弱場配體（small Δ）→ 高自旋（high-spin）→ 先各填一個再配對 → 4 個未成對電子 → **順磁性（paramagnetic）**

實驗結果與預測完全吻合，驗證了晶場模型的有效性。

## 五、晶場模型解釋顏色（Color）

### 5.1 顏色的來源

當可見光（visible light）照射錯離子時，若光子（photon）的能量**恰好等於** d 軌域分裂能 Δ，該波長的光就會被**吸收（absorbed）**，使 t₂g 的電子躍遷（transition）至 e_g：

```
ΔE = hc/λ
```

其中 ΔE 即為分裂能 Δ，λ 為被吸收光的波長，h 為普朗克常數（Planck's constant），c 為光速。

被吸收的顏色**不會**到達觀察者的眼睛；物質呈現的顏色是**未被吸收的互補色（complementary color）**。

### 5.2 吸收波長與觀察顏色的對應關係

| 吸收波長（nm） | 吸收顏色（color absorbed） | 觀察到的顏色（color observed） |
|--------------|--------------------------|-------------------------------|
| 400 | 紫色（violet） | 黃綠色（greenish yellow） |
| 450 | 藍色（blue） | 黃色（yellow） |
| 490 | 藍綠色（blue-green） | 紅色（red） |
| 570 | 黃綠色（yellow-green） | 紫色（violet） |
| 580 | 黃色（yellow） | 深藍色（dark blue） |
| 600 | 橙色（orange） | 藍色（blue） |
| 650 | 紅色（red） | 綠色（green） |

### 5.3 典型範例：Ti(H₂O)₆³⁺

Ti³⁺ 的 d 電子組態為 d¹，只有一個 d 電子：

- 基態：1 個電子在 t₂g 組（能量較低）
- 激發態：吸收能量，電子躍遷至 e_g 組
- Ti(H₂O)₆³⁺ 吸收**黃綠色（yellow-green）** 光（約 570 nm）
- 觀察到的顏色為互補色：**紫色（violet）**

```
能量躍遷示意：

    e_g  ___  ___
              ↑       ← 激發態（excited state）：電子在 e_g
              hν（黃綠色光被吸收）
    t₂g  ↑   ___  ___
    基態（ground state）：電子在 t₂g
```

### 5.4 配體不同導致顏色不同

因為不同配體產生不同大小的 Δ，d 電子躍遷所需能量不同，吸收不同波長的光，所以**配體改變時顏色也會改變**。

**Cr³⁺ 八面體錯合物的顏色比較：**

| 錯合物 | 配體（弱→強） | 顏色（color） |
|--------|------------|-------------|
| [Cr(H₂O)₄Cl₂]Cl | Cl⁻（弱場） | 綠色（green） |
| [Cr(H₂O)₅Cl]Cl₂ | Cl⁻/H₂O | 藍綠色（blue-green） |
| [Cr(H₂O)₆]Cl₃ | H₂O | 紫色（violet） |
| [Cr(NH₃)₄Cl₂]Cl | NH₃/Cl⁻ | 紫色（violet） |
| [Cr(NH₃)₅Cl]Cl₂ | NH₃/Cl⁻ | 紫色（purple） |
| [Cr(NH₃)₆]Cl₃ | NH₃（強場） | 黃色（yellow） |

配體場強由弱至強（Cl⁻ → H₂O → NH₃），Δ 增大，吸收波長縮短（向短波長移動），觀察到的顏色隨之改變。

> **延伸——寶石的顏色**：紅寶石（ruby）的紅色來自 Cr³⁺ 離子取代 Al₂O₃（剛玉 corundum）中約 1% 的 Al³⁺，周圍 6 個 O²⁻ 形成八面體場，導致 Cr³⁺ 的 3d 軌域分裂，強烈吸收藍紫色和黃綠色光，透射紅光。祖母綠（emerald）中的 Cr³⁺ 在鈹鋁矽酸鹽（beryl）環境中，場強略有不同，吸收黃色和藍紫色光，觀察到綠色。

## 六、其他幾何形狀的晶場圖

### 6.1 四面體錯合物（Tetrahedral Complexes）

四面體（tetrahedral）與八面體（octahedral）的差異：

**差異一：分裂大小（Splitting Magnitude）**

在四面體排列中，**沒有任何 d 軌域直接指向配體**（不像八面體中 dz² 和 dx²-y² 直接指向配體），因此配體對各 d 軌域的差別化排斥（differentiation）較小。

四面體分裂能（tetrahedral splitting energy）與八面體分裂能的關係：

```
Δ_tet = (4/9) × Δ_oct
```

即四面體分裂能約為八面體的 **4/9**（相同配體與金屬離子下）。

**差異二：軌域能量高低順序相反（Reversed Splitting Order）**

在四面體場中：
- **dxy、dxz、dyz 組**（靠近配體）：能量**較高**（對應八面體的 e_g）
- **dz²、dx²-y² 組**（遠離配體）：能量**較低**（對應八面體的 t₂g）

```
四面體晶場分裂圖：

    高能量  ───  ───  ───  dxy、dxz、dyz
                Δ_tet
    低能量  ───  ───         dz²、dx²-y²
```

**差異三：永遠是高自旋（Always High-Spin）**

由於 Δ_tet 很小（僅為 Δ_oct 的 4/9），沒有任何已知配體能夠使四面體錯合物產生低自旋情況。因此，**所有四面體錯合物均為高自旋（high-spin）**。

### 6.2 平面四方形錯合物（Square Planar Complexes）

平面四方形（square planar）可視為從八面體出發，**移除 z 軸的兩個配體**：

- 移除 ±z 軸的配體後，dz² 軌域能量大幅降低（不再被直接指向的配體排斥）
- 只有 dx²-y² 仍指向四個剩餘配體（沿 ±x、±y 方向），能量最高
- 五個 d 軌域能量由高到低排列：

```
    最高  ──────────  dx²-y²
          ──────────  dxy
          ──────────  dz²
          ──────  ──  dxz、dyz
    最低
```

### 6.3 直線形錯合物（Linear Complexes）

直線形（linear）可視為從八面體出發，**只留下 z 軸的兩個配體**：

- 僅 dz² 直接指向配體（± z 軸）→ 能量最高
- 其他 d 軌域遠離配體，能量較低

```
    最高  ──────────  dz²
          ──  ──  ──  dxy、dxz、dyz（依環境略有差異）
    最低  ──  ──      dx²-y²（遠離配體）
```

## 七、課本例題精講

### 例題一（課本 Example 19.4）

**題目**：Fe(CN)₆³⁻ 已知含有 1 個未成對電子。CN⁻ 配體對 Fe³⁺ 是強場還是弱場？

**解析：**

步驟一：確定金屬離子與電子組態

錯離子電荷 −3，6 個 CN⁻（各 −1，共 −6）→ Fe 氧化態：

```
Fe + 6(−1) = −3   →   Fe = +3
```

Fe³⁺ 的 d 電子組態：[Ar] 3d⁵，即 **d⁵**。

步驟二：分析兩種可能的排布

d⁵ 在八面體場中有兩種排布：

```
強場（large Δ）——低自旋：
    e_g  ___   ___
    t₂g  ↑↓   ↑↓   ↑
    → 1 個未成對電子

弱場（small Δ）——高自旋：
    e_g  ↑     ↑
    t₂g  ↑     ↑    ↑
    → 5 個未成對電子
```

步驟三：對照實驗

已知 Fe(CN)₆³⁻ 含有 **1 個未成對電子** → 符合強場（低自旋）排布。

**答：CN⁻ 對 Fe³⁺ 是強場配體（strong-field ligand）。**

---

### 例題二（課本 Example 19.5）

**題目**：預測錯離子 [Cr(CN)₆]⁴⁻ 中未成對電子的數目。

**解析：**

步驟一：確定金屬離子與電子組態

錯離子電荷 −4，6 個 CN⁻（各 −1，共 −6）→ Cr 氧化態：

```
Cr + 6(−1) = −4   →   Cr = +2
```

Cr²⁺ 的 d 電子組態：[Ar] 3d⁴，即 **d⁴**。

步驟二：判斷強場還是弱場

CN⁻ 在光譜化學系列中位於最強場（strong-field ligand），產生**大的 Δ**（低自旋情況）。

步驟三：畫出 d 軌域排布

d⁴ 在強場下，電子優先填滿 t₂g，不願躍越大的 Δ 至 e_g：

```
強場（large Δ）——低自旋：
    e_g  ___   ___
    t₂g  ↑↓   ↑    ↑
    → 2 個未成對電子
```

**答：[Cr(CN)₆]⁴⁻ 有 2 個未成對電子。**

> 說明：若為弱場，d⁴ 高自旋排布為 e_g(↑ ↑)、t₂g(↑ ↑ __)，4 個未成對電子。CN⁻ 的強場使電子寧可配對在 t₂g，也不跨越大的 Δ，故只有 2 個未成對電子。

### 例題三（課本 Example 19.6）

**題目**：畫出四面體錯合物 CoCl₄²⁻ 的晶場圖（crystal field diagram）。

**解析：**

步驟一：確定金屬離子與電子組態

錯離子電荷 −2，4 個 Cl⁻（各 −1，共 −4）→ Co 氧化態：

```
Co + 4(−1) = −2   →   Co = +2
```

Co²⁺ 的 d 電子組態：[Ar] 3d⁷，即 **d⁷**。

步驟二：確認為四面體場

四面體錯合物 → 分裂方向與八面體相反（dxy、dxz、dyz 在上，dz²、dx²-y² 在下），且 Δ_tet 很小 → 永遠高自旋。

步驟三：填入 7 個 d 電子（高自旋）

先各填一個（洪德規則），再從低能量開始配對：

```
高自旋四面體晶場圖：
    高能量  ↑↓   ↑↓   ↑    dxy、dxz、dyz
    低能量  ↑↓   ↑↓         dz²、dx²-y²
```

d⁷ 高自旋：5 個位置先各填一個（5 個 ↑），剩 2 個電子從最低能量開始配對。

```
    dxy  ↑↓
    dxz  ↑↓
    dyz  ↑         （高能量組，3 個位置）
    dz²  ↑↓
    dx²-y²  ↑     （低能量組，2 個位置）
```

**未成對電子數：3 個（dyz、dx²-y² 各 1 個，加上 dyz 的 1 個）→ 共 3 個未成對電子。**

**答：CoCl₄²⁻ 為高自旋四面體錯合物，有 3 個未成對電子，順磁性（paramagnetic）。**

## 八、進階例題（選自課後習題）

### 進階例題 A（Exercise 49，難度：中）

**題目**：[Cr(NH₃)₆]Cl₃ 溶液呈黃色，但 Cr(NH₃)₆³⁺ 並不吸收黃色光。為什麼？Cr(NH₃)₆³⁺ 實際上吸收哪種顏色的光？光譜化學系列（spectrochemical series）是什麼？如何利用各種錯合物吸收光的研究來建立此系列？Co(NH₃)₆²⁺ 與 Co(NH₃)₆³⁺ 哪個吸收波長較長？

**解析：**

**為何溶液呈黃色但不吸收黃色光？**

物質呈現的顏色是**未被吸收的光**（互補色 complementary color），而非被吸收的光。Cr(NH₃)₆³⁺ 呈**黃色**，表示它吸收的是黃色的互補色——**紫色（violet）** 或**藍紫色（blue-violet）** 光（約 400–450 nm）。

**光譜化學系列（spectrochemical series）：**

對多種已知組成的錯合物測量其吸收光譜（absorption spectrum），可得到 Δ 的大小。配體依 Δ 由大到小排列，即得光譜化學系列：

```
CN⁻ > NO₂⁻ > en > NH₃ > H₂O > OH⁻ > F⁻ > Cl⁻ > Br⁻ > I⁻
強場（large Δ）                                弱場（small Δ）
```

Δ 越大，d 電子躍遷所需能量越高，吸收波長越短（高頻光，偏藍紫端）。

**Co(NH₃)₆²⁺ vs. Co(NH₃)₆³⁺ 吸收波長比較：**

同一配體 NH₃，金屬離子電荷越高，Δ 越大。Co³⁺（+3）的電荷密度（charge density）高於 Co²⁺（+2），配體被吸引更靠近，排斥 d 電子效果更強 → Co(NH₃)₆³⁺ 的 Δ 較大，吸收能量較高的光，即**吸收波長較短的光**。

**答：Co(NH₃)₆²⁺ 吸收較長波長的光；Co(NH₃)₆³⁺ 吸收較短波長的光。**

### 進階例題 B（Exercise 54，難度：中高）

**題目**：三種錯合物 Co(NH₃)₆³⁺、Co(CN)₆³⁻ 和 CoF₆³⁻，其吸收電磁輻射的波長分別為（順序不定）770 nm、440 nm 和 290 nm。請將每個錯合物與其吸收波長對應。

**解析：**

**分析各配體的場強：**

由光譜化學系列：

```
CN⁻ > NH₃ > F⁻
強場              弱場
大 Δ              小 Δ
```

**Δ 大小順序：Co(CN)₆³⁻ > Co(NH₃)₆³⁺ > CoF₆³⁻**

**Δ 與吸收波長的關係：**

```
ΔE = hc/λ   →   Δ 越大，λ 越小（吸收波長越短）
```

| 錯合物 | 場強 | Δ 大小 | 吸收波長 |
|--------|------|--------|---------|
| Co(CN)₆³⁻ | 強場（strong field） | 最大 | 最短：**290 nm**（近紫外光） |
| Co(NH₃)₆³⁺ | 中等場 | 中等 | 中等：**440 nm**（藍色光） |
| CoF₆³⁻ | 弱場（weak field） | 最小 | 最長：**770 nm**（近紅外光） |

**答：**
- Co(CN)₆³⁻ → **290 nm**
- Co(NH₃)₆³⁺ → **440 nm**
- CoF₆³⁻ → **770 nm**

### 進階例題 D（Exercise 59，難度：中高）

**題目**：[Cu(H₂O)₆]²⁺ 的吸收最大值在 800 nm 附近；當四個 H₂O 被 NH₃ 取代，形成 [Cu(NH₃)₄(H₂O)₂]²⁺ 後，吸收最大值移至約 600 nm。這些結果在配體場強方面說明了什麼？

**解析：**

Cu²⁺ 的 d 電子組態為 d⁹，無論強場或弱場均只有一個未成對電子（d⁹ 的電子排布唯一）。因此顏色的差異純粹反映 **Δ 大小的不同**。

**分析吸收波長的改變：**

```
ΔE = hc/λ
```

吸收波長從 800 nm 移至 600 nm，波長**縮短** → 所需能量**增大** → Δ **增大**。

**原因：**

NH₃ 取代 H₂O 後，配體場強增加（由光譜化學系列知 NH₃ > H₂O），導致 d 軌域分裂能 Δ 增大，d 電子躍遷所需能量更高，因此吸收更短波長的光。

**結論：NH₃ 的配體場分裂能力（field-splitting ability）大於 H₂O，與光譜化學系列的順序（NH₃ > H₂O）一致。**

此實驗也可反過來操作：透過測量一系列錯合物的吸收最大值，即可比較不同配體的相對場強，建立光譜化學系列（spectrochemical series）。

### 進階例題 E（Exercise 67，難度：高）

**題目**：CoBr₄²⁻ 吸收電磁輻射的波長為 3.4 × 10⁻⁶ m。CoBr₆⁴⁻ 吸收電磁輻射的波長是比 3.4 × 10⁻⁶ m 長還是短？請解釋。

**解析：**

**步驟一：確定兩個錯合物的幾何形狀**

- CoBr₄²⁻：配位數 4 → 四面體形（tetrahedral）
- CoBr₆⁴⁻：配位數 6 → 八面體形（octahedral）

**步驟二：比較 Δ 的大小**

同一配體 Br⁻ 下，八面體（Δ_oct）與四面體（Δ_tet）分裂能的關係：

```
Δ_tet = (4/9) × Δ_oct
```

因此 Δ_oct > Δ_tet，即：

**CoBr₆⁴⁻（八面體）的 Δ > CoBr₄²⁻（四面體）的 Δ**

**步驟三：Δ 與吸收波長的關係**

```
ΔE = hc/λ   →   Δ 越大，λ 越小
```

CoBr₆⁴⁻ 的 Δ 較大 → 吸收波長較短。

CoBr₄²⁻ 吸收波長為 3.4 × 10⁻⁶ m（遠紅外線範圍）

**答：CoBr₆⁴⁻ 吸收電磁輻射的波長比 3.4 × 10⁻⁶ m 短。**

原因：八面體場的分裂能（Δ_oct）約為四面體場（Δ_tet）的 9/4 倍，電子躍遷需要更高的能量，對應更短的波長。

## 九、本節重點整理

### 八面體晶場分裂

| 項目 | 說明 |
|------|------|
| e_g 組（高能量） | dz²、dx²-y²，波瓣直接指向配體 |
| t₂g 組（低能量） | dxy、dxz、dyz，波瓣指向配體間隙 |
| 分裂能 Δ（Δ_oct） | e_g 與 t₂g 的能量差 |
| 強場/低自旋（strong-field / low-spin） | Δ 大，電子配對在 t₂g，未成對電子少 |
| 弱場/高自旋（weak-field / high-spin） | Δ 小，電子先各填一個，未成對電子多 |
| 適用於高/低自旋的 d 電子數 | d⁴、d⁵、d⁶、d⁷（才有兩種可能） |

### 光譜化學系列（由強至弱）

```
CN⁻ > NO₂⁻ > en > NH₃ > H₂O > OH⁻ > F⁻ > Cl⁻ > Br⁻ > I⁻
```

### 四面體 vs. 八面體比較

| 項目 | 八面體（octahedral） | 四面體（tetrahedral） |
|------|--------------------|--------------------|
| 高能量組 | e_g（dz²、dx²-y²） | dxy、dxz、dyz |
| 低能量組 | t₂g（dxy、dxz、dyz） | dz²、dx²-y² |
| 分裂能大小 | Δ_oct（較大） | Δ_tet = (4/9)Δ_oct（較小） |
| 高/低自旋 | 兩者均可能 | **永遠高自旋（always high-spin）** |

### 顏色規律

```
Δ 大 → 吸收短波長光（高能量，藍紫端）
Δ 小 → 吸收長波長光（低能量，紅端）
觀察到的顏色 = 吸收色的互補色（complementary color）
d⁰（如 Sc³⁺）和 d¹⁰（如 Zn²⁺）：無 d-d 躍遷 → 無色（colorless）
```
