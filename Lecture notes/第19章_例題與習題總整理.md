# 19.1　過渡金屬概論

## 例題 1（Exercise 6，難度：中）

**題目**：寫出下列各物種的電子組態（electron configurations）：Ti、Ti²⁺、Ti⁴⁺

**解析：**

**Ti（中性原子）**：Ti 原子序為 22，位於 Sc 之後，填充第二個 3d 電子：

Ti：[Ar] 4s² 3d²

**Ti²⁺**：Ti 失去 2 個電子，依規則先失去 4s 電子：

Ti²⁺：[Ar] 3d²

**Ti⁴⁺**：再失去 2 個 3d 電子（共失去 4 個電子）：

Ti⁴⁺：[Ar]

即氬的電子組態（無 3d 電子），呈現**無色（colorless）且反磁性（diamagnetic）**，因為沒有 d 電子。

**答：Ti [Ar] 4s² 3d²；Ti²⁺ [Ar] 3d²；Ti⁴⁺ [Ar]**

## 例題 2（Exercise 7，難度：中）

**題目**：寫出下列各物種的電子組態：Cr、Cr²⁺、Cr³⁺

**解析：**

**Cr（中性原子）**：Cr 是例外組態，注意不是 [Ar] 4s² 3d⁴：

Cr：[Ar] 4s¹ 3d⁵

**Cr²⁺**：失去 2 個電子，先失去唯一的 4s 電子，再失去 1 個 3d 電子：

Cr²⁺：[Ar] 3d⁴

> ⚠️ 常見錯誤：誤寫為 [Ar] 3d³ 4s¹（以為只失去 4s 電子）。正確做法是先移除所有 4s，再從 3d 補足差額。

**Cr³⁺**：失去 3 個電子：4s¹ 全部失去 + 3d 再失去 2 個：

Cr³⁺：[Ar] 3d³

Cr³⁺ 有 3 個未成對 3d 電子，是常見的順磁性（paramagnetic）離子，與實驗吻合。

**答：Cr [Ar] 4s¹ 3d⁵；Cr²⁺ [Ar] 3d⁴；Cr³⁺ [Ar] 3d³**

## 例題 3（Exercise 8，難度：中高）

**題目**：第一列過渡金屬中有哪兩個具有「非預期電子組態（unexpected electron configurations）」？教科書指出過渡金屬離子不含 4s 電子，為什麼？為何過渡金屬離子（transition metal ions）常有多種氧化態，而典型金屬（representative metals）通常只有一種？

**解析：**

**哪兩個元素有非預期組態？**

Cr（[Ar] 4s¹ 3d⁵，預期 [Ar] 4s² 3d⁴）和 Cu（[Ar] 4s¹ 3d¹⁰，預期 [Ar] 4s² 3d⁹）。

**為何離子不含 4s 電子？**

在中性原子中，4s 和 3d 軌域能量十分相近，但在形成陽離子（cation）後，有效核電荷（effective nuclear charge）增大，3d 軌域能量相對於 4s 大幅降低，成為更穩定的軌域。因此殘餘電子填入能量較低的 3d，而非 4s。換句話說，離子化過程改變了軌域能量的相對高低順序。

**為何過渡金屬有多種氧化態？**

典型金屬（如 Na、Mg、Al）的最外層是 s 和 p 電子，能量差異懸殊，電子要不全部失去、要不全不失去，因此只呈現一種穩定氧化態。過渡金屬的 4s 和 3d 軌域能量相近，不同程度地移除這些電子所需的能量差異不大，且形成的各氧化態離子在許多環境下均可穩定存在，因此出現多種氧化態。

## 例題 4（Exercise 9，難度：中高）

**題目**：什麼是鑭系收縮（lanthanide contraction）？它如何影響 4d 和 5d 過渡金屬的性質？

**解析：**

**鑭系收縮的定義：**

鑭系元素（lanthanides，Ce → Lu）中，電子逐一填入 4f 軌域。4f 軌域深埋原子內部，對其他電子的屏蔽效應（shielding effect）極差，而每增加一個電子核電荷同步增加一，使有效核電荷（effective nuclear charge）對外層電子的吸引力持續增強，導致原子半徑（atomic radius）在整個鑭系從左到右顯著縮小。這個效應稱為鑭系收縮（lanthanide contraction）。

**對 4d 和 5d 過渡金屬的影響：**

從第四週期到第五週期，正常預期原子半徑應因主量子數（principal quantum number）增加而顯著增大。然而，5d 元素（如 Hf、Ta、W 等）的前面正好橫跨了整個鑭系，核電荷的大幅增加幾乎完全抵消了半徑本應增大的效果，使 5d 元素的半徑與同族的 4d 元素幾乎相同。

4d 和 5d 同族元素的原子半徑（atomic radius）、游離能（ionization energies）和化學性質（chemical properties）極為相似。典型例子是 Zr 和 Hf：兩者化學性質幾乎完全相同，在自然界中永遠共生，其分離難度在所有元素對中最高，常需分餾（fractional distillation）其揮發性化合物才能分開。

## 例題 5（Exercise 10，難度：高）

**題目**：我們預期原子半徑（atomic radius）沿族（group）往下增大。試解釋為何鉿（Hf）打破了這個規律，其原子半徑甚至與鋯（Zr）幾乎相同（數據：Sc 1.57 Å、Y 1.693 Å、La 1.915 Å；Ti 1.477 Å、Zr 1.593 Å、Hf 1.476 Å）。

**解析：**

觀察數據：

| 族 | 第四週期 | 第五週期 | 第六週期 |
|----|---------|---------|---------|
| Sc/Y/La 族 | Sc：1.57 Å | Y：1.693 Å（增大 ✓） | La：1.915 Å（增大 ✓） |
| Ti/Zr/Hf 族 | Ti：1.477 Å | Zr：1.593 Å（增大 ✓） | **Hf：1.476 Å（幾乎與 Ti 相同！）** |

從 Ti → Zr，半徑正常增大（+0.116 Å）。但從 Zr → Hf，半徑不但沒有增大，反而幾乎等同於 Ti 的半徑。

**解釋：**

Hf（鉿，第六週期 5d 元素）之前正好橫跨了 14 個鑭系元素（La 之後的 Ce → Lu）。在這 14 個元素中，核電荷從 57 增加到 71，但 4f 電子對外層電子的屏蔽效應（shielding effect）極差，幾乎沒有緩衝作用。這使得 Hf 的有效核電荷（effective nuclear charge）比預期高出許多，對最外層電子（outermost electrons）的吸引力大幅增強，原子半徑因此顯著縮小。

這個鑭系收縮（lanthanide contraction）的效果恰好完全抵消了第六週期本應帶來的半徑增大，使 Hf 的半徑與第四週期的 Ti 幾乎相同（1.476 Å vs. 1.477 Å），打破了「同族往下半徑增大」的一般規律。

# 19.2　第一列過渡金屬

## 例題 6（Exercise 12b，難度：中）

**題目**：鈦白礦的氯化法反應為：

```
2TiO₂(s) + 3C(s) + 4Cl₂(g) →(950°C) 2TiCl₄(g) + CO₂(g) + 2CO(g)
TiCl₄(g) + O₂(g) →(1000–1400°C) TiO₂(s) + 2Cl₂(g)
```

請標示兩個反應中各元素的氧化態（oxidation states），並指出哪些元素被氧化（oxidized）、哪些被還原（reduced），以及各反應的氧化劑（oxidizing agent）和還原劑（reducing agent）。

**解析：**

**反應一：2TiO₂ + 3C + 4Cl₂ → 2TiCl₄ + CO₂ + 2CO**

| 物種 | 元素 | 反應前氧化態 | 反應後氧化態 | 變化 |
|------|------|------------|------------|------|
| TiO₂ | Ti | +4 | +4（在 TiCl₄ 中） | 不變 |
| TiO₂ | O | −2 | −2（在 CO₂/CO 中） | 不變 |
| C | C | 0 | +4（在 CO₂）或 +2（在 CO） | **被氧化（oxidized）↑** |
| Cl₂ | Cl | 0 | −1（在 TiCl₄ 中） | **被還原（reduced）↓** |

- 被氧化的元素：C（碳），0 → +4 或 +2；還原劑（reducing agent）：C
- 被還原的元素：Cl（氯），0 → −1；氧化劑（oxidizing agent）：Cl₂

**反應二：TiCl₄ + O₂ → TiO₂ + 2Cl₂**

| 物種 | 元素 | 反應前氧化態 | 反應後氧化態 | 變化 |
|------|------|------------|------------|------|
| TiCl₄ | Ti | +4 | +4（在 TiO₂ 中） | 不變 |
| TiCl₄ | Cl | −1 | 0（在 Cl₂ 中） | **被氧化（oxidized）↑** |
| O₂ | O | 0 | −2（在 TiO₂ 中） | **被還原（reduced）↓** |

- 被氧化的元素：Cl（氯），−1 → 0；還原劑（reducing agent）：TiCl₄
- 被還原的元素：O（氧），0 → −2；氧化劑（oxidizing agent）：O₂

## 例題 7（Exercise 14，難度：中）

**題目**：鐵在地殼中以赤鐵礦（hematite，Fe₂O₃）和磁鐵礦（magnetite，Fe₃O₄）兩種礦石形式存在。請問各礦石中鐵的氧化態（oxidation state）為何？磁鐵礦中 Fe²⁺ 和 Fe³⁺ 的比例為何？磁鐵礦的化學式通常寫作 FeO·Fe₂O₃，這合理嗎？

**解析：**

**赤鐵礦（Fe₂O₃）中鐵的氧化態：**

2x + 3(−2) = 0 → x = **+3**

**磁鐵礦（Fe₃O₄）中 Fe²⁺ 與 Fe³⁺ 的比例：**

設有 a 個 Fe²⁺ 和 b 個 Fe³⁺：

a + b = 3 且 2a + 3b = 8

解得 a = 1，b = 2 → **Fe²⁺ : Fe³⁺ = 1 : 2**

**FeO·Fe₂O₃ 的合理性：**

FeO 含 1 個 Fe²⁺，Fe₂O₃ 含 2 個 Fe³⁺，合計 1 個 Fe²⁺ + 2 個 Fe³⁺ + 4 個 O²⁻ = Fe₃O₄，**完全合理**，明確表示磁鐵礦是兩種不同氧化態鐵的複合氧化物。

## 例題 8（Exercise 15，難度：中高）

**題目**：Cr(VI) 形成兩種不同的含氧陰離子（oxyanions）：橙色的重鉻酸根（Cr₂O₇²⁻）和黃色的鉻酸根（CrO₄²⁻）。兩者之間的平衡為：

```
Cr₂O₇²⁻(aq) + H₂O(l) ⇌ 2CrO₄²⁻(aq) + 2H⁺(aq)
```

當 NaOH（aq）逐滴加入重鉻酸鈉溶液時，溶液的顏色如何變化？請解釋。

**解析：**

加入 NaOH 後，OH⁻ 與溶液中的 H⁺ 反應，使 [H⁺] 降低。根據勒沙特列原理（Le Châtelier's principle），H⁺ 是平衡右側的生成物，[H⁺] 降低使平衡**向右移動**，Cr₂O₇²⁻ 濃度下降，CrO₄²⁻ 濃度上升。

溶液顏色由**橙色（Cr₂O₇²⁻）** 逐漸轉為**黃色（CrO₄²⁻）**。

## 例題 9（綜合應用，難度：高）

**題目**：在釩的水溶液化學中，可以用強還原劑（如 Zn/HCl）將 VO₂⁺ 逐步還原。請預測在逐步加入還原劑的過程中，溶液顏色的變化順序，並寫出對應的半反應。

+5 → +4：VO₂⁺(aq) + 2H⁺(aq) + e⁻ → VO²⁺(aq) + H₂O(l)（黃色 → 藍色）

+4 → +3：VO²⁺(aq) + 2H⁺(aq) + e⁻ → V³⁺(aq) + H₂O(l)（藍色 → 藍綠色）

+3 → +2：V³⁺(aq) + e⁻ → V²⁺(aq)（藍綠色 → 紫色）

# 19.4　異構物

## 例題 19（課本 Example 19.3）

**題目**：錯離子 [Co(NH₃)Br(en)₂]²⁺ 是否具有幾何異構物？是否具有光學異構物？

**解析：**

**幾何異構物：**

Co³⁺ 配位數 6（八面體），NH₃ 和 Br⁻ 可以佔 cis（相鄰）或 trans（相對）位置。

**有幾何異構物（cis 和 trans）。**

**光學異構物：**

- trans 異構物：具對稱平面，鏡像可重疊 → 非手性（achiral），**無光學異構物**
- cis 異構物：鏡像不可重疊（nonsuperimposable）→ 手性（chiral），存在**一對對掌異構物（enantiomers）**

## 例題 20（Exercise 33，難度：中）

**題目**：定義下列各詞，並各舉一例：(a) isomers (b) structural isomers (c) stereoisomers (d) coordination isomers (e) linkage isomers (f) geometric isomers (g) optical isomers

**解析：**

**(a) 異構物（isomers）**：化學式相同但性質不同的化合物。例：cis/trans-[Co(NH₃)₄Cl₂]⁺

**(b) 結構異構物（structural isomers）**：相同原子但一個或多個鍵結不同。例：[Cr(NH₃)₅Cl]SO₄ 與 [Cr(NH₃)₅SO₄]Cl

**(c) 立體異構物（stereoisomers）**：所有鍵結相同但空間排列不同。例：cis/trans-Pt(NH₃)₂Cl₂

**(d) 配位異構物（coordination isomers）**：錯離子組成（配體分配）不同。例：[Co(en)₃][Cr(ox)₃] 與 [Cr(en)₃][Co(ox)₃]

**(e) 鍵結異構物（linkage isomers）**：配體鍵結原子不同。例：[Co(NH₃)₅(NO₂)]²⁺（nitro，N 端）與 [Co(NH₃)₅(ONO)]²⁺（nitrito，O 端）

**(f) 幾何異構物（geometric isomers）**：相同配體的相對位置不同（cis/trans 或 fac/mer）。例：cis/trans-[Co(NH₃)₄Cl₂]⁺

**(g) 光學異構物（optical isomers）**：分子與其鏡像不可重疊，使偏振光向相反方向旋轉。例：Δ/Λ-[Co(en)₃]³⁺

# 19.6　晶場模型

## 例題 30（課本 Example 19.4）

**題目**：Fe(CN)₆³⁻ 含有 1 個未成對電子。CN⁻ 配體對 Fe³⁺ 是強場還是弱場？

**解析：**

Fe³⁺：d⁵；d⁵ 在強場（low-spin）下：t₂g ↑↓ ↑↓ ↑ → **1 個未成對電子**；在弱場（high-spin）下：5 個未成對電子。

實驗結果（1 個未成對電子）符合強場排布。

**答：CN⁻ 對 Fe³⁺ 是強場配體（strong-field ligand）。**

## 例題 31（課本 Example 19.5）

**題目**：預測錯離子 [Cr(CN)₆]⁴⁻ 中未成對電子的數目。

**解析：**

Cr²⁺：d⁴；CN⁻ 為強場配體，低自旋（low-spin）排布：

```
e_g   ___  ___
t₂g   ↑↓   ↑    ↑
```

**答：2 個未成對電子。**

（弱場高自旋排布為 4 個未成對電子；CN⁻ 產生大 Δ，電子寧可在 t₂g 配對，不跨越大能隙。）

## 例題 32（課本 Example 19.6）

**題目**：畫出四面體錯合物 CoCl₄²⁻ 的晶場圖。

**解析：**

Co²⁺：d⁷；四面體場（永遠高自旋）；分裂方向與八面體相反（dxy、dxz、dyz 在上，dz²、dx²-y² 在下）：

```
高能量  dxy ↑↓  dxz ↑↓  dyz ↑
低能量  dz² ↑↓  dx²-y² ↑
```

**3 個未成對電子，順磁性（paramagnetic）。**

## 例題 33（Exercise 49，難度：中）

**題目**：[Cr(NH₃)₆]Cl₃ 呈黃色，但 Cr(NH₃)₆³⁺ 不吸收黃色光。為什麼？Co(NH₃)₆²⁺ 與 Co(NH₃)₆³⁺ 哪個吸收波長較長？

**解析：**

物質呈現的顏色是**未被吸收光的互補色（complementary color）**。Cr(NH₃)₆³⁺ 呈**黃色**，表示它吸收黃色的互補色——**紫色/藍紫色光**（約 400–450 nm）。

光譜化學系列（spectrochemical series）：對多種錯合物測量吸收光譜得到 Δ 的大小，配體依 Δ 由大到小排列。Δ 越大，吸收波長越短。

同一配體 NH₃ 下，**Co³⁺ 電荷高於 Co²⁺**，配體被吸引更靠近，Δ 更大，吸收更短波長的光。

**答：Co(NH₃)₆²⁺ 吸收較長波長的光；Co(NH₃)₆³⁺ 吸收較短波長的光。**

# 19.7　分子軌域模型

## 例題 38（Discussion Question 5，難度：中高）

**題目**：討論 MO 模型與晶場模型各自的優缺點。何時使用 MO 模型更適合？

**解析：**

| 項目 | 晶場模型（Crystal Field） | MO/配位場模型（Ligand Field） |
|------|--------------------------|------------------------------|
| 優點 | 簡單直觀，快速判斷高/低自旋和顏色 | 提供真實鍵結圖像；解釋光譜化學系列原因；可考慮 π 鍵效應 |
| 缺點 | 視配體為純點電荷，忽略共價鍵；無法解釋 Δ 大小差異 | 較複雜；快速定性分析時不如晶場模型直觀 |

適用情境：快速預測磁性和顏色 → 晶場模型；需解釋光譜化學系列、π 鍵效應 → MO/配位場模型

## 例題 39（Exercise 56，難度：中高）

**題目**：Co(NH₃)₆³⁺ 是反磁性，但 Fe(H₂O)₆²⁺ 是順磁性。請用 MO 模型解釋。

**解析：**

兩者均為 d⁶，差異在配體場強：

**Co(NH₃)₆³⁺（NH₃ 為強場配體）**：NH₃ 的 N 孤對電子軌域能量較高，接近 Co³⁺ 3d 軌域，混合程度大，e_g* 能量顯著升高，Δ 大 → 低自旋 → t₂g ↑↓ ↑↓ ↑↓ → **0 個未成對電子，反磁性（diamagnetic）**

**Fe(H₂O)₆²⁺（H₂O 為弱場配體）**：H₂O 的 O 孤對電子軌域能量較低（O 電負度高），與 Fe²⁺ 3d 軌域能量差大，混合程度小，e_g* 能量升高有限，Δ 小 → 高自旋 → e_g ↑ ↑，t₂g ↑↓ ↑ ↑ → **4 個未成對電子，順磁性（paramagnetic）**

## 例題 40（Exercise 60，難度：高）

**題目**：Fe(CN)₆³⁻ 有 1 個未成對電子；Fe(SCN)₆³⁻ 有 5 個未成對電子。SCN⁻ 在光譜化學系列中與 CN⁻ 相比位於何處？

兩者均為 Fe³⁺（d⁵）。

Fe(CN)₆³⁻：1 個未成對電子 → 低自旋 → **CN⁻ 為強場配體，Δ 大**

Fe(SCN)₆³⁻：5 個未成對電子 → 高自旋 → **SCN⁻ 為弱場配體，Δ 小**

**答：SCN⁻ 在光譜化學系列中位於 CN⁻ 的弱場側（far to the weak-field side），屬弱場配體。**

## 例題 41（綜合應用，難度：高）

**題目**：解釋為何 CO 和 CN⁻ 位於光譜化學系列最強場端，鹵素離子位於最弱場端。

**解析：**

**CO 和 CN⁻（強場）**：不僅是 σ 供電體（sigma donors），更是強 **π 受電配體（π-acceptors）**，具有低能量的空 π* 軌域。金屬 t₂g 電子可反饋（back-donate）進入這些空軌域，使 t₂g 能量降低，e_g* 不變 → **Δ = E(e_g*) − E(t₂g) 增大**。

**鹵素離子（弱場）**：是 **π 供電配體（π-donors）**，填滿的 p 軌域向金屬 t₂g 供電，使 t₂g 能量升高，e_g* 不變 → **Δ = E(e_g*) − E(t₂g) 減小**。

**純 σ 配體（NH₃、en）**：無 π 鍵，Δ 居中。

```
π 受電（強場）← CO > CN⁻ > en > NH₃ > H₂O > F⁻ > Cl⁻ > Br⁻ > I⁻ → π 供電（弱場）
```

# 19.8　配位錯合物的生物重要性

## 例題 42（Exercise 77，難度：中）

**題目**：什麼原因導致高山症？什麼是高原適應？

**解析：**

**高山症的原因：**

高海拔地區 O₂ 分壓低，血紅蛋白（Hb）與 O₂ 的結合平衡：

```
Hb(aq) + 4O₂(g) ⇌ Hb(O₂)₄(aq)
```

O₂ 分壓降低 → 平衡向左移（勒沙特列原理）→ 氧合血紅蛋白（oxyhemoglobin）減少 → 組織缺氧 → 疲勞（fatigue）、頭暈（dizziness），嚴重時引發高山症（high-altitude sickness）。

**高原適應：**

人體在低 O₂ 環境中刺激骨髓產生更多紅血球，合成更多血紅蛋白（hemoglobin）。[Hb] 增加 → 平衡右移 → 即使在低 O₂ 分壓下也能形成足夠的氧合血紅蛋白 → 維持正常供氧。此過程通常需數週。

## 例題 43（Exercise 76，難度：中）

**題目**：為何 CO 和 CN⁻ 對人體有毒？

**解析：**

**CO 的毒性：**

CO 對血紅蛋白（hemoglobin）中 Fe²⁺ 的親和力（affinity）**約為 O₂ 的 200 倍**，與 Fe²⁺ 結合形成極穩定的**羰基血紅蛋白（carboxyhemoglobin，HbCO）**，阻止 O₂ 的正常結合，導致缺氧（hypoxia）甚至窒息（asphyxiation）。

**CN⁻ 的毒性：**

CN⁻ 與**細胞色素氧化酶（cytochrome oxidase）** 中的含鐵活性位點強力配位，阻止此酶催化的氧化還原反應，使電子無法傳遞給 O₂，有氧代謝（aerobic metabolism）完全停止，細胞迅速死亡。CN⁻ 因此被稱為**呼吸抑制劑（respiratory inhibitor）**。

## 例題 44（Exercise 89，難度：高）

**題目**：血紅蛋白（Hb）相關平衡為：

```
HbH₄⁴⁺(aq) + 4O₂(g) ⇌ Hb(O₂)₄(aq) + 4H⁺(aq)
```

請用勒沙特列原理回答：
(a) 肺部和細胞中哪種形式的血紅蛋白佔優勢？
(b) 過度換氣（hyperventilate）時，血液 CO₂ 濃度降低，如何影響此平衡？向紙袋呼吸有何幫助？
(c) 心臟停止（cardiac arrest）時，注射碳酸氫鈉為何必要？

**解析：**

**(a) 肺部 vs. 細胞：**

肺部：O₂ 分壓高 → 平衡右移 → **Hb(O₂)₄（氧合血紅蛋白）佔優勢**，攜帶 O₂

細胞：O₂ 分壓低，細胞代謝產生 CO₂（H₂CO₃ → H⁺），[H⁺] 升高 → 平衡左移 → **HbH₄⁴⁺（去氧血紅蛋白）佔優勢**，釋放 O₂ 給組織

**(b) 過度換氣：**

大量 CO₂ 呼出 → 血液 CO₂↓ → CO₂ + H₂O ⇌ H⁺ + HCO₃⁻ 平衡左移 → [H⁺]↓（血液 pH 升高）→ 主平衡右移 → 血紅蛋白更緊密結合 O₂，不願釋放 → 組織缺氧，頭暈

向紙袋呼吸：反覆吸入自己呼出的富含 CO₂ 氣體 → 血液 CO₂ 回升 → [H⁺] 恢復正常 → 血紅蛋白釋放 O₂ 能力恢復 → 症狀緩解

**(c) 心臟停止時注射 NaHCO₃：**

心臟停止時無氧代謝產生大量乳酸和 CO₂，血液 [H⁺] 急劇升高（pH 降低）→ 主平衡大幅左移 → 血紅蛋白難以在肺部攜帶 O₂

NaHCO₃（鹼性）中和 H⁺：HCO₃⁻ + H⁺ → H₂O + CO₂，使 [H⁺] 降低，血液 pH 恢復正常，血紅蛋白能正常攜帶 O₂，為心臟復甦（resuscitation）提供基本條件。

## 例題 45（Exercise 90，難度：高）

**題目**：考慮以下反應與近似標準自由能變化：

```
Hb + O₂ → HbO₂        ΔG° = −70 kJ
Hb + CO → HbCO         ΔG° = −80 kJ
```

估算下列反應在 25°C 時的平衡常數 K：

```
HbO₂ + CO ⇌ HbCO + O₂
```

**解析：**

**步驟一：計算目標反應的 ΔG°**

目標反應 = 反應 2 − 反應 1：

ΔG° = −80 − (−70) = **−10 kJ = −10,000 J/mol**

**步驟二：由 ΔG° 計算 K**

ΔG° = −RT ln K

−10,000 = −(8.314)(298) ln K

ln K = 10,000 / 2477.6 ≈ 4.037

**K = e^4.037 ≈ 57**

**物理意義：**

K ≈ 57 表示在相同 CO 和 O₂ 濃度下，HbCO 濃度是 HbO₂ 的 57 倍。即使 CO 濃度只有 O₂ 的 1/57，血液中一半的血紅蛋白也會與 CO 結合，嚴重削弱攜氧能力，說明 CO 即使微量也極具毒性。
