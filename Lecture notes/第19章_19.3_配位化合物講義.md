# 第十九章　過渡金屬與配位化學
## 19.3　配位化合物（Coordination Compounds）

---

## 一、配位化合物的基本概念

### 1.1 配位化合物的組成

**配位化合物（coordination compound）** 通常由以下三部分組成：

| 組成部分 | 英文術語 | 說明 |
|---------|---------|------|
| 錯離子（complex ion） | complex ion | 過渡金屬離子與其所有配體的整體 |
| 配體（ligand） | ligand | 與金屬離子鍵結的分子或離子 |
| 對離子（counter ion） | counter ion | 平衡整體電荷所需的陰離子或陽離子，位於方括號外 |

**範例：[Co(NH₃)₅Cl]Cl₂**

```
[Co(NH₃)₅Cl]Cl₂

 └─────────┘ └──┘
   錯離子        對離子
 Co(NH₃)₅Cl²⁺   2 Cl⁻
```

- 方括號（square brackets）內為錯離子的組成
- 方括號外的 Cl⁻ 為對離子（counter ions）
- 固態中：大型 Co(NH₃)₅Cl²⁺ 陽離子與兩倍數量的 Cl⁻ 陰離子緊密堆積
- 溶於水後，錯離子與對離子各自獨立移動：

```
[Co(NH₃)₅Cl]Cl₂(s) →(H₂O) Co(NH₃)₅Cl²⁺(aq) + 2Cl⁻(aq)
```

> **注意**：錯離子內部的 Cl⁻（配體）不會在水中自由解離；只有方括號外的對離子才會。

### 1.2 Werner 配位理論的歷史背景

配位化合物早在 1700 年代就已為人所知，但其真實本質直到 19 世紀末才被了解。

**舊理論——鏈式理論（chain theory）**：

由哥本哈根大學教授 Sophus Mads Jorgensen（1837–1914）提出，主張金屬-氨錯合物（metal-ammine complexes）中的 NH₃ 以鏈式排列。例如，Co(NH₃)₆Cl₃ 被描述為含有 NH₃ 分子鏈的結構。

**Werner 的配位理論（coordination theory）**：

1890 年，年輕的瑞士化學家 Alfred Werner 在某個夜晚突然頓悟，提出了革命性的配位理論（coordination theory）：

- Co³⁺ 離子周圍以**八面體（octahedral）** 方式排列 6 個配體（ligands）
- Co(NH₃)₆Cl₃ 的正確描述為：Co(NH₃)₆³⁺ 錯離子（complex ion）加上 3 個 Cl⁻ 對離子（counter ions）
- Werner 同時解釋了幾乎所有已知的過渡金屬化合物，並首先指出立體化學（stereochemistry）不只是碳的專利

Werner 因此榮獲 **1913 年諾貝爾化學獎（Nobel Prize in Chemistry）**，是第一位獲此殊榮的瑞士化學家。

## 二、Werner 的兩種化合價（Two Types of Valence）

Werner 提出過渡金屬離子有兩種結合能力（combining ability / valence）：

| Werner 術語 | 現代術語 | 定義 |
|------------|---------|------|
| 初級化合價（primary valence） | 氧化態（oxidation state） | 金屬離子與帶相反電荷離子（counter ions）形成離子鍵的能力 |
| 次級化合價（secondary valence） | 配位數（coordination number） | 金屬離子與配體（Lewis bases）形成配位共價鍵的能力 |

**以 CoCl₃·5NH₃（即 [Co(NH₃)₅Cl]Cl₂）為例：**

- 初級化合價（primary valence）= **3**：Co³⁺ 與 3 個 Cl⁻ 離子鍵結
- 次級化合價（secondary valence）= **6**：Co³⁺ 與 6 個配體（5 個 NH₃ + 1 個 Cl⁻）配位

## 三、配位數（Coordination Number）

### 3.1 配位數的定義

**配位數（coordination number）** 是金屬離子與配體之間形成的鍵結（bonds）數目，反映了錯離子中金屬離子與配體的直接鍵結總數。

配位數的範圍：**2 到 8**，取決於金屬離子的大小（size）、電荷（charge）和電子組態（electron configuration）。

### 3.2 常見配位數與幾何形狀

| 配位數（Coordination Number） | 幾何形狀（Geometry） | 鍵角（Bond Angles） |
|------------------------------|--------------------|--------------------|
| 2 | 直線形（linear） | 180° |
| 4 | 四面體形（tetrahedral） | 109.5° |
| 4 | 平面四方形（square planar） | 90° |
| 6 | 八面體形（octahedral） | 90° |

> **重要**：**6 是最常見的配位數**，其次是 4，少數金屬離子配位數為 2。同一個金屬離子在不同情況下可能展現不同的配位數，目前沒有簡單的規則可以預測特定情況下的配位數。

### 3.3 常見金屬離子的配位數

| M⁺ 離子 | 常見配位數 | M²⁺ 離子 | 常見配位數 | M³⁺ 離子 | 常見配位數 |
|---------|----------|---------|----------|---------|----------|
| Cu⁺ | 2, 4 | Mn²⁺ | 4, 6 | Sc³⁺ | 6 |
| Ag⁺ | 2 | Fe²⁺ | 6 | Cr³⁺ | 6 |
| Au⁺ | 2, 4 | Co²⁺ | 4, 6 | Co³⁺ | 6 |
| | | Ni²⁺ | 4, 6 | Au³⁺ | 4 |
| | | Cu²⁺ | 4, 6 | | |
| | | Zn²⁺ | 4, 6 | | |

## 四、配體（Ligands）

### 4.1 配體的定義與鍵結本質

**配體（ligand）** 是具有孤對電子（lone pair）的中性分子或離子，可將孤對電子提供給金屬離子的空軌域，形成鍵結。

從路易斯酸鹼（Lewis acid-base）的角度理解：

- **金屬離子（metal ion）** = **路易斯酸（Lewis acid）**：電子對接受者（electron-pair acceptor）
- **配體（ligand）** = **路易斯鹼（Lewis base）**：電子對供給者（electron-pair donor）

此類鍵結稱為**配位共價鍵（coordinate covalent bond）**。

```
空的金屬離子軌域（empty metal ion hybrid orbital）
        +
配體的孤對電子（lone pair on ligand）
        ↓
    配位共價鍵（coordinate covalent bond）
```

### 4.2 單牙配體（Monodentate / Unidentate Ligands）

**單牙配體（monodentate ligand / unidentate ligand）** 只能透過一個原子（one atom）與金屬離子形成一個鍵結（"one tooth"，mono = 一，dentate = 齒）。

**常見單牙配體：**

| 配體 | 化學式 | 配體名稱（命名用） | 鍵結原子 |
|------|--------|----------------|---------|
| 水 water | H₂O | aqua | O |
| 氨 ammonia | NH₃ | ammine（注意雙 m） | N |
| 甲胺 methylamine | CH₃NH₂ | methylamine | N |
| 一氧化碳 carbon monoxide | CO | carbonyl | C |
| 一氧化氮 nitric oxide | NO | nitrosyl | N |
| 硫氰酸根 thiocyanate | SCN⁻ | thiocyanato | S 或 N（可鍵結異構） |
| 氰根 cyanide | CN⁻ | cyano | C |
| 亞硝酸根 nitrite | NO₂⁻ | nitro（N 鍵結）/ nitrito（O 鍵結） | N 或 O |
| 氫氧根 hydroxide | OH⁻ | hydroxo | O |
| 氟離子 fluoride | F⁻ | fluoro | F |
| 氯離子 chloride | Cl⁻ | chloro | Cl |
| 溴離子 bromide | Br⁻ | bromo | Br |
| 碘離子 iodide | I⁻ | iodo | I |

### 4.3 螯合配體（Chelating Ligands / Chelates）

**螯合配體（chelating ligand / chelate）** 含有兩個或以上可與金屬離子鍵結的孤對電子原子，可同時與一個金屬離子形成**多個鍵結**（源自希臘文 *chela*，意為「螃蟹螯」）。

#### (a) 雙牙配體（Bidentate Ligands）

可形成**兩個**鍵結的配體。

| 配體 | 縮寫 | 結構特徵 | 兩個鍵結原子 |
|------|------|---------|------------|
| 乙二胺（ethylenediamine） | en | H₂N–CH₂–CH₂–NH₂ | 兩個 N |
| 草酸根（oxalate） | ox | ⁻OOC–COO⁻ | 兩個 O |

**乙二胺（en）** 是最重要的雙牙配體之一，透過兩個 N 原子各提供一個孤對電子，與金屬形成**五員螯合環（five-membered chelate ring）**：

```
    NH₂–CH₂
   /         \
  M           CH₂–NH₂
   \         /
    （五員環 five-membered ring）
```

#### (b) 多牙配體（Polydentate Ligands）

可形成**兩個以上**鍵結的配體。

**二乙三胺（diethylenetriamine，dien）**：三牙配體（tridentate），含三個 N 原子

```
H₂N–CH₂CH₂–NH–CH₂CH₂–NH₂
```

**乙二胺四乙酸（ethylenediaminetetraacetate，EDTA⁴⁻）**：六牙配體（hexadentate ligand），含 2 個 N 和 4 個 O，共 6 個配位原子

EDTA 幾乎完全包圍金屬離子，與大多數金屬離子形成**極穩定的錯合物（very stable complex ions）**。

**EDTA 的重要應用：**

| 應用領域 | 說明 |
|---------|------|
| 解毒（detoxification） | 作為「清除劑（scavenger）」，移除人體內的有毒重金屬（如鉛 Pb） |
| 分析化學（analytical chemistry） | 用於金屬離子含量的定量分析（quantitative analysis） |
| 消費品（consumer products） | 廣泛存在於汽水、啤酒、沙拉醬、肥皂、清潔劑等，結合微量金屬離子，防止分解和沉澱 |

### 4.4 螯合效應（Chelate Effect）

螯合配體（chelating ligands）形成的錯合物（complex ions）通常比相同供電原子的單牙配體（monodentate ligands）形成的錯合物**更穩定**。例如：

```
Ni²⁺(aq) + 6NH₃(aq) ⇌ Ni(NH₃)₆²⁺(aq)         Kf = 3.2 × 10⁸
Ni²⁺(aq) + 3en(aq)  ⇌ Ni(en)₃²⁺(aq)           Kf = 1.6 × 10¹⁸
```

螯合效應（chelate effect）主要來自**熵效應（entropy effect）**：螯合配體取代單牙配體時，生成更多自由粒子（free particles），熵值（entropy, S）增大，使 ΔG 更負，Kf 更大。

## 五、配位化合物的命名規則（Nomenclature）

Werner 生前尚無統一命名系統；現代 IUPAC 命名規則如下：

### 規則一：陽離子在前，陰離子在後

與一般離子化合物相同，陽離子（cation）名稱放在陰離子（anion）之前。

### 規則二：錯離子命名時，配體名稱在金屬名稱之前

### 規則三：陰離子配體在字根後加 -o

| 陰離子（anion） | 配體名稱（ligand name） |
|---------------|----------------------|
| F⁻ | fluoro（氟） |
| Cl⁻ | chloro（氯） |
| Br⁻ | bromo（溴） |
| I⁻ | iodo（碘） |
| OH⁻ | hydroxo（羥） |
| CN⁻ | cyano（氰） |
| NO₂⁻（N 鍵結） | nitro（硝） |
| NO₂⁻（O 鍵結） | nitrito（亞硝） |
| SCN⁻ | thiocyanato（硫氰） |

**中性配體直接使用分子名稱，但以下四種為例外：**

| 分子 | 配體名稱 |
|------|---------|
| H₂O | aqua（水） |
| NH₃ | ammine（氨，注意雙 m） |
| CO | carbonyl（羰基） |
| NO | nitrosyl（亞硝醯） |

### 規則四：配體數目用前綴表示

| 配體數目 | 簡單前綴 | 複雜配體前綴（配體名稱已含 di-, tri- 等時使用） |
|---------|---------|----------------------------------------------|
| 1 | mono-（通常省略） | — |
| 2 | di- | bis- |
| 3 | tri- | tris- |
| 4 | tetra- | tetrakis- |
| 5 | penta- | — |
| 6 | hexa- | — |

> 例：乙二胺（ethylenediamine）名稱已含 di-，故 2 個 en 用 **bis(ethylenediamine)** 而非 diethylenediamine。

### 規則五：金屬的氧化態用羅馬數字標於括號內

### 規則六：多種配體存在時，按字母順序（alphabetical order）命名

前綴（di-、tri- 等）**不計入**字母排序。

### 規則七：錯離子為陰離子時，金屬名稱後加 -ate

部分金屬使用拉丁名（Latin name）：

| 金屬 | 陰離子錯合物字根 |
|------|---------------|
| 鐵 Iron | ferrate（鐵酸鹽） |
| 銅 Copper | cuprate（銅酸鹽） |
| 鉛 Lead | plumbate（鉛酸鹽） |
| 銀 Silver | argentate（銀酸鹽） |
| 金 Gold | aurate（金酸鹽） |
| 錫 Tin | stannate（錫酸鹽） |

## 六、命名例題講解

### 例題 1（課本 Example 19.1a）

**題目**：命名 [Co(NH₃)₅Cl]Cl₂

**解析步驟：**

步驟一：確定金屬氧化態

NH₃ 中性，每個 Cl⁻ 為 −1。整個化合物電中性，錯離子帶 +2 電荷：

```
Co + 5(0) + 1(−1) = +2   →   Co 氧化態 = +3
```

步驟二：列出配體（alphabetical order，忽略前綴）

- ammine（NH₃）：5 個 → **pentaammine**
- chloro（Cl⁻）：1 個 → **chloro**

字母順序：ammine（a）在 chloro（c）之前 → **pentaammminechloro...**

步驟三：錯離子為陽離子，金屬名稱不加 -ate → **cobalt(III)**

步驟四：對離子為 Cl⁻ → **chloride**

**答：pentaamminechlorocobalt(III) chloride（五氨氯鈷(III)氯化物）**

---

### 例題 2（課本 Example 19.1b）

**題目**：命名 K₃[Fe(CN)₆]

**解析步驟：**

步驟一：確定金屬氧化態

3 個 K⁺（+3）+ 6 個 CN⁻（−6）→ Fe 氧化態：

```
+3 + Fe + 6(−1) = 0   →   Fe = +3
```

步驟二：配體

- cyano（CN⁻）：6 個 → **hexacyano**

步驟三：錯離子 [Fe(CN)₆]³⁻ 為**陰離子** → 使用拉丁字根 **ferrate**，加氧化態 **(III)**

→ 陰離子名稱：**hexacyanoferrate(III)**

步驟四：陽離子 K⁺ → **potassium**

**答：potassium hexacyanoferrate(III)（六氰鐵(III)酸鉀）**

俗名（common name）：potassium ferricyanide（赤血鹽）

---

### 例題 3（課本 Example 19.1c）

**題目**：命名 [Fe(en)₂(NO₂)₂]₂SO₄

**解析步驟：**

步驟一：確定金屬氧化態

SO₄²⁻（−2）、4 個 NO₂⁻（共 −4）、en 中性，2 個錯離子共 +4 電荷，每個 Fe = +3：

```
2 × Fe + 4(0) + 4(−1) + (−2) = 0
2Fe = 6   →   Fe = +3
```

步驟二：列出配體（alphabetical order）

- ethylenediamine（en）：2 個，名稱已含 di-，用 **bis(ethylenediamine)**（b 開頭）
- nitro（NO₂⁻）：2 個 → **dinitro**（n 開頭）

字母順序：bis(ethylenediamine)（e）在 dinitro（n）之前

步驟三：錯離子為陽離子 → **iron(III)**

步驟四：對離子 SO₄²⁻ → **sulfate**

**答：bis(ethylenediamine)dinitroiron(III) sulfate**

---

### 例題 4（課本 Example 19.2a）

**題目**：由名稱推算化學式——triamminebromoplatinum(II) chloride

**解析步驟：**

- triammine：3 個 NH₃
- bromo：1 個 Br⁻（配體）
- platinum(II)：Pt²⁺
- 錯離子電荷：+2 + 3(0) + 1(−1) = +1 → 錯離子為 [Pt(NH₃)₃Br]⁺
- 需 1 個 Cl⁻ 平衡電荷 → 對離子為 Cl⁻

**答：[Pt(NH₃)₃Br]Cl**

---

### 例題 5（課本 Example 19.2b）

**題目**：由名稱推算化學式——potassium hexafluorocobaltate(III)

**解析步驟：**

- hexafluoro：6 個 F⁻
- cobaltate(III)：Co³⁺，且錯離子為陰離子（-ate 字尾）
- 錯離子電荷：+3 + 6(−1) = −3 → [CoF₆]³⁻
- 需 3 個 K⁺ 平衡 → potassium（K⁺ × 3）

**答：K₃[CoF₆]**

## 七、進階例題（選自課後習題）

### 進階例題 A（Exercise 22，難度：中）

**題目**：命名下列配位化合物：
- (a) [Co(NH₃)₆]Cl₂
- (b) [Co(H₂O)₆]I₃
- (c) K₂[PtCl₄]
- (d) K₄[PtCl₆]
- (e) [Cr(NH₃)₅Cl]Cl₂
- (f) [Cr(NH₃)₃(NO₂)₃]

**解析：**

**(a) [Co(NH₃)₆]Cl₂**

Co 氧化態：+2（6NH₃ 中性，2Cl⁻ 對離子）

配體：6 個 ammine → hexaammine；Co²⁺ 為陽離子錯合物 → cobalt(II)；對離子 Cl⁻ → chloride

**答：hexaamminecobalt(II) chloride**

**(b) [Co(H₂O)₆]I₃**

Co 氧化態：+3（6H₂O 中性，3I⁻ 對離子）

配體：6 個 aqua → hexaaqua；cobalt(III)；對離子 I⁻ → iodide

**答：hexaaquacobalt(III) iodide**

**(c) K₂[PtCl₄]**

錯離子 [PtCl₄]²⁻，Pt 氧化態：+2（4Cl⁻ = −4，錯離子電荷 = −2，Pt = +2）

錯離子為陰離子 → platinate(II)；4 個 chloro → tetrachloro；陽離子 K⁺ → potassium

**答：potassium tetrachloroplatinate(II)**

**(d) K₄[PtCl₆]**

錯離子 [PtCl₆]²⁻，Pt 氧化態：+4（6Cl⁻ = −6，錯離子電荷 = −2，Pt = +4）

陰離子錯合物 → platinate(IV)；6 個 chloro → hexachloro；陽離子 K⁺（×4）→ potassium

**答：potassium hexachloroplatinate(IV)**

**(e) [Cr(NH₃)₅Cl]Cl₂**

Cr 氧化態：+3（5NH₃ 中性，1Cl⁻ 配體，整體錯離子 +2，再加 2Cl⁻ 對離子）

驗證：+3 + 5(0) + (−1) = +2 ✓

字母順序：ammine（a）在 chloro（c）前 → pentaamminechloro；chromium(III)；對離子 chloride

**答：pentaamminechlorochromium(III) chloride**

**(f) [Cr(NH₃)₃(NO₂)₃]**

無對離子，整個化合物電中性。Cr 氧化態：+3（3NH₃ 中性，3NO₂⁻ = −3）

字母順序：ammine（a）在 nitro（n）前 → triamminetrinitro；chromium(III)

**答：triamminetrinitrochromium(III)**

### 進階例題 B（Exercise 25，難度：中）

**題目**：寫出下列化合物的化學式：
- (a) potassium tetrachlorocobaltate(II)
- (b) aquatricarbonylplatinum(II) bromide
- (c) sodium dicyanobis(oxalato)ferrate(III)
- (d) triamminechloroethylenediaminechromium(III) iodide

**解析：**

**(a) potassium tetrachlorocobaltate(II)**

- tetrachloro：4 個 Cl⁻ 配體
- cobaltate(II)：Co²⁺，陰離子錯合物
- 錯離子：Co²⁺ + 4Cl⁻ = [CoCl₄]²⁻（電荷 = +2 − 4 = −2）
- 2 個 K⁺ 平衡 → K₂[CoCl₄]

**答：K₂[CoCl₄]**

**(b) aquatricarbonylplatinum(II) bromide**

- aqua：1 個 H₂O
- tricarbonyl：3 個 CO（中性）
- platinum(II)：Pt²⁺，陽離子錯合物
- 錯離子：Pt²⁺ + 1H₂O + 3CO = [Pt(H₂O)(CO)₃]²⁺（電荷 = +2）
- 2 個 Br⁻ 平衡

**答：[Pt(H₂O)(CO)₃]Br₂**

**(c) sodium dicyanobis(oxalato)ferrate(III)**

- dicyano：2 個 CN⁻
- bis(oxalato)：2 個草酸根 C₂O₄²⁻（雙牙，縮寫 ox）
- ferrate(III)：Fe³⁺，陰離子錯合物
- 錯離子電荷：+3 + 2(−1) + 2(−2) = +3 − 2 − 4 = −3 → [Fe(CN)₂(ox)₂]³⁻
- 3 個 Na⁺ 平衡

**答：Na₃[Fe(CN)₂(C₂O₄)₂]**

**(d) triamminechloroethylenediaminechromium(III) iodide**

- triammine：3 個 NH₃
- chloro：1 個 Cl⁻
- ethylenediamine（en）：1 個（雙牙，佔 2 個配位位置）
- chromium(III)：Cr³⁺，陽離子錯合物
- 配位數驗證：3（NH₃）+ 1（Cl）+ 2（en）= 6 ✓
- 錯離子電荷：+3 + 3(0) + (−1) + 0 = +2 → [Cr(NH₃)₃Cl(en)]²⁺
- 2 個 I⁻ 平衡

**答：[Cr(NH₃)₃Cl(en)]I₂**

### 進階例題 C（Exercise 29，難度：中高）

**題目**：某鈷(III)配位化合物含有 4 個氨分子（ammonia molecules）、1 個硫酸根（sulfate ion）和 1 個氯離子（chloride ion）。將化合物水溶液加入 BaCl₂(aq) 無沉澱；加入 AgNO₃(aq) 則產生白色沉澱。請推測此配位化合物的結構。

**解析：**

**分析實驗現象：**

| 試劑 | 現象 | 推論 |
|------|------|------|
| BaCl₂(aq) | 無沉澱 | SO₄²⁻ 不在溶液中自由游離 → SO₄²⁻ 為配體（在方括號內） |
| AgNO₃(aq) | 白色沉澱（AgCl） | Cl⁻ 在溶液中自由游離 → Cl⁻ 為對離子（在方括號外） |

**確定錯離子組成：**

- Co³⁺ 最常見配位數為 6
- 配體：4 個 NH₃ + 1 個 SO₄²⁻（雙牙，佔 2 個配位位置）= 6 個配位位置 ✓
- 對離子：Cl⁻

**錯離子電荷：**

```
+3 + 4(0) + (−2) = +1   →   錯離子為 [Co(NH₃)₄SO₄]⁺
```

1 個 Cl⁻ 對離子平衡 → 化學式為 **[Co(NH₃)₄(SO₄)]Cl**

溶於水：

```
[Co(NH₃)₄(SO₄)]Cl(s) → [Co(NH₃)₄(SO₄)]⁺(aq) + Cl⁻(aq)
```

- Cl⁻ 自由游離 → 與 AgNO₃ 生成 AgCl 白色沉澱 ✓
- SO₄²⁻ 不游離 → 不與 BaCl₂ 反應 ✓

**答：化學式為 [Co(NH₃)₄(SO₄)]Cl，名稱為 tetraammine(sulfato)cobalt(III) chloride。**

### 進階例題 D（Exercise 31，難度：高）

**題目**：將 0.100 M 的 AgNO₃(aq) 加入各 100.0 mL、0.100 M 的以下配位化合物水溶液中，各能沉澱幾莫耳的 AgI？假設每個過渡金屬離子形成八面體（octahedral）錯合物（配位數 = 6）。

- Co(NH₃)₆I₃
- Pt(NH₃)₄I₄
- Na₂PtI₆
- Cr(NH₃)₄I₃

**解析思路：**

配位數 = 6 的八面體錯合物，方括號內的 I⁻ 為配體（不游離），方括號外的 I⁻ 為對離子（游離，與 Ag⁺ 形成 AgI 沉澱）。

**逐一分析：**

**(1) Co(NH₃)₆I₃**

Co³⁺，配位數 6，6 個 NH₃ 已填滿配位層 → I⁻ 全為對離子：

```
[Co(NH₃)₆]I₃  →  [Co(NH₃)₆]³⁺ + 3I⁻
```

**每莫耳沉澱 3 莫耳 AgI**

**(2) Pt(NH₃)₄I₄**

Pt²⁺（偶數 I 總數提示），配位數 6 → 4NH₃ + 2I⁻（配體）= 6，2I⁻ 為對離子：

```
[Pt(NH₃)₄I₂]I₂  →  [Pt(NH₃)₄I₂]²⁺ + 2I⁻
```

**每莫耳沉澱 2 莫耳 AgI**

**(3) Na₂PtI₆**

Pt⁴⁺（因 Na₂PtI₆：+2 − 4n = −2 → 需 Pt = +4），配位數 6 → 6I⁻ 全為配體，Na⁺ 為對離子：

```
Na₂[PtI₆]  →  2Na⁺ + [PtI₆]²⁻
```

I⁻ 全在方括號內，**不游離，每莫耳沉澱 0 莫耳 AgI**

**(4) Cr(NH₃)₄I₃**

Cr³⁺，配位數 6 → 4NH₃ + 2I⁻（配體）= 6，1I⁻ 為對離子：

```
[Cr(NH₃)₄I₂]I  →  [Cr(NH₃)₄I₂]⁺ + I⁻
```

**每莫耳沉澱 1 莫耳 AgI**

**各沉澱量計算（在 100.0 mL、0.100 M 溶液中，各含 0.0100 mol 化合物）：**

| 化合物 | 游離 I⁻ 數 | 沉澱 AgI（mol） |
|--------|-----------|----------------|
| Co(NH₃)₆I₃ | 3 | 0.0300 mol |
| Pt(NH₃)₄I₄ | 2 | 0.0200 mol |
| Na₂PtI₆ | 0 | 0 mol |
| Cr(NH₃)₄I₃ | 1 | 0.0100 mol |

## 八、本節重點整理

| 概念 | 要點 |
|------|------|
| 配位化合物（coordination compound） | = 錯離子（complex ion）+ 對離子（counter ions） |
| Werner 的初級化合價（primary valence） | 現代的氧化態（oxidation state） |
| Werner 的次級化合價（secondary valence） | 現代的配位數（coordination number） |
| 配位數（coordination number） | 最常見為 6（八面體）；其次為 4（四面體或平面四方形）；少數為 2（直線形） |
| 配體（ligand） | 路易斯鹼（Lewis base），提供孤對電子給金屬離子（Lewis acid）；形成配位共價鍵 |
| 單牙配體（monodentate） | 一個鍵結原子，如 NH₃、Cl⁻、H₂O |
| 雙牙配體（bidentate） | 兩個鍵結原子，如 en（乙二胺）、oxalate（草酸根） |
| 多牙配體（polydentate） | 多個鍵結原子，EDTA 最重要（六牙，hexadentate） |
| 螯合效應（chelate effect） | 多牙配體形成的錯合物比單牙配體更穩定，主因是熵增（entropy increase） |
| **命名順序** | 陽離子 → 陰離子；錯離子內：配體（字母順序）→ 金屬（+氧化態）|
| 陰離子錯合物 | 金屬名稱後加 -ate；部分金屬使用拉丁字根（Fe → ferrate、Cu → cuprate 等） |
| 對離子 vs. 配體的判斷 | 溶於水後，方括號外的離子游離；可用 AgNO₃（Cl⁻/Br⁻/I⁻）或 BaCl₂（SO₄²⁻）沉澱測試 |
