# 第十九章　過渡金屬與配位化學
## 19.8　配位錯合物的生物重要性（The Biological Importance of Coordination Complexes）

---

## 一、金屬離子在生物系統中的角色

過渡金屬離子具有兩個關鍵特性，使其在生物系統中不可或缺：

- **可以配位並釋放配體（coordinate and release ligands）**：金屬離子能與生物分子結合或解離，實現動態調控
- **容易進行氧化還原反應（undergo oxidation and reduction easily）**：金屬離子可在不同氧化態之間切換，參與電子傳遞

這兩個特性使過渡金屬離子成為生物體中理想的**氧氣運輸（oxygen transport）**、**氧氣儲存（oxygen storage）**、**電子傳遞（electron transfer）**、**催化反應（catalysis）** 和**藥物（drugs）** 的核心角色。

**第一列過渡金屬的生物功能：**

| 元素 | 生物功能（Biological Function） |
|------|-------------------------------|
| 鈧 Sc | 目前未知（None known） |
| 鈦 Ti | 目前未知（None known） |
| 釩 V | 人體中目前未知（None known in humans） |
| 鉻 Cr | 協助胰島素（insulin）控制血糖（blood sugar）；可能與膽固醇（cholesterol）控制有關 |
| 錳 Mn | 許多酶促反應（enzymatic reactions）所必需 |
| 鐵 Fe | 血紅蛋白（hemoglobin）和肌紅蛋白（myoglobin）的成分；參與電子傳遞鏈（electron transport chain） |
| 鈷 Co | 維生素 B₁₂（vitamin B₁₂）的成分，對碳水化合物、脂肪和蛋白質的代謝（metabolism）至關重要 |
| 鎳 Ni | 酶（enzymes）尿素酶（urease）和加氫酶（hydrogenase）的成分 |
| 銅 Cu | 多種酶的成分；協助鐵的儲存（iron storage）；參與毛髮、皮膚和眼睛色素（pigments）的生成 |
| 鋅 Zn | 胰島素（insulin）和許多酶（enzymes）的成分 |

本節以**鐵（iron）** 為重點，因其配位錯合物（coordination complexes）已被廣泛深入研究。

## 二、卟啉（Porphyrin）與血紅素（Heme）

### 2.1 卟啉配體（Porphyrin Ligand）

**卟啉（porphyrin）** 是一類複雜的環狀有機分子，作為**四牙配體（tetradentate ligand）** 與金屬離子（包括 Fe、Co、Mg）配位。

卟啉的共同特徵：
- 含有相同的中央環狀結構（central ring structure）
- 環的邊緣有不同的**取代基（substituents）**
- 4 個 N 原子作為配位原子，與金屬離子形成 4 個配位共價鍵

**重要的金屬-卟啉錯合物：**

| 金屬 | 錯合物名稱 | 生物功能 |
|------|----------|---------|
| Fe²⁺ 或 Fe³⁺ | 血紅素（heme） | 氧氣運輸（oxygen transport）和電子傳遞（electron transfer） |
| Mg²⁺ | 葉綠素（chlorophyll） | 光合作用（photosynthesis） |
| Co³⁺ | 維生素 B₁₂（vitamin B₁₂） | 代謝（metabolism） |

### 2.2 血紅素（Heme）的結構

**血紅素（heme）** 是含鐵的卟啉錯合物：

- Fe²⁺（或 Fe³⁺）與卟啉環的 4 個 N 原子配位（四牙配體，佔 4 個配位位置）
- Fe²⁺ 通常為六配位（six-coordinate），剩餘 2 個配位位置可供其他配體鍵結
- 血紅素整體為**平面結構（planar structure）**

## 三、細胞色素（Cytochromes）——電子傳遞

### 3.1 呼吸鏈（Respiratory Chain）

哺乳動物的主要能量來源是碳水化合物（carbohydrates）、蛋白質（proteins）和脂肪（fats）的氧化（oxidation）。氧氣（O₂）是最終的氧化劑（oxidizing agent），但並不直接與這些分子反應。

實際過程：
- 營養物質分解產生的電子（electrons）沿著一系列分子傳遞
- 最終將電子交給 O₂
- 這個複雜的電子傳遞路徑稱為**呼吸鏈（respiratory chain）**

### 3.2 細胞色素（Cytochromes）的結構與功能

**細胞色素（cytochromes）** 是呼吸鏈中主要的電子傳遞分子，由兩部分組成：

- 一個含鐵的血紅素（heme）錯合物
- 一個蛋白質（protein）

細胞色素中，Fe 在 **+2 和 +3 氧化態**之間切換，完成電子傳遞：

```
Fe²⁺（接受電子後）→ Fe³⁺（失去電子後）
    ↑                        ↓
接受來自               將電子傳遞給
上游分子的電子         下游分子或 O₂
```

## 四、肌紅蛋白（Myoglobin）——氧氣儲存

### 4.1 肌紅蛋白的結構

**肌紅蛋白（myoglobin）** 是肌肉中儲存氧氣（oxygen storage）的蛋白質，結構與細胞色素十分相似：

- 一個血紅素（heme）錯合物 + 一個蛋白質
- Fe²⁺ 與卟啉環的 4 個 N 原子配位（4 個位置）
- Fe²⁺ 還與蛋白質鏈上的 1 個 **N 原子**（組胺酸 histidine 的咪唑 imidazole 氮）配位（第 5 個位置）
- 留下**第 6 個配位位置**供 O₂ 分子鍵結

```
肌紅蛋白中 Fe²⁺ 的配位環境：

位置 1–4：卟啉環的 4 個 N（四牙配體）
位置 5：蛋白質組胺酸的 N
位置 6：O₂（可逆結合）
```

### 4.2 為何蛋白質能防止 Fe²⁺ 被氧化？

一個關鍵問題：若將 O₂ 通入只含血紅素（無蛋白質）的水溶液中，Fe²⁺ 會被立即氧化成 Fe³⁺；但在肌紅蛋白中，這種氧化並不發生。

**原因**：Fe²⁺ 的氧化需要**兩個血紅素分子之間形成氧橋（oxygen bridge）**：

```
Fe²⁺–O–O–Fe²⁺  →  2Fe³⁺ + O₂²⁻（過氧化物）
```

肌紅蛋白中龐大的蛋白質（bulky protein）包圍在血紅素周圍，在空間上阻止（steric hindrance）兩個肌紅蛋白分子靠得足夠近以形成氧橋，因此 Fe²⁺ 被保護、無法被氧化。

> **生物意義**：Fe³⁺ 無法與 O₂ 形成配位共價鍵（coordinate covalent bond），若 Fe²⁺ 被氧化，肌紅蛋白便喪失儲氧功能。蛋白質的三維結構（three-dimensional structure）對維持鐵的功能至關重要。

## 五、血紅蛋白（Hemoglobin）——氧氣運輸

### 5.1 血紅蛋白的結構

**血紅蛋白（hemoglobin）** 是血液中運輸氧氣（oxygen transport）的蛋白質：

- 由**四個類似肌紅蛋白的單元（four myoglobin-like units）** 組成
- 有兩種蛋白質鏈：α 鏈（alpha chains）× 2 + β 鏈（beta chains）× 2
- 每個單元含一個血紅素（heme）
- **每個血紅蛋白分子可結合 4 個 O₂ 分子**

### 5.2 氧合血紅蛋白（Oxyhemoglobin）的磁性

氧合血紅蛋白（oxyhemoglobin，攜帶 O₂ 的血紅蛋白）為**反磁性（diamagnetic）**，說明：

- O₂ 是對 Fe²⁺（d⁶）的**強場配體（strong-field ligand）**
- Fe²⁺（d⁶）+ 強場 O₂ → 低自旋（low-spin）→ 所有電子配對 → 反磁性

當 O₂ 釋放後，第 6 個配位位置改由**水分子（H₂O）** 佔據：

- H₂O 是弱場配體（weak-field ligand）
- Fe²⁺（d⁶）+ 弱場 H₂O → 高自旋（high-spin）→ 有未成對電子 → 順磁性（paramagnetic）
- 靜脈血（venous blood）因含去氧血紅蛋白而呈**藍色（bluish tint）**

```
O₂ 結合（arterial blood）：Fe²⁺ + O₂ → 低自旋，反磁性，亮紅色
O₂ 釋放（venous blood） ：Fe²⁺ + H₂O → 高自旋，順磁性，藍色
```

### 5.3 血紅蛋白與 O₂ 的平衡

血紅蛋白（Hb）與 O₂ 的結合可以用以下平衡表示：

```
Hb(aq) + 4O₂(g)  ⇌  Hb(O₂)₄(aq)
血紅蛋白            氧合血紅蛋白（oxyhemoglobin）
```

### 5.4 高山症（High-Altitude Sickness）與高原適應（High-Altitude Acclimatization）

在高海拔地區，空氣中 O₂ 含量（O₂ partial pressure）低於海平面。

根據**勒沙特列原理（Le Châtelier's principle）**：

```
Hb(aq) + 4O₂(g)  ⇌  Hb(O₂)₄(aq)

O₂ 濃度降低 → 平衡向左移 → Hb(O₂)₄ 濃度下降
→ 疲勞（fatigue）、頭暈（dizziness）、高山症（high-altitude sickness）
```

**人體的適應機制：**

長期生活在高海拔地區，人體會合成**更多的血紅蛋白（more hemoglobin）**，使平衡右移，補償低 O₂ 濃度的影響。這個過程稱為**高原適應（high-altitude acclimatization）**，通常需要數週。

> **實際應用**：運動員若要在高海拔地區參賽，應提前數週到當地訓練，待血紅蛋白濃度上升後再參賽，以發揮最佳表現。

## 六、CO 與 CN⁻ 的毒性機制

CO 和 CN⁻ 均對鐵有強烈的親和力，能干擾體內鐵錯合物的正常功能。

### 6.1 一氧化碳（CO）的毒性

**作用位點**：血紅蛋白（hemoglobin）中的 Fe²⁺

**機制**：
- CO 對血紅蛋白中 Fe²⁺ 的親和力（affinity）**約為 O₂ 的 200 倍**
- CO 與 Fe²⁺ 鍵結後形成**羰基血紅蛋白（carboxyhemoglobin）**，此結合非常穩定
- 羰基血紅蛋白（carboxyhemoglobin）**阻止 O₂ 的正常結合**，剝奪身體所需的氧氣

```
Hb + CO → HbCO（羰基血紅蛋白，carboxyhemoglobin）
          （穩定錯合物，不與 O₂ 交換）
→ 身體缺氧（hypoxia）→ 窒息（asphyxiation）
```

**治療方式**：吸入高濃度純氧，利用大量 O₂ 競爭，逐漸置換 CO。

### 6.2 氰化物（CN⁻）的毒性

**作用位點**：細胞色素氧化酶（cytochrome oxidase）——一種含鐵的細胞色素酶（cytochrome enzyme），催化呼吸鏈末端的氧化還原反應

**機制**：

- CN⁻ 與細胞色素氧化酶中的 Fe 強力配位
- 阻止電子傳遞過程（electron transfer process）的進行
- 呼吸鏈（respiratory chain）無法將電子傳遞給 O₂
- 細胞即使在有氧（aerobic）環境下也無法進行有氧代謝

```
CN⁻ + 細胞色素氧化酶（含 Fe）→ 穩定錯合物
→ 電子傳遞受阻 → 有氧代謝停止 → 迅速死亡（rapid death）
```

由於 CN⁻ 直接抑制細胞呼吸，因此被稱為**呼吸抑制劑（respiratory inhibitor）**。

### 6.3 CO 與 CN⁻ 毒性的比較

| 項目 | CO 中毒 | CN⁻ 中毒 |
|------|--------|---------|
| 作用位點 | 血紅蛋白（hemoglobin）中的 Fe²⁺ | 細胞色素氧化酶（cytochrome oxidase）中的 Fe |
| 競爭對象 | 取代 O₂ 的結合位置 | 阻斷電子傳遞鏈 |
| 毒性機制 | 阻止 O₂ 運輸 | 阻止細胞利用 O₂（有氧代謝） |
| 毒性速度 | 較慢（取決於暴露濃度） | 極快（數分鐘內致死） |

## 七、鐮刀型細胞貧血症（Sickle Cell Anemia）

血紅蛋白戲劇性地展示了生物分子**結構（structure）與功能（function）的緊密關係**：

**正常血紅蛋白**：蛋白質鏈上某特定位置有**極性（polar）** 胺基酸（amino acid）

**鐮刀型血紅蛋白**：合成時，蛋白質鏈上兩個位置插入了不正確的**非極性（nonpolar）** 胺基酸，取代了原本的極性胺基酸

後果：

- 非極性胺基酸取代使血紅蛋白的三維形狀（three-dimensional shape）大幅改變
- 紅血球（red blood cells）從正常的圓盤形（disk-shaped）變形為**鐮刀形（sickle-shaped）**
- 鐮刀形紅血球容易聚集，堵塞微血管（capillaries）
- 導致疼痛、貧血（anemia）及器官損傷

> **關鍵教訓**：即使在含有數百個胺基酸的蛋白質中，**僅僅 2 個胺基酸的改變**（在側鏈的極性上），就可以完全改變蛋白質的三維結構，進而喪失正常的生物功能。一級結構（primary structure，胺基酸序列）的微小改變足以引發嚴重疾病。

## 八、葉綠素（Chlorophyll）

**葉綠素（chlorophyll）** 是植物中進行光合作用（photosynthesis）的關鍵分子：

- 與血紅素同屬金屬卟啉（metalloporphyrin）錯合物
- 中心金屬離子為 **Mg²⁺**（而非 Fe）
- Mg²⁺ 與卟啉環的 4 個 N 原子配位
- 有兩種形式（葉綠素 a 和葉綠素 b），結構略有不同

> **比較**：血紅素（heme）含 Fe，負責 O₂ 運輸；葉綠素（chlorophyll）含 Mg，負責光合作用捕光。雖然金屬不同，但都使用卟啉作為四牙配體，體現了生物系統中的分子「設計重複使用」。

## 九、進階例題（選自課後習題）

### 進階例題 A（Exercise 77，難度：中）

**題目**：什麼原因導致高山症（high-altitude sickness）？什麼是高原適應（high-altitude acclimatization）？

**解析：**

**高山症的原因：**

在高海拔地區，大氣壓（atmospheric pressure）降低，O₂ 的分壓（partial pressure of O₂）也隨之降低。血紅蛋白（Hb）與 O₂ 的結合平衡為：

```
Hb(aq) + 4O₂(g)  ⇌  Hb(O₂)₄(aq)
```

O₂ 分壓降低 → 平衡向**左移（left shift）**（勒沙特列原理）→ 形成的氧合血紅蛋白（oxyhemoglobin）減少 → 血液攜帶的 O₂ 量不足 → 各組織（尤其是大腦）缺氧 → 出現**疲勞（fatigue）**、**頭暈（dizziness）**，嚴重時可引發稱為**高山症（high-altitude sickness）** 的嚴重疾病。

**高原適應（High-Altitude Acclimatization）：**

人體在低 O₂ 環境中會觸發生理性補償機制：刺激骨髓（bone marrow）**產生更多紅血球**，進而合成更多血紅蛋白（hemoglobin）。

血紅蛋白濃度增加（[Hb]↑）→ 平衡右移 → 即使在低 O₂ 分壓下，也能形成足夠的氧合血紅蛋白 → 維持正常的供氧水準。

這個適應過程通常需要**數週**，因此從低海拔地區移居高原的人初期會有不適，隨著血紅蛋白濃度上升，症狀逐漸消失。

### 進階例題 B（Exercise 76，難度：中）

**題目**：為何 CO 和 CN⁻ 對人體有毒？

**解析：**

**CO（一氧化碳）：**

CO 是強場配體（strong-field ligand），也是 σ 供電體（sigma donor）和 π 受電體（pi-acceptor），對 Fe²⁺ 的結合能力極強。

CO 與血紅蛋白（hemoglobin）中 Fe²⁺ 的**親和力（affinity）約為 O₂ 的 200 倍**，與 Fe²⁺ 結合後形成極穩定的羰基血紅蛋白（carboxyhemoglobin，HbCO）。HbCO 的形成阻止了 O₂ 的正常結合，使紅血球無法攜帶足夠 O₂ 供應組織，導致缺氧（hypoxia）甚至窒息（asphyxiation）。

**CN⁻（氰化物離子）：**

CN⁻ 與細胞色素氧化酶（cytochrome oxidase）中的含鐵活性位點（iron-containing active site）強力配位，阻止此酶催化的氧化還原反應進行。由於細胞色素氧化酶是呼吸鏈（respiratory chain）末端的關鍵酶，其被抑制後，電子無法傳遞給 O₂，有氧代謝（aerobic metabolism）完全停止，細胞迅速死亡。因此 CN⁻ 被稱為呼吸抑制劑（respiratory inhibitor）。

### 進階例題 C（Exercise 89，難度：高）

**題目**：血紅蛋白（Hb）是負責在血液中運輸 O₂ 的蛋白質，相關平衡為：

```
HbH₄⁴⁺(aq) + 4O₂(g)  ⇌  Hb(O₂)₄(aq) + 4H⁺(aq)
```

請用勒沙特列原理（Le Châtelier's principle）回答：

- (a) 在肺部（lungs）和細胞（cells）中，哪種形式的血紅蛋白（HbH₄⁴⁺ 或 Hb(O₂)₄）佔優勢？
- (b) 當一個人過度換氣（hyperventilate）時，血液中 CO₂ 濃度降低，這如何影響氧氣結合平衡？向紙袋（paper bag）呼吸如何幫助緩解過度換氣？
- (c) 心臟停止（cardiac arrest）時，注射碳酸氫鈉（sodium bicarbonate）溶液為何必要？

**解析：**

**(a) 肺部與細胞中血紅蛋白的形式**

**在肺部（lungs）**：

肺泡（alveoli）中 O₂ 分壓高（高濃度 O₂）→ 平衡**向右移** → **Hb(O₂)₄（氧合血紅蛋白）佔優勢** → 血紅蛋白攜帶 O₂

**在細胞（cells/tissues）**：

組織中 O₂ 被消耗，O₂ 分壓低；同時細胞代謝產生 CO₂，CO₂ 溶於水生成 H₂CO₃（碳酸），使 [H⁺] 升高 → 平衡**向左移** → **HbH₄⁴⁺（去氧血紅蛋白）佔優勢** → 釋放 O₂ 給組織

**(b) 過度換氣（Hyperventilation）**

過度換氣時，大量 CO₂ 被呼出，血液中 CO₂ 濃度降低：

```
CO₂ + H₂O  ⇌  H₂CO₃  ⇌  H⁺ + HCO₃⁻
CO₂↓ → 平衡左移 → [H⁺]↓（血液 pH 升高）
```

[H⁺] 降低 → 上述血紅蛋白平衡**向右移** → 血紅蛋白更緊密地結合 O₂，不願釋放 → 組織反而缺氧（hypoxia）→ 頭暈（dizziness）

**向紙袋呼吸的原理**：

呼出的氣體含高濃度 CO₂，反覆呼入 → 血液 CO₂ 濃度回升 → [H⁺] 恢復正常 → 血紅蛋白釋放 O₂ 的能力恢復 → 症狀緩解。

**(c) 心臟停止時注射碳酸氫鈉（NaHCO₃）**

心臟停止（cardiac arrest）時，血液循環停止，細胞仍進行無氧代謝（anaerobic metabolism），產生大量乳酸（lactic acid）和 CO₂，使血液 [H⁺] 急劇升高（血液酸化，pH 降低）。

[H⁺] 升高 → 血紅蛋白平衡**大幅向左移** → 即使心臟恢復跳動，血紅蛋白也難以在肺部結合 O₂

注射 NaHCO₃（鹼性）→ 中和過多的 H⁺：

```
HCO₃⁻(aq) + H⁺(aq)  →  H₂CO₃(aq)  →  H₂O(l) + CO₂(g)
```

[H⁺] 降低 → 血液 pH 恢復正常 → 血紅蛋白能正常攜帶 O₂ → 為心臟復甦（resuscitation）提供基本條件。

### 進階例題 D（Exercise 90，難度：高）

**題目**：CO 之所以有毒，是因為它與血紅蛋白的結合比 O₂ 更強。考慮以下反應和近似標準自由能變化（standard free energy changes）：

```
Hb + O₂ → HbO₂        ΔG° = −70 kJ
Hb + CO → HbCO         ΔG° = −80 kJ
```

請估算下列反應在 25°C 時的平衡常數（equilibrium constant）K：

```
HbO₂ + CO  ⇌  HbCO + O₂
```

**解析：**

**步驟一：計算目標反應的 ΔG°**

目標反應 = 反應 2 − 反應 1：

```
(Hb + CO → HbCO,  ΔG° = −80 kJ)
−(Hb + O₂ → HbO₂,  ΔG° = −70 kJ)
─────────────────────────────────
HbO₂ + CO → HbCO + O₂,  ΔG° = −80 − (−70) = −10 kJ
```

**步驟二：由 ΔG° 計算 K**

使用公式：

```
ΔG° = −RT ln K
```

代入數值（R = 8.314 J/(mol·K)，T = 298 K，ΔG° = −10,000 J/mol）：

```
−10,000 = −(8.314)(298) ln K
ln K = 10,000 / (8.314 × 298) = 10,000 / 2477.6 ≈ 4.037
K = e^4.037 ≈ 57
```

**答：K ≈ 57**

**物理意義解釋：**

K ≈ 57 意味著在平衡時，HbCO 的濃度是 HbO₂ 的 57 倍（在相同 CO 和 O₂ 濃度下）。即使 CO 濃度只有 O₂ 的 1/57，血液中的血紅蛋白也有一半會與 CO 結合。由於大氣中 CO 的存在（哪怕是微量），血紅蛋白都會優先結合 CO，嚴重削弱攜氧能力。

> **補充**：實際上 CO 對血紅蛋白的親和力估計約為 O₂ 的 200 倍，這裡計算得到 57 倍是因為使用了近似的 ΔG° 值。真實的 K 值約在 200 的量級。
