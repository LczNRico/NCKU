## 壹、專案概述

### 目標
為自學讀者（大氣科學入門程度）製作一套**完整、詳細、有系統**的大氣動力學講義，覆蓋全書 13 章。講義以「零基礎也能讀懂」為原則，同時兼顧大學部到研究所的學術深度。

### 核心原則
1. **物理優先**：所有數學推導之前，先用白話語言說清楚「為什麼要推這個」
2. **細節不省略**：每一個近似的使用條件、每一個量的物理意義都要交代
3. **台灣連結**：每冊結尾連結到台灣實際天氣現象，讓理論有落地感
4. **系統架構**：每冊開頭有路線圖，讀者隨時知道自己在哪裡

### 工作方式
- 使用者每次上傳對應章節的 **PDF 原文**，Claude 根據原文內容撰寫講義
- 若有格式或內容問題，使用者可隨時要求修改，Claude 更新對應段落
- 每次完成一冊後，更新本規劃文件的進度狀態

## 參、講義製作細節規範

### 3.1 啟動方式

每冊開始製作前，使用者需上傳對應章節的 **PDF 原文**。Claude 的製作流程為：

```
① 讀取 PDF 原文
       ↓
② 確認各節次內容範圍與重要公式
       ↓
③ 按照下方架構撰寫講義
       ↓
④ 輸出 .md 檔案
       ↓
⑤ 使用者確認 → 如有需要修改則更新局部段落
```

### 3.2 每冊統一架構

```
封面區
  ├── 冊號與標題
  ├── 涵蓋章節說明
  ├── 本冊學習目標（3–5 條）
  └── 本冊路線圖（各節邏輯流程圖）

正文（每節）
  ├── X.X.0  本節概述（Why：為什麼要學這個？）
  ├── X.X.1  物理直觀（What：這個現象是什麼？）
  │          先用生活類比或思想實驗說清楚，不用數學
  ├── X.X.2  數學推導（How：如何用數學描述？）
  │          ├── 逐步推導，每一步都附文字說明
  │          ├── 每個近似都說清楚「在什麼條件下成立」
  │          └── 最終結果用方框標示
  ├── X.X.3  重要辨析（常見混淆點或易錯觀念）
  └── X.X.4  本節小結（核心公式 + 一句話總結）

例題精講區（每冊 3–5 題）
  └── 各題格式見 3.4 節

附錄
  ├── 重要符號表
  ├── 公式速查表
  └── 🌏 台灣天氣連結
```

### 3.3 文字撰寫原則

**深度設定**：以「修過普通物理與微積分，但沒學過流體力學或大氣科學」的讀者為目標。

| 原則 | 說明 |
|------|------|
| 物理優先 | 所有推導都先有一段白話說明「這個推導在做什麼」，再展開數學 |
| 細節不省略 | 「顯然」、「可以驗證」這類跳步一律補齊 |
| 專有名詞雙語 | 每個大氣科學術語首次出現時標注英文，例如「位溫（Potential Temperature, θ）」 |
| 近似條件明確 | 每次使用近似（靜力近似、地轉近似等）都說明適用範圍與誤差量級 |
| 避免循環論證 | 不用「因為 A 所以 B，因為 B 所以 A」，每個概念的來源都要可追溯 |

### 3.4 例題格式規範

每道例題使用以下固定格式：

```markdown
### 例題 X.X（難度 ★★★★）
> 原書 Problem X.X

**【題目】**
（原文引用 + 中文翻譯，讓讀者知道原題長什麼樣）

**【解題思路】**
不直接給答案，先用 2–4 句說：
- 這題要用什麼工具/方程
- 有哪些近似可以使用
- 大概的解題路徑

**【完整解答】**
逐步展開，每個步驟附一行文字說明「這一步在做什麼」。

**【最終結果】**
$$\boxed{...}$$

**【延伸思考】**
（選填）這個結果有什麼物理含義？有什麼值得注意的地方？
```

**難度星級說明：**

| 星級 | 對應程度 | 說明 |
|------|---------|------|
| ★★☆☆☆ | 概念應用 | 代入公式即可，主要考察定義 |
| ★★★☆☆ | 基礎推導 | 需要 1–2 步數學推導 |
| ★★★★☆ | 進階計算 | 多步推導，需要整合多個概念 |
| ★★★★★ | 挑戰題 | 需要深度理解才能設定正確框架 |

### 3.5 數學格式規範

- **行內公式**：`$...$`，例如 `$f = 2\Omega\sin\phi$`
- **獨立公式**：`$$...$$`，居中顯示
- **重要結果加框**：`$$\boxed{...}$$`
- **公式編號**：重要公式在右側標注 `\tag{1.26}` 與原書對齊
- **向量**：粗體 `\mathbf{F}` 或上箭頭，與原書一致

## 伍、使用說明（給讀者自己的提醒）

### 如何閱讀一冊講義

1. **先讀路線圖**：了解這冊各節的邏輯順序
2. **每節先看概述**（Why）：確認這節要解決什麼問題，再開始讀
3. **推導要動手跟**：看到公式推導時，拿紙筆自己跟著算一遍，不要只用眼睛掃過
4. **近似條件要記**：每次看到「在某某近似下」的字樣，把條件抄下來——不懂近似的適用範圍就不算真的懂這個公式
5. **例題先自己試**：遮住解答，自己先想解題方向，再對照
6. **最後看台灣連結**：把抽象概念對應到實際天氣現象，幫助記憶
