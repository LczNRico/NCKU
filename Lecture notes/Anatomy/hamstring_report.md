# 膕繩肌完整報告 (Hamstrings)

---

## 一、組成介紹 (Composition Overview)

膕繩肌是位於大腿後側的肌肉群,由 **3 條肌肉、共 4 個起端**組成,除股二頭肌短頭外皆為**雙關節肌 (biarticular muscle)**,同時跨越髖關節與膝關節。

| 肌肉 | 英文 | 縮寫 | 關節數 |
|---|---|---|---|
| 半腱肌 | Semitendinosus | ST | 雙關節 |
| 半膜肌 | Semimembranosus | SM | 雙關節 |
| 股二頭肌長頭 | Biceps femoris, long head | BFlh | 雙關節 |
| 股二頭肌短頭 | Biceps femoris, short head | BFsh | **單關節**(僅跨膝) |

**位置關係**:半腱肌、半膜肌位於大腿後**內側**,合稱「內側膕繩肌 (medial hamstrings)」;股二頭肌(長頭+短頭)位於後**外側**,稱「外側膕繩肌 (lateral hamstrings)」。

> 💡 名稱由來:Hamstring 一詞源自屠宰業 —— 早期屠夫會用這幾條肌肉的肌腱將豬後腿(ham)懸掛(string up)風乾,因而得名。

## 二、各肌肉起止點 (Origin & Insertion)

### 半腱肌 (Semitendinosus, ST)
| 項目 | 內容 |
|---|---|
| 起點 (Origin) | 坐骨結節 (Ischial tuberosity) |
| 止點 (Insertion) | 脛骨近端內側,鵝掌肌腱 (Pes anserinus) |
| 支配神經 | 脛神經 (Tibial nerve),坐骨神經分支,L5–S2 |
| 特徵 | 肌腹短、肌腱極長(遠端 1/2 幾乎全為肌腱),常作為 ACL 重建的移植肌腱來源之一 |

### 半膜肌 (Semimembranosus, SM)
| 項目 | 內容 |
|---|---|
| 起點 (Origin) | 坐骨結節(較 ST 更外側、更上方的骨面) |
| 止點 (Insertion) | 脛骨內髁後內側面;部分纖維延伸形成膝關節後斜韌帶 (Posterior oblique ligament) 及膕斜韌帶 (Oblique popliteal ligament) |
| 支配神經 | 脛神經,L5–S2 |
| 特徵 | 四條膕繩肌中生理截面積(PCSA)最大,力量輸出潛力最高;止點結構複雜,同時對膝關節後內側提供動態穩定 |

### 股二頭肌長頭 (Biceps femoris, long head, BFlh)
| 項目 | 內容 |
|---|---|
| 起點 (Origin) | 坐骨結節(與半腱肌共用一條「聯合肌腱 conjoint tendon」起始) |
| 止點 (Insertion) | 腓骨頭 (Fibular head) |
| 支配神經 | 脛神經,L5–S2 |
| 特徵 | **臨床上受傷率最高的膕繩肌肌肉(約佔所有膕繩肌拉傷 80%)**,原因詳見第五章 |

### 股二頭肌短頭 (Biceps femoris, short head, BFsh)
| 項目 | 內容 |
|---|---|
| 起點 (Origin) | 股骨粗線 (Linea aspera)、外側髁上線 |
| 止點 (Insertion) | 腓骨頭(與長頭共用止點) |
| 支配神經 | **腓總神經 (Common fibular/peroneal nerve)**,坐骨神經另一分支 |
| 特徵 | 唯一單關節、且神經支配與其他三條不同的膕繩肌 —— 這個「雙神經雙關節」的解剖獨特性是股二頭肌整體(尤其長頭)易受傷的關鍵原因之一 |

## 三、各肌肉發力任務 (Muscle Actions)

| 肌肉 | 髖伸展 (Hip Extension) | 膝屈曲 (Knee Flexion) | 膝關節旋轉方向 |
|---|:---:|:---:|---|
| 半腱肌 | ✓ | ✓ | 內旋 (Internal rotation) |
| 半膜肌 | ✓ | ✓ | 內旋 (Internal rotation) |
| 股二頭肌長頭 | ✓ | ✓ | 外旋 (External rotation) |
| 股二頭肌短頭 | ✗ | ✓ | 外旋 (External rotation) |

**功能重點**:
- **內側膕繩肌(ST、SM)**:膝屈曲時使脛骨內旋,與膝關節內側穩定結構(內側副韌帶 MCL)協同工作
- **外側膕繩肌(BF)**:膝屈曲時使脛骨外旋,與外側結構(LCL、髂脛束)協同
- 這組**內外旋轉的相互制衡**,是膝關節在屈曲角度下維持旋轉穩定的重要機制,對籃球急停變向時的膝關節保護尤其關鍵
- 膕繩肌整體也是**前十字韌帶 (ACL) 的協同肌 (agonist/synergist)**:收縮時使脛骨相對股骨向後位移,抵抗 ACL 承受的前移剪力,這也是為什麼 ACL 復健極重視膕繩肌力量重建

## 四、動作模式中的應用 (Movement Patterns)

| 動作模式 | 主要收縮型態 | 主要負責肌肉 | 說明 |
|---|---|---|---|
| 短跑衝刺 (Sprinting) | **離心收縮 (Eccentric)** | BFlh 為主 | 擺盪後期 (late swing phase) 膕繩肌需在髖屈膝伸的姿勢下離心煞停小腿前擺,是拉傷風險最高的瞬間 |
| 羅馬尼亞硬舉 / 硬舉 (RDL/Deadlift) | 離心 + 向心 | 全膕繩肌 + 臀大肌 | 髖鉸鏈 (hip hinge) 動作模式,離心階段膕繩肌在拉長狀態下承重 |
| 北歐腿彎舉 (Nordic Hamstring Curl) | 離心為主 | 全膕繩肌,ST 貢獻最大 | 訓練膝屈曲離心強度,為公認拉傷預防黃金動作 |
| 增強式訓練/跳躍 (Plyometrics) | 向心為主(三關節伸展) | 全膕繩肌協同臀大肌 | 起跳瞬間協助髖伸展 |
| 踢球動作 (Kicking, 足球) | 離心 | 對側腿膕繩肌 | 踢擊腿在髖屈膝伸終端減速,常見拉傷情境 |
| 急停變向 (Cutting/Deceleration) | 離心 + 等長 | 全膕繩肌 | 膝屈曲角度下離心煞停body momentum,同時提供旋轉穩定 |
| 臀橋/臀推 (Bridge/Hip Thrust) | 向心 | 輔助臀大肌 | 髖伸展主動作肌為臀大肌,膕繩肌為協同肌 |

> 對你目前的訓練結構來說:RDL(週一)、北歐腿彎舉、臀推、Bulgarian Split Squat(週五)已完整涵蓋膕繩肌向心+離心刺激;籃球運動(週二)則是實際測試膕繩肌高速離心耐受度的場景。

## 五、膕繩肌拉傷 (Hamstring Strain Injury, HSI)

### 5.1 好發部位與受傷機制

膕繩肌拉傷依機制可分兩大類:

| 類型 | 好發肌肉 | 好發情境 | 受傷部位 |
|---|---|---|---|
| **高速跑動型 (Sprinting-type)** | BFlh(最常見) | 短跑衝刺、加速 | 肌肉肌腱接合處 (Myotendinous junction, MTJ),通常在肌肉中段偏近端 |
| **過度伸展型 (Stretching-type)** | SM 較常見 | 踢腿、舞蹈、跨欄、瑜伽式深髖屈同時伸膝 | 近端(靠近坐骨結節),嚴重時可致近端肌腱撕裂/骨突撕脫 |

**為什麼 BFlh 特別容易受傷?**
1. 雙關節架構,收縮時同時承受髖屈曲+膝伸展的雙重拉長張力
2. 短頭與長頭雖共用止點,但**神經支配不同**(脛神經 vs. 腓總神經),兩者收縮時序若不同步,會在共用肌腱處產生額外剪力
3. 衝刺擺盪後期離心負荷最大,肌肉在**接近最大拉長長度**時被要求產生高張力,是肌肉拉傷力學上最脆弱的組合

### 5.2 嚴重程度分級

| 分級 | 英文 | 病理變化 | 典型恢復期 |
|---|---|---|---|
| 第一級 (Grade I) | Mild strain | 少量肌纖維微撕裂,無明顯結構破壞 | 1–3 週 |
| 第二級 (Grade II) | Partial tear | 部分肌纖維斷裂,可觸及局部缺損或瘀血 | 3–8 週 |
| 第三級 (Grade III) | Complete rupture / Avulsion | 肌肉完全斷裂或近端肌腱從坐骨結節撕脫 | 數月,嚴重撕脫可能需手術 |

臨床上常搭配 **MRI 影像分級(British Athletics Muscle Injury Classification)**,依受傷位置(MTJ / 肌腱 / 肌腹)與範圍進一步細分,用來預測恢復期與復發風險。

### 5.3 危險因子 (Risk Factors)

| 類別 | 因子 |
|---|---|
| 不可改變 | 曾受傷病史(**單一最強預測因子**)、年齡增長、種族/肌肉架構差異 |
| 可改變 — 肌力 | 離心肌力不足、股四頭肌:膕繩肌力量比失衡 (Quad:Hamstring ratio) |
| 可改變 — 結構 | 肌束長度過短 (short fascicle length)、柔軟度失衡 |
| 可改變 — 神經肌肉控制 | 骨盆/腰椎控制不良、疲勞累積、衝刺技術缺陷 |
| 可改變 — 訓練管理 | 高速跑量急劇增加(workload spike)、熱身不足 |

### 5.4 預防策略 (Prevention)

1. **離心強度訓練為核心**:北歐腿彎舉 (Nordic Hamstring Curl) 是目前實證支持最強的預防動作,規律執行可有效提升 BFlh 離心力量與肌束長度
2. **肌束長度導向訓練**:RDL、Nordic curl 等在長肌肉長度下訓練的動作,能誘發肌束增長 (fascicle length adaptation),讓肌肉在高速離心情境下有更大安全緩衝
3. **漸進式衝刺暴露**:避免賽季初期或傷後突然大量高速跑動,採漸進式最大速度衝刺量規劃
4. **動態熱身**:包含漸進加速跑、動態伸展,啟動神經肌肉徵召效率
5. **腰骨盆控制訓練**:核心穩定性影響骨盆前傾角度,進而影響膕繩肌起始長度與受傷風險
6. **前次受傷完全康復再回場**:力量、柔軟度、跑動機制皆恢復對稱後才重返高強度訓練

### 5.5 恢復過程 (Rehabilitation Process)

| 階段 | 時間軸(依嚴重度調整) | 重點 |
|---|---|---|
| **急性期 (Acute)** | 傷後 0–3 天 | POLICE 原則(保護、適當負荷、冰敷、加壓、抬高),無痛範圍內活動,避免完全制動 |
| **亞急性期 (Subacute)** | 3 天–2 週 | 無痛等長收縮 → 漸進式等張訓練,恢復關節活動度,開始輕度伸展(避免過度牽拉) |
| **強化期 (Progressive Loading)** | 2–6 週 | 導入離心訓練(漸進式 Nordic curl、RDL),肌力對稱性追蹤,開始直線慢跑 |
| **功能期 (Functional/Sport-specific)** | 6 週以上 | 漸進式衝刺暴露(70%→85%→95%→100%最大速度)、變向/急停訓練、運動專項模擬 |
| **重返運動 (Return to Play)** | 依個案 | 需通過力量對稱測試(患側/健側比 >90%)、無痛完成最大速度衝刺、功能性測試(單腳跳、敏捷測試)全數通過 |

### 5.6 為何容易復發 (High Recurrence Rate)

膕繩肌拉傷是所有運動傷害中**復發率最高的肌肉傷害之一**,文獻上初次受傷後一年內復發比例相當可觀,原因包括:

1. **疤痕組織力學性質改變**:受傷處由排列雜亂、彈性較差的疤痕膠原填補,取代原本平行排列的肌纖維,該處成為新的力學弱點,好發於原受傷部位附近
2. **復健未完全、提早重返運動**:最常見的復發主因 —— 症狀緩解(疼痛消失)不等於組織與神經肌肉功能完全恢復,許多人在力量、肌束長度尚未恢復對稱前就重返高強度訓練
3. **離心肌力未完整恢復**:即使關節活動度與日常功能正常,離心肌力(尤其高速離心)往往是最後、也最容易被忽略恢復的能力
4. **肌束長度未恢復或縮短**:受傷後若未特別加入長肌肉長度訓練(如 Nordic curl、RDL),肌束可能維持縮短狀態,導致肌肉在高速離心時提前達到「危險拉長比例」
5. **恐懼-迴避行為 (Kinesiophobia)**:心理層面對再受傷的恐懼,導致衝刺技術不自覺改變(如縮短步幅、避免全力伸展髖關節),反而造成代償性生物力學異常,增加其他部位或對側肢體受傷風險
6. **訓練量管理疏失**:重返運動後高速跑動量規劃不當,短期內急速增加負荷

## 六、其他重要相關知識

### 近端膕繩肌肌腱病變 (Proximal Hamstring Tendinopathy)
與急性拉傷不同,這是**慢性、過度使用型**的止點病變,好發於坐骨結節附著處。常見於長跑者、久坐後突然增加訓練量者,特徵是**坐姿時疼痛加劇**(因坐骨結節受壓迫,肌腱在壓迫下同時承受張力,即「壓迫合併張力」的複合性病理機制),與急性肌肉撕裂的處理原則(急性期需休息)相反,慢性肌腱病變通常需要**漸進式負荷 (progressive tendon loading)** 介入。

### 膕繩肌症候群 (Hamstring Syndrome)
近端肌腱(特別是股二頭肌長頭與半腱肌聯合肌腱處)增厚或纖維化,壓迫鄰近的坐骨神經,產生類似坐骨神經痛的放射性疼痛,好發於坐姿、深蹲、直腿抬高動作時。需與單純肌腱病變或椎間盤神經壓迫做鑑別診斷。

### 神經張力 vs. 真正肌肉緊繃
臨床上「膕繩肌很緊」不一定是肌肉本身縮短,有時是**神經組織滑動張力異常**(如坐骨神經)造成類似緊繃感。可透過直膝抬腿測試 (Straight Leg Raise) 搭配踝關節背屈/蹠屈變化(Slump test 變化式)做鑑別 —— 若加入頸椎屈曲或踝關節動作會改變症狀表現,提示神經張力成分而非單純肌肉緊繃。

### 半腱肌作為 ACL 重建常用移植物
半腱肌(常合併股薄肌)因肌腱長、可摘取長度足夠、摘取後對膝屈曲力量影響相對小(有其他膕繩肌代償),是 ACL 重建手術中最常用的自體肌腱移植來源之一(Hamstring autograft)。

## 七、統整重點表

| 面向 | 關鍵重點 |
|---|---|
| 解剖特殊性 | 股二頭肌短頭是唯一單關節、且神經支配不同的膕繩肌組成 |
| 最易受傷肌肉 | 股二頭肌長頭 (BFlh),約佔所有膕繩肌拉傷 8 成 |
| 受傷高風險動作 | 短跑擺盪後期的離心煞停 |
| 最強預防手段 | 北歐腿彎舉(離心強度 + 肌束長度雙重效益) |
| 最強復發預測因子 | 既往受傷史 |
| 復發核心原因 | 提早重返運動、離心肌力與肌束長度未完全恢復 |
