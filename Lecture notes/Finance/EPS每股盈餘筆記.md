# 每股盈餘(EPS)完整筆記

## 一、基本定義

**EPS(Earnings Per Share, 每股盈餘)**:公司一年賺的錢,平均分配到每一股上,是多少錢。

### 計算公式

```
EPS = 公司稅後淨利 ÷ 流通在外股數
```

### 範例

假設某公司:
- 今年稅後淨利:10億元
- 流通在外股數:1億股

```
EPS = 10億 ÷ 1億股 = 10元
```

意思是理論上每一股可以分到10元的獲利。

---

## 二、為什麼要看EPS,而不是直接看淨利?

因為公司規模不同、股數不同,直接比較「賺多少錢」沒有意義。

| 公司 | 淨利 | 股數 | EPS |
|------|------|------|-----|
| A公司 | 100億元 | 50億股 | 2元 |
| B公司 | 10億元 | 1億股 | 10元 |

雖然A公司賺的**總金額**比較多,但平均到每一股,**B公司其實幫股東賺得更多**。

**結論**:EPS是用來比較「每一股的獲利效率」,而不是公司規模大小。

---

## 三、EPS的重要觀念

1. **EPS越高不代表股票越好**
   還要看股價貴不貴(需搭配本益比一起看:本益比 = 股價 ÷ EPS)

2. **EPS有分「過去」跟「預估」**
   - 過去EPS:已公布的實際財報數字
   - 預估EPS:分析師預測未來獲利,常用來計算「預估本益比」

3. **股本會影響EPS**
   若公司增資發行新股、股數變多,就算獲利不變,EPS也會被稀釋變低

---

## 四、同樣EPS數字,背後可能是不同組合造成的

### EPS「高」的兩種情況

**情況A:高獲利 + 股數普通(健康的高EPS)**
- 公司真的賺很多錢,獲利能力強
- 股數沒有異常減少,是實打實的獲利支撐
- 範例:淨利100億、股數10億股 → EPS = 10元
- 意義:最理想的情況,代表公司賺錢能力真的很強

**情況B:獲利普通 + 股數很少(數字好看但要小心)**
- 公司賺的錢不算特別多,但因股本小(股數少),平均下來EPS也會高
- 範例:淨利5億、股數0.5億股 → EPS = 10元(跟情況A一樣是10元!)
- 意義:公司規模可能較小,獲利的「絕對金額」不大,成長空間或抗風險能力要另外評估;也要注意流動性(股數少,交易量可能較低)

### EPS「低」的兩種情況

**情況A:獲利不佳(真正的問題)**
- 公司獲利能力真的不好,賺得少
- 範例:淨利1億、股數1億股 → EPS = 1元
- 意義:要檢視是產業問題、經營問題,還是一次性因素

**情況B:獲利不錯但股數過多(被稀釋)**
- 公司獲利其實還可以,但因股數太多(常增資、發新股、員工配股),導致平均EPS被拉低
- 範例:淨利20億、股數20億股 → EPS = 1元(跟情況A一樣是1元!)
- 意義:要留意公司是否常常「稀釋股權」,這對現有股東不利,應查核公司過去是否頻繁增資

---

## 五、關鍵提醒:EPS成長 vs 淨利成長,要分開看

這是很多新手容易忽略的重點:

- 如果**淨利成長**,但**股數也同時增加更多** → EPS可能不升反降
- 如果**淨利沒成長**,但公司透過「**庫藏股**」減少股數 → EPS反而會上升

### 建議做法

看EPS時,同時查兩個數字的變化:
1. 淨利成長率
2. 股數(流通股數)是否有明顯變動
