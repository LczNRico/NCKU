# 財報分析課程 — 模組一：三大報表基本邏輯

> 課程定位：七模組系統性財報分析課程第一站，後續模組將延續本模組建立的觀念，並以華城(1519)、士電(1503)、中興電(1513)等電力設備股實際數字延伸練習。

---

## 一、為什麼要學三大報表？

想像你要「健檢」一家公司，三大報表就是三種不同角度的健檢報告：

| 報表 | 回答的問題 | 就像人體健檢的… |
|---|---|---|
| **損益表** | 這段期間公司賺不賺錢？ | 這個月的收支明細 |
| **資產負債表** | 這家公司「現在」有多少家底？欠多少債？ | 某一天的體重、體脂率快照 |
| **現金流量表** | 公司帳上的錢是怎麼進出的？賺的錢是真金白銀還是紙上富貴？ | 血液是否真的有在循環 |

**關鍵觀念**：損益表和現金流量表是「一段期間」（例如某一季、某一年）的動態紀錄；資產負債表則是「某一個時間點」的靜態快照，就像拍照一樣。這個區分之後會一直用到，先記住。

---

## 二、損益表（Income Statement）：公司賺不賺錢

損益表的邏輯是「由上往下，層層扣除」：

```
營業收入（賣東西/服務收到的錢）
－ 營業成本（製造、進貨的直接成本）
＝ 營業毛利
－ 營業費用（銷售費用、管理費用、研發費用）
＝ 營業利益（本業賺的錢）
＋／－ 業外損益（利息收入、匯兌損益、處分資產等，非本業的錢）
＝ 稅前淨利
－ 所得稅費用
＝ 稅後淨利（Net Income，也叫「本期淨利」）
```

### 舉例說明（簡化教學數字）

| 項目 | 金額（萬元） |
|---|---|
| 營業收入 | 10,000 |
| 營業成本 | 7,500 |
| **營業毛利** | **2,500**（毛利率 25%） |
| 營業費用 | 1,300 |
| **營業利益** | **1,200**（營益率 12%） |
| 業外損益 | +100 |
| 稅前淨利 | 1,300 |
| 所得稅（假設20%） | 260 |
| **稅後淨利** | **1,040** |

若流通在外股數為 5,000 萬股：

**EPS = 稅後淨利 ÷ 流通股數 = 1,040萬 ÷ 5,000萬 = 0.208 元**

> EPS是損益表「最後一行」算出來的結果，跟毛利率、營益率是同一張表上不同層次的獲利能力指標，這是模組二會深入拆解的內容。

## 三、資產負債表（Balance Sheet）：公司的家底

核心公式（必須背起來）：

**資產 = 負債 + 股東權益**

白話講：**「公司擁有的東西」＝「用別人的錢買的」＋「用自己的錢買的」**

| 項目 | 白話解釋 | 常見科目 |
|---|---|---|
| **資產** | 公司擁有、能創造價值的東西 | 現金、應收帳款、存貨、廠房設備 |
| **負債** | 欠別人的，未來要還的 | 應付帳款、短期借款、應付公司債 |
| **股東權益** | 股東出的錢＋公司賺了沒分掉的錢 | 股本、資本公積、保留盈餘 |

資產和負債各自再分「流動」與「非流動」：

- **流動資產/負債**：一年內會變現或到期的（現金、存貨、應收帳款／短期借款、應付帳款）
- **非流動資產/負債**：一年以上的（廠房設備、長期投資／長期借款）

> 這個「流動」vs「非流動」的分類，是模組三「流動比率」「負債比」等安全性指標的基礎。

### 小練習

若一家公司資產 500 億，負債 200 億，股東權益是多少？

→ 500 − 200 = **300 億**

這 300 億就是「假如公司現在把所有東西賣掉、還完所有債，股東能分到的錢」，也叫「淨值」。

## 四、現金流量表（Cash Flow Statement）：錢是真的還是假的

損益表上的「賺錢」是用「權責發生制」算的——**東西賣出去就算營收，不管錢有沒有真的收到**。所以一家公司損益表很賺錢，帳上現金卻可能快燒光，這就是為什麼需要現金流量表來對帳。

現金流量表分三段：

| 現金流類型 | 代表意義 | 健康的公司通常... |
|---|---|---|
| **營業活動現金流（CFO）** | 本業實際收進來/付出去的現金 | 應該是**正數**，而且最好比稅後淨利還高或相近 |
| **投資活動現金流（CFI）** | 買賣廠房設備、轉投資的現金 | 成長型公司常是**負數**（在花錢擴產） |
| **籌資活動現金流（CFF）** | 借錢、還錢、發股利、買回庫藏股 | 依公司階段而定，發放股利會是負數 |

三段加總 = 本期現金增減，可對回資產負債表上「現金」這個科目的變化。

> **模組四「獲利含金量」的伏筆**：如果一家公司稅後淨利是正的、EPS很漂亮，但營業活動現金流是負的甚至遠低於淨利，代表獲利可能只是「應收帳款掛在帳上」或「存貨堆很多沒賣掉」，不是真的收到現金——這叫「獲利含金量低」，是很重要的財報陷阱警訊。

---

## 五、三張表怎麼串起來？

```
損益表的「稅後淨利」
    ↓（沒發放股利的部分，累加進去）
資產負債表的「股東權益－保留盈餘」

現金流量表的「期末現金餘額」
    ↓（必須完全對得上）
資產負債表的「資產－現金及約當現金」
```

**一句話總結三表關係**：
損益表告訴你「賺了多少」，現金流量表告訴你「這些錢有沒有真的進口袋」，資產負債表則是這一切累積下來、此刻公司的家底長什麼樣子。

---

## ✅ 模組一小結

1. 損益表：由上往下層層扣除，最後算出EPS
2. 資產負債表：資產＝負債＋股東權益，分流動/非流動
3. 現金流量表：分營業/投資/籌資三段，用來驗證損益表的「賺錢」是不是真的
4. 三張表彼此串連，不是各自獨立的
