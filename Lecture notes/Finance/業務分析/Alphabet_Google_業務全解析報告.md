## 一、先搞懂：Alphabet 與 Google 的關係

2015 年 8 月，Google 進行了一次組織重整，成立了一家**控股公司 Alphabet Inc.**，把原本的 Google 拆成兩塊：

- **Google LLC**：核心的搜尋、廣告、Android、YouTube、雲端等「會賺錢的本業」
- **Other Bets（其他賭注）**：Waymo、Verily 等「長期、高風險、還在燒錢」的實驗性事業

**為什麼要這樣做？** 兩個目的：

1. **財務透明化** —— 分開揭露後，投資人可以清楚看到「本業賺多少」與「新事業虧多少」，不會被混在一起看不清楚。
2. **資本配置紀律** —— 每個 Bet 要獨立為自己的成本負責，不能無限躲在搜尋廣告的獲利後面。

> **初學者重點**：你在證券商 App 上買的「Google」，買的其實是 **Alphabet Inc.** 這家控股公司的股票。Google 只是 Alphabet 底下最大的那間子公司。

### 股權結構的特殊之處（投資人必須知道）

Alphabet 有三種股票：

| 類別 | 代號 | 投票權 | 說明 |
|---|---|---|---|
| Class A | GOOGL | 1 票 | 一般大眾持有 |
| Class B | 未上市 | 10 票 | 創辦人 Larry Page、Sergey Brin 等內部人持有 |
| Class C | GOOG | 0 票 | 一般大眾持有，無投票權 |

**意義**：兩位創辦人透過 Class B 股，即使持股比例不高，仍掌握公司控制權。這是典型的「雙層股權結構（Dual-class share structure）」。對散戶而言，GOOGL 與 GOOG 價格差異極小，實務上兩者股價幾乎同步。

## 二、財報上的三大分部

Alphabet 在財報中只把業務分成 **三個報告分部**。這是你看財報時最重要的骨架：

| 分部 | FY2025 營收 | 佔比 | 獲利狀況 |
|---|---:|---:|---|
| **Google Services** | $342,721 百萬 | 85.1% | 高獲利，營業利益率長期在 34%～41% 區間 |
| **Google Cloud** | $58,705 百萬 | 14.6% | 已轉虧為盈，獲利快速放大 |
| **Other Bets** | $1,537 百萬 | 0.4% | 持續大額虧損（2025 年營業利益率約 −489%） |
| 避險損益 | −$127 百萬 | — | 匯率避險 |
| **合計** | **$402,836 百萬** | 100% | 全年營收年增約 15% |

> **關鍵洞察**：Google 業務看起來包山包海，但**超過 85% 的營收來自 Google Services，而 Services 裡面又有超過八成來自「廣告」**。所以本質上，Alphabet 今天仍然是一家**廣告公司**，只是正在快速長出第二個引擎（雲端）。

## 三、Google Services 完整拆解

這是 Alphabet 的現金牛。財報上再細分為四條營收線：

### 3-1. Google Search & other（搜尋及其他）

**FY2025 營收：$224,532 百萬（佔總營收約 55.7%）**
**2026 Q2：$63.3 億美元 × 10，即 $633 億美元，年增 17%**

這條線是整個 Alphabet 的心臟。包含：

#### 子業務內容

| 子項目 | 說明 |
|---|---|
| **Google 搜尋廣告** | 使用者搜尋關鍵字時出現的贊助結果。廣告主競標關鍵字，Google 依「點擊」收費（CPC 模式） |
| **Google Shopping 購物廣告** | 商品圖片＋價格的購物結果廣告 |
| **Google Maps 廣告** | 地圖上的商家推廣、在地搜尋廣告 |
| **Gmail 廣告** | 信箱「促銷內容」分頁中的廣告 |
| **Google Discover / News** | Android 主畫面左滑的資訊流廣告 |
| **Google Play 商店搜尋廣告** | App 搜尋結果內的推廣 |
| **AI Overviews / AI Mode** | 搜尋結果頁上方的 AI 摘要答案，現已開始置入廣告 |
| **Google Lens / Circle to Search** | 視覺搜尋，正在導入商業化 |

#### 商業模式核心

```
使用者免費搜尋 → 產生「意圖資料」 → 廣告主付費競標曝光 → Google 抽成
```

搜尋廣告之所以是史上最好的廣告生意，原因在於**意圖精準**：一個人搜尋「台南 冷氣安裝」時，他的購買意圖已經明確表達，這種廣告的轉換率遠高於電視或看板廣告。

#### 目前的關鍵變數：AI 會不會侵蝕搜尋？

這是 2024 年以來市場對 Google 最大的疑慮：

- **空方論點**：ChatGPT 等 AI 聊天機器人直接給答案，使用者不再點擊連結，廣告版位減少。
- **多方論點**：Google 已把 AI Overviews / AI Mode 整合進搜尋，並在 AI 答案中放廣告；使用者搜尋量不減反增；Gemini App 月活躍用戶已達約 9.5 億。

從 2026 Q2 財報看，搜尋營收年增 17%，暫時證明「AI 摧毀搜尋」的論點在短期內尚未成立。但公司財務長已預告 2026 Q3 起將面臨**高基期比較**（去年同期搜尋業績大幅加速），成長率可能放緩。

### 3-2. YouTube ads（YouTube 廣告）

**FY2025 營收：$40,367 百萬（佔總營收約 10.0%）**
**2026 Q2：約 $111 億美元，年增 13%**

#### 子業務內容

| 子項目 | 說明 |
|---|---|
| **In-stream 影片廣告** | 影片播放前／中插入的廣告（TrueView） |
| **YouTube Shorts 廣告** | 短影音的廣告，對標 TikTok、IG Reels |
| **YouTube Masthead** | 首頁頂部橫幅，品牌大戶專用 |
| **YouTube CTV（連網電視）** | 在電視機上看 YouTube 的廣告，正在搶食傳統電視廣告預算 |
| **YouTube Select** | 精選高品質頻道套裝，賣給大品牌 |

#### 重要觀察

- YouTube **2025 年全年總營收（廣告＋訂閱）已超過 600 億美元**。注意：財報中的「YouTube ads」只含廣告，訂閱收入被放在下面 3-4 的「訂閱、平台與裝置」。所以財報上的 YouTube 數字是**低估**其真實規模的。
- YouTube 在美國已是**串流電視收視時數第一名**，超越 Netflix。這代表它同時在吃「數位廣告」與「傳統電視廣告」兩塊餅。
- 對創作者的分潤（TAC，流量取得成本的一種）是主要成本，通常分給創作者約 55%。

### 3-3. Google Network（聯播網）

**FY2025 營收：$29,792 百萬（佔總營收約 7.4%）—— 唯一衰退的廣告業務（2024 年為 $30,359 百萬）**

這是 Google 幫「別人的網站與 App」賣廣告，然後抽成。

#### 子業務內容

| 子項目 | 說明 |
|---|---|
| **AdSense** | 中小型網站主嵌入 Google 廣告碼，Google 幫忙賣廣告並分潤 |
| **AdMob** | AdSense 的手機 App 版本 |
| **Google Ad Manager（GAM）** | 大型出版商用的廣告伺服器（原 DoubleClick for Publishers） |
| **AdX（Ad Exchange）** | 廣告交易所，即時競價（RTB）的「證券交易所」 |
| **Display & Video 360（DV360）** | 廣告主端的需求方平台（DSP） |

#### 為什麼這塊在衰退？

三個原因疊加：
1. **隱私法規收緊** —— 第三方 Cookie 逐步淘汰、Apple ATT 政策削弱追蹤能力。
2. **競爭加劇** —— Amazon、TikTok、Meta 的自有廣告網路搶食。
3. **反壟斷訴訟壓力** —— 美國司法部針對這塊業務的訴訟（見第九節），可能被迫分拆 AdX。

> **投資人重點**：Google Network 是 Alphabet 最脆弱的業務線。但它只佔總營收約 7%，即使被迫分拆，對整體衝擊有限——這也是為什麼 2025 年反壟斷判決後股價反而大漲的原因之一。

### 3-4. Google subscriptions, platforms, and devices（訂閱、平台與裝置）

**FY2025 營收：$48,030 百萬（佔總營收約 11.9%），年增約 19%**
**2026 Q2：約 $129 億美元，年增 15%**

這是成長最快的**非廣告**消費者業務，也是市場常常低估的一塊。

#### A. 訂閱（Subscriptions）

Alphabet 的付費訂閱總數在 2026 Q1 已達約 **3.5 億份**。

| 服務 | 內容 |
|---|---|
| **YouTube Premium** | 無廣告觀看＋背景播放 |
| **YouTube Music** | 音樂串流，對標 Spotify |
| **YouTube TV** | 美國的網路電視（有線電視替代品），約 800 萬以上訂戶 |
| **NFL Sunday Ticket** | 美式足球轉播權，YouTube 於 2023 年取得 |
| **Google One** | 雲端儲存空間訂閱 |
| **Google AI Pro / AI Ultra** | Gemini 進階 AI 訂閱方案，2025–2026 年成長最強勁的一塊 |
| **Nest Aware** | 智慧家庭攝影機的雲端錄影訂閱 |
| **Fitbit Premium** | 健康數據進階分析 |

#### B. 平台（Platforms）

| 平台 | 商業模式 |
|---|---|
| **Google Play 商店** | App 下載與內購抽成（一般 15%～30%）。這是「平台稅」，毛利極高 |
| **Android 作業系統** | 本身免費開源，但透過 GMS（Google 行動服務）授權與預設搜尋引擎綁定變現。全球超過 30 億台裝置 |
| **Chrome 瀏覽器** | 免費，但將流量導回 Google 搜尋（全球市佔率約 65%） |
| **Chrome OS / ChromeBook** | 教育市場為主的輕量作業系統 |
| **Google Play Games** | 遊戲平台服務 |

#### C. 裝置（Devices）—— 硬體事業

| 產品線 | 說明 |
|---|---|
| **Pixel 手機** | 自有品牌旗艦機，搭載自研 Tensor 晶片，是 Gemini AI 的展示櫥窗 |
| **Pixel Watch / Buds / Tablet** | 穿戴與周邊裝置 |
| **Nest** | 智慧家庭：溫控器、門鈴、攝影機、喇叭 |
| **Fitbit** | 2021 年收購的健康穿戴品牌 |
| **Chromecast / Google TV** | 電視串流裝置 |
| **Android XR / 智慧眼鏡** | 與三星、Warby Parker 等合作的 AR/AI 眼鏡（早期階段） |

> **注意**：硬體事業的毛利率遠低於軟體與廣告。Google 做硬體的主要目的不是賺硬體錢，而是**定義 Android 生態的標準、掌握使用者入口、展示 AI 能力**。這是策略性業務，不是獲利中心。

## 四、Google Cloud 完整拆解

**FY2025 營收：$58,705 百萬（年增 36%）**
**2026 Q2 營收：$247.68 億美元，年增 82%；營業利益 $88 億美元（去年同期為 $28 億）**
**2026 Q2 底積壓訂單（Backlog / RPO）：約 $5,140 億美元**

這是目前 Alphabet 成長故事的核心。從 2023 年才首次轉為單季獲利，到 2026 Q2 已經是年增 82% 的巨獸。

### 4-1. Google Cloud Platform（GCP）—— 基礎設施與平台

| 類別 | 主要產品 |
|---|---|
| **運算** | Compute Engine（虛擬機）、Google Kubernetes Engine（GKE，容器）、Cloud Run（無伺服器） |
| **儲存** | Cloud Storage、Persistent Disk、Filestore |
| **資料庫** | Cloud SQL、Spanner（全球分散式資料庫）、Bigtable、Firestore、AlloyDB |
| **資料分析** | **BigQuery**（資料倉儲，Google Cloud 的招牌武器）、Dataflow、Looker（BI 視覺化） |
| **網路** | Cloud CDN、Cloud Load Balancing、Cloud Interconnect、全球海底電纜網路 |
| **AI／機器學習** | **Vertex AI**（模型開發與部署平台）、Gemini API、Model Garden、Agentspace |
| **AI 基礎設施** | **TPU（Tensor Processing Unit）自研 AI 晶片** 與 NVIDIA GPU 的雲端租用 |
| **開發工具** | Cloud Build、Artifact Registry、Antigravity（AI 編碼工具，週活躍用戶已達 240 萬） |

#### 特別注意：TPU

Google 是**唯一自研 AI 訓練／推論晶片並大規模商用的雲端業者**。2026 Q2，Alphabet 首次認列 **TPU 硬體銷售收入**——這代表 TPU 從「自用 + 雲端出租」擴大到「直接賣給客戶」，是商業模式的重大轉折。

對半導體投資人（你的觀察名單中有 TSM、AMAT、AMD、NVDA）而言，這件事的意涵是：
- TPU 由 **博通（AVGO）協助設計、台積電（TSM）製造**
- TPU 若持續放量，是 NVIDIA 在 AI 加速器市場的主要威脅之一
- 但無論用 TPU 還是 GPU，**先進製程與封裝訂單都流向台積電**，這是 TSM 的結構性優勢

### 4-2. Google Workspace —— SaaS 應用

企業版的辦公室套裝，以「每位使用者每月訂閱費」計價：

| 產品 | 說明 |
|---|---|
| Gmail（企業版） | 商用信箱 |
| Google Drive / Docs / Sheets / Slides | 雲端文書協作 |
| Google Meet | 視訊會議 |
| Google Chat / Spaces | 團隊通訊 |
| Google Calendar | 行事曆 |
| **Gemini for Workspace** | 內建 AI 助理，是重要的漲價與加購來源 |
| NotebookLM Enterprise | AI 研究筆記工具 |

### 4-3. 資訊安全（Security）

這是 Google Cloud 近年最積極擴張的方向，靠併購快速補齊：

| 資產 | 取得方式 |
|---|---|
| **Mandiant** | 2022 年以 54 億美元收購，頂級資安事件應變顧問 |
| **Chronicle / Google SecOps** | 由 X 孵化，資安分析與威脅偵測平台 |
| **VirusTotal** | 惡意程式檔案掃描資料庫 |
| **Wiz** | **2026 年 3 月 11 日完成收購，總對價約 294.67 億美元** —— 雲端資安平台，是 Alphabet 史上最大宗併購案 |
| BeyondCorp | 零信任架構安全存取 |
| reCAPTCHA | 機器人偵測 |

> Wiz 這筆交易的策略意義：讓 Google Cloud 能保護**跨雲端（AWS、Azure、GCP 都能用）**的資安，把資安變成獨立於雲端市佔的成長引擎。

### 4-4. 產業垂直解決方案

醫療（Google Health / Med-PaLM）、金融、零售、製造、公部門（Google Public Sector）、電信等專屬雲端方案。

### 4-5. 能源與資料中心基礎建設

為了支撐 AI 運算，Alphabet 正在大舉投資能源：
- **Intersect Power** —— 以 48 億美元現金加承擔債務收購，取得資料中心與能源基礎設施能力
- 核能（SMR 小型模組化反應爐）採購協議、地熱、太陽能長約
- **2026 年資本支出（Capex）指引上調至最高 2,050 億美元**

## 五、Other Bets 完整拆解

**FY2025 營收：$1,537 百萬（僅佔總營收 0.4%），營業利益率約 −489%**
**2026 Q2 營收：$3.82 億美元，年增 2.4%**

這一段的財務貢獻極小，但**選擇權價值（option value）**極高。Other Bets 雇用至少 7,500 名員工。

### 5-1. Waymo —— 自動駕駛（最重要的一個）

| 項目 | 現況（2026 年） |
|---|---|
| 起源 | 2009 年 Google 自駕車專案 |
| 業務 | 完全無人的 Robotaxi 叫車服務 |
| 規模 | 每週超過 **50 萬趟**全自動駕駛乘車 |
| 城市 | 美國 11 個主要城市，2026 年已新開 6 個市場；正測試進軍倫敦、東京 |
| 估值 | 2026 年 2 月外部募資估值約 **1,260 億美元** |
| 領導 | Co-CEO：Tekedra Mawakana、Dmitri Dolgov |

**投資意義**：Waymo 是目前全球商業化最領先的 L4 自駕車公司。許多分析師認為 Waymo 的價值尚未反映在 Alphabet 股價中。若未來分拆上市（IPO），可能釋放可觀價值。

### 5-2. Verily —— 生命科學／健康科技

- 前身是 Google Life Sciences（2015 年從 X 獨立）
- 業務：AI 個人化健康、臨床試驗平台、健康資料分析
- 產品：Verily Me（消費者健康 App）、Project Baseline（大型健康研究）
- 有外部投資人（如新加坡淡馬錫）

### 5-3. Calico —— 抗老化與長壽研究

- 全名 California Life Company，2013 年成立
- 研究老化機制與相關疾病
- 與 AbbVie 合作研發
- **CEO 本人曾表示其藥物研究可能需要數十年才能產生影響** —— 這是典型的超長期賭注

### 5-4. Wing —— 無人機配送

- 已安全完成超過 **100 萬次**住家配送
- 合作夥伴包含 Walmart、DoorDash
- 主要市場：美國、澳洲、芬蘭

### 5-5. X（The Moonshot Factory）—— 登月工廠

- 負責人：Astro Teller
- 定位：孵化器，專門解決「用激進新技術解決世界級大問題」
- **畢業校友**：Waymo、Verily、Wing、Google Brain、Chronicle 都是從 X 孵化出來的

## ⚠️ 八、財報陷阱：這一季的 EPS 你必須看懂

**2026 Q2 的 GAAP EPS 是 $9.11，年增 294%。這個數字會嚴重誤導初學者。**

原因：淨利 $1,121.93 億中，有約 **$990.31 億來自「權益證券的未實現利益」**——主要是 Alphabet 持有的 SpaceX 與 Anthropic 股權因估值上升而產生的帳面獲利。

- **這不是本業賺的錢**
- **這沒有現金流入**
- **如果這些公司估值下修，下一季會變成巨額帳面虧損**

這就是為什麼要看 **Non-GAAP EPS $2.85** 與 **營業利益 $407.7 億**。營業利益才反映本業的真實表現（年增 30%）。

> 這正好呼應你在財報分析課程中的核心觀念：**「本業利益」與「業外損益」必須分開看**。此外，Q2 還認列了瑞典法院判給 PriceRunner 約 21 億美元本金的損害賠償（Alphabet 正在上訴），這也是業外項目。

另一個要注意的：**2026 年自由現金流（FCF）已轉為負值**，因為資本支出（最高 2,050 億美元）的擴張速度超過營運現金流的成長。這是 AI 軍備競賽的直接代價。

## 九、商業模式：錢到底怎麼賺的

用一張圖理解 Alphabet 的商業邏輯：

```
        【免費產品吸引使用者】
   搜尋、Gmail、Maps、YouTube、Android、Chrome
                  ↓
        【累積超大規模使用者與資料】
       數十億使用者 × 每天數十億次互動
                  ↓
     ┌────────────┴────────────┐
     ↓                          ↓
【廣告變現】                 【訂閱與雲端變現】
搜尋廣告、YouTube 廣告        Google One、AI Pro
聯播網廣告                    YouTube Premium
（佔營收 ~73%）               Google Cloud、Workspace
                              （佔營收 ~26%）
     └────────────┬────────────┘
                  ↓
          【龐大現金流】
                  ↓
     ┌────────────┼────────────┐
     ↓            ↓            ↓
  投資 AI     買回庫藏股     資助 Other Bets
 與資料中心    ＋現金股利     （Waymo 等）
```

### 三種護城河

1. **網路效應** —— 使用者越多，搜尋結果越好，廣告主越願意來，資料越多，AI 越強。
2. **規模經濟** —— 自建資料中心、海底電纜、自研晶片，單位運算成本遠低於競爭者。
3. **轉換成本／預設地位** —— Android、Chrome、Gmail 的預設入口地位，讓使用者「懶得換」。

## 十、投資角度：成長引擎與風險清單

### 10-1. 成長引擎（多方論點）

| 引擎 | 說明 |
|---|---|
| **雲端加速** | Cloud 年增 82%，積壓訂單 5,140 億美元，能見度極高 |
| **AI 全端整合** | 從晶片（TPU）→ 模型（Gemini）→ 應用（搜尋、Workspace）→ 雲端，是唯一具備全垂直整合的公司 |
| **訂閱經濟** | 3.5 億訂閱數，AI Pro/Ultra 方案成長強勁，毛利率高於廣告 |
| **YouTube 吃電視餅** | CTV 廣告仍有巨大成長空間 |
| **Waymo 選擇權** | 估值 1,260 億美元，尚未反映在多數估值模型中 |
| **現金部位** | 2,424 億美元現金＋有價證券，能承受長期投資與景氣循環 |

### 10-2. 風險清單（空方論點）

| 風險 | 說明 |
|---|---|
| **AI 顛覆搜尋** | 若使用者習慣直接問 AI 而非搜尋，廣告版位與單位經濟可能長期惡化 |
| **資本支出失控** | 2026 年 Capex 上看 2,050 億美元，FCF 已轉負。若 AI 需求不如預期，將是巨額減值風險 |
| **反壟斷（搜尋案）** | 2024/8/5 Mehta 法官判定 Google 在一般搜尋與搜尋文字廣告構成非法壟斷。2025/12/5 最終救濟判決**未要求分拆 Chrome 或 Android**，但限制排他性協議、要求對合格競爭者開放資料與搜尋聯播。合約限制已於 2026/2/3 生效，雙方仍在 D.C. 巡迴上訴法院互相上訴中 |
| **反壟斷（廣告技術案）** | 2025/4/17 Brinkema 法官判定 Google 在發布商廣告伺服器與廣告交易所市場非法壟斷。救濟階段仍在進行，可能被迫分拆 AdX |
| **歐盟與其他司法管轄區** | DMA 數位市場法、多國隱私法規、瑞典 PriceRunner 案（約 21 億美元）等持續增加合規與訴訟成本 |
| **TAC（流量取得成本）** | 支付給 Apple 等夥伴以維持預設搜尋地位的金額龐大，若被法規禁止，短期省錢但長期可能流失流量 |
| **Google Network 衰退** | 唯一負成長的廣告線 |
| **競爭** | OpenAI、Anthropic、Meta、Amazon、微軟在 AI 與雲端全面競爭 |
| **匯率** | 超過一半營收來自美國以外，美元強弱直接影響報表 |

### 10-3. 對「反壟斷」的正確理解

初學者常犯的錯誤是：**看到「敗訴」就恐慌**。

實際上，2024–2026 年 Google 連續在兩個案件被判違法，但股價在此期間大幅上漲，2026 年 1 月市值一度超越 Apple 成為全球第二大公司。原因是：

1. 法院傾向**行為救濟（behavioral remedies）**而非**結構救濟（分拆）**
2. 判決明確拒絕強制出售 Chrome 或 Android
3. 法院多次引用「AI 帶來的新競爭」作為不採取激進手段的理由
4. 上訴程序可能再拖數年

> **投資啟示**：法律風險要評估的是**「實際財務衝擊的機率 × 金額」**，而不是新聞標題的驚悚程度。這正是「利空出盡」的典型案例。

## 十一、新手追蹤指標檢查表

每季財報公布時，依序看這些數字：

### 必看（核心健康度）
- [ ] **總營收年增率** —— 是否維持雙位數
- [ ] **Google Search & other 年增率** —— AI 是否侵蝕搜尋的直接證據
- [ ] **Google Cloud 營收年增率與營業利益率** —— 第二引擎是否持續
- [ ] **Cloud Backlog（積壓訂單）** —— 未來營收的能見度
- [ ] **營業利益與營業利益率** —— 排除業外的真實獲利能力

### 次看（趨勢與品質）
- [ ] **資本支出（Capex）與自由現金流（FCF）** —— AI 投資的代價
- [ ] **YouTube 廣告年增率** —— 相對 Meta、TikTok 的競爭力
- [ ] **訂閱數與訂閱營收** —— 非廣告收入的多元化進度
- [ ] **Non-GAAP EPS vs GAAP EPS 的差距** —— 業外損益的干擾程度
- [ ] **Other Bets 虧損金額** —— 燒錢速度是否失控
- [ ] **庫藏股買回金額** —— 對 EPS 與 ROE 的影響

### 質性追蹤
- [ ] 反壟斷案件的上訴進度與救濟措施實際執行狀況
- [ ] Gemini 月活躍用戶與 token 處理量
- [ ] Waymo 城市擴張與每週乘車趟次
- [ ] TPU 對外銷售的規模
