### 1.2 商業模式的本質——「賣鏟子的人」

AMAT 不生產任何一顆晶片。它生產的是**製造晶片所需的設備**，公司自我定位為「**材料工程（materials engineering）解決方案的領導者**」。

理解 AMAT 有三個關鍵認知：

**第一，AMAT 是設備業中產品線最廣的一家。**
在晶圓製造的數十個製程步驟中，AMAT 幾乎每一個環節都有產品，唯一的重大缺口是**微影（lithography）**——那是 ASML 的獨占領域。10-K 明白指出：客戶把資本支出配置到「我們不服務的市場區塊，例如微影」，會直接不利於 AMAT。

**第二，AMAT 的護城河來自「跨製程協同最佳化」。**
因為同時擁有沉積、蝕刻、CMP、離子植入、製程控制的產品，AMAT 可以把多個步驟整合在同一個真空腔體內完成（integrated materials solutions），這是單一產品線廠商做不到的。10-K 用的字眼是「connect and co-optimize our technologies」。

**第三，AMAT 的營收由客戶的「資本支出」決定，不是由「終端需求」直接決定。**
這使它比 IC 設計公司**更晚、更劇烈**地感受到景氣循環。客戶蓋廠、擴產、技術轉換時 AMAT 大賺；客戶減資本支出時 AMAT 立刻承壓。

**第四，設備賣出去之後才是長期生意的開始。**
AMAT 累積的全球安裝機台基數（installed base）龐大，衍生出的備品、服務、軟體訂閱構成 AGS 分部——這是**遞延性、抗景氣的現金流來源**。

## 三、半導體系統分部

FY2025 營收約 **207 億美元**（占合併營收 73%）；FY2026 Q3 單季 70.4 億美元。這是 AMAT 獲利的主體。

10-K 對此分部的定義：設計、開發、製造並銷售用於製造積體電路的各類設備，涵蓋**材料工程、製程控制與先進封裝**，具體包括圖案轉換為元件結構、電晶體與內連線製造、量測、檢測與複驗、以及連接完成晶片的封裝技術。

以下按**製程步驟**拆解到產品層級。這是理解 AMAT 的正確方式——它的業務地圖是一張「晶圓製造流程圖」。

### 3.9 半導體系統的終端市場分布

10-K 將此分部的客戶分為三大市場：

| 終端市場 | FY2025 | FY2024 | FY2023 |
|---|---|---|---|
| **晶圓代工、邏輯及其他** | 67% | 68% | 77% |
| **DRAM** | 26% | 28% | 17% |
| **NAND 快閃記憶體** | 7% | 4% | 6% |

**「晶圓代工、邏輯及其他」再細分為：**
- **先進製程（leading-edge）**：7 奈米及以下
- **成熟製程（non-leading edge / ICAPS）**：物聯網、通訊、車用、電源、感測器

> ⚠️ **FY2025 的一個結構性弱點**：管理層在 Q4 法說會坦承，2025 年**中國以外成長最快的市場區塊，恰好是 AMAT 市占低或沒有市占的領域**——先進邏輯的投資偏向先進微影（ASML 的地盤），而 NAND 市場規模在 2025 年約翻倍，但 AMAT 在 NAND 的市占歷來偏低。這解釋了為何 FY2025 全年營收只成長 4%。

### 4.1 業務內容

| 特性 | 說明 |

| 分部 | Non-GAAP 營業利益率 | 去年同期 |

**半導體系統營業利益率大幅擴張的原因**：先進設備供給緊俏帶來的**定價權（pricing power）**，加上高毛利產品組合改善。管理層強調公司採用**「以價值為基礎的定價（value-based pricing）」**策略，多年來同時推升營收與毛利率。

> 💡 **對照你在博通報告看到的相反案例**：
> - 博通 FY2026 Q2：毛利率**下降**、營業利益率**上升** → 產品組合稀釋 + 營運槓桿
> - AMAT FY2026 Q3：毛利率**上升**（突破 50%）、營業利益率**上升** → 定價權 + 產品組合改善
>
> 兩者都是營業利益率上升，但**驅動力完全不同**。博通靠規模攤薄費用，AMAT 靠賣得更貴。這是分析獲利品質時必須區分的兩件事——**定價權驅動的利潤率擴張，品質高於單純的營運槓桿**，因為前者代表技術地位，後者只在營收持續成長時有效。

## 九、投資分析觀察重點

以下整理成分析框架，供你練習用，**非投資建議**。

### 9.1 出口管制——AMAT 最大的結構性風險

這是你先前已經研究過的主題，這裡補上最新進展：

| 事件 | 影響 |
|---|---|
| 管制累積效應 | 貿易限制造成的市場損失：FY2024 約等於中國市場的 **10%**，FY2025 **超過該數字的兩倍** |
| 2025 年「關聯企業規則」（affiliate rule） | 將出口黑名單擴及上市實體的**多數持股子公司**。AMAT 原估對 FY2026 營收衝擊 **6 億美元** |
| 規則暫停 | 該規則在美中領袖會談後暫停，重新開放約 6 億美元的全年銷售；FY2025 Q4 有約 1.1 億美元未出貨產品遞延至次季 |
| FY2026 最新估計 | 管理層於 Q3 法說會仍估出口管制將**削減 FY2026 營收約 6 億美元** |
| 無法服務的市場 | CEO 明言：AMAT **已無法供應中國的記憶體晶片與成熟製程市場** |
| 競爭劣勢 | CEO 直言：「非美國設備商沒有相同限制，受限客戶即使想買 Applied 也只能向他們採購。」日本與荷蘭廠商正在填補空缺 |

> ⚠️ **這個風險的隱蔽之處**：設備業的黏著性極高。競爭對手一旦裝機成功，就會取得後續的**服務合約與備品收入**，形成長期鎖定。因此「每一季無法銷售」的損失，不只是當季營收，而是**未來十年的服務現金流**。

### 9.2 應持續追蹤的核心指標

| 指標 | 為什麼重要 | 目前狀態（FY2026 Q3） |
|---|---|---|
| **Non-GAAP 毛利率** | 定價權與產品組合的溫度計 | 50.4%，已突破 50% |
| **半導體系統營業利益率** | 檢驗定價權是否持續 | 38.0%（去年 33.2%） |
| **AGS 營收年增率與利益率** | 遞延性現金流的健康度 | +22%，利益率 30% |
| **總 Backlog 與其結構** | 訂單能見度（同合約負債邏輯） | FY25 年底 150.02 億，31% 逾 12 個月 |
| **中國營收占比** | 出口管制暴露程度 | 28%（自 45% 高點下滑） |
| **各終端市場占比（代工/DRAM/NAND）** | 判斷是否押在成長最快的區塊 | 67% / 26% / 7% |
| **前兩大客戶集中度** | 單一客戶風險 | 19% + 15% = 34% |
| **資本支出與 EPIC Center 進度** | 未來競爭力的先行投資 | FY25 資本支出 23 億 |

### 9.3 主要風險（10-K 揭露）

1. **景氣循環**：10-K 開宗明義列為第一大風險。設備需求由客戶資本支出決定，波動遠大於終端需求
2. **AI 需求難以預測**：10-K 新增語言——「AI 快速演變，相關投資的時點與金額可能大幅改變，因此難以準確預測 AI 相關需求」
3. **出口管制與地緣政治**（見 9.1）
4. **客戶集中度**：前兩大客戶占 34%
5. **市占缺口**：不做微影；NAND 蝕刻市占偏低。客戶把資本支出配置到 AMAT 沒有產品的領域，AMAT 就吃不到
6. **中國本土競爭者崛起**：中國政府補貼扶植本土設備商（如北方華創、中微），加上美國管制反而給了非美競爭者機會
7. **政府調查**：自 2022 年起，AMAT 陸續收到來自**司法部（DOJ）、商務部工業安全局（BIS）、證管會（SEC）** 關於中國客戶出貨與出口管制合規的傳票，並仍持續收到新的傳票與資訊要求。結果無法預測
8. **稅務**：2025 年 7 月美國通過 OBBBA 法案，導致 AMAT 無法預估 CAMT 稅額抵減遞延所得稅資產的使用，已提列**全額評價備抵**，推升 FY2025 有效稅率。新加坡的優惠稅率自 **FY2030 起陸續到期**，能否續期無保證
9. **商譽減損**：FY2025 Q4 已認列減損

### 9.4 分析時容易犯的錯

| 常見誤解 | 實際情況 |
|---|---|
| 「AI 熱潮 = AMAT 立刻大賺」 | FY2025 全年營收僅成長 4%。AI 需求要先變成客戶的資本支出決策，再變成設備訂單，中間有 12–24 個月時滯。真正的爆發在 FY2026 才出現 |
| 「AMAT 是所有製程的龍頭」 | 微影完全不做（ASML）；蝕刻由 Lam 主導；檢測量測由 KLA 主導。AMAT 的強項是**沉積、磊晶、離子植入、CMP** |
| 「營收 +4% 代表競爭力衰退」 | FY2025 的問題是**市場成長發生在 AMAT 市占低的區塊**（先進微影、NAND），而非 AMAT 自身失去技術地位 |
| 「backlog 就是未來一年營收」 | 約 31% 預期超過 12 個月才交付；且出口規則變動可直接使 backlog 失效 |
| 「中國占比下降是壞事」 | 短期是營收損失，但同時降低了政策風險暴露。FY2026 Q3 中國降至 28%、美國占比接近翻倍，這是**營收結構的去風險化** |
| 「毛利率 50% 不如博通的 78%」 | 兩者商業模式不同。設備業有大量硬體成本，50% 毛利率在 WFE 業界已是頂尖水準，且是 AMAT **25 年來的最高點** |
| 「ROE 40%+ 代表經營極佳」 | **這是你已經驗證過的陷阱**：AMAT 的高 ROE 有相當部分來自庫藏股大量回購壓縮股東權益。加回庫藏股後，實質 ROE 從約 42.7% 降至約 13.7%。分析時務必用 DuPont 分解區分「經營效率驅動」與「資本結構驅動」 |

### 9.5 給你的延伸練習

用你已建立的框架，試著回答這幾個問題：

1. **合約負債／Backlog 練習**：AGS backlog 占總 backlog 48%，且服務屬於「按時間認列」。這對 AMAT 在景氣下行時的營收韌性有什麼意義？和華城 1519 的合約負債相比，哪一個的能見度品質較高？
2. **毛利率練習**：AMAT FY2026 Q3 毛利率突破 50%，管理層歸因於「定價權」。你要看哪些佐證數據，才能確認這不是短期的產品組合偶然？
3. **ROE 練習**：AMAT FY2025 回購 49 億美元（流通股數 −3%），同時 EPS 成長 9%（non-GAAP）。請拆解：這 9% 中有多少來自盈餘成長，多少來自股數減少？
4. **週期練習**：FY2025 營收 +4%，FY2026 Q4 財測 +51%。這種劇烈加速在景氣循環股身上意味著什麼？股價通常會領先或落後這個轉折？

## 附錄：AMAT 與博通的商業模式對照

你剛做完博通的報告，把兩者並排看，很多概念會立刻清楚：

| 面向 | 應用材料（AMAT） | 博通（AVGO） |
|---|---|---|
| **在產業鏈的位置** | 上游設備（賣鏟子） | 中游 IC 設計（賣晶片） |
| **產品** | 實體機台 + 服務 | 晶片 + 軟體授權 |
| **客戶** | 晶圓廠（台積電、三星、Intel、記憶體廠） | 雲端業者、手機廠、電信商、企業 IT |
| **營收驅動** | 客戶的**資本支出** | 客戶的**產品出貨量與訂閱續約** |
| **景氣敏感度** | 極高（週期股） | 中等（AI 需求 + 軟體訂閱緩衝） |
| **FY2025 營收** | 283.7 億美元 | 638.9 億美元 |
| **FY2025 成長** | +4% | +24% |
| **最新單季毛利率** | 50.4%（25 年新高） | 77.1%（因組合下滑） |
| **成長方式** | 內部研發為主 | 併購為主 |
| **製造模式** | 自有工廠組裝整合 | 幾乎全外包（95% 晶圓給台積電） |
| **員工人數** | 36,500 | 33,000 |
| **能見度工具** | Backlog（150 億） | Backlog（1,620 億） |
| **最大風險** | 出口管制 + 景氣循環 | 客戶集中（6 家 XPU 客戶） |
| **與台積電的關係** | **供應商**（賣設備給台積電） | **客戶**（向台積電買產能） |

> 💡 **一個有趣的傳導鏈**：博通的 XPU 訂單 → 台積電必須擴產先進製程與 CoWoS → 台積電向 AMAT 採購沉積、磊晶、CMP、先進封裝設備。所以**博通的 backlog 是 AMAT 未來營收的領先指標之一**。同樣地，HBM 需求 → 記憶體廠擴產 → AMAT 的 DRAM 與先進封裝設備訂單。
>
> 這正是你正在建立的「產業鏈思維」——不要孤立地看單一公司，要看它在鏈條中的位置，以及訊號從哪裡傳過來、傳到哪裡去。
