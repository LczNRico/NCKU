# 第 21 章　有機與生化分子
## 21.6　天然聚合物（Natural Polymers）

---

## 一、天然聚合物概述

許多重要的天然物質本身就是聚合物（polymers），例如：
- 澱粉（starch）、纖維素（cellulose）：碳水化合物聚合物（carbohydrate polymers）
- 蛋白質（proteins）：胺基酸聚合物（amino acid polymers）
- DNA、RNA：核苷酸聚合物（nucleotide polymers）
- 毛髮（hair）、蠶絲（silk）、棉花（cotton）：天然蛋白質或碳水化合物纖維

本節依序介紹三大類天然聚合物：**蛋白質（proteins）**、**碳水化合物（carbohydrates）**、**核酸（nucleic acids）**。

---

## 二、蛋白質（Proteins）

### 2.1 蛋白質的基本特性

蛋白質（proteins）是自然界最重要的一類聚合物：
- 佔人體質量約 **15%**
- 分子量（molar mass）範圍：約 6,000 至超過 1,000,000 g/mol
- 依據功能分為兩大類：

| 類別 | 英文 | 特徵 | 功能 |
|------|------|------|------|
| 纖維蛋白質 | fibrous proteins | 長纖維狀（elongated） | 提供結構與強度（structure and strength）；構成肌肉（muscle）、毛髮（hair）、軟骨（cartilage） |
| 球狀蛋白質 | globular proteins | 近球形（roughly spherical） | 執行生物功能：運輸氧氣（oxygen transport）、催化反應（catalysis）、免疫防禦（immune defense）、調節（regulation） |

### 2.2 胺基酸（Amino Acids）——蛋白質的單體（Monomers）

所有蛋白質的單體（monomers）都是 **α-胺基酸（α-amino acids）**，其通式為：

```
        H    O
        |    ‖
H₂N ── C ── C ── OH
        |
        R（側鏈 side chain）
```

- **α-碳（α-carbon）**：連接胺基（amino group，–NH₂）的碳，也是連接 R 基和羧基（carboxyl group，–COOH）的碳
- **R 基（side chain）**：決定各胺基酸的化學性質，共有 20 種常見胺基酸

**20 種胺基酸的分類：**

| 類別 | R 基特性 | 代表胺基酸 |
|------|---------|-----------|
| 非極性（nonpolar）R 基 | 主要含 C 和 H | 甘胺酸（glycine, Gly）、丙胺酸（alanine, Ala）、苯丙胺酸（phenylalanine, Phe）、纈胺酸（valine, Val）、白胺酸（leucine, Leu）等 |
| 極性（polar）R 基 | 含大量 N 和 O | 絲胺酸（serine, Ser）、天冬胺酸（aspartic acid, Asp）、離胺酸（lysine, Lys）、半胱胺酸（cysteine, Cys）等 |

> **疏水性（hydrophobic）vs. 親水性（hydrophilic）**：
> - 非極性 R 基 → **疏水性（hydrophobic）**：排斥水，傾向藏於蛋白質內部
> - 極性 R 基 → **親水性（hydrophilic）**：親水，傾向暴露在蛋白質表面

### 2.3 胜肽鍵（Peptide Linkage）的形成

兩個胺基酸（amino acids）之間透過**縮合反應（condensation reaction）** 形成**胜肽鍵（peptide linkage / peptide bond）**，釋出一分子水（H₂O）：

```
H₂N–CHR–COOH  +  H₂N–CHR'–COOH
→  H₂N–CHR–CO–NH–CHR'–COOH  +  H₂O
              ↑
         胜肽鍵（peptide bond）
          –CO–NH–
```

**多肽鏈（polypeptide chain）** 的形成：

```
胜肽鍵持續延長：
H₂N–[AA₁]–CO–NH–[AA₂]–CO–NH–[AA₃]–...–COOH

AA = 胺基酸殘基（amino acid residue）
左端（N 端，N-terminus）= 自由胺基（free amino group）
右端（C 端，C-terminus）= 自由羧基（free carboxyl group）
```

> **胜肽鍵（peptide bond）= 有機化學中的醯胺鍵（amide bond）**：–CO–NH–

### 2.4 蛋白質的結構層次（Levels of Protein Structure）

蛋白質的三維結構（three-dimensional structure）分四個層次：

#### 一級結構（Primary Structure）

**定義**：多肽鏈（polypeptide chain）中胺基酸（amino acids）的排列順序（sequence）。

以三字母縮寫（three-letter codes）表示，N 端在左，C 端在右：

```
例：lys-ala-leu（離胺酸-丙胺酸-白胺酸）
```

**多樣性計算：**
- 20 種胺基酸可任意排列
- n 種不同胺基酸組成的多肽（polypeptide）有 **n!** 種可能序列
- 20 種胺基酸 → 20! = 2.43 × 10¹⁸ 種可能序列
- 這保證了生物體可以製造幾乎無限種功能各異的蛋白質

**一級結構決定蛋白質功能的例子：**

催產素（oxytocin）與血管加壓素（vasopressin）都是 9 個胺基酸的多肽（polypeptide），僅差 **2 個胺基酸（2 amino acids）**，但功能完全不同：
- 催產素（oxytocin）：促進子宮收縮（uterine contraction）和泌乳（milk secretion）
- 血管加壓素（vasopressin）：升高血壓（blood pressure）、調節腎功能（kidney function）

```
催產素：cys–tyr–ile–gln–asn–cys–pro–leu–gly
血管加壓素：cys–tyr–phe–gln–asn–cys–pro–arg–gly
                        ↑                        ↑
                    差異位置（differences）
```

#### 二級結構（Secondary Structure）

**定義**：多肽鏈（polypeptide chain）局部的空間排列，由鏈內或鏈間的**氫鍵（hydrogen bonds）** 決定。

氫鍵形成於：一個胺基酸的羰基氧（carbonyl oxygen，C=O 的 O）與另一個胺基酸的醯胺氫（amide hydrogen，N–H 的 H）之間：

```
C=O ⋯ H–N（氫鍵 hydrogen bond，以虛線 ⋯ 表示）
```

兩種主要的二級結構（secondary structures）：

**α-螺旋（α-helix）：**
- 鏈在**鏈內（intrachain）** 捲曲形成螺旋（spiral/helix）
- 氫鍵在同一條鏈上形成（intrachain hydrogen bonds）
- 賦予蛋白質**彈性（elasticity）**
- 存在於：毛髮（hair）、羊毛（wool）的蛋白質 α-角蛋白（α-keratin）；肌腱（tendons）的膠原蛋白（collagen）

**褶板片（pleated sheet）：**
- 不同多肽鏈之間形成氫鍵（interchain hydrogen bonds）
- 鏈平行排列形成褶紋狀的片層結構
- 賦予蛋白質纖維**柔韌性（flexibility）** 和**抗拉伸性（resistance to stretching）**
- 存在於：蠶絲（silk）的絲蛋白（silk fibroin）、肌肉纖維（muscle fibers）

| 特性 | α-螺旋（α-helix） | 褶板片（pleated sheet） |
|------|------------------|----------------------|
| 氫鍵位置 | 鏈內（intrachain） | 鏈間（interchain） |
| 結構形態 | 螺旋狀（helical） | 平面褶紋（planar zigzag） |
| 賦予性質 | 彈性（elasticity） | 柔韌且抗拉伸（flexible but strong） |
| 代表蛋白質 | α-角蛋白（α-keratin）、膠原蛋白（collagen） | 絲蛋白（silk fibroin） |

#### 三級結構（Tertiary Structure）

**定義**：整條多肽鏈（polypeptide chain）的整體三維形狀（overall three-dimensional shape），由各種分子間作用力（intermolecular forces）維持：

| 作用力類型（Type of Interaction） | 參與的側鏈或基團（Involved Groups） |
|----------------------------------|----------------------------------|
| 氫鍵（hydrogen bonds） | 含 –OH、–NH₂、–COOH 的極性側鏈（polar side chains） |
| 偶極-偶極作用力（dipole-dipole interactions） | 極性側鏈（polar side chains） |
| 離子鍵（ionic bonds） | 帶正電的 –NH₃⁺ 與帶負電的 –COO⁻ |
| 共價鍵（covalent bonds）：雙硫鍵（disulfide bonds） | 兩個半胱胺酸（cysteine）的 –SH 氧化形成 –S–S– |
| 色散力（London dispersion forces） | 非極性側鏈（nonpolar side chains）之間 |

**雙硫鍵（disulfide bond / disulfide linkage）** 特別重要：

```
–CH₂–SH  +  HS–CH₂–  →(氧化 oxidation)  –CH₂–S–S–CH₂–  +  2H⁺ + 2e⁻
（半胱胺酸 cysteine）                        （雙硫鍵 disulfide bond）
```

**應用：燙髮（Permanent Waving of Hair）**

```
步驟一：還原劑（reducing agent）斷裂頭髮中的雙硫鍵（disulfide bonds）
步驟二：用捲髮器（curlers）固定頭髮的新形狀（tertiary structure 改變）
步驟三：氧化劑（oxidizing agent）在新位置重新形成雙硫鍵（disulfide bonds）
→ 頭髮保持新的捲曲形狀
```

**三級結構決定蛋白質形狀：**

- **纖維狀蛋白質（fibrous proteins）**：細長形，如 α-角蛋白（α-keratin）、膠原蛋白（collagen）
- **球狀蛋白質（globular proteins）**：近球形，如肌紅蛋白（myoglobin）——其二級結構以 α-螺旋（α-helix）為主，但在彎折處變為**無規線團（random-coil）** 排列，使整體摺疊成球狀

### 2.5 蛋白質變性（Denaturation）

**變性（denaturation）**：蛋白質的三維結構（three-dimensional structure）被破壞，但一級結構（primary structure，即胺基酸序列）不變。

常見的變性因素（denaturing agents）：
- **熱能（heat）**：如煮熟雞蛋時蛋白質變性
- **紫外線（UV radiation）/ X 射線（X-ray radiation）**：可能導致癌症（cancer）或基因損傷（genetic damage）
- **有毒化學物質（toxic chemicals）**：苯（benzene）、三氯乙烷（trichloroethane）等
- **重金屬（heavy metals）**：鉛（lead）、汞（mercury）與硫（sulfur）親和性強，破壞雙硫鍵（disulfide bonds）

> 蛋白質一旦變性（denatured），往往喪失其生物功能（biological function）。

## 三、碳水化合物（Carbohydrates）

### 3.1 基本概念

**碳水化合物（carbohydrates）** 的化學通式接近 **(CH₂O)ₙ**（因此早期稱為「碳的水合物」）。功能：
- 大多數生物的**能量來源（energy source）**
- 植物的**結構材料（structural material）**

### 3.2 單糖（Monosaccharides）——碳水化合物的單體（Monomers）

**單糖（monosaccharides）** 又稱簡單糖（simple sugars），是**多羥基醛（polyhydroxy aldehydes）** 或**多羥基酮（polyhydroxy ketones）**。

依碳數分類：

| 類別 | 英文 | 碳數 | 代表例 |
|------|------|------|--------|
| 戊糖 | pentoses | 5 | 核糖（ribose）、去氧核糖（deoxyribose）、核酮糖（ribulose） |
| 己糖 | hexoses | 6 | 葡萄糖（glucose）、果糖（fructose）、半乳糖（galactose）、甘露糖（mannose） |

### 3.3 手性碳（Chiral Carbon）與光學異構物（Optical Isomers）

若碳上接有**四個不同的基團（four different groups）**，稱為**手性碳（chiral carbon）**，其鏡像（mirror image）無法與原結構重疊（nonsuperimposable）→ 產生一對**光學異構物（optical isomers）**。

```
甘油醛（glyceraldehyde）是最簡單的糖，含 1 個手性碳（chiral carbon）：

        O
        ‖
    H – C
        |
  HO – C* – H        (* 標記手性碳 chiral carbon)
        |
    CH₂OH

→ 有 2 種光學異構物（optical isomers）：D-型和 L-型
```

**手性碳數目（number of chiral carbons）** 與異構物數目的關係：

```
n 個手性碳 → 最多 2ⁿ 種立體異構物（stereoisomers）

例：果糖（fructose）有 3 個手性碳 → 最多 2³ = 8 種立體異構物
```

### 3.4 葡萄糖的環化（Cyclization of Glucose）

單糖在水溶液中通常以**環狀結構（ring structure / cyclic form）** 存在——羥基（hydroxyl group，–OH）與醛基（aldehyde group，–CHO）或酮基（ketone group，C=O）之間形成分子內半縮醛（hemiacetal）或半縮酮（hemiketal）：

**葡萄糖（glucose）的環化：**

```
開鏈式（open-chain form）                    環狀式（cyclic form）
                                              
     CHO                               OH
      |                                 |
   H–C–OH              →          H   C     H
      |                            |   |    |
  HO–C–H                        O–C   C–OH  C–H
      |                            |   |    |
   H–C–OH                        H   C     |
      |                                |    |
   H–C–OH                           HO  CH₂OH
      |
   CH₂OH
```

- 環化形成 **6 員吡喃糖環（pyranose ring）**（含一個氧）
- 形成新的手性中心（chiral center），產生 **α-葡萄糖（α-glucose）** 和 **β-葡萄糖（β-glucose）**：
  - **α-型**：新形成的 –OH（半縮醛羥基 anomeric hydroxyl）位於環**下方（below the ring）**
  - **β-型**：新形成的 –OH 位於環**上方（above the ring）**

### 3.5 雙糖（Disaccharides）與多糖（Polysaccharides）

單糖透過**糖苷鍵（glycoside linkage）** 縮合（condensation），釋出 H₂O，形成更複雜的碳水化合物：

**蔗糖（sucrose，table sugar）= 葡萄糖（glucose）+ 果糖（fructose）**

```
α-D-葡萄糖  +  D-果糖  →(脫水 dehydration)  蔗糖（sucrose）+ H₂O
```

蔗糖是**二糖（disaccharide）**。消化時，唾液（saliva）中的酶（enzyme）催化水解（hydrolysis），釋出葡萄糖和果糖。

**三種重要的多糖（polysaccharides）比較：**

| 多糖 | 英文 | 單體 | 糖苷鍵類型 | 結構特點 | 功能 |
|------|------|------|-----------|---------|------|
| 澱粉 | starch | α-D-葡萄糖（α-D-glucose） | α-糖苷鍵（α-glycoside linkage） | 直鏈澱粉（amylose）+ 支鏈澱粉（amylopectin，高度分支） | 植物的能量儲存（energy storage in plants） |
| 纖維素 | cellulose | β-D-葡萄糖（β-D-glucose） | β-糖苷鍵（β-glycoside linkage） | 直鏈、無分支（unbranched） | 植物的結構材料（structural material in plants） |
| 肝糖 | glycogen | α-D-葡萄糖（α-D-glucose） | α-糖苷鍵（α-glycoside linkage） | 比澱粉分支更多（highly branched） | 動物的能量儲存（energy storage in animals） |

**為何人類能消化澱粉，卻無法消化纖維素？**

- 人體消化道含有 **α-糖苷酶（α-glycosidases）**，可水解 α-糖苷鍵（α-glycoside linkages）→ 可消化澱粉（starch）
- 人體**缺乏 β-糖苷酶（β-glycosidases）**，無法水解 β-糖苷鍵（β-glycoside linkages）→ 無法消化纖維素（cellulose）
- 白蟻（termites）、牛（cows）等動物的消化道中有特定細菌（bacteria）含有 β-糖苷酶（β-glycosidases），因此可以消化纖維素

> **關鍵**：α- 與 β- 葡萄糖僅一個 –OH 的空間方向不同，但導致聚合物（polymers）結構和人體消化能力完全不同——這是立體化學（stereochemistry）影響生物功能的典型例子。

## 四、核酸（Nucleic Acids）

### 4.1 DNA 與 RNA 的功能

| 種類 | 英文全名 | 位置 | 功能 | 分子量 |
|------|---------|------|------|--------|
| DNA | deoxyribonucleic acid（去氧核糖核酸） | 細胞核（nucleus） | 儲存遺傳信息（genetic information）；指導蛋白質合成（protein synthesis） | 可達數十億 g/mol |
| RNA | ribonucleic acid（核糖核酸） | 細胞質（cytoplasm） | 傳遞遺傳信息，執行蛋白質合成 | 20,000–40,000 g/mol |

### 4.2 核苷酸（Nucleotides）——核酸的單體（Monomers）

每個**核苷酸（nucleotide）** 由三部分組成：

```
核苷酸（nucleotide）= 五碳糖（pentose sugar）+ 含氮鹼基（nitrogenous base）+ 磷酸（phosphoric acid，H₃PO₄）
```

**五碳糖（pentose sugars）的比較：**

| 特性 | 去氧核糖（deoxyribose） | 核糖（ribose） |
|------|----------------------|--------------|
| 存在於 | DNA | RNA |
| 差異 | C2 位置為 –H | C2 位置為 –OH |

**含氮鹼基（nitrogenous bases）：**

| 鹼基（Base） | 縮寫 | 存在於 | 類型 |
|-------------|------|--------|------|
| 腺嘌呤（adenine） | A | DNA 和 RNA | 嘌呤（purine） |
| 鳥嘌呤（guanine） | G | DNA 和 RNA | 嘌呤（purine） |
| 胞嘧啶（cytosine） | C | DNA 和 RNA | 嘧啶（pyrimidine） |
| 胸腺嘧啶（thymine） | T | **僅 DNA** | 嘧啶（pyrimidine） |
| 尿嘧啶（uracil） | U | **僅 RNA** | 嘧啶（pyrimidine） |

核苷酸的連接：糖的 –OH 與磷酸（phosphoric acid）形成**磷酸酯鍵（phosphate ester bond）**，再連到下一個核苷酸的糖，形成**糖-磷酸骨架（sugar-phosphate backbone）**。

### 4.3 DNA 的雙螺旋結構（Double Helix Structure）

DNA 的結構特徵（由 Watson 和 Crick 於 1953 年提出）：

1. **兩條核苷酸鏈（nucleotide strands）** 以相反方向（antiparallel）纏繞形成**雙螺旋（double helix）**
2. 外側為**糖-磷酸骨架（sugar-phosphate backbone）**
3. 兩條鏈的含氮鹼基（nitrogenous bases）朝內，透過**氫鍵（hydrogen bonds）** 互補配對（complementary base pairing）

**互補鹼基配對（Complementary Base Pairing）：**

```
腺嘌呤（A）── 胸腺嘧啶（T）（2 個氫鍵 hydrogen bonds）
鳥嘌呤（G）≡ 胞嘧啶（C） （3 個氫鍵 hydrogen bonds）

（A 永遠與 T 配對；G 永遠與 C 配對）
```

```
雙螺旋示意圖：

5'──A──T──G──C──A──T──3'
    |  |  |  |  |  |
3'──T──A──C──G──T──A──5'
    （氫鍵 hydrogen bonds）
```

### 4.4 DNA 複製（DNA Replication）

細胞分裂（cell division）時，DNA 的遺傳信息（genetic information）必須精確複製（replicated）：

```
步驟一：雙螺旋（double helix）解旋（unwind）
        兩條互補鏈（complementary strands）分開

步驟二：以每條原有鏈（original strand）為**模板（template）**
        按互補配對規則（A-T, G-C）合成新的互補鏈（complementary strand）

步驟三：結果為兩個 DNA 雙螺旋（double helices）
        每個各含一條原有鏈和一條新合成鏈
        （半保留複製 semi-conservative replication）
```

### 4.5 蛋白質合成（Protein Synthesis）

DNA 攜帶的遺傳密碼（genetic code）通過以下步驟指導蛋白質（proteins）的合成：

**關鍵術語：**

| 術語 | 英文 | 說明 |
|------|------|------|
| 基因 | gene | DNA 上一段特定序列，攜帶一種蛋白質的密碼 |
| 密碼子 | codon | mRNA 上連續三個鹼基（bases）的組合，對應一種胺基酸（amino acid） |
| 反密碼子 | anticodon | tRNA 上與密碼子互補的三個鹼基序列 |
| 信使 RNA | messenger RNA（mRNA） | 將 DNA 上的遺傳信息傳遞到核糖體（ribosome） |
| 轉運 RNA | transfer RNA（tRNA） | 攜帶特定胺基酸（amino acid）到核糖體，每種 tRNA 對應一種胺基酸 |
| 核糖體 | ribosome | 蛋白質合成的場所（site of protein synthesis） |

**蛋白質合成的流程（Central Dogma，中心法則）：**

```
DNA（基因 gene）
    ↓ 轉錄（transcription）
mRNA（信使 RNA）
    ↓ 翻譯（translation，在核糖體 ribosome 上進行）
蛋白質（protein）
```

**詳細步驟：**

```
步驟一：轉錄（transcription）
  → 以 DNA 基因（gene）為模板，在細胞核（nucleus）中合成 mRNA
  → mRNA 鹼基序列與 DNA 互補：A-U，T-A，G-C，C-G
     （注意：RNA 中無 T，改用 U）

步驟二：mRNA 遷移至細胞質（cytoplasm）

步驟三：翻譯（translation）
  → 核糖體（ribosome）沿 mRNA 移動
  → tRNA 攜帶特定胺基酸（amino acid），其反密碼子（anticodon）
    與 mRNA 的密碼子（codon）互補結合
  → 胺基酸透過胜肽鍵（peptide bonds）依序連接
  → 核糖體移至下一個密碼子（codon），重複此過程
  → 多肽鏈（polypeptide chain）逐漸延長，直到遇到**終止密碼子（stop codon）**
```

**密碼子（codon）的組合數：**

```
4 種鹼基（A、U、G、C）每次取 3 個 → 4³ = 64 種不同密碼子（codons）
其中 61 個對應 20 種胺基酸（amino acids）（多個密碼子可對應同一胺基酸）
3 個為終止密碼子（stop codons）
```

### 例題 1（課本 Example 21.7）：三肽序列（Tripeptide Sequences）

**題目**：寫出由酪胺酸（tyrosine, tyr）、組胺酸（histidine, his）和半胱胺酸（cysteine, cys）三種胺基酸組成的所有可能三肽（tripeptides）的序列。


## 六、進階例題（選自課後習題）

### 進階例題 A（Exercise 95，難度：中）

**題目**：畫出由絲胺酸（serine, Ser）和丙胺酸（alanine, Ala）組成的兩種二肽（dipeptides）的結構。

**解析：**

絲胺酸（serine）：R 基 = –CH₂OH（含羥基 hydroxyl group）

丙胺酸（alanine）：R 基 = –CH₃

二肽（dipeptide）的可能順序：ser-ala 和 ala-ser（N 端在左）

**ser-ala 的結構：**

```
H₂N–CH(CH₂OH)–CO–NH–CH(CH₃)–COOH
        絲胺酸殘基          丙胺酸殘基
     （serine residue）   （alanine residue）
        ↑胜肽鍵（peptide bond）
```

**ala-ser 的結構：**

```
H₂N–CH(CH₃)–CO–NH–CH(CH₂OH)–COOH
      丙胺酸殘基          絲胺酸殘基
   （alanine residue）  （serine residue）
```

> **關鍵**：兩者分子式相同，但 N 端（N-terminus）和 C 端（C-terminus）的胺基酸不同，因此是兩種不同的化合物（化學性質不同）。

### 進階例題 B（Exercise 99，難度：高）

**題目**：以下側鏈（side chains）之間可發生哪些作用力，有助於維持蛋白質的三級結構（tertiary structure）？

**(a) 半胱胺酸（cysteine）和半胱胺酸（cysteine）**

**解析：**

兩個 cys 的 R 基均含 **–SH（硫氫基 thiol group）**。在氧化條件（oxidizing conditions）下形成**雙硫鍵（disulfide bond，–S–S–）**（共價鍵 covalent bond）：

```
–CH₂–SH + HS–CH₂–  →(氧化)  –CH₂–S–S–CH₂– + 2H⁺ + 2e⁻
```

→ **雙硫鍵（disulfide bond）**，是三級結構（tertiary structure）最強的非骨架共價作用力

**(b) 麩醯胺酸（glutamine, Gln）和絲胺酸（serine, Ser）**

**解析：**

- 麩醯胺酸（glutamine）R 基含 **–CONH₂（醯胺基 amide group）**
- 絲胺酸（serine）R 基含 **–OH（羥基 hydroxyl group）**

兩者均為極性側鏈（polar side chains），可形成**氫鍵（hydrogen bonds）**：

```
–CONH₂ ⋯ HO–（氫鍵 hydrogen bond）
```

**(c) 麩胺酸（glutamic acid, Glu）和離胺酸（lysine, Lys）**

**解析：**

- 麩胺酸（glutamic acid）R 基含 **–COOH（羧基 carboxyl group）**，在生理 pH 下去質子化為 **–COO⁻（帶負電）**
- 離胺酸（lysine）R 基含 **–NH₂（胺基 amino group）**，在生理 pH 下質子化為 **–NH₃⁺（帶正電）**

兩者之間形成**離子鍵（ionic bond）** / 鹽橋（salt bridge）：

```
–COO⁻ ⋯ ⁺NH₃– （靜電吸引 electrostatic attraction）
```

**(d) 脯胺酸（proline, Pro）和白胺酸（leucine, Leu）**

**解析：**

- 脯胺酸（proline）和白胺酸（leucine）的 R 基均為**非極性烴基（nonpolar hydrocarbon groups）**
- 非極性基團（nonpolar groups）之間的作用力為**色散力（London dispersion forces）**，又稱**疏水性作用（hydrophobic interactions）**：非極性側鏈（nonpolar side chains）在水中相互聚集，排除水分子

### 進階例題 C（Exercise 119 + 123，難度：高）

**題目（119）**：部分 DNA 序列為 **G-G-T-C-T-A-T-A-C**，試寫出其互補序列（complementary sequence）。

**解析：**

利用互補配對規則（complementary base pairing）：A-T（雙向互補）、G-C（雙向互補）：

```
原始 DNA 序列：   5'– G – G – T – C – T – A – T – A – C –3'
互補 DNA 序列：   3'– C – C – A – G – A – T – A – T – G –5'

（從 5' 至 3' 方向書寫互補鏈）：C-C-A-G-A-T-A-T-G
```

**題目（123b）**：給出能編碼三肽（tripeptide）trp-glu-phe-met 的一條 DNA 序列。

已知 mRNA 密碼子（codons）：
```
Trp（色胺酸）：UGG
Glu（麩胺酸）：GAA 或 GAG
Phe（苯丙胺酸）：UUU 或 UUC
Met（甲硫胺酸）：AUG
```

**解析：**

步驟一：選定 mRNA 序列（codon sequence）

```
mRNA：5'–UGG–GAA–UUU–AUG–3'
       Trp  Glu  Phe  Met
```

步驟二：mRNA 與 DNA 模板鏈（template strand）互補（A-U → A-T，G-C，U-A → T-A）：

```
DNA 模板鏈：3'–ACC–CTT–AAA–TAC–5'
```

步驟三：寫出對應的 DNA 非模板鏈（coding strand）（與 mRNA 序列相同，但 U 改回 T）：

```
DNA 編碼鏈：5'–TGG–GAA–TTT–ATG–3'
```

**答：DNA 編碼序列為 TGG-GAA-TTT-ATG**（其中 Glu 和 Phe 各有兩種選擇，共 2×2=4 種可能的 DNA 序列）

## 七、本節重點整理

### 蛋白質（Proteins）

| 概念 | 要點 |
|------|------|
| 單體（monomers） | 20 種 α-胺基酸（α-amino acids） |
| 連接鍵（linkage） | 胜肽鍵（peptide bond / amide bond，–CO–NH–） |
| 一級結構（primary structure） | 胺基酸序列（amino acid sequence） |
| 二級結構（secondary structure） | α-螺旋（α-helix）、褶板片（pleated sheet），由氫鍵（hydrogen bonds）維持 |
| 三級結構（tertiary structure） | 整體三維形狀，由氫鍵、離子鍵、雙硫鍵、色散力等維持 |
| 變性（denaturation） | 三維結構被破壞，功能喪失 |

### 碳水化合物（Carbohydrates）

| 概念 | 要點 |
|------|------|
| 單體（monomers） | 單糖（monosaccharides）：葡萄糖（glucose）等 |
| 連接鍵（linkage） | 糖苷鍵（glycoside linkage），縮合釋出 H₂O |
| 澱粉（starch） | α-糖苷鍵（α-glycoside linkage），可被人體消化 |
| 纖維素（cellulose） | β-糖苷鍵（β-glycoside linkage），人體無法消化 |
| 肝糖（glycogen） | α-糖苷鍵（α-glycoside linkage），動物能量儲存，高度分支（highly branched） |

### 核酸（Nucleic Acids）

| 概念 | 要點 |
|------|------|
| 單體（monomers） | 核苷酸（nucleotides）= 糖 + 鹼基（base）+ 磷酸（phosphoric acid） |
| DNA 鹼基配對 | A-T（2 個氫鍵）；G-C（3 個氫鍵） |
| RNA 鹼基配對 | A-U；G-C（RNA 中無 T，用 U） |
| DNA 複製（replication） | 以原鏈為模板，半保留複製（semi-conservative） |
| 中心法則（central dogma） | DNA → 轉錄（transcription）→ mRNA → 翻譯（translation）→ 蛋白質（protein） |
| 密碼子（codon） | mRNA 上連續三個鹼基，共 64 種（4³），編碼 20 種胺基酸 |
