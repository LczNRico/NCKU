## 21.1　烷烴：飽和烴（Alkanes: Saturated Hydrocarbons）

---

## 一、有機化學基本概念

### 1.1 什麼是有機化學？

**有機化學（organic chemistry）** 是研究含碳化合物及其性質的學科。碳具有兩個獨特的鍵結特性：

1. 碳可以與碳形成強鍵，構成長鏈（chain）或環狀骨架（ring）
2. 碳可以與多種非金屬（H、N、O、S、鹵素 halogens）形成強鍵

> **歷史補充：「生命力說」的破除**
> 19 世紀初，化學家認為有機化合物只能由生物體合成。1828 年，德國化學家 Friedrich Wöhler 將無機鹽氰酸銨（NH₄OCN）加熱，成功製出尿素（urea）——一種有機物，徹底推翻了「生命力說」。

### 1.2 烴（Hydrocarbons）的定義與分類

**烴**是只含碳和氫的化合物。依照鍵結類型分為：

| 類別 | 鍵結特徵 | 說明 |
|------|----------|------|
| **飽和烴（saturated）** | 僅含 C–C 單鍵 | 每個碳達到最多 4 個鍵結 |
| **不飽和烴（unsaturated）** | 含 C=C 或 C≡C | 可進一步加成其他原子 |

## 二、烷烴（Alkanes）的結構與通式

### 2.1 基本結構

- 烷烴為飽和烴，每個碳採取 **sp³ 混成（sp³ hybridization）**，呈**正四面體幾何（tetrahedral geometry）**
- C–C–C 鍵角 = **109.5°**
- 「直鏈」烷烴其實呈**鋸齒狀**（zigzag），並非真正的直線

### 2.2 通式

正烷烴（直鏈烷烴）的分子式符合：

```
CₙH₂ₙ₊₂
```

例如：辛烷（n = 8）→ C₈H₁₈；壬烷（n = 9）→ C₉H₂₀

### 2.3 前十個正烷烴

| 名稱（中） | 名稱（英） | 分子式 | 沸點（°C） | 結構異構物數目 |
|------------|------------|--------|------------|----------------|
| 甲烷 | Methane | CH₄ | −162 | 1 |
| 乙烷 | Ethane | C₂H₆ | −89 | 1 |
| 丙烷 | Propane | C₃H₈ | −42 | 1 |
| 丁烷 | Butane | C₄H₁₀ | 0 | 2 |
| 戊烷 | Pentane | C₅H₁₂ | 36 | 3 |
| 己烷 | Hexane | C₆H₁₄ | 68 | 5 |
| 庚烷 | Heptane | C₇H₁₆ | 98 | 9 |
| 辛烷 | Octane | C₈H₁₈ | 126 | 18 |
| 壬烷 | Nonane | C₉H₂₀ | 151 | 35 |
| 癸烷 | Decane | C₁₀H₂₂ | 174 | 75 |

> **規律**：分子量越大，沸點越高（分子間色散力 London dispersion forces 越強）。

## 三、結構異構物（Structural Isomers）

### 3.1 定義

**結構異構物**：分子式相同、但原子連接方式（鍵結）不同的分子。從丁烷（C₄H₁₀）開始出現。

### 3.2 丁烷的兩種異構物

```
正丁烷（n-butane）：     CH₃–CH₂–CH₂–CH₃       沸點 = −0.5°C
異丁烷（isobutane）：    CH₃–CH(CH₃)–CH₃        沸點 = −12°C
```

> **規律**：支鏈越多，分子形狀越接近球形，分子間接觸面積越小，色散力（London dispersion forces）越弱，沸點越低。

### 3.3 戊烷的三種異構物

```
正戊烷（n-pentane）：    CH₃CH₂CH₂CH₂CH₃
異戊烷（isopentane）：   CH₃CH(CH₃)CH₂CH₃
新戊烷（neopentane）：   C(CH₃)₄
```

## 四、烷烴的 IUPAC 命名規則

### 規則 1：確定主鏈（root name）

找出分子中**最長的連續碳鏈**，以其碳數決定根名：

| 碳數 | 前綴 | 根名 |
|------|------|------|
| 1 | meth- | methane |
| 2 | eth- | ethane |
| 3 | prop- | propane |
| 4 | but- | butane |
| 5 | pent- | pentane |
| 6 | hex- | hexane |
| 7 | hept- | heptane |
| 8 | oct- | octane |
| 9 | non- | nonane |
| 10 | dec- | decane |

### 規則 2：取代基命名（烷基）

烷基（alkyl group）是從烷烴去掉一個 H 後的片段，字尾改為 **-yl**：

| 結構 | 名稱 |
|------|------|
| –CH₃ | methyl（甲基） |
| –CH₂CH₃ | ethyl（乙基） |
| –CH₂CH₂CH₃ | propyl（丙基） |
| –CH(CH₃)₂ | isopropyl（異丙基） |
| –C(CH₃)₃ | tert-butyl（叔丁基） |

### 規則 3：取代基位置編號

從**最靠近分支**的一端開始對主鏈編號，使取代基獲得**最小號碼**。

### 規則 4：寫出完整名稱

格式為：**位置號–取代基名稱 + 主鏈名稱**

若有多個相同取代基，用前綴 di-（2個）、tri-（3個）、tetra-（4個）。取代基名稱按**字母順序**排列（不計 di-、tri- 等前綴）。

## 六、環烷烴（Cyclic Alkanes）

### 6.1 基本概念

環烷烴通式：**CₙH₂ₙ**（比正烷烴少 2 個 H，因為形成環需一對 C–C 鍵取代兩個 C–H 鍵）

### 6.2 各環烷烴的穩定性比較

| 環名稱 | 碳數 | 鍵角 | 穩定性 | 原因 |
|--------|------|------|--------|------|
| 環丙烷 cyclopropane | 3 | 60° | 最不穩定（活性高） | 與 sp³ 理想 109.5° 相差最大，軌域無法正面重疊，形成「彎曲鍵（bent bonds / banana bonds）」，鍵角張力（angle strain）極大 |
| 環丁烷 cyclobutane | 4 | 90° | 不穩定 | 鍵角張力（angle strain）仍大 |
| 環戊烷 cyclopentane | 5 | 接近 108° | 穩定 | 與 109.5° 接近，鍵角張力小 |
| 環己烷 cyclohexane | 6 | 接近 109.5° | 非常穩定 | 採「椅式（chair form）」構型，達到正常鍵角，幾乎無張力 |

### 6.3 環己烷的構型

環己烷可以有兩種空間排列：

- **椅式（chair form）**：所有鍵角接近 109.5°，最穩定；室溫下 >99% 存在此形式
- **船式（boat form）**：兩個 H 原子相互排斥，能量較高，不穩定

### 6.4 環烷烴命名

- 在根名前加 **cyclo-**
- 環上的碳編號使取代基號碼盡量小
- 取代基按字母順序排列

**範例：**

```
1-ethyl-2-propylcyclobutane
（環丁烷的 1 號碳接乙基，2 號碳接丙基）
```

## 七、烷烴的化學反應

### 7.1 為何烷烴相對不活潑？

- C–C 鍵（347 kJ/mol）和 C–H 鍵（413 kJ/mol）都很強
- 分子非極性，不受親核試劑（nucleophile）或親電試劑（electrophile）攻擊
- 25°C 下不與酸、鹼或強氧化劑反應

### 7.2 燃燒反應（Combustion）

烷烴在足夠高溫下與 O₂ 劇烈反應，放出大量熱：

```
2C₄H₁₀(g) + 13O₂(g) → 8CO₂(g) + 10H₂O(g)
```

這是烷烴作為燃料（天然氣、汽油、石蠟）的基礎。

### 7.3 鹵素取代反應（Halogenation / Substitution）

在**紫外光（hv）** 照射下，鹵素可逐步取代烷烴上的 H：

```
CH₄  + Cl₂ →(hv)  CH₃Cl + HCl     （氯甲烷）
CH₃Cl + Cl₂ →(hv)  CH₂Cl₂ + HCl   （二氯甲烷）
CH₂Cl₂ + Cl₂ →(hv)  CHCl₃ + HCl   （三氯甲烷，俗名氯仿）
CHCl₃ + Cl₂ →(hv)  CCl₄ + HCl     （四氯化碳）
```

**機制**：紫外光使 Cl–Cl 鍵均裂（homolytic cleavage），產生 Cl 自由基（free radical，帶有不成對電子的活性物種），再攻擊 C–H 鍵。

> **補充：CFCs（氯氟碳化物 chlorofluorocarbons）**
> 含有 F 和 Cl 的甲烷衍生物（如 CF₂Cl₂，商品名 Freon）因化學惰性而被廣泛用作冷媒（coolant），但其化學穩定性使其漂至平流層（stratosphere）並破壞臭氧層（ozone layer），目前已被全球逐步禁用。

### 7.4 脫氫反應（Dehydrogenation）

在 Cr₂O₃ 催化劑及高溫下，烷烴可移除 H₂ 而生成不飽和烴：

```
CH₃CH₃  →(Cr₂O₃, 500°C)  CH₂=CH₂ + H₂
（乙烷）                    （乙烯）
```

## 八、進階例題（選自課後習題）

### 進階例題 A（改編自 Exercise 9b）

**題目**：2,2,4-trimethylpentane（又名 isooctane，辛烷值標準 100 的物質）請畫出其結構式，並說明為何「2,2,4-三甲基戊烷」是正確命名。

**解析：**

步驟一：主鏈為戊烷（5碳），三個甲基分別在 2、2、4 號碳。

```
   CH₃ CH₃     CH₃
    |   |        |
CH₃–C–CH₂–CH–CH₃
    |
   （此即 2 號碳，接了兩個甲基）
1   2    3   4   5
```

步驟二：驗證命名是否正確。

- 最長鏈：試著找更長的鏈

若從「CH₃（最左）→ C → CH₂ → CH → CH₃（最右）」= 5 碳，加上第 2 號碳另一個 CH₃，若嘗試以第 2 號碳的 CH₃ 當主鏈末端，可以找到一條 6 碳鏈嗎？

```
沿路徑：CH₃ → C(2) → CH₂ → CH → CH₃ = 5 碳主鏈 ✓（無法延伸至 6 碳）
```

- 編號方向：從左端開始，取代基位置為 2, 2, 4；若從右端，則為 2, 4, 4 → 2+2+4=8 < 2+4+4=10，故從左端編號正確。

**答**：結構正確，命名正確。這個分子是汽油辛烷值的 100 標準品，代表抗爆性極佳。

### 進階例題 B（Exercise 11a）

**題目**：命名下列化合物：
```
     CH₃
      |
CH₃–C–CH₂–CH–CH₂–CH₃
      |         |
      CH₃      CH₃
```

**解析步驟：**

步驟一：找最長鏈

從最左邊的 CH₃ → C → CH₂ → CH → CH₂ → CH₃（最右）= **6 碳** → 主鏈為己烷（hexane）

步驟二：標號

```
CH₃–C–CH₂–CH–CH₂–CH₃
  |         |
  CH₃      CH₃
1   2    3   4   5   6
```

步驟三：確認從哪端編號

- 從左：取代基在 2, 2, 4 → 總和 = 8
- 從右：取代基在 3, 5, 5 → 總和 = 13

從左端編號，總和較小，正確。

步驟四：列出取代基

- 2 號碳：兩個甲基（dimethyl）
- 4 號碳：一個甲基

**答：2,2,4-trimethylhexane**

### 進階例題 C（Exercise 32，難度較高）

**題目**：若將 2-methylbutane（C₅H₁₂）中的一個 H 以 Cl 取代，可得幾種不同的一氯取代物？

**解析：**

首先畫出 2-methylbutane 的結構，找出所有**不同型別的 H**：

```
   CH₃
    |
CH₃–CH–CH₂–CH₃
 a   b   c    d

a：三個 CH₃ 上的 H（型別 a）→ 注意：碳1 的三個 H 等價，碳3' 的三個 H 也等價
b：中央 CH 上的 H（型別 b）→ 1 個 H
c：CH₂ 上的 H（型別 c）→ 2 個 H
d：末端 CH₃ 上的 H（型別 d）→ 3 個 H
```

更仔細分析：

```
        CH₃(1)
         |
CH₃(2)–CH–CH₂(3)–CH₃(4)
```

- H 在 C1（甲基）：–CH₂Cl 出現在第 2 號碳的甲基分支上
- H 在 C2（CH）：–CHCl 在主鏈中央
- H 在 C3（CH₂）：–CH₂Cl 在 C3 位置
- H 在 C4（末端 CH₃）：–CH₂Cl 在末端

但注意：C1（分支 CH₃）和 C4（末端 CH₃）的 H **並不等價**（所處化學環境不同）。

因此共有 **4 種** 不同的一氯取代物：

```
1.  CH₂Cl–CH(CH₃)–CH₂CH₃   → 取代 C1（分支甲基上）→ 1-chloro-2-methylbutane
2.  CH₃–CCl(CH₃)–CH₂CH₃    → 取代 C2（中央 CH）  → 2-chloro-2-methylbutane
3.  CH₃–CH(CH₃)–CHClCH₃    → 取代 C3（CH₂）     → 1-chloro-2-methylbutane 的另一版…

（重新以 IUPAC 命名確認是否為新異構物）
```

仔細列出並確認每種產物都不相同：

| 取代位置 | 產物結構 | IUPAC 名稱 | 是否與其他重複？ |
|----------|----------|------------|-----------------|
| C1 的 CH₃（分支） | ClCH₂–CH(CH₃)–CH₂CH₃ | 1-chloro-2-methylbutane | 否 |
| C2（主鏈CH） | CH₃–CCl(CH₃)–CH₂CH₃ | 2-chloro-2-methylbutane | 否 |
| C3（主鏈CH₂） | CH₃–CH(CH₃)–CHCl–CH₃ | 3-chloro-2-methylbutane | 否 |
| C4（末端 CH₃） | CH₃–CH(CH₃)–CH₂–CH₂Cl | 1-chloro-3-methylbutane | 否 |

**答：共有 4 種不同的一氯取代物。**

> 這題的關鍵是系統性地找出所有化學環境不同的 H，不能遺漏，也不能重複計算。

## 九、本節重點整理

| 概念 | 要點 |
|------|------|
| 烷烴通式 | CₙH₂ₙ₊₂；環烷烴為 CₙH₂ₙ |
| 混成方式（hybridization） | sp³；鍵角 109.5° |
| 結構異構物（structural isomers） | 分子式相同但連接方式不同，從 C₄ 開始出現 |

| 沸點趨勢 | 分子量↑ → 沸點↑；支鏈↑ → 沸點↓（色散力 London dispersion forces 減弱） |
