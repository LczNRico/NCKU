# 第十九章　過渡金屬與配位化學
## 19.2　第一列過渡金屬（The First-Row Transition Metals）

---

## 一、概述

本節逐一介紹第一列過渡金屬（first-row transition metals）Sc 到 Zn 各元素的主要化學性質、常見氧化態（common oxidation states）、典型化合物（typical compounds）以及重要工業應用。

---

## 二、各元素詳述

### 2.1 鈧（Scandium, Sc）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 21 |
| 電子組態（electron configuration） | [Ar] 4s² 3d¹ |
| 主要氧化態（oxidation state） | +3 |
| 典型化合物 | ScCl₃、Sc₂O₃、Sc₂(SO₄)₃ |

**化學性質：**

- Sc³⁺ 沒有 d 電子（d⁰ 組態），因此其化合物**無色（colorless）且反磁性（diamagnetic）**
- 化學性質與**鑭系元素（lanthanides）** 高度相似
- 鈧金屬稀少且罕見，可由熔融 ScCl₃ 電解（electrolysis of molten ScCl₃）製得
- 主要用途：部分高強度燈具（high-intensity lamps）等電子裝置

> **概念連結**：過渡金屬化合物的顏色（color）和磁性（magnetism）通常來自金屬離子的 d 電子；Sc³⁺ 無 d 電子，故無此性質。此規律在 19.6 節晶場模型（crystal field model）中會詳細解釋。

### 2.2 鈦（Titanium, Ti）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 22 |
| 電子組態（electron configuration） | [Ar] 4s² 3d² |
| 主要氧化態（oxidation state） | +4（最常見）；+3（較少見）；+2（固態中存在） |
| 地殼含量 | 0.6%（質量百分率） |

**重要化合物：**

| 化合物 | 氧化態 | 性質與用途 |
|--------|--------|-----------|
| TiO₂（氧化鈦(IV) titanium(IV) oxide） | +4 | 白色不透明顏料（white pigment）；廣泛用於紙張、油漆、塑膠、防曬乳等 |
| TiCl₄（四氯化鈦 titanium(IV) chloride） | +4 | 無色液體（沸點 137°C）；在潮濕空氣中與水反應生成 TiO₂ 白霧 |
| Ti(H₂O)₆³⁺ | +3 | 紫色（purple）水合離子 |

**TiO₂ 的工業製程：**

**(a) 金紅石礦（rutile，不純 TiO₂）的氯化法：**

```
TiCl₄(g) + O₂(g) → TiO₂(s) + 2Cl₂(g)
```

先用氯氣將 TiO₂ 轉為揮發性的 TiCl₄，分離雜質後再燃燒得到純 TiO₂。

**(b) 鈦鐵礦（ilmenite，FeTiO₃）的硫酸法：**

```
FeTiO₃(s) + 2H₂SO₄(aq) → Fe²⁺(aq) + TiO²⁺(aq) + 2SO₄²⁻(aq) + 2H₂O(l)
```

在真空下靜置使 FeSO₄·7H₂O 結晶析出後移除，再加熱使 TiO₂·H₂O 沉澱，最後加熱脫水：

```
TiO₂·H₂O(s) →(加熱 heat) TiO₂(s) + H₂O(g)
```

**TiCl₄ 的水解：**

```
TiCl₄(l) + 2H₂O(l) → TiO₂(s) + 4HCl(g)
```

在潮濕空氣中，TiCl₄（無色液體）立即水解生成白色 TiO₂ 固體。

**金屬鈦的應用：**

- 密度低、強度高，是製造**噴射發動機（jet engines）** 的理想材料
- 每台波音 747 的引擎含有約 **5000 kg** 鈦合金
- 對化學侵蝕的高抵抗力，用於化學工業的管道（pipes）和反應器（reaction vessels）

### 2.3 釩（Vanadium, V）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 23 |
| 電子組態（electron configuration） | [Ar] 4s² 3d³ |
| 主要氧化態（oxidation state） | +5（最常見）；+4、+3、+2（在水溶液中均可存在） |
| 地殼含量 | 0.02%（質量百分率） |

**水溶液中的氧化態與顏色（重要！）：**

| 氧化態 | 水溶液中的物種 | 顏色（color） |
|--------|--------------|-------------|
| +5 | VO₂⁺（釩醯陽離子 vanadyl cation） | 黃色（yellow） |
| +4 | VO²⁺（釩醯離子 vanadyl ion） | 藍色（blue） |
| +3 | V³⁺(aq) | 藍綠色（blue-green） |
| +2 | V²⁺(aq) | 紫色（violet） |

> **說明**：高氧化態（+5、+4）不以水合陽離子（hydrated cation Vⁿ⁺(aq)）形式存在，因為高電荷導致配位水分子極酸，H⁺ 脫離後形成含氧陽離子（oxycation）VO₂⁺ 和 VO²⁺。

**重要化合物與應用：**

- V₂O₅（五氧化二釩 vanadium(V) oxide）：橙色固體（mp = 650°C），是製造硫酸（sulfuric acid）工業中重要的催化劑（catalyst）
- 80% 的釩用於鋼鐵（steel）合金，尤以製造硬鋼（hard steel）用於引擎零件和車軸
- 鐵釩合金（ferrovanadium）可由還原 V₂O₅ 和 Fe₂O₃ 的混合物製得

### 2.4 鉻（Chromium, Cr）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 24 |
| 電子組態（electron configuration） | [Ar] 4s¹ 3d⁵（例外！） |
| 主要氧化態（oxidation state） | +2、+3、+6 |
| 主要礦石 | 鉻鐵礦 chromite（FeCr₂O₄） |

**典型鉻化合物：**

| 氧化態 | 典型化合物 | 顏色（color） |
|--------|----------|-------------|
| +2 | CrX₂（X = 鹵素） | 多為藍色 |
| +3 | CrX₃、Cr₂O₃、Cr(OH)₃ | 綠色（green）、藍綠色（blue-green） |
| +6 | K₂Cr₂O₇ | 橙色（orange） |
| +6 | Na₂CrO₄ | 黃色（yellow） |
| +6 | CrO₃ | 紅色（red） |

**重要化學反應：**

**(a) Cr²⁺（亞鉻離子 chromous ion）的還原性：**

Cr²⁺ 是強還原劑（strong reducing agent），可去除氣體中微量的 O₂：

```
4Cr²⁺(aq) + O₂(g) + 4H⁺(aq) → 4Cr³⁺(aq) + 2H₂O(l)
```

**(b) 重鉻酸根（dichromate ion，Cr₂O₇²⁻）的氧化性（酸性條件）：**

Cr(VI) 在酸性溶液中以重鉻酸根（Cr₂O₇²⁻）形式存在，是強氧化劑（strong oxidizing agent）：

```
Cr₂O₇²⁻(aq) + 14H⁺(aq) + 6e⁻ → 2Cr³⁺(aq) + 7H₂O(l)     E° = +1.33 V
```

**(c) 鉻酸根（chromate ion，CrO₄²⁻）在鹼性條件：**

在鹼性溶液中，Cr(VI) 轉為鉻酸根（CrO₄²⁻），氧化能力大幅減弱：

```
CrO₄²⁻(aq) + 4H₂O(l) + 3e⁻ → Cr(OH)₃(s) + 5OH⁻(aq)     E° = −0.13 V
```

**Cr₂O₇²⁻ 與 CrO₄²⁻ 的互轉（pH 依賴性）：**

```
2CrO₃(s) + H₂O(l) → 2H⁺(aq) + Cr₂O₇²⁻(aq)    （酸性 → 橙色）
加鹼後 → CrO₄²⁻                                  （鹼性 → 黃色）
```

此互轉遵循**勒沙特列原理（Le Châtelier's principle）**：增加 H⁺ 濃度使平衡偏向 Cr₂O₇²⁻；增加 OH⁻ 則偏向 CrO₄²⁻。

**Cr₂O₇²⁻ 與 CrO₄²⁻ 的結構比較：**

- CrO₄²⁻：正四面體形（tetrahedral），Cr–O 鍵完全等價
- Cr₂O₇²⁻：兩個四面體共用一個橋接氧（bridging oxygen），Cr–O–Cr 鍵角約 115°

**工業應用：**

- 主要礦石 FeCr₂O₄ 可用碳還原得到鐵鉻合金（ferrochrome），直接加入鍊鋼過程
- 鉻金屬常用於鋼的電鍍（electroplating），表面形成緻密透明氧化膜（invisible oxide coating）防止進一步腐蝕

### 2.5 錳（Manganese, Mn）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 25 |
| 電子組態（electron configuration） | [Ar] 4s² 3d⁵ |
| 主要氧化態（oxidation state） | +2（最常見）、+4、+7 |
| 地殼含量 | 0.1%（質量百分率） |

**典型錳化合物：**

| 氧化態 | 典型化合物 | 顏色（color） |
|--------|----------|-------------|
| +2 | Mn(OH)₂、MnS、MnSO₄、MnCl₂ | 粉紅色（pink）；MnSO₄ 為紅色（reddish） |
| +4 | MnO₂ | 深棕色（dark brown） |
| +7 | KMnO₄ | 紫色（purple） |

**Mn(H₂O)₆²⁺** 在水溶液中呈**淡粉色（light pink）**。

**高錳酸根（permanganate ion，MnO₄⁻）的氧化性：**

在酸性溶液中，MnO₄⁻ 是強氧化劑，被還原為 Mn²⁺：

```
MnO₄⁻(aq) + 8H⁺(aq) + 5e⁻ → Mn²⁺(aq) + 4H₂O(l)     E° = +1.51 V
```

此反應顏色變化明顯（深紫色 → 近無色），廣泛用於**酸鹼滴定與氧化還原滴定（redox titration）** 的終點指示。

**工業應用：**

- 主要用於製造特別堅硬的鋼材（especially hard steel），用於碎石機（rock crushers）、銀行金庫（bank vaults）、裝甲板（armor plate）
- 有趣來源：海底的**錳結核（manganese nodules）**——球狀固體，含錳鐵氧化物及少量 Co、Ni、Cu，被認為是部分由海洋生物作用形成

**典型鐵化合物：**

| 氧化態 | 典型化合物 | 顏色（color） |
|--------|----------|-------------|

| +2 | K₄Fe(CN)₆ | 黃色（yellow） |
| +3 | FeCl₃ | 棕黑色（brownish black） |

| +3 | Fe(SCN)₃ | 紅色（red） |
| +2, +3 混合 | Fe₃O₄（磁鐵礦 magnetite） | 黑色（black） |
| +2, +3 混合 | KFe[Fe(CN)₆]（普魯士藍 Prussian blue） | 深藍色（deep blue） |

**水溶液中的水合離子顏色：**

- Fe(H₂O)₆²⁺：**淡綠色（light green）**

```
Fe(H₂O)₆³⁺(aq) ⇌ Fe(OH)(H₂O)₅²⁺(aq) + H⁺(aq)     Ka ≈ 6 × 10⁻³
```

**化學性質：**

- 白色有光澤（white, lustrous），活潑性高，在潮濕空氣中迅速被 O₂ 氧化形成鐵鏽（rust），鐵鏽為鐵氧化物的混合物
- 主要化學涉及 **+2 和 +3 氧化態**

### 2.9 銅（Copper, Cu）

**基本資料：**

| 項目 | 內容 |

| 礦石 | 含硫化物（sulfides）、砷化物（arsenides）、氯化物（chlorides）、碳酸鹽（carbonates）的礦石 |

**典型銅化合物：**

| 氧化態 | 典型化合物 | 顏色（color） |
|--------|----------|-------------|

**化學性質：**

- 在空氣中緩慢腐蝕，生成**銅綠（patina）**——鹼式硫酸銅（basic copper sulfate）等化合物，呈特徵綠色：

```
3Cu(s) + 2H₂O(l) + SO₂(g) + 2O₂(g) → Cu₃(OH)₄SO₄(s)
```

自由女神像（Statue of Liberty）的綠色正是此原因。

**重要合金（important alloys）：**

| 合金名稱 | 組成（質量百分率） |
|---------|-----------------|
| 黃銅（Brass） | Cu (20–97%)、Zn (2–80%)、微量 Sn、Pb、Mn |
| 青銅（Bronze） | Cu (50–98%)、Sn (0–35%)、Zn (0–29%)、微量 Pb、P |
| 純銀（Sterling silver） | Cu (7.5%)、Ag (92.5%) |
| 18K 黃金（Gold, 18-karat） | Cu (5–14%)、Au (75%)、Ag (10–20%) |
| 14K 黃金（Gold, 14-karat） | Cu (12–28%)、Au (58%)、Ag (4–30%) |

**工業重要性：**

- 全球銅年產量的 **50%** 用於電氣應用（electrical applications）
- 廣泛用於管路（plumbing）
- 雖微量銅對生命必需，但大量接觸毒性極強；銅鹽用於殺菌（kill bacteria）、殺真菌（fungi）和藻類（algae）

### 2.10 鋅（Zinc, Zn）

**基本資料：**

| 項目 | 內容 |
|------|------|
| 原子序 | 30 |
| 電子組態（electron configuration） | [Ar] 4s² 3d¹⁰ |
| 主要氧化態（oxidation state） | **+2（唯一的氧化態）** |
| 主要礦石 | 閃鋅礦（sphalerite，(ZnFe)S），常與方鉛礦（galena，PbS）共生 |

**化學性質：**

- 白色有光澤（white, lustrous）金屬，活潑性高（very active metal），迅速失去光澤（tarnishes rapidly）
- 良好的還原劑（excellent reducing agent）
- 形成**無色鹽類（colorless salts）**，含 Zn²⁺ 離子
- **鋅有 3d¹⁰ 滿殼層，無未成對 d 電子**，因此其化合物無色且反磁性（類似 Sc³⁺ 的 d⁰ 情況）
- 約 **90%** 的鋅產量用於**鍍鋅（galvanizing）** 鋼材，防止鐵腐蝕（corrosion）

> **特別注意**：雖然 Zn 屬於 d 區第一列的最後一個元素，但因 3d¹⁰ 完全填滿，化學行為較接近典型金屬（representative metals）。

## 三、第一列過渡金屬性質比較總表

## 四、進階例題（選自課後習題）

### 進階例題 A（Exercise 12b，難度：中）

**題目**：鈦白礦的氯化法反應為：

```
2TiO₂(s) + 3C(s) + 4Cl₂(g) →(950°C) 2TiCl₄(g) + CO₂(g) + 2CO(g)
TiCl₄(g) + O₂(g) →(1000–1400°C) TiO₂(s) + 2Cl₂(g)
```

請標示兩個反應中各元素的氧化態（oxidation states），並指出哪些元素被氧化（oxidized）、哪些被還原（reduced），以及各反應的氧化劑（oxidizing agent）和還原劑（reducing agent）。

**解析：**

**反應一：2TiO₂ + 3C + 4Cl₂ → 2TiCl₄ + CO₂ + 2CO**

標示氧化態：

| 物種 | 元素 | 反應前氧化態 | 反應後氧化態 | 變化 |
|------|------|------------|------------|------|
| TiO₂ | Ti | **+4** | +4（在 TiCl₄ 中） | 不變 |
| TiO₂ | O | −2 | −2（在 CO₂/CO 中） | 不變 |
| C | C | **0** | +4（在 CO₂）或 +2（在 CO） | **被氧化（oxidized）↑** |
| Cl₂ | Cl | **0** | −1（在 TiCl₄ 中） | **被還原（reduced）↓** |

- **被氧化的元素**：C（碳），0 → +4 或 +2
- **被還原的元素**：Cl（氯），0 → −1
- **還原劑（reducing agent）**：C（碳），因為它自身被氧化，使別人被還原
- **氧化劑（oxidizing agent）**：Cl₂（氯氣），因為它自身被還原，使別人被氧化

**反應二：TiCl₄ + O₂ → TiO₂ + 2Cl₂**

標示氧化態：

| 物種 | 元素 | 反應前氧化態 | 反應後氧化態 | 變化 |
|------|------|------------|------------|------|
| TiCl₄ | Ti | +4 | +4（在 TiO₂ 中） | 不變 |
| TiCl₄ | Cl | **−1** | 0（在 Cl₂ 中） | **被氧化（oxidized）↑** |
| O₂ | O | **0** | −2（在 TiO₂ 中） | **被還原（reduced）↓** |

- **被氧化的元素**：Cl（氯），−1 → 0
- **被還原的元素**：O（氧），0 → −2
- **還原劑（reducing agent）**：TiCl₄（其中的 Cl⁻）
- **氧化劑（oxidizing agent）**：O₂

### 進階例題 B（Exercise 14，難度：中）

**題目**：鐵在地殼中以赤鐵礦（hematite，Fe₂O₃）和磁鐵礦（magnetite，Fe₃O₄）兩種礦石形式存在。請問各礦石中鐵的氧化態（oxidation state）為何？磁鐵礦中 Fe²⁺ 和 Fe³⁺ 的比例為何？磁鐵礦的化學式通常寫作 FeO·Fe₂O₃，這合理嗎？

**解析：**

**赤鐵礦（Fe₂O₃）中鐵的氧化態：**

設 Fe 的氧化態為 x：

```
2x + 3(−2) = 0
2x = +6
x = +3
```

**赤鐵礦中 Fe 的氧化態為 +3。**

**磁鐵礦（Fe₃O₄）中鐵的氧化態：**

設 Fe 平均氧化態為 x：

```
3x + 4(−2) = 0
3x = +8
x = +8/3 ≈ +2.67
```

這是 +2 和 +3 的混合平均值，說明磁鐵礦含有 **Fe²⁺ 和 Fe³⁺ 兩種鐵離子**。

**Fe²⁺ 與 Fe³⁺ 的比例：**

設每個 Fe₃O₄ 單元中有 a 個 Fe²⁺ 和 b 個 Fe³⁺：

```
a + b = 3         （鐵原子總數）
2a + 3b = 8       （總氧化態 = +8，因為 4 個 O²⁻ 貢獻 −8）

解：a = 1，b = 2
```

**Fe²⁺ : Fe³⁺ = 1 : 2**

**FeO·Fe₂O₃ 的合理性驗證：**

FeO 含 1 個 Fe²⁺，Fe₂O₃ 含 2 個 Fe³⁺ → 合計 1 個 Fe²⁺ + 2 個 Fe³⁺ + 4 個 O²⁻ = Fe₃O₄

$$\text{FeO} \cdot \text{Fe}_2\text{O}_3 \equiv \text{Fe}_3\text{O}_4 \quad \checkmark$$

**這樣的寫法完全合理**，明確表示磁鐵礦是兩種不同氧化態鐵的複合氧化物。

### 進階例題 C（Exercise 15，難度：中高）

**題目**：Cr(VI) 形成兩種不同的含氧陰離子（oxyanions）：橙色的重鉻酸根（Cr₂O₇²⁻）和黃色的鉻酸根（CrO₄²⁻）。兩者之間的平衡為：

```
Cr₂O₇²⁻(aq) + H₂O(l) ⇌ 2CrO₄²⁻(aq) + 2H⁺(aq)
```

當 NaOH（aq）逐滴加入重鉻酸鈉溶液時，溶液的顏色如何變化？請解釋。

**解析：**

**分析平衡的方向：**

加入 NaOH 後，OH⁻ 與溶液中的 H⁺ 反應：

```
OH⁻(aq) + H⁺(aq) → H₂O(l)
```

這使得溶液中 H⁺ 濃度降低（[H⁺] ↓）。

根據**勒沙特列原理（Le Châtelier's principle）**：H⁺ 是上述平衡的生成物，[H⁺] 降低會使平衡向**右移動（向生成物方向）**，即：

$$\text{Cr}_2\text{O}_7^{2-} \xrightarrow{[H^+]\downarrow} 2\text{CrO}_4^{2-}$$

- 起始：溶液以 Cr₂O₇²⁻ 為主 → **橙色（orange）**
- 加入 NaOH 後：平衡右移，CrO₄²⁻ 濃度增大 → 顏色逐漸由橙色轉為**黃色（yellow）**

**答**：加入 NaOH 後，溶液由橙色（重鉻酸根 Cr₂O₇²⁻ 的顏色）逐漸轉變為黃色（鉻酸根 CrO₄²⁻ 的顏色），原因是 OH⁻ 消耗了 H⁺，使平衡向生成 CrO₄²⁻ 的方向移動。

### 進階例題 D（綜合應用，難度：高）

**題目**：在釩的水溶液化學中，可以用強還原劑（如 Zn/HCl）將 VO₂⁺ 逐步還原。請預測在逐步加入還原劑的過程中，溶液顏色的變化順序，並寫出對應的半反應。

**解析：**

**顏色變化順序（由高氧化態到低氧化態）：**

```
VO₂⁺（+5，黃色）→ VO²⁺（+4，藍色）→ V³⁺（+3，藍綠色）→ V²⁺（+2，紫色）
  黃色 → 藍色 → 藍綠色 → 紫色
```

**對應的半反應（reduction half-reactions）：**

**(1) +5 → +4：**

```
VO₂⁺(aq) + 2H⁺(aq) + e⁻ → VO²⁺(aq) + H₂O(l)
```

（黃色 → 藍色）

**(2) +4 → +3：**

```
VO²⁺(aq) + 2H⁺(aq) + e⁻ → V³⁺(aq) + H₂O(l)
```

（藍色 → 藍綠色）

**(3) +3 → +2：**

```
V³⁺(aq) + e⁻ → V²⁺(aq)
```

（藍綠色 → 紫色）

> **說明**：氧化態越低，3d 電子越多，對應的 d-d 電子躍遷（d-d transitions）能量不同，吸收不同波長的可見光（visible light），因此顏色各異。V²⁺ 和 V³⁺ 的水合離子不穩定，在空氣中易被 O₂ 重新氧化，實驗操作需在無氧（inert atmosphere）下進行。

## 五、本節重點整理

| 元素 | 最常見氧化態 | 水溶液中水合離子顏色 | 最重要特徵 |
|------|------------|------------------|----------|
| Sc | +3 | 無色（colorless） | d⁰，無發色 |
| Ti | +4 | Ti³⁺ 紫色 | TiO₂ 白色顏料，航太材料 |
| V | +2∼+5 | 四種不同顏色 | V₂O₅ 工業催化劑 |
| Cr | +3（最穩定） | Cr³⁺ 綠色 | Cr₂O₇²⁻（橙）↔ CrO₄²⁻（黃） |
| Mn | +2、+7 | Mn²⁺ 淡粉色 | MnO₄⁻（紫）強氧化劑 |
| Fe | +2、+3 | Fe²⁺ 綠色；Fe³⁺ 棕黃色 | 最豐富重金屬，生鏽 |
| Co | +2、+3 | Co²⁺ 玫瑰色 | 豐富配位化合物，維生素 B₁₂ |
| Ni | +2 | Ni²⁺ 翠綠色 | 幾乎只有 +2 |
| Cu | +2（最常見） | Cu²⁺ 鮮藍色 | 不與 H⁺ 反應；銅綠；合金 |
| Zn | +2 | 無色（colorless） | d¹⁰ 滿殼，鍍鋅 |

**關鍵規律總結：**

- **d⁰ 和 d¹⁰ 的過渡金屬離子（Sc³⁺、Ti⁴⁺、Zn²⁺）**：無 d 電子躍遷，化合物無色（colorless）且反磁性（diamagnetic）
- **Cr(VI) 的 pH 依賴性**：酸性 → Cr₂O₇²⁻（橙色，強氧化劑）；鹼性 → CrO₄²⁻（黃色，弱氧化劑）
- **高錳酸根（MnO₄⁻）**：深紫色，酸性條件下強氧化劑，被還原為幾乎無色的 Mn²⁺，可作滴定指示劑
- **Fe³⁺ 溶液呈黃棕色**：實為 Fe³⁺ 水解產物 Fe(OH)(H₂O)₅²⁺ 的顏色，而非 Fe(H₂O)₆³⁺ 本身
- **Cu 不與稀鹽酸或稀硫酸反應**（E° = −0.34 V < 0），是第一列中唯一無法在酸中還原 H⁺ 的過渡金屬
