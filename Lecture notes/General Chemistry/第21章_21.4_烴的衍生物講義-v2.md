# 第 21 章　有機與生化分子
## 21.4　烴的衍生物（Hydrocarbon Derivatives）

---

## 一、官能基（Functional Groups）總覽

### 1.1  官能基總覽 (Function Group Overview)

**烴的衍生物（hydrocarbon derivatives）** 是以烴為骨架，含有額外原子或原子團（稱為**官能基 functional groups**）的有機化合物。不同官能基賦予分子特定的化學性質與反應模式。

| 類別（Class） | 官能基（Functional Group） | 通式（General Formula） | 代表例（Example） |
|--------------|--------------------------|------------------------|-----------------|
| 鹵烴（halohydrocarbons） | –X（F, Cl, Br, I） | R–X | CH₃I（碘甲烷 iodomethane） |
| 醇（alcohols） | –OH（羥基 hydroxyl group） | R–OH | CH₃OH（甲醇 methanol） |
| 醚（ethers） | –O–（醚鍵 ether linkage） | R–O–R' | CH₃OCH₃（二甲醚 dimethyl ether） |
| 醛（aldehydes） | –CHO（醛基 aldehyde group） | R–CHO | HCHO（甲醛 formaldehyde） |
| 酮（ketones） | C=O（羰基 carbonyl group） | R–CO–R' | CH₃COCH₃（丙酮 acetone） |
| 羧酸（carboxylic acids） | –COOH（羧基 carboxyl group） | R–COOH | CH₃COOH（乙酸 acetic acid） |
| 酯（esters） | –COO–（酯基 ester group） | R–COO–R' | CH₃COOC₂H₅（乙酸乙酯 ethyl acetate） |
| 胺（amines） | –NH₂（胺基 amino group） | R–NH₂ | CH₃NH₂（甲胺 methylamine） |

> **R 的意義**：R 和 R' 代表**烴基片段（hydrocarbon fragments）**，可以是烷基（alkyl group）、芳基（aryl group）等。

### 1.2　官能基命名優先順序（Nomenclature Priority Order）

當一個分子含有**多個官能基**時，IUPAC 命名以**優先順序最高**的官能基作為**主官能基（principal characteristic group）**，決定主鏈字尾（suffix）；其餘優先順序較低的官能基則以**前綴（prefix）** 方式標示。

**優先順序（由高至低）：**

```
羧酸 > 醯胺 > 醛 > 酮 > 醇/酚 > 胺 > 苯 > 炔 > 烯 > 烷
Carboxylic acid > Amide > Aldehyde > Ketone > Alcohol > Amine > Benzene > Alkyne > Alkene > Alkane
```

| 優先順序 | 官能基（中文） | 官能基（英文） | 主官能基字尾（Suffix） | 非主官能基前綴（Prefix） |
|---------|--------------|--------------|----------------------|------------------------|
| 1 | 羧酸 | Carboxylic acid | **-oic acid** | carboxy- |
| 2 | 醯胺 | Amide | **-amide** | carbamoyl- |
| 3 | 醛 | Aldehyde | **-al** | oxo- |
| 4 | 酮 | Ketone | **-one** | oxo- |
| 5 | 醇 | Alcohol | **-ol** | hydroxy- |
| 6 | 胺 | Amine | **-amine** | amino- |
| 7 | 炔 | Alkyne | **-yne** | — |
| 8 | 烯 | Alkene | **-ene** | — |
| 9 | 烷 | Alkane | **-ane** | — |

> **應用原則：**
> - 優先順序**最高**的官能基 → 決定主鏈字尾，作為主官能基
> - 優先順序**較低**的官能基 → 以前綴（prefix）方式標示
> - 炔／烯／烷為碳鏈本身，位置永遠以數字標示

**範例：**
```
HO–CH₂–CH₂–COOH
→ 主官能基：羧酸（-oic acid，優先順序第1）
→ 次官能基：醇（hydroxy- 前綴，優先順序第5）
→ 命名：3-羥基丙酸（3-hydroxypropanoic acid）
```

## 二、醇（Alcohols）

### 2.1 定義與命名

醇（alcohols）含有**羥基（hydroxyl group，–OH）**。系統命名規則：

1. 找含 –OH 的最長碳鏈（parent chain）作為主鏈
2. 主鏈字尾：將烷烴的 **-ane** 改為 **-ol**
3. 從最靠近 –OH 的一端開始編號，使 –OH 的號碼最小
4. 其他取代基（substituents）命名方式同烷烴

```
命名範例：

CH₃OH           →  甲醇（methanol）
CH₃CH₂OH        →  乙醇（ethanol）
CH₃CH₂CH₂OH     →  1-丙醇（1-propanol）
CH₃CHOHCH₃      →  2-丙醇（2-propanol）
```

### 2.2 醇的分級（Classification of Alcohols）

依照連接 –OH 的碳所接的**烴基片段（hydrocarbon fragments）數目**分類：

```
R–CH₂OH           →  伯醇（primary alcohol，一級醇）：–OH 碳接 1 個 R
R–CHOH–R'         →  仲醇（secondary alcohol，二級醇）：–OH 碳接 2 個 R
R–C(OH)–R'–R''   →  叔醇（tertiary alcohol，三級醇）：–OH 碳接 3 個 R
```

### 2.3 醇的沸點：氫鍵的影響

醇的沸點（boiling point）遠高於相近分子量的烷烴：

| 化合物 | 分子量（molar mass） | 沸點（boiling point） |
|--------|--------------------|-----------------------|
| 甲醇 methanol（CH₃OH） | 32 g/mol | 65°C |
| 乙烷 ethane（C₂H₆） | 30 g/mol | −89°C |

原因：醇分子間可形成**氫鍵（hydrogen bonds）**（O–H⋯O），分子間作用力（intermolecular forces）遠強於烷烴的色散力（London dispersion forces）。

### 2.4 重要的醇

**甲醇（methanol，CH₃OH）：**
- 俗名「木醇（wood alcohol）」（早期由木材乾餾得到）
- 工業製法：CO 加氫（hydrogenation of CO）

```
CO + 2H₂  →(ZnO/Cr₂O₃, 400°C)  CH₃OH
```

- 用途（uses）：製備乙酸（acetic acid）、黏著劑（adhesives）、纖維（fibers）、塑料（plastics）；可作為燃料（fuel）
- **毒性（toxicity）**：對人體毒性極強，少量即可導致失明（blindness）甚至死亡

**乙醇（ethanol，CH₃CH₂OH）：**
- 酒精飲料的成分，由葡萄糖發酵（fermentation）製得：

```
C₆H₁₂O₆  →(酵母 yeast)  2CH₃CH₂OH + 2CO₂
（葡萄糖 glucose）         （乙醇 ethanol）
```

- 發酵液酒精濃度上限約 **13%**（酵母在此濃度以上死亡）
- 工業製法：乙烯（ethylene）與水的加成反應（addition reaction）

```
CH₂=CH₂ + H₂O  →(酸催化劑 acid catalyst)  CH₃CH₂OH
```

- 用途（uses）：燃料（gasohol，汽油酒精混合燃料）、溶劑（solvent）、製備乙酸

**乙二醇（1,2-ethanediol，ethylene glycol）：**
- 含**兩個 –OH 基（polyhydroxyl alcohol，多羥基醇）**
- 是汽車防凍液（antifreeze）的主要成分
- **毒性（toxicity）**：有毒，不可誤食

**苯酚（phenol，C₆H₅OH）：**
- 最簡單的**芳香醇（aromatic alcohol）**
- –OH 直接接在苯環（benzene ring）上
- 用途：製造聚合物（polymers）用於黏著劑（adhesives）和塑料（plastics）

## 三、醛與酮（Aldehydes and Ketones）

### 3.1 羰基（Carbonyl Group）

醛（aldehydes）和酮（ketones）都含有**羰基（carbonyl group）**：

```
    C = O
```

區別：
- **醛（aldehyde）**：羰基碳（carbonyl carbon）至少接一個 **H**，官能基為 **–CHO（醛基 aldehyde group）**
- **酮（ketone）**：羰基碳兩側均接**碳鏈（carbon chain）**，即 **R–CO–R'**

```
醛（aldehyde）：     酮（ketone）：

   O                    O
   ‖                    ‖
R–C–H               R–C–R'
```

### 3.2 命名規則

**醛（aldehydes）命名：**
- 主鏈字尾：**-ane → -al**
- 醛基碳（aldehyde carbon）固定為 **C1**（永遠在鏈端，不須另外標號）

```
HCHO        →  甲醛（methanal / formaldehyde）
CH₃CHO      →  乙醛（ethanal / acetaldehyde）
CH₃CH₂CHO  →  丙醛（propanal）
```

**酮（ketones）命名：**
- 主鏈字尾：**-ane → -one**
- 用數字標示羰基（carbonyl group）的位置（取最小號碼）

```
CH₃COCH₃         →  丙酮（propanone / acetone）
CH₃COCH₂CH₃      →  2-丁酮（2-butanone / methyl ethyl ketone, MEK）
CH₃CH₂COCH₂CH₃  →  3-戊酮（3-pentanone）
```

### 3.3 醛與酮的製備：醇的氧化（Oxidation of Alcohols）

```
伯醇（primary alcohol）  →(氧化 oxidation)  醛（aldehyde）
                          →(進一步氧化 further oxidation)  羧酸（carboxylic acid）

仲醇（secondary alcohol）→(氧化 oxidation)  酮（ketone）

叔醇（tertiary alcohol） →  不發生此類氧化反應（no reaction）
```

**範例：**
```
CH₃CH₂OH  →(氧化 oxidation)  CH₃CHO  →(進一步氧化)  CH₃COOH
（乙醇，伯醇）                （乙醛，醛）              （乙酸，羧酸）

CH₃CHOHCH₃  →(氧化)  CH₃COCH₃
（2-丙醇，仲醇）       （丙酮，酮）
```

### 3.4 醛與酮的重要性質

- **酮（ketones）** 常作為良好**溶劑（solvents）**，如丙酮（acetone）是去光指甲油（nail polish remover）的成分
- **醛（aldehydes）** 通常有強烈氣味（odor）：
  - 香草醛（vanillin）：香草豆（vanilla beans）的香氣來源
  - 肉桂醛（cinnamaldehyde）：肉桂（cinnamon）的特徵氣味
  - 丁醛（butyraldehyde）：腐敗奶油（rancid butter）的臭味

## 四、羧酸（Carboxylic Acids）

### 4.1 定義與命名

羧酸（carboxylic acids）含有**羧基（carboxyl group，–COOH）**，是有機弱酸（weak acids）。

命名規則：
- 主鏈字尾：**-ane → -oic acid**（**-oic 酸**）
- 羧基碳（carboxyl carbon）固定為 **C1**

```
HCOOH        →  甲酸（methanoic acid / formic acid）
CH₃COOH      →  乙酸（ethanoic acid / acetic acid）
CH₃CH₂COOH  →  丙酸（propanoic acid / propionic acid）
CH₃(CH₂)₂COOH →  丁酸（butanoic acid / butyric acid）
```

### 4.2 羧酸的製備

**強氧化劑（strong oxidizing agent）** 氧化伯醇（primary alcohol）：

```
CH₃CH₂OH  →(KMnO₄(aq))  CH₃COOH
（乙醇）                   （乙酸）
```

### 4.3 羧酸的重要性質

- 在水溶液中呈**弱酸性（weakly acidic）**：RCOOH ⇌ RCOO⁻ + H⁺
- 分子間可形成**氫鍵（hydrogen bonds）**，沸點（boiling point）高
- 常有**刺激性氣味（pungent odor）**，如乙酸是醋的主要成分

---

## 五、酯（Esters）

### 5.1 酯化反應（Esterification）

**羧酸（carboxylic acid）** 與**醇（alcohol）** 在酸催化劑（acid catalyst）下反應，生成**酯（ester）** 和**水（water）**，這個反應稱為**酯化反應（esterification）**：

```
R–COOH  +  HO–R'  ⇌(H⁺)  R–COO–R'  +  H₂O
（羧酸）    （醇）           （酯）      （水）
```

**範例：乙酸（acetic acid）與乙醇（ethanol）反應**

```
CH₃COOH  +  CH₃CH₂OH  ⇌(H⁺)  CH₃COOCH₂CH₃  +  H₂O
（乙酸）      （乙醇）           （乙酸乙酯 ethyl acetate）
```

### 5.2 酯的命名

格式：**醇部分（-yl）+ 酸部分（-oate）**

- 酸部分：將 **-oic acid** 改為 **-oate**
- 醇部分：烷基名稱 + **-yl**

```
CH₃COOCH₂CH₃      →  乙酸乙酯（ethyl acetate / ethyl ethanoate）
CH₃COOCH₂CH₂CH₂CH₂CH₃  →  乙酸正戊酯（n-amyl acetate / n-pentyl ethanoate）
                              （香蕉香氣的來源 banana odor）
CH₃COO–C₈H₁₇      →  乙酸正辛酯（n-octyl acetate / n-octylethanoate）
                        （柳橙香氣的來源 orange odor）
```

### 5.3 酯的重要性質

- 酯通常有**甜的水果香氣（sweet, fruity odor）**，與母體羧酸的刺激性氣味截然不同
- 許多天然香氣（natural fragrances）和人工香料（artificial flavors）都來自酯類

### 5.4 重要的酯：阿斯匹靈（Aspirin）

水楊酸（salicylic acid）與乙酸（acetic acid）的酯化反應（esterification）產物：

```
水楊酸（salicylic acid）+ 乙酸（acetic acid）
→ 乙醯柳酸（acetylsalicylic acid）+ H₂O
```

**乙醯柳酸（acetylsalicylic acid）** 即為阿斯匹靈（aspirin），廣泛用作**止痛藥（analgesic）**。

## 六、胺（Amines）

### 6.1 定義與結構

**胺（amines）** 可視為**氨（ammonia，NH₃）** 的衍生物——氨的 N–H 鍵被 **N–C 鍵（N–C bonds）** 取代：

```
一級胺（primary amine）：R–NH₂          （一個 N–C 鍵）
二級胺（secondary amine）：R–NH–R'       （兩個 N–C 鍵）
三級胺（tertiary amine）：R–N–R'–R''    （三個 N–C 鍵）
```

### 6.2 命名規則

簡單胺常用俗名（common names），如：

| 分子式 | 俗名 | 分級（class） |
|--------|------|--------------|
| CH₃NH₂ | 甲胺（methylamine） | 一級胺（primary amine） |
| (CH₃)₂NH | 二甲胺（dimethylamine） | 二級胺（secondary amine） |
| (CH₃)₃N | 三甲胺（trimethylamine） | 三級胺（tertiary amine） |
| C₆H₅NH₂ | 苯胺（aniline） | 一級胺（primary amine） |

系統命名：以 **amino-（胺基 amino group）** 作為前綴：

```
CH₃CHCH₂CH₃   →  2-胺基丁烷（2-aminobutane）
    |
   NH₂
```

### 6.3 胺的重要性質

- 胺（amines）具有**鹼性（basic character）**：N 上的孤對電子（lone pair）可接受質子（proton）
- 許多胺（amines）具有**魚腥味（fishlike odor）**
- 動植物腐爛的臭味來自胺類，如：
  - **腐胺（putrescine，H₂N(CH₂)₄NH₂）**
  - **屍胺（cadaverine，H₂N(CH₂)₅NH₂）**
- **芳香胺（aromatic amines）** 多用於製造染料（dyes），但許多具有**致癌性（carcinogenicity）**，需謹慎處理

## 七、課本例題精講

### 例題 1（課本 Example 21.6）：醇的命名與分級

**題目**：命名下列醇，並指出其為伯、仲或叔醇：

**(a)**
```
CH₃CHCH₂CH₃
    |
    OH
```

**解析：**

主鏈為 4 碳（butane），–OH 在 C2 → **2-丁醇（2-butanol）**

–OH 所在碳（C2）連接 CH₃ 和 CH₂CH₃ 兩個烴基片段（hydrocarbon fragments）→ **仲醇（secondary alcohol）**

**(b)**
```
ClCH₂CH₂CH₂OH
```

**解析：**

主鏈 3 碳，–OH 在 C1，C3 有 Cl 取代基（substituent）→ **3-氯-1-丙醇（3-chloro-1-propanol）**

–OH 所在碳（C1）只接一個烴基片段（–CH₂CH₂Cl）→ **伯醇（primary alcohol）**

**(c)**
```
     CH₃
      |
CH₃–C–CH₂CH₂CH₂CH₂Br
      |
     OH
```

**解析：**

主鏈：從 –OH 碳往最長方向數：C（OH）→ CH₂ → CH₂ → CH₂ → CH₂Br = 6 碳；加上 CH₃（在 C2）

→ 主鏈 6 碳，–OH 在 C2，末端 C6 有 Br，C2 有額外 CH₃

→ **6-溴-2-甲基-2-己醇（6-bromo-2-methyl-2-hexanol）**

–OH 所在碳接 CH₃、CH₃、–CH₂CH₂CH₂CH₂Br 三個烴基片段 → **叔醇（tertiary alcohol）**

## 八、進階例題（選自課後習題）

### 進階例題 A（Exercise 43，難度：中）

**題目**：命名所有分子式為 C₅H₁₂O 的醇（alcohols），並問有多少個醚（ethers）的分子式也是 C₅H₁₂O？

**解析（醇）：**

C₅H₁₂O 中，–OH 接在戊烷（pentane）骨架上，系統性列舉：

**主鏈 5 碳（戊醇，pentanol）：**

```
1. CH₃CH₂CH₂CH₂CH₂OH         →  1-戊醇（1-pentanol）【伯醇 primary】

2. CH₃CH₂CH₂CHOHCH₃          →  2-戊醇（2-pentanol）【仲醇 secondary】

3. CH₃CH₂CHOHCH₂CH₃          →  3-戊醇（3-pentanol）【仲醇 secondary】
```

**主鏈 4 碳（甲基丁醇，methylbutanol）：**

```
4. (CH₃)₂CHCH₂CH₂OH          →  3-甲基-1-丁醇（3-methyl-1-butanol）【伯醇 primary】

5. CH₃CH₂C(CH₃)(OH)CH₃       →  2-甲基-2-丁醇（2-methyl-2-butanol）【叔醇 tertiary】

6. (CH₃)₂CHCHOHCH₃           →  3-甲基-2-丁醇（3-methyl-2-butanol）【仲醇 secondary】

7. (CH₃)₂CHCH(OH)            →  ...注意是否有新結構
   確認：(CH₃)₂CHCH₂OH        →  2-甲基-1-丁醇（2-methyl-1-butanol）【伯醇 primary】
```

**主鏈 3 碳（二甲基丙醇，dimethylpropanol）：**

```
8. (CH₃)₃CCH₂OH               →  2,2-二甲基-1-丙醇（2,2-dimethyl-1-propanol）【伯醇 primary】
```

共 **8 種醇**。

**醚（ethers）的數目：**

C₅H₁₂O 的醚（R–O–R'）：R 和 R' 的碳數加總為 5，列舉不同的 R / R' 組合（考慮對稱性）：

```
CH₃–O–CH₂CH₂CH₂CH₃      →  甲基正丁基醚（methyl n-butyl ether）
CH₃–O–CH(CH₃)CH₂CH₃      →  甲基仲丁基醚（methyl sec-butyl ether）
CH₃–O–C(CH₃)₂CH₃          →  甲基叔丁基醚（methyl tert-butyl ether, MTBE）
CH₃CH₂–O–CH₂CH₂CH₃       →  乙基丙基醚（ethyl propyl ether）
CH₃CH₂–O–CH(CH₃)₂         →  乙基異丙基醚（ethyl isopropyl ether）
```

共 **6 種醚（ethers）**。

### 進階例題 B（Exercise 61，難度：高）

**題目**：氧化（oxidation）下列各醇，給出產物結構（伯醇→醛→羧酸；仲醇→酮；叔醇→無反應）：

**(a) 3-methyl-1-butanol（3-甲基-1-丁醇，伯醇 primary alcohol）**

```
(CH₃)₂CHCH₂CH₂OH
         →(第一步氧化)  (CH₃)₂CHCH₂CHO      3-甲基丁醛（3-methylbutanal）
         →(進一步氧化)  (CH₃)₂CHCH₂COOH     3-甲基丁酸（3-methylbutanoic acid）
```

**(b) 3-methyl-2-butanol（3-甲基-2-丁醇，仲醇 secondary alcohol）**

```
(CH₃)₂CHCHOHCH₃
         →(氧化)  (CH₃)₂CHCOCH₃     3-甲基-2-丁酮（3-methyl-2-butanone）
```

**(c) 2-methyl-2-butanol（2-甲基-2-丁醇，叔醇 tertiary alcohol）**

```
CH₃C(OH)(CH₃)CH₂CH₃
         →  不反應（no reaction）
```

> **規律總結**：
> - 伯醇（primary alcohol）：可氧化兩次，最終得羧酸（carboxylic acid）
> - 仲醇（secondary alcohol）：只能氧化一次，得酮（ketone）
> - 叔醇（tertiary alcohol）：不發生此類氧化，因連接 –OH 的碳上無 H 可被移除

### 進階例題 C（Exercise 67，難度：中高）

**題目**：完成下列酯化反應（esterification），給出產物結構並命名：

**(a) CH₃COOH + CH₃OH →**

**解析：**

乙酸（acetic acid）+ 甲醇（methanol）在酸催化劑（acid catalyst）下酯化：

```
CH₃COOH  +  CH₃OH  →(H⁺)  CH₃COOCH₃  +  H₂O
```

產物：**乙酸甲酯（methyl acetate / methyl ethanoate）**

命名：methyl（來自甲醇 methanol）+ ethanoate（來自乙酸 ethanoic acid）

**(b) CH₃CH₂CH₂OH + HCOOH →**

**解析：**

正丙醇（1-propanol）+ 甲酸（methanoic acid / formic acid）酯化：

```
HCOOH  +  HOCH₂CH₂CH₃  →(H⁺)  HCOO–CH₂CH₂CH₃  +  H₂O
```

產物：**甲酸正丙酯（propyl methanoate / propyl formate）**

命名：propyl（來自 1-propanol）+ methanoate（來自 methanoic acid）

### 進階例題 D（Exercise 50 節錄，難度：高，綜合判斷）

**題目**：判斷下列各敘述是否正確，若錯請說明原因：

**(a)** CH₃CH₂CH₂COOCH₃ 是戊酸（pentanoic acid）的結構異構物（structural isomer）。

**解析：**

CH₃CH₂CH₂COOCH₃ 分子式：C₅H₁₀O₂

戊酸（pentanoic acid）= CH₃CH₂CH₂CH₂COOH，分子式：C₅H₁₀O₂

分子式相同，鍵結方式不同（一為酯，一為羧酸）→ **正確，兩者互為結構異構物（structural isomers）**

**(b)**
```
CH₃CH₂OCH₂CH₂CH₃
```
是 2-戊醇（2-pentanol）的結構異構物（structural isomer）。

**解析：**

CH₃CH₂OCH₂CH₂CH₃ 分子式：C₅H₁₂O（醚 ether）

2-pentanol = CH₃CHOHCH₂CH₂CH₃，分子式：C₅H₁₂O（醇 alcohol）

分子式相同，鍵結不同 → **正確，兩者互為結構異構物（structural isomers）**

**(c)** 三甲胺（trimethylamine）是丁胺（butylamine，CH₃CH₂CH₂CH₂NH₂）的結構異構物（structural isomer）。

**解析：**

三甲胺（trimethylamine）= (CH₃)₃N，分子式：C₃H₉N

丁胺（butylamine）= CH₃CH₂CH₂CH₂NH₂，分子式：C₄H₁₁N

分子式**不同** → **錯誤，兩者不是結構異構物**
