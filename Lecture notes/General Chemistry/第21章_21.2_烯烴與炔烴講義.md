# 第 21 章　有機與生化分子
## 21.2　烯烴與炔烴（Alkenes and Alkynes）

---

## 一、烯烴（Alkenes）的基本概念

### 1.1 定義與通式

**烯烴（alkenes）** 是含有至少一個 **C=C 雙鍵（carbon-carbon double bond）** 的不飽和烴（unsaturated hydrocarbon）。

通式：**CₙH₂ₙ**（非環狀、單一雙鍵）

> 與烷烴相比，每形成一個雙鍵就少 2 個 H，因為一個 π 鍵取代了原本兩個 C–H 鍵的位置。

### 1.2 乙烯（Ethylene, C₂H₄）的鍵結結構

乙烯是最簡單的烯烴，其鍵結特性來自 **sp² 混成（sp² hybridization）**：

- 每個碳有 3 個 sp² 混成軌域，形成**三個 σ 鍵（sigma bonds）**：
  - C–H σ 鍵（×2）
  - C–C σ 鍵（×1）
- 每個碳剩下一個未混成的 **2p 軌域（2p orbital）**，兩個碳的 2p 軌域側向重疊，形成 **π 鍵（pi bond）**

```
結構示意：

    H       H
     \     /
      C = C
     /     \
    H       H

鍵角：所有鍵角均為 120°（平面三角形幾何 trigonal planar geometry）
```

**σ 鍵 vs. π 鍵比較：**

| 特性 | σ 鍵（sigma bond） | π 鍵（pi bond） |
|------|-------------------|-----------------|
| 形成方式 | 軌域正面（head-on）重疊 | 軌域側向（side-to-side）重疊 |
| 鍵的強度 | 較強 | 較弱（容易斷裂） |
| 旋轉 | 允許自由旋轉（free rotation） | **阻礙旋轉**（restricted rotation） |
| 位置 | C=C 雙鍵中的第一個鍵 | C=C 雙鍵中的第二個鍵 |

> **關鍵概念**：π 鍵阻礙了 C=C 兩側基團的自由旋轉，這正是**順反異構物（cis-trans isomerism）** 存在的根本原因。

---

## 二、烯烴的 IUPAC 命名

### 2.1 命名規則

1. 找含雙鍵的**最長碳鏈**作為主鏈（parent chain），字尾改為 **-ene**（而非烷烴的 -ane）
2. **從最靠近雙鍵的一端**開始編號，使雙鍵碳獲得**最小號碼**
3. 雙鍵（double bond）位置以**雙鍵起始碳的號碼**標示
4. 取代基（substituent）命名規則與烷烴相同

### 2.2 命名範例

```
CH₂=CHCH₂CH₃          →  1-丁烯（1-butene）
                           （雙鍵在 C1–C2 之間，取 C1）

CH₃CH=CHCH₃           →  2-丁烯（2-butene）
                           （雙鍵在 C2–C3 之間，取 C2）

CH₂=CH₂               →  乙烯（ethene / ethylene）

CH₃CH=CH₂             →  丙烯（propene / propylene）
```

> **注意**：乙烯（ethylene）和丙烯（propylene）是這兩個化合物常用的俗名，系統名為 ethene 和 propene。

---

## 三、順反異構物（Cis-Trans Isomerism）

### 3.1 產生原因

由於 π 鍵阻礙了雙鍵兩側基團的旋轉，若雙鍵兩端的碳各自接有**兩個不同的取代基（substituents）**，便會產生空間排列不同的**立體異構物（stereoisomers）**。

### 3.2 命名規則

- **順式（cis）**：兩個相同（或相似）的取代基（substituents）位於雙鍵的**同側（same side）**
- **反式（trans）**：兩個相同（或相似）的取代基（substituents）位於雙鍵的**異側（opposite sides）**

### 3.3 2-丁烯的順反異構物

```
        CH₃   CH₃                    CH₃    H
          \   /                         \   /
           C=C          vs.              C=C
          /   \                         /   \
         H     H                       H    CH₃

    cis-2-butene（順-2-丁烯）      trans-2-butene（反-2-丁烯）
    （兩個 CH₃ 在同側）             （兩個 CH₃ 在異側）
```

### 3.4 判斷是否有順反異構物的條件

雙鍵的**每一端碳**必須各自連接**兩個不同的基團（groups）／取代基（substituents）**，才可能有順反異構物。

```
以下情況「不會」有順反異構物：

CH₂=CHCH₃   →  C1 上有兩個 H（相同），不符合條件，無順反異構物

以下情況「會」有順反異構物：

CH₃CH=CHCH₃  →  C2 接 H 和 CH₃（不同）；C3 也接 H 和 CH₃（不同）→ 有順反異構物
```

### 3.5 烷烴 vs. 烯烴的旋轉比較

| 化合物 | 特性 |
|--------|------|
| 乙烷（ethane）C₂H₆ | C–C σ 鍵，**可自由旋轉（free rotation）** |
| 乙烯（ethylene）C₂H₄ | C=C（σ + π），**旋轉受限（restricted rotation）** |

## 四、炔烴（Alkynes）的基本概念

### 4.1 定義與通式

**炔烴（alkynes）** 是含有至少一個 **C≡C 三鍵（carbon-carbon triple bond）** 的不飽和烴。

通式：**CₙH₂ₙ₋₂**（非環狀、單一三鍵）

### 4.2 乙炔（Acetylene, C₂H₂）的鍵結結構

乙炔是最簡單的炔烴，其鍵結特性來自 **sp 混成（sp hybridization）**：

- 每個碳有 2 個 sp 混成軌域，形成**兩個 σ 鍵**：
  - C–H σ 鍵（×1）
  - C–C σ 鍵（×1）
- 每個碳剩下**兩個**未混成的 2p 軌域，分別與另一個碳的對應 2p 軌域側向重疊，形成**兩個 π 鍵**

```
結構示意：

H–C≡C–H

鍵角：180°（直線形幾何 linear geometry）
```

**三鍵的組成：**

```
C≡C  =  1 個 σ 鍵  +  2 個 π 鍵
```

### 4.3 炔烴的 IUPAC 命名

- 找含三鍵的最長碳鏈，字尾改為 **-yne**
- 從最靠近三鍵的一端編號
- 三鍵位置以起始碳的號碼標示

```
CH₃CH₂C≡CCH₃    →  2-戊炔（2-pentyne）
                     （三鍵在 C2–C3 之間，取 C2）
```

> **注意**：炔烴的三鍵為直線形，C≡C 兩端的碳各只接一個取代基，因此炔烴**不存在順反異構物**。

---

## 五、三類不飽和烴的鍵結比較

| 特性 | 烷烴（alkanes） | 烯烴（alkenes） | 炔烴（alkynes） |
|------|----------------|----------------|----------------|
| 鍵型 | C–C（單鍵） | C=C（雙鍵） | C≡C（三鍵） |
| 混成 | sp³ | sp² | sp |
| 幾何形狀 | 四面體（109.5°） | 平面三角形（120°） | 直線形（180°） |
| σ 鍵數 | 1 | 1 | 1 |
| π 鍵數 | 0 | 1 | 2 |
| 順反異構物 | 不存在 | **可能存在** | 不存在 |
| 主要反應 | 取代反應 | **加成反應** | **加成反應** |
| 通式（非環） | CₙH₂ₙ₊₂ | CₙH₂ₙ | CₙH₂ₙ₋₂ |

## 六、烯烴與炔烴的化學反應

### 6.1 加成反應（Addition Reactions）的概念

由於烯烴和炔烴含有**較弱的 π 鍵**，其主要反應為**加成反應（addition reactions）**：π 鍵斷裂，新原子或基團從雙鍵兩端加入，形成新的 σ 鍵。

```
一般式：
          A–B
          ↓
  –C=C–  +  A–B  →  –C–C–
                      |  |
                      A  B
```

### 6.2 氫化反應（Hydrogenation）

在 Pt、Pd 或 Ni **催化劑（catalyst）** 下，烯烴與 H₂ 加成，生成烷烴：

```
CH₂=CHCH₃  +  H₂  →(Pt/Pd/Ni)  CH₃CH₂CH₃
（1-丙烯 1-propene）              （丙烷 propane）
```

**工業應用**：植物油（liquid，含 C=C）氫化（hydrogenation）製成固態起酥油（solid shortening）或人造奶油（margarine）。

> **催化劑的作用**：H₂ 分子的 H–H 鍵（鍵能 436 kJ/mol）本身很強，需要金屬催化劑（metal catalyst）協助吸附並削弱 H–H 鍵後，才能在常溫下與烯烴快速反應（詳見異相催化 heterogeneous catalysis 機制）。

### 6.3 鹵化反應（Halogenation）

烯烴與鹵素（X₂）加成，**不需光照**，在室溫下即可自發進行：

```
CH₂=CHCH₂CH₂CH₃  +  Br₂  →  CH₂BrCHBrCH₂CH₂CH₃
（1-戊烯 1-pentene）           （1,2-二溴戊烷 1,2-dibromopentane）
```

> **鑑定雙鍵的方法**：將溴液（bromine solution，棕紅色 brown-red）加入含烯烴的樣品，若**溴液褪色（decolorization）**，表示發生了加成反應（addition reaction），確認有 C=C 存在。

### 6.4 加水反應（Hydration）

在酸（H⁺）酸催化（acid catalysis）下，烯烴與水加成生成醇（alcohol）：

```
CH₂=CH₂  +  H₂O  →(H⁺)  CH₃CH₂OH
（乙烯 ethylene）            （乙醇 ethanol）
```

這是工業生產乙醇的重要方法之一。

### 6.5 炔烴的加成反應

炔烴含有**兩個 π 鍵**，可進行兩次加成反應：

```
第一步（加一個 HBr）：
CH₃C≡CH  +  HBr  →  CH₃CBr=CH₂

第二步（再加一個 HBr）：
CH₃CBr=CH₂  +  HBr  →  CH₃CBr₂CH₃
```

### 6.6 聚合反應（Polymerization）

某些烯烴在特定條件下可進行**聚合反應（polymerization）**，將大量單體（monomer）連接成高分子聚合物（polymer）。詳細內容見 21.5 節。

```
n CH₂=CH₂  →(催化劑 catalyst)  –(CH₂–CH₂)ₙ–
  （乙烯）                        （聚乙烯 polyethylene）
```

## 七、環烯烴（Cyclic Alkenes）

烯烴和炔烴也可以形成環狀結構：

```
環己烯（cyclohexene）：   六員環，含一個 C=C 雙鍵

4-甲基環戊烯（4-methylcyclopentene）：
  五員環，含一個 C=C，第 4 號碳接甲基
```

**環烯烴命名規則**：
- 環上雙鍵的碳編號固定為 **1 和 2**
- 從雙鍵碳開始，朝**最靠近取代基（substituent）** 的方向編號

## 八、課本例題精講

### 例題 1（課本 Example 21.5a）

**題目**：命名下列分子：

```
        H       CH₃
         \     /
          C = C
         /     \
  CH₃CH₂CH      H
         |
         CH₃
```

**解析步驟：**

步驟一：找最長含雙鍵的碳鏈

從 CH₃（最右上）→ C（雙鍵右端）→ C（雙鍵左端）→ CH（帶甲基）→ CH₂ → CH₃（最左下）= **6 碳鏈** → 主鏈為己烯（hexene）

步驟二：編號（從最靠近雙鍵的端點開始）

```
         H        CH₃
          \      /
           C  = C
          /      \
CH₃CH₂CH          H
         |
         CH₃
6    5  4    3  2   1
```

雙鍵在 C2–C3 之間 → **2-hexene**

步驟三：確認取代基

C4 上有一個 **methyl（甲基）** → **4-methyl**

步驟四：確認順反

- C2（左端）：接 H 和 CH₃ → 兩個不同基團 ✓
- C3（右端）：接 H 和 CH₂CH₂CH₃ → 兩個不同基團 ✓

觀察兩個較大的基團（CH₃ 在 C2，CH₂… 鏈在 C3）是否在同側：H 和 CH₃ 分別在雙鍵上下，**H 在同側** → 兩個烷基（CH₃ 和 4-methylpentyl）在異側 → **trans（反式）**

**答：4-methyl-trans-2-hexene（4-甲基-反-2-己烯）**

---

### 例題 2（課本 Example 21.5b）

**題目**：命名下列分子：

```
CH₃CH₂C≡C–CH–CH₂CH₃
              |
              CH₂
              |
              CH₃
```

**解析步驟：**

步驟一：找最長含三鍵的碳鏈

沿 CH₃CH₂–C≡C–CH–CH₂CH₃ = **7 碳鏈** → 主鏈為庚炔（heptyne）

步驟二：編號（從最靠近三鍵的一端）

```
CH₃CH₂C≡C–CH–CH₂CH₃
            |
            CH₂
            |
            CH₃
1   2  3  4  5   6   7
```

三鍵在 C3–C4 之間 → **3-heptyne**

步驟三：確認取代基

C5 上有一個 –CH₂CH₃（乙基 ethyl） → **5-ethyl**

**答：5-ethyl-3-heptyne（5-乙基-3-庚炔）**

## 九、進階例題（選自課後習題）

### 進階例題 A（Exercise 21，難度：中）

**題目**：下列哪些化合物（Exercise 13 中）具有順反異構物（cis-trans isomerism）？

Exercise 13 的化合物列舉（節錄相關者）：

```
(a) CH₂=CHCH₂CH₃           → 1-butene
(c) CH₃CH₂CH=CHCH(CH₃)CH(CH₃)CH₃
(d) CH₂=C(CH₃)CH(CH₂CH₃)(CH₃)CH₃ （略）
(e) 環己烯衍生物（略）
```

**解析方法**：對每個雙鍵，逐一檢查兩端碳是否各接兩個不同基團。

**(a) CH₂=CHCH₂CH₃（1-butene）**

```
C1（=CH₂）：接兩個 H → 相同 → 不符合條件
```
→ **無**順反異構物

**(c) CH₃CH₂CH=CHCH(CH₃)₂（3-甲基-3-己烯，簡化版）**

假設結構為 CH₃CH₂CH=CHCH₃：
```
C3：接 H 和 CH₂CH₃（不同）✓
C4：接 H 和 CH₃（不同）✓
```
→ **有** cis-trans 異構物

**判斷原則小結：**

> C=C 的某端若為 **=CH₂**（接兩個 H），則該化合物**無**順反異構物。
> 若兩端碳各接的兩個基團均不同，則**有**順反異構物。

### 進階例題 C（Exercise 29 + 延伸，難度：高）

**題目**：畫出 C₅H₁₀ 的所有結構異構物（忽略環狀）。其中哪些具有順反異構物？

**解析：**

C₅H₁₀ 符合烯烴通式 CₙH₂ₙ（n=5），含一個雙鍵，列出所有雙鍵位置和分支情況：

**主鏈為戊烯（pentene）：**

```
1. CH₂=CHCH₂CH₂CH₃          →  1-pentene（1-戊烯）
2. CH₃CH=CHCH₂CH₃            →  2-pentene（2-戊烯）
3. CH₃CH₂CH=CHCH₃            →  與 2 相同（反方向寫法）
```

確認：2-pentene 就是第 2 種，不是新異構物。

**主鏈為丁烯，帶甲基取代基（methyl substituent）：**

```
4.   CH₂=C(CH₃)CH₂CH₃        →  2-methyl-1-butene（2-甲基-1-丁烯）

5.   CH₂=CHCH(CH₃)CH₃        →  3-methyl-1-butene（3-甲基-1-丁烯）

6.   CH₃C(CH₃)=CHCH₃         →  2-methyl-2-butene（2-甲基-2-丁烯）
```

共 **5 種** 結構異構物（1-pentene、2-pentene、2-methyl-1-butene、3-methyl-1-butene、2-methyl-2-butene）。

**哪些有順反異構物？**

逐一檢查：

| 化合物 | C=C 兩端碳的基團 | 有順反異構物？ |
|--------|-----------------|---------------|
| 1-pentene | C1 = CH₂（兩個 H 相同） | **無** |
| 2-pentene | C2：H、CH₃（不同）✓；C3：H、CH₂CH₃（不同）✓ | **有** |
| 2-methyl-1-butene | C1 = CH₂（兩個 H 相同） | **無** |
| 3-methyl-1-butene | C1 = CH₂（兩個 H 相同） | **無** |
| 2-methyl-2-butene | C2：CH₃、CH₃（相同） | **無** |

**答：只有 2-pentene 具有 cis-trans 異構物（cis-2-pentene 和 trans-2-pentene）。**

### 進階例題 D（Exercise 58，難度：高，Markovnikov 規則）

**題目**：以下反應的主要有機產物為何？
- (a) CH₃CH₂CH=CH₂ + H₂O →(H⁺)
- (b) CH₃CH₂CH=CH₂ + HBr →

**背景知識：馬氏規則（Markovnikov's Rule）**

當 HX 或 H₂O 加成至不對稱烯烴時：

> **H 加到含氫較多的碳（more substituted carbon），X 或 OH 加到含氫較少的碳**

理由：此方向會形成較穩定的碳正離子（carbocation）中間體（intermediate），能量上更有利。

**(a) CH₃CH₂CH=CH₂ + H₂O →(H⁺)**

```
C3（=CH–）：接 1 個 H  ←  含氫較少
C4（=CH₂）：接 2 個 H  ←  含氫較多

根據 Markovnikov：H 加到 C4，OH 加到 C3
```

**主要產物**：

```
CH₃CH₂CH(OH)CH₃     →  2-butanol（2-丁醇，仲醇 secondary alcohol）
```

**(b) CH₃CH₂CH=CH₂ + HBr →**

```
同理：H 加到 C4，Br 加到 C3
```

**主要產物**：

```
CH₃CH₂CHBrCH₃     →  2-bromobutane（2-溴丁烷）
```

> **補充說明**：次要產物（minor product）是 H 加到 C3、Br 加到 C4，生成 1-bromobutane（1-溴丁烷）。主要產物（major product）在考試中均以 Markovnikov 方向為準。

## 十、本節重點整理

| 概念 | 要點 |
|------|------|
| 烯烴通式 | CₙH₂ₙ（非環狀、一個雙鍵） |
| 炔烴通式 | CₙH₂ₙ₋₂（非環狀、一個三鍵） |
| 混成方式 | 烯烴：sp²（120°）；炔烴：sp（180°） |
| C=C 雙鍵組成 | 1 個 σ 鍵 + 1 個 π 鍵 |
| C≡C 三鍵組成 | 1 個 σ 鍵 + 2 個 π 鍵 |
| 順反異構物（cis-trans isomerism） | 需雙鍵兩端碳各接不同基團；炔烴無此現象 |
| 主要反應 | 加成反應（addition reaction）：氫化 hydrogenation、鹵化 halogenation、加水 hydration、聚合 polymerization |
| Markovnikov 規則 | H 加到含 H 較多的碳，X/OH 加到含 H 較少的碳 |
| 烯烴 vs. 苯 | 烯烴偏向加成反應；苯（因離域 π 電子）偏向取代反應（詳見 21.3） |
