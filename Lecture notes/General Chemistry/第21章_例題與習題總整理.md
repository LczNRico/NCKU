<details>
<summary>解析</summary>

### 【題 2-1】烯烴命名（課本 Example 21.5a）

命名下列分子（含順反標示）：

```
        H       CH₃
         \     /
          C = C
         /     \
  CH₃CH₂CH      H
         |
         CH₃
```

<details>
<summary>解析</summary>

步驟一：最長含雙鍵碳鏈 = 6 碳 → hexene

步驟二：從含雙鍵最近端編號

```
6    5  4    3  2   1

         |
         CH₃

雙鍵在 C2–C3 → **2-hexene**

步驟三：C4 有 methyl（甲基）取代基（substituent）→ **4-methyl**

步驟四：順反判斷

- C2 端：H 和 CH₃（不同）✓
- C3 端：H 和 CH₂…鏈（不同）✓
- 兩個 H 在雙鍵同側 → 兩個大基團在異側 → **trans（反式）**

**答：4-methyl-trans-2-hexene**
</details>

### 【題 2-3】順反異構物的判斷（Exercise 21）★★

判斷下列化合物是否具有順反異構物（cis-trans isomerism），並說明原因：

(a) CH₂=CHCH₂CH₃（1-butene）

(b) CH₃CH=CHCH₃（2-butene）

(c) CH₂=C(CH₃)₂（2-methylpropene）

<details>
<summary>解析</summary>

**判斷條件**：C=C 兩端碳各自接的兩個基團必須均不同。

**(a) 1-butene：**
```
C1（=CH₂）：接兩個 H → 相同 → 條件不符
```
→ **無**順反異構物

**(b) 2-butene：**
```
C2：接 H 和 CH₃（不同）✓
C3：接 H 和 CH₃（不同）✓
```
→ **有** cis-2-butene 和 trans-2-butene

**(c) 2-methylpropene：**
```
C2（=C）：接兩個 CH₃ → 相同 → 條件不符
```
→ **無**順反異構物

**規則小結**：若雙鍵某端為 =CH₂（接兩個 H）或兩個相同取代基，則無順反異構物。
</details>

(b) trans-2-butene

          \        /
           C  =  C
          /        \
         H          CH₃
```
</details>

### 【題 2-5】C₅H₁₀ 的所有烯烴異構物（Exercise 29）★★★

畫出 C₅H₁₀ 的所有非環狀結構異構物，並指出哪些具有 cis-trans 異構物。

<details>
<summary>解析</summary>

C₅H₁₀ = 烯烴通式 CₙH₂ₙ（n=5），含一個雙鍵：

```
1. CH₂=CHCH₂CH₂CH₃          →  1-pentene
2. CH₃CH=CHCH₂CH₃            →  2-pentene
3. CH₂=C(CH₃)CH₂CH₃          →  2-methyl-1-butene
4. CH₂=CHCH(CH₃)CH₃          →  3-methyl-1-butene
5. CH₃C(CH₃)=CHCH₃           →  2-methyl-2-butene
```

共 **5 種**結構異構物。

**順反異構物判斷：**

| 化合物 | 判斷 |
|--------|------|

| 3-methyl-1-butene | C1 = CH₂（兩個 H）→ **無** |

### 【題 2-6】Markovnikov 規則應用（Exercise 58）★★★

給出下列反應的**主要有機產物（major organic product）**：

(a) CH₃CH₂CH=CH₂ + H₂O →(H⁺)

(b) CH₃CH₂CH=CH₂ + HBr →

<details>
<summary>解析</summary>

**馬氏規則（Markovnikov's Rule）**：H 加到含氫較多的碳（more substituted carbon），X 或 OH 加到含氫較少的碳。

**(a) + H₂O：**
```
C3（=CH–）：1個H → 含氫較少 ← OH 加這裡
C4（=CH₂）：2個H → 含氫較多 ← H 加這裡
```
主要產物：CH₃CH₂CH(OH)CH₃ = **2-butanol（2-丁醇，仲醇 secondary alcohol）**

**(b) + HBr：**
同理：Br 加到 C3，H 加到 C4

主要產物：CH₃CH₂CHBrCH₃ = **2-bromobutane（2-溴丁烷）**

> 次要產物（minor product）：1-bromobutane，由 H 加到 C3、Br 加到 C4 而來。
</details>

### 【題 3-3】二氯苯與三氯苯的異構物分析（Exercise 33）★★★

(a) 說明 o-、m-、p-二氯苯的結構差異

(b) 三氯苯（trichlorobenzene）共有幾種異構物？

(c) 已知苯環上第一個 Cl 取代基（substituent）會導引下一個 Cl 優先進入 ortho 或 para 位，m-dichlorobenzene 的合成是否困難？

(d) 哪種三氯苯最難合成？

<details>
<summary>解析</summary>

**(a) 二氯苯三種異構物：**
```
o-dichlorobenzene：1,2-二氯苯（兩個 Cl 相鄰）
m-dichlorobenzene：1,3-二氯苯（Cl 間隔一個 C）
p-dichlorobenzene：1,4-二氯苯（Cl 正對面）
```
補充：目前最常見防蟲劑（mothballs）為 p-dichlorobenzene。

**(b) 三氯苯的異構物：**
```
1,2,3-trichlorobenzene（三個相鄰）
1,2,4-trichlorobenzene（兩個相鄰，一個間隔）
1,3,5-trichlorobenzene（對稱，每隔一個碳）
```
**共 3 種**

**(c) m-dichlorobenzene 的合成難度：**
第一個 Cl 的導向效應（directing effect）使後續取代基進入 ortho/para，**不進入 meta**。因此直接鹵化（halogenation）無法得到 m-dichlorobenzene，需要設計特別的合成路線。→ **合成困難**

**(d) 最難合成的三氯苯：**
**1,3,5-trichlorobenzene（均三氯苯）** 最難合成，因每個 Cl 都在 meta 位，違反 Cl 取代基的 ortho/para 導向規則，需完全不同的策略。
</details>

### 【題 4-2】C₅H₁₂O 的醇與醚（Exercise 43）★★★

(a) 命名所有分子式為 C₅H₁₂O 的醇（alcohols），共幾種？

(b) 分子式同為 C₅H₁₂O 的醚（ethers）有幾種？

<details>
<summary>解析</summary>

**(a) C₅H₁₂O 的醇（共 8 種）：**

主鏈 5 碳：
```
1. CH₃CH₂CH₂CH₂CH₂OH       → 1-pentanol（伯醇）
2. CH₃CH₂CH₂CHOHCH₃        → 2-pentanol（仲醇）
3. CH₃CH₂CHOHCH₂CH₃        → 3-pentanol（仲醇）
```

主鏈 4 碳（帶甲基）：
```
4. (CH₃)₂CHCH₂CH₂OH        → 3-methyl-1-butanol（伯醇）
5. CH₃CH₂C(CH₃)(OH)CH₃     → 2-methyl-2-butanol（叔醇）
6. (CH₃)₂CHCHOHCH₃         → 3-methyl-2-butanol（仲醇）
7. (CH₃)₂CHCH₂OH（主鏈3+CH₃）→ 2-methyl-1-butanol（伯醇）
```

主鏈 3 碳（帶兩個甲基）：
```
8. (CH₃)₃CCH₂OH             → 2,2-dimethyl-1-propanol（伯醇）
```

**共 8 種醇。**

**(b) C₅H₁₂O 的醚（共 6 種）：**

```
CH₃–O–CH₂CH₂CH₂CH₃         → 甲基正丁基醚（methyl n-butyl ether）
CH₃–O–CH(CH₃)CH₂CH₃        → 甲基仲丁基醚（methyl sec-butyl ether）
CH₃–O–C(CH₃)₂CH₃           → 甲基叔丁基醚（methyl tert-butyl ether，MTBE）
CH₃CH₂–O–CH₂CH₂CH₃        → 乙基丙基醚（ethyl propyl ether）
CH₃CH₂–O–CH(CH₃)₂         → 乙基異丙基醚（ethyl isopropyl ether）
```

另可驗證是否有對稱醚（symmetric ether）：CH₃CH₂CH₂CH₂CH₂–OH 無對稱醚。

**共 6 種醚（ethers）。**
</details>

### 【題 4-3】醇的氧化產物（Exercise 61）★★

給出下列各醇氧化（oxidation）後的產物結構，並命名：

(a) 3-methyl-1-butanol（3-甲基-1-丁醇）

(b) 3-methyl-2-butanol（3-甲基-2-丁醇）

(c) 2-methyl-2-butanol（2-甲基-2-丁醇）

<details>
<summary>解析</summary>

**規則：**
- 伯醇（primary alcohol）→ 醛（aldehyde）→（進一步氧化）羧酸（carboxylic acid）
- 仲醇（secondary alcohol）→ 酮（ketone）
- 叔醇（tertiary alcohol）→ 不反應（no reaction）

**(a) 3-methyl-1-butanol = (CH₃)₂CHCH₂CH₂OH → 伯醇（primary alcohol）**
```
→(第一步) (CH₃)₂CHCH₂CHO        3-甲基丁醛（3-methylbutanal）
→(進一步) (CH₃)₂CHCH₂COOH      3-甲基丁酸（3-methylbutanoic acid）
```

**(b) 3-methyl-2-butanol = (CH₃)₂CHCHOHCH₃ → 仲醇（secondary alcohol）**
```
→(氧化) (CH₃)₂CHCOCH₃           3-甲基-2-丁酮（3-methyl-2-butanone）
```

**(c) 2-methyl-2-butanol = CH₃C(OH)(CH₃)CH₂CH₃ → 叔醇（tertiary alcohol）**
```
→ 不反應（no reaction）
```
</details>

### 【題 4-4】酯化反應與命名（Exercise 67）★★

完成下列酯化反應（esterification），並命名產物：

(a) CH₃COOH + CH₃OH →(H⁺)

(b) HCOOH + CH₃CH₂CH₂OH →(H⁺)

<details>
<summary>解析</summary>

**(a) 乙酸（acetic acid）+ 甲醇（methanol）：**

CH₃COOH + CH₃OH →(H⁺) CH₃COOCH₃ + H₂O
```

命名：methyl（來自甲醇）+ ethanoate（來自乙酸 ethanoic acid）

**(b) 甲酸（formic acid / methanoic acid）+ 1-丙醇（1-propanol）：**

HCOOH + HOCH₂CH₂CH₃ →(H⁺) HCOO–CH₂CH₂CH₃ + H₂O
```
產物：**甲酸正丙酯（propyl methanoate / propyl formate）**
</details>

### 【題 4-5】結構異構物正誤判斷（Exercise 50 節錄）★★★

判斷下列敘述是否正確，若錯請說明原因：

(a) CH₃CH₂CH₂COOCH₃ 是戊酸（pentanoic acid）的結構異構物（structural isomer）

(b) CH₃CH₂OCH₂CH₂CH₃ 是 2-pentanol 的結構異構物

(c) 三甲胺（trimethylamine，(CH₃)₃N）是丁胺（butylamine，CH₃CH₂CH₂CH₂NH₂）的結構異構物

<details>
<summary>解析</summary>

**(a)：**
CH₃CH₂CH₂COOCH₃ 分子式：C₅H₁₀O₂（酯 ester）
pentanoic acid = CH₃CH₂CH₂CH₂COOH，分子式：C₅H₁₀O₂（羧酸 carboxylic acid）
分子式相同，鍵結方式不同 → **正確，兩者互為結構異構物**

**(b)：**
CH₃CH₂OCH₂CH₂CH₃ 分子式：C₅H₁₂O（醚 ether）
2-pentanol 分子式：C₅H₁₂O（醇 alcohol）
分子式相同，鍵結方式不同 → **正確，兩者互為結構異構物**

**(c)：**
trimethylamine = (CH₃)₃N，分子式：C₃H₉N
butylamine = C₄H₁₁N
分子式**不同** → **錯誤，兩者不是結構異構物**
</details>

# 21.5　聚合物（Polymers）

### 【題 5-1】辨識聚合物單體與類型（課本 Table 21.7 改編）★★

指出下列聚合物的單體（monomer），並說明屬於加成聚合（addition polymerization）或縮合聚合（condensation polymerization），以及均聚物（homopolymer）或共聚物（copolymer）：

(a) Teflon，重複單元（repeating unit）：–(CF₂–CF₂)ₙ–

(b) Dacron，重複單元：–[O–CH₂CH₂–O–CO–C₆H₄–CO]ₙ–

<details>
<summary>解析</summary>

**(a) Teflon：**
- 重複單元：–CF₂–CF₂–
- 單體（monomer）：**CF₂=CF₂（四氟乙烯 tetrafluoroethylene）**
- C=C 雙鍵開環，無副產物（by-products）→ **加成聚合（addition polymerization）**
- 一種單體 → **均聚物（homopolymer）**

**(b) Dacron：**
- 含酯鍵（ester bonds）連接
- 單體：**乙二醇（ethylene glycol，HOCH₂CH₂OH）** 和 **對苯二甲酸（p-terephthalic acid）**
- 每次連接釋出 H₂O → **縮合聚合（condensation polymerization）**
- 兩種單體 → **共聚物（copolymer）**，屬聚酯（polyester）
</details>

### 【題 5-2】形成聚合物的單體結構要求（Exercise 71）★★★

(a) 形成**均聚物聚酯（homopolymer polyester）** 的單體需具備哪些結構特徵？

(b) 形成**共聚物聚醯胺（copolymer polyamide）** 如尼龍（nylon）的兩種單體各需具備哪些結構特徵？

(c) 某單體若能同時形成加成聚合物（addition polymer）和縮合聚合物（condensation polymer），需具備哪些結構？

<details>
<summary>解析</summary>

**(a) 均聚物聚酯：**
酯鍵（ester bond）由 –COOH 和 –OH 縮合形成。若用一種單體，則該單體必須**同時具有 –COOH 和 –OH**：

```
例：乳酸（lactic acid）：HO–CH(CH₃)–COOH
   羥基酸（hydroxy acid）：HO–R–COOH
```

**(b) 共聚物聚醯胺：**
醯胺鍵（amide bond）由 –NH₂ 和 –COOH 縮合形成。需兩種單體：

```
單體 A：H₂N–R–NH₂（二胺 diamine，兩端均為 –NH₂）
單體 B：HOOC–R'–COOH（二元酸 diacid，兩端均為 –COOH）

例：已二胺 + 己二酸 → 尼龍
```

**(c) 兼具兩種聚合能力的單體：**
需同時具備：
- **C=C 雙鍵（double bond）**：供加成聚合（addition polymerization）
- **兩個可縮合的官能基（functional groups）**（如 –OH 和 –COOH）：供縮合聚合（condensation polymerization）
</details>

### 【題 5-3】異戊二烯與天然橡膠（Exercise 78）★★★

(a) 給出異戊二烯（isoprene，CH₂=C(CH₃)–CH=CH₂）的系統命名

(b) 天然橡膠（natural rubber）中雙鍵為 cis 構型，杜仲膠（gutta percha）中為 trans 構型。畫出各三個重複單元的結構，並標明構型。兩者性質有何差異？

<details>
<summary>解析</summary>

**(a) 系統命名：**

主鏈 4 碳，C1–C2 和 C3–C4 各有雙鍵，C2 有 CH₃ 取代基（substituent）

**2-甲基-1,3-丁二烯（2-methyl-1,3-butadiene）**

**(b) 結構與性質：**

聚合後重複單元為 –CH₂–C(CH₃)=CH–CH₂–

**天然橡膠（cis）：**
```
     CH₃    CH₂–（鏈）
       \    /
        C=C            ← cis：較大基團在同側
       /    \
–CH₂        H
```

**杜仲膠（trans）：**
```
     CH₃    H
       \    /
        C=C            ← trans：較大基團在異側
       /    \
–CH₂        CH₂–（鏈）
```

**性質差異：**

| 特性 | 天然橡膠（cis） | 杜仲膠（trans） |
|------|----------------|----------------|
| 鏈形狀 | 彎曲（curved） | 較伸直（extended） |
| 結晶度 | 低 | 較高 |
| 彈性（elasticity） | 高 | 低（偏硬） |
| 用途 | 輪胎（tires）、橡皮擦 | 早期高爾夫球、牙科材料 |
</details>

### 【題 6-1】三肽序列計算（課本 Example 21.7）★

寫出由酪胺酸（tyrosine, tyr）、組胺酸（histidine, his）和半胱胺酸（cysteine, cys）三種胺基酸（amino acids）組成的所有可能三肽（tripeptides）序列。

<summary>解析</summary>

```
tyr-his-cys     his-tyr-cys     cys-tyr-his
tyr-cys-his     his-cys-tyr     cys-his-tyr
```

**共 6 種**。（N 端在左，C 端在右）

### 【題 6-2】二肽結構繪製（Exercise 95）★★

畫出由絲胺酸（serine, Ser）和丙胺酸（alanine, Ala）組成的兩種二肽（dipeptides）的結構。

<details>
<summary>解析</summary>

絲胺酸（Ser）R 基 = –CH₂OH；丙胺酸（Ala）R 基 = –CH₃

兩種排列（N 端在左）：

**ser-ala：**
```
H₂N–CH(CH₂OH)–CO–NH–CH(CH₃)–COOH
         ↑ 胜肽鍵（peptide bond）
```

**ala-ser：**
```
H₂N–CH(CH₃)–CO–NH–CH(CH₂OH)–COOH
```

兩者分子式相同，但 N 端和 C 端的胺基酸不同，為兩種不同的化合物。
</details>

### 【題 6-3】蛋白質側鏈的作用力分析（Exercise 99）★★★

以下側鏈（side chains）之間可形成哪種作用力，有助於維持蛋白質的三級結構（tertiary structure）？

(a) 半胱胺酸（cysteine）和半胱胺酸（cysteine）

(b) 麩醯胺酸（glutamine, Gln）和絲胺酸（serine, Ser）

(c) 麩胺酸（glutamic acid, Glu）和離胺酸（lysine, Lys）

(d) 脯胺酸（proline, Pro）和白胺酸（leucine, Leu）

<details>
<summary>解析</summary>

**(a) Cys + Cys：**
兩者 R 基均含 **–SH（硫氫基 thiol group）**，氧化後形成：
```
–CH₂–SH + HS–CH₂– →(氧化) –CH₂–S–S–CH₂–
```
→ **雙硫鍵（disulfide bond）**，共價鍵（covalent bond），是三級結構中最強的側鏈作用力

**(b) Gln + Ser：**
Gln R 基含 –CONH₂（醯胺基 amide group）；Ser R 基含 –OH（羥基 hydroxyl group）
兩者均為極性側鏈（polar side chains）→ 形成 **氫鍵（hydrogen bonds）**：
```
–CONH₂ ⋯ HO–
```

**(c) Glu + Lys：**
Glu R 基在生理 pH 下帶 **–COO⁻（負電）**；Lys R 基帶 **–NH₃⁺（正電）**
→ 形成 **離子鍵（ionic bond）/ 鹽橋（salt bridge）**：
```
–COO⁻ ⋯ ⁺H₃N–
```

**(d) Pro + Leu：**
兩者 R 基均為**非極性烴基（nonpolar hydrocarbon groups）**
→ **色散力（London dispersion forces）/ 疏水性作用（hydrophobic interactions）**
</details>

### 【題 6-4】DNA 互補序列與蛋白質合成（Exercise 119 + 123）★★★

(a) 部分 DNA 序列為 **G-G-T-C-T-A-T-A-C**，寫出其互補序列（complementary sequence）。

(b) 已知 mRNA 密碼子（codons）：Trp = UGG；Glu = GAA 或 GAG；Phe = UUU 或 UUC；Met = AUG。
    給出編碼三肽 **trp-glu-phe-met** 的一條 DNA 編碼序列（coding strand）。

<details>
<summary>解析</summary>

**(a) 互補序列：**

配對規則：A-T（互補）；G-C（互補）

```
原始序列（5'→3'）：G – G – T – C – T – A – T – A – C
互補序列（3'→5'）：C – C – A – G – A – T – A – T – G
```

從 5'→3' 方向書寫互補鏈：**C-C-A-G-A-T-A-T-G**

**(b) DNA 編碼序列：**

步驟一：選定 mRNA 密碼子序列（codon sequence）
```
mRNA（5'→3'）：UGG – GAA – UUU – AUG
                Trp   Glu   Phe   Met
```

步驟二：DNA 編碼鏈（coding strand）與 mRNA 相同，但 U 改回 T
```
DNA 編碼鏈（5'→3'）：TGG – GAA – TTT – ATG
```

注意：Glu 可用 GAA 或 GAG；Phe 可用 UUU 或 UUC，因此共有 **2×2 = 4 種**可能的 DNA 序列，此為其中一種。
</details>
