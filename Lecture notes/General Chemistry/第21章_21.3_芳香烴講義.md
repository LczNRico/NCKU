# 第 21 章　有機與生化分子
## 21.3　芳香烴（Aromatic Hydrocarbons）

---

## 一、苯（Benzene）的結構

### 1.1 基本特徵

苯（benzene）分子式為 **C₆H₆**，是最簡單的芳香烴（aromatic hydrocarbon）。其結構特徵：

- 六個碳原子形成**平面環（planar ring）**
- 所有鍵角均為 **120°**
- 所有 C–C 鍵**等長等強**（鍵長介於單鍵與雙鍵之間，約 139 pm）

### 1.2 鍵結描述：局域電子模型（Localized Electron Model）

在局域電子模型（localized electron model）中，苯用**共振結構（resonance structures）** 來描述：

```
     （結構一）          （結構二）
      交替單雙鍵    ↔     交替雙單鍵

        H               H
        |               |
   H–C   C–H       H–C   C–H
      ‖   ‖             ‖   ‖
   H–C   C–H  ↔   H–C   C–H
        |               |
        H               H
```

這兩個共振結構（resonance structures）的平均即為苯真實的電子分布，六個 C–C 鍵完全等價。

### 1.3 鍵結描述：分子軌域模型（Molecular Orbital Model）

更精確的描述：

- 每個碳採取 **sp² 混成（sp² hybridization）**
- sp² 軌域形成 C–C **σ 鍵（sigma bonds）** 和 C–H **σ 鍵**，構成平面骨架
- 每個碳剩餘的一個 **2p 軌域（2p orbital）** 垂直於環平面，六個 2p 軌域側向重疊，形成**離域 π 電子系統（delocalized π electron system）**

```
圖示：

      π 電子雲（在環平面上下）
      ↑↑↑↑↑↑
  ────────────────
  六個碳的 sp² 骨架
  ────────────────
      ↓↓↓↓↓↓
```

- 離域 π 電子（delocalized π electrons）分散在整個環上，不屬於任何一對碳原子
- 通常用**環內圓圈（circle inside ring）** 代表離域 π 電子系統

```
    苯的三種表示方式：

   （共振結構一）  （共振結構二）   （圓圈表示）
       ／‾＼          ／‾＼           ／‾＼
      |  ‖  |    ↔   |     |         |  ○  |
       ＼_／          ＼_／           ＼_／
```

## 二、苯的特殊穩定性

### 2.1 為何苯不像一般烯烴進行加成反應？

一般不飽和烴（如烯烴 alkenes）含有局域 π 鍵，容易發生**加成反應（addition reactions）**。但苯的 π 電子**完全離域（fully delocalized）**，形成高度穩定的閉合電子系統，稱為**芳香性（aromaticity）**。

破壞這個離域系統需要大量額外能量，因此苯偏好**取代反應（substitution reactions）**（保留環的完整），而非加成反應。

### 2.2 穩定性的量化：共振能（Resonance Energy）

實驗測定苯的氫化熱（heat of hydrogenation）遠小於三個獨立 C=C 雙鍵的預期值，差值約為 **150 kJ/mol**，即為苯的**共振穩定化能（resonance stabilization energy）**，又稱**離域能（delocalization energy）**。

## 三、苯的取代反應（Substitution Reactions of Benzene）

苯在適當催化劑（catalyst）下，可以讓環上的 H 被其他原子或基團（group）取代，但**環的結構保持完整**：

### 3.1 鹵化反應（Halogenation）

需要路易斯酸催化劑（Lewis acid catalyst）如 **FeCl₃ 或 AlCl₃**：

```
苯 + Cl₂  →(FeCl₃)  氯苯（chlorobenzene）+ HCl

苯 + Br₂  →(FeBr₃)  溴苯（bromobenzene）+ HBr
```

### 3.2 硝化反應（Nitration）

需要**濃硝酸（concentrated HNO₃）** 與**濃硫酸（concentrated H₂SO₄）** 的混合物（H₂SO₄ 作為催化劑）：

```
苯 + HNO₃  →(H₂SO₄)  硝基苯（nitrobenzene）+ H₂O
```

### 3.3 烷基化反應（Alkylation，Friedel-Crafts 反應）

需要 **AlCl₃** 作為路易斯酸催化劑（Lewis acid catalyst），以鹵烷（alkyl halide）為試劑：

```
苯 + CH₃Cl  →(AlCl₃)  甲苯（toluene / methylbenzene）+ HCl
```

### 3.4 取代反應 vs. 加成反應的比較

| 特性 | 一般烯烴（alkenes） | 苯（benzene） |
|------|--------------------|--------------------|
| π 電子狀態 | 局域（localized） | **離域（delocalized）** |
| 主要反應類型 | 加成反應（addition） | **取代反應（substitution）** |
| 反應後 π 系統 | 消失 | **保留** |
| 反應條件 | 不需特殊催化劑 | 需路易斯酸催化劑（Lewis acid catalyst） |

> **關鍵概念**：苯偏好取代反應的根本原因，在於加成反應會破壞離域 π 系統（delocalized π system），損失共振穩定化能；取代反應則保留了環的芳香性（aromaticity）。

## 四、苯衍生物（Benzene Derivatives）的命名

### 4.1 一取代苯（Monosubstituted Benzene）

直接在「苯」前加取代基（substituent）名稱：

```
甲苯（toluene / methylbenzene）：苯環 + –CH₃
氯苯（chlorobenzene）：苯環 + –Cl
硝基苯（nitrobenzene）：苯環 + –NO₂
```

> 甲苯（toluene）是氯苯等的常用俗名，系統名為 methylbenzene。

### 4.2 二取代苯（Disubstituted Benzene）的三種位置關係

當苯環上有**兩個取代基（substituents）** 時，有三種不同的相對位置：

| 前綴 | 縮寫 | 意義 | 取代基位置 |
|------|------|------|----------|
| 鄰位（ortho-） | o- | 相鄰（adjacent） | 1,2- |
| 間位（meta-） | m- | 間隔一個碳（one carbon between） | 1,3- |
| 對位（para-） | p- | 正對面（opposite） | 1,4- |

```
      Cl              Cl              Cl
       |               |               |
   ／‾＼          ／‾＼           ／‾＼
  |     |         |     |          |     |
   ＼_／           ＼_／            ＼_／
       |                  |                    |
      Cl（1,2-）         Cl（1,3-）           Cl（1,4-）
   鄰二氯苯            間二氯苯             對二氯苯
  o-dichlorobenzene   m-dichlorobenzene   p-dichlorobenzene
```

### 4.3 多取代苯的 IUPAC 命名

用數字標示各取代基（substituents）位置，取代基按字母順序（alphabetical order）排列：

```
範例：1,2-二溴苯（1,2-dibromobenzene）= o-dibromobenzene

      Br
       |
   ／‾＼
  |     |
   ＼_／
       |
      Br

1 號碳接第一個 Br，2 號碳接第二個 Br
```

### 4.4 苯基（Phenyl Group）

當苯環作為取代基（substituent）連接到其他碳鏈時，稱為**苯基（phenyl group）**，縮寫為 **Ph–** 或 **C₆H₅–**：

```
範例：4-chloro-2-phenylhexane
      （己烷主鏈，2 號碳接苯基，4 號碳接氯）
```

## 五、更複雜的芳香系統（More Complex Aromatic Systems）

苯環可以互相「稠合（fused）」，形成多環芳香烴（polycyclic aromatic hydrocarbons, PAHs）：

| 結構 | 名稱 | 用途或效應 |
|------|------|-----------|
| 兩個稠合苯環 | 萘（naphthalene） | 舊式防蟲劑（mothballs） |
| 三個直線排列苯環 | 蒽（anthracene） | 染料（dyes） |
| 三個成角排列苯環 | 菲（phenanthrene） | 染料、爆炸物、藥物合成 |
| 五個稠合苯環 | 3,4-苯並芘（3,4-benzpyrene） | 活性致癌物（active carcinogen），存在於煙霧（smoke）和煙霧污染（smog）中 |

> **健康提醒**：多環芳香烴（PAHs），尤其是 3,4-苯並芘，是香菸煙霧和燒烤食物中的重要致癌物（carcinogen）。

## 六、課本例題精講

### 例題 1：命名取代苯（改編自課本 Figure 21.12）

**題目**：說明以下化合物的系統命名與俗名：

**(a)**
```
   CH₃
    |
  ／‾＼
 |     |
  ＼_／
    |
   Cl
```

**解析：**

- 主體為苯環，取代基（substituents）為 CH₃（甲基 methyl）和 Cl（氯 chloro）
- CH₃ 在 1 號碳，Cl 在 3 號碳（間位關係 meta）
- 系統名：**3-chloro-1-methylbenzene**（按字母序：chloro 先於 methyl）
  但甲苯（toluene）作為母體，俗名更常用：**m-chlorotoluene（間-氯甲苯）**
- 也可寫作：**3-chlorotoluene**

**(b)**
```
   NO₂
    |
  ／‾＼
 |     |
  ＼_／
    |
   Br
```

**解析：**

- 取代基（substituents）為 NO₂（硝基 nitro）和 Br（溴 bromo）
- 兩者為間位（meta，1,3-位）關係
- 系統名：**1-bromo-3-nitrobenzene**（按字母序）
- 俗名：**m-bromonitrobenzene（間-溴硝基苯）**

## 七、進階例題（選自課後習題）

### 進階例題 A（Exercise 16，難度：中）

**題目**：畫出下列芳香烴的結構式：
- (a) o-ethyltoluene（鄰-乙基甲苯）
- (b) p-di-tert-butylbenzene（對-二叔丁基苯）
- (c) 1-phenyl-2-butene

**(a) o-ethyltoluene**

步驟一：母體為甲苯（toluene），即苯環上有一個 CH₃（甲基 methyl group）

步驟二：o-（ortho，鄰位）表示乙基（ethyl group, –CH₂CH₃）在 CH₃ 的相鄰碳（1,2-位）

```
      CH₃
       |
   ／‾＼
  |     |  ← 1 號碳（CH₃）
   ＼_／
       |
    CH₂CH₃  ← 2 號碳（乙基 ethyl）
```

系統名為：**1-ethyl-2-methylbenzene**

**(b) p-di-tert-butylbenzene**

步驟一：苯環上兩個**叔丁基（tert-butyl group, –C(CH₃)₃）**

步驟二：p-（para，對位）表示兩個取代基（substituents）在 1,4-位（正對面）

```
      C(CH₃)₃
         |
     ／‾＼
    |     |
     ＼_／
         |
      C(CH₃)₃
```

系統名：**1,4-di-tert-butylbenzene**

**(c) 1-phenyl-2-butene**

步驟一：主鏈為丁烯（2-butene），雙鍵在 C2–C3

步驟二：1 號碳接苯基（phenyl group，–C₆H₅）

```
Ph–CH₂–CH=CH–CH₃

其中 Ph = 苯基（phenyl）= C₆H₅–
```

完整結構：

```
C₆H₅–CH₂–CH=CH–CH₃
  1     2    3    4
```

### 進階例題 B（Exercise 33，難度：高）

**題目**：
- (a) 指出 o-、m-、p-二氯苯（dichlorobenzene）各為哪種異構物
- (b) 三氯苯（trichlorobenzene）有幾種異構物？
- (c) 一個 Cl 取代基（substituent）會讓下一個取代基優先進入 ortho 或 para 位。試問 m-dichlorobenzene 的合成是否困難？為什麼？
- (d) 哪種三氯苯（trichlorobenzene）最難合成？

**(a) 二氯苯的三種異構物：**

```
  1,2-二氯苯（1,2-dichlorobenzene）= o-dichlorobenzene（鄰二氯苯）
  1,3-二氯苯（1,3-dichlorobenzene）= m-dichlorobenzene（間二氯苯）
  1,4-二氯苯（1,4-dichlorobenzene）= p-dichlorobenzene（對二氯苯）
```

> **補充**：目前取代防蟲劑（mothballs）的物質正是 **1,4-dichlorobenzene（p-dichlorobenzene）**，而非舊式的萘（naphthalene）。

**(b) 三氯苯的異構物數目：**

系統性列舉（三個 Cl 在六個碳上的不同排列）：

```
1,2,3-trichlorobenzene（三個相鄰）
1,2,4-trichlorobenzene（兩個相鄰，一個間隔）
1,3,5-trichlorobenzene（對稱排列，每隔一個碳）
```

共 **3 種**異構物。

**(c) m-dichlorobenzene 的合成難度：**

題目說明：第一個 Cl 取代基（substituent）的導向效應（directing effect）使第二個 Cl 優先進入 **ortho（鄰位）** 或 **para（對位）**，不進入 **meta（間位）**。

因此：
- 從苯直接氯化（halogenation）只能得到 o- 和 p- 二氯苯
- **m-dichlorobenzene 無法由苯直接兩次鹵化得到**，合成上相當困難，需要設計特別的合成路線（例如先引入其他導向基，再轉換官能基）

**(d) 最難合成的三氯苯：**

以 (c) 的邏輯延伸：

- **1,3,5-trichlorobenzene（均三氯苯）** 最難合成，因為每個 Cl 都在 meta 位，而 Cl 取代基（substituent）本身就傾向導引後續取代基進入 ortho/para，完全避開 meta 位——要在全部 meta 位放 Cl，違反了導向規則，需要非直接的多步合成。

### 進階例題 C（Exercise 17，難度：中）

**題目**：Cumene（異丙苯）的結構如下，請給出其系統命名（systematic name）：

```
    CH(CH₃)₂
       |
   ／‾＼
  |     |
   ＼_／
```

**解析：**

步驟一：確認取代基（substituent）種類

–CH(CH₃)₂ 為**異丙基（isopropyl group）**

步驟二：確認母體

苯環接一個異丙基，即一取代苯（monosubstituted benzene）

步驟三：系統命名

苯環為母體，異丙基為取代基（substituent）：

**答：isopropylbenzene（異丙基苯）**

> **補充**：Cumene（異丙苯）在工業上是製造丙酮（acetone）和苯酚（phenol）的重要原料，每年全球產量超過百萬噸。

## 八、本節重點整理

| 概念 | 要點 |
|------|------|
| 苯的分子式 | C₆H₆；平面環（planar ring）；所有鍵角 120° |
| 碳的混成方式（hybridization） | sp²；每個碳一個 2p 軌域參與 π 系統 |
| π 電子特性 | 完全離域（fully delocalized）於六個碳上 |
| 芳香性（aromaticity） | 高度穩定；共振穩定化能約 150 kJ/mol |
| 主要反應類型 | 取代反應（substitution reaction），而非加成反應（addition reaction） |
| 取代反應條件 | 鹵化需 FeCl₃/AlCl₃；硝化需 H₂SO₄；烷基化（Friedel-Crafts）需 AlCl₃ |
| 二取代苯命名 | 鄰（ortho-, o-, 1,2-）、間（meta-, m-, 1,3-）、對（para-, p-, 1,4-） |
| 苯基（phenyl group） | –C₆H₅，苯作為取代基（substituent）時的名稱 |
| 多環芳香烴（PAHs） | 苯環稠合而成；部分為致癌物（carcinogens），如 3,4-苯並芘 |
