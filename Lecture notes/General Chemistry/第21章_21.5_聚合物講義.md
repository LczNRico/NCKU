# 第 21 章　有機與生化分子
## 21.5　聚合物（Polymers）

---

## 一、聚合物的基本概念

### 1.1 定義

**聚合物（polymers）** 是由大量小分子（稱為**單體 monomers**）重複連結而成的大分子（macromolecules），通常為鏈狀結構。聚合物構成了合成纖維（synthetic fibers）、橡膠（rubbers）和塑料（plastics）的基礎。

```
n 個單體（monomers）  →(聚合反應 polymerization)  聚合物（polymer）

單體（monomer）：小分子，含有可反應的官能基（functional groups）
聚合物（polymer）：數千至數百萬個單體連結而成
```

### 1.2 重要術語

| 術語 | 英文 | 說明 |
|------|------|------|
| 單體 | monomer | 構成聚合物的基本小分子 |
| 聚合物 | polymer | 由大量單體組成的大分子 |
| 均聚物 | homopolymer | 只由**一種**單體聚合而成 |
| 共聚物 | copolymer | 由**兩種或以上**不同單體聚合而成 |
| 二聚體 | dimer | 兩個單體連結的產物 |
| 熱塑性聚合物 | thermoplastic polymer | 加熱後可重新熔融塑形 |
| 熱固性聚合物 | thermoset polymer | 成形後加熱不能再熔融或溶解 |

### 1.3 聚合物工業的重要性

美國約 50% 的工業化學家從事聚合物化學（polymer chemistry）相關工作，顯示其對現代經濟的關鍵地位。

## 二、加成聚合（Addition Polymerization）

### 2.1 定義與機制

**加成聚合（addition polymerization）**：單體直接加成連結，**不生成任何副產物（by-products）**。通常由含 **C=C 雙鍵（carbon-carbon double bond）** 的烯烴類單體（alkene monomers）進行。

反應由**自由基引發劑（free radical initiator）** 啟動：

**步驟一：鏈引發（chain initiation）**
```
引發劑 I₂  →(光或熱)  2 I•（自由基 free radical）

I•  +  CH₂=CH₂  →  I–CH₂–CH₂•
```

**步驟二：鏈增長（chain propagation）**
```
I–CH₂–CH₂•  +  CH₂=CH₂  →  I–CH₂–CH₂–CH₂–CH₂•

（重複數千次，鏈不斷延長）
```

**步驟三：鏈終止（chain termination）**
```
兩個自由基（free radicals）相遇結合：
•–鏈–•  +  •–鏈–•  →  鏈–鏈（不再含自由基）
```

### 2.2 聚乙烯（Polyethylene，PE）

最簡單、最重要的加成聚合物（addition polymer）：

```
n CH₂=CH₂  →(催化劑 catalyst)  –(CH₂–CH₂)ₙ–
   乙烯（ethylene）              聚乙烯（polyethylene）
```

**兩種聚乙烯的比較：**

| 特性 | 低密度聚乙烯（LDPE, low-density polyethylene） | 高密度聚乙烯（HDPE, high-density polyethylene） |
|------|----------------------------------------------|----------------------------------------------|
| 鏈結構 | 含多個**支鏈（branches）**，排列鬆散 | 主要為**直鏈（linear chains）**，排列緊密 |
| 密度（density） | 較低 | 較高 |
| 結晶度（crystallinity） | 較低 | 較高 |
| 強度（strength） | 較低 | 較高 |
| 主要用途（uses） | 透明薄膜包裝（packaging films）、垃圾袋（garbage bags） | 吹塑瓶（blow-molded bottles）、管材（pipes） |

**Ziegler-Natta 催化劑（Ziegler-Natta catalyst）：**
- 組成：三乙基鋁（triethylaluminum，Al(C₂H₅)₃）+ 四氯化鈦（titanium(IV) chloride，TiCl₄）
- 特點：可在較低溫度和壓力下製造**高度線型（highly linear）** 的聚乙烯
- 缺點：接觸空氣即燃燒，需特殊處理

### 2.3 其他常見加成聚合物

| 單體（Monomer） | 聚合物（Polymer） | 用途（Uses） |
|----------------|------------------|-------------|
| 乙烯（ethylene，CH₂=CH₂） | 聚乙烯（polyethylene，PE） | 包裝薄膜（packaging films）、瓶子（bottles） |
| 丙烯（propylene，CH₂=CHCH₃） | 聚丙烯（polypropylene，PP） | 薄膜（films）、地毯（carpets）、模製品（molded parts） |
| 氯乙烯（vinyl chloride，CH₂=CHCl） | 聚氯乙烯（polyvinyl chloride，PVC） | 管道（pipes）、地板磚（floor tiles）、服裝（clothing） |
| 丙烯腈（acrylonitrile，CH₂=CHCN） | 聚丙烯腈（polyacrylonitrile，PAN） | 地毯（carpets）、織物（fabrics） |
| 四氟乙烯（tetrafluoroethylene，CF₂=CF₂） | 聚四氟乙烯（Teflon，PTFE） | 不沾鍋塗層（nonstick coatings）、電氣絕緣（electrical insulation） |
| 苯乙烯（styrene，CH₂=CHC₆H₅） | 聚苯乙烯（polystyrene，PS） | 容器（containers）、隔熱材料（thermal insulation） |

**Teflon（特氟龍）的發現：**
1938 年，杜邦（DuPont）化學家 Roy Plunkett 意外發現儲存的四氟乙烯（tetrafluoroethylene）氣體聚合成白色粉末——Teflon。C–F 鍵（bond）的高強度使 Teflon 具有極強的化學惰性（chemical inertness）、不燃性（nonflammability）和耐高溫性。

### 2.4 聚丙烯的鏈結構異構（Tacticity）

聚丙烯（polypropylene）的 CH₃ 取代基（substituents）排列方式影響其性質：

```
等規鏈（isotactic chain）：CH₃ 全部在鏈的同側
    H  CH₃ H  CH₃ H  CH₃
    |   |   |   |   |   |
–– C – C – C – C – C – C ––
    |   |   |   |   |   |
    H   H   H   H   H   H

間規鏈（syndiotactic chain）：CH₃ 交替排列在兩側
    H  CH₃ H   H  H  CH₃
    |   |   |   |   |   |
–– C – C – C – C – C – C ––
    |   |   |   |   |   |
    H   H   H  CH₃  H   H

無規鏈（atactic chain）：CH₃ 無規律排列
```

| 鏈型 | 結晶度（crystallinity） | 強度（strength） |
|------|----------------------|-----------------|
| 等規（isotactic） | 高（高規整性，鏈堆積緊密） | 最強 |
| 間規（syndiotactic） | 中 | 中 |
| 無規（atactic） | 低（非晶態 amorphous） | 最弱 |

> Ziegler-Natta 催化劑（Ziegler-Natta catalyst）可製造高度等規（isotactic）的聚丙烯，使其結晶度高、強度大，比聚乙烯（polyethylene）更硬更強。

## 三、縮合聚合（Condensation Polymerization）

### 3.1 定義

**縮合聚合（condensation polymerization）**：每次鏈延長時，兩個單體之間形成一個共價鍵（covalent bond），同時釋出一個**小分子副產物（small molecule by-product）**（通常是水 H₂O 或 HCl）。

```
單體A–官能基  +  官能基–單體B  →  單體A–鍵–單體B  +  小分子（如 H₂O）
```

### 3.2 尼龍（Nylon）——聚醯胺（Polyamide）

尼龍（nylon）是最重要的縮合聚合物（condensation polymer）之一，屬於**聚醯胺（polyamide）**（因為連接鍵為醯胺鍵 amide bond）。

**製備：已二胺（hexamethylenediamine）+ 己二酸（adipic acid）**

```
H₂N–(CH₂)₆–NH₂  +  HOOC–(CH₂)₄–COOH
  已二胺                    己二酸
（hexamethylenediamine）   （adipic acid）

→  [–NH–(CH₂)₆–NH–CO–(CH₂)₄–CO–]ₙ  +  n H₂O
         尼龍（nylon）重複單元
```

每次形成一個 **C–N 鍵（amide bond，醯胺鍵）** 即釋出一分子水（water）。

**尼龍的性質與用途：**
- 紡絲後鏈趨於平行排列（crystalline），鏈間形成大量**氫鍵（hydrogen bonds）**，使纖維強韌
- 美國年產量超過 100 萬噸
- 用途（uses）：服裝（clothing）、地毯（carpets）、繩索（rope）

**尼龍的發現：**
Wallace Carothers（杜邦公司）製備尼龍時，最初產物為黏稠狀，幾乎無結構強度。研究助理 Julian Hill 偶然將其拉成細絲，發現絲狀物具有類絲般的光澤與強度——這是**鏈對齊（chain alignment）** 增加結晶度（crystallinity）和氫鍵（hydrogen bonds）的結果。工業上通過**紡絲噴嘴（spinneret）** 強制鏈對齊來生產高強度纖維。

### 3.3 達克綸（Dacron）——聚酯（Polyester）

**製備：乙二醇（ethylene glycol）+ 對苯二甲酸（p-terephthalic acid）**

```
HO–CH₂CH₂–OH  +  HOOC–[苯環]–COOH
   乙二醇               對苯二甲酸
（ethylene glycol）   （p-terephthalic acid）

→  [–O–CH₂CH₂–O–CO–[苯環]–CO–]ₙ  +  n H₂O
         Dacron 重複單元
```

每個連接鍵為**酯鍵（ester bond）**，因此 Dacron 屬於**聚酯（polyester）**。

**用途（uses）：** 服裝（clothing）、與棉花混紡（blended with cotton）

### 3.4 縮合聚合 vs. 加成聚合比較

| 特性 | 加成聚合（addition polymerization） | 縮合聚合（condensation polymerization） |
|------|-----------------------------------|----------------------------------------|
| 副產物（by-products） | **無** | **有**（通常為 H₂O 或 HCl） |
| 單體結構要求 | 需含 C=C 雙鍵（double bond） | 需含兩個可反應官能基（functional groups） |
| 典型聚合物 | 聚乙烯（PE）、PVC、Teflon | 尼龍（nylon）、Dacron、Bakelite |
| 鏈型 | 均聚物（homopolymer）為主 | 均聚物或共聚物（copolymer）均可 |

## 四、增強聚合物強度的方法

### 4.1 交聯（Crosslinking）

**交聯（crosslinking）** 是指相鄰聚合物鏈之間形成**共價鍵（covalent bonds）**，將鏈結構連接在一起：

- 增加材料的強度（strength）和硬度（hardness）
- Bakelite（電木）：高度交聯（highly crosslinked），不可重新熔融 → 熱固性聚合物（thermoset polymer）
- 橡膠的硫化（vulcanization）：硫橋（sulfur bridges）連接相鄰橡膠鏈

### 4.2 橡膠的硫化（Vulcanization of Rubber）

天然橡膠（natural rubber）為異戊二烯（isoprene）的聚合物，鏈與鏈之間無鍵結，質地柔軟黏稠，不適合用作輪胎（tires）。

1839 年，Charles Goodyear 意外發現將**硫（sulfur）** 加入橡膠並加熱，可大幅改善其性質——此過程稱為**硫化（vulcanization）**：

```
天然橡膠鏈：  –CH₂–CH=C(CH₃)–CH₂–  ×n

硫化後：硫原子（sulfur atoms）形成硫橋（sulfur bridges）
       連接相鄰鏈上的碳原子（carbon atoms）
       使鏈與鏈之間產生共價鍵（covalent bonds）
```

**硫化橡膠（vulcanized rubber）的特性：**
- 仍具彈性（elastic / reversibly stretchable）
- 強度（strength）大幅提升
- 不再黏稠，適合製造輪胎（tires）和工業橡膠製品

### 4.3 鏈長（Chain Length）對性質的影響

- 分子量（molecular weight）越大，鏈間**纏結（entanglement）** 越多，強度越高
- 但分子量過高會使黏度（viscosity）大幅增加，不易加工（processing）
- 實際產品往往是**最佳性質**和**加工容易度**之間的妥協（compromise）

> **重要**：分子量（molecular weight）影響物理性質（physical properties）如強度、熔點，但**不**影響化學性質如抗化學侵蝕能力（resistance to chemical attack）、顏色（color）、折射率（refractive index）等。

## 五、課本例題精講

### 例題 1：辨識聚合物的單體與類型（改編自 Table 21.7）

**題目**：下列聚合物分別由何種單體製成？屬於加成聚合（addition polymerization）還是縮合聚合（condensation polymerization）？

**(a) Teflon（特氟龍）**

```
重複單元（repeating unit）：–(CF₂–CF₂)ₙ–
```

**解析：**
- 重複單元為 –CF₂–CF₂–，因此單體（monomer）為 **CF₂=CF₂（四氟乙烯 tetrafluoroethylene）**
- C=C 雙鍵打開連接，無副產物 → **加成聚合（addition polymerization）**
- 均聚物（homopolymer）

**(b) Dacron**

```
重複單元（repeating unit）：–[O–CH₂CH₂–O–CO–C₆H₄–CO]ₙ–
```

**解析：**
- 含酯鍵（ester bond）連接，且有 –O– 和 –CO– 兩側分屬不同單體
- 單體為：**乙二醇（ethylene glycol，HOCH₂CH₂OH）** 和 **對苯二甲酸（p-terephthalic acid）**
- 每次連接釋出水（H₂O）→ **縮合聚合（condensation polymerization）**
- 共聚物（copolymer）

## 六、進階例題（選自課後習題）

### 進階例題 A（Exercise 72a、72b，難度：中）

**題目**：指出下列聚合物的單體（monomers），並分類為加成聚合（addition）或縮合聚合（condensation），以及均聚物（homopolymer）或共聚物（copolymer）：

**(a)**
```
重複單元：–(CH₂–CHF)ₙ–
```

**解析：**
- 重複單元（repeating unit）為 –CH₂–CHF–
- 單體（monomer）：**CH₂=CHF（氟乙烯 vinyl fluoride）**
- 打開 C=C 雙鍵，無副產物 → **加成聚合（addition polymerization）**
- 一種單體 → **均聚物（homopolymer）**

**(b)**
```
重複單元：–(O–CH₂CH₂–O–CO–CH₂CH₂–CO)ₙ–
```

**解析：**

觀察連接鍵（linkage）：含有 **–O–CO–（酯鍵 ester bond）**

拆解重複單元（repeating unit）找單體：
- **–O–CH₂CH₂–O–** 來自乙二醇（ethylene glycol，HOCH₂CH₂OH）
- **–CO–CH₂CH₂–CO–** 來自丁二酸（succinic acid，HOOCCH₂CH₂COOH）

每次連接釋出水（H₂O）→ **縮合聚合（condensation polymerization）**

兩種不同單體 → **共聚物（copolymer）**，屬**聚酯（polyester）**

### 進階例題 B（Exercise 71，難度：高）

**題目**：

(a) 形成均聚物聚酯（homopolymer polyester）的單體需具備哪些結構特徵（structural features）？

(b) 形成共聚物聚醯胺（copolymer polyamide，如尼龍 nylon）的單體需具備哪些結構特徵？

(c) 若某單體既能形成加成聚合物（addition polymer）又能形成縮合聚合物（condensation polymer），其結構需具備哪些特徵？

**解析：**

**(a) 均聚物聚酯的單體結構要求：**

聚酯（polyester）的連接鍵為酯鍵（ester bond），需要羧基（carboxyl group，–COOH）與羥基（hydroxyl group，–OH）反應。

若只用**一種**單體就能形成聚酯，則此單體必須**同時具有 –COOH 和 –OH 兩種官能基（functional groups）**：

```
HO–R–COOH（羥基酸 hydroxy acid）

例如：乳酸（lactic acid）：CH₃CH(OH)COOH
```

自身縮合：
```
HO–R–COOH  +  HO–R–COOH  →  HO–R–COO–R–COOH + H₂O
（鏈不斷延長）
```

**(b) 共聚物聚醯胺的單體結構要求：**

醯胺鍵（amide bond）由 **–NH₂（胺基 amino group）** 和 **–COOH（羧基 carboxyl group）** 縮合形成。

共聚物（copolymer）需要兩種單體，各自在**兩端**均含有**相同的官能基（functional groups）**：

```
單體 A：H₂N–R–NH₂（二胺 diamine，兩端均為 –NH₂）
單體 B：HOOC–R'–COOH（二元酸 diacid，兩端均為 –COOH）

例如：已二胺（hexamethylenediamine）+ 己二酸（adipic acid）→ 尼龍
```

**(c) 可同時形成兩類聚合物的單體：**

需同時具備：
- **C=C 雙鍵（carbon-carbon double bond）**：允許加成聚合（addition polymerization）
- **兩個可縮合的官能基（condensable functional groups）**（如 –OH 和 –COOH）：允許縮合聚合（condensation polymerization）

```
例如：乙醇酸（glycolic acid）：HOCH₂COOH
若再含有 C=C 雙鍵，如：
CH₂=C(OH)COOH（α-羥基丙烯酸 α-hydroxyacrylic acid 的衍生物）
即可同時進行兩種聚合
```

### 進階例題 C（Exercise 78，難度：高）

**題目**：異戊二烯（isoprene）是天然橡膠（natural rubber）的重複單元（repeating unit）。

(a) 給出異戊二烯的系統命名（systematic name）

(b) 天然橡膠（natural rubber）中，雙鍵為 **cis（順式）** 構型；人工合成的**杜仲膠（gutta percha）** 中，雙鍵為 **trans（反式）** 構型。請畫出各三個重複單元的結構，並標明雙鍵的構型（configuration）。

**解析：**

**(a) 異戊二烯的系統命名：**

異戊二烯（isoprene）的結構：

```
CH₂=C(CH₃)–CH=CH₂
```

- 最長含雙鍵碳鏈：4 碳（丁二烯 butadiene 骨架），C1 和 C3 各有一個雙鍵 → 1,3-丁二烯衍生物
- C2 有 CH₃ 取代基（methyl substituent）

**系統名：2-甲基-1,3-丁二烯（2-methyl-1,3-butadiene）**

**(b) 天然橡膠 vs. 杜仲膠的結構：**

聚合時，異戊二烯在 C1 和 C4 連接（1,4-加成），保留一個 C=C 雙鍵在 C2–C3：

重複單元：

```
–CH₂–C(CH₃)=CH–CH₂–
```

**天然橡膠（natural rubber）：cis 構型**

```
     CH₃    CH₂–（鏈繼續）
       \    /
        C=C
       /    \
–CH₂        H
（三個重複單元，雙鍵兩側基團在同側 cis）
```

**杜仲膠（gutta percha）：trans 構型**

```
     CH₃    H
       \    /
        C=C
       /    \
–CH₂        CH₂–（鏈繼續）
（三個重複單元，雙鍵兩側基團在異側 trans）
```

**性質差異：**

| 特性 | 天然橡膠（natural rubber，cis） | 杜仲膠（gutta percha，trans） |
|------|-------------------------------|------------------------------|
| 鏈的形狀 | 彎曲（curved），鏈間不易規則堆積 | 較為伸直（extended），鏈間堆積較整齊 |
| 結晶度（crystallinity） | 低 | 較高 |
| 彈性（elasticity） | 高（高彈性橡膠） | 低（較硬，似皮革 leather-like） |
| 用途（uses） | 輪胎（tires）、橡皮擦（erasers） | 早期高爾夫球（golf balls）、牙科材料 |

> **關鍵**：cis vs. trans 構型的差異雖然只是空間排列不同，但對聚合物的巨觀性質（macroscopic properties）影響極大——這正是立體化學（stereochemistry）在高分子材料中的重要體現。

## 七、本節重點整理

| 概念 | 要點 |
|------|------|
| 聚合物（polymer） | 由單體（monomers）重複連結而成的大分子 |
| 加成聚合（addition polymerization） | C=C 雙鍵開環，自由基（free radical）機制，**無副產物** |
| 縮合聚合（condensation polymerization） | 官能基縮合，**釋出小分子**（如 H₂O） |
| 均聚物（homopolymer） | 一種單體；共聚物（copolymer）：兩種以上單體 |
| 熱塑性（thermoplastic） | 可重新熔融塑形；熱固性（thermoset）：不可重熔 |
| 交聯（crosslinking） | 鏈間共價鍵（covalent bonds），增加強度（strength） |
| 硫化（vulcanization） | 硫橋（sulfur bridges）交聯橡膠鏈，提升強度和彈性 |
| 等規（isotactic） | 取代基（substituents）全在同側；強度最高 |
| 間規（syndiotactic） | 取代基交替排列；無規（atactic）：隨機排列 |
| 分子量（molecular weight）的影響 | 分子量↑ → 強度↑、黏度↑，但**不影響化學性質** |
