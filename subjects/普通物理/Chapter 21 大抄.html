§ 21.1  電通量  Electric Flux  Φ_E
三種情形
① 垂直 \(\Phi_E = EA\) E ⊥ 面，最大值
② 傾斜 \(\Phi_E = EA\cos\theta = \vec{E}\cdot\vec{A}\) \(\theta\) = E 與法向量夾角
③ 微元 \(d\Phi_E = \vec{E}\cdot d\vec{A} = E\,dA\cos\theta\)
④ 曲面 \(\displaystyle\Phi_E = \int_S \vec{E}\cdot d\vec{A}\)
⑤ 封閉 \(\displaystyle\Phi_E = \oint \vec{E}\cdot d\vec{A}\) 法向量朝外（outward normal）
面積向量

\(\vec{A} = A\hat{n}\)　大小 = 面積，方向 = 法向量（垂直面朝外）

正負號判斷
\(\theta\)電場方向通量
\(\theta < 90°\)穿出封閉面\(> 0\)（正）
\(\theta = 90°\)沿表面切線（掠過）\(= 0\)
\(\theta > 90°\)穿入封閉面\(< 0\)（負）

淨通量 = 穿出電場線數 − 穿入電場線數

§ 21.2  高斯定律  Gauss's Law
核心公式
\[\oint \vec{E}\cdot d\vec{A} = \frac{q_{in}}{\varepsilon_0}\]

\(q_{in}\) = 高斯面內的淨電荷；與面外電荷完全無關

高斯面（Gaussian Surface）

假想的封閉曲面，物理上不存在，純為計算而選取

選對高斯面 → 把難積分變成代數題

選高斯面的四個條件（越多越好）

① 面上各處 \(E\) 為常數（可提出積分號）

② \(\vec{E}//d\vec{A}\)，則 \(\vec{E}\cdot d\vec{A} = E\,dA\)

③ \(\vec{E}\perp d\vec{A}\)，則通量 = 0（此面可忽略）

④ 某部分面上 \(E = 0\)（同樣通量 = 0）

三種標準幾何與對應高斯面
對稱性高斯面形狀
球形（點電荷、帶電球）同心球面
柱形（無限長線電荷）共軸圓柱面
平面（無限大帶電平面）圓柱（穿過平面）
面內、面外、面上
位置對面上 E對 \(q_{in}\)對淨通量
面內有影響✅ 計入有
面外有影響（局部）❌ 不計零（進出相消）
面上有影響✅ 視為面內有
⚠ 面外電荷對淨通量貢獻恆為零——穿入多少就穿出多少，這是高斯定律的幾何本質
等價庫倫定律（驗證）

對點電荷取球形高斯面：\(E\cdot 4\pi r^2 = q/\varepsilon_0\)　→　\(E=kq/r^2\) ✓

解題六步驟

① 判斷對稱性 → ② 選高斯面（場點在面上）

③ 化簡左側 \(E\cdot A_{total}\) → ④ 計算 \(q_{in}\)

⑤ 代入 \(EA_{total} = q_{in}/\varepsilon_0\) 解 E

⑥ 驗證極限（\(r\to\infty\) 退化點電荷？）

§ 21.3  八大應用 — 完整推導提醒與結果
① 點電荷 \(q\)

推導：球面高斯面，\(\vec{E}//d\vec{A}\)，E 為常數
\(E\cdot 4\pi r^2 = q/\varepsilon_0\)

\[E = k\frac{q}{r^2}\quad(r>0)\]
② 均勻帶雷球殼——內部 \((r < R)\)

推導：球形高斯面（半徑 r < R）完全在球殼內部
\(q_{in} = 0 \Rightarrow E\cdot 4\pi r^2 = 0\)

\[E = 0\quad(r < R)\]

▶ 球殼對內部任意位置的電場貢獻為零 = 靜電屏蔽原理

③ 均勻帶雷球殼——外部 \((r \ge R)\)

推導：球形高斯面（半徑 r > R），\(q_{in}=Q\)
\(E\cdot 4\pi r^2 = Q/\varepsilon_0\)

\[E = k\frac{Q}{r^2}\quad(r\ge R)\]

▶ 外部等同於電荷全集中於球心的點電荷

④ 均勻帶電實心絕緣球——內部 \((r \le R)\)

推導：體電荷密度 \(\rho = Q/(\tfrac{4}{3}\pi R^3)\)

球形高斯面（半徑 r），包圍電荷：\(q_{in}=\rho\cdot\tfrac{4}{3}\pi r^3 = Q\cdot r^3/R^3\)

\(E\cdot 4\pi r^2 = Qr^3/(\varepsilon_0 R^3)\)

\[E = k\frac{Q}{R^3}\,r\quad(r\le R)\quad\Rightarrow E\propto r\]

▶ 球心 r=0 時 E=0；在 r=R 處 E=kQ/R²，與外部銜接（連續）

⑤ 均勻帶電實心絕緣球——外部 \((r \ge R)\)

推導：高斯面包圍全部電荷 \(q_{in}=Q\)，與球殼外部相同

\[E = k\frac{Q}{r^2}\quad(r\ge R)\]
E-r 圖：內部線性 \(E\propto r\)，在 r=R 達最大，外部 \(E\propto 1/r^2\) 下降，在 r=R 處連續
⑥ 無限長線電荷（線密度 \(\lambda\)）

推導：取共軸圓柱高斯面（半徑 r，長 ℓ）

上下底面：\(\vec{E}\perp d\vec{A}\) → 通量 = 0
側曲面：\(\vec{E}//d\vec{A}\)，E 為常數 → \(E\cdot 2\pi r\ell\)
\(q_{in} = \lambda\ell\)　→　\(E\cdot 2\pi r\ell = \lambda\ell/\varepsilon_0\)

\[E = \frac{\lambda}{2\pi\varepsilon_0 r} = \frac{2k\lambda}{r}\]
⑦ 非導體無限大平面（面密度 \(\sigma\)）分母有 2

推導：圓柱形高斯面，平面從正中間穿過，兩底面積各 A

側面：\(\vec{E}\perp d\vec{A}\) → 0
左底 + 右底：各貢獻 \(EA\) → 總通量 \(2EA\)
\(q_{in}=\sigma A\)　→　\(2EA = \sigma A/\varepsilon_0\)

\[E = \frac{\sigma}{2\varepsilon_0}\quad\text{（平面兩側均成立）}\]

分母有 2：因電場在兩側，通量分攤給兩個底面

⑧ 帶電導體表面外側（面密度 \(\sigma\)）分母無 2

前提：導體內 \(E=0\)；表面電場必垂直表面

推導：微小圓柱，一端在導體內，一端在導體外

內底面：\(E=0\) → 0
側曲面：\(\vec{E}\perp d\vec{A}\) → 0
外底面：\(\vec{E}//d\vec{A}\) → \(EA\)
\(q_{in}=\sigma A\)　→　\(EA = \sigma A/\varepsilon_0\)

\[E = \frac{\sigma}{\varepsilon_0}\quad\text{（方向垂直表面，}\sigma{>0}\text{ 朝外）}\]

無 2：電場只在外側，通量全由一個底面承擔

§ 21.4  靜電平衡中的導體（Conductors in Electrostatic Equilibrium）
四大性質
性質①　導體內部 E = 0

反證：若 E≠0，自由電子受力移動 → 不平衡，矛盾

物理機制：外場使電荷重新分布，產生反向內場恰好抵消外場

性質②　多餘電荷在外表面

取高斯面於導體材料內：E=0 → 通量=0 → q_in=0

對任意縮小的高斯面均成立 → 內部體電荷密度處處為零

性質③　表面電場 ⊥ 表面，\(E=\sigma/\varepsilon_0\)

反證：若有切向分量 → 表面電子受力移動 → 矛盾

大小推導：同應用⑧，\(EA = \sigma A/\varepsilon_0\)

性質④　尖端效應

曲率越大（越尖）→ σ 越大 → E 越大

應用：避雷針頂端 E 超過空氣崩潰電場（3×10⁶ V/m），主動引雷

腔體屏蔽（Electrostatic Shielding）
腔內狀況腔內 E腔體壁面感應電荷
腔內無電荷= 0內壁 = 0，外壁 = 0
腔內有 +q≠ 0內壁感應 −q，外壁感應 +q

法拉第籠原理：金屬殼的腔內 E=0，外部電場無法透過導體進入腔內

取高斯面於導體材料中 → q_in = 0 → 腔壁上必無淨感應電荷（腔內無電荷時）

複合導體解題流程（同心球殼例）

實心球帶 +2Q，外球殼帶 −Q

位置條件電場
實心球內（r < R）導體內，E=00
兩球之間q_in = +2Q\(k\cdot2Q/r^2\)
球殼材料內導體內，E=00
球殼外（r > R₂）q_in = +2Q+(−Q) = +Q\(kQ/r^2\)

口訣：先用 E=0 推感應電荷 → 再用電荷守恆推各層剩餘 → 最後高斯定律求 E

考前關鍵觀念 & 易錯點
高斯定律 vs 庫倫定律

兩者等價，但高斯定律只在對稱性高時才能化簡計算。

沒有對稱性 → 仍可用高斯定律，但無法化簡，需回到庫倫積分。

正電荷 → 電場線向外（通量為正）
