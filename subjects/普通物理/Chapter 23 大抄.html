23.1 電容器與電容
電容定義
$$C = \frac{Q}{\Delta V}$$
  • $Q$：任一板電荷量的大小（正值）
  • $\Delta V$：兩板電位差的大小（正值）
  • $C$ 由幾何形狀決定，與 $Q$、$\Delta V$ 無關

單位

$$1\ \text{F} = 1\ \text{C/V}$$
單位換算
微法拉 μF$10^{-6}\ \text{F}$
奈法拉 nF$10^{-9}\ \text{F}$
皮法拉 pF$10^{-12}\ \text{F}$
通用推導策略
假設電荷 Q
    ↓ 高斯定律
求電場 E
    ↓ 積分
求電位差 ΔV
    ↓ C = Q/ΔV
求電容 C
✓ 關鍵：電容只與導體的幾何形狀（大小、形狀、間距）有關，與充了多少電荷無關。
23.2 計算電容
平行板電容器

面積 $A$，板間距 $d$，面電荷密度 $\sigma = Q/A$

推導步驟

  • 電場（高斯定律）：$E = \sigma/\varepsilon_0 = Q/\varepsilon_0 A$
  • 電位差：$\Delta V = Ed = Qd/\varepsilon_0 A$
  • 代入 $C = Q/\Delta V$
$$\boxed{C = \frac{\varepsilon_0 A}{d}}$$
✓ $A\uparrow$ 或 $d\downarrow$ → $C\uparrow$
圓柱形電容器

內半徑 $a$，外半徑 $b$，長度 $\ell$，$\lambda = Q/\ell$

推導步驟

  • 高斯面：同軸圓柱，半徑 $r$（$a < r < b$）
  • 電場：$E_r = \lambda/2\pi\varepsilon_0 r = 2k\lambda/r$
  • 電位差：$\Delta V = 2k\lambda\ln(b/a)$
$$\boxed{C = \frac{\ell}{2k\ln(b/a)} = \frac{2\pi\varepsilon_0\,\ell}{\ln(b/a)}}$$

單位長度電容：$C/\ell = 2\pi\varepsilon_0/\ln(b/a)$

球形電容器

內球半徑 $a$，外殼半徑 $b$

推導步驟

  • 電場（$a < r < b$）：$E_r = kQ/r^2$
  • 電位差：$\Delta V = kQ(b-a)/ab$
$$\boxed{C = \frac{ab}{k(b-a)} = 4\pi\varepsilon_0\frac{ab}{b-a}}$$
孤立球體

令球形電容器外殼 $b\to\infty$，$a\to R$：

$$\boxed{C = \frac{R}{k} = 4\pi\varepsilon_0 R}$$
⚠ 任何單一導體都有電容！
四種幾何形狀電容公式總覽
形狀公式幾何參數$C\uparrow$ 條件

23.3 含介電質的電容器
介電質的基本效應

插入介電常數 $\kappa > 1$ 的介電質後：

$$\boxed{C = \kappa C_0}$$
固定電荷（斷開電池）
$Q$ 不變，$\Delta V$ 減小： $$\Delta V = \frac{\Delta V_0}{\kappa}$$ $$\vec{E} = \frac{\vec{E}_0}{\kappa}$$
固定電位差（保持電池）
$\Delta V$ 不變，$Q$ 增大： $$Q = \kappa Q_0$$ 多餘電荷由電池補充
感應電荷密度
$\sigma_0$（極板）$\sigma_i$（介電質表面）
位置金屬極板介電質兩側表面
性質自由電荷束縛電荷（極化產生）
來源電池充電分子極化重排
可移動可以不行

感應電荷密度公式

$$\boxed{\sigma_i = \frac{\kappa-1}{\kappa}\sigma_0} \quad (\sigma_i < \sigma_0)$$

合電場

$$E = E_0 - E_i \quad \Rightarrow \quad E = \frac{E_0}{\kappa}$$
⚠ $\sigma_i$ 產生的感應電場方向與 $E_0$ 相反，使合電場減弱。
含介電質的平行板電容器
$$C = \kappa\frac{\varepsilon_0 A}{d} = \frac{\varepsilon A}{d}$$

其中 $\varepsilon = \kappa\varepsilon_0$ 為介電質的電容率（permittivity）。

部分填入時（厚度 $a < d$）

$$\Delta V = E_0(d-a) + Ea = E_0\left[(d-a)+\frac{a}{\kappa}\right]$$
$$C = \frac{\varepsilon_0 A}{(d-a)+a/\kappa}$$
⚠ 未填滿時，不能用 $C = \kappa C_0$！
介電強度與常見材料

23.4 電容器的並聯與串聯
並聯（Parallel）

各電容器兩端電壓相同，電荷各自儲存：

$$\Delta V_1 = \Delta V_2 = \cdots = \Delta V$$
$$Q = Q_1 + Q_2 + \cdots$$
$$\boxed{C_{eq} = C_1 + C_2 + \cdots + C_n}$$
✓ $C_{eq} >$ 任一個別電容
✓ 直覺：等效面積增大，$C\uparrow$
⚠ 類比：並聯電容 ↔ 串聯電阻（直接相加）
串聯（Series）

各電容器電荷相同，電壓各自分擔：

$$Q_1 = Q_2 = \cdots = Q$$
$$\Delta V = \Delta V_1 + \Delta V_2 + \cdots$$
$$\boxed{\frac{1}{C_{eq}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n}}$$
✓ $C_{eq} <$ 任一個別電容
✓ 直覺：等效間距增大，$C\downarrow$
⚠ 類比：串聯電容 ↔ 並聯電阻（取倒數相加）
並聯 vs 串聯 完整對照
並聯串聯
電壓各電容相同 $\Delta V$不同，相加等於總電壓
電荷不同，相加等於總電荷各電容相同 $Q$
等效公式$C_{eq} = \sum C_i$$1/C_{eq} = \sum 1/C_i$
$C_{eq}$ 大小大於任一個別電容小於任一個別電容
電壓分配各電容電壓相同$\Delta V_i = Q/C_i$，$C$ 小的電壓大
電阻類比類似電阻串聯類似電阻並聯

混合組合解題流程

① 辨識並聯組（電壓相同的電容）→ 合併：Ceq = ΣCi
② 辨識串聯組（電荷相同的電容）→ 合併：1/Ceq = Σ1/Ci
③ 從最終 Ceq 求總電荷 Q = Ceq·ΔV
④ 逐層還原：串聯各段 Q 相同，並聯各段 ΔV 相同
23.5 帶電電容器的儲能
電容器儲存的電位能

推導思路

充電過程中，電荷 $q$ 已在電容器上，再送入 $dq$ 所需微小功：

$$dW = \frac{q}{C}\,dq$$

對 $0 \to Q$ 積分：

$$\boxed{U = \frac{Q^2}{2C} = \frac{1}{2}C(\Delta V)^2 = \frac{1}{2}Q\Delta V}$$
✓ 三種形式等價，適用於任何形狀的電容器。

常用選擇

  • 已知 $Q$、$C$ → 用 $Q^2/2C$
  • 已知 $\Delta V$、$C$ → 用 $\frac{1}{2}C(\Delta V)^2$
  • 已知 $Q$、$\Delta V$ → 用 $\frac{1}{2}Q\Delta V$
電場能量密度

電場能量密度（單位體積的儲能）：

$$\boxed{u_E = \frac{1}{2}\kappa\varepsilon_0 E^2 = \frac{1}{2}\varepsilon E^2}$$

真空中（$\kappa = 1$）：$u_E = \frac{1}{2}\varepsilon_0 E^2$

✓ 普遍性：此公式適用於任何電場存在的地方，不只限於電容器。

推導（平行板）

$$u_E = \frac{U}{Ad} = \frac{C(\Delta V)^2}{2Ad} = \frac{\kappa\varepsilon_0 A}{d}\cdot\frac{(Ed)^2}{2Ad} = \frac{1}{2}\kappa\varepsilon_0 E^2$$
⚠ 能量守恆的常見陷阱

充好電的電容器 $C_1$ 斷開電池後，接上未充電的電容器 $C_2$，電荷重新分配：

$$\Delta V_f = \frac{C_1}{C_1+C_2}\Delta V_i \qquad Q_{1f} = C_1\Delta V_f \qquad Q_{2f} = C_2\Delta V_f$$
⚠ 重要：重新分配後總儲能 $U_f < U_i$，能量減少了！
消失的能量 = 導線上的熱能 + 電磁輻射，不違反能量守恆。

⚠ 常見易錯點
  • $C = \kappa C_0$ 只在介電質完全填滿時成立
  • 串聯電容：$C$ 小的分擔電壓大（$\Delta V \propto 1/C$）
  • 並聯電容：$C$ 大的儲存電荷多（$Q \propto C$）
  • 電容和電阻的串並聯公式剛好相反
  • 電荷重分配後能量一定減少，不違反守恆
  • $\sigma_0$ 在極板，$\sigma_i$ 在介電質表面，兩者完全不同
