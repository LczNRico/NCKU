22.1 電位能
電位能定義

測試電荷 $q$ 在電場 $\vec{E}$ 中移動，電場做功：

$$dW = \vec{F}\cdot d\vec{s} = q\vec{E}\cdot d\vec{s}$$

對應電位能變化（$dU = -dW$）：

$$\boxed{\Delta U = U_B - U_A = -W_{AB} = -q\int_A^B\vec{E}\cdot d\vec{s}}$$

以無窮遠為參考點（$U_\infty = 0$）：

$$U_B = -q\int_\infty^B \vec{E}\cdot d\vec{s}$$
✓ 路徑無關：電力為保守力，積分結果只取決於起終點。
功與能量關係
情況結論
電場做正功$\Delta U < 0$（位能下降）
電場做負功$\Delta U > 0$（位能上升）
正電荷順電場移動位能降，動能增
負電荷逆電場移動位能降，動能增
⚠ 電位能屬於電荷與電場的系統，非電荷單獨擁有。
22.2 電位與電位差
電位定義
$$\boxed{V = \frac{U}{q}}$$
$$\boxed{\Delta V = V_B - V_A = -\int_A^B\vec{E}\cdot d\vec{s}}$$
  • 電位是純量，疊加時代數相加
  • 電場線指向電位降低的方向
  • 等位面與電場線永遠垂直
單位與換算
量單位換算
電位 $V$伏特（V）$1\ \text{V} = 1\ \text{J/C}$
電場 $E$V/m = N/C$1\ \text{N/C} = 1\ \text{V/m}$
能量（微觀）電子伏特 eV$1\ \text{eV} = 1.6\times10^{-19}\ \text{J}$

外力做功

$$W_{AB(\text{app})} = q\Delta V = q(V_B - V_A)$$
✓ 電子伏特：$1\ \text{eV} = (e)(1\ \text{V}) = 1.6\times10^{-19}\ \text{J}$
22.3 均勻電場中的電位
沿電場 / 逆電場
沿電場方向（θ=0°）
$$\Delta V = -Ed$$

$V_B < V_A$（電位降低）

逆電場方向（θ=180°）
$$\Delta V = +Ed$$

$V_B > V_A$（電位升高）

任意方向位移

$$\Delta V = -\vec{E}\cdot\vec{s} = -Es\cos\theta$$
✓ 等位面：垂直電場的平面上各點電位相同，在等位面上移動不做功。
電位能變化 $\Delta U = q\Delta V$
電荷移動$\Delta U$物理意義
$+|q|$沿電場$-|q|Ed$位能↓，動能↑
$+|q|$逆電場$+|q|Ed$位能↑，需外力

22.4 點電荷的電位
單一點電荷
推導（取 $V_\infty = 0$）
1
$V_B - V_A = -\int_{r_A}^{r_B} E_r\,dr = -kq\int_{r_A}^{r_B} r^{-2}\,dr$
2
$= kq\left[\dfrac{1}{r_B} - \dfrac{1}{r_A}\right]$，令 $r_A\to\infty$
$$\boxed{V = k\frac{q}{r}} \quad (r > 0)$$
✓ 純量！$V$ 的正負由 $q$ 決定，$r\to 0$ 時 $V\to\pm\infty$。
多點電荷與系統電位能

疊加原理（純量相加）

$$\boxed{V = k\sum_n \frac{q_n}{r_n}}$$

兩點電荷系統電位能

$$\boxed{U = k\frac{q_1 q_2}{r_{12}}}$$

三點電荷系統電位能

$$U = k\left(\frac{q_1q_2}{r_{12}}+\frac{q_1q_3}{r_{13}}+\frac{q_2q_3}{r_{23}}\right)$$
符號$U$意義
同號電荷$U > 0$需正功克服排斥
異號電荷$U < 0$需負功克服吸引
22.5–22.6 電偶極
電偶極的電位（22.5）

$+q$ 與 $-q$ 相距 $2a$，電偶極矩 $p = 2aq$（方向由 $-q$ 指向 $+q$）

精確公式（任意 $r$）

$$V = kq\left(\frac{1}{r_+} - \frac{1}{r_-}\right) = kq\frac{r_- - r_+}{r_+ r_-}$$

遠場近似（$r \gg 2a$）

利用 $r_- - r_+ \approx 2a\cos\theta$，$r_+r_- \approx r^2$：

$$\boxed{V = k\frac{p\cos\theta}{r^2}} \quad (r\gg 2a)$$
角度 $\theta$$V$
$0°$（正電荷側）最大正值
$90°$（垂直平分面）$V = 0$
$180°$（負電荷側）最大負值
電偶極在外電場（22.6）

力矩（外積）

$$\boxed{\tau = pE\sin\theta \qquad \vec{\tau} = \vec{p}\times\vec{E}}$$

位能推導（內積積分）

積分過程（參考點 $\theta_0 = 90°$）
1
$dW = \vec{\tau}\cdot d\vec{\theta} = -pE\sin\theta\,d\theta$
2
$dU = -dW = pE\sin\theta\,d\theta$
3
$U = pE\int_{90°}^{\theta}\sin\theta\,d\theta = -pE\cos\theta$
$$\boxed{U = -pE\cos\theta = -\vec{p}\cdot\vec{E}}$$
$\theta$$U$穩定性
$0°$（同向）$-pE$（最小）穩定平衡
$90°$$0$（參考點）力矩最大
$180°$（反向）$+pE$（最大）不穩定平衡
⚠ 區分：22.5 是偶極產生的電位，22.6 是偶極在外場中的行為。
22.7–22.10 連續電荷分佈的電位
帶電棒（22.7）

均勻帶電棒，$Q$，長 $L$，$\lambda = Q/L$，$dV = k\,dq/r$

P 的位置公式
軸線延伸，距左端 $a$$\dfrac{kQ}{L}\ln\!\left(\dfrac{a+L}{a}\right)$
垂直平分線，距中點 $a$$\dfrac{2kQ}{L}\ln\!\left(\dfrac{L/2+\sqrt{(L/2)^2+a^2}}{a}\right)$
端點正上方，距端點 $a$$\dfrac{kQ}{L}\ln\!\left(\dfrac{L+\sqrt{L^2+a^2}}{a}\right)$
✓ 關鍵積分：$\displaystyle\int\frac{dx}{\sqrt{x^2+a^2}} = \ln(x+\sqrt{x^2+a^2})$
帶電弧（22.8）

半徑 $R$，圓心角 $\phi$，均勻帶電 $Q$

每點到圓心距離均為 $R$（常數），可提出積分外：

$$\boxed{V = k\frac{Q}{R}}$$
✓ 與點電荷形式相同！弧心到各段距離等長，方向不影響純量積分。
帶電環（22.9）

半徑 $R$，均勻帶電 $Q$，P 在軸線上距環心 $a$

所有電荷元素到 P 的距離 $r = \sqrt{R^2+a^2}$ 為常數：

$$\boxed{V = \frac{kQ}{\sqrt{R^2+a^2}}}$$
特殊情況結果
$a = 0$（環心）$V = kQ/R$（同帶電弧）
$a\gg R$（遠處）$V \approx kQ/a$（退化為點電荷）
帶電圓盤（22.10）

半徑 $R$，面電荷密度 $\sigma$，P 在軸線上距圓心 $a$

策略：分割為同心環，對各環電位積分（令 $u = r^2+a^2$）

$$\boxed{V = 2\pi k\sigma\!\left(\sqrt{R^2+a^2}-a\right) = \frac{\sigma}{2\varepsilon_0}\!\left(\sqrt{R^2+a^2}-a\right)}$$
22.11–22.12 球體與導體的電位
均勻帶電球體（22.11）
區域電場 $E_r$電位 $V$
外部 $r \geq R$$kQ/r^2$$kQ/r$（同點電荷）
內部 $r \leq R$$kQr/R^3$$\dfrac{kQ}{2R}\!\left(3-\dfrac{r^2}{R^2}\right)$
球心 $r=0$
$V_0 = \dfrac{3kQ}{2R}$（最大值）
球面 $r=R$
$V_R = \dfrac{kQ}{R}$（內外銜接）
⚠ 內部曲線為拋物線，外部為雙曲線，$r=R$ 處平滑連接。
帶電導體（22.12）
  • 電荷只在外表面
  • 內部電場為零：$\vec{E}_\text{內} = 0$
  • 導體表面為等位面（$V = $ 常數）
  • 內部電位等於表面電位

球形導體電位

$$V = \begin{cases} kQ/r & r \geq R \\ kQ/R = \text{常數} & r \leq R \end{cases}$$

非對稱導體

表面仍為等位面，但電荷密度不均：

$$R_c\,\sigma = \text{常數} \quad\Rightarrow\quad \sigma \propto \frac{1}{R_c}$$
✓ 曲率越大（越尖銳），表面電荷密度越大，電場越強。
22.13 電位梯度
從電位求電場
推導（比較兩種 dV 的表達式）
1
$dV = -\vec{E}\cdot d\vec{s} = -E_x\,dx - E_y\,dy - E_z\,dz \quad\cdots(1)$
2
連鎖律：$dV = \dfrac{\partial V}{\partial x}dx + \dfrac{\partial V}{\partial y}dy + \dfrac{\partial V}{\partial z}dz \quad\cdots(2)$
3
比較 (1)(2) 各分量係數得電位梯度關係
$$\boxed{E_x = -\frac{\partial V}{\partial x},\quad E_y = -\frac{\partial V}{\partial y},\quad E_z = -\frac{\partial V}{\partial z}}$$ $$\boxed{\vec{E} = -\nabla V}$$

球對稱（徑向）

$$\boxed{E_r = -\frac{dV}{dr}}$$
電位梯度驗證（各電荷分佈）
電位 $V$$E = -dV/dr$結果
點電荷：$kq/r$$-d(kq/r)/dr$$kq/r^2$ ✓
帶電環：$kQ/\sqrt{R^2+a^2}$$-dV/da$$kQa/(R^2+a^2)^{3/2}$ ✓
帶電圓盤：$\sigma(\sqrt{R^2+a^2}-a)/2\varepsilon_0$$-dV/da$$\dfrac{\sigma}{2\varepsilon_0}\!\left(1-\dfrac{a}{\sqrt{R^2+a^2}}\right)$ ✓
✓ 計算策略：先求純量 $V$（積分簡單），再微分得向量 $\vec{E}$（比直接用庫倫定律容易）。

⚠ 常見易錯點
  • 電位是純量，電場是向量；疊加時電位直接代數相加
  • 電場線從高電位指向低電位
  • 22.5 是偶極產生的電位；22.6 是偶極在外場中的位能，兩者意義完全不同
  • $E_r = -dV/dr$ 是對距離微分，不是對時間
  • 帶電棒三種情況：積分上下限和 $r$ 的表達式各不相同，要先確認 P 點位置
  • 導體內部電位等於表面電位（不是零）
  • 球體內部電場 $\propto r$，電位 $\propto (3-r^2/R^2)$，不要混淆
