Chapter 21 · Gauss's Law · Section 21.4

靜電平衡中的
導體

Conductors in Electrostatic Equilibrium — 四大性質與完整推導

導體（conductor）內部含有大量可自由移動的電子。當系統達到靜電平衡（electrostatic equilibrium）時，導體內部沒有淨電荷流動。這個條件對電場與電荷分布產生嚴格的限制，構成本節四大性質的基礎。

⚠ 靜電平衡的定義
導體內部自由電子沒有任何淨移動的狀態。這並不代表電子靜止不動（熱運動仍然存在），而是巨觀上無電流流動。

§ 21.4.1四大性質總覽

性質 01

導體內部電場為零

靜電平衡時，導體內任意一點的電場 \(\vec{E}_{int} = \vec{0}\)。

性質 02

多餘電荷在外表面

孤立導體上任何多餘電荷，全部分布在外表面，內部與腔體壁面無淨電荷。

性質 03

表面電場垂直於表面

導體表面緊鄰外側的電場，方向必定垂直於表面，大小為 \(E = \sigma/\varepsilon_0\)。

性質 04

尖端電荷密度最大

導體表面曲率越大（越尖銳）的地方，面電荷密度 \(\sigma\) 越大，電場越強。

§ 21.4.2性質一：內部電場為零

推導（反證法）

PROOF — 反證法
假設 導體內部某點存在電場 \(\vec{E} \neq \vec{0}\)。
推論 導體內自由電子受到力 \(\vec{F} = -e\vec{E}\)，產生定向移動（即電流）。
矛盾 這與「靜電平衡，無電流」的前提矛盾。
結論 假設不成立，故靜電平衡時導體內部電場必為零。 \(\blacksquare\)

物理機制——屏蔽效應

當導體被置於外部電場 \(\vec{E}_{ext}\) 中，自由電子重新分布，在導體兩端形成感應電荷，建立一個方向相反的內部電場 \(\vec{E}_{int}\)。最終達到平衡時：

靜電平衡條件
\[\vec{E}_{net} = \vec{E}_{ext} + \vec{E}_{int} = \vec{0}\] \[\Rightarrow \vec{E}_{int} = -\vec{E}_{ext}\]

此過程所需時間約 \(10^{-6}\) 秒，在靜電學問題中視為瞬間完成。

外部電場 → 自由電子累積 (-) ─────┌─────────────────┐───── │ →E_int ← │ │ 導體內部 │ ← E_net = 0 │ │ ─────└─────────────────┘───── 正電荷暴露 (+) ← E_ext 仍然存在於外部

§ 21.4.3性質二：多餘電荷分布在外表面

推導（高斯定律）

在導體內部任意位置畫一個高斯面（完全在導體材料內部，不包含腔體）。

PROOF — 高斯定律
前提 高斯面上每一點都在導體內，因此 \(\vec{E} = \vec{0}\)。
計算 \(\displaystyle\Phi_E = \oint \vec{E}\cdot d\vec{A} = 0\)
結論 由高斯定律 \(\Phi_E = q_{in}/\varepsilon_0\)，故 \(q_{in} = 0\)。高斯面內無淨電荷。
推廣 此高斯面可任意縮小或移動，高斯面內始終 \(q_{in}=0\)，故導體內部任意位置的體電荷密度為零。所有多餘電荷只能存在於外表面。 \(\blacksquare\)
💡 腔體（Cavity）的情況
若導體內有一個空腔，且腔內沒有帶電體，則腔體的內壁上也沒有感應電荷，腔內電場同樣為零——這就是靜電屏蔽（electrostatic shielding）的原理，法拉第籠（Faraday cage）即基於此原理。

§ 21.4.4性質三：表面電場大小與方向

（A）方向：必垂直於表面

PROOF — 反證法
假設 表面電場存在平行於表面的分量 \(\vec{E}_{\parallel}\)。
推論 表面自由電子受到切向力，沿表面移動，形成表面電流。
矛盾 違背靜電平衡假設，故 \(\vec{E}_{\parallel} = \vec{0}\)，電場只有垂直分量。 \(\blacksquare\)

（B）大小：\(E = \sigma / \varepsilon_0\)

取一個微小的圓柱形高斯面，一端在導體內部，一端緊貼導體外側，兩端底面積各為 \(A\)：

外側（E ≠ 0） ╔══════════════╗ ← 外底面，面積 A，E // dA，貢獻 EA ║ 圓柱高斯面 ║ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ← 導體表面（電荷 σ 在此） ║ ║ ╚══════════════╝ ← 內底面，E = 0，貢獻 0 內側（E = 0）

計算各部分通量：

面 條件 通量
外底面 \(\vec{E}//d\vec{A}\)，\(E\) 為常數 \(\Phi = EA\)
內底面 \(\vec{E} = \vec{0}\)（導體內） \(\Phi = 0\)
側曲面（外） \(\vec{E} \perp d\vec{A}\) \(\Phi = 0\)
側曲面（內） \(\vec{E} = \vec{0}\) \(\Phi = 0\)
總通量 \(\Phi_E = EA\)

高斯面內包圍電荷 \(q_{in} = \sigma A\)，代入高斯定律：

導體表面外側電場
\[EA = \frac{\sigma A}{\varepsilon_0} \implies \boxed{E = \frac{\sigma}{\varepsilon_0}}\]

方向：\(\sigma > 0\) 時指向外，\(\sigma < 0\) 時指向內

§ 21.4.5性質四：尖端效應

由性質三知 \(E = \sigma/\varepsilon_0\)，因此電場強弱直接反映面電荷密度的大小。而導體表面電荷的分布並不均勻：

  • 曲率半徑越小（越尖銳）的地方，\(\sigma\) 越大，\(E\) 越大。
  • 曲率半徑越大（越平坦）的地方，\(\sigma\) 越小，\(E\) 越小。
  • 曲率為零（無限大平面）時，\(\sigma\) 最均勻。
⚡ 應用：避雷針
避雷針頂端極尖銳，曲率極大，因此頂端電場強度遠超周圍空氣的崩潰電場（約 \(3 \times 10^6\) V/m），可游離空氣，主動將雷電引導至針尖而非建築物。

直觀解釋

在尖銳處，曲面彎曲劇烈，相鄰表面電荷之間的排斥力有較大的向外分量，使電荷更難留在此處——但電荷必須維持靜電平衡，所以尖端需要更高的電荷密度才能抵消這種趨向，結果是電荷在尖端大量累積。

§ 21.4.6導體 vs 非導體對照

特性 導體（靜電平衡） 非導體（均勻分布）
內部電場 \(E = 0\)（永遠） \(E \neq 0\)（可能有）
電荷位置 只在外表面 可分布於體積內部
表面外側電場 \(E = \sigma/\varepsilon_0\) \(E = \sigma/(2\varepsilon_0)\)（無限大平面）
電場方向 必定垂直於表面 由分布決定，不一定垂直
分母差異原因 電場只在外側，單面承擔全部通量 電場兩側各半，通量分給兩個底面

§ 21.4.7典型例題：同心導體球殼

實心導體球（半徑 \(R\)，帶電 \(+2Q\)）位於導體球殼（內半徑 \(R_1\)，外半徑 \(R_2\)，帶電 \(-Q\)）的正中心。求各區域電場及電荷分布。

電荷分布推導

ANALYSIS
區域① \(r < R\)（實心球內）：導體內部，\(E = 0\)。
區域② \(R < r < R_1\)（兩導體之間的空間）：\(q_{in} = +2Q\)，由高斯定律 \(E = k(2Q)/r^2\)。
球殼內壁 球殼材料內部 \(E=0\)，取高斯面在材料內，\(q_{in}=0\)，故球殼內壁需感應 \(-2Q\)，抵消實心球的 \(+2Q\)。
球殼外壁 球殼總電荷 \(-Q\)，內壁已感應 \(-2Q\)，故外壁剩餘 \(+Q\)。
區域③ \(R_1 < r < R_2\)（球殼材料內）：導體內部，\(E=0\)。
區域④ \(r > R_2\)（球殼外）：\(q_{in} = +2Q + (-Q) = +Q\)，\(E = kQ/r^2\)。
區域 電場 說明
\(r < R\) \(E = 0\) 導體內部
\(R < r < R_1\) \(\displaystyle E = k\frac{2Q}{r^2}\) \(q_{in} = +2Q\)
\(R_1 < r < R_2\) \(E = 0\) 導體球殼材料內
\(r > R_2\) \(\displaystyle E = k\frac{Q}{r^2}\) \(q_{in} = +2Q - Q = +Q\)

§考前速查總結

性質一 導體內部 \(E = 0\)（靜電平衡的必要條件）
性質二 多餘電荷在外表面（由高斯定律 \(q_{in}=0\) 推出）
性質三 \(E = \sigma/\varepsilon_0\)，方向垂直表面（比非導體平面大 2 倍）
性質四 曲率越大 → \(\sigma\) 越大 → \(E\) 越大（尖端效應）
腔體屏蔽 腔內無電荷時，腔內 \(E = 0\)（法拉第籠原理）
感應電荷 腔內電荷 \(+q\) → 內壁感應 \(-q\)，外壁感應 \(+q\)
解題流程 先用 \(E=0\) 確定感應電荷 → 再用高斯定律求各區域 \(E\)
常見陷阱 導體表面 \(\sigma/\varepsilon_0\)，非導體無限大平面 \(\sigma/2\varepsilon_0\)，勿混淆
