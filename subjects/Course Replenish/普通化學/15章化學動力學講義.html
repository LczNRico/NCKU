15.1　反應速率

一、定義

反應速率定義為單位時間內反應物或生成物濃度的變化量：

$$\text{Rate} = \frac{\Delta[\text{A}]}{\Delta t}$$

因反應物濃度隨時間減少，取負號使速率為正值：

$$\text{Rate} = -\frac{\Delta[\text{A}]}{\Delta t} \qquad \text{（反應物）}$$

二、平均速率 vs. 瞬間速率

種類定義獲取方式
平均速率某段時間區間的平均值直接由數據計算
瞬間速率\(-d[\text{A}]/dt\)，特定時刻的速率濃度-時間曲線的切線斜率
初始速率\(t \to 0\) 時的瞬間速率最常用，逆反應可忽略

三、不同物種的速率關係

對於 \(a\text{A} + b\text{B} \to c\text{C} + d\text{D}\)：

$$\text{Rate} = -\frac{1}{a}\frac{d[\text{A}]}{dt} = -\frac{1}{b}\frac{d[\text{B}]}{dt} = +\frac{1}{c}\frac{d[\text{C}]}{dt} = +\frac{1}{d}\frac{d[\text{D}]}{dt}$$
⚠ 注意
各物種速率需除以各自的化學計量係數後才可互相比較。

四、例題

▸ 例題 1：由速率數據推算化學計量係數

已知：\(-\Delta[\text{A}]/\Delta t = 0.0080\)，\(-\Delta[\text{B}]/\Delta t = 0.0120\)，\(\Delta[\text{C}]/\Delta t = 0.0160\)（單位 mol/L·s），求係數 a、b、c。

展開解答

比值 \(0.0080 : 0.0120 : 0.0160 = 2 : 3 : 4\)

故 \(a=2,\ b=3,\ c=4\)，即 \(2\text{A}+3\text{B}\to 4\text{C}\)。

▸ 例題 2：H₂O₂ 分解的平均速率

\(2\text{H}_2\text{O}_2 \to 2\text{H}_2\text{O} + \text{O}_2\)，在 0 到 \(2.16\times10^4\) s 內，\([\text{H}_2\text{O}_2]\) 由 1.000 降至 0.500 mol/L。

求 H₂O₂ 的平均消耗速率及 O₂ 的平均生成速率。

展開解答
$$-\frac{\Delta[\text{H}_2\text{O}_2]}{\Delta t} = \frac{0.500}{2.16\times10^4} = 2.31\times10^{-5}\ \text{mol/L·s}$$
$$\frac{\Delta[\text{O}_2]}{\Delta t} = \frac{1}{2}\times 2.31\times10^{-5} = 1.16\times10^{-5}\ \text{mol/L·s}$$

（第二段同理，速率約為第一段的一半，暗示速率依賴濃度。）

▸ 例題 3：速率常數的單位

已知速率定律 \(\text{Rate} = k[\text{Cl}_2]^{1/2}[\text{CHCl}_3]\)，求 k 的單位（濃度 mol/L，時間 s）。

展開解答

總級數 \(= 1/2 + 1 = 3/2\)

$$k = \frac{\text{mol/L·s}}{(\text{mol/L})^{3/2}} = \text{L}^{1/2}\text{mol}^{-1/2}\text{s}^{-1}$$

15.2　速率定律導論

一、速率定律的形式

$$\text{Rate} = k[\text{A}]^n[\text{B}]^m\cdots$$
  • k（速率常數）：與溫度有關，與濃度無關
  • n, m（反應級數）：必須由實驗決定，不能從方程式係數推算
  • 總級數 = n + m + …

二、兩種速率定律

微分速率定律積分速率定律
描述速率如何隨濃度變化濃度如何隨時間變化
形式Rate = k[A]ⁿln[A] = −kt + ln[A]₀（一級）
獲取方式初始速率法作圖法
互相關係知其一即知其二

三、速率常數 k 的重要性質

  • k 隨溫度升高而增大（見 15.8 節）
  • k 的數值與單位取決於反應級數
  • 定義速率的物種不同，k 值不同
⚠ 重要提醒
同一反應，若以不同物種定義速率，k 值不同，需注意計量關係換算。
例如 \(2\text{NO}_2 \to 2\text{NO} + \text{O}_2\)，以 NO₂ 定義時 \(k = 2k'\)（k' 以 O₂ 定義）。

四、反應級數的意義

級數 n濃度加倍，速率變為？

−11/2（抑制）

15.3　決定速率定律——初始速率法

一、核心概念

設計多組實驗，每次只改變一種反應物的濃度，比較初始速率比值求各物種的級數。

$$n = \frac{\ln(\text{Rate}_2 / \text{Rate}_1)}{\ln([\text{A}]_2 / [\text{A}]_1)}$$
提示
當濃度比為整數倍時可直接心算；遇到非整數倍濃度比時必須用對數公式。

二、例題

▸ 例題 1：BrO₃⁻ + Br⁻ + H⁺（三物種）
實驗[BrO₃⁻][Br⁻][H⁺]初始速率 (mol/L·s)
10.100.100.108.0 × 10⁻⁴
20.200.100.101.6 × 10⁻³
30.200.200.103.2 × 10⁻³
40.100.100.203.2 × 10⁻³
展開解答

比較實驗 1、2（[BrO₃⁻] 加倍，速率加倍）：\(n=1\)

比較實驗 2、3（[Br⁻] 加倍，速率加倍）：\(m=1\)

比較實驗 1、4（[H⁺] 加倍，速率 \(\times 4\)）：\(p=2\)

$$\text{Rate} = k[\text{BrO}_3^-][\text{Br}^-][\text{H}^+]^2 \quad \text{（總級數 = 4）}$$

代入實驗 1 求 k：\(k = 8.0 \times 10^{-4} / (0.10)^4 = 8.0\ \text{L}^3\text{mol}^{-3}\text{s}^{-1}\)

▸ 例題 2：I⁻ + OCl⁻（負級數）

實驗數據（部分）：

實驗[I⁻][OCl⁻][OH⁻]初始速率
10.00130.0120.109.4 × 10⁻³
50.00130.0120.05018.7 × 10⁻³
60.00130.0120.204.7 × 10⁻³
展開解答

比較實驗 1 和 5，[OH⁻] 由 0.10 減半為 0.050，速率加倍：

$$2.0 = (0.5)^p = 2^{-p} \implies p = -1$$

[OH⁻] 增大反而抑制速率 → 負一級！

$$\text{Rate} = k\frac{[\text{I}^-][\text{OCl}^-]}{[\text{OH}^-]}$$

代入實驗 1：\(k = 9.4\times10^{-3}\times0.10 / (0.0013\times0.012) = 60\ \text{s}^{-1}\)

▸ 例題 3：H₂SeO₃ 六級反應（非整數倍濃度比）

速率定律為 \(\text{Rate} = k[\text{H}_2\text{SeO}_3][\text{H}^+]^2[\text{I}^-]^3\)，總級數 6。

對 I⁻ 的推導（[I⁻] 加倍，速率 \(\times 7.95 \approx 8 = 2^3\)），故 \(c=3\)。

展開解答（求 k）

代入實驗 1（[H₂SeO₃] = 1.0×10⁻⁴，[H⁺] = 2.0×10⁻²，[I⁻] = 2.0×10⁻²，Rate = 1.66×10⁻⁷）：

$$k = \frac{1.66\times10^{-7}}{(1.0\times10^{-4})(2.0\times10^{-2})^2(2.0\times10^{-2})^3} = 5.2\times10^5\ \text{L}^5\text{mol}^{-5}\text{s}^{-1}$$

15.4　積分速率定律

一、一級反應

推導： \(-d[\text{A}]/dt = k[\text{A}]\)，分離變數積分：

$$\ln[\text{A}] = -kt + \ln[\text{A}]_0 \iff \ln\frac{[\text{A}]_0}{[\text{A}]} = kt$$
  • 直線作圖：\(\ln[\text{A}]\) vs. \(t\)，斜率 \(= -k\)
  • 半衰期：\(t_{1/2} = 0.693/k\)（與初濃度無關）
  • 連續半衰期：每個 \(t_{1/2}\) 完全相同
符號辨析
正確 ✓
\(\ln([\text{A}]/[\text{A}]_0) = -kt\)
\(\ln([\text{A}]_0/[\text{A}]) = +kt\)
錯誤 ✗
\(\ln([\text{A}]/[\text{A}]_0) = +kt\)

分子分母的順序決定正負號，記憶方式：分子較大 → ln 為正 → 右側也為正。

二、二級反應

推導： \(-d[\text{A}]/dt = k[\text{A}]^2\)，積分：

$$\frac{1}{[\text{A}]} = kt + \frac{1}{[\text{A}]_0}$$
  • 直線作圖：\(1/[\text{A}]\) vs. \(t\)，斜率 \(= +k\)
  • 半衰期：\(t_{1/2} = 1/(k[\text{A}]_0)\)（與初濃度成反比）
  • 連續半衰期：每個後續 \(t_{1/2}\) 是前一個的 2 倍

三、零級反應

推導： \(-d[\text{A}]/dt = k\)，積分：

$$[\text{A}] = -kt + [\text{A}]_0$$
  • 直線作圖：\([\text{A}]\) vs. \(t\)，斜率 \(= -k\)
  • 半衰期：\(t_{1/2} = [\text{A}]_0/(2k)\)（與初濃度成正比）
  • 連續半衰期：每個後續 \(t_{1/2}\) 是前一個的 1/2（越來越短）

四、判斷反應級數的流程

  • 計算各時刻的 \([\text{A}]\)、\(\ln[\text{A}]\)、\(1/[\text{A}]\)
  • 作 \([\text{A}]\) vs. \(t\)：直線 → 零級
  • 作 \(\ln[\text{A}]\) vs. \(t\)：直線 → 一級
  • 作 \(1/[\text{A}]\) vs. \(t\)：直線 → 二級
  • 或觀察半衰期：固定→一級；加倍→二級；縮短→零級

    • 五、假一級速率定律（Pseudo-First-Order）

    對多反應物反應，設計使某一反應物濃度遠小於其他物種，其他物種濃度視為常數：

    $$\text{Rate} = k[\text{B}]_0^m[\text{C}]_0^p[\text{A}]^n = k'[\text{A}]^n$$

    其中 \(k' = k[\text{B}]_0^m[\text{C}]_0^p\) 為假 n 級速率常數。由 \(k'\) 反推真正的 \(k\)：

    $$k = \frac{k'}{[\text{B}]_0^m[\text{C}]_0^p}$$

    六、例題

    ▸ 例題 1：N₂O₅ 分解（一級驗證 + 計算）

    分解 99% ≈ 6.65 個半衰期；分解 99.9% ≈ 9.97 個半衰期。

    附錄：n 級反應積分速率定律通式推導

    一、推導（n ≠ 1）

    $$-\frac{d[\text{A}]}{dt} = k[\text{A}]^n \implies \int_{[\text{A}]_0}^{[\text{A}]}[\text{A}]^{-n}\,d[\text{A}] = -k\int_0^t dt$$
    $$\frac{[\text{A}]^{1-n} - [\text{A}]_0^{1-n}}{1-n} = -kt$$
    $$\boxed{[\text{A}]^{1-n} = (1-n)(-kt) + [\text{A}]_0^{1-n}}$$
    $$\boxed{[\text{A}]^{1-n} - [\text{A}]_0^{1-n} = (n-1)kt}$$
    ⚠ 符號勘誤
    第二式右側為 +(n−1)kt，非 −(n−1)kt。
    驗算（n=2）：\(1/[\text{A}] - 1/[\text{A}]_0 = +kt\)（標準二級積分式）✓

    二、n = 1 的情況（另行積分）

    $$\int\frac{d[\text{A}]}{[\text{A}]} = \ln[\text{A}] \implies \ln[\text{A}] = -kt + \ln[\text{A}]_0$$

    三、n 級半衰期通式（n ≠ 1）

    $$t_{1/2} = \frac{2^{n-1}-1}{(n-1)k[\text{A}]_0^{n-1}}$$

    四、連續半衰期的規則

    每個後續半衰期與前一個的比值：

    $$\frac{t_{1/2}^{(m+1)}}{t_{1/2}^{(m)}} = 2^{n-1} \quad \text{（等比數列，公比 } 2^{n-1}\text{）}$$
    級數 n公比 2^(n−1)規則
    01/2每個半衰期縮短為前一個的 1/2
    11每個半衰期相同（固定值）
    22每個半衰期加倍
    34每個半衰期變為 4 倍

    15.6　反應機構

    一、基本名詞

    名詞定義
    基元步驟機構中單一步驟，速率定律由分子數直接寫出
    中間體某步驟生成、後續步驟消耗，不出現在整體方程式中
    分子數碰撞物種數：單分子(1)、雙分子(2)、三分子(3)
    速率決定步驟最慢步驟，決定整體反應速率

    二、基元步驟的速率定律

    分子數步驟速率定律
    單分子A → productsRate = k[A]
    雙分子A + B → productsRate = k[A][B]
    雙分子2A → productsRate = k[A]²
    三分子A + B + C → productsRate = k[A][B][C]（極少見）

    三、有效機構的兩個必要條件

    必要條件（缺一不可）
    1. 各基元步驟相加 = 整體平衡方程式
    2. 機構推導出的速率定律 = 實驗測得的速率定律
    滿足條件的機構可能不只一個，無法絕對證明機構正確。

    四、兩種常見機構類型

    類型一：第一步為速率決定步驟

    速率定律直接由第一步的分子數寫出，不含中間體。

    類型二：第一步為快速平衡，第二步為速率決定步驟

    由第二步寫速率定律，利用第一步的平衡條件消去中間體：

    $$k_1[\text{反應物}] = k_{-1}[\text{中間體}] \implies [\text{中間體}] = \frac{k_1}{k_{-1}}[\text{反應物}]$$

    五、例題

    ▸ 例題 1：O₃ 分解（快速平衡機構）

    實驗速率定律：\(\text{Rate} = k[\text{O}_3]^2/[\text{O}_2]\)

    機構：\(\text{O}_3 \rightleftharpoons \text{O}_2 + \text{O}\)（快速平衡），\(\text{O} + \text{O}_3 \xrightarrow{k_2} 2\text{O}_2\)（慢）

    展開解答

    速率決定步驟：Rate = k₂[O][O₃]，含中間體 [O]，利用平衡消去：

    $$k_1[\text{O}_3] = k_{-1}[\text{O}_2][\text{O}] \implies [\text{O}] = \frac{k_1[\text{O}_3]}{k_{-1}[\text{O}_2]}$$
    $$\text{Rate} = k_2 \cdot \frac{k_1[\text{O}_3]}{k_{-1}[\text{O}_2]} \cdot [\text{O}_3] = \frac{k_1k_2}{k_{-1}}\cdot\frac{[\text{O}_3]^2}{[\text{O}_2]} = k\frac{[\text{O}_3]^2}{[\text{O}_2]}\ \checkmark$$

    速率定律中 O₂（生成物）出現在分母，這是快速平衡機構的特徵。

    ▸ 例題 2：Cl₂ + CHCl₃（非整數級數的來源）

    實驗速率定律：\(\text{Rate} = k[\text{Cl}_2]^{1/2}[\text{CHCl}_3]\)

    機構：\(\text{Cl}_2 \rightleftharpoons 2\text{Cl}\)（快速平衡），\(\text{Cl} + \text{CHCl}_3 \xrightarrow{k_2} \text{HCl}+\text{CCl}_3\)（慢），\(\text{CCl}_3+\text{Cl}\xrightarrow{k_3}\text{CCl}_4\)（快）

    展開解答

    平衡步驟消去 [Cl]：\(k_1[\text{Cl}_2]=k_{-1}[\text{Cl}]^2 \implies [\text{Cl}]=(k_1/k_{-1})^{1/2}[\text{Cl}_2]^{1/2}\)

    $$\text{Rate} = k_2(k_1/k_{-1})^{1/2}[\text{Cl}_2]^{1/2}[\text{CHCl}_3] = k[\text{Cl}_2]^{1/2}[\text{CHCl}_3]\ \checkmark$$
    洞察
    非整數級數幾乎都來自平衡步驟的開根號。
    Cl₂ 在快速平衡中解離為兩個 Cl，平衡式給出 [Cl] ∝ [Cl₂]^(1/2)，導致 1/2 級。
    ▸ 例題 3：判斷 2NO + O₂ → 2NO₂ 的正確機構

    實驗速率定律：Rate = k[NO]²[O₂]，以下哪個機構可能正確？

    (b) \(\text{NO}+\text{O}_2\rightleftharpoons\text{NO}_3\)（快速平衡），\(\text{NO}_3+\text{NO}\to2\text{NO}_2\)（慢）

    (d) \(2\text{NO}\rightleftharpoons\text{N}_2\text{O}_2\)（快速平衡），\(\text{N}_2\text{O}_2+\text{O}_2\to2\text{NO}_2\)（慢）

    展開解答

    機構(b)：消去 [NO₃]：\(k_1[\text{NO}][\text{O}_2]=k_{-1}[\text{NO}_3]\)，代入第二步：

    $$\text{Rate} = k_2 \cdot\frac{k_1}{k_{-1}}[\text{NO}][\text{O}_2]\cdot[\text{NO}] = k[\text{NO}]^2[\text{O}_2]\ \checkmark$$

    機構(d)：消去 [N₂O₂]：\(k_1[\text{NO}]^2=k_{-1}[\text{N}_2\text{O}_2]\)，代入第二步：

    $$\text{Rate} = k_2\cdot\frac{k_1}{k_{-1}}[\text{NO}]^2\cdot[\text{O}_2] = k[\text{NO}]^2[\text{O}_2]\ \checkmark$$

    (b) 和 (d) 均滿足條件，僅憑速率定律無法區分，需要偵測中間體 NO₃ 或 N₂O₂。

    15.7　穩態近似法（Steady-State Approximation）

    一、核心假設

    $$\frac{d[\text{中間體}]}{dt} = 0 \iff \text{生成速率} = \text{消耗速率}$$

    物理意義：中間體一生成就立刻被消耗，濃度維持極低但穩定的值。

    二、穩態近似 vs. 快速平衡

    快速平衡法穩態近似法
    假設正逆反應速率相等中間體濃度不隨時間改變
    適用條件第一步明顯為快速平衡無法明確指定速率決定步驟
    普遍性較受限更普遍，快速平衡是其特例

    三、操作步驟

  • 寫出反應機構
  • 找出所有中間體
  • 對每個中間體：生成速率之和 = 消耗速率之和
  • 解出 [中間體] 的表達式
  • 寫出整體反應速率定律
  • 代入 [中間體]，消去中間體濃度

    • 四、例題

    ▸ 例題 1：2NO + H₂ → N₂O + H₂O

    機構：\(2\text{NO}\rightleftharpoons\text{N}_2\text{O}_2\)（步驟 1），\(\text{N}_2\text{O}_2+\text{H}_2\xrightarrow{k_2}\text{N}_2\text{O}+\text{H}_2\text{O}\)（步驟 2）

    展開解答

    中間體：N₂O₂，穩態：\(k_1[\text{NO}]^2 = k_{-1}[\text{N}_2\text{O}_2] + k_2[\text{N}_2\text{O}_2][\text{H}_2]\)

    $$[\text{N}_2\text{O}_2] = \frac{k_1[\text{NO}]^2}{k_{-1}+k_2[\text{H}_2]}$$
    $$\text{Rate} = \frac{k_1k_2[\text{NO}]^2[\text{H}_2]}{k_{-1}+k_2[\text{H}_2]}$$

    兩個極限：

    • \(k_{-1} \gg k_2[\text{H}_2]\)：Rate ≈ \(\frac{k_1k_2}{k_{-1}}[\text{NO}]^2[\text{H}_2]\)（三級，同快速平衡）
    • \(k_2[\text{H}_2] \gg k_{-1}\)：Rate ≈ \(k_1[\text{NO}]^2\)（對 H₂ 零級，第一步為速率決定）
    ▸ 例題 2：N₂O₅ 分解（兩個中間體）

    機構含 NO₃ 和 NO 兩個中間體，推導結果：

    展開解答

    對 NO 的穩態：\(k_2[\text{NO}_3][\text{NO}_2] = k_3[\text{NO}_3][\text{NO}]\)，得 \([\text{NO}]=k_2[\text{NO}_2]/k_3\)

    代入對 NO₃ 的穩態，最終得：

    $$\text{Rate} = \frac{2k_1k_2}{k_{-1}+2k_2}[\text{N}_2\text{O}_5] = k[\text{N}_2\text{O}_5]$$

    與實驗的一級結果一致，其中複合速率常數 \(k = \frac{2k_1k_2}{k_{-1}+2k_2}\)。

    15.8　化學動力學模型（阿瑞尼士方程式）

    一、碰撞模型

    反應發生需要：

    1. 碰撞能量 ≥ 活化能 Eₐ
    2. 碰撞方向正確（立體因子）

    二、能量圖

    能量 | 過渡態（活化錯合物） | △ | /|\ | / | \ | Eₐ → / | \ ← Eₐ（逆）= Eₐ + |ΔE|（放熱時） | / | \ | / | \ | 反應物 / ΔE \ 生成物 |________/____________\________→ 反應進度
    重要區別
    • Eₐ：決定反應速率（Eₐ 越大，速率越慢）
    • ΔE：決定反應方向（熱力學），與速率無關
    • 逆反應活化能 = Eₐ − ΔE（放熱反應）

    三、阿瑞尼士方程式

    $$\boxed{k = Ae^{-E_a/RT}}$$
    • A（頻率因子）= 碰撞頻率 × 立體因子
    • Eₐ（活化能）：單位 J/mol
    • R = 8.3145 J/mol·K
    • T：絕對溫度（K）

    線性化形式（作圖求 Eₐ）

    $$\ln k = -\frac{E_a}{R}\cdot\frac{1}{T} + \ln A$$

    以 \(\ln k\) vs. \(1/T\) 作圖得直線，斜率 \(= -E_a/R\)，截距 \(= \ln A\)。

    兩點法

    $$\ln\frac{k_2}{k_1} = \frac{E_a}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)$$

    四、例題

    ▸ 例題 1：兩點法求 Eₐ 及預測 k

    HI 分解：Eₐ = 186 kJ/mol，T₁ = 555 K 時 k₁ = 3.52×10⁻⁷ L/mol·s。

    (a) 求 645 K 時的 k₂；(b) 欲使 k 增大 1000 倍，需升溫至幾 K？

    展開解答

    (a)

    $$\ln\frac{k_2}{k_1} = \frac{186\times10^3}{8.3145}\left(\frac{1}{555}-\frac{1}{645}\right) = 5.64$$
    $$k_2 = 282\times3.52\times10^{-7} = 9.93\times10^{-5}\ \text{L/mol·s}$$

    (b) ln(1000) = 6.908：

    $$\frac{1}{T_2} = \frac{1}{555} - \frac{6.908}{2.237\times10^4} = 1.493\times10^{-3} \implies T_2 = 670\ \text{K}$$
    ▸ 例題 2：由 ln k vs. 1/T 圖求多個量

    (CH₃)₃CBr + OH⁻ 反應，ln k vs. 1/T 直線：斜率 = −1.10×10⁴ K，截距 = 33.5（k 單位 s⁻¹）。

    求 Eₐ、A、25°C 時的 k，並討論「溫度升高 10 K，速率加倍」的適用性。

    展開解答
    $$E_a = (8.3145)(1.10\times10^4) = 91.5\ \text{kJ/mol}$$
    $$A = e^{33.5} = 3.93\times10^{14}\ \text{s}^{-1}$$
    $$k_{25°C} = e^{-3.43} = 3.25\times10^{-2}\ \text{s}^{-1}$$

    25→35°C 實際倍率：

    $$\frac{k_{35}}{k_{25}} = e^{1.197} = 3.3\ \text{倍（並非加倍）}$$

    「升高 10 K 速率加倍」對應的 Eₐ ≈ 53 kJ/mol，對 Eₐ 偏高的反應誤差很大。

    回到頂端

    15.9　催化劑（Catalysis）

    一、定義與作用原理

    催化劑：能加速反應速率但本身不被消耗的物質。

    作用：提供一條活化能較低的替代路徑。

    催化劑的關鍵性質
    • 降低 Eₐ（活化能）
    • 不改變 ΔE（反應熱）
    • 不改變平衡常數 K
    • 同時加速正反應與逆反應
    • 催化反應的 ln k vs. 1/T 圖斜率絕對值較小

    二、均相 vs. 異相催化

    均相催化異相催化
    定義與反應物同相與反應物不同相
    常見形式液相酸鹼、酵素固體金屬、金屬氧化物
    優點均勻接觸、選擇性高易回收、耐高溫

    三、異相催化——四個基本步驟

  • 吸附與活化：反應物分子吸附在催化劑表面，相關化學鍵削弱
  • 表面遷移：吸附分子在表面移動，彼此靠近
  • 表面反應：形成新化學鍵，生成產物
  • 脫附：產物與表面結合力弱，離開表面
    • 名詞辨析
    吸附（Adsorption）：物質聚集在另一物質表面
    吸收（Absorption）：物質進入另一物質內部（如海綿吸水）

    四、異相催化的重要實例

    4.1 Haber 製程——合成氨

    $$\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g)$$
    • 催化劑：鐵（Fe），現代工業使用 Fe + K + Ca 混合物
    • 鐵與氮的結合強度「恰好適中」：夠強防止 N 重新結合成 N₂，夠弱讓 N+H 形成 NH₃
    • Fritz Haber 測試超過 1000 種催化劑後選定鐵

    4.2 乙烯氫化——製造飽和脂肪

    $$\text{C}_2\text{H}_4(g) + \text{H}_2(g) \xrightarrow{\text{Pt/Pd/Ni}} \text{C}_2\text{H}_6(g)$$

    工業用途：將不飽和脂肪（液態油）轉化為飽和脂肪（固態，如人造奶油）。

    機制：H₂ 吸附於金屬表面，H-H 鍵斷裂；C₂H₄ 的 C=C π 鍵削弱；表面 H 原子逐一轉移至碳原子；C₂H₆ 脫附。

    4.3 SO₂ 的氧化——環境與工業的雙面性

    面向說明
    負面：酸雨空氣中塵粒和水滴催化 SO₂ → SO₃，SO₃ + H₂O → H₂SO₄，造成酸雨危害
    正面：工業製硫酸以 Pt/V₂O₅ 固體為催化劑，催化 SO₂ + O₂ → SO₃，再製成 H₂SO₄

    4.4 汽車觸媒轉化器

    以鉑（Pt）和銠（Rh）沉積在陶瓷蜂巢上，處理廢氣：

    廢氣成分轉化反應主要催化劑
    CO2CO + O₂ → 2CO₂Pt
    烴類烴 + O₂ → CO₂ + H₂OPt
    NO2NO → N₂ + O₂Rh（特別有效）
    負面效應
    • 轉化器也可能催化 SO₂ → SO₃，SO₃ 與水蒸氣生成 H₂SO₄
    • 鉛汽油中的四乙基鉛會毒化催化劑（catalyst poisoning），是鉛汽油被禁用的主因之一

    4.5 石油脫硫

    天然石油含硫醇（R-SH），燃燒產生 SO₂。脫硫反應：

    $$\text{R-SH} \to \text{R-H} + \text{S}$$

    催化劑：鉬（Mo）、鈷（Co）、硫的混合物。機制：硫醇吸附後 S-H 鍵斷裂，H 轉移至 R 片段形成 R-H，S 留在表面。

    五、均相催化的重要實例

    5.1 NO 對臭氧的雙重效應

    對流層（低層）— 促進 O₃ 生成

    高溫燃燒產生 NO，NO 氧化成 NO₂，NO₂ 光分解產生 O 原子，O + O₂ → O₃（光化學煙霧）

    平流層（高層）— 促進 O₃ 分解

    NO + O₃ → NO₂ + O₂；NO₂ + O → NO + O₂；整體：O₃ + O → 2O₂（NO 為催化劑，破壞臭氧層）

    5.2 氟氯碳化物（Freons/CFCs）與臭氧破洞

    Freon-12（CCl₂F₂）在平流層被紫外光分解產生 Cl 原子：

    $$\text{CCl}_2\text{F}_2 \xrightarrow{h\nu} \text{CClF}_2 + \text{Cl}$$

    Cl 催化 O₃ 分解：

    $$\text{Cl} + \text{O}_3 \to \text{ClO} + \text{O}_2$$
    $$\text{ClO} + \text{O} \to \text{Cl} + \text{O}_2$$

    整體：O₃ + O → 2O₂，Cl 為催化劑，一個 Cl 原子可摧毀數萬個 O₃ 分子。目前 Freons 已在全球被禁用（噴霧罐、冷媒等）。

    5.3 酸催化——乙烯水合製乙醇

    $$\text{CH}_2{=}\text{CH}_2 + \text{H}_2\text{O} \xrightarrow{\text{H}^+} \text{CH}_3\text{CH}_2\text{OH}$$

    機制：H⁺ 攻擊 C=C 雙鍵形成碳陽離子中間體（缺八隅體，活性高）→ 與 H₂O 反應 → 脫去 H⁺（催化劑重生）。

    六、酵素催化（Enzyme Catalysis）

    6.1 結構與特性

    酵素是由 α-胺基酸組成的蛋白質大分子，折疊後形成活性位點（active site），賦予酵素高度專一性。

    6.2 催化機構

    $$\text{E} + \text{S} \underset{k_{-1}}{\stackrel{k_1}{\rightleftharpoons}} \text{E·S} \xrightarrow{k_2} \text{E} + \text{P}$$
    符號意義
    E酵素（enzyme）
    S受質（substrate）
    E·S酵素-受質複合體，反應在此發生
    P產物，釋放後酵素重新利用

    6.3 米氏方程式（Michaelis-Menten Equation）

    由穩態近似推導：

    $$\text{Rate} = \frac{k_2[\text{E}]_T[\text{S}]}{K_m + [\text{S}]}$$

    其中米氏常數 \(K_m = (k_{-1}+k_2)/k_1\)，\([\text{E}]_T = [\text{E}]+[\text{E·S}]\)。

    [S] 的範圍近似結果行為
    [S] ≪ KₘRate ≈ (k₂[E]ₜ/Kₘ)[S]一級反應
    [S] ≫ KₘRate ≈ k₂[E]ₜ = Vₘₐₓ零級反應（活性位點飽和）

    6.4 羧肽酶 A（Carboxypeptidase-A）

    含 307 個胺基酸、含 Zn²⁺ 的蛋白酶，負責切除蛋白質鏈末端的胺基酸。Zn²⁺ 極化 C=O 鍵，使鄰近 C-N 鍵更容易斷裂。

    6.5 酵素的效率

    碳酸酐酶：每個酵素分子每秒催化超過 600,000 個 CO₂ 分子反應。微量酵素即可維持生命所需速率。

    6.6 極端酵素（Extremozymes）

    來自極端環境微生物（嗜熱、嗜冷、嗜酸、嗜鹼等）的酵素，可在工業常規酵素無法運作的條件下發揮催化活性。全球工業酵素市場超過 70 億美元。

    七、例題

    ▸ 例題 1：催化劑對活化能的影響

    H₂O₂ 分解：無催化劑 Eₐ = 70.0 kJ/mol，加 MnO₂ 後 Eₐ = 42.0 kJ/mol（20°C）。

    (a) 求 k 比值；(b) 需升溫至幾度才能讓未催化速率等於 20°C 催化速率？

    展開解答

    (a) T = 293 K，A 相同：

    $$\frac{k_{\text{催化}}}{k_{\text{未催化}}} = e^{(70000-42000)/(8.3145\times293)} = e^{11.5} \approx 9.9\times10^4$$

    催化劑使速率常數增大約 10 萬倍！

    (b) 令兩者 k 相等：

    $$T_2 = \frac{70000\times293}{42000} = 488\ \text{K} = 215°\text{C}$$
    ▸ 例題 2：N₂O 在 Pt 表面的零級分解

    \(2\text{N}_2\text{O}(g) \xrightarrow{\text{Pt}} 2\text{N}_2 + \text{O}_2\)，[N₂O]₀ = 0.50 mol/L，k = 2.4×10⁻⁴ mol/L·s。

    (a) 為何是零級？(b) 反應物完全耗盡時間？(c) [N₂O]₀ 加倍後，耗盡時間如何變化？

    展開解答

    (a) Pt 表面位點有限，[N₂O] 夠高時表面完全飽和，速率由表面反應決定，為常數。

    (b) 零級，令 [A] = 0：\(t = [\text{A}]_0/k = 0.50/(2.4\times10^{-4}) \approx 2100\ \text{s}\)

    (c) [N₂O]₀ = 1.00 mol/L：\(t = 1.00/(2.4\times10^{-4}) \approx 4200\ \text{s}\)，剛好加倍，驗證零級反應 \(t_{1/2}\propto[\text{A}]_0\)。

    ▸ 例題 3：酵素動力學推導（米氏方程式）

    由穩態近似對 E·S 推導完整速率定律，設 [E]ₜ = [E] + [E·S]。

    展開解答

    穩態：\(k_1[\text{E}][\text{S}] = (k_{-1}+k_2)[\text{E·S}]\)

    令 [E] = [E]ₜ − [E·S]：

    $$[\text{E·S}] = \frac{k_1[\text{E}]_T[\text{S}]}{k_{-1}+k_2+k_1[\text{S}]} = \frac{[\text{E}]_T[\text{S}]}{K_m+[\text{S}]}$$
    $$\text{Rate} = k_2[\text{E·S}] = \frac{k_2[\text{E}]_T[\text{S}]}{K_m+[\text{S}]}$$

    低 [S]：Rate ≈ \((k_2[\text{E}]_T/K_m)[\text{S}]\)（一級）；高 [S]：Rate → \(k_2[\text{E}]_T = V_{\max}\)（零級）。

    化學動力學（第 15 章） │ ├── 速率定律 │ ├── 微分速率定律 Rate = k[A]ⁿ[B]ᵐ │ │ └── 由初始速率法決定 │ └── 積分速率定律 [A] 對 t 的函數 │ ├── 零級：[A] vs. t → 直線，t₁/₂ = [A]₀/2k │ ├── 一級：ln[A] vs. t → 直線，t₁/₂ = 0.693/k（獨立於[A]₀） │ ├── 二級：1/[A] vs. t → 直線，t₁/₂ = 1/(k[A]₀) │ └── n 級通式：[A]^(1−n)−[A]₀^(1−n) = (n−1)kt │ ├── 反應機構 │ ├── 基元步驟（分子數 → 速率定律） │ ├── 中間體 │ │ ├── 快速平衡法：利用 k₁[A] = k₋₁[I] 消去 │ │ └── 穩態近似法：d[I]/dt = 0（更普遍） │ └── 速率決定步驟（最慢步驟） │ ├── 溫度效應 │ └── Arrhenius 方程式：k = Ae^(−Eₐ/RT) │ ├── 作圖法：ln k vs. 1/T，斜率 = −Eₐ/R │ └── 兩點法：ln(k₂/k₁) = (Eₐ/R)(1/T₁ − 1/T₂) │ └── 催化劑 ├── 均相（酸鹼催化、NO 效應、Freons 問題） ├── 異相（Haber、氫化、SO₂、觸媒轉化器、脫硫） └── 酵素（E·S 複合體、米氏方程式 Vmax）
    考試常見重點整理
    1. 速率定律只能由實驗決定，k 只與溫度有關
    2. 判斷反應級數：三種作圖法；或觀察半衰期是否固定
    3. 一級反應：\(t_{1/2} = 0.693/k\)，與 [A]₀ 無關；連續 t₁/₂ 相等
    4. 二級反應：\(t_{1/2} = 1/(k[\text{A}]_0)\)；連續 t₁/₂ 加倍
    5. n 級連續 t₁/₂ 公比 = \(2^{n-1}\)
    6. 有效機構：①相加等於整體方程式；②速率定律與實驗一致
    7. 穩態近似 ⊃ 快速平衡（當 k₋₁ ≫ k₂ 時兩者等價）
    8. Arrhenius：\(\ln k = (-E_a/R)(1/T) + \ln A\)，斜率 = \(-E_a/R\)
    9. 催化劑降低 Eₐ，不改變 ΔE 和 K；同時加速正逆反應
    10. 酵素：低 [S] 一級，高 [S] 零級（Vₘₐₓ，飽和）
