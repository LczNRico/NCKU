① 分離變數法

Separation of Variables

標準形式
\[ \frac{dy}{dx} = \frac{f(x)}{g(y)} \quad \Rightarrow \quad g(y)\,dy = f(x)\,dx \]
解題步驟
  1. 把含 y 的移到左邊，含 x 的移到右邊
  2. 兩邊同時積分
  3. 代入初始條件求積分常數 C
解：\(\displaystyle \int g(y)\,dy = \int f(x)\,dx + C\)

化學範例：一階反應 d[A]/dt = −k[A] → [A] = [A]₀e^(−kt)

② 齊次 ODE

Homogeneous ODE

辨識方式
⚠️ M(x,y) 和 N(x,y) 都是同樣 n 次的齊次函數
→ 驗證：M(λx, λy) = λⁿM(x,y)，N 同理
解題步驟
  1. 令 \(v = y/x\)，即 \(y = vx\)
  2. 求 \(dy/dx = v + x\,dv/dx\)（乘積規則）
  3. 代入原方程，化簡後變成可分離變數的 ODE
  4. 對 v, x 分離變數積分
  5. 最後把 v = y/x 代回
換元核心：\(\displaystyle \frac{dy}{dx} = v + x\frac{dv}{dx}\)
③ 函數型換元

Substitution: y' = f(ax + by + c)

辨識方式
⚠️ 右邊是 x 和 y 的線性組合的函數，如 y' = sin(x + 2y)
解題步驟
  1. 令 \(t = ax + by + c\)
  2. 取全微分：\(dt = a\,dx + b\,dy\)，即 \(\frac{dt}{dx} = a + b\frac{dy}{dx}\)
  3. 解出 \(dy/dx = (dt/dx - a)/b\)，代入原方程
  4. 得到只含 t, x 的可分離 ODE
  5. 積分後代回 t = ax + by + c
換元核心：\(\displaystyle \frac{dt}{dx} = a + b\,f(t)\)
④ 恰當方程

Exact ODE

辨識方式
✅ 恰當條件：\(\displaystyle \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\)
解題步驟
  1. 確認恰當條件成立
  2. 對 M 積分（對 x 積分，y 當常數）：\(F = \int M\,dx + g(y)\)
  3. 對 F 做 ∂/∂y，令其等於 N，解出 g'(y)
  4. 積分求 g(y)
  5. 寫出解：F(x, y) = C
解：\(F(x,y) = C\)，其中 \(\partial F/\partial x = M\)，\(\partial F/\partial y = N\)

⚠️ Step 3 解出的 g'(y) 必須只含 y，不含 x，否則恰當條件有誤

⑤ 積分因子

Integrating Factor

使用時機
⚠️ ∂M/∂y ≠ ∂N/∂x，無法直接用恰當方程解法
四種情況
檢驗條件 積分因子
\(\displaystyle\frac{\partial M/\partial y - \partial N/\partial x}{N} = f(x)\)（只含 x） \(I(x) = e^{\int f(x)\,dx}\)
\(\displaystyle\frac{\partial M/\partial y - \partial N/\partial x}{-M} = f(y)\)（只含 y） \(I(y) = e^{\int f(y)\,dy}\)
\(\displaystyle\frac{\partial M/\partial y - \partial N/\partial x}{N - M} = f(x+y)\) \(I(x+y) = e^{\int f(x+y)\,d(x+y)}\)
\(\displaystyle\frac{\partial M/\partial y - \partial N/\partial x}{Ny - Mx} = f(xy)\) \(I(xy) = e^{\int f(xy)\,d(xy)}\)
解題步驟
  1. 計算 ∂M/∂y − ∂N/∂x
  2. 依序用四種分母試除，看哪個結果只含單一變數
  3. 找到對應的積分因子 I
  4. 把 I 乘進原方程：IM dx + IN dy = 0
  5. 新方程是恰當方程，用④的步驟求解
