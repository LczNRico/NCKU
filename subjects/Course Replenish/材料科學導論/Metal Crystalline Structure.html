Detailed Information（詳細資訊）

1. FCC (Face-Centered Cubic) 面心立方

Number of Atoms per Unit Cell（每單位晶胞原子數）:

  • Corner atoms: 8 × 1/8 = 1
  • Face-centered atoms: 6 × 1/2 = 3
  • Total = 4 atoms

Atomic Packing Factor（原子堆積因子）:

APF = (Volume of atoms) / (Volume of unit cell)
APF = (4 × 4πr³/3) / a³
With a = 2√2 r:
APF = 0.74 = 74%

Coordination Number（配位數）:

Each atom touches 12 nearest neighbors

Unit Cell Length（單位晶胞長度）:

a = 2√2 r ≈ 2.828r
r = a√2/4 ≈ 0.354a

Common Examples（常見實例）:

Al, Cu, Au, Ag, Pb, Ni, Pt, γ-Fe (above 912°C)

2. BCC (Body-Centered Cubic) 體心立方

Number of Atoms per Unit Cell（每單位晶胞原子數）:

  • Corner atoms: 8 × 1/8 = 1
  • Body-centered atom: 1 × 1 = 1
  • Total = 2 atoms

Atomic Packing Factor（原子堆積因子）:

APF = (Volume of atoms) / (Volume of unit cell)
APF = (2 × 4πr³/3) / a³
With a = 4r/√3:
APF = 0.68 = 68%

Coordination Number（配位數）:

Each atom touches 8 nearest neighbors

Unit Cell Length（單位晶胞長度）:

a = 4r/√3 ≈ 2.309r
r = a√3/4 ≈ 0.433a

Common Examples（常見實例）:

α-Fe (below 912°C), Cr, W, Mo, V, Na, K

3. HCP (Hexagonal Close-Packed) 六方最密堆積

Number of Atoms per Unit Cell（每單位晶胞原子數）:

  • Corner atoms: 12 × 1/6 = 2
  • Face-centered atoms (top & bottom): 2 × 1/2 = 1
  • Interior atoms: 3 × 1 = 3
  • Total = 6 atoms

Atomic Packing Factor（原子堆積因子）:

Same as FCC (both are close-packed)
APF = 0.74 = 74%

Coordination Number（配位數）:

Each atom touches 12 nearest neighbors

  • 6 in the same layer
  • 3 in the layer above
  • 3 in the layer below

Unit Cell Length（單位晶胞長度）:

a = 2r
c = √(8/3) a ≈ 1.633a (ideal ratio)
r = a/2 = 0.5a

Note:

The ideal c/a ratio is 1.633, but actual values vary:

  • Ideal: c/a = 1.633
  • Zn: c/a = 1.86
  • Mg: c/a = 1.62
  • Ti: c/a = 1.59
  • Co: c/a = 1.62

Common Examples（常見實例）:

Mg, Zn, Ti, Co, Cd, Zr, Be

Key Comparisons（關鍵比較）

Packing Efficiency（堆積效率）:

  • Highest: FCC = HCP (0.74)
  • Lower: BCC (0.68)

Ductility（延展性）:

  • Most ductile（最具延展性）: FCC (12 slip systems)
  • Moderate（中等）: BCC (48 slip systems, but higher critical resolved shear stress)
  • Least ductile（延展性最低）: HCP (limited slip systems)

Slip Systems（滑移系統）:

  • FCC: 12 systems {111}⟨110⟩
  • BCC: 48 systems {110}⟨111⟩, {112}⟨111⟩, {123}⟨111⟩
  • HCP: 3 systems {0001}⟨11̄20⟩ (basal slip)

Stacking Sequence（堆疊順序）:

  • FCC: ABCABC...
  • HCP: ABAB...
  • BCC: Not close-packed

Calculation Examples（計算範例）

Example 1: Copper (Cu) - FCC

Given: a = 0.3615 nm

Find: Atomic radius

Solution:
r = a√2/4 = 0.3615 × 1.414/4
r = 0.128 nm

Example 2: Iron (α-Fe) - BCC

Given: r = 0.124 nm

Find: Lattice parameter

Solution:
a = 4r/√3 = 4 × 0.124/1.732
a = 0.286 nm

Example 3: Magnesium (Mg) - HCP

Given: a = 0.321 nm, c/a = 1.624

Find: c parameter

Solution:
c = a × 1.624 = 0.321 × 1.624
c = 0.521 nm
