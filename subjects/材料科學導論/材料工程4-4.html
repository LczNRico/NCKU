4.4

組成規格

通常需要用其組成元素來表示合金的組成（composition）（或濃度（concentration））5。指定組成的兩種最常見方式是重量（或質量）百分比和原子百分比。重量百分比（weight percent, wt%）的基礎是特定元素的重量相對於合金總重量的比例。對於含有由1和2表示的兩個假設原子的合金，元素1的重量百分比濃度 C1 定義為：

重量百分比的計算（針對雙元素合金）
C1 = m1 / (m1 + m2) × 100 (4.3a)

其中 m1 和 m2 分別代表元素1和元素2的重量（或質量）。元素2的濃度也可以用類似的方式計算。6

原子百分比（atom percent, at%）計算的基礎是元素的莫耳數相對於合金中元素的總莫耳數。某指定質量的假設元素1的莫耳數 nm1 可以如下計算：

nm1 = m'1 / A1 (4.4)

這裡，m'1 和 A1 分別表示元素1的質量（以克為單位）和原子量。在包含元素1和元素2原子的合金中，以原子百分比表示的元素1濃度 C'1 定義為7：

原子百分比的計算（針對雙元素合金）
C'1 = nm1 / (nm1 + nm2) × 100 (4.5a)

同樣地，元素2的原子百分比也可以確定。8

原子百分比計算也可以基於原子數量而非莫耳數來進行，因為所有物質的一莫耳都含有相同數量的原子。

組成轉換

有時需要從一種組成方案轉換為另一種——例如，從重量百分比轉換為原子百分比。我們接下來提供以兩個假設元素1和2進行這些轉換的方程式。使用前一節的慣例（即，重量百分比以 C1 和 C2 表示，原子百分比以 C'1 和 C'2 表示，原子量為 A1 和 A2），我們將這些轉換方程式表示如下：

重量百分比轉換為原子百分比（針對雙元素合金）
C'1 = C1A2 / (C1A2 + C2A1) × 100 (4.6a)
C'2 = C2A1 / (C1A2 + C2A1) × 100 (4.6b)
原子百分比轉換為重量百分比（針對雙元素合金）
C1 = C'1A1 / (C'1A1 + C'2A2) × 100 (4.7a)
C2 = C'2A2 / (C'1A1 + C'2A2) × 100 (4.7b)

由於我們只考慮兩種元素，當意識到以下關係時，涉及前述方程式的計算會簡化：

C1 + C2 = 100 (4.8a)
C'1 + C'2 = 100 (4.8b)

單位體積質量轉換

此外，有時需要將濃度從重量百分比轉換為每單位體積材料的一種組分的質量（即從 wt% 單位到 kg/m³）；後者組成方案經常用於擴散計算（第5.3節）。以此基礎表示的濃度使用雙撇號表示（即 C''1 和 C''2），相關方程式如下：

重量百分比轉換為單位體積質量（針對雙元素合金）
C''1 = (C1 / (C1/ρ1 + C2/ρ2)) × 10³ (4.9a)
C''2 = (C2 / (C1/ρ1 + C2/ρ2)) × 10³ (4.9b)

對於密度 ρ 以 g/cm³ 為單位，這些表達式產生 C''1 和 C''2 的單位為 kg/m³。

此外，有時我們希望確定二元合金的密度和原子量，給定以重量百分比或原子百分比表示的組成。如果我們以 ρave 和 Aave 分別表示合金密度和原子量，則：

密度計算（針對雙元素金屬合金）
ρave = 100 / (C1/ρ1 + C2/ρ2) (4.10a)
ρave = (C'1A1 + C'2A2) / (C'1A1/ρ1 + C'2A2/ρ2) (4.10b)
原子量計算（針對雙元素金屬合金）
Aave = 100 / (C1/A1 + C2/A2) (4.11a)
Aave = (C'1A1 + C'2A2) / 100 (4.11b)

應該注意的是，方程式4.9和4.11並不總是準確的。在其推導中，假設合金總體積恰好等於各個元素體積的總和。對於大多數合金來說，這通常不是事實；然而，這是一個合理有效的假設，並且對於稀溶液和存在固溶體的組成範圍不會導致顯著誤差。

例題 4.3

組成轉換方程式的推導

推導方程4.6a。

解答

為了簡化此推導，我們假設質量以克為單位表示並用撇號表示（例如，m'1）。此外，合金總質量（以克為單位）M' 為：

M' = m'1 + m'2 (4.12)

使用 C'1 的定義（方程4.5a）並結合 nm1 的表達式（方程4.4）以及 nm2 的類似表達式，得到：

C'1 = nm1 / (nm1 + nm2) × 100
= (m'1/A1) / (m'1/A1 + m'2/A2) × 100 (4.13)

重新排列方程4.3a的克質量等效式得到：

m'1 = C1M' / 100 (4.14)

將此表達式及其 m'2 等效式代入方程4.13，得到：

C'1 = (C1M'/100A1) / (C1M'/100A1 + C2M'/100A2) × 100 (4.15)

簡化後，我們得到：

C'1 = C1A2 / (C1A2 + C2A1) × 100

這與方程4.6a相同。

例題 4.4

組成轉換——從重量百分比到原子百分比

確定由 97 wt% 鋁和 3 wt% 銅組成的合金的原子百分比組成。

解答

如果我們將各自的重量百分比組成表示為 CAl = 97 和 CCu = 3，代入方程4.6a和4.6b得到：

C'Al = CAlACu / (CAlACu + CCuAAl) × 100
= (97)(63.55 g/mol) / [(97)(63.55 g/mol) + (3)(26.98 g/mol)] × 100
= 98.7 at%

以及

C'Cu = CCuAAl / (CCuAAl + CAlACu) × 100
= (3)(26.98 g/mol) / [(3)(26.98 g/mol) + (97)(63.55 g/mol)] × 100
= 1.30 at%
