3.10 晶體學平面

晶體結構中平面的方位以類似的方式表示。同樣地，單位晶胞被選為基礎，三軸座標系統如圖3.5所示。除六方晶系外的所有晶系中，晶體學平面均以三個米勒指數（Miller indices）表示為 (hkl)。任何兩個相互平行的平面均為等效平面，並具有相同的指數。確定 h、k 和 l 指數的程序如下：

  1. 若該平面通過所選的原點，則必須在單位晶胞內透過適當的平移構造另一個平行平面，或在另一個單位晶胞的角落建立新的原點。8
  2. 此時，晶體學平面與三個軸的相交點或與三個軸平行的情況被確定（參考座標系統的原點）。這些與 x、y 和 z 軸的截距將分別被標記為 A、B 和 C。9
  3. 取這些數字的倒數。平行於某軸的平面被認為具有無限大的截距，因此指數為零。
  4. 然後將截距的倒數根據（即乘以）各自的 a、b 和 c 晶格參數進行規範化。即：
a/A   b/B   c/C
  1. 如有必要，透過乘以或除以公因數，將這三個數字轉換為最小整數組。10
  2. 最後，將整數指數（不以逗號分隔）括在括號中，即：(hkl)。h、k 和 l 整數分別對應於 x、y 和 z 軸的規範化截距倒數。

總結來說，h、k 和 l 指數可使用以下方程式確定：

h = na/A    (3.13a)
k = nb/B    (3.13b)
l = nc/C    (3.13c)

在這些表達式中，n 是將 h、k 和 l 化為整數所需的因數。

位於原點負側的截距以橫槓或負號標示在適當的指數上方。此外，反轉所有指數的方向會指定另一個與原點對側且距離相等的平行平面。圖3.10中表示了幾個低指數平面。

8選擇新原點時，建議採用以下程序：

若與原點相交的晶體學平面位於單位晶胞的某一面上，則將原點沿與該平面相交的軸平行移動一個單位晶胞距離。

若與原點相交的晶體學平面通過單位晶胞的某一軸，則將原點沿其他兩軸之一平行移動一個單位晶胞距離。

對於所有其他情況，將原點沿三個單位晶胞軸中的任一軸平行移動一個單位晶胞距離。

9這些截距點是晶格位置座標，其值使用第3.8節中概述的程序確定。

10有時不進行指數簡化（例如，對於第3.16節中描述的X射線繞射研究）；例如，(002)不簡化為(001)。此外，對於陶瓷材料，簡化指數平面的離子排列可能與未簡化平面不同。

解答

例題 3.11

指定晶體學平面的構造

在下列單位晶胞中構造一個(101)平面。

解答

為解決此問題，以相反順序執行前例中使用的程序。對於此(101)方向，

h = 1
k = 0
l = 1

使用這些 h、k 和 l 指數，我們要使用重新排列形式的方程式3.13a–3.13c來求解 A、B 和 C 的值。取 n 的值為1（因為這三個米勒指數均為整數）得到：

A = na/h = (1)(a)/1 = a

B = nb/k = (1)(b)/0 = ∞b

C = nc/l = (1)(c)/1 = c

因此，此(101)平面與 x 軸相交於 a（因為 A = a），與 y 軸平行（因為 B = ∞b），並與 z 軸相交於 c。在圖 (b) 所示的單位晶胞上，標示了此平面截距的位置。

唯一與 y 軸平行並與 x 和 z 軸在軸向座標 a 和 c 處相交的平面，如圖 (c) 所示。

請注意，參考單位晶胞的晶體學平面表示是用線條畫出來表示此平面與單位晶胞面（或這些面的延伸）的相交。以下指南有助於表示晶體學平面：

  • 如果 h、k 和 l 指數中有兩個為零[如(100)]，則該平面將平行於單位晶胞的一個面（見圖3.10a）。
  • 如果其中一個指數為零[如(110)]，則該平面將是平行四邊形，其兩側與相對的單位晶胞邊緣（或相鄰單位晶胞的邊緣）重合（見圖3.10b）。
  • 如果指數均不為零[如(111)]，則所有相交線都將通過單位晶胞面（見圖3.10c）。

原子排列

晶體學平面的原子排列通常是令人感興趣的，這取決於晶體結構。圖3.11和3.12分別表示了FCC和BCC晶體結構的(110)原子平面。也包括了簡化球形單位晶胞。請注意，每種情況的原子堆積都不同。圓圈代表位於晶體學平面中的原子，如同從完整尺寸硬球中心取一切片所獲得的。

包含所有具有相同原子堆積的平面的「晶族」（family）即為晶體學等效（crystallographically equivalent）的平面，即具有相同的原子堆積；晶族以括號中的指數表示，如{100}。例如，在立方晶體中，(111)、(111)、(111)、(111)、(111)、(111)、(111)和(111)平面都屬於{111}晶族。然而，對於四方晶體結構，{100}晶族僅包含(100)、(100)、(010)和(010)平面，因為(001)和(001)平面在晶體學上並不等效。此外，在立方系統中，具有相同指數的平面（無論順序和符號如何）都是等效的。例如，(123)和(312)都屬於{123}晶族。

六方晶體

對於具有六方對稱性的晶體，希望等效平面具有相同的指數；如同方向一樣，這是透過圖3.8a所示的Miller-Bravais系統來完成的。此慣例導致四指數 (hkil) 方案，在大多數情況下較為有利，因為它更清楚地標示六方晶體中平面的方位。i 是由 h 和 k 的總和確定，透過

i = −(h + k)    (3.14)

否則，三個 h、k 和 l 指數對於兩種索引系統都是相同的。
