4.3

固體中的雜質

僅由一種原子類型組成的純金屬是不可能的；雜質或外來原子總是存在的，且其中一些以晶體點缺陷的形式存在。事實上，即使使用相對精密的技術，也很難將金屬精煉到純度超過 99.9999%。在此水平下，在 1 m³ 材料中存在約 10²² 至 10²³ 個雜質原子。大多數常見的金屬並非高度純淨；相反地，它們是合金（alloys），其中雜質原子被刻意添加以賦予材料特定的特性。通常，合金化用於金屬以改善機械強度和耐腐蝕性。例如，純銀是 92.5% 銀–7.5% 銅合金。在正常的環境條件下，純銀具有高度抗腐蝕性，但也非常軟。與銅合金化可顯著增強機械強度，而不會明顯降低耐腐蝕性。

向金屬中添加雜質原子會形成固溶體（solid solution）和/或新的第二相（second phase），這取決於雜質的種類、其濃度和合金的溫度。本節討論固溶體的概念；新相的形成延後至第9章處理。

與雜質和固溶體相關的幾個術語值得提及。關於合金，溶質（solute）和溶劑（solvent）是常用的術語。溶劑（Solvent）是存在量最多的元素或化合物；有時，溶劑原子也稱為主原子（host atoms）。溶質（Solute）用於表示存在量較少的元素或化合物。

固溶體

當溶質原子添加到主材料中時，只要形成的結構保持不變，就會形成固溶體。也許與液體溶液進行類比是有用的。如果將兩種可互溶的液體（如水和酒精）混合，則產生的液體溶液分子會混合，其組成在整個過程中是均勻的。固溶體在組成上也是均勻的；雜質原子在固體內隨機且均勻地分散。

雜質點缺陷存在於固溶體中，其中有兩種類型：置換型（substitutional）和間隙型（interstitial）。對於置換型類型，溶質原子取代或替代主原子的位置（圖4.2）。溶質和溶劑原子的幾個特徵決定了前者在後者中溶解的程度。這些表示為四個休謨-羅色里法則（Hume-Rothery rules），如下所示：

休謨-羅色里法則

  1. 原子尺寸因子（Atomic size factor）。只有當兩種原子類型之間的原子半徑差小於約 ±15% 時，這種類型的固溶體才能容納可觀的溶質量。否則，溶質原子會造成顯著的晶格扭曲並形成新的相。
  2. 晶體結構（Crystal structure）。對於可觀的固溶度，兩種原子類型的金屬晶體結構必須相同。
  3. 電負度因子（Electronegativity factor）。一種元素的電正性越強，另一種元素的電負性越強，它們形成金屬間化合物而非置換型固溶體的可能性就越大。
  4. 化合價（Valences）。在其他因素相同的情況下，金屬更傾向於溶解另一種化合價較高的金屬，而不是溶解化合價較低的金屬。

置換型固溶體的一個例子見於銅和鎳。這兩種元素在所有比例下完全互溶。關於上述控制溶解度程度的規則，銅和鎳的原子半徑分別為 0.128 和 0.125 nm；兩者都具有 FCC 晶體結構；它們的電負度分別為 1.9 和 1.8（圖2.9）。最後，最常見的化合價對於銅為 +1（雖然有時可以是 +2）和鎳為 +2。

間隙型固溶體

對於間隙型固溶體，雜質原子填充主原子之間的空隙或間隙（見圖4.2）。對於 FCC 和 BCC 晶體結構，都有兩種類型的間隙位置——四面體（tetrahedral）和八面體（octahedral）；這些是由最近鄰主原子的數量來區分的，即配位數。四面體位置的配位數為 4；從周圍主原子的中心畫出的直線形成四面體。然而，對於八面體位置，配位數為 6；連接這六個球心而產生的八面體。3 對於 FCC，有兩種類型的八面體位置，其代表性點座標為 0 ½ 1 和 ½ ½ ½。單個四面體位置類型的代表性座標為 ¼ ¼ ¼。4 這些位置在 FCC 單位晶胞內的位置標註於圖 4.3a。同樣地，對於 BCC，有兩種八面體和一種四面體類型。八面體位置的代表性座標如下：½ ½ 0 和 ½ 1 0；對於 BCC 四面體，1 ½ ¼ 是一個代表性座標。圖 4.3b 顯示了 BCC 單位晶胞內這些位置的位置。4

圖 4.3 四面體和八面體間隙位置在 (a) FCC 和 (b) BCC 單位晶胞內的位置

金屬材料具有相對較高的原子堆積因子，這意味著這些間隙位置相對較小。因此，間隙雜質的原子直徑必須遠小於主原子的直徑。通常，間隙雜質原子的最大允許濃度很低（小於 10%）。即使非常小的雜質原子通常也比間隙位置大，因此，它們會在相鄰的主原子上引入一些晶格應變。問題 4.8 和 4.9 要求確定雜質原子半徑 r（以主原子半徑 R 表示），該半徑剛好適合 BCC 和 FCC 的四面體和八面體間隙位置，而不會引入任何晶格應變。

碳在添加到鐵中時形成間隙型固溶體；碳的最大濃度約為 2%。碳原子的原子半徑遠小於鐵的原子半徑：0.071 nm 相對於 0.124 nm。

陶瓷材料的固溶體也是可能的，如第12.5節所討論。

BCC 八面體間隙位置半徑的計算

計算剛好適合 BCC 八面體位置的雜質原子半徑 r（以主原子的原子半徑 R 表示，且不引入晶格應變）。

解答

如圖 4.3b 所示，對於 BCC，一個八面體間隙位置位於單位晶胞邊緣的中心。為了使間隙原子位於此位置而不引入晶格應變，該原子恰好接觸兩個相鄰的主原子，這兩個主原子是單位晶胞的角原子。圖示顯示 BCC 單位晶胞的 (100) 面上的原子；大圓圈代表主原子——小圓圈代表位於立方體邊緣上的八面體位置的間隙原子。

在此圖上標註了單位晶胞的邊長，即角原子中心之間的距離，根據方程 3.4，等於：

單位晶胞邊長 = 4R/√3

還顯示單位晶胞邊長等於主原子半徑 2R 的兩倍加上間隙原子半徑 2r 的兩倍；即：

單位晶胞邊長 = 2R + 2r

現在，將這兩個單位晶胞邊長表達式相等，我們得到：

2R + 2r = 4R/√3

並求解 r 以 R 表示：

2r = 4R/√3 − 2R = (2/√3 − 1)(2R)

或

r = (2/√3 − 1)R = 0.155R
