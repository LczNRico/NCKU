原子模型與量子力學基礎

原子模型

在十九世紀後期，人們認識到固體中涉及電子的許多現象無法用古典力學來解釋。隨之而來的是建立了一套原理和定律來控制原子和亞原子實體系統，這些原理和定律被稱為量子力學。理解電子在原子和結晶固體中的行為必然涉及量子力學概念的討論。然而，詳細探討這些原理超出了本教科書的範圍，這裡只給出非常表面和簡化的處理。

量子力學的一個早期分支是簡化的波爾原子模型，在這個模型中，假設電子圍繞原子核在離散的軌道中旋轉，任何特定電子的位置在其軌道方面或多或少地被明確定義。這個原子模型在圖2.1中表示。

另一個重要的量子力學原理規定電子的能量是量化的——也就是說，電子只被允許具有特定的能量值。電子可以改變能量，但在這樣做時，它必須做一個量子跳躍，要麼跳到一個允許的更高能量（伴隨能量的吸收），要麼跳到一個更低的能量（伴隨能量的發射）。通常，將這些允許的電子能量視為與能級或狀態相關是方便的。這些狀態不隨能量連續變化——也就是說，相鄰的狀態被有限的能量分開。例如，波爾氫原子的允許狀態在圖2.2a中表示。這些能量被視為負值，而零參考是未束縛或自由電子。當然，與氫原子相關的單個電子只填充這些狀態中的一個。

因此，波爾模型代表了描述原子中電子的早期嘗試，從位置（電子軌道）和能量（量化能級）兩個方面來描述。

波爾模型最終被發現有一些重大限制，因為它無法解釋涉及電子的幾個現象。通過波機械模型達成了解決方案，在這個模型中，電子被認為表現出波狀和粒子狀特性。在這個模型中，電子不再被視為在離散軌道中運動的粒子；相反，位置被認為是電子在原子核周圍各個位置的機率。換句話說，位置是通過機率分佈或電子雲來描述的。圖2.3比較了氫原子的波爾模型和波機械模型。在本教科書的過程中使用了這兩個模型；選擇取決於哪個模型允許最簡單的解釋。

量子數

在波力學中，原子中的每個電子都由四個參數特徵化，稱為量子數。電子機率密度（或軌道）的大小、形狀和空間取向由這些量子數中的三個指定。此外，波爾能級分離成電子子殼層，量子數決定每個子殼層內的狀態數。殼層由主量子數 n 指定，它可以取從一開始的整數值；有時這些殼層用字母 K、L、M、N、O 等來表示，分別對應於 n = 1、2、3、4、5 等，如表2.1所示。還要注意的是，這個量子數與波爾模型有關。這個量子數與電子軌道的大小（或其與核的平均距離）相關。

第二個（或方位角）量子數 l 指定子殼層。l 的值受 n 的大小限制，可以取從 l = 0 到 l = (n-1) 的整數值。每個子殼層用與 l 值相關的小寫字母——s、p、d 或 f——表示，如下所示：

此外，電子軌道形狀取決於 l。例如，s軌道是球形的並以原子核為中心（圖2.4）。p子殼層有三個軌道（如下所述）；每個軌道都有一個啞鈴形的節面（圖2.5）。這三個軌道的軸彼此垂直，類似於 x-y-z 座標系；因此，將這些軌道標記為 px、py 和 pz 是方便的（見圖2.5）。d子殼層的軌道配置更複雜，這裡不討論。

每個子殼層的電子軌道數由第三個（或磁性）量子數 ml 決定；ml 可以取 -l 和 +l 之間的整數值，包括0。當 l = 0 時，ml 只能有0的值，因為 +0 和 -0 是相同的。這對應於 s 子殼層，它只能有一個軌道。此外，對於 l = 1，ml 可以取 -1、0 和 +1 的值，三個 p 軌道是可能的。類似地，可以顯示出d子殼層有五個軌道，f子殼層有七個軌道。在沒有外部磁場的情況下，每個子殼層內的所有軌道在能量上是相同的。然而，當施加磁場時，這些子殼層狀態分裂，每個軌道呈現稍微不同的能量。表2.1呈現了 n、l 和 ml 量子數值和關係的總結。

因此，波爾模型被波力學進一步完善，其中三個新量子數的引入導致每個殼層內的電子子殼層。在這個基礎上比較這兩個模型在圖2.2a和2.2b中對氫原子進行了說明。

使用波機械模型的各種殼層和子殼層的完整能級圖顯示在圖2.6中。圖中的幾個特徵值得注意。首先，主量子數越小，能級越低；例如，1s狀態的能量小於2s狀態，而2s狀態又小於3s。其次，在每個殼層內，子殼層能級隨 l 量子數的值增加而增加。例如，3d狀態的能量比3p大，而3p又比3s大。最後，在一個殼層的狀態與相鄰殼層的狀態之間可能存在能量重疊，這在 d 和 f 狀態中尤其明顯；例如，3d狀態的能量通常比4s大。

電子構型

前面的討論主要涉及電子狀態——電子允許的能量值。為了確定這些狀態被電子填充的方式，我們使用包立排斥原理，這是另一個量子力學概念，它規定每個電子狀態最多只能容納兩個電子，而且必須具有相反的自旋。因此，s、p、d 和 f 子殼層可以分別容納總共2、6、10和14個電子；表2.1的右欄注明了前四個殼層中每個軌道可能占據的最大電子數。

當然，原子中並非所有可能的狀態都被電子填充。對於大多數原子，電子填充電子殼層和子殼層中最低可能的能量狀態，兩個電子具有相反的自旋佔據每個狀態。鈉原子的能量結構在圖2.7中示意性表示。當所有電子按照前述限制占據最低可能能量時，原子被稱為處於基態。然而，電子向更高能量狀態的躍遷是可能的，如第18章和第21章所討論的。原子的電子構型或結構表示這些狀態被填充的方式。在常規表示法中，每個子殼層中的電子數通過殼層-子殼層標記後的上標表示。例如，氫、氦和鈉的電子構型分別為1s¹、1s²和1s²2s²2p⁶3s¹。表2.2列出了一些更常見元素的電子構型。

在此時，關於這些電子構型的評論是必要的。首先，價電子是那些占據最外殼層的電子。這些電子極其重要；如將要看到的，它們參與原子之間的結合形成原子和分子聚合體。此外，許多固體的物理和化學性質都基於這些價電子。

另外，一些原子具有所謂的穩定電子構型——也就是說，最外層或價電子殼層內的狀態完全被填滿。通常，這對應於最外殼層僅s和p狀態被總共八個電子佔據，如氖、氬和氪原子；一個例外是氦，它只包含兩個1s電子。這些元素（Ne、Ar、Kr和He）是惰性或稀有氣體，它們在化學上實際上是不反應的。一些具有未填滿價殼層的元素原子通過獲得或失去電子來假設穩定的電子構型，通過與其他原子形成帶電離子或通過與其他原子共享電子來實現。這是一些化學反應的基礎，也是固體中原子結合的基礎，如第2.6節所解釋的。
