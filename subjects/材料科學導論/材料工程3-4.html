3.4 金屬晶體結構

這類材料的原子鍵結屬於金屬鍵，因此本質上是非方向性的。因此，最近鄰原子的數量和位置所受的限制極小；這使得大多數金屬晶體結構具有相對較大的最近鄰原子數和緻密的原子堆積。此外，對於金屬，當我們使用硬球模型來描述晶體結構時，每個球代表一個離子核心。表3.1列出了許多金屬的原子半徑。大多數常見金屬具有三種相對簡單的晶體結構：面心立方、體心立方和六方最密堆積。

面心立方晶體結構

面心立方(FCC)

許多金屬所具有的晶體結構具有立方幾何形狀的單位晶胞，原子位於每個角落和所有立方體面的中心。它被恰當地稱為面心立方(FCC)晶體結構。具有這種晶體結構的一些熟悉金屬包括銅、鋁、銀和金(另見表3.1)。圖3.1a顯示了FCC單位晶胞的硬球模型，而在圖3.1b中，原子中心由小圓圈表示，以提供更好的原子位置透視圖。圖3.1c中的原子聚集體代表由許多FCC單位晶胞組成的晶體部分。這些球體或離子核心沿面對角線彼此接觸；立方邊長a和原子半徑R的關係為：

有時候，我們需要確定與每個單位晶胞相關的原子數量。根據原子的位置，它可能被認為與相鄰單位晶胞共享——也就是說，只有該原子的某部分被分配給特定晶胞。例如，對於立方單位晶胞，完全位於內部的原子「屬於」該單位晶胞，位於晶胞面上的原子與另一個晶胞共享，而位於角上的原子則由八個晶胞共享。每個單位晶胞的原子數N可使用以下公式計算：

N = Ni + Nf/2 + Nc/8        (3.2)

其中

Ni = 內部原子數
Nf = 面上原子數
Nc = 角上原子數

對於FCC晶體結構，有八個角原子(Nc = 8)、六個面原子(Nf = 6)，沒有內部原子(Ni = 0)。因此，根據方程式3.2，

N = 0 + 6/2 + 8/8 = 4

或者說，總共有四個完整的原子可以分配給給定的單位晶胞。這在圖3.1a中描繪出來，其中僅在立方體的範圍內表示球體部分。該晶胞由立方體內部從角原子中心生成的體積組成，如圖所示。

角位置和面位置實際上是等效的——也就是說，將立方體角從原始角原子平移到面原子的中心不會改變晶胞結構。

配位數
原子堆積因子(APF)

晶體結構的另外兩個重要特性是配位數和原子堆積因子(APF)。對於金屬，每個原子都有相同數量的最近鄰或接觸原子，這就是配位數。對於面心立方，配位數為12。這可以通過檢查圖3.1a來確認：前面原子有四個角最近鄰原子圍繞著它，四個面原子在前面單位晶胞中與它接觸，以及四個等效的面原子位於前面(未顯示)的下一個單位晶胞中。

APF是單位晶胞內所有原子的球體體積總和(假設原子硬球模型)除以單位晶胞體積——即

原子堆積因子的定義
APF = 單位晶胞中原子的體積 / 總單位晶胞體積        (3.3)

對於FCC結構，原子堆積因子為0.74，這是對於所有具有相同直徑的球體可能的最大堆積。此APF的計算也包含在一個例題中。金屬通常具有相對較大的原子堆積因子，以最大化自由電子雲提供的屏蔽效應。

N = Ni + Nf/2 + Nc/6        (3.5)

也就是說，每個角原子的六分之一被分配給一個單位晶胞(而不是如立方結構的八分之一)。因為對於HCP，頂面和底面各有6個角原子(總共12個角原子)、2個面中心原子(來自頂面和底面各一個)和3個中間平面內部原子，使用方程式3.5可以得到HCP的N值為：

N = 3 + 2/2 + 12/6 = 6

因此，每個單位晶胞分配有6個原子。

FCC原子堆積因子的計算

證明FCC晶體結構的原子堆積因子為0.74。

解答

APF定義為單位晶胞中固體球體體積的分數，或

APF = 單位晶胞中原子的體積 / 總單位晶胞體積 = VS / VC

總原子和單位晶胞體積都可以用原子半徑R來計算。球體的體積為(4/3)πR3，並且因為每個FCC單位晶胞有四個原子，所以FCC原子(或球體)總體積為

VS = (4)(4/3)πR3 = (16/3)πR3

從例題3.1，總單位晶胞體積為

VC = 16R3√2

因此，原子堆積因子為

APF = VS / VC = [(16/3)πR3] / [16R3√2] = 0.74
