3.4 金屬晶體結構

這類材料中的原子鍵結為金屬鍵結，因此本質上是非方向性的。因此，對於最近鄰原子的數量和位置，限制很少；這導致大多數金屬晶體結構具有相對較多的最近鄰原子數量和緻密的原子堆積。此外，對於金屬，當我們使用晶體結構的硬球模型時，每個球體代表一個離子核心。表3.1列出了多種金屬的原子半徑。大多數常見金屬具有三種相對簡單的晶體結構：面心立方、體心立方和六方最密堆積。

面心立方晶體結構

許多金屬的晶體結構具有立方幾何形狀的單位晶胞，原子位於每個角落和所有立方體面的中心。它被恰當地稱為面心立方（FCC）晶體結構。一些具有這種晶體結構的常見金屬包括銅、鋁、銀和金（另見表3.1）。圖3.1a顯示了FCC單位晶胞的硬球模型，而在圖3.1b中，原子中心由小圓圈表示，以提供更好的原子位置透視圖。圖3.1c中的原子聚集體代表由許多FCC單位晶胞組成的晶體截面。這些球體或離子核心沿面對角線彼此接觸；立方體邊長a與原子半徑R的關係式為

a = 2R√2 (3.1)

有時，我們需要確定與每個單位晶胞相關的原子數量。根據原子的位置，它可能被認為與相鄰的單位晶胞共享——也就是說，只有原子的某些部分被分配給特定的晶胞。例如，對於立方單位晶胞，完全位於內部的原子「屬於」該單位晶胞，位於晶胞面上的原子與另一個晶胞共享，而位於角落的原子則由八個晶胞共享。每個單位晶胞的原子數N可以使用以下公式計算：

N = Ni + Nf/2 + Nc/8 (3.2)

其中

Ni = 內部原子的數量
Nf = 面原子的數量
Nc = 角原子的數量

FCC單位晶胞計算

對於FCC晶體結構，有八個角原子（Nc = 8）、六個面原子（Nf = 6）和零個內部原子（Ni = 0）。因此，根據方程式3.2，

N = 0 + 6/2 + 8/8 = 4

或者說，總共可以將四個完整的原子分配給給定的單位晶胞。這在圖3.1a中描繪出來，其中在立方體的範圍內僅表示球體的部分。該晶胞由從角原子中心產生的立方體體積組成，如圖所示。

角位置和面位置實際上是等效的——也就是說，將立方體角從原始角原子平移到面原子的中心不會改變晶胞結構。

晶體結構的另外兩個重要特徵是配位數和原子堆積因子（APF）。對於金屬，每個原子具有相同數量的最近鄰或接觸原子，這就是配位數。對於面心立方，配位數為12。這可以通過檢查圖3.1a來確認：前面的面原子周圍有四個角最近鄰原子，從後面接觸的四個面原子，以及位於前單位晶胞旁邊的四個其他等效面原子（未顯示）。

APF是單位晶胞內所有原子的球體體積（假設原子硬球模型）除以單位晶胞體積的總和——即，

APF = 單位晶胞內原子的體積 / 單位晶胞總體積 (3.3)

對於FCC結構，原子堆積因子為0.74，這是所有具有相同直徑的球體可能的最大堆積。此APF的計算也作為範例問題包含在內。金屬通常具有相對較大的原子堆積因子，以最大化自由電子雲提供的屏蔽效應。

體心立方晶體結構

另一種常見的金屬晶體結構也具有立方單位晶胞，原子位於所有八個角和立方體中心的單個原子。這被稱為體心立方（BCC）晶體結構。圖3.2c顯示了描繪此晶體結構的球體集合，而圖3.2a和3.2b分別是BCC單位晶胞的硬球和縮球模型圖。中心原子和角原子沿立方體對角線彼此接觸，單位晶胞長度a與原子半徑R的關係式為

a = 4R/√3 (3.4)

BCC晶體結構的配位數為8；每個中心原子的最近鄰是其八個角原子。由於BCC的配位數小於FCC，因此BCC的原子堆積因子也較低——0.68對0.74。

也可以有一個僅由位於立方體角落的原子組成的單位晶胞。這被稱為簡單立方（SC）晶體結構；硬球和縮球模型分別顯示在圖3.3a和3.3b中。沒有金屬元素具有這種晶體結構，因為其相對較低的原子堆積因子（見概念檢查3.1）。唯一的簡單立方元素是鋇，被認為是類金屬（或半金屬）。

為了計算HCP晶體結構每個單位晶胞的原子數，方程式3.2修改為：

N = Ni + Nf/2 + Nc/6 (3.5)

也就是說，六分之一的每個角原子被分配給一個單位晶胞（而不是與立方結構的1/8）。因為對於HCP，在每個頂部和底部面有6個角原子（總共12個角原子）、2個面中心原子（每個頂部和底部面各一個）和3個中間平面內部原子，使用方程式3.5可以得到HCP的N值為

N = 3 + 2/2 + 12/6 = 6

因此，6個原子被分配給每個單位晶胞。
