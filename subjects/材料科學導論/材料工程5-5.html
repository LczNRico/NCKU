5.5 影響擴散的因素

擴散物種

擴散係數 D 的大小指示原子擴散的速率。擴散物種和主體材料影響擴散係數。例如，在500°C的α-鐵中，自擴散和碳的互擴散之間在數量級上存在顯著差異，碳的互擴散的 D 值較大（3.0 × 10−21 對比 1.4 × 10−12 m2/s）。此比較也提供了空位和間隙模式擴散速率之間的對比，如前面所討論的。自擴散通過空位機制發生，而鐵中的碳擴散是間隙性的。

溫度

溫度對擴散係數和擴散速率有深遠的影響。例如，對於Fe在α-Fe中的自擴散，擴散係數在溫度從500°C上升到900°C時，大約增加了六個數量級（從3.0 × 10−21到1.8 × 10−15 m2/s）。擴散係數對溫度的依賴性為

D = D0 exp(−Qd/RT) (5.8)

其中

D0 = 與溫度無關的預指數因子（m2/s）

Qd = 擴散的活化能（J/mol 或 eV/atom）

R = 氣體常數，8.31 J/mol·K 或 8.62 × 10−5 eV/atom·K

T = 絕對溫度（K）

活化能可以被認為是產生一莫耳原子的擴散運動所需的能量。較大的活化能導致相對較小的擴散係數。表5.2列出了幾個擴散系統的 D0 和 Qd 值。

對方程式5.8取自然對數得到

ln D = ln D0 − (Qd/R)(1/T) (5.9a)

範例問題 5.4

擴散係數的確定

使用表5.2中的數據，計算鎂在鋁中於550°C時的擴散係數。

解答

此擴散係數可以通過應用方程式5.8來確定；來自表5.2的 D0 和 Qd 值分別為1.2 × 10−4 m2/s 和 130 kJ/mol。因此，

D = (1.2 × 10−4 m2/s) exp[−(130,000 J/mol)/((8.31 J/mol·K)(550 + 273 K))]
= 6.7 × 10−13 m2/s

範例問題 5.5

擴散係數活化能和預指數計算

圖5.7顯示了銅在金中擴散的擴散係數對數（以10為底）相對於絕對溫度倒數的圖。確定活化能和預指數的值。

解答

根據方程式5.9b，圖5.7中線段的斜率等於 −Qd/2.3R，並且在1/T = 0時的截距給出 log D0 的值。因此，活化能可以確定為

Qd = −2.3R(斜率) = −2.3R [Δ(logD)/Δ(1/T)]
= −2.3R [(log D1 − log D2)/(1/T1 − 1/T2)]

其中 D1 和 D2 分別是在1/T1 和 1/T2 處的擴散係數值。讓我們任意取 1/T1 = 0.8 × 10−3 (K)−1 和 1/T2 = 1.1 × 10−3 (K)−1。我們現在可以從圖5.7中線段讀取相應的 log D1 和 log D2 值。

[然而，在執行此操作之前，需要注意：圖5.7中的縱軸按對數（以10為底）縮放；但是，實際的擴散係數值在此軸上標示。例如，對於 D = 10−14 m2/s，D 的對數為 −14.0，而不是 10−14。此外，此對數縮放影響十年值之間的讀數；例如，在10−14 和 10−15 之間位置中途的值不是 5 × 10−15，而是 10−14.5 = 3.2 × 10−15。]

圖5.7

銅在金中擴散的擴散係數對數相對於絕對溫度倒數的圖。

因此，從圖5.7，在1/T1 = 0.8 × 10−3 (K)−1 時，log D1 = −12.40，而對於1/T2 = 1.1 × 10−3 (K)−1，log D2 = −15.45，並且從圖5.7中線段的斜率確定的活化能為

Qd = −2.3R [(log D1 − log D2)/(1/T1 − 1/T2)]
= −2.3(8.31 J/mol·K) [−12.40 − (−15.45)]/[0.8 × 10−3(K)−1 − 1.1 × 10−3(K)−1]
= 194,000 J/mol = 194 kJ/mol

現在，與其嘗試進行圖形外推以確定 D0，我們可以使用方程式5.9b分析地獲得更準確的值，並且我們獲得特定的 D（或 log D）值及其對應的 T（或1/T）從圖5.7。因為我們知道在1/T = 1.1 × 10−3 (K)−1 時 log D = −15.45，則

log D0 = log D + (Qd/2.3R)(1/T)
= −15.45 + [(194,000 J/mol)(1.1 × 10−3 [K]−1)]/[(2.3)(8.31 J/mol·K)]
= −4.28

因此，D0 = 10−4.28 m2/s = 5.2 × 10−5 m2/s。

設計範例 5.1

擴散溫度-時間熱處理規範

鋼齒輪的耐磨性將通過硬化其表面來改善。這將通過在稱為滲碳的過程中增加外表面層內的碳含量來實現；鋼件在升高且恆定的溫度下暴露於富含碳氫化合物氣體（如甲烷，CH4）的氣氛中。鋼的初始碳含量為0.20 wt%，而表面濃度將保持在1.00 wt%。為使此處理有效，必須在表面下方0.75 mm的位置建立0.60 wt%的碳含量。指定溫度在900至1050°C之間的適當熱處理，以溫度和時間表示。使用表5.2中γ-鐵中碳擴散的數據。

解答

因為這是一個非穩態擴散情況，讓我們首先使用方程式5.5，使用以下濃度參數值：

C0 = 0.20 wt% C

Cs = 1.00 wt% C

Cx = 0.60 wt% C

因此，

(Cx − C0)/(Cs − C0) = (0.60 − 0.20)/(1.00 − 0.20) = 1 − erf(x/(2√Dt))

因此，

0.5 = erf(x/(2√Dt))

關鍵術語定義：

  • 活化能（Activation energy, Qd）：產生一莫耳原子的擴散運動所需的能量
  • 預指數因子（Preexponential factor, D0）：與溫度無關的擴散常數
  • 氣體常數（Gas constant, R）：8.31 J/mol·K 或 8.62 × 10−5 eV/atom·K
  • 絕對溫度（Absolute temperature）：以開爾文（K）為單位的溫度
  • 溫度倒數（Reciprocal temperature）：1/T，用於製作擴散圖
