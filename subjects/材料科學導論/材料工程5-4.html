5.4 菲克第二定律—非穩態擴散

大多數實際的擴散情況是非穩態的——也就是說，在固體中某特定點的擴散通量和濃度梯度隨時間變化，導致擴散物種的淨累積或耗損。這在圖5.4中得到說明，該圖顯示了三個不同擴散時間的濃度分布。在非穩態條件下，使用方程式5.2是可能的但不方便；相反地，使用偏微分方程式

∂C/∂t = ∂/x (D ∂C/∂x) (5.4a)

圖5.4

在三個不同時間 t1、t2 和 t3 下的非穩態擴散濃度分布。

被稱為菲克第二定律。如果擴散係數獨立於組成（這應該針對每個特定的擴散情況進行驗證），方程式5.4a簡化為

∂C/∂t = D ∂2C/∂x2 (5.4b)

當指定了具有物理意義的邊界條件時，此表達式的解（濃度以位置和時間表示）是可能的。Crank 和 Carslow 和 Jaeger 給出了這些解的綜合集合（見參考文獻）。

一個在實際上重要的解是針對半無限固體3，其中表面濃度保持恆定。通常，擴散物種的來源是氣相，其分壓保持在恆定值。此外，做出以下假設：

  1. 在擴散之前，固體中任何擴散溶質原子均均勻分布，濃度為 C0。
  2. 表面處 x 的值為零，並隨著進入固體的距離而增加。
  3. 時間被認為在擴散過程開始之前的瞬間為零。

這些條件簡單地陳述如下：

初始條件

對於 t = 0，C = C0 在 0 ≤ x ≤ ∞

邊界條件

對於 t > 0，C = Cs（恆定表面濃度）在 x = 0

對於 t > 0，C = C0 在 x = ∞

將這些條件應用於方程式5.4b 得到解

(Cx − C0)/(Cs − C0) = 1 − erf(x/(2√Dt)) (5.5)

其中 Cx 代表時間 t 後深度 x 處的濃度。表達式 erf(x/2√Dt) 是高斯誤差函數4，其值在數學表中給出，用於各種 x/2√Dt 值；表5.1給出了部分列表。出現在方程式5.5中的濃度參數在圖5.5中標示，這是在特定時間拍攝的濃度分布。因此，方程式5.5展示了濃度、位置和時間之間的關係——即，Cx 作為無因次參數 x/√Dt 的函數，如果已知參數 C0、Cs 和 D，則可以在任何時間和位置確定。

假設希望在合金中達到某個特定的溶質濃度 C1；方程式5.5的左側現在變為

(C1 − C0)/(Cs − C0) = 常數

範例問題 5.2

非穩態擴散時間計算 I

對於某些應用，有必要使鋼（或鐵-碳合金）的表面硬化程度高於其內部。這可以通過在稱為滲碳的過程中增加碳的表面濃度來實現；在升高的溫度下，將鋼件暴露於富含碳氫化合物氣體（如甲烷，CH4）的氣氛中。

考慮一種這樣的合金，其初始碳濃度均勻為0.25 wt%，在950°C（1750°F）下進行處理。如果表面的碳濃度突然提升並保持在1.20 wt%，需要多長時間才能在表面下方0.5 mm的位置達到0.80 wt%的碳含量？

在此溫度下，鐵中碳的擴散係數為1.6 × 10−11 m2/s；假設鋼件為半無限。

解答

因為這是一個表面組成保持恆定的非穩態擴散問題，使用方程式5.5。此表達式中除時間 t 外的所有參數值在問題中均已指定如下：

C0 = 0.25 wt% C

Cs = 1.20 wt% C

Cx = 0.80 wt% C

x = 0.50 mm = 5 × 10−4 m

D = 1.6 × 10−11 m2/s

因此，

(Cx − C0)/(Cs − C0) = (0.80 − 0.25)/(1.20 − 0.25) = 1 − erf[(5 × 10−4 m)/(2√(1.6 × 10−11 m2/s)(t))]
0.4210 = erf(62.5 s1/2/√t)

範例問題 5.3

非穩態擴散時間計算 II

銅在鋁中於500°C和600°C的擴散係數分別為4.8 × 10−14 和 5.3 × 10−13 m2/s。確定在500°C下的大約時間，該時間將產生與在Al中某個特定點的銅濃度相同的擴散結果（就銅濃度而言），作為在600°C下10小時熱處理的結果。

解答

這是一個可以使用方程式5.6b的擴散問題。因為在500°C和600°C下，組成在某個位置 x0 保持相同，方程式5.6b可以寫為

x02/(D500t500) = x02/(D600t600)

結果為5

D500t500 = D600t600

或

t500 = D600t600/D500 = (5.3 × 10−13 m2/s)(10 h)/(4.8 × 10−14 m2/s) = 110.4 h

關鍵術語定義：

  • 菲克第二定律（Fick's second law）：描述非穩態擴散的偏微分方程式
  • 非穩態擴散（Nonsteady-state diffusion）：擴散通量和濃度梯度隨時間變化的擴散過程
  • 半無限固體（Semi-infinite solid）：在擴散時間內，擴散原子不會到達棒端的固體
  • 高斯誤差函數（Gaussian error function, erf）：用於描述非穩態擴散的數學函數
  • 滲碳（Carburizing）：增加鋼表面碳濃度的熱處理過程
  • 邊界條件（Boundary conditions）：描述邊界處狀態的條件
  • 初始條件（Initial condition）：描述初始狀態的條件
