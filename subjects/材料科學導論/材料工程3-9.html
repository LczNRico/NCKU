3.9 晶體學方向

晶體學方向（crystallographic direction）被定義為連接兩點之間的有向線，或稱為向量。以下步驟用於確定三個方向指數：

  1. 首先建立一個右手x-y-z座標系統。為方便起見，其原點可位於單位晶胞的角落。
  2. 確定位於方向向量上的兩點座標（參考座標系統）——例如，對於向量尾部，點1：x1、y1和z1；而對於向量頭部，點2：x2、y2和z2。5
  3. 尾部點座標從頭部點分量中減去——即，x2 − x1、y2 − y1和z2 − z1。
  4. 然後將這些座標差值以其各自的a、b和c晶格參數進行歸一化（即除以）——即，
    (x2 − x1) / a, (y2 − y1) / b, (z2 − z1) / c
    得到一組三個數字。
  5. 如有必要，將這三個數字乘以或除以一個公因數，以將它們化簡為最小整數值。
  6. 將得到的三個指數（不用逗號分隔）括在方括號內，如：[uvw]。u、v和w整數分別對應於相對於x、y和z軸的歸一化座標差值。

總結而言，u、v和w指數可使用以下方程式確定：

u = n((x2 − x1) / a)     (3.10a)

v = n((y2 − y1) / b)     (3.10b)

w = n((z2 − z1) / c)     (3.10c)

在這些方程式中，n是可能需要將u、v和w化簡為整數的因數。

對於三個軸中的每一個，都有正座標和負座標。因此，負指數也是可能的，用相應指數上方的橫線表示。例如，[111]方向在−y方向有一個分量。此外，改變所有指數的符號會產生一個反平行方向；即，[1̄1̄1̄]與[111]正好相反。如果要為特定晶體結構指定多於一個方向（或平面），則為保持一致性，一旦建立正負符號慣例後就不應改變。

[100]、[110]和[111]方向是常見的方向；它們繪製在圖3.7所示的單位晶胞中。

範例問題 3.7

方向指數的確定

確定附圖所示方向的指數。

解答

首先需要注意向量的尾部和頭部座標。從圖中可知，尾部座標如下：

x1 = a    y1 = 0b    z1 = 0c

對於頭部座標，

x2 = 0a    y2 = b    z2 = c/2

現在取點座標差值，

x2 − x1 = 0a − a = −a

y2 − y1 = b − 0b = b

z2 − z1 = c/2 − 0c = c/2

現在可以使用方程式3.10a到3.10c來計算u、v和w的值。然而，由於z2 − z1差值是分數（即c/2），我們預期為了使三個指數為整數值，需要將n設為2。因此，

u = n((x2 − x1) / a) = 2(−a / a) = −2

v = n((y2 − y1) / b) = 2(b / b) = 2

w = n((z2 − z1) / c) = 2(c/2 / c) = 1

最後，將−2、2和1指數括在方括號內，得到[2̄21]作為方向標記。6

此程序總結如下：

x y z
頭部座標 (x2, y2, z2) 0a b c/2
尾部座標 (x1, y1, z1) a 0b 0c
座標差值 −a b c/2
計算得到的 u, v, 和 w 值 u = −2 v = 2 w = 1
方括號表示 [2̄21]
範例問題 3.8

特定晶體學方向的構造

在下列單位晶胞中繪製一個[1̄10]方向，其尾部位於座標系統的原點O。

解答

此問題是通過反向執行前述範例的程序來解決的。對於此[1̄10]方向，

u = 1

v = −1

w = 0

因為方向向量的尾部位於原點，其座標如下：

x1 = 0a

y1 = 0b

z1 = 0c

我們現在想要求解向量頭部的座標——即x2、y2和z2。這可以使用方程式3.10a到3.10c的重新排列形式，並納入上述三個方向指數（u、v和w）和向量尾部座標的值來實現。將n的值取為1，因為三個方向指數都是整數，導致

x2 = ua + x1 = (1)(a) + 0a = a

y2 = vb + y1 = (−1)(b) + 0b = −b

z2 = wc + z1 = (0)(c) + 0c = 0c

此方向向量的構造過程顯示在附圖中。

由於向量的尾部位於原點，我們從標記為O的點開始，然後以逐步方式移動以定位向量頭部。因為x頭部座標（x2）為a，我們沿著x軸從點O移動a個單位到達點Q。從點Q，我們沿著與−y軸平行的方向移動b個單位到達點P，因為y頭部座標（y2）為−b。向量沒有z分量，因為z頭部座標（z2）為0c。最後，從點O到點P繪製一條線，如圖所示，以構造對應於此[1̄10]方向的向量。

對於某些晶體結構，具有不同指數的幾個非平行方向在晶體學上是等效的，這意味著沿每個方向的原子間距是相同的。例如，在立方晶體中，以下指數表示的所有方向都是等效的：[100]、[1̄00]、[010]、[01̄0]、[001]和[001̄]。為方便起見，等效方向被組合成一個族，括在角括號內，如：⟨100⟩。此外，在立方晶體中，具有相同指數但不考慮順序或符號的方向是等效的。也就是說，例如，[123]和[213]是等效的。這一般對其他晶體系統不成立。例如，對於四方對稱的晶體，[100]和[010]方向是等效的，而[100]和[001]則不是。

六方晶體中的方向

對於具有六方對稱性的晶體，會出現一個問題，即某些等效晶體學方向沒有相同的指數組。這種情況使用四軸或米勒-布拉維座標系統來處理，如圖3.8a所示。三個a1、a2和a3軸都包含在一個平面內（稱為基面），彼此之間成120°角。z軸垂直於此基面。方向指數按前述方法獲得，用四個指數表示，如[uvtw]；按慣例，u、v和t與基面中各a1、a2和a3軸的向量座標差值有關；第四個指數與z軸有關。

從三指數系統（使用圖3.8b的a1-a2-z座標軸）轉換到四指數系統的方式為

[UVW] → [uvtw]

使用以下公式完成7：

u = (1/3)(2U − V)     (3.11a)

v = (1/3)(2V − U)     (3.11b)

t = −(u + v)     (3.11c)

w = W     (3.11d)

這裡，大寫的U、V和W指數與三指數方案相關（而非之前的u、v和w），而小寫的u、v、t和w則與米勒-布拉維四指數系統相關。例如，使用這些方程式，[010]方向變為[12̄10]；此外，[12̄10]也等效於以下方向：[1̄21̄0]、[1̄21̄0]、[1̄21̄0]。

圖3.8：六方晶體單位晶胞的座標軸系統：(a) 四軸米勒-布拉維系統；(b) 三軸系統。

圖3.9的六方晶體單位晶胞中繪製了幾個方向。方向指數的確定使用類似於其他晶體系統所用的程序——通過從頭部點座標減去向量尾部點座標。為了簡化此程序的示範，我們首先使用圖3.8b的三軸a1-a2-z座標系統確定U、V和W指數，然後使用方程式3.11a至3.11d轉換為u、v、t和w指數。

三組頭部和尾部座標的標記方案如下：

軸 頭部座標 尾部座標
a1 a1″ a1′
a2 a2″ a2′
z z″ z′

使用此方案，方程式3.10a到3.10c的六方指數U、V和W等效形式如下：

U = n((a1″ − a1′) / a)     (3.12a)

V = n((a2″ − a2′) / a)     (3.12b)

W = n((z″ − z′) / c)     (3.12c)

在這些方程式中，包含參數n是為了在必要時便於將U、V和W化簡為整數值。

圖3.9：對於六方晶體系統，[0001]、[11̄00]和[112̄0]方向。
範例問題 3.9

六方單位晶胞的方向指數確定

對於附圖所示的方向，執行以下操作：

(a) 確定參考圖3.8b的三軸座標系統的方向指數。

(b) 將這些指數轉換為參考四軸方案（圖3.8a）的指數組。

解答

我們首先需要做的是確定參考草圖中表示的三軸方案的向量的U、V和W指數；這可以使用方程式3.12a到3.12c來完成。因為向量經過原點，a1′ = a2′ = 0a且z′ = 0c。此外，從草圖中，向量頭部的座標如下：

a1″ = 0a

a2″ = −a

z″ = c/2

因為z″的分母是2，我們假設n = 2。因此，

U = n((a1″ − a1′) / a) = 2((0a − 0a) / a) = 0

V = n((a2″ − a2′) / a) = 2((−a − 0a) / a) = −2

W = n((z″ − z′) / c) = 2((c/2 − 0c) / c) = 1

此方向通過將上述指數括在方括號中表示——即[021]。

(b) 要將這些指數轉換為參考四軸方案的指數組，需要使用方程式3.11a至3.11d。對於此[021]方向

U = 0     V = −2     W = 1

並且

u = (1/3)(2U − V) = (1/3)[(2)(0) − (−2)] = 2/3

v = (1/3)(2V − U) = (1/3)[(2)(−2) − 0] = −4/3

t = −(u + v) = −(2/3 − 4/3) = 2/3

w = W = 1

將前述指數乘以3可將它們化簡為最小組，得到u、v、t和w的值分別為2、−4、2和3。因此，圖中所示的方向向量為[242̄3]。

在給定指數組的情況下，繪製具有六方對稱性的晶體中方向向量所用的程序相對複雜；因此，我們選擇省略此程序的描述。

5 有時更方便的做法是將向量尾部定位在原點以外的某個點。

6 負號表示為橫線放在相應指數上方。

7 對於這些轉換，必須注意不要混淆大寫和小寫的u、v和w。
