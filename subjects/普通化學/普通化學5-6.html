5.6 氣體的動力分子理論

到目前為止，我們從實驗的角度考慮了氣體的行為。根據不同類型實驗的觀察，我們知道在低於1 atm的壓力下，大多數氣體非常接近理想氣體定律所描述的行為。現在我們想建構一個模型來解釋這種行為。

在建構模型之前，我們將簡要回顧科學方法。回想一下，定律是一種概括在許多實驗中觀察到的行為的方式。定律非常有用，因為它們允許我們預測類似系統的行為。例如，如果化學家製備了一種新的氣態化合物，在已知壓力和溫度下測量氣體密度可以提供該化合物莫耳質量的可靠數值。

然而，儘管定律總結了觀察到的行為，但它們並沒有告訴我們為什麼自然以觀察到的方式行為。這是科學家的核心問題。為了嘗試回答這個問題，我們建構理論（建立模型）。化學中的模型包含對個別原子或分子（微觀粒子）可能在做什麼的推測，以引起宏觀系統（大量原子和分子的集合）的觀察行為。

如果模型能夠解釋所討論的觀察行為並正確預測未來實驗的結果，則認為該模型是成功的。請注意，模型永遠無法被證明是絕對正確的。事實上，任何模型本質上都是一種近似，註定會在某個時候失效。模型的範圍從簡單到極其複雜。我們使用簡單的模型來預測近似行為，使用更複雜的模型來非常精確地解釋觀察到的定量行為。在本文中，我們將強調提供可能發生的事情的近似圖像並符合最重要實驗結果的簡單模型。

這種模型的一個例子是動力分子理論，這是一個試圖解釋理想氣體性質的簡單模型。該模型基於對個別氣體粒子（原子或分子）行為的推測。動力分子理論的假設可以陳述如下：

動力分子理論
  • 粒子與它們之間的距離相比非常小，以至於個別粒子的體積被假設為可忽略的（零）。
  • 粒子處於恆定運動中。粒子與容器壁的碰撞是氣體施加壓力的原因。
  • 假設粒子彼此不施加力；它們被假設為既不互相吸引也不互相排斥。
  • 假設一群氣體粒子的平均動能與氣體的克耳文溫度成正比。

當然，真實的氣體粒子確實具有有限的體積並且確實對彼此施加力。因此它們並不完全符合這些假設。但我們將看到這些假設確實解釋了理想氣體行為。

模型的真正檢驗是其預測與實驗觀察的吻合程度。動力分子模型的假設將理想氣體描繪為由沒有體積且彼此沒有吸引力的粒子組成，該模型假設氣體通過與容器壁的碰撞產生壓力。為了檢驗此模型的有效性，我們需要考慮這個問題：「當我們將物理學原理應用於這些氣體粒子的集合時，我們能否推導出一個與理想氣體定律一致的壓力表達式？」答案是，「是的，我們可以。」我們現在將詳細考慮這個推導。

批判性思考

您已經學習了動力分子理論的假設。如果我們不能假設第三個假設是真的會怎樣？這將如何影響測量的氣體壓力？

定量動力分子模型

假設在一個邊長各為L米的立方容器中有n莫耳理想氣體。假設每個氣體粒子的質量為m，並且處於快速、隨機、直線運動中，與壁碰撞（▶ 圖5.11）。碰撞將被假設為彈性—不發生動能損失。我們想要計算來自碰撞氣體粒子對壁的力，然後，由於壓力是單位面積的力，得到氣體壓力的表達式。

在我們推導氣體壓力的表達式之前，我們必須首先討論速度的一些特徵。氣體中的每個粒子都有一個特定的速度u，它可以分解為分量ux、uy和uz（▼ 圖5.12）。首先，使用ux和uy並應用畢達哥拉斯定理，我們可以得到uxy（圖5.12）：

uxy2 = ux2 + uy2

然後，如圖5.12所示構造另一個三角形，我們發現

u2 = uxy2 + uz2

或

u2 = ux2 + uy2 + uz2

現在讓我們考慮一個個別氣體粒子如何運動。例如，這個粒子多久會撞擊垂直於x軸的盒子的兩個壁？請注意，只有速度的x分量會影響粒子對這兩個壁的撞擊（▼ 圖5.13）。速度的x分量越大，粒子在這兩個壁之間移動的速度就越快，從而在單位時間內對這些壁產生更多的撞擊。請記住，氣體的壓力是由這些與壁的碰撞引起的。

(b) 對於彈性碰撞，速度的x分量和總速度的方向發生完全反轉。動量的變化（終態−初態）為
−mux − mux = −2mux

垂直於x軸的兩個壁的碰撞頻率（單位時間的碰撞次數）由下式給出：

（碰撞頻率）x = x方向的速度 / 壁之間的距離 = ux / L

接下來，碰撞的力是多少？力被定義為質量乘以加速度（單位時間內速度的變化）：

F = ma = m(Δu / Δt)

其中F代表力，a代表加速度，Δu代表速度的變化，Δt代表給定的時間長度。

由於我們假設粒子具有恆定的質量，我們可以寫成

F = mΔu / Δt = Δ(mu) / Δt

量mu是粒子的動量（動量是質量和速度的乘積），表達式F = Δ(mu)/Δt意味著力是單位時間內動量的變化。當粒子撞擊垂直於x軸的壁時，如圖5.13所示，發生彈性碰撞，導致速度的x分量發生完全反轉。也就是說，ux的符號或方向，當粒子與壁之一碰撞時會反轉。因此，最終動量是負的或與初始動量相反的。請記住，彈性碰撞意味著速度的大小沒有變化。x方向的動量變化為

動量的變化 = Δ(mux)
= 終態動量 − 初態動量
= −mux − mux
= −2mux

我們對氣體粒子對盒子壁施加的力的大小感興趣。由於我們知道每個作用都會產生一個相等但相反的反作用，因此撞擊時相對於壁的動量變化為−(−2mux)，或2mux。

回想一下，由於力是單位時間內動量的變化，那麼

Forcex = Δ(mux) / Δt

對於垂直於x軸的壁。

這個表達式可以通過將每次撞擊的動量變化乘以單位時間的撞擊次數來獲得：

Forcex = (2mux)(ux / L) = 單位時間內動量的變化

也就是說，

Forcex = 2mux2 / L

到目前為止，我們只考慮了垂直於x軸的盒子的兩個壁。我們可以假設垂直於y軸的兩個壁的力的大小由下式給出：

Forcey = 2muy2 / L

並且垂直於z軸的兩個壁的力的大小由下式給出：

Forcez = 2muz2 / L

壓力是單位面積的力，或者是撞擊壁的所有分子的力的總和除以壁的面積。壓力為：

Pressure = [2mux2 / L + 2muy2 / L + 2muz2 / L] / 6L2

由於我們已經證明

u2 = ux2 + uy2 + uz2

壓力等於

Pressure = [2m / L(ux2 + uy2 + uz2)] / 6L2 = [2m / L(u2)] / 6L2

現在，由於我們想要「平均」粒子引起的壓力，我們使用速度平方的平均值ū2來獲得：

「平均」粒子引起的壓力 = 2mū2L / 6L3 = mū2 / 3L3

化學洞察

分離氣體

假設您為一家擁有巨大天然氣儲層的石油公司工作，該儲層含有甲烷和氮氣的混合物。事實上，氣體混合物含有如此多的氮氣，以至於它不適合作為燃料。您的工作是從甲烷（CH₄）中分離氮氣（N₂）。您如何完成這項任務？您顯然需要某種「分子過濾器」，它能阻止稍大的甲烷分子（尺寸≈430 pm）並允許較小的氮分子（尺寸≈410 pm）通過。要完成這種尺寸相近的分子的分離，將需要非常精確的「過濾器」。

好消息是存在這樣的過濾器。新澤西州恩格爾哈德公司的Steven Kuznicki和Valerie Bell以及麻薩諸塞大學的Michael Tsapatsis製造了一種「分子篩」，其中的孔隙（通道）尺寸可以精確調整，以分離N₂分子和CH₄分子。所涉及的材料是一種特殊的水合鈦矽酸鹽（含有H₂O、Ti、Si、O和Sr），由恩格爾哈德申請專利並稱為ETS-4（恩格爾哈德鈦矽酸鹽-4）。當用於交換ETS-4中的鍶離子的鈉離子被替換並且新材料被仔細脫水時，會發生均勻且可控制的孔徑縮小（見圖）。研究人員已經表明，該材料可用於將N₂（≈410 pm）與O₂（≈390 pm）分離。他們還表明，有可能將天然氣的氮含量從18%降低到不到5%，甲烷回收率為90%。

鈦（藍色）、矽（綠色）和氧（紅色）原子在加熱時收縮的分子篩框架——在室溫下（左）d = 4.27 Å；在250°C時（右）d = 3.94 Å。

由於立方體的體積V等於L3，我們可以寫成

Pressure = P = mū2 / 3V

到目前為止，我們只考慮了由單個「平均」粒子對壁造成的壓力。當然，我們想要整個氣體樣品造成的壓力。給定氣體樣品中的粒子數可以表示為：

氣體粒子數 = nNA

其中n是莫耳數，NA是亞佛加厥常數。

因此，n莫耳氣體對盒子造成的總壓力為

P = nNA mū2 / 3V

接下來，我們想根據氣體分子的動能來表示壓力。動能（由運動引起的能量）由½mu2給出，其中m是質量，u是速度。由於我們使用速度平方的平均值（ū2），並且由於mū2 = 2(½mū2)，我們有

P = 2/3[nNA(½mū2) / V]

回想一下，P是氣體的壓力，n是氣體的莫耳數，NA是亞佛加厥常數，m是每個粒子的質量，ū2是粒子速度平方的平均值，V是容器的體積。

KE = ½ mu2，由粒子運動引起的能量。

量½mū2代表平均動能，屬於一個粒子。◀ 如果將個別粒子的平均動能乘以NA（一莫耳中的粒子數），我們得到一莫耳氣體粒子的平均動能：

(KE)avg = NA(½mū2)

使用這個定義，我們可以將壓力的表達式重寫為

P = 2/3[n(KE)avg / V]     或     PV / n = 2/3(KE)avg

動力分子理論的第四個假設是，氣體樣品中粒子的平均動能與克耳文溫度成正比。因此，由於(KE)avg ∝ T，我們可以寫成

PV / n = 2/3(KE)avg ∝ T     或     PV / n ∝ T

請注意，這個表達式是從動力分子理論的假設推導出來的。它與理想氣體定律相比如何——從實驗得到的方程式？比較理想氣體定律，

PV / n = RT     來自實驗

與動力分子理論的結果，

PV / n ∝ T     來自理論

這些表達式具有完全相同的形式，如果將R（通用氣體常數）視為第二種情況下的比例常數。

理想氣體定律與動力分子理論之間的一致性使我們對該模型的有效性充滿信心。我們為理想氣體粒子假設的特性必須在至少某些條件下與它們的實際行為一致。

溫度的意義

我們從動力分子理論中看到，克耳文溫度是氣體粒子平均動能的量度。可以通過組合以下方程式來獲得溫度與平均動能之間的確切關係

PV / n = RT = 2/3(KE)avg

這得出表達式

(KE)avg = 3/2RT

這是一個非常重要的關係。它總結了氣體的克耳文溫度的意義：克耳文溫度是氣體粒子隨機運動的指標，溫度越高意味著運動越大。

均方根速度

在來自動力分子理論的方程式中，氣體粒子的平均速度是一種特殊的平均值。符號ū2表示粒子速度平方的平均值。ū2的平方根稱為均方根速度，並用符號urms表示：

urms = √ū2

我們可以從以下方程式獲得urms的表達式

(KE)avg = NA(½mū2)     和     (KE)avg = 3/2RT

組合這些方程式得到

NA(½mū2) = 3/2RT     或     ū2 = 3RT / NAm

對最後一個方程式的兩邊取平方根得到

√ū2 = urms = √(3RT / NAm)

在這個表達式中，m代表以公斤為單位的單個氣體粒子的質量。當NA（一莫耳中的粒子數）乘以m時，其乘積是一莫耳氣體粒子以公斤為單位的質量。我們將這個量稱為M。將M代入NAm到urms的方程式中，我們得到

urms = √(3RT / M)

在我們使用這個方程式之前，我們需要考慮R的單位。到目前為止，我們使用0.08206 L atm K−1 mol−1作為R的值。但是為了獲得urms所需的單位（米每秒），R必須以不同的單位表示。如第5章所述，能量的SI單位是焦耳（J）。焦耳定義為公斤米平方每秒平方（kg m2/s2）。當R從升大氣壓轉換為焦耳時，它的值為8.3145 J K−1 mol−1。當R使用這些單位時

R = 0.08206 L atm K−1 mol−1
R = 8.3145 J K−1 mol−1

在表達式√(3RT/M)中使用時，urms的單位為米每秒，如所需。

到目前為止，我們對氣體樣品中實際發現的速度範圍沒有任何說明。在真實氣體中，粒子之間存在大量碰撞。例如，當釋放氨等有臭味的氣體時，氣味需要一些時間才能滲透空氣，如我們將在5.7節中看到的。這種延遲是由於NH3分子和O2和N2分子之間在空氣中進行混合過程的碰撞所致。

如果可以監控特定氣體粒子的路徑，它可能看起來非常不規則，如圖5.14 ◀ 所示。粒子在特定氣體樣品中碰撞之間移動的平均距離稱為平均自由徑。它通常是一個非常小的距離（在STP下，O2為1 × 10−7 m）。氣體粒子之間的許多碰撞的一個影響是產生大範圍的速度，因為粒子碰撞並交換動能。雖然在STP下氧氣的urms約為500 m/s，但大多數O2分子沒有這個速度。在STP下氧氣的分子速度的實際分布如圖5.15 ◀ 所示。該圖顯示了在氧氣分子中具有每個特定速度的相對數量。

我們也對溫度對速度分布的影響感興趣。圖5.16 ◀ 顯示了在三個溫度下氮氣的速度分布。請注意，隨著溫度升高，曲線的最大值（反映平均速度）向更高的值移動，速度範圍變得更大。

理想氣體中粒子的速度分布由馬克士威-波茲曼分布定律描述：

f(u) = 4π(m / 2kBT)3/2 u2e−mu2/2kBT

其中

u = 速度，以m/s為單位
m = 氣體粒子的質量，以kg為單位
kB = 波茲曼常數 = 1.38066 × 10−23 J/K
T = 溫度，以K為單位
圖5.16

在三個溫度下具有給定速度的N2分子的相對數量的圖。請注意，隨著溫度升高，平均速度（反映在曲線峰值處）和速度範圍都會增加。

這個方程式是由蘇格蘭物理學家James C. Maxwell和奧地利物理學家Ludwig E. Boltzmann獨立推導的，他們在理想氣體的動力分子描述的基礎理論工作中做了大量工作。函數f(u)du代表速度在u和u + du之間的氣體分子的分數，其中du代表一個無窮小的速度增量。這個函數就是在圖5.15和5.16中繪製的函數。

分析這個表達式可以得到以下方程式，用於最可幾速度 ump（由最大數量的氣體粒子所擁有的速度）：

ump = √(2kBT / m) = √(2RT / M)

其中

M = 氣體粒子的莫耳質量，以kg為單位 = 6.022 × 1023 × m
R = 氣體常數 = 6.022 × 1023 × kB

請注意，R和kB由亞佛加厥常數相關。事實上，將kB視為每個粒子（每個分子）的氣體定律常數是有用的。

可以從f(u)獲得的另一種速度類型是平均速度 uavg（有時寫作ū），由以下方程式給出：

uavg = ū = √(8kBT / πm) = √(8RT / πM)

因此，我們有三種方法來描述理想氣體中粒子的「典型」速度：均方根速度、最可幾速度和平均速度。從urms、ump和uavg的方程式可以看出，這些速度並不相同。事實上，它們的比率為

ump : uavg : urms = 1.000 : 1.128 : 1.225
