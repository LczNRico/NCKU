5.7 溢流與擴散

我們已經看到，分子動力論的假設結合適當的物理原理，產生了一個方程式，成功地擬合了氣體在接近理想行為時的實驗觀察性質。涉及氣體的兩種現象為這個模型提供了進一步的測試。

擴散是用來描述氣體混合速率的術語。當教室前方釋放少量刺鼻氣味的氨氣時，需要一些時間才能讓教室裡的每個人都聞到它，因為氨氣與空氣混合需要時間。擴散速率就是氣體混合的速率。溢流（effusion）是用來描述氣體通過微小孔口進入真空腔室的過程的術語（▼ 圖5.18）。溢流速率測量的是氣體轉移到腔室中的速率。

圖5.17

氮氣在273 K時的速度分布，標示了最可能速度 ump（曲線的最大值處的速度）、平均速度 uavg 和均方根速度 urms。

溢流

蘇格蘭化學家Thomas Graham（1805-1869）通過實驗發現，氣體的溢流速率與其粒子質量的平方根成反比。換句話說，在相同溫度和壓力下，兩種氣體的相對溢流速率由氣體粒子質量的平方根的反比給出：

氣體1的溢流速率 / 氣體2的溢流速率 = √M₂ / √M₁

其中 M₁ 和 M₂ 代表氣體的莫耳質量。▶ 這個方程式被稱為葛蘭姆溢流定律（Graham's law of effusion）。

注意：在葛蘭姆定律中，莫耳質量的單位可以是 g/mol 或 kg/mol，因為在比值 √M₂/√M₁ 中單位會相消。

圖5.18

氣體溢流進入真空腔室。溢流速率（氣體通過針孔屏障轉移的速率）與氣體分子質量的平方根成反比。

分子動力論模型是否正確預測了葛蘭姆定律所總結的氣體相對溢流速率？要回答這個問題，我們必須認識到氣體的溢流速率直接取決於其粒子的平均速度。氣體粒子移動得越快，它們越有可能通過溢流孔口。這個推理導致以下對在相同溫度 T 下兩種氣體的預測：

氣體1的溢流速率 / 氣體2的溢流速率 = 氣體1的 uavg / 氣體2的 uavg = √8RT/πM₁ / √8RT/πM₂ = √M₂ / √M₁

這個方程式就是葛蘭姆定律，因此分子動力論模型符合氣體溢流的實驗結果。

擴散

擴散經常通過圖5.19 ▼所示的課堂演示來說明，其中兩個棉塞，一個浸泡在氨水中，另一個浸泡在鹽酸中，同時放置在長管的兩端。在管中形成氯化銨（NH₄Cl）的白環，數分鐘後NH₃和HCl分子相遇：

NH₃(g) + HCl(g) ——→ NH₄Cl(s)
白色固體

氣體通過管子的過程令人驚訝地緩慢，考慮到在25°C時HCl和NH₃分子的速度分別約為450和660 m/s。為什麼NH₃和HCl分子需要幾分鐘才能相遇？答案是管子含有空氣，因此NH₃和HCl分子在通過管子時與O₂和N₂分子發生許多碰撞。雖然這些碰撞大大減慢了它們通過管子的進度，但仍然可以合理地預期NH₃和HCl分子所移動的相對距離與它們的速度有關：

dNH₃ / dHCl = NH₃移動的距離 / HCl移動的距離 = uavg(NH₃) / uavg(HCl) = √MHCl / √MNH₃ = √36.5 / √17 = 1.5

然而，仔細的實驗顯示，這個預測並不成立——觀察到的距離比為1.3，而不是葛蘭姆定律預測的1.5。

圖5.19

(a) NH₃和HCl分子通過空氣的相對擴散速率的演示。兩個棉塞，一個浸有HCl(aq)，另一個浸有NH₃(aq)，同時插入管子兩端。從棉塞蒸發的氣態NH₃和HCl向彼此擴散，在它們相遇的地方反應形成NH₄Cl(s)的白環。

(b) 當HCl(g)和NH₃(g)在管中相遇時，會形成NH₄Cl(s)的白環。

這種差異並非由於分子動力論或葛蘭姆定律的失敗；它的存在是因為這個「擴散」實驗並不涉及簡單的擴散過程。相反，它涉及氨和氯化氫氣體通過管中空氣的流動（flow）。因為NH₃和HCl分子與管中的N₂和O₂分子經歷許多碰撞，NH₃和HCl的流速與它們的分子速度不成直接比例。較高的速度導致更多的分子間碰撞，這反過來阻礙了氣體的流動。因為氨氣的質量較小（因此平均速度較高），氨氣的流動受到的阻礙比氯化氫氣體更大。因此，NH₃(g)移動的距離比從葛蘭姆定律預期的要小（觀察到的距離比小於1.5）。▶

注意：如果管中沒有空氣，距離比將如葛蘭姆定律所預測的為1.5。

雖然我們在這裡只給出了定性的處理，但伴隨氣體混合的現象已經得到很好的理解，這個實驗的結果可以用定量理論非常準確地描述。

儘管目前正在使用其他技術，但氣體擴散在核反應器用鈾的濃縮中發揮了重要作用。天然鈾主要是²³⁸U，它不能裂變產生能量。它只含有約0.7%的可裂變核素²³⁵U。為了使鈾作為核燃料有用，²³⁵U的相對含量必須增加到約3%。在氣體擴散濃縮過程中，天然鈾（含有²³⁸U和少量²³⁵U）與氟反應形成²³⁸UF₆和²³⁵UF₆的混合物。由於這些分子的質量略有不同，在給定溫度下它們具有略微不同的速度，這使得它們能夠通過多級擴散過程分離。

為了理解這個過程如何運作，想像一系列被半透膜隔開的腔室，這些膜允許一些UF₆分子通過，但防止氣體的大量流動。實際上，每個多孔壁的作用很像溢流池中的一個小孔。假設來自天然鈾的UF₆被放入腔室1中。因此，腔室1含有99.3% ²³⁸UF₆和0.7% ²³⁵UF₆（即每993個²³⁸UF₆分子對應1個²³⁵UF₆分子）。這種UF₆的一些分子通過半透膜擴散到腔室2中，該腔室最初是空的。由於其質量較小，²³⁵UF₆的速度略高於²³⁸UF₆，因此以略高的速率擴散。因此，腔室2將含有²³⁵UF₆與²³⁸UF₆的比值略高於7比993。

雖然這個過程被稱為氣體擴散，因為腔室被僅有效允許單個UF₆分子通過的屏障隔開，但它的行為像一個溢流過程。因此，我們可以從葛蘭姆定律找到腔室2中兩種類型UF₆的實際比值：

²³⁵UF₆的擴散速率 / ²³⁸UF₆的擴散速率 = √mass(²³⁸UF₆) / √mass(²³⁵UF₆)

= √352.05 g/mol / √349.03 g/mol

= 1.0043

²³⁵UF₆ / ²³⁸UF₆ = 1.0043 × (²³⁵UF₆ / ²³⁸UF₆) = 1.0043(7/993)

這個濃縮過程（在²³⁵UF₆中）隨著腔室2中的稍微濃縮的氣體擴散到腔室3中而繼續，並再次被因子1.0043濃縮。重複相同的過程，直到發生足夠的濃縮。顯然，這個過程需要很多階段。例如，要計算從0.700% ²³⁵U濃縮到3.00% ²³⁵U所需的步驟數，我們有以下方程式：
