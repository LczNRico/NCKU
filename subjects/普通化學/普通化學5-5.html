5.5 道爾頓分壓定律

引導約翰·道爾頓提出原子理論的實驗中，包括他對混合氣體的研究。1803年，道爾頓將他的觀察總結如下：對於容器中的混合氣體，其施加的總壓力等於每種氣體單獨存在時所施加的壓力之和。這個陳述，被稱為道爾頓分壓定律，可以表示如下：

P總 = P1 + P2 + P3 + ···

其中下標指的是各個氣體（氣體1、氣體2等）。壓力P1、P2、P3等被稱為分壓，也就是說，每種氣體單獨存在於容器中時所施加的壓力。

假設每種氣體都表現得理想，則每種氣體的分壓可以從理想氣體定律計算：

P1 = n1RT/V,    P2 = n2RT/V,    P3 = n3RT/V,    ···

混合物的總壓力P總可以表示為

P總 = P1 + P2 + P3 + ··· = n1RT/V + n2RT/V + n3RT/V + ···

= (n1 + n2 + n3 + ···)(RT/V) = n總(RT/V)

其中n總是各種氣體的莫耳數總和。因此，對於理想氣體的混合物，重要的是粒子的總莫耳數，而不是各個氣體粒子的身份或組成。這個概念如圖5.9所示。

圖5.9

混合氣體中每種氣體的分壓取決於該氣體的莫耳數。總壓力是各分壓的總和，並取決於氣體粒子的總莫耳數，無論其身份如何。

重要結論：這個重要結果表明了理想氣體的一些基本特徵。由理想氣體所施加的壓力由氣體粒子的身份（結構）揭示了關於理想氣體的兩件事：（1）個別氣體粒子的體積必定不重要，以及（2）粒子之間的作用力必定不重要。如果這些因素很重要，則施加的壓力將取決於個別粒子的性質。這些觀察將強烈影響我們最終構建來解釋理想氣體行為的模型。

此時我們需要定義莫耳分率：混合物中給定組分的莫耳數與混合物中總莫耳數的比值。希臘字母χ（chi）用來表示莫耳分率。對於混合物中的給定組分i，莫耳分率χi為

χ1 = n1/n總 = n1/n1 + n2 + n3 + ···

從理想氣體方程式，我們知道氣體的莫耳數與氣體的壓力成正比，因為

n = P(V/RT)

也就是說，對於混合物中的每種組分，

n1 = P1(V/RT),    n2 = P2(V/RT),    ···

因此，我們可以用壓力來表示莫耳分率：

χ1 = n1/n總 = P1(V/RT)/P1(V/RT) + P2(V/RT) + P3(V/RT) + ···

= (V/RT)P1/(V/RT)(P1 + P2 + P3 + ···)

= P1/P1 + P2 + P3 + ··· = P1/P總

同樣地，

χ2 = n2/n總 = P2/P總

依此類推。因此，理想氣體混合物中特定組分的莫耳分率與其分壓直接相關。

莫耳分率的表達式，

χ1 = P1/P總

可以重新排列為：

P1 = χ1 × P總

也就是說，氣體混合物中特定組分的分壓等於該組分的莫耳分率乘以總壓力。

當氣體通過水的置換收集時，就會出現氣體混合物。例如，圖5.10顯示了通過氯酸鉀的固體分解產生的氧氣的收集。

圖5.10

通過熱分解KClO3產生氧氣。MnO2催化劑與KClO3混合，使反應更快。

通過氯酸鉀固體的分解，在這種情況下，瓶中的氣體是水蒸氣和所收集氣體的混合物。水蒸氣的存在是因為水分子從液體表面逃逸並聚集在液體上方的空間中。水分子也會返回液體。

註：蒸氣壓將在第16章詳細討論。

當逃逸速率等於返回速率時，蒸氣狀態中的水分子數量保持恆定，因此水蒸氣的壓力保持恆定。這個壓力取決於溫度，稱為水的蒸氣壓。

道爾頓定律

空氣中氮氣的莫耳分率為0.7808。當大氣壓力為760. torr時，計算空氣中N2的分壓。

互動範例 5.8

水上收集氣體

在試管中加熱氯酸鉀（KClO3）固體樣品（圖5.10），並根據以下反應分解：

2KClO3(s) ⟶ 2KCl(s) + 3O2(g)

產生的氧氣在22°C下通過水的置換收集，總壓力為754 torr。收集的氣體體積為0.650 L，而22°C時水的蒸氣壓為21 torr。計算收集氣體中O2的分壓以及分解的樣品中KClO3的質量。

解答

我們要去哪裡？
我們被要求找出收集氣體中O2的分壓和原始樣品中反應物（KClO3）的質量

我們知道什麼？
我們有平衡方程式，並給出了氣體混合物的體積、溫度和總壓力，以及該溫度下水的蒸氣壓。

我們如何到達那裡？
由於氧氣和水蒸氣是混合物中唯一的氣體，我們可以從道爾頓分壓定律確定氧氣的分壓：

P總 = PO₂ + PH₂O = PO₂ + 21 torr = 754 torr

因此

PO₂ = 754 torr − 21 torr = 733 torr

現在我們必須從氧氣的分壓確定KClO3的質量。回想一下我們在化學計量問題中使用的策略。也就是說，我們可以從O2的莫耳數確定KClO3的質量，而我們可以從O2的莫耳數確定KClO3的莫耳數。我們知道O2的分壓。伴隨體積和溫度，我們可以使用理想氣體定律找出O2的莫耳數：

nO₂ = PO₂V/RT

在這種情況下

PO₂ = 733 torr = 733 torr/760 torr/atm = 0.964 atm
V = 0.650 L
T = 22°C + 273 = 295 K
R = 0.08206 L atm K−1 mol−1

因此

nO₂ = (0.964 atm)(0.650 L)/(0.08206 L atm K−1 mol−1)(295 K) = 2.59 × 10−2 mol

接下來，我們從分解KClO3的平衡方程式使用莫耳比來計算產生這個數量O2所需的KClO3莫耳數：

2.59 × 10−2 mol O2 × 2 mol KClO3/3 mol O2 = 1.73 × 10−2 mol KClO3

使用KClO3的莫耳質量，我們計算KClO3的克數：

1.73 × 10−2 mol KClO3 × 122.6 g KClO3/1 mol KClO3 = 2.12 g KClO3

因此原始樣品含有2.12 g的KClO3。

化學洞察

安全氣囊的化學

在現代汽車中加入安全氣囊已導致因車禍造成的傷害數量顯著減少。安全氣囊儲存在所有汽車的方向盤和儀表板中，許多汽車現在還配備了額外的安全氣囊來保護乘客的膝蓋、頭部和肩部。事實上，一些汽車製造商現在甚至在座椅安全帶中配備了安全氣囊。此外，由於安全氣囊的展開可能會嚴重傷害兒童，所有汽車現在都配備了"智能"安全氣囊，其展開力度與座位乘客的體重成比例。

術語"安全氣囊"實際上是一個誤稱，因為空氣並不參與充氣過程。相反，安全氣囊是由於爆炸性產生N2氣體而迅速充氣（約30毫秒）。最初使用的是疊氮化鈉，它會分解產生N2，

2NaN3(s) → 2Na(s) + 3N2(g)

但現在已被毒性較低的材料取代。

觸發安全氣囊的感應裝置必須反應非常迅速。例如，考慮一輛汽車撞到混凝土橋墩。當這種情況發生時，內部加速度計會向控制模組發送消息，表明可能發生碰撞。然後微處理器分析來自幾個加速度計和車門壓力感應器的測量減速度，並決定是否適合展開安全氣囊。所有這些都發生在初始撞擊的40毫秒內。

由於安全氣囊必須提供適當的緩衝效果，因此在充氣時氣囊就開始排氣。事實上，在碰撞事件的中期，氣囊中的最大壓力為5磅每平方英寸（psi）。安全氣囊代表了一個案例，其中爆炸性化學反應挽救了生命，而不是相反。
