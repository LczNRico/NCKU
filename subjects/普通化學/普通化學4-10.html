4.10 氧化還原反應

如我們所見，許多重要物質是離子化合物。例如，氯化鈉可由元素態的鈉和氯反應生成：

2Na(s) + Cl₂(g) ⟶ 2NaCl(s)

在此反應中，固態鈉含有中性鈉原子，與含有雙原子Cl₂分子的氯氣反應，生成含有Na⁺和Cl⁻離子的離子固體NaCl。此過程如圖4.19所示。像這樣涉及一個或多個電子轉移的反應，稱為氧化還原反應或氧還反應。

許多重要的化學反應涉及氧化和還原。事實上，大多數用於能源生產的反應都是氧還反應。在人類體內，糖類、脂肪和蛋白質的氧化提供了生命所需的能量。燃燒反應也涉及氧化和還原，它提供了大部分用於驅動我們文明的能源。一個例子是甲烷與氧氣的反應：

CH₄(g) + 2O₂(g) ⟶ CO₂(g) + 2H₂O(g) + 能量

儘管此反應中的反應物或生成物都不是離子化合物，但該反應仍被認為涉及電子從碳轉移到氧。為了解釋這一點，我們必須引入氧化數的概念。

氧化數

氧化數（又稱氧化態）的概念提供了一種在氧化還原反應中追蹤電子的方法。氧化數是由一組規則定義的，這些規則大多描述如何分配含有共價鍵的化合物中的共用電子。然而，在討論這些規則之前，我們需要討論鍵中電子的分布。

回想第4.1節中對水分子的討論，氧對電子的吸引力大於氫，導致水分子中的O—H鍵具有極性。這種現象也發生在其他鍵中，我們將在第13章詳細討論極性這個主題。現在，我們將滿足於一些一般性指導原則，以幫助我們

在氧化還原反應中追蹤電子。對共用電子吸引力最強的非金屬位於週期表右上角。它們是氟、氧、氮和氯。這些原子吸引共用電子的相對能力為：

F > O > N ≈ Cl
最強吸引力          最弱吸引力
對電子             對電子

也就是說，氟吸引共用電子的程度最大，其次是氧，然後是氮和氯。

互動範例 4.13

分配氧化數

為以下原子中的所有原子分配氧化數。

a. CO₂     b. SF₆     c. NO₃⁻

解答

a. 此處優先適用的規則是氧被分配氧化數-2。碳的氧化數可以通過認識到由於CO₂沒有電荷，氧化數的總和必須為0來確定。由於每個氧為-2且有兩個氧原子，碳原子必須被分配氧化數+4：

CO₂
+4  -2（每個氧）

b. 由於氟對共用電子的吸引力較大，我們首先分配其氧化數。因為氟在離子化合物中的電荷為1-，我們將每個氟原子的氧化數分配為-1。然後必須為硫分配氧化數+6，以平衡六個氟原子的總共-6：

SF₆
+6  -1（每個氟）

c. 由於氧對共用電子的吸引力大於氮，我們首先分配其氧化數為-2。因為三個氧的氧化數總和為-6，且NO₃⁻離子上的淨電荷為1-，氮必須具有氧化數+5：

NO₃⁻
+5  -2（每個氧）

實際電荷以n-或n+表示。氧化數（非實際電荷）以-n或+n表示。例如，對於NO₃⁻，整體電荷為1-；N的氧化數為+5，O的氧化數為-2。

表4.3
分配氧化數的規則
1. 元素態原子的氧化數為0。例如，Na(s)、O₂(g)、O₃(g)和Hg(l)中每個原子的氧化數為0。
2. 單原子離子的氧化數與其電荷相同。例如，Na⁺離子的氧化數為+1。
3. 在其與非金屬的共價化合物中，氫被分配氧化數+1。例如，在化合物HCl、NH₃、H₂O和CH₄中，氫被分配氧化數+1。
4. 氧在其共價化合物中被分配氧化數-2，例如CO、CO₂、SO₂和SO₃。此規則的例外情況發生在過氧化物（含有O₂²⁻基團的化合物）中，其中每個氧被分配氧化數-1。最著名的過氧化物例子是過氧化氫（H₂O₂）。
5. 在二元化合物中，對鍵中電子吸引力較大的元素被分配一個負氧化數，等於其在離子化合物中的電荷。例如，氟總是被分配氧化數-1。也就是說，為了計算電子，假設氟為F⁻。氮通常被分配-3。例如，在NH₃中，氮被分配氧化數-3；在H₂S中，硫的氧化數為-2；在HI中，碘被分配氧化數-1；依此類推。
6. 電中性化合物的氧化數總和必須為零，對於任何離子物種，氧化數總和必須等於整體電荷。例如，對於水中的氫和氧原子，氧化數之和為0；對於CO₃²⁻，碳和氧原子的氧化數之和為-2；對於NH₄⁺，氮和氫原子的氧化數之和為+1。
批判性思考

如果氧的氧化數被定義為-1而不是-2，會產生什麼影響（如果有的話）？這對氫的氧化數會有什麼影響？

四個氧的總共-8。因此每個鐵原子的氧化數為+8/3。氧化數為非整數值可能看起來奇怪，因為電荷以整數表示。然而，儘管它們很少見，非整數氧化數確實會出現，這是因為表4.3中的規則劃分電子的方式相當任意。在化合物Fe₃O₄中，例如，規則假設所有鐵原子都相等，而實際上這種化合物最好被視為含有四個O²⁻離子、兩個Fe³⁺離子和一個Fe²⁺離子（每個化學式單位）。（注意鐵的「平均」電荷為8/3+，等於我們上面確定的氧化數。）非整數氧化數不應使您感到困惑。它們的作用與整數氧化數相同——用於追蹤電子。

氧化還原反應的特徵

氧化還原反應的特徵是電子轉移。在某些情況下，這種轉移以字面意義發生形成離子，例如在此反應中：

2Na(s) + Cl₂(g) ⟶ 2NaCl(s)

然而，有時這種轉移是以更形式化的意義發生，例如在甲烷的燃燒中（給出每個原子的氧化數）：

CH₄(g) + 2O₂(g) ⟶ CO₂(g) + 2H₂O(g)
氧化數：
-4 +1    0      +4 -2    +1 -2
（每個H）                 （每個O）  （每個H）

請注意，O₂中氧的氧化數為0，因為它是元素態形式。在此反應中沒有離子化合物，但我們仍然可以用電子轉移的術語來描述這個過程。請注意，碳在CH₄中的氧化數從-4變為在CO₂中的+4。這樣的變化可以通過失去八個電子（符號e⁻代表一個電子）來解釋：

CH₄ ⟶ CO₂ + 8e⁻
-4        +4

另一方面，每個氧從O₂中的氧化數0變為H₂O和CO₂中的-2，表示每個原子獲得兩個電子。由於涉及四個氧原子，這是獲得八個電子的過程：

2O₂ + 8e⁻ ⟶ CO₂ + 2H₂O
0              4(-2) = -8

氫的氧化數沒有發生變化，因此它在形式上不涉及電子轉移過程。

有了這個背景，我們現在可以定義一些重要術語。氧化是氧化數的增加（失去電子）。還原是氧化數的減少（獲得電子）。因此在反應

2Na(s) + Cl₂(g) ⟶ 2NaCl(s)
0        0        +1  -1

鈉被氧化，氯被還原。此外，Cl₂被稱為氧化劑（電子接受體），Na被稱為還原劑（電子給體）。這些概念總結於圖4.20中。

圖4.20

氧化還原過程的摘要，其中M被氧化，X被還原。圖中顯示兩個圓形區域，左側是金黃色的M和藍綠色的X，通過「電子轉移」箭頭連接到右側的M⁺（較小的金黃色球）和X⁻（較大的藍綠色球）。

失去電子 獲得電子
氧化數增加 氧化數減少
還原劑 氧化劑

氧化是氧化數的增加。還原是氧化數的減少。

一個有用的記憶工具是OIL RIG（Oxidation Involves Loss；Reduction Involves Gain，氧化涉及失去；還原涉及獲得）。

關於反應

CH₄(g) + 2O₂(g) ⟶ CO₂(g) + 2H₂O(g)
-4  +1    0        +4  -2    +1  -2

我們可以說以下內容：

碳被氧化，因為其氧化數增加（碳在形式上失去了電子）。

氧被還原，如其氧化數的減少所示（氧在形式上獲得了電子）。

CH₄是還原劑。

O₂是氧化劑。

氧化劑被還原，還原劑在氧還反應中被氧化。

請注意，當命名氧化劑或還原劑時，指定的是整個化合物，而不僅僅是經歷氧化數變化的元素。
