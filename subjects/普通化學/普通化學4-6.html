4.6 描述溶液中的反應

在本節中，我們將探討用於表示溶液中反應的方程式類型。例如，當我們將鉻酸鉀水溶液與硝酸鋇水溶液混合時，會發生反應形成鉻酸鋇沉澱（BaCrO₄）和溶解的硝酸鉀。到目前為止，我們已經寫出了這個反應的分子方程式：

K₂CrO₄(aq) + Ba(NO₃)₂(aq) ⟶ BaCrO₄(s) + 2KNO₃(aq)

雖然這個方程式顯示了反應的反應物和產物，但它並未給出溶液中實際發生情況的清晰圖像。正如我們所見，鉻酸鉀、硝酸鋇和硝酸鉀的水溶液含有獨立的離子，而不是如分子方程式所暗示的分子。因此，完整離子方程式

2K⁺(aq) + CrO₄²⁻(aq) + Ba²⁺(aq) + 2NO₃⁻(aq)
⟶ BaCrO₄(s) + 2K⁺(aq) + 2NO₃⁻(aq)

更能準確地表示反應物和產物在溶液中的實際形式。在完整離子方程式中，所有強電解質物質都以離子形式表示。

強電解質是一種在水中溶解時會完全解離成離子的物質。

完整離子方程式顯示，只有部分離子參與反應。反應前後，K⁺和NO₃⁻離子都存在於溶液中。這些不直接參與溶液反應的離子稱為旁觀離子。參與此反應的離子是Ba²⁺和CrO₄²⁻離子，它們結合形成固體BaCrO₄：

Ba²⁺(aq) + CrO₄²⁻(aq) ⟶ BaCrO₄(s)

這個方程式稱為淨離子方程式，它僅包含直接參與反應的溶液組分。化學家通常會寫出反應在溶液中的淨離子方程式，因為它給出了反應物和產物的實際形式，並且僅包含發生變化的物種。

淨離子方程式只包含在反應中發生變化的組分。

範例 4.6

撰寫反應方程式

對於以下每個反應，請寫出分子方程式、完整離子方程式和淨離子方程式。

a. 將氯化鉀水溶液加入硝酸銀水溶液中，形成氯化銀沉澱和硝酸鉀水溶液。

b. 將氫氧化鉀水溶液與硝酸鐵(III)水溶液混合，形成氫氧化鐵(III)沉澱和硝酸鉀水溶液。

解答

a. 分子方程式：

KCl(aq) + AgNO₃(aq) ⟶ AgCl(s) + KNO₃(aq)

完整離子方程式（請記住，任何在水中溶解的離子化合物將以分離的離子形式存在）：

K⁺(aq) + Cl⁻(aq) + Ag⁺(aq) + NO₃⁻(aq) ⟶
↑
旁觀離子                           ↑
旁觀離子

                  AgCl(s) + K⁺(aq) + NO₃⁻(aq)
                  ↑
固體，
不寫成
分離的離子    ↑
旁觀離子    ↑
旁觀離子

淨離子方程式：消去旁觀離子，

K⁺(aq) + Cl⁻(aq) + Ag⁺(aq) + NO₃⁻(aq)
⟶ AgCl(s) + K⁺(aq) + NO₃⁻(aq)

得到以下淨離子方程式：

Cl⁻(aq) + Ag⁺(aq) ⟶ AgCl(s)

b. 分子方程式：

3KOH(aq) + Fe(NO₃)₃(aq) ⟶ Fe(OH)₃(s) + 3KNO₃(aq)

完整離子方程式：

3K⁺(aq) + 3OH⁻(aq) + Fe³⁺(aq) + 3NO₃⁻(aq)
⟶ Fe(OH)₃(s) + 3K⁺(aq) + 3NO₃⁻(aq)

淨離子方程式：

3OH⁻(aq) + Fe³⁺(aq) ⟶ Fe(OH)₃(s)
用於描述溶液中反應的三種方程式類型

1. 分子方程式給出了反應的整體化學計量，但不一定給出反應物和產物在溶液中的實際形式。

2. 完整離子方程式將所有強電解質的反應物和產物以離子形式表示。

3. 淨離子方程式僅包含發生變化的溶液組分。不包括旁觀離子。
