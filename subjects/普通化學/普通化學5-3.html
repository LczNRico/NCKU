5.3 理想氣體定律

我們已經考慮了三個通過實驗觀察揭示氣體行為的定律：

波以耳定律： V = k/P （在恆定 T 和 n 時）
查理定律： V = bT （在恆定 P 和 n 時）
亞佛加厥定律： V = an （在恆定 T 和 P 時）

這些關係顯示氣體體積如何依賴於壓力、溫度和存在的氣體莫耳數，可以如下組合：

V = R(Tn/P)

其中 R 是組合比例常數，稱為通用氣體常數。當壓力以大氣壓表示且體積以公升表示時，R 的值為 0.08206 L atm K−1 mol−1。前述方程式可以重新排列為更熟悉的理想氣體定律形式：

PV = nRT

理想氣體定律是氣體的狀態方程式，其中氣體的狀態是其特定狀態的條件，由壓力、體積、溫度和莫耳數描述。知道這四個性質中的任何三個就足以完全定義氣體的狀態，因為第四個性質可以從理想氣體定律的方程式中確定。

重要的是要認識到理想氣體定律是一個經驗方程式——它是基於對氣體性質的實驗測量而得出的。實質上，遵守此方程式的氣體被稱為理想行為。換句話說，這個方程式定義了理想氣體的行為，這是一個假設的物質。理想氣體方程式最好被視為極限定律——它表達了真實氣體在低壓和高溫下接近的行為。大多數氣體在 1 atm 以下的壓力下遵守此方程式，只會產生極小的誤差。除非給您相反的資訊，否則在本書中處理涉及氣體的問題時，您應該假設理想氣體行為。

註：R = 0.08206 L atm K−1 mol−1

註：理想氣體定律在 1 atm 以下的壓力下最適用。

互動範例 5.2

理想氣體定律 I

氫氣 (H₂) 樣品在 0°C 的溫度和 1.5 atm 的壓力下具有 8.56 L 的體積。計算此氣體樣品中存在的 H₂ 莫耳數。

解答 對 n 求解理想氣體定律得到

n = PV/(RT)

在此情況下 P = 1.5 atm，V = 8.56 L，T = 0°C + 273 = 273 K，且 R = 0.08206 L atm K−1 mol−1。因此

n = (1.5 atm)(8.56 L) / [(0.08206 L atm / K mol)(273 K)] = 0.57 mol

理想氣體定律經常用於計算當氣體條件改變時將發生的變化，如下所述。

互動範例 5.3

理想氣體定律 II

假設我們有一個氨氣樣品，在 1.68 atm 的壓力下體積為 3.5 L。氣體在恆溫下被壓縮至 1.35 L 的體積。使用理想氣體定律計算最終壓力。

解答 當使用理想氣體定律描述氣體狀態變化時，我們所做的基本假設是該方程式同樣適用於初始和最終狀態。

我們要去哪裡？

我們試圖確定在恆溫下被壓縮的氣體樣品的壓力。

我們知道什麼？

我們知道氣體樣品的原始體積和壓力以及新體積。我們也知道溫度保持恆定。

我們如何到達那裡？

在處理氣體時，我們對壓力、體積、溫度和莫耳數等狀態變化因素感興趣。在處理狀態變化時，我們應該總是問：「哪些因素改變，哪些因素保持不變？」然後我們將從理想氣體定律開始，並以這樣的方式重寫它，使得改變的因素在方程式的一側，保持不變的因素在方程式的另一側。在這種情況下，壓力和體積改變，而溫度和莫耳數保持不變（R 當然也是，根據定義）。因此我們將理想氣體定律寫為

PV = nRT
改變 保持不變

由於 n 和 T 在此情況下保持相同，我們可以寫 P₁V₁ = nRT 和 P₂V₂ = nRT。組合這些方程式得到

P₁V₁ = nRT = P₂V₂　　或　　P₁V₁ = P₂V₂

我們已知 P₁ = 1.68 atm，V₁ = 3.5 L，V₂ = 1.35 L。對 P₂ 求解得到

P₂ = (V₁/V₂)P₁ = (3.5 L / 1.35 L) × 1.68 atm = 4.4 atm

檢查：這個答案有意義嗎？體積減少（在恆溫下），所以壓力應該增加，正如計算結果所示。請注意，計算出的最終壓力為 4.4 atm。因為大多數氣體在 1 atm 以上不會理想地行為，我們可能會發現，如果我們測量此氣體樣品的壓力，觀察到的壓力會與 4.4 atm 略有不同。

互動範例 5.4

理想氣體定律 III

在 5°C 下體積為 3.8 L 的甲烷氣體樣品在恆壓下被加熱至 86°C。計算其新體積。

解答

我們要去哪裡？

我們試圖確定在恆壓下被加熱的氣體樣品的新體積。

我們知道什麼？

我們知道氣體樣品的原始體積和溫度以及新溫度。我們也知道壓力保持恆定。

我們如何到達那裡？

在處理狀態變化時，我們應該總是問並回答以下兩個問題：

哪些因素在改變？哪些因素保持不變？

溫度和體積在改變，壓力和氣體莫耳數保持不變。

為了解決這個問題，我們採用理想氣體定律，並通過將它們放在方程式的相對兩側來分離變化的變量和常數。在這種情況下，體積和溫度改變，莫耳數和壓力（當然還有 R）保持不變。因此 PV = nRT 變成

V/T = nR/P

這導致

V₁/T₁ = nR/P　　和　　V₂/T₂ = nR/P

組合這些方程式得到

V₁/T₁ = nR/P = V₂/T₂　　或　　V₁/T₁ = V₂/T₂

我們已知

T₁ = 5°C + 273 = 278 K　　T₂ = 86°C + 273 = 359 K
V₁ = 3.8 L　　V₂ = ?

因此

V₂ = (T₂V₁)/T₁ = (359 K)(3.8 L) / 278 K = 4.9 L

檢查：答案合理嗎？在這種情況下，溫度升高（在恆壓下），所以體積應該增加。因此答案是合理的。

範例 5.4 中的問題可以描述為查理定律問題，而範例 5.3 中的問題可以說是波以耳定律問題。然而，在這兩種情況下，我們都從理想氣體定律開始。使用理想氣體定律的真正優勢在於它適用於幾乎任何涉及氣體的問題，並且易於記憶。

互動範例 5.5

理想氣體定律 IV

一個乙硼烷氣體 (B₂H₆) 樣品，一種暴露在空氣中會爆炸成火焰的物質，在 −15°C 的溫度和 345 torr 的壓力下具有 3.48 L 的體積。如果條件改變使得溫度為 36°C 且壓力為 468 torr，樣品的體積會是多少？

解答

我們要去哪裡？

我們試圖確定壓力和溫度都改變的氣體樣品的新體積。

我們知道什麼？

我們知道氣體樣品的原始體積、壓力和溫度以及新的壓力和溫度。

我們如何到達那裡？

在處理狀態變化時，我們應該總是問並回答以下兩個問題：

哪些因素在改變？哪些因素保持不變？

壓力、體積和溫度在改變，氣體莫耳數保持不變。

讓我們以這樣的方式重寫理想氣體定律，使得改變的因素在方程式的一側，保持不變的因素在方程式的另一側。

由於對於此樣品，壓力、溫度和體積都改變，而莫耳數保持不變，我們使用以下形式的理想氣體定律

PV/T = nR

這導致

P₁V₁/T₁ = nR = P₂V₂/T₂　　或　　P₁V₁/T₁ = P₂V₂/T₂

然後

V₂ = (T₂P₁V₁) / (T₁P₂)

我們有

P₁ = 345 torr　　P₂ = 468 torr
T₁ = −15°C + 273 = 258 K　　T₂ = 36°C + 273 = 309 K
V₁ = 3.48 L　　V₂ = ?

因此

V₂ = (309 K)(345 torr)(3.48 L) / (258 K)(468 torr) = 3.07 L

由於範例 5.5 中使用的方程式涉及壓力的比值，因此不必將壓力轉換為大氣壓單位。torr 單位會抵消。（您可以通過將 P₁ = 345/760 和 P₂ = 468/760 代入方程式來獲得相同的答案。）然而，溫度必須始終轉換為克耳文標度；由於此轉換涉及 273 的加法，轉換因子不會抵消。要小心。

註：在應用理想氣體定律時，始終將溫度轉換為克耳文標度。
